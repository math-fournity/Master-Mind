# A 组参考材料：七政四余命宫与官禄宫分析

## 一、安命安身

命宫是整个星盘的起点，决定了十二宫的排列。

典籍依据：星平会海卷一五星变局——"命宫莫把他星取，但于安命求元守。行限须教论变通，便把局垣深考究。""元守者，元日所生之星，以安命之宫取之，以为主曜。"

### 命主星与度主星

- 一宫主：命宫地支所属五行的星曜为宫主。如命宫在寅，寅属木，木星为宫主。
- 二宫度：命宫所在宿的五行所属星曜为度主。

命主星（宫主）是命宫分析的核心——命主星的强弱、庙旺、与其他星曜的关系，决定了命宫的整体格局。

## 二、状态判断——庙旺平陷

每个天体在每个地支位置有不同的力量状态，从强到弱：

| 状态 | 含义 | 力量 |
|---|---|---|
| 殿 | 星曜入本殿（最高尊严） | 最强 |
| 垣 | 星曜入本垣 | 极强 |
| 庙 | 星曜入庙 | 强 |
| 旺 | 星曜入旺 | 较强 |
| 乐 | 星曜乐居 | 中等偏上 |
| 喜 | 星曜喜居 | 中等 |
| 怒 | 星曜怒居（受克） | 弱 |

庙旺平陷表是七政四余的核心数据之一——11个天体×12地支 = 132个状态。星曜在庙旺则力量充分发挥，在平陷则力量受制。

### 升殿

当星曜的五行与宿的五行一致时，称为"升殿"，力量最强。如木星在木宿（角/斗/奎/井）为木星升殿，太阳在日宿（房/虚/昴/星）为太阳升殿。

二十八宿五行归属：
- 木宿：角/斗/奎/井
- 金宿：亢/牛/娄/鬼
- 土宿：氐/女/胃/柳
- 日宿(火)：房/虚/昴/星
- 月宿(水)：心/危/毕/张
- 火宿：尾/室/觜/翼
- 水宿：箕/壁/参/轸

### 宿位泄气

星曜在非本五行宿位时：
- 如果星曜五行生宿五行 → 泄气（力量消耗）。如木星在尾宿(火宿)，木生火，为泄气。
- 如果星曜五行克宿五行 → 克宿（星曜与宿位不谐）。如水星在尾宿(火宿)，水克火，为克宿。
- 如果宿五行生星曜五行 → 受生（力量增强）。
- 如果宿五行克星曜五行 → 受克（力量压制）。

## 三、五行生克意识

五行生克是七政四余推命的第一意识。所有星曜分析——庙旺、恩用仇难、格局成破、限运吉凶——都建立在五行生克之上。

### 星曜五行

| 星曜 | 五行 |
|---|---|
| 日 | 火（阳火） |
| 月 | 水（阴水） |
| 木 | 木 |
| 火 | 火 |
| 土 | 土 |
| 金 | 金 |
| 水 | 水 |

### 宫位五行

| 宫位 | 地支 | 五行 |
|---|---|---|
| 子丑 | 子、丑 | 土 |
| 寅亥 | 寅、亥 | 木 |
| 卯戌 | 卯、戌 | 火 |
| 辰酉 | 辰、酉 | 金 |
| 巳申 | 巳、申 | 水 |
| 午 | 午 | 日（火之精） |
| 未 | 未 | 月（水之副） |

### 生克关系

正面关系（生）：木生火、火生土、土生金、金生水、水生木

反面关系（克）：木克土、土克水、水克火、火克金、金克木

比和：星曜与宫位同五行，如木星在寅(木宫)，无损耗无制约，力量完整保留。

### 以命主为核心的恩用仇难

以命宫地支五行为命主，其他星曜按与命主的生克关系分为四类：

| 关系 | 定义 | 含义 |
|---|---|---|
| 恩（生我） | 生命主五行的星曜 | 核心吉星，扶助命主 |
| 用（我生） | 命主所生的星曜 | 次吉，但泄命主之气 |
| 仇（克我） | 克命主五行的星曜 | 核心凶星，压制命主 |
| 难（我克） | 命主所克的星曜 | 次凶，但命主能制 |

恩用仇难定局表：

| 命宫 | 主 | 恩（生我） | 用（我生） | 仇（克我） | 难（我克） |
|---|---|---|---|---|---|
| 子丑 | 土 | 火罗 | 金 | 木炁 | 水孛 |
| 寅亥 | 木 | 水孛 | 火罗 | 金 | 土计 |
| 卯戌 | 火 | 木炁 | 土计 | 水孛 | 金 |
| 辰酉 | 金 | 土计 | 水孛 | 火罗 | 木炁 |
| 巳申 | 水 | 金 | 木炁 | 土计 | 火罗 |
| 午 | 日 | 金水 | 火罗 | 木炁 | （日不克不生） |
| 未 | 月 | 金 | 木炁 | 土计 | （月不克不生） |

### 庙旺判断中的五行

星曜的庙旺平陷不只是看星曜在哪个宫位，还要看五行关系。比如火星在寅亥（木宫）为入庙，因为木生火；在辰酉（金宫）为受克，因为火克金。

### 颠倒颠

五行生克不是简单的"生就好、克就坏"：
- 生太过反为害：如命主弱，恩星太多反把命主"溺爱"坏了
- 克中有生：如命主强，仇星反而是激发命主的力量（煞为权）
- 物随类化：命坐火宫，则官禄也属火，喜木气生，忌水孛克——不是只看命宫，十二宫都随命主五行取用

## 四、阴阳昼夜

昼生属阳，夜生属阴。

昼生以太阳为主、月亮为辅；夜生以月亮为主、太阳为辅。

昼生对星曜的影响：
- 太阳：昼生得时，力量增强
- 月亮：昼生失时（月喜夜），力量折损
- 木星：昼生木旺（阳木得阳助）
- 火星：昼生无特殊增损
- 水星：昼生无特殊增损
- 土星：昼生无特殊增损

## 六、官禄宫分析

### 官禄宫的基本概念

官禄宫代表命主的事业、功名、官职。官禄宫的判断与命宫类似，但有自己的特点：

1. **官主星**：官禄宫地支所属五行的星曜为官主。如官禄宫在亥，亥属木，木星为官主。
2. **官禄星曜配置**：官禄宫内有哪些星曜落入，这些星曜的庙旺状态。
3. **空宫判断**：如果官禄宫无星曜落入（空宫），则官禄宫的力量完全依赖官主星的状态。
4. **三方四正**：官禄宫的三合宫和对宫的星曜分布，对官禄宫有间接影响。

### 命官同主

当命宫和官禄宫同属一种五行时，命主星和官主星为同一颗星——这叫"命官同主"。

本命命宫在寅（木），官禄宫在亥（木），寅亥同属木，宫主同为木星——命官同主。

命官同主的含义：
- 命主=官主，命强则官强
- 命主星的状态同时决定命宫和官禄宫的根基
- 命主承载：命主极强则能承官禄之重——官禄虽好，命主弱则难以发挥；命主强则官禄可充分发挥

### 空宫的含义

官禄宫为空宫（无星曜落入）时：
1. 官禄宫本身无星，其力量完全依赖官主星的状态。官主星极强→官禄宫虽空但不弱。
2. 空宫不代表无事业——而是事业的力量来源不在官禄宫本身，而在命宫（因为命官同主）。
3. 空宫的吉凶取决于三方四正和宫主星：宫主极强+三方四正中性偏吉→官禄宫虽空但格局不差。

### 三方四正

三方四正是指一个宫位的三合宫（隔三宫的两个宫位）和对宫（隔六宫的宫位）。三方四正的星曜分布对目标宫位有间接影响。

官禄宫（亥）的三方四正：
- 三合宫：卯（财帛宫）、未（奴仆宫）
- 对宫：巳（田宅宫）

### 恩用仇难跨宫

恩用仇难不仅作用于命宫，也跨宫作用于官禄宫：
- 恩星（生我）生命主也扶官主——因为命主=官主
- 用星（我生）泄命主也泄官主
- 仇星（克我）克命主也克官主
- 难星（我克）命主能制也能制官主之难

### 颠倒颠跨宫

颠倒颠不仅适用于命宫，也跨宫适用于命官关系：
- 命主极强则能承受用星之泄（不被泄垮），官禄之泄同理——命主强则官禄之泄为输出而非消耗
- 煞为权：命主强时，仇星不是压制而是激发，对官禄也是如此
