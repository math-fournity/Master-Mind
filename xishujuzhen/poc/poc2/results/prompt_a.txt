## 题面

已知 a_1, a_2, ..., a_n 为实数，且 sum(a_i) = n, sum(a_i^2) = 2n, sum(a_i^3) = 3n。

证明存在常数 C_2 > 0 使得 max{a_1,...,a_n} - min{a_1,...,a_n} >= sqrt(5) + C_2 * n^(-3/2)。

## 参考材料（教材Markdown）

矩条件与极差：给定实数 a_1,...,a_n，其 k 阶矩定义为 m_k = sum(a_i^k)。矩条件约束变量分布，可用来推导极差下界。

常用方法：
1. 平移变换：通过 x_i = a_i - a_bar 把均值移到0，简化矩条件。平移不改变极差。
2. 构造多项式：寻找多项式 q(x)，使得 sum q(x_i) = 0，利用 q 的根的位置约束变量范围。
3. 分类讨论：根据变量是否落在 q 的根的邻域内进行分类。结合多个矩恒等式可以排除不可能的情形。
4. 数值试探：用具体数值例子检验猜想或确认最优常数。

不变量思维：在受约束的极值问题中，寻找不变量是关键。矩条件 sum q(x_i)=0 本身就是不变量关系。如果能找到两个独立的不变量关系，它们的组合可以给出更强的约束。

三点构型：极值构型常常退化为"两点或三点分布"。三点构型：k个点取值u，1个点取值y，n-k-1个点取值v。代入矩条件可以数值求解。

参考结论：对于本题条件，第一问的最优常数是 C = sqrt(5)（即 max-min >= sqrt(5)）。第二问需要在此基础上证明更精细的下界 sqrt(5) + C_2*n^(-3/2)。
