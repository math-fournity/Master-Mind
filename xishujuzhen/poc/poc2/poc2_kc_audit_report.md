### 节点：关键多项式

- 审计判定：✅

### 节点：投影到根
- KC内容：把变量投影到 q(x) 的根 r, s 附近。在极值构型中，大部分点集中在 r 和 s 附近，少数点偏离。
- 转译内容（第二章§3，行303-327）：将变量投影到根 r, s 附近。k个点在 r 附近（x_i = r + α_i），n-k-1个点在 s 附近（x_j = s + β_j），1个偏离点 y。展开 q(x_i) = (x_i-r)(x_i-s) 在根附近的一阶近似，得到恒等式 sum q(x_i)=0 的一阶近似形式。
- 审计判定：✅
- 说明：转译忠实反映了 kc 的"投影到根附近"和"大部分点集中在 r,s 附近，少数偏离"两个要点。补充的一阶展开（q(r+α_i) ≈ -sqrt(5)·α_i 等）数学正确，是对 kc 的合理丰富。

### 节点：扰动分析
- KC内容：在极值构型附近做扰动分析。设 x_i = x_i^0 + delta_i，代入矩条件，展开到一阶/二阶项。
- 转译内容（第三章§1，行356-380）：设 x_i = x_i^0 + δ_i，代入矩条件展开。一阶变分给出 ∑δ_i=0、∑x_i^0·δ_i=0、∑(x_i^0)^2·δ_i=0（三个正交条件，维度从 n 降到 n-3）。二阶变分给出 ∑δ_i^2 + 2∑x_i^0 δ_i = 0（来自 ∑x_i^2=n）和另一方程（来自 ∑x_i^3=-n）。
- 审计判定：⚠️
- 说明：转译忠实反映了 kc 的"设 x_i = x_i^0 + δ_i，代入矩条件，展开到一阶/二阶项"的核心内容。一阶变分的三个正交条件正确。但二阶变分中来自 ∑x_i^3=-n 的方程存在系数瑕疵：正确展开 (x_i^0+δ_i)^3 应得 3(x_i^0)^2·δ_i + 3x_i^0·δ_i^2 + δ_i^3，其中 x_i^0·δ_i^2 的系数应为 3，而转译写为"x_i^0 δ_i^2 + δ_i^2·x_i^0"（系数为2）。此为次要系数错误，不影响 kc 核心内容的忠实性，但数学精确性有瑕疵。

- 审计判定：✅

### 节点：badly_approximable
- KC内容：sqrt(5) 是二次无理数，其连分数展开 [2;4,4,4,...] 是周期的。二次无理数是 badly approximable 的：存在 c>0 使得 |sqrt(5) - p/q| > c/q^2 对所有有理数 p/q 成立。
- 转译内容（第四章§1，行463-486）：sqrt(5) 是二次无理数（x^2-5=0 的根），连分数展开 [2; overline{4,4,4,...}]，周期。BA 性质定义：partial quotients 有界 ⟺ 存在 c>0 使 |α-p/q| > c/q^2。二次无理数都是 BA 的（Lagrange 定理）。对 sqrt(5) 具体给出 |sqrt(5)-p/q| > c/q^2。
- 审计判定：✅
- 说明：转译忠实反映了 kc 的全部内容：二次无理性、连分数展开 [2;4,4,4,...]、周期性、BA 性质及 c/q^2 下界。补充的 Lagrange 定理（连分数周期 ⟹ partial quotients 有界 ⟹ BA）是 kc "二次无理数都是 BA"的正确理论依据。BA 性质的等价刻画（partial quotients 有界 ⟺ c/q^2 下界）数学正确。

### 节点：柯西不等式应用
- KC内容：用柯西不等式结合稳定性方程和 badly approximable 性质，得到扰动大小的下界为 O(n^(-3/2))，从而极差差额 >= C_2*n^(-3/2)。
- 转译内容（第四章§2，行509-538）：分四步结合稳定性方程和 BA 性质，用柯西不等式得到 n^(-3/2) 下界。给出柯西不等式 (sum|δ_i|)^2 <= n·sum δ_i^2，指数分解 n^(-3/2) = n^(-2)·n^(1/2)，其中 -2 来自 BA 性质，+1/2 来自柯西不等式维度因子。
- 审计判定：✅
- 说明：转译忠实反映了 kc 的"用柯西不等式结合稳定性方程和 BA 性质"和"极差差额 >= C_2*n^(-3/2)"两个核心要点。柯西不等式形式正确。指数分解 -3/2 = -2 + 1/2 是对 kc "O(n^(-3/2))"的合理结构阐释。注意 kc 中"O(n^(-3/2))"实为大O记号的轻微滥用（应为 Ω 表示下界），转译正确理解为下界，反而比 kc 更精确。
