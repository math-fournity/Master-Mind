# 大师-POC-1 A组回答（对照组·教材Markdown）

## 第一问的完整证明

### 步骤1：平移归一化

令 $x_i = a_i - 1$（因为 $\bar{a} = \frac{1}{n}\sum a_i = 1$），则：

$$\sum x_i = \sum(a_i - 1) = n - n = 0$$
$$\sum x_i^2 = \sum(a_i^2 - 2a_i + 1) = 2n - 2n + n = n$$
$$\sum x_i^3 = \sum(a_i^3 - 3a_i^2 + 3a_i - 1) = 3n - 6n + 3n - n = -n$$

极差不变：$\max a_i - \min a_i = \max x_i - \min x_i$。

**数学动机**：平移变换把均值移到 0，使矩条件标准化为整齐形式，便于后续构造多项式。这是教材中"平移变换"方法的应用。

### 步骤2：构造关键多项式

我们需要一个多项式 $q(x)$，使得 $\sum q(x_i) = 0$。

观察标准化后的矩条件：$\sum x_i = 0, \sum x_i^2 = n, \sum x_i^3 = -n$。

尝试 $q(x) = x^2 + x - 1$：

$$\sum q(x_i) = \sum(x_i^2 + x_i - 1) = n + 0 - n = 0 \checkmark$$

$q(x)$ 的根为：
$$r = \frac{-1 - \sqrt{5}}{2}, \quad s = \frac{-1 + \sqrt{5}}{2}$$
$$s - r = \sqrt{5}$$

**数学动机**：$q(x) = x^2 + x - 1$ 的选择不是随意的。我们需要 $\sum q(x_i) = 0$，即 $\sum x_i^2 + \sum x_i - n = 0$，也就是 $n + 0 - n = 0$。这个多项式同时利用了二阶矩和一阶矩条件。教材中提到"寻找多项式 q(x) 使得 sum q(x_i) = 0"，这里直接构造。

### 步骤3：导出第二个矩恒等式

计算 $\sum x_i q(x_i)$：

$$\sum x_i q(x_i) = \sum x_i(x_i^2 + x_i - 1) = \sum(x_i^3 + x_i^2 - x_i) = -n + n - 0 = 0$$

所以我们有两个恒等式：
$$\sum q(x_i) = 0 \quad (\*)$$
$$\sum x_i q(x_i) = 0 \quad (\*\*)$$

**数学动机**：教材中提到"如果能找到两个独立的不变量关系，它们的组合可以给出更强的约束"。第二个恒等式利用了三阶矩条件，与第一个恒等式独立。

### 步骤4：分类讨论证明极差 >= sqrt(5)

记 $m = \min x_i, M = \max x_i$。我们需要证明 $M - m \ge \sqrt{5} = s - r$。

反证法：假设 $M - m < \sqrt{5}$。

**4a. 区间 [m, M] 至少含一个根**

$q(x) = (x - r)(x - s)$ 在区间外为正（当 $x > s$ 或 $x < r$ 时），在区间内为负（当 $r < x < s$ 时）。

如果 $[m, M]$ 不含 $r$ 也不含 $s$，则 $q$ 在 $[m, M]$ 上恒正或恒负。
- 若恒正：所有 $q(x_i) > 0$，与 $\sum q(x_i) = 0$ 矛盾。
- 若恒负：所有 $q(x_i) < 0$，与 $\sum q(x_i) = 0$ 矛盾。

所以 $[m, M]$ 至少含一个根。

**4b. [m, M] 不能只含一个根**

假设 $M - m < \sqrt{5} = s - r$，则 $[m, M]$ 不可能同时含 $r$ 和 $s$（因为两根距离为 $\sqrt{5}$）。所以 $[m, M]$ 恰好含一个根。

**情形1**：$[m, M]$ 只含 $s$（不含 $r$）。

此时 $r < m \le s \le M < r + \sqrt{5} = s$ 不对，应该是 $r < m$ 且 $s \in [m, M]$。

- $x_i > s$ 时 $q(x_i) > 0$（在 $s$ 右侧）
- $x_i < s$ 时 $q(x_i) < 0$（在 $r$ 和 $s$ 之间，或 $x_i < r$ 但 $r < m$ 所以不会）

令 $W = \sum_{q(x_i)>0} q(x_i) = -\sum_{q(x_i)<0} q(x_i) > 0$。

对于 $q(x_i) > 0$ 的点，$x_i > s$，所以 $x_i > s$。
对于 $q(x_i) < 0$ 的点，$x_i < s$，所以 $x_i < s$。

因此：
$$\sum x_i q(x_i) = \sum_{q>0} x_i q(x_i) + \sum_{q<0} x_i q(x_i)$$
$$> s \sum_{q>0} q(x_i) + s \sum_{q<0} q(x_i) = s \cdot 0 = 0$$

等等，这里需要更仔细。$q(x_i) > 0$ 的点 $x_i > s$，所以 $x_i q(x_i) > s \cdot q(x_i)$。$q(x_i) < 0$ 的点 $x_i < s$，所以 $x_i q(x_i) > s \cdot q(x_i)$（因为 $q(x_i) < 0$，不等号反转）。

因此 $\sum x_i q(x_i) > s \sum q(x_i) = 0$，与 $(\*\*)$ 矛盾。

**情形2**：$[m, M]$ 只含 $r$（不含 $s$）。

类似地，$q(x_i) > 0$ 的点 $x_i < r$，$q(x_i) < 0$ 的点 $x_i > r$（但 $x_i < s$）。

$q(x_i) > 0$ 的点 $x_i < r$，所以 $x_i q(x_i) < r \cdot q(x_i)$（$q > 0$）。
$q(x_i) < 0$ 的点 $x_i > r$，所以 $x_i q(x_i) < r \cdot q(x_i)$（$q < 0$，不等号反转）。

因此 $\sum x_i q(x_i) < r \sum q(x_i) = 0$，与 $(\*\*)$ 矛盾。

**结论**：两种情形都矛盾，所以 $[m, M]$ 必须同时含 $r$ 和 $s$，从而 $M - m \ge s - r = \sqrt{5}$。

**数学动机**：分类讨论结合两个恒等式——第一个恒等式排除"不含根"，第二个恒等式排除"只含一个根"。这是教材中"结合多个矩恒等式排除不可能情形"方法的应用。

### 步骤5：确认 sqrt(5) 是最优常数

用三点构型检验：取 $k$ 个点为 $u$，1 个点为 $y$，$n-k-1$ 个点为 $v$，代入矩条件：

$$ku + y + (n-k-1)v = 0$$
$$ku^2 + y^2 + (n-k-1)v^2 = n$$
$$ku^3 + y^3 + (n-k-1)v^3 = -n$$

数值求解（如 $n=500$），可得 $v - u \approx \sqrt{5} + O(1/n)$，说明 $\sqrt{5}$ 可以逼近，是最优常数。

**数学动机**：教材中提到"用具体数值例子检验猜想"。三点构型是矩约束极值问题的典型极值构型。

因此 $C = \sqrt{5}$。

## 第二问的判断

### 初步分析

第二问声称存在 $C_2 > 0$ 使得 $\max a_i - \min a_i \ge \sqrt{5} + C_2 n^{-1/3}$。

由第一问的证明和三点构型的数值试探，我们知道极差可以逼近 $\sqrt{5}$，且逼近的速率是 $O(1/n)$（从三点构型 $v - u = \sqrt{5} + O(1/n)$ 可见）。

### 数值检验

取 $n = 500$ 的三点构型，极差差额约为 $0.0018$，即 $O(1/n)$ 量级。

而 $500^{-1/3} \approx 0.126$。

如果第二问成立，则极差差额应至少为 $C_2 \cdot 0.126$，即常数级。但实际差额只有 $0.0018$ 量级，远小于 $0.126$。

因此，**第二问的指数 $n^{-1/3}$ 是错误的**。

### 正确版本

三点构型显示极差差额为 $O(1/n)$。因此，正确的第二问应该是：

$$\max a_i - \min a_i \ge \sqrt{5} + C_2 \cdot n^{-\alpha}$$

其中 $\alpha$ 应使得 $n^{-\alpha} = O(1/n)$ 或更小，即 $\alpha \ge 1$。

但更精确地说，第二问要给出一个**可达的下界**，而不仅仅是上界。三点构型给出的是上界（极差可以多小），第二问需要的是下界（极差至少多大）。

从三点构型 $v - u = \sqrt{5} + O(1/n)$ 可知，极差差额至少是 $O(1/n)$ 量级。因此正确的指数应该是 $\alpha = 1$，即：

$$\max a_i - \min a_i \ge \sqrt{5} + C_2 / n$$

但更仔细的分析需要考虑三点构型是否真的是最坏情况。如果三点构型给出了最小的极差差额，那么 $O(1/n)$ 就是正确的量级。

**结论**：第二问指数 $n^{-1/3}$ 错误，正确指数应为 $n^{-1}$ 或更小。$n^{-1/3}$ 太大了——它要求的下界远超实际可达的极差。

## 证明过程中每一步的数学动机

1. **平移归一化**：把均值移到 0，矩条件变整齐，便于构造多项式。动机：简化计算。
2. **构造 $q(x) = x^2 + x - 1$**：需要 $\sum q(x_i) = 0$，即利用二阶矩和一阶矩条件。动机：寻找不变量关系。
3. **第二个恒等式**：$\sum x_i q(x_i) = 0$ 利用三阶矩。动机：获得更强的约束。
4. **分类讨论**：用第一个恒等式排除"不含根"，第二个排除"只含一个根"。动机：两个独立约束的组合比单个更强。
5. **三点构型数值检验**：确认 $\sqrt{5}$ 可逼近。动机：证明下界后需确认最优性。
6. **第二问数值检验**：$n=500$ 时差额 $O(1/n)$ 远小于 $n^{-1/3}$。动机：检验命题自洽性。
