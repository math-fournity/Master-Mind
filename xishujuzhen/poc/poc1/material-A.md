# 矩条件与极差

给定实数 $a_1, \ldots, a_n$，其 $k$ 阶矩定义为 $m_k = \sum a_i^k$。

矩条件约束了变量的分布，可以用来推导极差（max - min）的下界。

## 常用方法

### 1. 平移变换

通过 $x_i = a_i - \bar{a}$ 把均值移到 0，简化矩条件。平移不改变极差。

### 2. 构造多项式

寻找一个多项式 $q(x)$，使得 $\sum q(x_i) = 0$，利用 $q$ 的根的位置约束变量的范围。

如果 $q$ 在区间 $[m, M]$ 外恒正（或恒负），而 $\sum q(x_i) = 0$，那么不可能所有 $x_i$ 都落在同一侧——这给出了极差的下界估计。

### 3. 分类讨论

根据变量是否落在 $q$ 的根的邻域内进行分类。结合多个矩恒等式可以排除不可能的情形。

### 4. 数值试探

用具体数值例子检验猜想或确认最优常数。在证明不等式之前，先用具体数值例子检验命题是否自洽是一个好习惯。如果数值与命题矛盾，可能命题本身有误。

## 不等式证明中的不变量思维

在受约束的极值问题中，寻找不变量（在变换下保持不变的量）是关键。矩条件 $\sum q(x_i) = 0$ 本身就是一个不变量关系——无论 $x_i$ 怎么变，只要满足矩条件，这个等式就成立。

如果能找到两个独立的不变量关系（例如 $\sum q(x_i) = 0$ 和 $\sum x_i q(x_i) = 0$），它们的组合可以给出更强的约束。

## 三点构型

在矩约束极值问题中，极值构型常常退化为"两点或三点分布"——即 $n$ 个变量只取 2-3 个不同的值。这是因为矩约束数量有限（3 个矩条件），自由度不足以支撑更复杂的构型。

三点构型：$k$ 个点取值 $u$，1 个点取值 $y$，$n-k-1$ 个点取值 $v$。代入矩条件可以数值求解。

## 参考结论

对于本题的条件 $\sum a_i = n, \sum a_i^2 = 2n, \sum a_i^3 = 3n$，第一问的最优常数是 $C = \sqrt{5}$。
