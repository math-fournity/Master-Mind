# 算思（Operatorial Thinking）— 系统目录

> **本目录方法论体系正式命名**：**算思 / Operatorial Thinking**（2026-09-28 用户裁定，
> 定义/边界/战绩/命名约定见 `naming.md`）。本 README 是其调查资产入口。
> **执行制度**：执行算思任务时，必须先加载 `ot-closure.md`（执行闭包）+ `ot-sop.md`（SOP，
> 含文档合同：每份产出文档的章节结构与刻画维度）；新任务开卷建 `ot-<任务名>/` 子目录，
> 按两模式（M-A 增量建造 / M-B 存量执行）与六道质量门（G1–G6）运行。
> **沉淀制度**：任务产出分三类沉淀（A 对象知识留任务内 / B 可复用资产入 `assets/` /
> C 系统迭代提案入 `docs/proposals/`）——规则见 `docs/SEDIMENTATION.md`，收口走 G6 沉淀门。
>
> **⭐ 必读对话存档**：`docs/DIALOGUE-foundation-discovery-20260928.md` —— 十轮问答完整记录，
> 通过用户逐轮追问发现了算思系统的**第0层前提（计算阅读框架）**、目的不变式、三因子模型、
> 只需一跃原理。**任何接手算思系统的 AI，读完闭包和 SOP 后，下一步读本文件。**

## 一句话结论

用户判断成立并精确化一处：HoTT 交接仓 48 条用户原文证据显示，悖论观察结构是 **6 层面 ×
10 facet 的立体网格**（两个幽灵的"复活"=同一网格坐标在新理论上的重新命中，即算子化操作本身）；

（OP-0..OP-7 + 三条反先验/现实对齐/人工判据纪律），完全自动化不可行处恰在价值排序层。
