# AS-FRAME-DIST — 六轴距离框架

> 类：FRAME｜来源：Distance-B1｜版本 v1.0

比较两个数学工作体（如：本方法 vs 一台自动证明系统；本方法 vs 一位大师）的"距离"时，按六轴展开，每轴先立证据再下裁决：

1. **路线轴**——路线是生成的还是继承的？（蓝图来源考证）
2. **算子轴**——己方算子在对方产物中能否找到文件级/工作级对应物？
3. **粒度轴**——对方的分解粒度从何而来（蓝图/自组织）？与己方算子粒度比较。
4. **仲裁轴**——双方的正确性判据形态是否收敛（人工读/机器查）？
5. **货架轴**——双方可用的机械就绪度差异（决定性增量清单）。
6. **意义轴**——该距离对己方方法结论的反身影响（加固/修正/互补）。

使用纪律：同构判定须逐环给出对应关系与差异；差异项（如"修复环"的有无）往往是信息量最大处。
