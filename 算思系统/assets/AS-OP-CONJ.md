# AS-OP-CONJ — 合取审计算子（G1 缺失修复）

> 来源：生成性实验（用户观察 KC-000003/019 中网格未恢复的核心项）

| 字段 | 值 |
|---|---|
| 名称 | 合取审计（Conjunction Audit） |
| 输入 | 一个悖论/矛盾的结论 |
| 前置条件 | 已完成 Z2 前提考古（知道前提是什么） |
| 动作 | 把理论的前提分解为合取式：P = P₁∧P₂∧…∧Pₙ；对每个 Pᵢ 单独标记"这一项对应现实吗？如果这项为假，矛盾是否消失？" |
| 输出 | 逐项真假标记的前提清单 + 定位到具体的"假与项"（= 非现实前提） |
| 失败模式 | 前提不是独立与项而是嵌套结构（需要先展开嵌套）；把推论当前提（假与项必须在前提层不在结论层） |
| 粒度 | 单个前提项 |
| 机器化状态 | 概念层可形式化（合取分解+逐项检验）；需要自然语言理解来自动分解前提 |

用户原话锚点：KC-000003/019"全真才真一假即假"；KC-000047"合取推断中的前提……可以逐项审查"。
