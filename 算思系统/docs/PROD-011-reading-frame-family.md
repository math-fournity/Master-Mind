# PROD-011 — 阅读框架家族化：从单一第 0 层到多镜头体系

> **触发**（用户 2026-09-28 原话要义）："打穿认同的力量除了来自定理的产出，还来自我们有力的
> '程序'。但是我们的程序来自罗素悖论，我怀疑、担心这会狭隘化。"
> **诊断**：担心已被证据证实——Huh 试点出现两处 facet 语义平移（F1 攻击→解释、F9 反证→
> 反例检验），且 H1-H5 核心算子无一来自 Z/R 族（悖论系）；计算读法在结构转移类问题上不
> 适用。现行第 0 层是**从悖论单案例过拟合的**。

## 1. 结构性诊断

现行算思系统的"程序面"（阅读框架+算子族）诞生于单一认知源：用户对悖论的计算读法。
由此长出的一切（Z 族/R 族/构造-查询二分/幽灵检测）在"理论与计算现实之间有裂缝"这类
问题上强大，但对以下类型的数学**不是正确镜头**：

- 结构转移类（Huh：拟阵当代数簇读——核心操作是类比，不是审计）
- 解析估计类（筛法/圆法——核心操作是量级与消长，不是停机）
- 几何直觉类（完备空间/上同调——核心操作是"看"到几何对象，不是程序化）

**如果用悖论系镜头跑 68 人，将发生系统性错译：所有思维被强翻成"哪里有幽灵"，而真正
的思维动作（类比/不变量/形状复用/几何视觉化）被漏掉。**

## 3. 对"打穿认同"的影响

程序面的力量来自**它能在多少种不同类型的数学上启动**。单一悖论系镜头只能对基础论/
可计算性社区有效（极窄受众）；六镜头家族才能覆盖代数/几何/分析/组合/数论各社区。
**镜头家族的多样性 = 程序面认同面的宽度。**

## 4. 预注册多样性审计（68 人项目首批执行）

在 1936-1966 首批（~12 人）执行时统计：
- 每位得主的关键思维动作中，**悖论系算子（Z/R 族）能覆盖的比例**；
- 需要类比/不变量/几何/生态/戏剧镜头的比例；
- 完全无法用现有六镜头捕获的比例（→新镜头候选）。

预注册预期：悖论系覆盖 <30%；六镜头合计覆盖 >70%；余下为新镜头源。如果悖论系覆盖
>50%，说明 68 人执行发生了系统性错译（用悖论镜头硬套），需要纠偏。
