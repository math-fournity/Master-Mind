# P-004 — 第二轮 Anthropic FLT 考察的深度确定协议

- **问题**（用户 2026-09-28）：是否应继续考察 Anthropic FLT 证明？第二轮深度是动态确定
  还是能提前确定？
- **分析**：纯提前确定（固定页数/文件数）会重演"蛮干 vs 靶向"的老问题（KC-000048）；纯
  动态确定则失去可审计性（深度由执行者情绪决定）。**裁定：分层混合——预算提前定，靶点
  动态选**（预算=承诺，靶点=策略）。
- **建议修订条**（作为 M-B 类任务的深度协议，可复用）：
  1. **L0 已完成层**（不再重跑）：PROOF-PATH 全文、README、文件名级统计、3 个文件头、
     外部官方文——B1 批六轴已闭环。
  2. **L1 靶向层（第二轮主体，预算提前定）**：只做四个有明确假设的靶向，每个预算固定——
     ① **W 算子逐个验证**（预算：每算子 ≤3 个证明文件抽样，只读 PROOF-PATH 指名文件）；
     ② **DAG 结构三点抽样**（预算：3 个子图各 ≤50 节点，测分叉/扇出/深度）；
     ③ **ATTRIBUTION 全表量化**（预算：106+23 行全读一遍，产出货架剖面表）；
     ④ **外部过程材料**（官方技术 PDF 全读：失败次数/重试机制/蓝图修订史）。
  3. **L2 动态层（预算池制）**：L1 执行中发现的意外线索（如某主题异常分布、某失败模式
     反复出现）可从池中支领取样——**池总量提前定**（≤30 文件/页），单支取须在 batches
     记录理由；池用尽即停，新线索登记 FND 留给第三轮。
  4. **停止判据（提前定）**：四靶向各有预设交付物（映射表精化/DAG 剖面/货架表/过程时间
     线）；交付齐即停——**不设"看够为止"这类不可审计判据**。
- **是否继续的建议**：值得做第二轮（L0 层留了三个 med 置信关系与 D3 粒度机制未解），但
  优先级让位于两个更高价值项：B 关对抗重放（用户开新会话）与 68 人全景语料；本协议就绪
  后随时可跑。
- **触发条件**：用户下令启动第二轮时，本协议直接实例化为任务 CLOSURE。
- **状态**：open（2026-09-28 立）
