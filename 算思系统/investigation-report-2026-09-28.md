## 3. 结构分析：单一概念格为何不够

FCA 概念格 = 单一形式背景（对象×属性）导出的一个偏序。表达力上它可以登记任意属性，但对该
认知结构有三处**结构性失配**（非实现细节问题）：

1. **轴独立性丢失**。层面族与 facet 族是两个近正交的投影族：F3（时间）与 F4（经济性）互不
   包含、同时作用于多个层面。格中一切属性进入同一偏序，"可比性"语义被强加于本不可比的观察
   方向——立体结构被压成一维。
2. **层次自反性缺失**。L6（观察者层）观察并批判其余层的认知来源（KC-000017/042）。格是单层
   对象语言，无内建的反射/索引结构来表达"关于本格的概念"。
3. **重参数化检索缺失**。"复活"操作=在新对象上按旧坐标检索（§2 末）。这是**投影族上的查询**，
   不是格内概念遍历。与本项目 304 号已记录的 FCA gap 一致：FCA 是对象-属性单层结构，tell 识别
   需要的是思维拓扑的粒度分层（306 号）+ 多投影。

**格的正确定位**：每个 (层面×facet) 胞内部的概念组织仍可用格（局部 FCA）；但整体骨架应是
**多投影纤维结构**。本项目 GROVE 线已有其雏形与先例（发证）：

- GROVE 线 `dev-docs/225-v0-2026-08-07-AI数学工程的语义场证书框架（作者：GPT-5.5）.md` 与
  `来自另一个AI/1.md`（226 号数学化路线全文）：**语义场 Σ 定义为范畴**（对象=数学处境，
  态射=表示变换/规范化/对偶化/特例化/推广/形式化翻译）、**证书 C 为偏序范畴**（工程纪律=单调
  增长）、**"语义能量"不定义为单标量而定义为多分量序量**（表示复杂度/证书距离/自由度残差/
  粘合缺陷/反例压力/形式化缺口——启发式下降=Pareto 改善）、**图册=Grothendieck 拓扑**（一组
  能共同看清处境的表示作为覆盖，粘合失败=障碍）。〔证据等级：1.md 全文已读；225 号文档未逐字
  读，经 ChangeLog 与 1.md 交叉印证〕
- 项目内同构先例：K/T/H 三稀疏投影（同一矩阵的三个查询投影）、SystemAssets 的"7 面相"、
  根级 `facets/` 目录。

结论：**用户判断成立**——概念格是必要局部组件、不足以做整体骨架；立体认知结构的形式化落点
是"基空间=对象，纤维=各层面各 facet 上的看法，变换=表示变换态射，判据=多分量序量"的纤维化
结构（225 号路线的推广）。

## 4. 方案：引导 AI 自行完成多层次多 facet 算子化的程序（OP-0..OP-7 草案）

设计对接 AI 的两个身份：**模式匹配器**需要参数化模式（细粒度、可索引、无歧义检索）；**多约束
求解器**需要变量+约束+目标+判据。"同构之桥"四字对两者都欠约束（§5 展开）。

| 阶段 | 输入 | 动作 | 产出与验收 |
|---|---|---|---|
| **OP-0 语料冻结** | 大师作品全集 | 界定对象、冻结局部语料、登记选择偏差 | 语料清单+哈希；防"顺手只读名篇"偏差 |
| **OP-1 强制 facet 轮读** | 同一文本 × F1..F10 | 每遍用单一 facet 透镜重读（受控变量） | 每 facet 一份观察笔记；空 facet 显式留痕 |
| **OP-2 层面标定** | 全部观察 | 每条标 L1–L6（允许多标）；跨层移动处单独登记 | 层面混淆=错误信号（同一陈述在两个层面给出不同真值需拆分） |
| **OP-3 算子假设抽取** | 已标定观察 | 脱水+原语化：改写为 算子名/输入/前置条件/动作/输出/失败模式/粒度 七字段 | 对接 307 号（点=函数、边=调用、看法=重构）与 382/383 号 TellCore 字段结构；算子入册登记（先查重后增长——原语目录纪律） |
| **OP-4 消融与因果取商** | 算子七字段 | 逐字段删除测最小充分集（383 号 POC-1 方法） | 每算子附最小充分字段集+消融收据 |
| **OP-5 迁移与假朋友测试** | 算子族 | 跨对象正迁移 + 结构缺失对照（382 号 CasePack：正迁移/变形/假朋友/边界/组合） | 假朋友=表面相似但算子字段缺失——必须能被拒绝 |
| **OP-6 网格定位与空格发现** | 已验证算子 | 挂到层面×facet 网格；空格即候选研究方向 | 网格热力图；空格清单（"哪些层面哪些 facet"的机器可执行版） |
| **OP-7 形式化与验证合同** | 存活算子 | 每算子配机器可检查骨架（KC-000021 纪律："要真的在沙盒中运行过"） | 六门纪律：可选择/可执行/可终止/可组合/可归责/可持续学习 |

**三条跨阶段纪律**（全部来自本次调查的原文证据，缺一则程序退化为"AI 复述训练先验"）：

1. **反先验纪律**（KC-000017/042/043）：每个提取产物对照独立语料回答"这是大师的结构，还是
   训练先验的回声？"——助力与阻力一体两面，须显式审计。
2. **现实对齐动作强制**（KC-000044/045/046）：每算子必须完成一次"用人话+现实例子"重述与
   诠释-对齐——这是本次"AI 缺的是动作不是能力"教训的程序化。
3. **第一人称判据不可外包**：分叉价值排序（哪个空格值得填、哪个候选算击倒）仍需人工 tell；
   程序做到"把需要判断的点显式化并请求判断"，不冒充自动判断。

**可行性判断**：启发式意义下可行——每步有明确输入/动作/验收，失败可定位到阶段与字段；完全
自动化不可行处恰为 L6 层（与上一轮"三体系统"结论一致并精确化：AI 可执行 OP-0..OP-7 的机械
部分与初稿生成，价值排序保留人工）。

## 5. Worked Example："同构之桥"的算子化展开

四个字 → 五算子 × 七字段的信息扩容（对"模式太粗糙"的定量刻画）：

| 算子 | 职责 | 关键字段示例（含 negative_boundary） |
|---|---|---|
| B1 结构提取 | 读出两侧对象的前提结构/深度/证明形状 | 失败模式：只提取表面术语——**边界：术语重合≠结构对应** |
| B2 对应建立 | 对象级/定理级/技术级三层对应+方向性 | 失败模式：把类比修辞当映射 |
| B3 迁移执行 | 搬运结论、调整参数（parameter_slots） | 失败模式：参数未随表示变换更新 |
| B4 边界裁定 | 失效条件、假朋友识别（382 号经验） | 必须输出"何时这不是桥" |
| B5 验证 | 机器可检查骨架+反例压力 | 对接 KC-000021 运行收据要求 |

对模式匹配器：五算子×七字段提供可索引的细粒度特征（四字云→结构化键）；对多约束求解器：
字段即约束（前置条件=约束、失败模式=剔除谓词、粒度=变量尺度）。**"同构之桥"由此从标签变为
可执行物。**

## 附录 B：facet 封闭性的精确化（2026-09-28，用户追问"核心是否在于 facet 找全"）

**用户判断**：最核心的问题在于 facet 的找全。**调查结论**：对一半——"找全"须拆成三层，且
第三层（生成机制）比清单更核心。

1. **语料内找全（可闭合）**：对冻结语料，"用过哪些 facet"是考古完备性问题，判据=网格外
   观察数为 0（OP-0..OP-2 的机器可验交付）。
2. **面向未来找全（不可终局，只可测量）**：facet 族开放生成（证据：KC-000006"时间机制不能
   收窄为稠密性"——每个理论删的现实元素不同；F6 完成性 2×2 由维度叉乘生成；09-26 P1–P3
   当场新铸）。正确形式=**留出语料的网格外命中率**（out-of-grid rate），非零即铸新 facet。
3. **生成机制（真正核心）**：网格失灵时如何铸新 facet。全部历史证据指向同一生成器——
   **现实对齐动作**（人话+现实例子重述、构造写成程序看停机；KC-000016/044/046）；重述失败的
   位置即缺失 facet 的藏身处。两幽灵复活均为该生成器的工作产物。
4. **层面/facet 不对称**：L1–L6 是有界反射塔（观察者层封顶，反射封闭），层面族有封闭性
   论证；facet 是"理论删了什么"的开放枚举。核心问题恰好落在 facet 上，因为它是两个族中
   开放的那个。
5. **程序修正**：OP 重心从"枚举"移向三件事——判据（两级 out-of-grid 指标）、生成器（现实
   对齐动作升级为 OP 标准纪律）、组合语法（叉乘/取反/换层的 facet 生成规则显式化，F6 即
   叉乘产物）；"哪个空格值得填"的价值排序仍不可外包。

## 附录 C：倒置命题——facet 找全内嵌于完整思维结构化（2026-09-28，用户再追问）

**用户命题**：facet 的找全会不会本身就隐藏在完整的思维结构化之中——facet 不过是完整结构化
结果的**不同解读视角、不同抽象层次**的读法？

**判定：成立，且可精确化**。设彻底结构化给出完整结构 S（225 号语义场推广：处境为对象、
表示变换为态射、多分量序量为判据），则：

1. **本体论方向（命题本体）**：facet = S 的投影/读法（如坐标卡之于流形）；层面×facet 网格
   = S 的投影族按（高度=抽象层次，方向=解读视角）的自然索引。**完整结构化=图册粘合的完备，
   facet 找全=覆盖的充分——同一条件的两面**（225 号："一组能共同看清处境的表示"即覆盖）。
2. **认识论方向（诚实对偶）**：我们只拥有 S 的投影痕迹（作品/对话/行为），实践永远逆向
   （从投影重建 S）。故"找全"变换为：**当前投影组粘合是否无障碍**——两 facet 读法在重叠处
   不一致、或现实对齐重述失败，即缺失投影的探测器。与附录 B 的生成器构成**双探测器**
   （out-of-grid 率 + 粘合障碍）。
3. **语料级闭合的机制**：观察→重建 S→投影导出→再观察是闭包迭代；有限语料上有限步收敛
   （FCA 闭包算子同型）。语料级完备=不动点：新语料不再产生网格外观察、S 不再长出新投影。
4. **不消失的两件事**：投影的有意义性选择（退化投影无穷多，哪些值得成为 facet=价值排序，
   不可外包）；S 按领域开放生成（每理论删的现实元素不同）。最终图景是一条链：
   **生成器（现实对齐）→ 结构 S → 投影族（层面×facet）**；考古=从投影痕迹恢复 S，
   生成=延伸 S。用户倒置把 facet 清单从目标降格为**导出物**——与案例结论互证：大师持有
   的是生成器而非清单。
5. **对格/纤维之争的再确认**：既然 facet 是投影，其正确居所是投影索引结构（纤维/图册），
   而非被压平的单一偏序——从另一方向证成 §3 的纤维化选择。
