## U-FI-2：新立声明 A——patching = 幽灵闭合器

### 第 0 层计算读法应用于证明核心机制

**读法**。模性提升（R=T）的核心困难：你想对 R（泛形变环）执行查询——它的性质、它与 T 的关系——但 R 不是显式构造的对象（它是万有性定义的）。用构造/查询语言：**查询的目标对象的构造未完成**。

**patching 在这个读法下的角色**：它证明辅助层级的 Hecke 代数在逆极限下成为幂级数环（可显式计算的对象），从而使原始查询获得下降通道。Wiles 自述 L135："de Shalit's theory, if generalised, could be used together with duality to **glue** the Hecke rings at suitable auxiliary levels into a power series ring."（"glue"=闭合的关键词）。**patching 就是"使查询合法化的完成机制"——它把一个幽灵候选（对不可显式构造的对象的查询）闭合为合法查询（粘合成可计算对象后下降）。**

### 判据三问

- **Q1 原文有而作者未拆出？** ✓。Wiles 从未把 patching 与集合论基础/罗素悖论联系起来——他不需要跨到那个领域。他描述 patching 的方式是技术性的（"粘合成幂级数环"），不是结构性的（"这是一台使查询权获支撑的机器"）。后者是构造/查询算子的应用——跨了他不工作的领域（基础论/哲学）。
- **Q2 可移植？** ✓/待验。构造/查询算子已跨三域（朴素集合论/HoTT/证明过程），本声明是第四域（**证明内部的技术机制**——前三例都是"理论/过程有幽灵"，本例是"技术装置的角色 = 幽灵闭合器"）。**可检验预言**（下节）构成移植的实质内容。
- **Q3 相称证据？** ✓。原文锚点（L135 "glue...into a power series ring"、L129 "I searched without success for the key"、TW 引言 "missing ingredient...complete intersections"——完整的幽灵候选→闭合器→合法查询链）。机器级（Algebra.PatchingDatum）。
  ◐ 标注：R=T 的形变环/Hecke 代数**并非字面上的"不停机程序"**——读法经解释桥（R 的万有性定义→隐式构造→需闭合装置），与 Z6 对 HoTT 的应用同理（需元理论/证明支撑）。已加负面边界。

### 可检验预言

**预言**：任何未来改进的模性提升定理，均需保留或改造某种 patching 式完成装置（不可能绕过"使查询合法化"这一步）。→ U-FI-4 文献核验。

## U-FI-3：新立声明 B——Selmer 群的双重角色

### 读法

Selmer 群（由局部条件控制的上同调群）在 FLT 与 BSD 中扮演**结构角色相同但方向相反**的量：

| | FLT（Wiles） | BSD（C 关） |
|---|---|---|
| 对象 | H¹(Gal, Ad⁰ρ) 的子群 | E(Q) 的 Tate-Shafarevich 群相关的 Selmer 群 |
| 用途 | 证明 R=T 需要**杀死**它（Selmer=0 ⟹ 完全交 ⟹ 同构） | 猜想 E(Q) 秩 = **数**它（Selmer 秩 = 解析秩 = BSD 内容） |
| 在幽灵框架下 | 伪查询结果的度量（非零 = 幽灵残留） | 查询结果的计数（非零 = 真实信息） |
| 一句话 | **消歧**（排除假结果） | **计真**（量化真结果） |

**超越性声明**：Wiles 知道 Selmer 群的一切技术细节，但"消歧/计真的统一框架——同一个结构量在一处是被消灭的幽灵残留、在另一处是被计数的真实信号"——这一统一视角是算思网格的产物，不在他的文本中。

### 判据三问

- **Q1** ✓（Wiles 只在 FLT 语境下讨论 Selmer，从未做 FLT-BSD 的结构对比）；
- **Q2** ✓（此读法把我们的 A/B 关与 C 关在算子层统一起来——自身即可移植性的证据）；
- **Q3** ◐/✓（原文锚点=Wiles Chapter 3 "Selmer group"的角色；BSD 侧为标准文献。但"消歧/计真"这个命名本身尚无外部引证——如实标注为**命名性贡献**而非**发现性贡献**。准确地说：两个定理中 Selmer 群角色不同是数学家众所周知的事实；**用幽灵框架将其统一命名并连接到构造/查询算子**是本声明的独有贡献）。

### 可检验预言

**预言**：如果 C 关 BSD 排序的第一策略（欧拉系全覆盖 ⊕ 主猜想普适化）是正确的，那么其中 Selmer 群的控制技术应当与 FLT 中 Wiles 的 Selmer 界共享某个技术骨架（两者均源自 Galois 上同调对偶性）——这一点若成立，强化"消歧/计真统一"的深层正当性。
