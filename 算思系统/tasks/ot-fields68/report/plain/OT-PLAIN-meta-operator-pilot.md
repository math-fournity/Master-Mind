# 人话版 · 第九关：首批四人元算子挖掘

## 这一关在干什么

你问："为什么不去所有得主的得奖作品里寻找新元算子？AI 擅长识别模式。"对——所以这一关
换了方法：不是"拿我们的旧工具去套新人"，而是**问每个新人手里有没有我们还没有的钥匙**。

用已入库的四位得主（四种完全不同的数学风格）跑首测：Scholze（几何/算术）、Bhatt（代数/
统一理论）、Maynard（解析/优化）、Viazovska（构造/精确匹配）。

## 结果：四把新钥匙

| 得主 | 他的关键动作 | 他手里的钥匙（新镜头） |
|---|---|---|
| **Scholze** | 把 p 进世界变得几何干净 | **搬家读法**：不在原地硬啃，问"搬到哪个世界问题会变简单"，然后造一座桥把整个问题搬过去 |
| **Bhatt** | 发现三种上同调是同一件事 | **溯源读法**：不向外推（推广），向内收——"这些下游有没有一个共同上游？" |
| **Maynard** | 改进筛法配重 | **拧旋钮读法**：框架不动（还是筛法），找到被前人忽视的自由度（权重），拧到最优 |
| **Viazovska** | 造出恰好闭合的模形式 | **精确构造读法**：理论说"如果存在一个恰好这样的对象，等式就闭合"——那就不找近似的，精确造出它 |

**这四把钥匙全都不在我们原来从罗素悖论长出来的镜头家族里。**

## 最重要的数字

在这四个人身上，从悖论长出来的计算读法直接适用率 = **0/4**。不是低于 30%——是零。
你担心的"狭隘化"不是理论风险，是首批实测现实。如果没有这次改向，我们就会拿着悖论
这把锤子去敲 68 个钉子，一个都敲不对。

## 新旧钥匙之间的关系

四把新钥匙不是孤立的——它们跟旧镜头有精确的结构关系：

- Viazovska 的"精确构造"跟罗素的"构造/查询"是**同一枚硬币的两面**：悖论审计用构造的
  失败证明不存在；精确构造用构造的成功证明最优性。一攻一守，同源反向。
- Scholze 的"搬家"是 Huh"类比"的加强版：类比说"像"，搬家说"就是"（等价）。
- Bhatt 的"溯源"跟 Huh 的"推广"方向相反：一个从一到多，一个从多到一。

镜头家族现在 **十把钥匙**，各管一类数学。
