# 人话版 · 第七关：Anthropic FLT 第二轮考察（按 P-004 深度协议执行）

## 这一关在干什么

上一轮我们用六条线看清了"距离"，但留了几个中等置信的悬案。这一轮按事先定好的预算和靶
点（"预算提前定、靶点动态选"）回去补四个洞：①十招在机器代码里逐个对号；②看清它的依赖
图到底长什么样；③把"货架清单"全表数一遍；④把它的攻关时间线钉死。

## 四个洞补完，每个都有硬收获

**①十招全部对上号，而且对到了语句级。** 上一轮有两招只到"主题级"置信（知道大概在哪个
区域，没找到确切文件）。这轮逐个核对：11 个路线图点名的文件全部存在；随机精读四条关键
定理的 Lean 语句，和我们 A 关写的算子语义**一字一句对得上**——最漂亮的是"3 换 5 换胎"
那招，机器里的定理原文就是"存在另一条半稳定曲线，模 3 不可约，且所有好素数上迹差被 5
整除"，和我们当年从怀尔斯引言里拆出来的文字完全同构。

**②依赖图的真相：明修栈道，暗度陈仓。** 三万条定理表面上每个只 import 一两个文件，好像
谁也不依赖谁；深看才发现是**成对骗术**——每个"定理陈述文件"和它的"证明文件"互相引用，
真正的依赖网被搬到了平台层（Prove2Me 的 DAG）去维护。为什么这么设计？因为这样任何一个
代理改一个证明，Lean 只需重编译那一对文件，三万件的大厦才能被几十个代理并行施工。**数
学分解在蓝图层，编译分解在管道层——两层分解各自为并行服务**。这回答了上轮遗留的"分解
从哪来"。

**③货架清单数完了：136 行里 36 行是怀尔斯的"独奏"预制件。** 上一轮说"怀尔斯亲手做的部
分被人类社群预制成零件"只是中等置信；这轮全表量化，36 行文件含形变论/patching 关键词，
置信升满格。

**④时间线钉死。** 11 天；失败期（代理互相失联）→ 上平台 → 三段子图推进 → 8 月 18 日凌
晨根定理闭合；人类只丢了两句高层指令（"Jacobian 当方案很优先"、"Mazur 定理尽快推完"）；
蓝图用的是社区现成的 86 页，没改；总成本 60 亿输出 token。还有个惊人的对照实验：3 个个
人订阅 3 天形式化了 Vinogradov 三素数定理——这套打法是可复制的，不是一次性奇迹。

## 意外收获

发现他们的管道有统一战术：每条证明都以同一个战术调用管道解文件——**三万条证明其实是"
一条战术统一挂账"的形态**，这和我们"算子统一登记"的思路是同一个直觉的两种实现。另外
官方文没提 BSD 等后续目标，所以我们 C 关的 BSD 排序暂时没有新的外部对账材料。

## 要坦白的

三万条定理我们仍然只读了不到 25 个文件（预算纪律如此，够四个靶向裁决但不支持更细的统
计）；管道战术的语义是推断（没读管道源码）；官方文是 Anthropic 自述，第三方独立报道仍未
核验。这轮预算池（≤30 文件）一次都没动用——四个靶向按计划打完，这就是"预算提前定"的
意义：没有超支，也没有偷工。
