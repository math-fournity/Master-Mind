# 341号 · 全流程日志方案——滚动日志到system/logs/

**日期**：2026-08-11
**状态**：方案设计
**来源**：用户要求"在整个系统的全流程中加上日志输出，日志输出到system/logs子目录中"

---

## 1. 需求

1. 整个系统全流程加日志输出
2. 日志输出到`system/logs/`子目录
3. 单个日志文件大小不超过1MB
4. 整个日志目录不超过500MB
5. 循环滚动——超过500MB时删除最旧的日志文件

---

## 2. 方案设计

### 2.1 日志模块——system/log.py

新建`system/log.py`，提供统一的日志接口：

```python
"""
系统日志——滚动日志到system/logs/

特性：
- 单文件不超过1MB，超过自动滚动到新文件
- 整个目录不超过500MB，超过删除最旧文件
- 日志文件名：vein_YYYYMMDD_HHMMSS_N.log（N是同一秒内的序号）
- 格式：[timestamp] [level] [module] message
"""

import logging
import os
from logging.handlers import RotatingFileHandler

LOG_DIR = os.path.join(os.path.dirname(os.path.dirname(os.path.abspath(__file__))), "logs")
MAX_FILE_SIZE = 1 * 1024 * 1024  # 1MB
MAX_DIR_SIZE = 500 * 1024 * 1024  # 500MB
BACKUP_COUNT = 500  # 最多保留500个日志文件（500MB / 1MB）

def get_logger(name: str = "vein_analysis") -> logging.Logger:
    """获取日志logger"""
    os.makedirs(LOG_DIR, exist_ok=True)
    logger = logging.getLogger(name)
    if logger.handlers:  # 避免重复添加handler
        return logger
    logger.setLevel(logging.DEBUG)
    
    # 滚动文件handler——单文件1MB，最多500个备份
    log_file = os.path.join(LOG_DIR, "vein_analysis.log")
    handler = RotatingFileHandler(
        log_file,
        maxBytes=MAX_FILE_SIZE,
        backupCount=BACKUP_COUNT,
        encoding="utf-8",
    )
    handler.setLevel(logging.DEBUG)
    formatter = logging.Formatter(
        "[%(asctime)s] [%(levelname)s] [%(name)s] %(message)s",
        datefmt="%Y-%m-%d %H:%M:%S",
    )
    handler.setFormatter(formatter)
    logger.addHandler(handler)
    
    # 同时输出到stdout
    stdout_handler = logging.StreamHandler()
    stdout_handler.setLevel(logging.INFO)
    stdout_handler.setFormatter(formatter)
    logger.addHandler(stdout_handler)
    
    return logger
```

### 2.2 日志记录点

在vein_analysis.py的关键位置加日志：

| 位置 | 日志内容 | 级别 |

### 2.3 日志目录管理

`system/logs/`目录结构：
```
system/logs/
├── vein_analysis.log          # 当前日志文件
├── vein_analysis.log.1        # 第1个滚动备份
├── vein_analysis.log.2        # 第2个滚动备份
├── ...
└── vein_analysis.log.500      # 第500个滚动备份（最旧）
```

Python的`RotatingFileHandler`自带滚动功能：
- 当前文件超过1MB → 重命名为`vein_analysis.log.1`，创建新的`vein_analysis.log`
- 所有`.N`文件序号+1
- 超过`backupCount=500`个备份 → 删除最旧的

500个文件 × 1MB = 500MB，满足"整个目录不超过500MB"的要求。

`system/logs/`不需要提交到git——加到`.gitignore`：
