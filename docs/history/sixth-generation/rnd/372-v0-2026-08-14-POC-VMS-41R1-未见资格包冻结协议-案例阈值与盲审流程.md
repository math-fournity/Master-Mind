```text

```

未来模型资格化阶段的profile PASS最低阈值：

```text
artifact/protocol gate: all PASS
anchor coverage: 6/6 cases PASS
typed path: 6/6 cases PASS
temporal status: 6/6 cases PASS
true/false merge constraints: all relevant cases PASS
forbidden semantics precision: all negative/boundary cases PASS
file effect verdict: no confirmed forbidden effect
blind manual audit: >= 5/6 ACCEPT and no high-severity source-fidelity failure
```

任何协议观察缺失、gold泄漏、blindness breach、unknown-start未解决或attempt重试，均只能进入`INCONCLUSIVE_PROTOCOL`或failure localization，不能计作科学PASS/FAIL。

## 6. 盲审流程

第一轮Reviewer只能看到：

```text
public case source
candidate occurrence DAG
candidate source spans
rubric without hidden acceptable-set IDs or mechanical verdict
masked case ID
```

第一轮Reviewer不得看到：

```text
acceptable-sets.json
reference-candidates.json
mechanical error summary
qualification aggregate
candidate prompt/template internals beyond visible input
```

Broker必须先封存`BlindReviewJudgment`，再join机械结果。若Reviewer先看见hidden acceptable set或mechanical summary，该case只能用于failure localization。
