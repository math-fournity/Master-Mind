# History

This topic preserves lineage, legacy assets, migrations, and historical concept routes. It is the first stop
when a question asks why a system exists, what replaced it, whether something was deleted, or how a concept
evolved.

Primary files:

- `sixth-generation-route-replacements.md`: current sixth-generation lineage, superseded routes, canonical truth order, and recovery pointers.
- `system-lineage.md`: system-generation and island chronology.
- `legacy-assets.md`: old directories, replacement relationships, and retention reasons.
- `git-log-lineage.tsv`: machine-derived commit/date/subject/path/topic index.

Git history is evidence, not the current requirements database. Current state remains in root `MEMORY.md`;
current requirements remain in root `feature-list.md`.
