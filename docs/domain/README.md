# Domain And Terminology

The repo's domain is AI-assisted mathematics-system manufacturing: systems that analyze mathematical problem
solving, extract tell/hint signals, guide future solver attempts, and preserve evidence.

## Core Concept Families

- Cognitive closure: task-relative, minimal sufficient, evidence-traceable knowledge before action.
- Grove loop: guide tree, solver tree, terminal retrieval, new edge generation.
- Tell/Hint: recognition-side signal and injection-side direction.
- VMS: virtual mathematical system lineage and verification experiments.
- Non-specialization: research line for directions that help across problems without leaking answers.
- Evidence factory: Seven/Eight style systems that produce auditable artifacts instead of ungrounded claims.

Use `Glossary.md`, `GroveCoreCognition.md`, `SystemAssets.md`, and `docs/history/system-lineage.md` for deeper
routes. Treat old definitions as historical until the current island evidence confirms them.
