# 105-大师-POC-3验证方案

> **文档定位**：83号文档设计了三层提取（L1/L2/L3）的POC验证方案。本文档是POC-3的正式执行方案，细化实验设计、题目选择、评分标准、执行流程。

## 一、验证目标

### 1.1 核心假设

**从题库解法中通过AI多次分析提取的L2/L3思维点，比仅提取L1的解题思路，具有显著更高的跨题复用性和分析质量增益。**

### 1.2 可证伪性

- 如果L2/L3提取的思维点在跨题分析中不比L1有优势 → 三层提取方案价值不成立
- 如果题3（远迁移）C组不显著优于B组 → L3范式思维的跨领域迁移价值不成立

## 二、实验设计

### 2.1 三组对照

| 组别 | 提示内容 | 提取层次 |
|---|---|---|
| **A组（对照组）** | 题目 + L1解法路径 | 仅L1 |
| **B组（L2组）** | 题目 + L1路径 + L2思维模式 | L1+L2 |
| **C组（L3组）** | 题目 + L1路径 + L2思维模式 + L3范式思维 | L1+L2+L3 |

### 2.2 提取-复用链条

```
题1（Cayley-Hamilton定理）——提取题
  ↓ 三层提取
  L1路径 + L2思维模式 + L3范式思维
  ↓ 作为提示材料
  ↓
题2（近迁移）——另一道线性代数题
  → A/B/C三组对照 → 评分
  ↓
题3（远迁移）——非线代领域的题
  → A/B/C三组对照 → 评分
```

### 2.3 关键设计原则

1. **三组面对同一道新题**（不是提取L1/L2/L3的那道题）
2. **提示中包含从其他题提取的L1/L2/L3思维点**——测试跨题复用性
3. **盲评**：评分AI不知道哪组是A/B/C
4. **三组用三个独立subagent**，background模式并行执行

## 三、题目选择

### 3.1 题1（提取题）：Cayley-Hamilton定理

**理由**：
- 83号文档第五节已有完整的三层分析
- 有三种经典解法（矩阵法/模论法/行列式法），适合提取跨领域映射
- L3范式思维清晰：矩阵=模等价

**三层提取已在83号文档第五节完成**：
- L1：三条解法路径
- L2：多项式恒等式检验、局部-全局、恒等式构造、不变量
- L3：矩阵=模等价范畴论范式

### 3.2 题2（近迁移复用题）：谱定理（有限维）

**候选**：实对称矩阵的谱定理——"实对称矩阵可对角化，特征值全为实数"

**理由**：
- 同属线性代数领域 → 近迁移
- 需要用到不变量思维（L2）——特征值是不变量
- 多种证明路径（代数法/几何法/分析法）→ 可验证L2跨题复用
- 难度适中（本科级，证明思路清晰但不平凡）

**备选**：如果谱定理的L2/L3复用不明显，改用Jordan标准型定理。

### 3.3 题3（远迁移复用题）：Brouwer不动点定理（有限维）

**候选**：有限维Brouwer不动点定理——"闭球到自身的连续映射有不动点"

**理由**：
- 属于拓扑学 → 远迁移（从线性代数到拓扑）
- L3范式思维"矩阵=模等价"虽然不直接适用，但L3的**跨领域映射思维方式**应能帮助AI看到代数和拓扑之间的结构对应
- 需要用到不变量思维（L2）——拓扑不变量（Euler特征数）
- 多种证明路径（代数拓扑法/组合法/分析法）→ 跨领域映射丰富
- 难度适中（本科拓扑级）

**备选**：如果Brouwer不动点定理太复杂，改用更简单的拓扑题（如连通性/紧致性的证明）。

## 四、三层提取材料（从题1提取）

### 4.1 L1（三条解法路径）

**路径A（矩阵证明）**：
1. 设A是n×n矩阵，特征多项式p(λ)=det(λI-A)
2. 要证p(A)=0
3. 对任意非零向量v，构造Av的序列
4. 用Cayley-Hamilton直接代入验证

**路径B（模论证明）**：
1. 将矩阵A视为模自同态
2. 构造R-模的正合序列
3. 用Nakayama引理
4. 推出结论

**路径C（行列式证明）**：
1. 构造adj(λI-A)·(λI-A)=det(λI-A)·I
2. 代入λ=A
3. 多项式整除关系给出结论

### 4.2 L2（AI二次分析提取的数学思维）

| 思维模式 | 来源路径 | 适用领域 |
|---|---|---|
| 多项式恒等式检验 | 路径A | 代数、数论 |
| 局部-全局 | 路径B | 代数、拓扑、数论 |
| 恒等式构造 | 路径C | 代数、分析 |
| **不变量思维** | 三条路径共有 | **全部数学领域** |

**关键L2**：不变量思维——特征多项式是不变量，无论用什么方法都应该得到同一个。这是弥漫性最强的思维模式。

### 4.3 L3（AI三次分析提取的范式思维）

**L3范式**：矩阵=模等价

- 路径A（矩阵）和路径B（模论）之间的映射揭示了"矩阵论和模论是同一个东西的两种视角"
- 这是范畴论中"等价范畴"的范式思维
- L3一旦被提取，不只服务于Cayley-Hamilton，而是为整个线性代数增加了一层跨领域映射边
- **跨领域映射思维方式**：看到A领域的结构，联想B领域是否有对应——这是比"不变量思维"更高一层的范式

## 五、评分维度（8维15分制，参考POC-2）

| 维度 | 满分 | A组预期 | B组预期 | C组预期 |
|---|---|---|---|---|
| 1. 证明正确性 | 2.0 | 1.0 | 1.3 | 1.5 |
| 2. 证明完整性 | 2.0 | 0.8 | 1.2 | 1.5 |
| 3. 数学知识准确性 | 2.0 | 1.3 | 1.5 | 1.7 |
| 4. 可审计性 | 2.0 | 1.0 | 1.3 | 1.5 |
| 5. 转译忠实性 | 2.0 | 1.0 | 1.3 | 1.5 |
| 6. 跨领域关联 | 2.0 | 0.5 | 1.0 | **1.7** |
| 7. 思维深度 | 2.0 | 0.8 | 1.3 | **1.7** |
| 8. 可迁移性 | 1.0 | 0.3 | 0.5 | **0.8** |

**关键判别维度**：
- **跨领域关联**（维度6）：C组应显著高于B组，因为L3范式思维帮助看到跨领域映射
- **思维深度**（维度7）：C组应显著高于B组，因为L3提供了范式级视角
- **可迁移性**（维度8）：C组应高于B组，因为L3跨领域可用

## 六、成功/失败定义

### 6.1 成功

1. **题2（近迁移）**：B组和C组总分均显著优于A组（边际增益≥+2.0/15分制）
2. **题3（远迁移）**：C组总分显著优于B组（**L3增量增益≥+1.5/15分制**）
3. **L2/L3审计通过率≥80%**

### 6.2 失败

1. 题2：B/C组不显著优于A组 → L2提取价值不成立
2. 题3：C组不显著优于B组 → **L3提取价值不成立**
3. 审计通过率<50% → 提取质量不可靠

### 6.3 部分成功

1. 题2成功但题3失败 → L2价值成立但L3价值不成立，需改进L3提取方法
2. 审计通过率50-80% → 提取方向对但质量需提升

## 七、执行流程

### 7.1 准备阶段

1. 题1的三层提取材料落盘（L1/L2/L3完整记录）
2. 选题2和题3
3. 准备A/B/C三组提示材料：
   - A组：题目 + 题1的L1路径
   - B组：题目 + 题1的L1路径 + L2思维模式
   - C组：题目 + 题1的L1路径 + L2思维模式 + L3范式思维

### 7.2 实验阶段

4. 三组subagent并行执行（background模式）
   - subagent-A：题2 + A组提示
   - subagent-B：题2 + B组提示
   - subagent-C：题2 + C组提示
5. 同样对题3执行三组对照
6. 输出保存到文件

### 7.3 评分阶段

7. 盲评subagent评分（不知道哪组是A/B/C）
8. 第四个独立subagent做L2/L3提取质量审计

### 7.4 结果落盘

9. 落106号POC-3结果文档
10. 更新AGENTS.md

## 八、与POC-1/POC-2的区别

| 维度 | POC-1 | POC-2 | POC-3 |
|---|---|---|---|
| 验证什么 | 依赖图提示 vs 无提示 | 七步骤工作流 vs 依赖图JSON | L1+L2+L3 vs 仅L1 |
| 题目 | 1道（矩条件极差题） | 1道（同上第二问） | 3道（提取+近迁移+远迁移） |
| 组数 | 2组（A vs B） | 3组（A vs B' vs B） | 3组（A vs B vs C） |
| 关键测试 | 依赖图是否有用 | 工作流是否优于裸依赖图 | **L3跨领域迁移是否有效** |
| 领域 | 单领域 | 单领域 | **跨领域** |

POC-3是数学版相比星学版的**本质增量验证**——L3范式思维的跨领域迁移，这是星学项目没有验证过的。
