# 83-解法路径的三层提取与POC验证方案

## 背景

2026-08-03，在讨论题库作为数学思维积累方向（82 号文档）后，用户提出了一个关键洞察：

> 有些思维性的东西，只能叫解题思路，而另外一些，由于其特殊性，人们又会称之为数学思维，甚至，有些达到了更高的级别，人们直接称其为"一种新的思维"。所以，稀疏矩阵的积累，如果我们仅仅是看了题库的一题的一种解法，只能得到最低级的东西，那是不对的。或许某种解法，本身就有很多点可以提取，如果再用AI的智能进一步分析一下，可能还会提取到更多高级的点。这些高级的点，就不是只能在小范围内使用了。

本文档记录对这个洞察的完整论证，并设计 POC 验证方案。

---

## 一、核心论点

**从一道题的解法中可以提取的东西，不是同一个层次的，而是有三个等级的。只提取最低等级，得到的只是一个题解数据库，不是大师思维系统。**

| 层次 | 名称 | 复用范围 | 对应星学概念 |
|---|---|---|---|
| **L1 解题思路** | 具体步骤 | 只在类似题中复用 | 命例中的具体判断步骤 |
| **L2 数学思维** | 思维模式 | 跨题复用，弥漫性 | 星学意识（五行生克、恩用仇难） |
| **L3 新的思维方式** | 范式级 | 跨领域复用，改变分析框架 | 星学中没有直接对应——这是数学特有的高价值层 |

---

## 二、三个层次的详细论证

### 2.1 L1：解题思路（具体步骤）

一道题的解法写下来就是 L1——"第一步作辅助线，第二步用相似比，第三步..."。这是具体的步骤序列。

**特征**：
- 直接从解法文本中读出
- 只在类似题中有效——"这道题作这条辅助线"换一道题就没用了
- 如果依赖图只记录 L1，那它只是一个题解数据库
- 对应依赖图中的具体边：`步骤1 → 步骤2 → 步骤3`

**提取方式**：直接记录，不需要 AI 分析。

### 2.2 L2：数学思维（思维模式）

L2 不是直接"读"出来的，而是从 L1 中**抽象**出来的。

一道题的解法中，"第二步用相似比"——为什么这里能用相似比？是因为解题者识别到了什么结构？答案可能是："解题者识别到这个图形中有相似结构，而识别相似结构是一种'寻找不变量'的思维。"

"寻找不变量"就是 L2——它不是这道题的解法步骤，而是从这道题的解法中**抽象出来的思维模式**。

**特征**：
- 需要从 L1 中抽象提取（AI 二次分析）
- 弥漫性：在拓扑学中调用（同伦不变量），在代数中调用（特征不变量），在数论中调用（模不变量）
- 对应星学项目中的"星学意识"——五行生克不是某个步骤的专属，而是贯穿整个推命过程的底层思维
- 对应依赖图的"列"（意识维度），制造螺旋上升环路

**提取方式**：AI 二次分析——从具体解法步骤中抽象出思维模式。

### 2.3 L3：新的思维方式（范式级）

L3 更进一步。"寻找不变量"本身是一种思维方式（L2），而"把不变量作为研究对象来重构整个领域"就是范畴论的思维方式——这是 L3。

**特征**：
- 需要从多个 L2 中综合提取（AI 三次分析）
- 范式级：不是解某类题的技巧，而是重新定义了一个领域是什么的思维方式
- 跨领域性：一个范式节点连接多个领域，改变它们的依赖结构
- **L3 的本质特征：改变图结构本身**。L2 在现有图结构中被调用，L3 重新连接现有节点——原本不相关的代数和拓扑，通过函子概念建立了新的跨领域边

**典型案例**：
- Grothendieck 的概形：不是"解某类题的技巧"，而是重构了代数几何是什么
- 范畴论的函子：把不同数学领域之间的对应关系本身作为研究对象
- 表示论：把代数结构"表示"为线性变换，从而可以用线性代数研究抽象代数

**提取方式**：AI 三次分析——从多个 L2 思维模式中综合出范式级思维。

## 三、提取过程的形式化

```
解法文本（L1 原料）
  ↓ 第一次提取（直接记录）
  L1 解法路径：步骤1→步骤2→步骤3（具体边）
  ↓ AI 二次分析（抽象）
  L2 思维模式：这道题用了"寻找不变量"的思维（意识节点）
  ↓ AI 三次分析（综合多个解法的 L2）
  L3 范式思维：多个领域都在用"不变量"思维，这是一种跨领域的思维方式（范式节点）
```

**层次越高，复用范围越广，但提取难度越大，需要的 AI 智能越多。**

| 提取阶段 | 输入 | 输出 | 方法 | 复用范围 |
|---|---|---|---|---|
| 第一次提取 | 解法文本 | L1 路径 | 直接记录 | 类似题 |
| AI 二次分析 | L1 路径 | L2 思维模式 | 抽象 | 跨题、跨领域 |
| AI 三次分析 | 多个 L2 | L3 范式思维 | 综合 | 改变图结构 |

## 四、对依赖图结构的影响

这直接对应星学项目 63 号文档中的三维稀疏矩阵，并扩展了数学版的结构：

```
依赖图的节点有三个层次：

L1 节点（具体知识）：定理、概念、技巧
  → 依赖图的"行"（分析节点）
  → 边：具体的知识依赖（"这个定理依赖那个引理"）

L2 节点（数学意识）：寻找不变量、对偶化、极端检验、局部-全局...
  → 依赖图的"列"（意识维度）
  → 边：意识-问题调用（"这道题调用了'寻找不变量'意识"）
  → 弥漫性：同一个意识被多个问题节点调用，形成螺旋上升环路

L3 节点（范式思维）：函子思维、概形思维、表示论思维...
  → 依赖图的"第三维"（范式层）
  → 边：范式-领域重构（"这种思维方式重构了整个领域"）
  → 跨领域性：一个范式节点连接多个领域，改变它们的依赖结构
```

**L2 节点制造螺旋上升环路**——"寻找不变量"在代数题中被调用一次，在拓扑题中被调用一次，在数论题中被调用一次——平面投影上看是环路（反复调用同一个意识），三维上看是螺旋上升（每次在不同领域深化）。这正是星学 POC 验证过的机制。

**L3 节点改变图的结构**——当一种新的思维方式（如范畴论）出现时，它不是在现有依赖图中增加一个节点，而是**重新连接**现有节点。原本不相关的代数和拓扑，通过函子概念建立了新的跨领域边。这是 L3 区别于 L2 的本质特征。

## 五、具体案例：Cayley-Hamilton 定理

### 5.1 L1（三种解法路径）

- 路径A：特征多项式 → 代入矩阵 → 矩阵恒等式
- 路径B：模的正合序列 → Nakayama 引理 → 结论
- 路径C：行列式恒等式 → 伴随矩阵 → 多项式整除

### 5.2 L2（AI 二次分析提取的数学思维）

- 路径A用了"多项式恒等式检验"思维——要证两个多项式相等，只需在足够多点验证
- 路径B用了"局部-全局"思维——在局部环上证明，然后推出全局结论
- 路径C用了"恒等式构造"思维——构造一个恒等式让结论自然得出
- 三条路径共同用了"不变量"思维——特征多项式是不变量，无论用什么方法都应该得到同一个

### 5.3 L3（AI 三次分析提取的范式思维）

- 路径A和路径B之间的映射揭示了"矩阵论和模论是同一个东西的两种视角"——这是范畴论中"等价范畴"的范式思维
- 这种范式思维不只适用于 Cayley-Hamilton，它适用于整个线性代数——矩阵和模是等价的，矩阵的许多定理都可以通过模论重证，反之亦然
- L3 的"矩阵=模"范式思维一旦被提取，它就不只服务于 Cayley-Hamilton 一道题，而是为整个线性代数的依赖图增加了一层跨领域映射边

## 六、POC 验证方案

### 6.1 验证目标

**核心假设**：从题库解法中通过 AI 多次分析提取的 L2/L3 思维点，比仅提取 L1 的解题思路，具有显著更高的跨题复用性和分析质量增益。

**可证伪性**：如果 L2/L3 提取的思维点在跨题分析中不比 L1 有优势，则三层提取方案的价值不成立。

### 6.2 实验设计

**三组对照**：

| 组别 | 提示内容 | 提取层次 | 对应星学 POC |
|---|---|---|---|
| **A 组（对照组）** | 题目 + L1 解法路径 | 仅 L1 | 类似星学 POC-1 的 A 组（无依赖图提示） |
| **B 组（L2 组）** | 题目 + L1 路径 + L2 思维模式 | L1 + L2 | 类似星学 POC-1 的 B 组（有依赖图提示） |
| **C 组（L3 组）** | 题目 + L1 路径 + L2 思维模式 + L3 范式思维 | L1 + L2 + L3 | 超越星学 POC，验证 L3 的增量价值 |

**关键设计**：三组面对的是**同一道新题**（不是提取 L1/L2/L3 的那道题），但提示中包含从**其他题**提取的 L1/L2/L3 思维点。这测试的是**跨题复用性**——从一道题提取的思维点，能否帮助解另一道题。

### 6.3 题目选择

选择 3 道题，构成一个"提取-复用"链条：

**题1（提取题）**：Cayley-Hamilton 定理（已知三种解法，L1/L2/L3 已在第五节分析）

**题2（近迁移复用题）**：另一道线性代数定理题（如谱定理），测试从题1提取的思维点能否帮助解同类题

**题3（远迁移复用题）**：一道非线代领域的题（如拓扑中的不动点定理），测试 L3 范式思维能否跨领域迁移

**实验流程**：
```
题1（Cayley-Hamilton）
  ↓ 三层提取
  L1 路径 + L2 思维模式 + L3 范式思维
  ↓ 作为提示材料
  ↓
题2（近迁移）→ A/B/C 三组对照 → 评分
题3（远迁移）→ A/B/C 三组对照 → 评分
```

### 6.4 评分维度（5 维，参考星学 POC-1 评分体系）

| 维度 | 满分 | A 组预期 | B 组预期 | C 组预期 |
|---|---|---|---|---|
| **解法正确性** | 2 | 基本正确 | 基本正确 | 基本正确 |
| **思路清晰度** | 2 | 一般 | 较好 | 较好 |
| **跨领域关联** | 2 | 低 | 中 | **高** |
| **思维深度** | 2 | 浅（仅具体步骤） | 中（有思维模式） | **深（有范式视角）** |
| **可迁移性** | 2 | 低（只适用此题） | 中（同类题可用） | **高（跨领域可用）** |
| **总计** | 10 | ~6 | ~7.5 | **~9** |

**预期结果**：
- 题2（近迁移）：B 组和 C 组都优于 A 组，但 B 和 C 差距较小（因为近迁移中 L2 已经够用）
- 题3（远迁移）：C 组显著优于 B 组（因为远迁移需要 L3 范式思维才能跨领域）

**如果题3的 C 组不显著优于 B 组**，说明 L3 提取的价值不成立，需要重新审视三层提取方案。

### 6.5 提取质量审计

除了三组对照，还需要验证 AI 提取的 L2/L3 是否真的正确：

**L2 审计**：提取的"数学思维"是否真的是弥漫性的？是否在多个领域确实可调用？
- 审计方法：让独立 AI 实例检查"L2 思维模式X在领域Y中是否真的适用"

**L3 审计**：提取的"范式思维"是否真的是范式级的？是否真的改变了图结构？
- 审计方法：让独立 AI 实例检查"L3 范式Y是否真的连接了原本不相关的领域A和领域B"

### 6.6 执行模式

参考星学 POC 的 Subagent 对照实验执行模式（67 号文档）：

- 三组用三个独立的 subagent，background 模式并行执行
- 输入材料由主 Agent 准备（题1的三层提取结果 + 题2/题3的题目）
- 输出保存到文件
- 盲评：评分 AI 不知道哪组是 A/B/C
- 提取审计用第四个独立 subagent

### 6.7 成功/失败定义

**成功**：
1. 题2：B 组和 C 组总分均显著优于 A 组（边际增益 ≥ +2.0，参考星学 POC-5 的 +3.95）
2. 题3：C 组总分显著优于 B 组（L3 增量增益 ≥ +1.5）
3. L2/L3 审计通过率 ≥ 80%

**失败**：
1. 题2：B/C 组不显著优于 A 组 → L2 提取价值不成立
2. 题3：C 组不显著优于 B 组 → L3 提取价值不成立
3. L2/L3 审计通过率 < 50% → 提取质量不可靠

**部分成功**：
1. 题2 成功但题3 失败 → L2 价值成立但 L3 价值不成立，需要改进 L3 提取方法
2. 审计通过率 50-80% → 提取方向对但质量需提升

## 七、对项目建设的启示

### 7.1 题库结构化格式的更新

82 号文档第五节定义的题目记录结构需要扩展，增加 L2/L3 提取字段：

```
{
  "problem_id": "...",
  "solutions": [
    {
      "method": "...",
      "path": [...],              // L1（不变）
      "l2_patterns": [            // 新增：AI 二次分析提取的数学思维
        {"pattern": "寻找不变量", "evidence_step": 3, "applicable_domains": ["algebra", "topology", "number_theory"]},
        {"pattern": "局部-全局", "evidence_step": 5, "applicable_domains": ["algebra", "topology"]}
      ],
      "l3_paradigms": [           // 新增：AI 三次分析提取的范式思维
        {"paradigm": "矩阵=模等价", "domains_connected": ["linear_algebra", "module_theory"], "graph_restructure": "增加线性代数↔模论跨领域边"}
      ],
      ...
    }
  ]
}
```

### 7.2 提取管道的设计

题库建设不只是"录入题目和答案"，而是需要一个三层提取管道：

```
解法文本 → [L1 提取器] → L1 路径
                        ↓
              [L2 提取器：AI 二次分析] → L2 思维模式
                                          ↓
                              [L3 提取器：AI 三次分析] → L3 范式思维
```

每个提取器的输出需要审计（6.5 节），确保提取质量。

### 7.3 math-notes/数学意识/ 的内容来源

82 号文档中 `math-notes/数学意识/` 的内容（类比思维、对偶思维等）现在有了明确的来源——它们就是从题库中通过 L2 提取得到的。不是凭空写的，而是从具体解法中抽象出来的，每条都有实证来源（哪道题的哪个解法步骤）。

### 7.4 依赖图节点类型的扩展

依赖图节点从单一类型扩展为三种：

| 节点类型 | 来源 | 边类型 | 复用范围 |
|---|---|---|---|
| L1 知识节点 | 题解路径直接记录 | 知识依赖边 | 类似题 |
| L2 意识节点 | AI 二次分析提取 | 意识-问题调用边 | 跨题、跨领域 |
| L3 范式节点 | AI 三次分析提取 | 范式-领域重构边 | 改变图结构 |

## 八、与星学 POC 的关系

本 POC 验证的是数学版相比星学版的一个**本质增量**：

- 星学 POC1-8 验证的是：依赖图提示 vs 无提示的分析质量增益
- 本 POC 验证的是：**三层提取（L1+L2+L3）vs 单层提取（仅L1）的跨题复用增益**

星学中，依赖图的节点主要是 L1（具体星学知识）和 L2（星学意识），L3 没有显式出现——因为星学是一个封闭体系，不存在"跨领域范式重构"。

数学中，L3 是核心增量——数学有多个领域（代数/几何/分析/拓扑/数论...），领域之间的范式映射（范畴论、表示论、同调论）是数学研究的最高层次活动。本 POC 如果验证 L3 价值成立，将为数学版依赖图的设计提供关键依据。
