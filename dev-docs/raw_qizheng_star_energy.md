## 一、星曜能量机制总论

七政四余的星曜能量，不是单一属性，而是由**五层算子叠加**决定的：

### 1.1 第一层算子：五行属性（能量本底）

每颗星曜都归属一个五行，五行决定其基本「气质」：

| 五行 | 星曜 | 本性气质（经典表述） |
|---|---|---|
| 火 | 太阳、火星、罗睺 | 礼/兵，炎上，主礼、威权、急暴 |
| 木 | 木星、紫炁 | 仁，曲直，主仁、生长、仁爱、福德 |
| 水 | 月亮、水星、月孛 | 智，润下，主智、流动、情、暗昧 |
| 金 | 金星 | 义，从革，主义、收敛、财富、艺术 |
| 土 | 土星、计都 | 信，稼穑，主信、承载、迟滞、阻隔 |

五行之间有确定的**相生相克**关系（见第四节），这是星曜之间所有互动的底层逻辑。

### 1.2 第二层算子：阴阳（昼夜属性）

- 每颗星曜分阴阳。阴阳决定它是「昼星」还是「夜星」：
  - **昼星**（昼生有力）：太阳、土星、计都、水星、月孛、木星、紫炁
  - **夜星**（夜生有力）：月亮、火星、罗睺、金星
  - 昼星夜出、夜星昼现，则光芒减弱、影响力下降（《果老星宗》卷六「论七政四余躔次喜忌」）。
- 更深的阴阳逻辑来自《天元五歌》：「先将昼夜别阴阳，昼夜晨昏出没详」「阳令惟用水与孛，阴令惟爱火与土」——四时节令也有阴阳，星曜要「得时」。

### 1.3 第三层算子：庙旺乐陷（位置增益）

星曜落在什么宫、什么宿，决定其能量是放大还是衰减。等级顺序：

```
入垣（本家宫，最强） > 升殿（本宿，强） > 入庙（庙宫） > 乘旺（旺宫） > 乐乡（乐宫） > 喜宫 > 好宫 > 平 > 陷（落陷，最弱）
```

- **入垣/归垣**：星曜在「自己当宫主」的宫位（如日守午、月守未、木守寅亥、火守卯戌、土守子丑、金守辰酉、水守巳申）。
- **升殿**：星曜躔在「自己度主」的宿（如日躔星虚房昴、月躔心张危毕、木躔角斗奎井、火躔尾室觜翼、土躔女胃柳氐、金躔亢牛娄鬼、水躔箕壁参轸）。
- **入庙/乘旺/乐/喜/好**：见第二节各星详表。
- **落陷**：在「克我之宫/宿」或「我克之乡」失次。古诗：「吉星落陷吉性大减，凶星落陷凶性倍增」。

### 1.4 第四层算子：化气（人格化职能）

每颗星曜「化」某种气，这是它在命盘里担当的**社会职能/人事象征**：

| 星曜 | 化气 | 含义 |
|---|---|---|
| 太阳 | 化贵 | 贵气、君父、权威 |
| 太阴（月） | 化富 | 富气、母妻、财富、滋养 |
| 木星 | 化贵（仁） | 仁、福寿、官爵 |
| 火星 | 化兵/礼 | 兵刑、行动、威权 |
| 土星 | 化信（富） | 信、承载、田宅 |
| 金星 | 化义（权） | 义、财、婚、审美 |
| 水星 | 化智（文） | 智、文、沟通、术数 |

> 注：化气的经典表述在各派略有出入（天官五星派尤重「化气」），上表为常见归纳。更精确的「十干化曜」（年干→天禄/天暗/天福/天耗/天荫/天贵/天刑/天印/天囚/天权）见第六节。

### 1.5 第五层算子：生克关系（恩用仇难 + 余奴伤主）

这是星曜之间互动的核心算子（《天元五歌》《果老星宗·至宝论》）：

- **生我者为恩星**（父母之类，吉）：得恩星扶持则吉。
- **我生者为用星**（子孙，泄我之气）：用星得地则秀。
- **克我者为难星**（官鬼，凶）：难星侵凌则凶。
- **我克者为仇星**（妻财被我制）：仇星得地反成福。

以金星（属金）为例：
- 恩星：土星、计都（土生金）
- 用星：水星、月孛、月亮（金生水）
- 难星：太阳、罗睺、火星（火克金）
- 仇星：木星、紫炁（金克木）

另一条重要规则是**余奴伤主**（果老星宗卷九「余奴伤主论」）：四余是七政的「余奴」，余奴犯主则凶——
- 罗睺是火星的余奴，犯火（及日）则凶；
- 计都是土星的余奴，犯土（及月）则凶；
- 紫炁是木星的余奴，犯木则凶；
- 月孛是水星的余奴，犯水则凶。

### 1.6 星曜之间的「守照冲钓」

星曜不是孤立的，它们通过空间关系产生「合力」：

| 关系 | 定义 | 吉凶 |
|---|---|---|
| **守** | 星曜同宫（本宫） | 有情则吉，无情则凶 |
| **照** | 三方（三合，相隔120°）或四正（对宫冲照） | 拱照吉则吉、冲照凶则凶 |
| **冲** | 对宫（子午、丑未…对照） | 凶星对照为祸，吉星对照为助 |
| **钓/拱** | 三合拱（申子辰、寅午戌、巳酉丑、亥卯未） | 有情拱者吉 |
| **夹** | 两星夹一宫（日月夹命、福禄夹身） | 有情夹者贵 |
| **会/聚** | 诸星聚一宫一度（如五星连珠、十一曜拱命） | 顺度相生则贵格 |
| **截** | 罗计拦截（昼截东南、夜拦西北） | 截断出文东武西、漏出有用星则贵 |
| **躔次/交战** | 两星同度克战（金木共躔、水火同步） | 相克则战，凶 |

《天元五歌》总结：「三方对照紧相随，同宫过宫一例推。拱夹有情权力大，日月交授格尤奇。」又：「以恩为用多至宝，以难为用多颠倒。以恩为忌寿而贫，以难为忌身不保。」

## 四、五行生克与庙旺规律总结

### 4.1 五行相生相克（能量流转底层）

```
相生：木生火 → 火生土 → 土生金 → 金生水 → 水生木
相克：木克土 → 土克水 → 水克火 → 火克金 → 金克木
```

星曜能量按此流转：生我者（恩）给我能量，我生者（用）泄我能量，克我者（难）夺我能量，我克者（仇）被我制。

### 4.2 庙旺乐陷规律（位置增益的口诀）

来自《果老星宗·星辰庙旺图》及各家「庙旺歌」，归纳如下（黄道十二宫，子=宝瓶…午=狮子…依二十八宿配宫）：

**庙宫歌**
```
土丑罗寅火卯中，金在辰宫计在巳，
水罗午地好相逢，孛星惟向未中取，
紫气申宫总一同，日月戌方云入庙，
计都木亥尽亨通。
```

**旺宫歌**
```
水瓶火丑孛寅当，土罗计在卯中旺，
辰位土宿再荣昌，水日巳宫金到午，
木居未上紫干扬，太阴在酉天尾戌，
金木之星亥上藏。
```

**乐宫歌**（寻宫主所在）
```
土星子丑金辰酉，末属太阴午太阳，
火星卯戌水巳申，木星到亥兼寅，
罗睺午上计都子，紫来戌上孛逢辰。
```

**喜宫歌**
```
日寅月亥水辰清，土居午上木居末，
火申罗戌便昌荣。
```

**好宫歌**（垣局）
```
太阴太阳与土星，子午卯酉为垣局；
木星辰戌及丑未，水火寅中及巳亥，
罗计卯酉福犹奢，孛紫寅申邦国泰。
```

**躔度喜忌（升殿宿）**
```
日躔星虚房昴（四日度），月躔心张危毕（四月度），
木躔角斗奎井（四木度），火躔尾室觜翼（四火度），
土躔女胃柳氐（四土度），金躔亢牛娄鬼（四金度），
水躔箕壁参轸（四水度）。
```

**忌格（失次）**：星曜居「克战之宫/度」则凶，如木入金乡（辰酉）、火居水地（巳申）、土在木宫（寅亥）、金乘火位（卯戌）、水居土室（子丑）、金木共躔、水火同步、木土相克、火金交战、土水相激（均为相克战格）。

### 4.3 四时旺相休囚死（令星）

《果老星宗》李憕问答：「春木旺、火相、水休、金囚、土死；夏火旺、土相、木休、水囚、金死；秋金旺、水相、火休、木囚、土死；冬水旺、木相、金休、土囚、火死；季月土旺、金相、水休、木囚、火死。」

对应**令星**（当令之星）：春木、夏火、秋金、冬水、季月土。令星得时则有力，失时则减。

## 五、星曜之间生克互动的实战法则

1. **恩用仇难定吉凶**：以命度主星为我，生我（恩）、我生（用）、克我（难）、我克（仇）。恩星得地则贵，难星侵凌则凶。
2. **余奴伤主**：罗伤火、计伤土、炁伤木、孛伤水；用神星被其本余奴犯则损（如「木气脚疾」「气罗克子」「孛罗交战」）。
3. **制化通关**：凶星得相克之星制伏则转吉——太阳通关诸煞（尤罗月孛）、木星制火土罗计、金星调和水火矛盾。
4. **守照冲钓有情无情**：日月夹命/拱命最贵；福禄拱身命吉；凶星拱夹刃雄则凶；罗计拦截成格则封闭待通。
5. **昼夜得宜**：昼星昼生、夜星夜生方显力；反背则减（如孤阳无辅、寒月单行）。
6. **庙旺落陷定强弱**：吉星庙旺吉性倍增，落陷大减；凶星庙旺可化凶为吉（如「庙旺凶星化凶为吉」），落陷凶性倍增。

## 七、研究不足与待补

1. **化气表述不统一**：「化贵/化富/化兵/化信/化义/化智」为各派常见归纳，但天官五星派的「化气」体系与果老星宗并不完全一致，且本项目 `constants.json` 中「化气」字段尚未结构化提取，需对照《星学大成》卷一「十干变曜所属」逐条补全。
2. **庙旺数据有分歧**：不同流派（琴堂/果老/天官）庙旺表略异；本项目 `core.py` 的 `calc_dignity` 用的是 moira_s.prop 数据，需与本节口诀逐宿核对（尤其是「殿/垣」二态 project AGENTS.md 标注「当前无数据」）。
3. **四余的庙旺细节**：四余的「乐/喜/好」宫在部分歌诀中残缺（如计都喜宫、月孛喜宫原歌未明列），需补《三辰通载》各余星篇的「枢要歌/玉关歌」。
4. **恩用仇难的「我」的动态性**：恩用仇难以命度主为参照，不同命局「我」不同，本文给的是以金星为静态例，实战需以命主/身主/用神为动态参照。
5. **缺「强弱宫」「虚实五星」维度**：《星学大成》强调「虚实」与「强弱宫」，星曜能量还受本盘强弱宫、暗盘虚实影响，本文未展开。
6. **四余天文定义仍存新旧法争议**：罗睺升/降交点、紫炁是否真有天文对应、月孛用 mean 还是 oscu，学界与术家尚无统一，本项目采用「与 Java MOIRA 默认一致 + 双模式开关」的务实方案，但旧法（罗=降交点）在断语上可能与部分古籍相反，需标注。
7. **未覆盖「三辰通载」逐星歌断**：每颗星曜入宫/躔度/照宫的详细断语（如「岁星入宫枢要歌」「荧惑躔度玉关歌」）未逐条摘入，宜作为后续 raw 研究的扩展。
