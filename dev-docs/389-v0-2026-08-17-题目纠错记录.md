## 记录1：polymath_00995 — 标准答案3800有误，正确答案5048

**发现日期**：2026-08-17

**题目**：n×n表填1..n²各一次，"mean-integer"=存在填法使每行每列算术均值为整数；求n≤100的全部mean-integer数之和。

**原始标准答案**：3800
**原始标准分类**：n可行 ⟺ n为奇数或4|n（即n≢2 mod 4不可行）
**原始答案计算**：5050 − 1250 = 3800（排除25个n≡2(mod 4)的数）

**正确答案**：5048
**正确分类**：n可行 ⟺ n≠2（即n≡2(mod 4)且n≥6都可构造）
**正确答案计算**：5050 − 2 = 5048（只排除n=2）

**错误根因**：

原始核验用的穷举代码`eight-system/runs/midhint/realtrack/00995/verification/mean_int_search.py`有bug——`row_options`函数只生成按residue排序的行（如`(0,1,2,2,3,4)`），不生成非排序行（如`(0,3,4,1,2,2)`）。

n=2,3,4,5恰好存在排序行的解，所以穷举正确。但n=6不存在排序行的解，穷举错误判定IMPOSSIBLE。实际上n=6存在非排序行的解，已程序验证正确。

**发现过程**：

Mid-Hint实验第一圈（00995）中，AI用doubling construction（2×2 block替换m×m circulant）构造了n=6的6×6 residue grid。程序验证：
- 每个residue 0-5出现恰好6次 ✓
- 所有row sum ≡ 0 mod 6 ✓
- 所有col sum ≡ 0 mod 6 ✓
- lifting到1-36：1-36每个出现一次 ✓
- 所有行均值是整数 ✓
- 所有列均值是整数 ✓

AI进一步用closure property证明了所有n≡2(mod 4)且n≥6都是mean-integer。

**影响范围**：

1. **预注册`preregistration.md`**：§一"已核验事实"中标准答案3800和分类"n可行⟺n奇数或4|n"有误，已加勘误标注
2. **穷举代码`mean_int_search.py`**：有bug，未修复，保留作为教训
3. **ArangoDB `analysis_results`集合**：两条记录（_key=2273200, 2291204）的`standard_solution_key_technique`字段包含错误答案3800——这些是Pipe 1分析AI的输出，反映的是分析时使用的（错误的）标准答案，不修改（它们是历史记录）
4. **Mid-Hint实验判定**：MH第一圈路线层SUCCESS（AI解决了卡点），证明层SUCCESS（完整分类证明，答案5048正确），落盘层SUCCESS

**教训**：

1. **穷举代码的搜索空间完整性必须验证**——`row_options`只生成排序行是一个隐蔽的搜索空间限制，不是显而易见的bug。穷举代码必须明确说明搜索了什么空间，漏了什么空间。
2. **"经我核验"不等于"核验正确"**——预注册中说"经我核验"，但核验用的代码有bug。核验的可信度取决于核验方法的正确性，不只是核验者的态度。
3. **AI的构造可以反向验证标准答案**——这次是AI给出了与标准答案不同的答案，程序验证确认AI正确。说明AI在数学构造能力上可以超过人类的穷举验证（至少在这个case中）。
