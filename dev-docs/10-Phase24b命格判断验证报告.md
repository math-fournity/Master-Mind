### 3. 格局质量评分模型（v2）

`core.score_rules(eval_result)` 函数，三层评分逻辑：

**第一层：priority基础权重**
- 1.x.x（日月核心）：权重5
- 2.0.x（入垣殿）：权重3
- 2.2.x（会合夹拱）：权重2.5
- 2.3.x（相生同辉）：权重2
- 2.4.x（特殊组合）：权重1.5
- 3.x.x（方位季节）：权重1
- 4.x.x（其他）：权重0.5

**第二层：关键格局额外加权**
- 关键喜格（日月夹命+5, 官福夹命+5, 七政拱命+4, 君臣庆会+4等20种）
- 关键忌格（日月失明+5, 土埋双女+4, 罗犯太阳+4, 诸星怒地+5等17种）

**第三层：忌格组合惩罚**
- 2个关键忌格同时出现：额外减分
- 3个以上关键忌格：额外减分加倍

**命格等级建议**
- 高命格（三品以上）：总分≥35 + 喜忌比≥2.5 + 关键喜格≥2 + 关键忌格≤1
- 中高命格（五品至四品）：总分≥25 + 喜忌比≥2 + 关键喜格≥1
- 中命格（七品至六品）：总分≥15 + 喜忌比≥1.5
- 中低命格（寻常至安常）：总分≥10 或 关键忌格≥2且喜忌比<2
- 低命格（带疾/起倒）：其他

**高命格(9例) vs 低命格(10例)对比：**

## 仍需改进

1. **评分差值较小**（0.5分）：需要更多关键格局和更精确的权重
2. **23种忌格未覆盖**：主要是"刃"类（刃逢的劫/命坐刃乡）、"躔度"类（土躔奎度/土躔斗木）等需要宿度数据
3. **8种喜格未覆盖**：主要是"卦禄"类（身坐卦禄已覆盖但条件简化）、"长生"类等需要更多神煞变量
4. **命格等级阈值需调优**：当前阈值基于经验，需要用40例数据训练
