## 形式化分析

### 1. 形式化五问

#### 规则: 元守星辨析 → 此主元来不是活

- **算子**: 元守（natal guarding / 本命守宫之星）
- **输入**: 
  - "五星宿"——七政四余星曜体系
  - "先后宫主"——宫主系统（先）与度主系统（后）
  - "元守星"——世俗所称的本命守宫星
- **输出**: 
  - 概念辨析命题："世人只说元守星，此主元来不是活"
  - 即：世俗所说的"元守星"并非一个动态的、可变化的"活"概念，而是由宫主/度主系统静态确定的
- **可求值性**: **部分可求值**——
  - 宫主可求值：给定命宫地支 → 宫主星（子丑→土，寅亥→木，卯戌→火，辰酉→金，巳申→水，午→日，未→月）
  - 度主可求值：给定命宫宿度 → 度主星（按二十八宿五行归属）
  - "元守星"的精确定义需进一步考证——歌诀本身是在辨析而非定义
- **一致性**: 与《果老星宗》"宫主者…以度主为是"一致——先定宫主，后定度主，二者构成"先后宫主"的层级关系

### 2. 定量化分析

#### 宫主映射表（定量结构）

| 命宫地支 | 宫主星 | 五行 |

| 子、丑 | 土星 | 土 |
| 寅、亥 | 木星 | 木 |
| 卯、戌 | 火星 | 火 |
| 辰、酉 | 金星 | 金 |
| 巳、申 | 水星 | 水 |
| 午 | 太阳 | 日（火之精） |
| 未 | 太阴 | 月（水之精） |

**量化特征**：
- 12地支 → 7主星（日月五星）的多对一映射
- 每个宫主对应一个五行属性
- 午未为日月专宫，其余10地支按五行两两配对
- 这是一个**完全确定的查表函数**，无歧义

#### "先后"的层级量化

"先后宫主"暗示一个优先级序列：
1. **先**（第一级）：宫主——按命宫地支查表
2. **后**（第二级）：度主——按命宫宿度查表
3. **回退规则**（来自《果老星宗》）：度主无星时以宫主论

### 3. 开放性分析

#### "此主元来不是活"的多重解读

这是本节最核心也最模糊的命题，存在多种解读：

1. **解读A——静态确定性**：
   - "不是活"= 不是动态变化的
   - 元守星由出生时刻的命宫决定，一经确定便不再改变
   - 与流年、行运中变化的"飞星""流耀"形成对比
   - **支持证据**：主星守宫歌前六节均讨论"主星入命"的静态格局

2. **解读B——概念纠正**：
   - "不是活"= 世人所说的"元守星"这个概念本身不够精确/不够"活"
   - 应该用"先后宫主"（宫主+度主）来替代笼统的"元守星"说法
   - **支持证据**：歌诀前半句"论五星宿无多诀，先后宫主分明说"是在给出正确方法

3. **解读C——方法论提示**：
   - "不是活"= 不要把元守星当作一个独立的、可单独操作的"活"实体
   - 元守星必须放在宫主/度主的框架中理解
   - **支持证据**：《果老星宗》"以度主为是"的优先级思想

**待考证问题**：

#### "先后"二字的歧义

- **解读1**：先=宫主，后=度主（时间/层级上的先后）
- **解读2**：先后=前后的宫主（如命宫主与身宫主的先后排列）
- **解读3**：先后=生年前后（如大运前后段的宫主变化）

从《果老星宗》"以度主为是"的表述来看，**解读1最为合理**——宫主是初步（先），度主是精确（后）。

### 4. 全息分析（跨体系）

#### 与八字体系的对应

- **宫主 → 八字"日主"**：宫主由命宫地支决定，类似八字中日干决定日主
- **度主 → 八字"藏干"**：度主由宿度决定，类似八字地支藏干提供更细粒度的主星
- **"先后"层级 → 八字"本气/中气/余气"**：宫主如本气，度主如藏干中的中气余气

#### 与紫微斗数的对应

- **宫主 → 紫微"宫位主星"**：紫微斗数中每个宫位有主星入驻，类似宫主守宫
- **度主 → 紫微"度数"概念**：紫微斗数虽不强调宿度，但星曜入庙旺平陷仍与度数相关
- **"元守星" → 紫微"本命盘星曜"**：出生时排定的星曜位置，与"元守"概念一致

#### 与西方占星的对应

- **宫主（Lord of House） → 西方占星"宫主星"**：西方占星中每个宫位的守护星，与七政四余宫主完全对应
- **度主 → 西方占星"定位星"（Dispositor）**：星曜所在星座的守护星，类似度主
- **"先后" → 西方占星的"宫主星 vs 定位星"双层系统**

### 5. 时代性分析

#### 历史背景

- **"世人只说元守星"**：反映当时（明代或更早）民间星命学界存在一种笼统使用"元守星"概念的流行做法
- **"此主元来不是活"**：作者试图纠正这种笼统做法，强调应回到"先后宫主"的精确体系
- 这是一种**学术纠偏**的口吻，暗示《星平会海》编者对当时星命学实践的不满

#### 现代诠释

- **"元守星"→ 本命盘核心主星**：在现代七政四余实践中，"元守星"可理解为出生时排定的命主星/身主星
- **"先后宫主"→ 宫主+度主双系统**：现代实践应同时考虑宫主（粗粒度）和度主（细粒度）
- **"不是活"→ 静态属性**：元守星是出生时确定的静态属性，不随时间变化，与行运星（动态）形成对比
