## 1. 题海战术的总思路

用户要求：系统化搜索数学各门类能够下载下来的大型题库（题海），用于批量测试裸AI的数学能力边界。

1. **题量大**（500题以上）
2. **有解答**（可校验）
3. **可下载**（PDF/电子版可获得）
4. **覆盖数学各门类**

## 7. 题海战术执行方案

### 7.1 分层测试策略

```
第一层：初等数学（笹部系列）
  → 定位AI在哪个初等数学领域/难度开始做不出来
  → 题量：从15000中筛选2000-3000道构造性证明题

第二层：大学数学（吉米多维奇+代数习题集+Springer系列）
  → 定位AI在大学数学哪个领域开始做不出来
  → 题量：从~10000中筛选2000道证明题

第三层：研究级（丘成桐+Berkeley+arXiv+Ramanujan）
  → 定位AI在研究级问题上的能力边界
  → 题量：~500-1000道

第四层：竞赛最难题（CMO/JMO/KMO/IMO P6）
  → 定位AI在顶尖竞赛题上的能力边界
  → 题量：~50-100道
```

### 7.2 执行流程

```
Step 1: 下载题海PDF（第一优先6个来源）
Step 2: OCR/提取题目为结构化格式（题号+题面+答案）
Step 3: 按难度分级筛选（基础计算题跳过，重点选证明题/构造题）
Step 4: 5个sub agent并行测试，不许联网
Step 5: 校验（SymPy数值验证 + 对比标准答案）
Step 6: 记录"解不出来"的题目 → 按门类/难度分类
Step 7: 生成"AI能力边界图谱"——哪个门类/哪个难度级别开始做不出来
Step 8: 进入系统引导实验池
```
