## 1. 扩展验证目标

269号报告发现4阶群对AI太简单（10/10正确）。本扩展验证在更大规模虚拟群上测试AI baseline，目标是找到AI做不出来的虚拟群论题。

## 2. 测试设计

**10道难题**，选自600道题库中的大规模非交换群：
- S₄（24阶对称群）× 6类挑战模板
- D₆（12阶二面体群）× 4类挑战模板

**挑战难度**：
- S₄有30个子群（vs 4阶群的3-5个子群）
- S₄有5个共轭类（vs 4阶群的4个单元素共轭类）
- S₄的中心是平凡的（vs 4阶交换群中心=整个群）
- 24×24乘法表=576个条目（vs 4×4=16个条目）

## 4. 关键发现

### 4.1 GLM-5.2在虚拟群论上能力极强

**24阶群对AI仍然不够难**。AI能：
- 从乘法表反推群结构（S₄/D₆）
- 枚举全部子群（30个/16个）
- 计算共轭类和中心
- 构造同态
- 标注同构类型

### 4.2 268号报告的6类挑战模板在虚拟群论中未复现

268号报告分析的真实难题挑战类型（跨概念推理跳跃50%、需要非显然构造42%）在虚拟群论中**完全没有出现**。原因：

1. **群论问题结构太清晰**——"找子群""判正规""求中心"都是标准操作，AI有完整的知识库
2. **虚拟群的规模不够大**——24阶群的乘法表虽大，但AI用Python可以暴力枚举
3. **问题太"教科书化"**——真实竞赛难题需要跨概念跳跃，虚拟群论题都在单一领域内
4. **AI的群论知识太强**——GLM-5.2对群论有深入理解，能识别S₄/D₆等经典群

### 4.3 虚拟群论baseline强是正面信号

虽然没找到AI做不出来的题，但这说明：
- **虚拟群论基础设施完全可用**——生成器、题目、验证、评估全链路通畅
- **AI能在虚拟群上做真实推理**——不是靠猜，而是靠完整的数学推理
- **先验知识污染可控**——AI用S₄/D₆等真实数学概念解题，但这是预期行为（虚拟群和真实群同构，AI识别同构关系是正确推理）

### 4.4 需要重新设计"挑战"的构造方式

268号报告的6类挑战模板来自**真实竞赛难题**（AIME/USAMO/HMMT级别）。这些题的挑战不在于"计算量"而在于"推理跳跃"——需要连接不同数学领域的概念。

虚拟群论题目前都在**单一领域内**（群论），无法复现"跨概念推理跳跃"。要复现268号的挑战类型，需要：

**方案A：跨域虚拟题**
- 构造需要群论+数论联合推理的虚拟题
- 例如："虚拟群G的阶是p²q形式，判断G是否是单群"——需要群论+数论联合

**方案B：证明题而非计算题**
- 构造需要多步证明链的虚拟定理证明题
- 例如："证明虚拟群G的每个p-子群都包含在某个Sylow p-子群中"——需要组织证明结构

**方案C：非标准问题**
- 构造不在标准群论教科书中的问题
- 例如："虚拟群G的自同构群的结构是什么"——需要构造自同构，计算量大且不显然

**方案D：接受baseline强，直接进入POC-VMS-1**
- 不追求"AI做不出来"的题
- POC-VMS-1的目标是从QA序列中提炼Pattern，即使AI做出来了，QA序列也有价值
- Pattern的验证不依赖AI做不出来，而依赖检索系统能否在大量干扰中找到正确Pattern

## 5. 推荐

**推荐方案D**——接受baseline强，直接进入POC-VMS-1。

**理由**：
1. POC-VMS系列的核心验证目标是**检索系统能力**，不是AI能力边界
2. 即使AI能做出来，预演模式的QA序列仍然包含有价值的Pattern
3. 检索系统的验证（POC-VMS-2~4）需要的是大量Pattern，不是难题
4. 跨域虚拟题（方案A）和证明题（方案B）的设计成本高，且偏离了VMS的核心目标

**但保留方案A作为后续选项**：如果POC-VMS-2~3发现检索系统在"跨概念Pattern"上效果不好，可以回来构造跨域虚拟题来补充Pattern库。
