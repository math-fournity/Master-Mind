## 1. 题海战术的总思路

用户要求：系统化搜索数学各门类能够下载下来的大型题库（题海），用于批量测试裸AI的数学能力边界。

**筛选标准**：
1. **题量大**（500题以上）
2. **有解答**（可校验）
3. **可下载**（PDF/电子版可获得）
4. **覆盖数学各门类**

**v1更新**：v0只覆盖了纸质书的PDF扫描版（笹部系列、吉米多维奇、Springer Problem Books等）。v1新增了2026年最新发布的**纯电子化、AI训练级**超大规模题库——这些题库原本就是为训练/评测大模型数学推理能力而建，数据格式干净（JSON/Parquet/LaTeX），不需要OCR，直接可用。

## 2A. 纯电子化来源（2026年最新 · v1新增）

**这是v1最重要的新增内容。** 以下来源全部是2024-2026年发布的、为AI数学推理研究而建的超大规模电子题库，数据格式干净（JSON/Parquet/LaTeX），不需要OCR，直接可用。题量远超纸质来源。

### 2A.1 MathNet（MIT ICLR 2026 · 30,676题 · 最大竞赛题库）

| 项目 | 内容 |
|------|------|
| **来源** | MIT等机构，ICLR 2026论文 |
| **题量** | **30,676题** |
| **覆盖** | 47个国家、17种语言、143个竞赛、1985-2025年 |
| **格式** | HuggingFace dataset（JSON/Parquet） |

| **GitHub** | https://github.com/ShadeAlsha/MathNet |
| **网站** | https://mathnet.mit.edu |
| **数据** | HuggingFace托管（通过`datasets`库加载） |
| **论文** | https://arxiv.org/abs/2604.18584 |

**独特价值**：目前世界上最大的国际数学奥林匹克问题及解答的数字化开源数据库。47国17语言，覆盖CMO/JMO/KMO/IMO/巴尔干/北欧/亚太/伊比利亚等全部主要竞赛。**非AoPS众包**，而是官方国家队题册，质量有保证。

## 2C. 纸质来源 vs 纯电子化来源对比

| 维度 | 纸质来源（§2） | 纯电子化来源（§2A） |
|------|----------------|---------------------|
| 总题量 | ~35,000-40,000 | ~950,000+ |
| 数据格式 | PDF扫描（需OCR） | JSON/Parquet/LaTeX（直接可用） |
| 解答质量 | 专家撰写 | 专家撰写 + CoT格式 |
| AI训练数据风险 | 低-中（题量大） | 中-高（AI研究社区已知） |
| 获取速度 | 慢（OCR瓶颈） | 快（直接下载） |
| 领域覆盖 | 初等数学全领域 | 竞赛数学+K12+论坛 |
| 形式化验证 | 无 | 有（compfiles Lean 4） |
| 抗污染 | 高（日文/中文老书） | 低-中（公开数据集） |

**结论**：两类来源互补。纸质来源（笹部/吉米多维奇）适合**抗污染测试**（AI没见过的题），纯电子化来源适合**大规模快速测试**（数据干净，直接可用）。

## 6. 题海战术执行方案（v1更新）

### 6.1 分层测试策略

```
第一层：抗污染测试（纸质来源 · AI没见过的题）
  → 笹部系列15000题 + 吉米多维奇5000题
  → 定位AI在"没见过的题"上的真实能力
  → 数据格式：PDF需OCR，但抗污染价值最高

第二层：大规模快速测试（电子化来源 · 数据干净）
  → MathNet 30K竞赛题 + NuminaMath 11万证明题
  → 定位AI在竞赛数学各领域的能力分布
  → 数据格式：JSON/Parquet，直接可用

第三层：抗污染+时间戳验证（AoPS-Instruct）
  → LiveAoPSBench按时间戳分割
  → 检测AI是否因预训练暴露而"假会"
  → 旧题vs新题对比，定位真实推理能力

第四层：研究级（丘成桐+Berkeley+arXiv+Ramanujan+ConjectureBench）
  → 定位AI在研究级问题上的能力边界
  → ConjectureBench测试猜想提出能力

第五层：竞赛最难题（CMO/JMO/KMO/IMO P6）
  → 定位AI在顶尖竞赛题上的能力边界
  → compfiles提供Lean 4形式化验证
```

### 6.2 执行流程

```
Phase 1: 下载（当前进行中）
  → 纯电子化来源：HuggingFace + GitHub（快速，数据干净）
  → 纸质来源：Internet Archive + Z-Library（较慢，需OCR）

Phase 2: 数据预处理
  → 电子化来源：直接加载（JSON/Parquet）
  → 纸质来源：OCR提取题目为结构化格式
  → 按难度分级筛选（基础计算题跳过，重点选证明题/构造题）

Phase 3: Baseline测试
  → 5个sub agent并行测试，不许联网
  → 每题3次运行
  → 校验（SymPy数值验证 + 对比标准答案 + Lean 4形式化验证）

Phase 4: 分析
  → 记录"解不出来"的题目 → 按门类/难度/来源分类
  → 生成"AI能力边界图谱"——哪个门类/哪个难度级别开始做不出来
  → 对比纸质来源vs电子化来源的通过率（抗污染效果验证）

Phase 5: 进入系统引导实验池
  → 从"解不出来"的题中筛选适合引导的题
  → 用数学大师系统引导AI解题
  → 验证系统引导的增益效果
```
