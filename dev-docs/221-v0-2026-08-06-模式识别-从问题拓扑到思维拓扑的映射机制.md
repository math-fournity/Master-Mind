## 0. 本文档的定位

220号从四个小学/初中例子中提取出"换基"这一统一拓扑。但留下了一个关键问题：**面对一个新问题，怎么知道该不该换基？该换什么基？**

这就是模式识别的问题。本文档回答：模式识别识别的是什么？它和拓扑是什么关系？它需要什么条件才能工作？

## 1. 什么时候你会想到"换基"

回到220号的四个例子，看触发信号：

| 例子 | 触发信号 | 你看到了什么 |
|---|---|---|
| 鸡兔同笼抬腿法 | 两种动物脚数不同但有共同部分 | 当前表示中有隐藏的直和分解 |
| 分数约分 | 50和100有公因子 | 当前表示中有冗余 |
| 因式分解 | x²-1看起来像平方差 | 当前表示中隐藏了乘积结构 |
| 内角和 | 三个角看起来独立但不独立 | 当前表示中有虚假的自由度 |

四个信号各不相同。但有一个共同点：

> **你看到了当前表示中的某种"不自然"——冗余、隐藏的乘积、虚假的自由度、不对称。**

"不自然"就是换基的触发条件。当前表示不是最优的——结构特征被隐藏、扭曲、不清晰。

---

## 2. 模式识别识别的是什么

### 2.1 不是表面内容

模式识别不是识别"这是鸡兔同笼"——那是表面内容的识别，只对同类题有效。

### 2.2 是表示与结构之间的不匹配

模式识别识别的是：

> **当前表示中，我关心的结构特征是隐藏的、扭曲的、不清晰的。**

更精确地说，识别的是**当前表示和内在结构之间的不匹配**——表示方式没有让结构特征以最清晰的方式呈现。

### 2.3 这种"不匹配"本身就是拓扑的

"不匹配"不是表面特征（具体数字、具体条件），而是结构特征——它跨越表面内容。x²-1的"隐藏乘积"和50/100的"冗余"表面完全不同，但都是"当前表示不匹配内在结构"。

所以模式识别识别的是**问题的拓扑特征**——具体地说，是"表示与结构不匹配"这一类拓扑特征的各种子模式。

---

## 3. "不自然"的种类——换基的子模式

"当前表示不自然"不是一个单一信号，而是有多种不同的"不自然"。每种"不自然"对应换基拓扑的一个**子模式**，也对应一种不同的换基方法。

### 3.1 从四个例子中提取的子模式

| 子模式 | "不自然"的表现 | 例子 | 换基方法 |
|---|---|---|---|
| **冗余** | 表示中有可约去的公共因子 | 50/100 | 约分——去掉冗余 |
| **隐藏乘积** | 展开形式掩盖了因子结构 | x²-1 | 因式分解——从展开到乘积 |
| **虚假自由度** | 看起来独立的量被全局约束 | (A,B,C) with A+B+C=180° | 换基——从独立坐标到和+自由坐标 |
| **隐藏直和** | 混合表示掩盖了共同+差异的分解 | 鸡兔同笼的脚数 | 直和分解——分离共同部分和差异部分 |

### 3.2 可能还有更多子模式

这四个子模式来自四个例子。随着例子积累，可能发现更多"不自然"的种类：

| 候选子模式 | "不自然"的表现 | 可能的例子 |
|---|---|---|
| **不对称** | 表示中本应对称的部分不对称 | 坐标系选择不当 |
| **过度参数化** | 参数比自由度多 | 有约束的参数空间 |
| **尺度不匹配** | 不同项的量级差异大 | 渐近分析中的主项+修正项 |
| **基底不匹配** | 问题的对称性和表示的对称性不一致 | 群论中的表示论 |

### 3.3 子模式库的开放性

子模式库是**开放的**——每解决一个新问题，可能发现一种新的"不自然"，从而增加一个子模式。这意味着模式识别能力随经验增长——这和人类数学家的经验积累一致。

## 4. 模式识别的两步结构

### 4.1 两步

模式识别不是一步完成的，而是两步：

```
步骤1：识别问题的拓扑（这个问题有什么形状特征？）
步骤2：映射到思维的拓扑（这种形状该用什么思维模式？）
```

### 4.2 在换基的例子中

| 例子 | 步骤1：识别问题拓扑 | 步骤2：映射到思维拓扑 |
|---|---|---|
| 分数约分 | "表示中有冗余" | "冗余→约分（去掉冗余的换基）" |
| 因式分解 | "展开形式掩盖了乘积结构" | "隐藏乘积→因式分解（展开到乘积的换基）" |
| 内角和 | "三个量看起来独立但不独立" | "虚假自由度→换基（独立坐标到和+自由坐标）" |
| 抬腿法 | "混合表示掩盖了共同+差异" | "隐藏直和→直和分解（混合到共同+差异）" |

### 4.3 两步的依赖关系

步骤2依赖步骤1——必须先识别出问题的拓扑特征，才能映射到思维拓扑。但步骤1也依赖步骤2——你知道哪些拓扑特征是"有用的不自然"，因为你有一个思维拓扑库告诉你什么"不自然"值得注意。

这是一个**双向依赖**：问题拓扑和思维拓扑互相定义。这不是缺陷，而是认知的本质——你看到什么，部分取决于你知道看什么。

---

## 5. 模式识别需要什么条件

### 5.1 拓扑库（必要条件）

模式识别依赖于**已知的拓扑特征库**——你提取过多少种"不自然"，就能识别多少种"不自然"。

```
模式识别能力 = f(拓扑库的大小, 拓扑库的多样性, 映射的准确性)
```

没有拓扑库，模式识别就是盲目的——你看到x²-1不会想到平方差，因为你不知道"隐藏乘积"这个子模式。

### 5.2 拓扑库的来源

拓扑库从哪里来？从**具体例子的抽象**中来：

```
具体例子 → 提取思维拓扑 → 归入拓扑库 → 面对新问题时匹配
```

220号从四个例子中提取了"换基"拓扑和四个子模式。这就是拓扑库的初始版本。

### 5.3 映射的准确性

光有拓扑库不够，还需要**准确的映射**——从问题拓扑到思维拓扑的映射。

映射的准确性来自：
1. **子模式的清晰定义**——"冗余"是什么？"隐藏乘积"是什么？定义越清晰，匹配越准确
2. **子模式之间的区分**——"虚假自由度"和"过度参数化"有什么区别？区分越清楚，不会误匹配
3. **反例的积累**——什么情况下"看起来像冗余"但其实不是？反例防止过度匹配

## 6. 模式识别与AI引导的关系

### 6.1 引导者需要模式识别

引导者面对AI的回复，需要判断：
- AI走的方向对不对？
- AI有没有看到"不自然"？
- AI需不需要被提示"这里有不自然"？

这些判断都需要模式识别——引导者需要识别AI当前面对的问题拓扑，判断是否需要换基，决定是否提示。

### 6.2 非特定化引导的模式识别

218号揭示了特定化引导的问题：引导者通过引用AI选的特定方向，隐含地确认了正确路径。

模式识别提供了一种**非特定化引导**的可能：

```
引导者识别到问题拓扑特征（如"隐藏乘积"）
  → 提示AI："你有没有注意到当前表示中可能隐藏了某种结构？"
  → AI自己发现乘积结构
  → AI自己换基
```

这个提示是非特定的——它没有说"因式分解"，没有说"用(x+1)(x-1)"，只是指向了"不自然"这一拓扑特征。但它也不是完全空泛的——它指向了具体的"不自然"种类，比纯元认知指令（"再想想"）更有效。

### 6.3 这就是219号说的"结构化引导"

219号提出第三个选项：基于问题拓扑的非特定引导。221号明确了这个选项的机制——**引导者用模式识别判断问题拓扑，用拓扑库中的子模式设计提示，提示指向拓扑特征而非特定解答路径**。

## 7. 模式识别本身的拓扑

### 7.1 模式识别是什么拓扑？

模式识别本身是不是一种思维拓扑？如果是，它和换基是什么关系？

**模式识别是换基的前置操作**——它识别"需要换基"，但不执行换基。它的拓扑是：

```
模式识别 = (感知当前表示) × (匹配已知拓扑特征) × (判断不匹配)
```

### 7.2 模式识别可能属于另一个拓扑

但模式识别不只是换基的前置。它也前置于其他思维拓扑——比如归纳法（识别"这个问题有递归结构"）、构造法（识别"这个问题需要构造一个新对象"）。

所以模式识别可能是一个**元拓扑**——它不解决任何问题，但判断该用什么拓扑来解决问题。

### 7.3 元拓扑的层级

```
元拓扑（模式识别）：判断该用什么拓扑
  ↓
思维拓扑（换基/生成/...）：执行某种思维模式
  ↓
具体操作（约分/因式分解/...）：在具体问题上执行
```

模式识别在最顶层——它不解决问题，但决定该用什么来解决问题。

## 8. 当前拓扑库的版本

### 8.1 v0.1（来自220号的四个例子）

**思维拓扑：换基**
- 定义：在保持本质不变的前提下，找到让结构最清晰的表示
- 子模式：
  1. 冗余→约分
  2. 隐藏乘积→因式分解
  3. 虚假自由度→换基（独立坐标到和+自由坐标）
  4. 隐藏直和→直和分解（混合到共同+差异）

### 8.2 v0.2（本文档新增）

**元拓扑：模式识别**
- 定义：识别当前表示与内在结构之间的不匹配，判断该用什么思维拓扑
- 子模式：等待积累（需要更多例子才能识别"不匹配"的种类）

**候选思维拓扑：生成**（220号§8.5提出，待验证）
- 定义：从已知生成未知
- 候选子模式：归纳法、构造法、递推

### 8.3 拓扑库的增长方式

```
每解决一个新例子：
  1. 提取思维拓扑（如果是新的→加入拓扑库）
  2. 提取子模式（如果是新的→加入对应拓扑的子模式库）
  3. 提取模式识别信号（如果是新的→加入"不自然"的种类库）
  4. 验证映射准确性（这个子模式→这个换基方法，是否一致）
```

## 9. 下一步

### 9.1 验证"生成"拓扑

220号提出候选反例：归纳法、构造法、反证法。需要验证它们是否真的不能用换基解释。

- **数学归纳法**：从n=k推出n=k+1。这是"换基"还是"生成"？
  - 换基视角：把"对所有n成立"换成"从k到k+1的传递性"——这是换基吗？
  - 生成视角：从已知（n=k成立）生成未知（n=k+1成立）——这更像生成
  - **初步判断：更像生成，但需要更仔细的分析**

- **构造法**：构造一个新对象满足条件。这是"换基"还是"生成"？
  - 换基视角：构造的新对象是问题的一种新表示吗？
  - 生成视角：新对象是从条件"生成"的，不是已有对象的换表示
  - **初步判断：更像生成**

- **反证法**：假设结论不成立→矛盾。这是"换基"还是"生成"？
  - 换基视角：从"结论成立"换到"结论不成立"——这是换基吗？
  - 生成视角：从假设生成矛盾——这更像生成
  - **初步判断：模糊，可能两者都有**

### 9.2 积累更多换基的子模式

从更多例子中提取"不自然"的新种类：
- 不对称（坐标系选择不当）
- 过度参数化（有约束的参数空间）
- 尺度不匹配（渐近分析中的主项+修正项）
- 基底不匹配（群论中的表示论）

### 9.3 积累模式识别的信号

从更多例子中提取"什么时候该想到换基"的信号：
- 看到公因子→冗余
- 看到平方差模式→隐藏乘积
- 看到约束减少自由度→虚假自由度
- 看到混合中有共同部分→隐藏直和

### 9.4 建立映射

把"不自然"的种类→换基方法→具体操作的映射建立清楚，验证映射的准确性和可复用性。

## 10. 结论

### 10.1 模式识别识别的是什么

识别的是**当前表示与内在结构之间的不匹配**——即问题的拓扑特征，具体表现为各种"不自然"（冗余、隐藏乘积、虚假自由度、隐藏直和等）。

### 10.2 模式识别是元拓扑

模式识别不解决问题，但判断该用什么拓扑来解决问题。它是思维拓扑之上的元拓扑。

### 10.3 模式识别需要拓扑库

模式识别能力取决于拓扑库的大小和多样性。拓扑库从具体例子的抽象中积累——每解决一个新问题，可能发现新的"不自然"种类，从而扩展模式识别能力。

### 10.4 模式识别使非特定化引导成为可能

引导者用模式识别判断问题拓扑，用拓扑库中的子模式设计提示，提示指向拓扑特征而非特定解答路径。这就是219号说的"结构化引导"的具体机制。
