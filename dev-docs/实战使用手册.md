# MOIRA 七政四余 AI 实战使用手册

**版本**：2026-07-08（v1.1）
**目的**：让 AI 能够系统化、 repeatable 地完成一次完整七政四余推命。

---

## 标准入口：build_chart()

```python
from qizheng.chart import build_chart
chart = build_chart(year, month, day, hour, lon, lat)
```

**必查 22 字段**（每次论命必看）：
- bodies, dignities, mansions, speed_states
- eight_char, four_poles
- star_signs, now_data
- daxian, current_daxian, daxian_stars, limits
- rules（matched）
- houses, life_sign, self_sign

---

## 8 个业务工作流入口 · AI 提示模板

### 入口 1 · 命主档案管理
**模板**：
1. `db.add_subject(...)`（必须填 time_uncertainty）
2. `db.add_life_event(sid, year, event_type, description)`
3. 记录重大事件用于后续矫正

### 入口 2 · 排盘（定盘）
**模板**：
```python
chart = build_chart(...)
# 必须验证：命宫、身宫、四柱干支、昼夜判定
```

### 入口 3 · 出生时间矫正
**模板**：
- 生成初始 chart
- 收集 life_event
- AI 映射事件 → 星象
- 调用 `analysis.rectify_multi_point(year, month, day, targets)`
- 返回 consistency_score + recommended_ut

### 入口 4 · 格局分析
**模板**：
- `chart['rules']['matched']`
- 结合 `dignities` 判断成破
- 优先级越小越重要

### 入口 5 · 洞微大限推演
**模板**：
```python
from qizheng import analysis
for i in range(12):
    res = analysis.analyze_daxian_limit(chart, i)
    # 重点看 house、palace_lord、stars_in_limit、shen_sha_in_house
```

### 入口 6 · 流年推演
**模板**：
```python
res = analysis.analyze_liunian(chart, age)
```

### 入口 7 · 综合判读（AI 智能层核心）
**Checklist**（必须逐条过）：
- 身命二主强弱（命宫主 + 命度主庙旺）
- 四正宫（命、田、妻、官）吉凶
- 五行生克平衡
- 神煞叠加（吉多/凶多/交见）
- 格局成破（matched 是否完整）
- 大限/流年叠加

### 入口 8 · 主数据维护
- 新规则需“先搜索” + eval_rules 验证零异常

## 已知陷阱（必须避免）

- 节气分年月 vs 农历分年月
- 早子时规则
- 紫炁线性运动
- 罗睺 true_as_north

**本手册持续更新**。每次实战后补充新发现。
