# MOIRA 七政四余 AI 实战使用手册

**版本**：2026-07-08（v1）
**目的**：让 AI 能够系统化、 repeatable 地完成一次完整七政四余推命。

---

## 标准入口：build_chart()

```python
from qizheng.chart import build_chart
chart = build_chart(year, month, day, hour, lon, lat)
# 返回 22 个顶层字段，AI 论命的标准原料
```

**必查字段**（每次论命必看）：
- `bodies` + `dignities` + `mansions`
- `eight_char`
- `star_signs`
- `daxian` + `current_daxian` + `daxian_stars`
- `rules`（matched 格局）
- `now_data`（流年）

---

## 8 个业务工作流入口 SOP（AI 提示模板）

### 入口 1 · 命主档案管理
**提示模板**：
1. 录入 subject（含 time_uncertainty）。
2. 记录 life_event（结婚/升迁/疾病等）。
3. 关联 chart / rectification / daxian。

### 入口 2 · 排盘（定盘）
**提示模板**：
```python
chart = build_chart(...)
# 验证：命宫、身宫、四柱干支、昼夜
```

### 入口 3 · 出生时间矫正
**提示模板**：
- 先用近似时间生成 chart。
- 收集 life_event。
- AI 判断事件对应星象。
- 调用 `rectify_multi_point()`（待实现）。

### 入口 4 · 格局分析
**提示模板**：
- 查看 `chart['rules']['matched']`
- 结合 `dignities` 判断成破。
- 优先级 `[level.rank.sub]` 越小越重要。

### 入口 5 · 洞微大限推演
**提示模板**：
```python
from qizheng import analysis
for i in range(12):
    res = analysis.analyze_daxian_limit(chart, i)
    # AI 逐限判断
```

### 入口 6 · 流年推演
**提示模板**：
```python
res = analysis.analyze_liunian(chart, age)
```

### 入口 7 · 综合判读
**AI 智能层 checklist**：
- 身命二主强弱
- 四正宫吉凶
- 五行生克
- 神煞叠加
- 格局成破
- 大限/流年叠加

### 入口 8 · 主数据维护
- 规则库扩展需遵循“先搜索” + 验证零异常。

## 已知陷阱（必须避免）

- 节气分年月 vs 农历分年月（calc_four_poles use_solar_terms=True）
- 早子时（23时后不跨日）
- 紫炁线性运动（非 MEAN_APOG）
- 罗睺 true_as_north 开关

**本手册将持续更新**。每次实战后把新发现的坑补充进来。
