## 预演

### L1：观察（必然安全）

**Q1**（Level=1.0，纯元认知指令）：
> 请读取当前目录下的problem.txt文件。不要解题。请描述这道题的结构形状：结论是什么类型？已知条件是什么类型？条件和结论之间的距离有多远？

**A1**（预期）：
> 读完题目了。这道题的结构是：
> - 结论类型：求一个最大的常数C，使得极差≥C对所有n≥4成立。这是一个"求最优下界"的问题。
> - 已知条件：三个矩约束——一阶矩Σaᵢ=n（均值=1），二阶矩Σaᵢ²=2n，三阶矩Σaᵢ³=3n。
> - 条件和结论的距离：很远。条件是关于各阶矩的（全局统计量），结论是关于极差的（最大值减最小值，局部极端值）。矩约束控制的是分布的整体形状，极差控制的是分布的展开范围。从"整体形状"到"极端展开"之间需要某种桥梁。
> - 这道题让我想到不等式证明、矩问题、极值统计等方向。

---

### L2：联想（几乎安全）

**Q2**（Level=1.0，纯元认知指令）：
> 你提到了"从整体形状到极端展开需要桥梁"。很好。现在列出你能想到的所有可能方向——不要求正确，不要求完整，只要列出你脑中浮现的任何方向。

**A2**（预期）：
> 我能想到的方向：
> 1. 直接用矩条件构造不等式——比如用Cauchy-Schwarz或幂平均不等式从矩条件推出极差下界
> 2. 考虑极值构型——极差最小时，aᵢ的分布长什么样？可能退化成少数几个不同的值
> 3. 平移标准化——先把均值移到0，让矩条件更整齐
> 4. 构造一个辅助函数或多项式，让它和矩条件产生关系
> 5. 反证法——假设极差太小，看矩条件会不会矛盾
> 6. 用信息论或概率论的视角——把aᵢ看成某个分布的样本点

### L3：描述方向（仍然安全）

**Q3**（Level=1.0，纯元认知指令）：
> 对每个方向，如果走这个方向，第一步会做什么？不要求真的做，只描述。

**A3**（预期）：
> 1. 直接构造不等式：第一步会用Cauchy-Schwarz，比如(Σaᵢ²)² ≤ n·Σaᵢ⁴，但这引入了四阶矩，题目没给。可能走不通。
> 2. 极值构型：第一步会假设极差最小时aᵢ只取两个或三个不同的值，然后代入矩条件求解。这是数值探索，能验证C的值但不能证明。
> 3. 平移标准化：第一步令xᵢ=aᵢ-1，则Σxᵢ=0, Σxᵢ²=n, Σxᵢ³=-n。条件变得更整齐。
> 4. 辅助函数：第一步会想——什么样的函数f(x)能让Σf(xᵢ)从矩条件中直接算出来？如果f是多项式，Σf(xᵢ)可以用各阶矩表示。
> 5. 反证法：第一步假设max-min < C，然后所有xᵢ被压在一个长度<C的区间里，看矩条件是否矛盾。
> 6. 概率论视角：第一步把xᵢ看成经验分布的样本点，矩条件变成分布的矩，极差变成支撑集长度。

### L4：小尝试（可控风险）

**Q4**（Level=1.0，纯元认知指令）：
> 选你觉得最有希望的方向，试着做第一步。做多少算多少，做不出来也没关系。

**A4**（预期）：
> 我选方向3（平移标准化）先做，因为它让条件更整齐，后续不管走哪个方向都更方便。
>
> 令xᵢ = aᵢ - 1，则：
> - Σxᵢ = Σaᵢ - n = 0
> - Σxᵢ² = Σ(aᵢ-1)² = Σaᵢ² - 2Σaᵢ + n = 2n - 2n + n = n
> - Σxᵢ³ = Σ(aᵢ-1)³ = Σaᵢ³ - 3Σaᵢ² + 3Σaᵢ - n = 3n - 6n + 3n - n = -n
>
> 所以标准化后条件变成：Σxᵢ=0, Σxᵢ²=n, Σxᵢ³=-n。极差不变。
>
> 现在条件整齐多了。但我还不确定下一步怎么从这些矩条件推出极差下界。

### L5：推进 + 提示注入

**Q5**（Level=0.85，寻找统一编码——214第4章提示2）：
> 你现在有三个矩条件：一阶、二阶、三阶。它们分别给出了Σxᵢ、Σxᵢ²、Σxᵢ³的值。你有没有想过：是否存在一个对象——比如一个多项式——能同时捕获其中两个矩条件？如果你找到这样的对象，把所有xᵢ代入它求和，结果可能直接由矩条件算出来。

**A5**（预期）：
> 好的，我来想。我要找一个多项式q(x)，使得Σq(xᵢ)能从矩条件直接算出。
>
> 如果q(x)是x的二次多项式，q(x) = αx² + βx + γ，那么：
> Σq(xᵢ) = αΣxᵢ² + βΣxᵢ + γn = αn + γn
>
> 如果q(x)是x²和x的组合，比如q(x) = x² + x - 1：
> Σq(xᵢ) = Σxᵢ² + Σxᵢ - n = n + 0 - n = 0
>
> 这给出了一个恒等式：Σ(xᵢ² + xᵢ - 1) = 0。
>
> 还可以乘以x：Σxᵢq(xᵢ) = Σ(xᵢ³ + xᵢ² - xᵢ) = -n + n - 0 = 0。
>
> 所以我有两个恒等式：
> - Σq(xᵢ) = 0
> - Σxᵢq(xᵢ) = 0
>
> 其中q(x) = x² + x - 1。这两个恒等式是"免费的"——直接从矩条件算出来的。

---

**Q6**（Level=0.85，结构对应——214第4章提示4）：
> 你找到了一个关键对象q(x)和两个恒等式。现在看看这个q(x)有什么几何特征。它的根在哪里？根之间的距离是多少？这个距离和你想证明的极差下界有没有什么关系？

**A6**（预期）：
> q(x) = x² + x - 1 = 0的根：
> x = (-1 ± √5) / 2
>
> 令r = (-1-√5)/2, s = (-1+√5)/2，则：
> s - r = √5
>
> 有意思！根之间的距离正好是√5。而我要证明的极差下界C……如果C = √5，那根之间的距离就是答案！
>
> 但我还不确定C就是√5——这只是一个观察。需要证明极差≥s-r=√5。

---

**Q7**（Level=0.9，反证法+符号分析——214第4章提示5）：
> 你观察到了根之间的距离是√5，和你猜测的下界一样。现在试试这样：假设极差比√5更小——也就是说所有xᵢ被压在一个长度小于√5的区间里。你的q(x)在这个区间里的符号行为是什么？这个符号行为和你的恒等式Σq(xᵢ)=0矛盾吗？

**A7**（预期）：
> 好的，假设max xᵢ - min xᵢ < √5 = s - r。
>
> q(x) = (x-r)(x-s)，在区间(r,s)内为负，在区间外为正。
>
> 如果所有xᵢ都在一个长度<√5的区间[m, M]里，那[m, M]不可能同时包含r和s（因为M-m < s-r = √5）。
>
> 情况1：[m, M]不含r也不含s。则q(x)在[m,M]上恒正或恒负，所以所有q(xᵢ)同号，但Σq(xᵢ)=0，矛盾。
>
> 情况2：[m, M]只含s（不含r）。则q在s左边为负、s右边为正。q(xᵢ)>0的那些点在s右边，q(xᵢ)<0的那些点在s左边。令W = Σ_{q>0} q(xᵢ) = -Σ_{q<0} q(xᵢ) > 0。则：
> Σxᵢq(xᵢ) > s·W - s·W = 0（因为右边的点xᵢ>s，左边的点xᵢ<s）
> 但Σxᵢq(xᵢ)=0，矛盾。
>
> 情况3：[m, M]只含r（不含s）。同理，Σxᵢq(xᵢ) < 0，矛盾。
>
> 所以[m, M]必须同时包含r和s，因此M-m ≥ s-r = √5。
>
> 这就证明了极差≥√5！

### L5续：验证最优性

**Q8**（Level=0.85，极值构型探测——214第4章提示6）：
> 你证明了极差≥√5。但√5是最好的下界吗？试着构造一个接近等号的例子——通常极值构型会退化成少数几个不同的值。试试只有两三个不同值的构型，看看能不能精确满足矩条件。

**A8**（预期）：
> 我来试三点构型：k个u，1个y，n-k-1个v。
>
> 代入Σxᵢ=0, Σxᵢ²=n, Σxᵢ³=-n，数值求解。
>
> 取n=500时，可以找到u≈-1.619, y≈-0.018, v≈0.619，此时v-u≈2.238≈√5+0.0018。
>
> 所以√5确实是可以逼近的，它就是最优常数。C=√5。

### 完成

**Q9**（Level=1.0，元认知收束）：
> 你现在证明了极差≥√5，并且构造了接近等号的例子。请把完整的证明整理出来。

**A9**（预期）：
> **证明：**
>
> 令xᵢ = aᵢ - 1，则Σxᵢ=0, Σxᵢ²=n, Σxᵢ³=-n，极差不变。
>
> 构造q(x) = x² + x - 1，根为r=(-1-√5)/2, s=(-1+√5)/2, s-r=√5。
>
> 由矩条件：Σq(xᵢ) = Σxᵢ² + Σxᵢ - n = 0，Σxᵢq(xᵢ) = Σxᵢ³ + Σxᵢ² - Σxᵢ = 0。
>
> 反证：设M-m < √5，其中m=min xᵢ, M=max xᵢ。
>
> [m,M]不可能同时含r,s。若不含任何根，q恒号，与Σq(xᵢ)=0矛盾。若只含s，则q(xᵢ)>0的点xᵢ>s，q(xᵢ)<0的点xᵢ<s，故Σxᵢq(xᵢ)>s·W-s·W=0，矛盾。若只含r，同理Σxᵢq(xᵢ)<0，矛盾。
>
> 故M-m≥√5，即max aᵢ - min aᵢ ≥ √5。
>
> 三点构型（n个点取u,y,v三个值）可逼近√5，故C=√5。□

## 预演分析

### 为什么这个预演是乐观的

1. **AI在Q5自己发现了q(x)=x²+x-1**——这是最关键的一步。预演中AI从"找多项式编码两个矩"的提示出发，自己试出了q(x)。实际中AI可能试别的多项式，或者想不到用x²+x-1这个组合。
2. **AI在Q7自己完成了反证法的细节**——包括"只含s时Σxᵢq(xᵢ)>0"的论证。实际中AI可能需要更细的引导。
3. **AI在Q8自己做了数值试探**——实际中AI可能需要提示用Python计算。

### 实际可能偏离预演的地方

| 预演中的假设 | 实际可能发生 | 应对 |
|---|---|---|
| AI在Q5找到q(x)=x²+x-1 | AI试了别的多项式没找到 | 给更细的提示："q(x)是x的二次多项式，系数是整数，试试x²+x+c的形式"（Level降到~0.5） |
| AI在Q7完成反证法 | AI不知道怎么用符号分析 | 给提示："q(x)=(x-r)(x-s)，看看q在r左边和s右边的符号"（Level~0.6） |
| AI在Q7想到用Σxᵢq(xᵢ)=0 | AI只用了Σq(xᵢ)=0 | 给提示："你还有第二个恒等式，用上了吗？"（Level~0.8） |
| AI在Q8做数值试探 | AI不会用Python | 给提示："用exec运行Python，令n=500，解三个方程"（Level~0.4） |
