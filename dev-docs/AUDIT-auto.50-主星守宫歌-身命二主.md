## 原始文本内容

从《星平会海》卷一·主星守宫歌中提取的"身命二主"部分（卷一.txt 行352-362）：

### 身命二主歌诀

> 内外二苔君且听，命主入身身入命。 纵教生煞会凶星，富贵荣华天赋定。 身命主宫坐田宅，千仑万箱无破克。 田宅之主入命来，管取珍珠多蓄积。 身命主宫守子孙，母乃附子岂无恩。 子主若还回顾母，官高禄厚世推尊。 身命主，入奴仆，纵是吉星也劳碌。
>
> 身心放下作闲人，犹忌小人生反覆。
>
> 身命主，入妻宫，妻财昌盛貌雍容。 妻主若还来入命，定招外舍横财通。 身命主，入八煞，财禄少年当早发。 若还煞星来入命，疾厄缠身难解脱。 身命主，入迁移，过房出祖定无疑。 若不赘居并入舍，也须偏产庶生儿。

### 注释文本

> 身命二主，星家之录要，如在强宫，主福无疑矣。 奴仆之宫，非贫则贱。疾厄之宫，非为恶弱命，主膺之，亦主显寄。

### 上下文定位

"身命二主"是主星守宫歌的第一个子节，也是篇幅最长、规则最丰富的子节。后续子节（财田主、兄弟主、官禄主、福德主、相貌主、元守主）均为本节的细化展开。

## 形式化分析

### 1. 形式化五问

本节包含多条规则，逐条分析：

#### 规则1: 命主入身 + 身主入命（互垣）→ 富贵荣华

- **算子**: 入（entering/入驻）、互垣（mutual palace exchange）
- **输入**: 命主星 + 身宫；身主星 + 命宫
- **输出**: 吉利 - 富贵荣华天赋定（即使会凶星也无妨）
- **可求值性**: 是 - 给定星盘，检查命主星所在宫位=身宫 AND 身主星所在宫位=命宫
- **一致性**: 与《果老星宗》"身命同守官福乃為上客"一致；互垣=双向守宫，是最强格局

#### 规则2: 身命主入田宅 → 千仑万箱

- **算子**: 守/坐（guarding/sitting）
- **输入**: 身命二主 + 田宅宫
- **输出**: 吉利 - 千仑万箱无破克（巨额财富）
- **可求值性**: 是 - 检查身命二主是否在田宅宫
- **一致性**: 与《果老星宗》"田宅宫别有吉星临照，亦能自创立"一致

#### 规则3: 田宅主入命 → 珍珠多蓄积

- **算子**: 入（entering）
- **输入**: 田宅宫主星 + 命宫
- **输出**: 吉利 - 珍珠多蓄积（财富积累）
- **可求值性**: 是 - 检查田宅宫主星是否在命宫
- **一致性**: 与互垣逻辑一致——宫主入命=逆向守宫

#### 规则4: 身命主入子孙 + 子主回顾母 → 官高禄厚

- **算子**: 守（guarding）+ 回顾（looking back/三方照）
- **输入**: 身命二主 + 子女宫；子女宫主星 + 命宫（回顾）
- **输出**: 吉利 - 官高禄厚世推尊
- **可求值性**: 是 - 检查身命二主在子女宫 AND 子女宫主星三方照命宫
- **一致性**: "母乃附子"比喻母子宫主互动，与互垣逻辑一致

#### 规则5: 身命主入奴仆 → 劳碌

- **算子**: 入（entering）
- **输入**: 身命二主 + 奴仆宫
- **输出**: 凶 - 纵是吉星也劳碌（即使吉星入奴仆也劳碌）
- **可求值性**: 是 - 检查身命二主是否在奴仆宫
- **一致性**: 与注释"奴仆之宫，非贫则贱"一致；奴仆宫为弱宫，主星入弱宫为凶

#### 规则6: 身命主入妻宫 → 妻财昌盛

- **算子**: 入（entering）
- **输入**: 身命二主 + 妻妾宫
- **输出**: 吉利 - 妻财昌盛貌雍容
- **可求值性**: 是
- **一致性**: 妻妾宫为次强宫，主星入之为吉

#### 规则7: 妻主入命 → 外舍横财

- **算子**: 入（entering）
- **输入**: 妻妾宫主星 + 命宫
- **输出**: 吉利 - 定招外舍横财通
- **可求值性**: 是
- **一致性**: 互垣逻辑——妻主入命=逆向守宫

#### 规则8: 身命主入八煞（疾厄）→ 财禄早发

- **算子**: 入（entering）
- **输入**: 身命二主 + 疾厄宫（八煞）
- **输出**: 吉凶参半 - 财禄少年当早发（吉），但若煞星入命则疾厄缠身（凶）
- **可求值性**: 是 - 需要双条件判断
- **一致性**: 与注释"疾厄之宫，非为恶弱命，主膺之，亦主显寄"一致——疾厄宫虽弱，但主星入之反主显达

#### 规则9: 身命主入迁移 → 过房出祖

- **算子**: 入（entering）
- **输入**: 身命二主 + 迁移宫
- **输出**: 凶/变 - 过房出祖定无疑，或赘居入舍，或偏产庶生
- **可求值性**: 是
- **一致性**: 与《果老星宗》"身守遷移，主居六三，過房之命"（卷四 行21）完全一致

## 发现总结

### 新维度发现

1. **算子维度**: 确认"入"（entering）和"互垣"（mutual palace exchange）是主星守宫体系的核心算子
   - "入"=单向守宫（主星入他宫）
   - "互垣"=双向守宫（命主入身+身主入命）
   - "回顾"=三方照（子主回顾母=子主三方照命宫）
2. **集合维度**: 身命二主×8宫位的守宫规则矩阵（9条规则覆盖6个宫位）
3. **命题维度**: 主星守宫命题（主星+宫位→吉凶），含条件命题（疾厄宫的双条件判定）
4. **状态维度**: 吉凶状态分级——吉（富贵荣华/千仑万箱/妻财昌盛）、凶（劳碌/疾厄缠身）、变（过房出祖/偏产庶生）
5. **层级维度**: 互垣 > 单向守宫 > 回顾照——互垣是最强格局

### 成熟度提升

- **覆盖率**: 本节是主星守宫歌中规则最密集的子节（9条规则），建立了完整的"主星×宫位"判断框架
