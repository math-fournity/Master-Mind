## 1. 题海战术的总思路

用户要求：系统化搜索数学各门类能够下载下来的大型题库（题海），用于批量测试裸AI的数学能力边界。

**筛选标准**：
1. **题量大**（500题以上）
2. **有解答**（可校验）
3. **可下载**（PDF/电子版可获得）
4. **覆盖数学各门类**

**v1更新**：v0只覆盖了纸质书的PDF扫描版（笹部系列、吉米多维奇、Springer Problem Books等）。v1新增了2026年最新发布的**纯电子化、AI训练级**超大规模题库——这些题库原本就是为训练/评测大模型数学推理能力而建，数据格式干净（JSON/Parquet/LaTeX），不需要OCR，直接可用。

## 2C. 纸质来源 vs 纯电子化来源对比

| 维度 | 纸质来源（§2） | 纯电子化来源（§2A） |
|------|----------------|---------------------|
| 总题量 | ~35,000-40,000 | ~1100万+ |
| 数据格式 | PDF扫描（需OCR） | JSON/Parquet/LaTeX（直接可用） |
| 解答质量 | 专家撰写 | 专家撰写 + CoT格式 + Lean 4验证 |
| AI训练数据风险 | 低-中（题量大） | 中-高（AI研究社区已知） |
| 获取速度 | 慢（OCR瓶颈） | 快（直接下载） |
| 领域覆盖 | 初等数学全领域 | 竞赛数学+K12+论坛+研究级代数 |
| 形式化验证 | 无 | 有（compfiles + FATE Lean 4） |
| 抗污染 | 高（日文/中文老书） | 低-中（公开数据集） |
| 多模态 | 无 | 有（We-Math 2.0 + InfiMM-WebMath） |
| 中文来源 | 笹部系列（日文） | Math23K + NuminaMath cn_contest + InfiMM中英 |

**结论**：两类来源互补。纸质来源（笹部/吉米多维奇）适合**抗污染测试**（AI没见过的题），纯电子化来源适合**大规模快速测试**（数据干净，直接可用）。中国高校开源数据集（F10-F17）填补了纸质来源在多模态、形式化验证、中文应用题方面的空白。

## 6. 题海战术执行方案（v1更新）

### 6.1 分层测试策略

```
第一层：抗污染测试（纸质来源 · AI没见过的题）
  → 笹部系列15000题 + 吉米多维奇5000题
  → 定位AI在"没见过的题"上的真实能力
  → 数据格式：PDF需OCR，但抗污染价值最高

第二层：大规模快速测试（电子化来源 · 数据干净）
  → MathNet 30K竞赛题 + NuminaMath 11万证明题
  → 定位AI在竞赛数学各领域的能力分布
  → 数据格式：JSON/Parquet，直接可用

第三层：抗污染+时间戳验证（AoPS-Instruct）
  → LiveAoPSBench按时间戳分割
  → 检测AI是否因预训练暴露而"假会"
  → 旧题vs新题对比，定位真实推理能力

第四层：研究级（丘成桐+Berkeley+arXiv+Ramanujan+ConjectureBench）
  → 定位AI在研究级问题上的能力边界
  → ConjectureBench测试猜想提出能力

第五层：竞赛最难题（CMO/JMO/KMO/IMO P6）
  → 定位AI在顶尖竞赛题上的能力边界
  → compfiles提供Lean 4形式化验证
```

### 6.2 执行流程

```
Phase 1: 下载（当前进行中）
  → 纯电子化来源：HuggingFace + GitHub（快速，数据干净）
  → 纸质来源：Internet Archive + Z-Library（较慢，需OCR）

Phase 2: 数据预处理
  → 电子化来源：直接加载（JSON/Parquet）
  → 纸质来源：OCR提取题目为结构化格式
  → 按难度分级筛选（基础计算题跳过，重点选证明题/构造题）

Phase 3: Baseline测试
  → 5个sub agent并行测试，不许联网
  → 每题3次运行
  → 校验（SymPy数值验证 + 对比标准答案 + Lean 4形式化验证）

Phase 4: 分析
  → 记录"解不出来"的题目 → 按门类/难度/来源分类
  → 生成"AI能力边界图谱"——哪个门类/哪个难度级别开始做不出来
  → 对比纸质来源vs电子化来源的通过率（抗污染效果验证）

Phase 5: 进入系统引导实验池
  → 从"解不出来"的题中筛选适合引导的题
  → 用数学大师系统引导AI解题
  → 验证系统引导的增益效果
```

### 8.3 数据集schema（v2 · 9类字段）

每条记录包含以下9类字段：

```
1. 标识字段
   _key:           ArangoDB主键
   repo_id:        HF/GitHub仓库ID
   platform:       huggingface | github | web | internet_archive | z_library | springer
   title:          数据集名称
   doc_id:         212号文档编号（E1/F1等）

2. 价值描述字段（核心）
   description:    数据集是什么——完整描述
   unique_value:   独特价值——为什么这个数据集重要
   notes:          其他备注

3. 内容属性字段
   problem_count:      题量
   data_size:          数据大小
   format:             数据格式 [parquet, jsonl, pdf, lean, tex, ...]
   source_type:        来源类型 [competition, k12, research, synthetic, multimodal, formal, textbook]
   math_domain:        数学门类 [analysis, algebra, geometry, number_theory, ...]
   difficulty_level:   难度级别 [elementary, undergraduate, graduate, research, competition]
   has_solutions:      是否有解答
   solution_format:    解答格式 [answer_only, cot, proof, lean_code, detailed, process_reward, code]
   year_range:         覆盖年份范围

4. 来源归属字段
   institution:    发布机构
   publisher:      出版方
   language:       语言列表
   country:        国家

5. HF/GitHub元数据字段
   downloads:          HF下载量
   likes:              HF点赞数
   tags:               HF标签列表
   task_categories:    任务类型
   size_categories:    大小分类
   license:            许可证
   last_modified:      最后修改时间
   created_at:         创建时间
   tier:               按下载量分级 1|2|3|4|0

6. 获取字段
   url:                直达链接
   access_method:      获取方式 [direct, login, crawler, purchase, api]
   access_difficulty:  获取难度 [low, medium, high]

7. 下载状态字段
   download_status:    [not_started, in_progress, completed, blocked, skipped]
   download_date:      下载完成日期
   local_path:         本地存放路径
   local_size:         本地文件大小
   file_count:         文件数量
   download_notes:     下载备注

8. 项目相关性字段
   priority:           下载优先级 [1, 2, 3, 4]
   test_layer:         测试层级 [1, 2, 3, 4, 5]（对应§6.1分层测试策略）
   anti_contamination: 是否适合抗污染测试
   ai_baseline_score:  AI基准得分（如有）

9. 入库管理字段
   ingest_source:  入库来源 [hf_api, doc_212+user_list, hf_api+curated]
   ingest_date:    入库日期
   last_updated:   最后更新时间
```

### 8.6 查询示例

```python
from arango import ArangoClient
client = ArangoClient(hosts='http://localhost:8529')
db = client.db('xishujuzhen_math_glm52', username='root', password='REDACTED-DB-PASSWORD')

# 查询已下载完成的数据集
result = db.aql.execute('FOR d IN math_datasets FILTER d.download_status == "completed" RETURN {title: d.title, path: d.local_path, size: d.local_size}')

# 查询有详细描述的Tier 1数据集
result = db.aql.execute('FOR d IN math_datasets FILTER d.tier == 1 AND LENGTH(d.description) > 50 SORT d.downloads DESC RETURN {repo_id: d.repo_id, desc: d.description, downloads: d.downloads}')

# 查询所有形式化数学数据集
result = db.aql.execute('FOR d IN math_datasets FILTER "formal" IN d.source_type RETURN {title: d.title, desc: d.description, url: d.url}')

# 查询所有竞赛题库按题量排序
result = db.aql.execute('FOR d IN math_datasets FILTER "competition" IN d.source_type AND d.problem_count != null SORT d.problem_count DESC RETURN {title: d.title, count: d.problem_count}')

# 查询适合抗污染测试的数据集
result = db.aql.execute('FOR d IN math_datasets FILTER d.anti_contamination == true RETURN {title: d.title, desc: d.description}')
```
