## 2. 方案

### 步骤 1：恢复认知图（从 JSON 导入到 ArangoDB）

**做什么**：运行已有的 `cognition_import_math.py`（merge/upsert 模式），把 JSON 中的 35 个单元、51 条边、29 条版本导入 ArangoDB。

**命令**：
```bash
cd /data/master-mind-glm5.2-grove
source .env
.venv/bin/python3 xishujuzhen/cognition_import_math.py
```

**预期结果**：ArangoDB 从 0/0/0 变为 35/51/29+（补充 v1 后版本数更多）。

**风险**：低。脚本已是 merge 模式，不会 truncate。JSON 是确定的源数据。

**验证**：
- 导入后检查 ArangoDB 计数
- 运行 `cognition_audit_math.py all` 做全量审计
- 运行 SessionStart hook 确认显示非零计数

### 步骤 2：导出验证（ArangoDB → JSON 双向同步）

**做什么**：运行 `cognition_export_math.py --dry-run`，确认 ArangoDB 和 JSON 一致。

**命令**：
```bash
.venv/bin/python3 xishujuzhen/cognition_export_math.py --dry-run
```

**预期结果**：显示 ArangoDB 和 JSON 一致，无差异。

### 步骤 3：配置 arangodump 定期备份

**做什么**：ArangoDB 跑在 Docker 容器 `arangodb` 中，`arangodump` 在容器内。通过 `docker exec` 执行备份，用 cron 定时运行。

**备份策略**：
- 备份命令：`docker exec arangodb arangodump --server.endpoint tcp://127.0.0.1:8529 --server.database xishujuzhen_math_glm52 --server.username root --server.password REDACTED-DB-PASSWORD --output-directory /tmp/backup`
- 备份后从容器复制到宿主机：`docker cp arangodb:/tmp/backup /data/master-mind/backups/arango/$(date +%Y%m%d)`
- cron 任务：每天凌晨 3 点执行
- 保留策略：保留最近 7 天

**实现方式**：
1. 写一个 `scripts/backup_arango.sh` 脚本，封装上述命令
2. 设置 cron 定时任务

**风险**：低。备份是只读操作，不影响 ArangoDB 运行。

### 步骤 4：更新 AGENTS.md TODO 列表

**做什么**：把 4 项数据丢失修复 TODO 中已完成的 3 项标记为 `[x]`，未完成的 1 项指向步骤 3。
