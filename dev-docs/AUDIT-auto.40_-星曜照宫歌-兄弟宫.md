## 定量化思考

### 1. 兄弟数量推断模型

本段首次出现**星曜→兄弟数量**的映射：
- 土星 → 五人（土之数五，河图数）

释云还提到"空陷，主无多"——空亡/陷地时数量减少。

**量化方案**：
```
兄弟数量 = base_count(星曜) × modifier(庙旺平陷状态)
- 土星 base = 5（河图土数）
- 庙旺 → ×1.0 或更高
- 平 → ×0.6-0.8
- 陷/空亡 → ×0.2-0.4（"无多"）
```

这与命宫/财帛宫中的"庙旺平陷"系统形成统一——**庙旺平陷不仅是星曜状态，还是数量/程度的乘数**。

### 2. 分散度量化

月孛规则中"三人三路去，四人亦作四方行"暗示：
```
分散度 = 兄弟数量 / 聚集度
聚集度 = f(吉星数量, 庙旺状态)
```

凶星（月孛/罗喉/计都）使聚集度→0，分散度→最大值。

### 3. 吉凶能量等级

11条规则的吉凶分布：
| 等级 | 星曜 | 判定 |
|---|---|---|
| 吉（有条件） | 木星 | 吉星遇则宜，恶曜随则断 |
| 吉（有条件） | 太阴 | 太阳同值则福 |
| 凶（表面吉） | 金星 | 表面有情实则不亲 |
| 凶 | 太阳 | 陷→分居 |
| 凶 | 水星 | 不宜，无义侵欺 |
| 凶 | 火星 | 争竞反目 |
| 凶 | 土星 | 五人但聚少离多 |
| 凶 | 紫炁 | 孤星两分离 |
| 凶 | 月孛 | 各奔四方 |
| 凶 | 罗喉 | 悖逆恩义休 |
| 凶 | 计都 | 参商各自居 |

**发现**：兄弟宫是一个**以凶为主**的宫位——11星中9星为凶或条件凶，仅木星（有吉星条件下）和太阴（有太阳条件下）可为吉。这反映了七政四余对兄弟宫的基本定位：**兄弟宫本质是"分离宫"**。

## 开放性思考

### 新算子发现：陷

规则6中太阳照兄弟宫用"陷"而非"照/临"——"岂使三宫陷太阳"。这不是普通的星曜落宫，而是带有**状态判定**的算子：

- **照/临**：中性描述，星曜在某宫位
- **陷**：负面状态，星曜在某宫位且处于失地/落陷状态

**"陷"算子的形式化**：
- 输入：(星曜, 宫位)
- 输出：布尔值——该星曜在该宫位是否为陷地
- 依赖：需要星曜×宫位的庙旺平陷表

这与 `qizheng/core.py` 中已实现的 `calc_dignity()` / `calc_dignity_from_lon()` 相关——但当前庙旺平陷表是按**地支/宿度**组织的，不是按**宫位**组织的。**"陷"算子需要建立星曜×宫位的庙旺关系表**，这是一个待发现的新维度。

### 新概念发现：星曜属性是宫位条件的函数

紫炁在命宫主清孤修仙，在田宅宫主福荫双亲，在兄弟宫主两分离——**同一星曜在不同宫位展现完全不同的面向**。

这意味着形式系统中，星曜属性不能是常量，而必须是**宫位的函数**：
```
星曜效果(星曜X, 宫位Y) = f(X的性质, Y的性质, X×Y的交互)
```

这与量子力学中的"观测者效应"有同构性——粒子的表现取决于它所处的势场。星曜的"吉凶"不是绝对的，而是星曜与宫位交互的结果。

### 新概念发现：孤星

紫炁被称为"孤星"——这不是一个通用的算子，而是紫炁的特有属性。孤星在兄弟宫的效应是"两分离"。

**待发现**：是否还有其他"孤星"？孤星属性是否可以量化？孤星在哪些宫位表现为孤？

## 全息思考

### 1. 兄弟宫 = 闲极宫的跨体系对应

### 2. "参商"典故的天文-命理同构

计都照兄弟宫用"参商"比喻——参星（猎户座）与商星（天蝎座）在天球上相距约180°，此出彼没永不相见。这是**天文现象→命理隐喻**的直接映射。

在八字中，"比劫逢冲"（比肩/劫财被冲克）表达同样的兄弟分离含义。**底层模式**：两个本应同类的元素（兄弟/比劫）因对立力量（参商/冲克）而分离。

### 3. 吉凶条件修饰的跨体系同构

木星照兄弟宫的"吉星遇着甚相宜，只恐中间恶曜随"——基础判定+条件修饰的模式，在八字中表现为：
- 基础：比肩（吉）→ 兄弟互助
- 修饰：比肩逢七杀（凶）→ 兄弟反目

**底层模式**：基础格局 + 条件修饰 = 最终判定。这是跨体系通用的命理推理结构。

## 时代性思考

### 1. "兄弟数量"在现代社会的兑现

土星照兄弟宫主"五人同"——在古代，五子同堂是常见现象。在现代社会（计划生育、少子化），兄弟数量大幅减少。

**时代性修正**：
- 古代：土星照兄弟宫 → 兄弟五人
- 现代：土星照兄弟宫 → 兄弟关系的质量判定（而非数量），或映射为"社交圈中同辈关系"
- 能量单位不变（土之数五=稳定、厚重的关系），但兑现方式从"血缘兄弟数量"变为"同辈关系的稳定性"

### 2. "异姓兄弟"的时代演变

土星照兄弟宫"恐招异姓为兄弟"——古代指结拜兄弟、异母兄弟。现代可映射为：
- 合作伙伴关系
- 义兄弟/结拜关系
- 非血缘的同辈亲密关系

**星象是条件不是宿命**：土星照兄弟宫的"异姓兄弟"在古代可能是被迫（如过继），在现代可以是主动选择（如合伙人）。

### 3. "南北分居"的当代解读

太阴照兄弟宫"南北分居难并屋"——古代指兄弟分家后各居一方。在现代，这几乎是常态（城市化导致核心家庭化）。

**时代性修正**：古代"南北分居"是凶象（兄弟疏离），现代"分居"是中性（社会常态）。星象的能量单位（分离力）不变，但"分离"的吉凶判定需要随时代调整。

## SOP 汇报三要素

### 维度汇报

**新算子发现**：
1. **陷**（规则6）：不是普通"照/临"，而是带有状态判定的算子——星曜在某宫位且处于落陷状态。输入=(星曜,宫位)，输出=布尔值。需要建立星曜×宫位的庙旺关系表。
2. **孤星**（规则8）：紫炁的特有属性标签，在兄弟宫表现为"两分离"。这不是通用算子，而是星曜特有属性。

**新维度发现**：
1. **星曜→兄弟数量映射维度**：土星→五人（河图土数）。这是首次出现星曜与兄弟数量的直接映射，需要建立完整的"星曜-数量"对照表。
2. **星曜属性=宫位函数维度**：同一星曜在不同宫位展现不同面向（紫炁在命宫/田宅/兄弟三宫表现完全不同），星曜属性不能是常量，必须是宫位的函数。
3. **分散度量化维度**：月孛规则中"三人三路、四人四方"暗示分散度与兄弟数量成正比。

**已有维度验证**：
- 算子维度：照/临/见/有/陷——5种算子变体，其中"陷"为新发现
- 集合维度：11星曜×兄弟宫=11条规则，集合完整
- 命题维度：吉凶二分+条件修饰——与命宫/财帛宫一致

### 成熟度汇报

- **覆盖率**：已提升——从只能描述"命宫/财帛宫"的星曜照宫，扩展到"兄弟宫"的11星照宫。星曜照宫歌已完成3/12宫=25%。
- **一致性**：已验证——11条规则之间无矛盾。吉星（木/月）主和，凶星（火/水/孛/罗/计）主散，与卷三"吉星入兄弟宫主和乐，凶星入宫主忿争"完全一致。与已有规则库（命宫/财帛宫）的"照"算子体系一致。
- **可求值性**：已实现——11条规则全部可求值。给定星盘实例，判定各星曜是否在第三宫 → 输出兄弟关系判定。条件修饰规则（木星需判定吉/凶星同宫，太阴需判定太阳是否同值）也可求值。

### 可计算性汇报

- **形式可计算**：已实现——11条规则的算子、输入、输出全部明确，可算法化。`qizheng/core.py` 中 `calc_all_bodies()` 可计算各星曜宫位，`calc_dignity()` 可计算庙旺状态。
- **定量可计算**：待建设——兄弟数量推断（土→5）需要建立完整的"星曜-河图数-数量"映射表。分散度量化需要建立"分散度=数量/聚集度"模型。这些在当前代码中尚未实现。
- **推演可计算**：部分实现——吉凶二分+条件修饰的推理链可形式化为决策树。但"陷"算子需要星曜×宫位的庙旺关系表，当前庙旺表是按地支/宿度组织的，需扩展为按宫位组织。
- **暂时不可计算**：星曜属性=宫位函数——同一星曜在不同宫位的不同面向，需要建立"星曜×宫位→效果"的完整映射矩阵（11星×12宫=132个条目），当前仅完成3个宫位（命/财帛/兄弟）=33个条目。
