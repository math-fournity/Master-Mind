## 4. 迁移步骤（精确到命令）

### 阶段 A：用 git filter-repo 创建带历史的新 repo

**原理**：克隆原 repo → 用 filter-repo 只保留需要的路径 → 得到只含相关历史的新 repo。

```bash
# A1. 克隆原 repo 到临时位置（bare clone，filter-repo 要求）
git clone --bare ~/master-mind-glm5.2-worktree /tmp/analysis-system-filter

# A2. 运行 filter-repo，保留需要的路径
cd /tmp/analysis-system-filter
git filter-repo \
  --path analysis-devin-failure-system/ \
  --path "AnalysisSystem开发/" \
  --path AnalysisSystemDesign.md \
  --path AnalysisSystem.md \
  --path AnalysisSystemOps.md \
  --path MonitorPipe.md \
  --path 续传规范文档.md \
  --path scripts/conversation_mapper.py \
  --path "Tell分类学研究过程文档/poc_assets/poc_2.7/poc_2.7/problem_list.json" \
  --path "Tell分类学研究过程文档/poc_assets/poc_2.7/poc_2.7/results.json" \
  --invert-paths --path analysis-devin-failure-system/output/

# 注意：filter-repo 的 --path 是"保留"语义，--invert-paths --path 是"排除"语义。
# 上面的命令：先保留所有指定路径，再排除 output/。
# 但 filter-repo 的 --path 和 --invert-paths 不能同时用。
# 正确做法：分两步，或者用 --path-glob 排除 output。

# 正确的命令（两步法）：
# 第一步：保留需要的路径
git filter-repo \
  --path analysis-devin-failure-system/ \
  --path "AnalysisSystem开发/" \
  --path AnalysisSystemDesign.md \
  --path AnalysisSystem.md \
  --path AnalysisSystemOps.md \
  --path MonitorPipe.md \
  --path 续传规范文档.md \
  --path scripts/conversation_mapper.py \
  --path "Tell分类学研究过程文档/poc_assets/poc_2.7/poc_2.7/problem_list.json" \
  --path "Tell分类学研究过程文档/poc_assets/poc_2.7/poc_2.7/results.json"

# 第二步：排除 output/（在已过滤的 repo 上再过滤）
git filter-repo --invert-paths --path analysis-devin-failure-system/output/

# A3. 把过滤后的 bare repo 转为正常 repo
cd /tmp/analysis-system-filter
git clone --no-local /tmp/analysis-system-filter ~/master-mind-analysis-system
cd ~/master-mind-analysis-system
git checkout -b main  # 或保留原分支名 glm5.2

# A4. 验证历史保留
git log --oneline | wc -l          # 应该有 79+ 个 commit
git log --oneline -- analysis-devin-failure-system/ | wc -l  # 应该有 79 个
git log --oneline -- "AnalysisSystem开发/" | wc -l           # 应该有 3 个

# A5. 清理临时 bare repo
rm -rf /tmp/analysis-system-filter

# A6. 补充 filter-repo 丢失的未跟踪文件（见§3.2措施2）
SRC=~/master-mind-glm5.2-worktree
DST=~/master-mind-analysis-system
cp "$SRC/analysis-devin-failure-system/src/solver_launcher.py" \
   "$DST/analysis-devin-failure-system/src/solver_launcher.py"
# results.json 在阶段B2中会放到 data/poc_2.7/，先cp到临时位置
cp "$SRC/Tell分类学研究过程文档/poc_assets/poc_2.7/poc_2.7/results.json" \
   "$DST/data/poc_2.7/results.json"
```
