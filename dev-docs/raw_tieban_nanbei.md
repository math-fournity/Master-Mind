## 一、总源流：邵雍「一源三派」与铁卜子整编

铁板神数体系普遍托名北宋邵雍（邵康节，1011–1077）《皇极经世》象数体系。但所有可考文献都指出：**宋至清数百年并无铁板神数确实描述，现存条文与明代宫廷御用的《皇极分经数》最为类似，真正兴起流行在清代乾隆、嘉庆年间（距今约 240 年）**。铁卜子（又称铁道人，清中叶道门隐士）对散落的邵子数诀做大规模整合、校订、增补查表体系、加入清代时宪历与官场称谓，定名《铁板神数》——「铁板」二字一解为「铁卜子版本」，一解为「铁一般准确、板上钉钉」。

传说中邵雍分三派（此为各流派自我定位的「权威谱系」叙事，非严格史料）：

| 传承对象 | 流派称谓 | 条文规模（各源说法不一，见下） | 备注 |
|---|---|---|---|
| 女儿 | 南派 / 南方派 | 约 12000 条（一说 1200 条，见争议） | 今所见坊间主流版本 |
| 儿子邵伯温 | 洛阳派 / 中州派 / 北派 | 约 6144 条（一说 1200 / 6000 余） | 即《邵子神数》《皇极天书》《蠢子数》 |
| 女婿 | 江南派 | 约 5000 条 | 被主流贬为「用假八卦滚为伪诀，不足为取」 |

另有「中州算盘数」被单独称为「袖珍式铁板神数」，封闭程度最高。

**重要核验提示（推断/待核）**：「邵雍传女/子/婿分三派」本质是后世各支派**建构师承权威**的祖師化叙事。邵雍现存著作（含《皇极经世》《梅花易数》）中并无今日流行铁板神数之完整条文结构，故「邵雍为祖」更接近术数界追认，而非可考史实。各派条文数量在不同来源间差异极大（如南派有「1200」与「12000」两种数字，北派有「1200/6000/6144」三种），说明数字本身也带有门派宣传性质，需以一手秘本逐条清点才能定论。

## 二、南派与北派的划分标准

南/北之分在公开文献中有两层含义，需区分：

### 2.1 按「传承地域/对象」划分（祖源叙事层）
- **南派**：传说邵雍传女。以日干支 + 时干支主算。清末民初由南流前辈自大陆传至香港，至今仍有传承（港台四大名家：董慕节、阮闲云、江哲生、林千博；董慕节 1922–2024，人称「董半仙」）。
- **北派**：传说邵雍传子邵伯温（洛阳派 / 中州派）。以月干支 + 时干支主算。地域在华北/洛阳一带，**近代几近失传**。

### 2.2 按「卦数系统」划分（算法层，来自「馥灵之钥」线上排盘站的明确说法，推断/待核其普遍适用性）
该来源把两派对应到两套不同的八卦数序：
- **北派古典 = 先天八卦数（邵雍《皇极经世》加一倍法）**：乾1 兑2 离3 震4 巽5 坎6 艮7 坤8。
- **南派 12000 条主流 = 后天八卦数（洛书轨迹）**：坎1 坤2 震3 巽4 中5 乾6 兑7 艮8 离9。

> ⚠ 注意：多数维基/百科类来源只说「南派日干支、北派月干支」，并未将先天/后天八卦数直接绑死到南北派。先天/后天之分更常见于「先后天卦取数法」这一**通用算法步骤**（同一流派内部也会先后天并用）。故「北派=先天、南派=后天」这一对应，**仅见于单一商业站点的说明，建议标注为推断/待核**，不可当作学界定论。

### 2.3 岭南派（非南北三分法中的第三元，而是南派主干）
- 现存坊间 **12000 条版本主流 = 岭南派**，源自明代《皇极分经数》。
- 现存最早完整版本为**虚白庐藏清中叶刻本（原二函十三册、十四集/十四卷）**，以及清代道光刻印本《神机妙算铁版数》（全十三卷，收于《续修四库全书》子部）。
- 即：南派 → 岭南派 12000 条，是今日实际流通的主体。

**流派归属小结（建议采用）：**
- **归南派 / 南系主干**：邵雍传女一支 → 岭南派 12000 条 → 清末传香港 → 董慕节等港台名家 → 周进谅《神机妙算铁板神数》12000 条完整版、心一堂《铁板神数》清刻足本（虚白庐藏）。
- **归北派 / 北系**：邵雍传子邵伯温 → 洛阳派/中州派 → 《邵子神数》《皇极天书》《蠢子数》（约 6144 条）。
- **江南派（传女婿，约 5000 条）**：被主流贬为「假八卦滚伪诀」，地位边缘，通常不列入正统南北二分。
- **中州算盘数**：袖珍式，最封闭，独立于上述三分。

## 三、条文体系差异

### 3.1 数量与编号范围（各源差异大，均标注待核精确性）
| 支派 | 条文数（公开说法） | 备注 |
|---|---|---|
| 南派/岭南派 | **12000 条**（主流）；个别源写「1200」疑为漏「0」 | 按 10 大内容分类、8 个章节（子集至亥集 12 集 + 干集 + 坤集） |
| 北派/洛阳派/邵子神数 | **6144 条**（国学问答源）；另有「6000 余」「1200」等异说 | 以七言句为主；大运流年条文编排简易 |
| 江南派 | 约 5000 条 | 贬为伪诀 |
| 中州算盘数 | 未详（袖珍式） | 最封闭 |

### 3.2 卷帙结构（周进谅《神机妙算铁板神数》目录可考）
该书为国内「正宗铁板神数」大师周进谅的坤集大解码巨著，收 12000 条完整版诗句，结构为：
- **第一部·干集（干）**：铁板神数起法、神数之法、阳爻起时法、阴爻起时法、神数起大运法、六亲数取法、声与音数的推法、铁板神数的运用。（即「钥匙/起例」层，含秘数钥匙表）
- **第二部·坤集（坤）**：坤集密码数、卦序之解、铁板神数完整版 → **子集、丑集、寅集、卯集、辰集、巳集、午集、未集、申集、酉集、戌集、亥集**（12 地支集，条文主体）。
- 即总数 = 干集（起例钥匙）+ 坤集（密码暗语）+ 12 地支集（约 12000 条诗文断语）。

> 「正宗铁板神数书卷应有二十卷，部分分支流派大多数用十二卷或八卷，由于部分卷帙有缺失，就算考时定刻准确，所推算的条文与正宗卷亦有相关出入。」——说明条文体系在流传中**卷帙残缺、各派所用不尽完整**，这是南/北/各支派条文「对不上」的根因之一。

### 3.3 乾集 vs 坤集 职能差异（关键）
- **乾集（干集）= 起例/钥匙层**：记载如何依出生资料「起数、化数、查条」——神数起法、八卦加则、六亲数取法、声与音数推法、以及**乾集钥匙秘表（如「纳父生肖卦为晋，卦数 900」「纳乾坤屯卦」等）**。这是算法说明书。
- **坤集 = 密码本/暗语层**：把十天干加「月」「支」配以代号数字，再依数字查命运事项。坤集是业者秘而不宣的核心——王亭之「踢爆铁板神数」即指出「密码全部在于坤集」，业者用「套话（问诊式问问题获取信息）+ 考刻分（反复校时）凑答案」。
  - 坤集中含各「宫甲流度」：乾宫甲流度（父生肖）、坤宫甲流度（母生肖）、木宫甲流度（妻）、比宫甲流度（兄弟）、艮宫甲流度（子女）、金宫甲流度（女命丈夫）、戊木甲流度（娶三妻）等。
  - 例如坤集乾宫甲流度「未」的刻分代号「辛戊壬戊 9353」→ 查条文「父命羊年生方合」；「未」对宫「丑」「辛月壬戊 9053」→「父命牛年生方合」。

**南派/北派在乾坤集上的差异（推断/待核）**：两派都依赖乾集（起例）与坤集（密码）双层结构，差异主要在**起数所用干支柱（日/时 vs 月/时）与卦数系统（后天 vs 先天）**。北派《邵子神数》条文更少、且「大运流年无需正规演算，用子平法即可断吉凶后套入条文」，故其乾集起例比南派简略。

## 四、起数 / 考刻方法差异

### 4.1 共通的底层取数（两派共享的「数字基石」）
- **太玄取数诀（杨子太玄数）**（各源一致）：
  `甲己子午九，乙庚丑未八，丙辛寅申七，丁壬卯酉六，戊癸辰戌五，巳亥单四数。`
  即天干/地支 → 数字化编码（源自河图生成数 + 音律纳甲）。
- **八卦加则例**（各源一致）：
  `爻从三十起，乾卦六为头。兑为后少女，集中一网收。变知六八止，应世两同俦。遇十当不用，玄玄妙法周。当看多寡数，及止悉因由。`
- **天干配卦诀**：`壬甲从乾数，乙癸向坤求。庚来震上立，辛在巽方留。己以离门起，戊以坎为头。丙须艮处出，丁向兑家收。`
- **起卦诀 / 考时定刻用乾坤**：`考时定刻用乾坤，干为父兮母为坤。二十四条明日月，八刻天干又一村。` `甲乙斗宫定刻分，十二生肖作用神。`

### 4.2 南派主算法（日干支 + 时干支）
- 年柱起卦考父母 / 月柱起卦考兄弟姐妹 / **日柱起卦考夫妻** / **时柱起卦考子女**（心易派/南派核心心法）。
- 主算用**日干支 + 时干支**，配**后天八卦数（洛书）**起数。
- 运用「八卦滚法」：先求根本卦与根本数序，再取根本卦第 2–4 爻为内卦、第 3–5 爻为外卦得「八卦滚第一卦」，结合出生年干支（上元/中元/下元甲子轮）用太玄数换算，除以 9 定变爻得第二卦，除以 6 定变爻得余卦，累计 **8 个卦 × 每卦 6 条文 = 18 条则数序**（福山堂/周新春易学网详述）。

### 4.3 北派主算法（月干支 + 时干支）
- 主算用**月干支 + 时干支**，配**先天八卦数（邵雍加一倍法）**起数（据馥灵之钥）。
- 《邵子神数》特征（奇真网「邵子神数随口断」详述）：
  - 六亲推算（生肖、配偶姓氏）比铁板更完备，但**大运流年完全不必正规演算**。
  - 大运条文按六十甲子分 60 种，每种仅 4 种情况（十年好运 / 十年恶运 / 前五年好後五年坏 / 前五年坏後五年好），用子平法断吉凶後套入即可。
  - 流年条文**两岁合为一条**，仅分「好/坏」两种情况（如 67–68 岁同条）。
  - 条文少（约 6144），故排列严密、可规律化记忆，「随口断」可行。
  - 有 B 开头条文（B=8，如 B2121 = (8+2)121 = 10121）。

### 4.4 考时定刻（两派共有，但刻分基准阐释有别）
- 通用：一时辰分 **8 刻**，一刻 **15 分**；共一日 12 时辰 × 8 刻 = **96 刻**（「九十六刻为纲」）。
- 考刻目的：以六亲生肖（父、母、兄弟、配偶、子女）反推真实出生刻分，因「刻分用的是卦气，并非时钟刻分」，即便出生时辰精确到秒也常错，必须当面以六亲信息校刻。
- 考刻三原则（现代实务）：①父母生肖为最高权威，优先校准；②兄弟人数含夭折/送养、不含自己；③一刻对上不代表全对，须父母+兄弟+配偶/子女三组全吻合方通过。

### 4.5 秘数加减与「步长」——±48 vs ±96（重点核验项）
公开资料明确列出的秘数系列（老神婆风水网）：
- **九九秘数（两套）**：9、18、27、36、45……
- **六十四秘数**：64
- **九十六秘数**：96
- **五十秘数**：50
- 另有「以 8000 为基数 + 出生时刻天干序数，循环 +9」的批算示例（铁板宗师）；以及「气数 + 卦数（乾集钥匙，如 900/1080）」得到条文基数，再以此基数加减秘数循环演算全部命运条文（心易派循环演算法）。

**关于 ±48 / ±96 步长（用户线索）**：
- 公开 web 摘要中**未直接出现「±48」「±96 秘数步长」的明文表述**。
- 可考的邻近事实是：①「九十六秘数 = 96」是已知秘数之一；②父母生肖考刻表中，相邻地支生肖代号约差 **50 号**（如乾宫甲流度：子 9003、丑 9053、寅 9103、卯 9153……亥 9553，即每推进一生肖 +50）；③坤集条文「初刻不中可向前推进 10 分、30 分、50 分」以找到符合生肖的条文。
- **推断/待核**：用户所说的「秘数加减步长 ±48 vs ±96」，很可能指不同支派在「考刻推进 / 条文跳跃」时使用的步长粒度差异（一说是 48 号一跳、一说是 96 号一跳，对应一日 96 刻的某种映射）。但此具体数字在本次 web 检索的公开摘要中**未能直接取证**，需查阅一手秘本（如周进谅坤集解码、心一堂清刻足本所附「秘钥密码表」、或梁湘润《铁版神数考释》）方能确认。本项列为**高优先待核**。

### 4.6 父母生肖考刻表范围（重点核验项）
- 表结构：以十二地支（子丑寅卯辰巳午未申酉戌亥）为生肖索引，每支对应「初刻」代号（如「辛月月戊」「辛月壬戊」等暗语），查得条文号即「某生肖年生方合」。
- 范围：父 = 乾宫甲流度（约 9003–9553，跨 12 生肖 × 约 50 号间隔）；母 = 坤宫甲流度（约 9655–9955 一类）。
- 校准规则：初刻不中 → 推进 10/30/50 分，或取对宫地支再查（如「未」不中查对宫「丑」）。
- **推断/待核**：上述具体编号区间取自单个公开帖文示例，非全表清点；±48/±96 步长若与「每生肖 +50 号」有关联，需一手文献确认。列为**高优先待核**。

## 五、南派与北派代表版本对照

| 维度 | 南派代表版本 | 北派代表版本 |
|---|---|---|
| 谱系 | 邵雍传女 → 岭南派 | 邵雍传子邵伯温 → 洛阳派/中州派 |
| 主算干支 | 日干支 + 时干支 | 月干支 + 时干支 |
| 卦数系统 | 后天八卦数（洛书，坎1…离9） | 先天八卦数（邵雍，乾1…坤8）〔据单一来源，待核〕 |
| 条文数 | 约 12000 条 | 约 6144 条（异说 1200/6000） |
| 最早完整本 | 虚白庐藏清中叶刻本（14 卷）；道光《神机妙算铁版数》（13 卷） | 《邵子神数》《皇极天书》《蠢子数》 |
| 现代代表文献/人物 | 周进谅《神机妙算铁板神数》（12000 条完整版）；董慕节（港）；心一堂《铁板神数》清刻足本（附秘钥密码表）；徐宇农《铁板神数大公开》 | 邵氏后人有会此术者（洛阳派正宗）；软体插件「邵子神数洛阳派」；奇真网「邵子神数随口断」 |
| 考刻/演算特征 | 须算至「分」，八卦滚 8 卦 × 6 条文 = 18 条则；大运流年需正规演算 | 大运流年**无需正规演算**，子平法断吉凶後套入；流年两岁一条 |
| 封闭程度 | 中等（有部分公开教学/软件） | 高（几近失传） |

岭南派（南派主干）12000 条始祖 = 明代《皇极分经数》（宫廷御用）。现存坊间条文多抄自清道光《神机妙算铁版数》。

## 六、其他常被提及的版本/支派定位

- **润德堂本**：公开检索中仅作为铁板神数相关刻本/抄本被提及，本次 web 摘要未获其具体卷帙与南北归属的明细。推断/待核：可能属民国石印/抄本体系之一，需查《续修四库全书》子部或心一堂丛刊书目定位。
- **皇极分经数**：明代宫廷御用，非「派」而是**南派 12000 条之祖本**，在清代已被《铁板神数》取代（《四库》书目无《皇极分经数》记录）。
- **神机妙算铁版数**：清道光刻本（13 卷），现存最早完整「神数」刻本，由《皇极分经数》修改演变而来的第一部神数，是岭南派条文主要抄录源。
- **铁卜子本**：清乾嘉铁卜子（铁道人）整编本，奠定后世各派推演根基，加入清代时宪历与官场称谓；各派皆奉为「校」之祖。
- **中州算盘数**：最封闭，「袖珍式铁板神数」，独立于南北三分。
