## 原始文本内容

从《星平会海》卷一·主星守宫歌中提取的"财田主"部分（行364-368）：

### 财田主守宫歌诀

> 财帛主，田宅主，身命二星喜相遇。
>
> 若无暗曜与刑囚，可与石崇斗豪富。 此宫破耗之地。

### 文本校勘说明

1. **"财田主"标题**：此段合并讨论财帛主与田宅主两个宫主星，与前后各段单独讨论一个宫主（兄弟主、官禄主、福德主、相貌主）的体例不同，说明财帛与田宅在命理逻辑上关系紧密，常合并论断。
2. **"此宫破耗之地"**：此注释句位置有歧义——可能指财帛宫为"破耗之地"（因财帛宫在十二宫顺序中排第二，紧邻命宫，有消耗命宫资源之象），也可能指田宅宫。从《星学大成》"天耗星与兄弟同推，此星耗财之神，故以兄弟当之，忌在田财二宫"来看，"破耗"与田财二宫均有关联。
3. **"暗曜"**：指罗睺、计都等隐曜（四余中的凶星），与日月金木水火土（七政/明曜）相对。
4. **"刑囚"**：指天刑星与天囚星。在十干变曜体系中，"变为刑者属奴仆""变为囚者属疾厄"，均为凶星。

### 对照结论

三套典籍在财帛主与田宅主的核心逻辑上高度一致：
1. 财帛主/田宅主与身命星相遇→大富
2. 无凶星（暗曜/刑囚/耗星）干扰→富可敌国
3. 有凶星干扰→破败无产

《星平会海》的独特之处在于将财帛主与田宅主**合并论断**，且使用"石崇斗豪富"的夸张比喻强调富格上限。

## 形式化分析

### 1. 形式化五问

#### 规则1: 财帛主 + 田宅主 + 身命二星相遇 → 可与石崇斗豪富

- **算子**: 喜相遇（会合/同宫/三合）
  - "相遇"在七政四余中可指同宫（会）、对宫（冲）、三合（拱）等关系
  - 此处"喜相遇"指财帛主、田宅主与身星、命星形成有利的位置关系
- **输入**: 财帛宫主星 + 田宅宫主星 + 身星 + 命星
  - 四星形成有利组合（同宫/三合/对照等）
- **输出**: 大吉利 - 可与石崇斗豪富（极富之命，可与历史首富石崇比拼财富）
- **可求值性**: 是 - 给定星盘，可计算财帛主、田宅主、身星、命星的位置，判定是否形成有利组合
- **一致性**: 与七政四余财田格局理论一致。与《星学大成》"在财帛在七强与身命主同宫主大富"完全吻合。

#### 规则2: 若无暗曜与刑囚 → 可与石崇斗豪富（前提条件）

- **算子**: 无（否定条件/排除凶星）
  - "无" = 不存在暗曜（罗睺、计都）与刑囚（天刑、天囚）在相关宫位
- **输入**: 财帛宫 + 田宅宫 + 命宫 + 身宫（相关宫位无凶星）
- **输出**: 大吉利 - 满足无凶星条件时，富格成立
- **可求值性**: 是 - 给定星盘，可检查相关宫位是否存在罗睺、计都、天刑、天囚等凶星
- **一致性**: 与《星学大成》"如田宅地更是忌星相犯加以命弱失陷 一生并无田宅"的凶星否定条件一致。凶星存在则富格不成立。

#### 规则3: 此宫破耗之地（注释）

- **算子**: 破耗（消耗/衰减）
- **输入**: 财帛宫/田宅宫
- **输出**: 中性偏凶 - 此宫为破耗之地，暗示财田二宫本身有消耗特性
- **可求值性**: 部分 - "破耗之地"是一个定性描述，需要结合具体星盘判断破耗程度
- **一致性**: 与《果老星宗》"天耗星...忌在田财二宮"一致，说明田财二宫本身容易被耗星影响。

### 2. 定量化分析

#### 四星相遇的概率

歌诀要求财帛主、田宅主、身星、命星四者"相遇"。如果"相遇"指同宫：
- 四星同宫概率约 (1/12)³ ≈ 1/1728 ≈ 0.06%（身命二星通常同宫或相近，故按三次独立计算）
- 这极其罕见，与"石崇斗豪富"的极富定位一致

如果"相遇"包括三合（拱）：
- 三合概率约 (1/3)³ ≈ 3.7%，相对常见但仍属高格

#### 凶星排除的概率

"无暗曜与刑囚"要求相关宫位无罗睺、计都、天刑、天囚四凶星。
- 四凶星分布在12宫，每个凶星不在指定宫位的概率约 11/12
- 四凶星均不在相关宫位的概率约 (11/12)⁴ ≈ 70.6%
- 这个条件相对容易满足，说明凶星排除是富格的必要非充分条件

#### 综合概率

富格 = 四星相遇 ∧ 无凶星 ≈ 0.06% × 70.6% ≈ 0.04%（同宫情况）
这说明"石崇斗豪富"级别的极富之命确实极其罕见。

### 3. 开放性分析

#### 待考证问题

1. **"相遇"的确切含义**：歌诀中"身命二星喜相遇"的"相遇"是指：
   - 财帛主与田宅主相遇？还是财田二主与身命二星相遇？
   - "相遇"是否包括三合、对照，还是仅指同宫？
   - 从语法上看，"财帛主，田宅主，身命二星喜相遇"可解读为四星互相相遇，也可解读为财田二主与身命二星相遇

2. **"暗曜"的范围**：暗曜是否仅指罗睺、计都，还是也包括月孛、紫气？
   - 狭义：暗曜 = 罗睺 + 计都（日月交点的隐曜）
   - 广义：暗曜 = 四余（罗睺、计都、月孛、紫气）中除紫气外的凶曜
   - 紫气通常为吉星，可能不算暗曜

3. **"刑囚"的体系归属**：歌诀使用地支五行宫主体系，但"刑囚"来自十干变曜体系（天刑星、天囚星）。这是否说明《星平会海》在实际推命中混用了两套体系？

4. **"此宫破耗之地"的指代**：指财帛宫还是田宅宫？还是两者都是？
   - 从《果老星宗》"忌在田财二宮"来看，两者都有破耗之性
   - 但注释紧跟在"可与石崇斗豪富"之后，可能是对富格的警示：即使富格成立，财田二宫本身仍有破耗风险

### 5. 时代性分析

#### 历史背景
- **"石崇"**: 西晋石崇（249-300年），中国古代首富的代名词，以"金谷园"闻名，与王恺斗富的典故广为流传。用石崇比喻极富，是命理文献的通用手法。
- **"豪富"**: 古代社会财富的最高等级，超越一般的"富"，达到"豪"（奢豪）级别。
- **"破耗之地"**: 反映了古代对财富不稳定性的认知——财帛田宅虽为富源，但也是消耗之地，需要吉星守护才能守住。

#### 现代诠释
- "石崇斗豪富" → 财富达到行业顶尖、福布斯级别
- "暗曜与刑囚" → 各种破财因素：经济危机、法律纠纷、健康问题等
- "破耗之地" → 财富管理中的风险意识，资产配置中的消耗因素
