## 一、模块功能概览

retrieval子系统负责按约束检索知识、管理三层存储（hot/warm/cold）、生成微包、查询表示映射。

| 模块 | 功能 |
|---|---|
| retriever | 按义务/表示/权限/证据等级过滤，返回最小知识接口，不返回整图或答案 |
| retrieval_order | 5层优先级检索（类型/前提→表示变换→图关系→语义相似→历史因果） |
| dg_adapter | 从legacy dg_*生成candidate K投影，只读，深拷贝+哈希校验 |
| kth_projection | K/T/H三种查询投影，稀疏激活计算a_t = W^T * p_t |
| hot_store | 实时保存Solver当前工作台状态（Q_0/W_t/关键事件/开放义务/最小证据/激活包） |
| warm_store | 按当前义务查询的类型过滤/表示映射/语义检索/图扩展/证据排序 |
| cold_store | 论文/教材/题解/MathLib/题库/全部证据，默认不进Solver上下文 |
| micro_pack | 完成一个研究动作所需的最小数据包，每轮增量注入 |
| representation_query | 6种表示映射类型查询，运输只在义务通过后成立 |
| source_registry | 论文/教材版本/许可证/撤稿状态，防止使用已撤稿来源 |

## 二、审计检查项

### 2.1 检索安全性（retriever.py）

| 检查项 | 说明 | 标准 |
|---|---|---|
| 不返回整图 | max_items限制防止整图返回 | max_items有上限且生效 |
| 过滤答案关键词 | 过滤答案/answer/solution等 | 答案关键词被过滤 |
| 只返回有权限内容 | 权限检查生效 | 无权限内容不返回 |
| 可追溯 | 返回的内容有来源 | 每个条目有source字段 |
| 证据等级标注 | 返回的内容标注证据等级 | evidence_level字段非空 |

**判定**：通过=5项全通过；有缺陷=过滤有小遗漏；失败=返回了整图或答案专属材料

### 2.2 检索顺序（retrieval_order.py）

| 检查项 | 说明 | 标准 |
|---|---|---|
| 5层优先级 | 类型/前提→表示变换→图关系→语义相似→历史因果 | 按此顺序检索 |
| 不只做embedding | 5层中只有第4层是语义相似 | 不把检索简化为embedding匹配 |
| 7类内容区分 | 7类内容类型区分返回，不合并为"相关知识" | 类型标注正确 |
| 只返回激活包需要的 | 只返回激活包需求的最小内容 | 不返回激活包不需要的内容 |

**判定**：通过=4项全通过；有缺陷=顺序正确但类型合并；失败=只做embedding或返回了不需要的内容

### 2.3 dg_adapter只读性（dg_adapter.py）

| 检查项 | 说明 | 标准 |
|---|---|---|
| 只读 | 不修改dg_*数据 | 无写操作 |
| 深拷贝 | 通过深拷贝防止外部修改 | _dg_nodes/_dg_edges是深拷贝 |
| 哈希校验 | 用内容哈希验证数据未被修改 | check_readonly用内容哈希 |
| 5种关系分拆 | K投影按5种关系矩阵分拆 | requires/uses/generalizes/analogous/verified_by |

**判定**：通过=4项全通过；失败=修改了dg_*数据或深拷贝缺失

### 2.4 K/T/H投影（kth_projection.py）

| 检查项 | 说明 | 标准 |
|---|---|---|
| 查询投影非真值库 | K/T/H是查询投影不是独立权威真相库 | 不把投影当知识库 |
| 认识论层级固定 | 认识论层级不变 | 不随意改变层级 |
| 候选状态提升 | 只有Verifier和发布门可提升候选状态 | 不自动提升 |
| 7种数值 | 稀疏矩阵值不是0/1而是7种数值组合 | 数值类型正确 |

**判定**：通过=4项全通过；失败=把投影当真值库或自动提升候选状态

### 2.5 三层存储（hot/warm/cold_store.py）

| 检查项 | 说明 | 标准 |
|---|---|---|
| hot只保存充分快照 | 不保存全部历史 | hot_store只有充分快照 |
| warm按义务查询 | 不返回全部 | warm_store按当前义务过滤 |
| cold默认不进上下文 | 只有按需查询才返回 | cold_store不自动注入 |
| cold标签不被当已理解 | 冷索引标签不是已理解知识 | 标签只是索引 |

**判定**：通过=4项全通过；失败=cold自动进上下文或hot保存全部历史

### 2.6 微包（micro_pack.py）

| 检查项 | 说明 | 标准 |
|---|---|---|
| 最小内容 | 只包含完成一个研究动作所需的最小内容 | 不包含多余内容 |
| 不预载未来路线 | 过滤完整解法/最终答案等关键词 | 预载关键词被过滤 |
| 增量注入 | 每轮增量注入Solver上下文 | 不是一次性全部注入 |

**判定**：通过=3项全通过；失败=预载了未来路线或一次性全部注入

### 2.7 表示映射（representation_query.py）

| 检查项 | 说明 | 标准 |
|---|---|---|
| 6种map_type | 全部支持 | 6种类型都可查询 |
| 运输条件 | 运输只在义务通过后成立 | 义务未通过时不运输 |
| 12字段完整 | RepresentationMap包含12个字段 | 字段完整 |
| 不自动成为表示变换 | 普通跨领域边不自动成为表示变换 | 需要显式声明 |

**判定**：通过=4项全通过；有缺陷=6种支持但运输条件未检查；失败=义务未通过时运输或普通边自动成为表示变换

### 2.8 来源注册（source_registry.py）

| 检查项 | 说明 | 标准 |
|---|---|---|
| 撤稿检查 | 已撤稿的来源不继续使用 | retracted=True的来源被过滤 |
| 版本记录 | 记录版本信息 | version字段非空 |
| 许可证记录 | 记录许可证信息 | license字段非空 |

**判定**：通过=3项全通过；失败=使用了已撤稿来源
