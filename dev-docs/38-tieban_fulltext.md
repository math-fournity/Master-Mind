## 二、铁板神数的结构原理

铁板神数的"铁口直断"建立在一个**确定性编码链**上，与七政四余的"天文计算链"是同一命运场 F 的两种投影（详见 `39-energy_operator_deep.md`）：

```
生辰八字 → 太玄数 / 干支取数 → 先天/后天卦 → 基本命数
        → 考时定刻（用已知六亲反校准"调整数/刻分"）
        → ±秘数（基础数 ± 48×n 等）
        → 条文编号 → 查《铁板神数》条文
```

关键点：
1. **考时定刻**：以父母生肖、兄弟数等已知六亲信息反推校准出生"刻分"，即把模糊的生辰精确到"刻"（一刻=15 分钟），这是铁板区别于八字"时辰级"精度的核心。
2. **父母生肖考刻表**：父生肖×母生肖 → 十二地支×十二地支 = 144 条基数（起于 9024，终于 10454，每格 +10）。例如父鼠母牛 = 9034。
3. **基本数±展开**：以实例八字"甲子 戊辰 甲午 乙亥"为例，四柱配太玄数得先天基本数 2253、后天基本数 8222，再按 `基础数 ± 48×n`（n=2,4,8,16）展开 16 条条文（2349 时有指南车 / 2445 欲上高楼未有梯 / 3021 命中三子高飞 / 2157 兄弟四人…）。

## 三、取数歌诀全集（结构核心句 · 逐句星象解码见 `40-tieban_sentence_decode.md`）

以下为各流派共传的"起数心法"，是把生辰八字转换为基本数、卦象的算法诗。它们是铁板神数里**最直接编码星象机制**的句子：

- **先天/后天八卦数**：乾一兑二离三震四巽五坎六艮七坤八（先天）；坎一坤二震三巽四中五乾六兑七艮八离九（后天）。
- **天干取数诀**：壬甲从乾数，乙癸向坤求，丙于艮门立，丁向兑家流，戊从坎处出，己以离为头，庚来震上立，辛在巽方游。
- **地支取数诀**：亥子一六水，寅卯三八木，巳午二七火，申酉四九金，中宫辰戌位，丑未五同归。
- **太玄取数诀**：甲己子午九，乙庚丑未八，丙辛寅申七，丁壬卯酉六，戊癸辰戌五，巳亥当属四。
- **大纲歌**：八刻分命妙无穷，九十六局见天工。阳前阴后共八数，吉凶休咎自不同。
- **起卦诀**：考时定刻用乾坤，干为父兮母为坤。二十四条明日月，八刻天干又一村。
- **定刻分诀**：甲乙斗宫定刻分，十二生肖作用神。日月并明觅踪迹，迂回辗转推六亲。
- **铁板神数开窍**：三六宫分重六宫…（以周易卦序、阴阳爻变说明条文数的生成）。
- 以及：数取先天/后天卦诀、八卦加则例、男女异命歌、日主变卦取数诀、四柱天干取数诀、前后变卦取数诀、大运取数诀、值年卦诀、定刻取数诀、铁板神数开窍（共约 20 首，全文见 `raw_tieban_text.md` 第二节）。
