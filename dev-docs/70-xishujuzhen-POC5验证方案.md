# 70 · xishujuzhen POC-5 验证方案

## 一、实验定位

POC-5在POC-4基础上做两个维度的加码：

1. **场景维度**：从静态分析（命宫+官禄宫）扩展到**动态分析（大限流年）**。静态命盘分析是大限流年分析的前置依赖——必须先有静态命盘结论，才能做动态分析。跨宫依赖从"命宫→官禄宫"扩展到"原盘静态分析→大限动态分析"。
2. **审计维度**：三步流程的第2步（AI解读JSON）新增**自审报告**（转译忠实性审计），与第3步的审计报告（执行忠实性审计）形成闭环审计链。

### 核心假设

1. 动态分析（大限流年）的依赖关系比静态分析更复杂（时间维度+宫位维度+星曜维度），B组（依赖图+三步流程+双重审计）的边际增益应比POC-4更大。
2. 第2步自审能闭环审计链，提升整体可靠性——如果解读AI漏译了某个节点或边，第2步自审就能发现，不需要等到第3步间接发现。
3. 跨宫依赖在动态分析中的表现：原盘静态分析结论（命主极强、恩用仇难定局、颠倒颠）传递到大限动态分析，影响限运吉凶判断。

### 与POC-4的对比

| 指标 | POC-4 | POC-5 |
|---|---|---|
| 分析类型 | 静态（命宫+官禄宫） | 静态+动态（原盘+大限流年） |
| 节点数 | 19 | ~30（19静态+~11动态） |
| 边数 | 25 | ~40（25静态+~15动态） |
| 跨宫依赖边 | 4（命宫→官禄宫） | ~8（4静态跨宫+4静态→动态跨宫） |
| 螺旋环路 | 1 | 1（复用五行生克↔阴阳昼夜） |
| 第2步自审 | 无 | **有（完整审计表）** |
| 审计链 | 单环（执行忠实性） | **双环闭环（转译忠实性→执行忠实性）** |

## 二、场景设计

### 命主数据

复用POC-4的命主：1985年3月15日 06:00（卯时），经度116.4，纬度39.9，昼生。

命主35岁（2020年），分析当前大限的吉凶。

### 分析任务

1. **静态分析（复用POC-4结论作为前置）**：命宫+官禄宫分析，得出命主极强、官主极强、空宫不空、有实权之象等结论。
2. **动态分析（POC-5新增）**：
   - 12限框架计算，识别当前所在限
   - 当前限宫位判断（落在哪个宫）
   - 限宫主庙旺判断
   - 限内星曜配置（原盘哪些星曜落入当前限宫位）
   - 限内行运星（当前限内有哪些行运星）
   - 流年太岁关系（2020年太岁与命宫的关系）
   - 流年-大限叠加分析
   - 限运吉凶综合判断

### 静态→动态的跨宫依赖

| 跨宫依赖边 | 命理含义 |
|---|---|
| 命主星判断 → 限宫主判断 | 如果限宫位与命宫同五行，则限宫主=命主，命主极强→限宫主极强 |
| 恩用仇难定局 → 限内星曜解读 | 恩用仇难定局决定了限内星曜的吉凶分类（恩星入限为吉，仇星入限为凶） |
| 颠倒颠 → 限运吉凶修正 | 命主极强则能承限内凶星之克（煞为权），颠倒颠跨宫传递到动态分析 |
| 官禄宫分析 → 限运吉凶 | 如果当前限宫位是官禄宫，则官禄分析结论影响限运吉凶 |

## 四、三步流程设计（含第2步自审）

### 第1步：系统生成JSON（经典计算，无AI参与）

系统用`build_chart()`排盘 + 依赖图生成器，输出JSON，包含：
- 星盘数据（静态+动态：12限框架、当前限、限内星曜、流年太岁）
- 依赖图（~30节点、~40边、~8跨宫依赖边）
- 螺旋环路（1个）
- 解读要求（含自审要求）★ POC-5新增
- 审计要求（执行忠实性）

### 第2步：AI解读JSON → 大师提示词 + 自审报告 ★ POC-5新增自审

AI解读JSON，输出**两份文件**：

#### 文件1：大师提示词（同POC-4）

逐节点解读、逐边解读、逐环路解读、逐跨宫依赖边解读、整体思维路径。

## 七、核心假设与验证条件

### 假设1：动态分析复杂度放大B组优势

**验证条件**：B组总分 - A组总分 > POC-4的+2.7分（即边际增益>2.7）

**如果成立**：说明动态分析的依赖关系复杂度确实放大了B组的优势。
**如果不成立**：说明动态分析的复杂度不足以放大B组优势，或A组知识嵌入已足够应对动态分析。

### 假设2：第2步自审闭环审计链

**验证条件**：第2步自审报告的转译忠实性≥95%，且第3步审计报告的执行忠实性≥95%

**如果成立**：说明双重审计链有效闭环，解读和分析两个环节都可追溯。
**如果不成立**：说明某个环节的审计覆盖率不足，需要改进审计模板。

### 假设3：静态→动态跨宫依赖可行

**验证条件**：4条静态→动态跨宫依赖边的覆盖率=100%，且每条边的传递过程有明确说明

**如果成立**：说明依赖图可以表达静态→动态的跨宫依赖，AI可沿其传递分析结果。
**如果不成立**：说明静态→动态的跨宫依赖表达或传递有问题。

## 八、局限

1. **动态分析只覆盖当前限**：12限中只深入分析当前限（命主35岁所在限），未做12限全量分析。如果做12限全量分析，依赖图会更大更复杂。
2. **流年只覆盖单年**：只分析2020年（命主35岁）的流年，未做限内逐年推演。如果做逐年推演，依赖图需要扩展。
3. **大限交接期未覆盖**：未分析大限交接期（前后2-3年）的运势转折。交接期分析是动态分析的重要组成部分，但POC-5暂不覆盖。
4. **动态分析无新螺旋环路**：动态分析的依赖关系是线性的，没有需要螺旋深化的判断。如果未来加入"限运吉凶→回到命主星判断→修正限运吉凶"的螺旋，可以测试螺旋环路在动态分析中的表现。
5. **A组大限流年知识已充分补充**：A组的参考材料会补充大限流年知识，A组也能完成动态分析。如果A组不补充大限流年知识，B组的边际增益可能更大。
6. **第2步自审是AI自审**：自审报告由解读AI自己生成，不是第三方审计。如果解读AI有系统性盲区，自审可能发现不了。未来可考虑交叉审计（另一个AI审计解读AI的输出）。
