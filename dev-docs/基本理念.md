## 思维的形状，我想试着把握、引导、启发它，让它成功

我觉得，我们这个数学大师系统，基于这样一种理念：“思维的形状是能够被看到和引导的”。

我们不妨假设：

Agent A看到了一个题目Q，给出了它的思考过程，它没有给出答案。

Agent B看到同一个题目Q，给出了B的思考过程，它给出了答案。

我们可以研究A的输出过程，得到它的思路，也许是一个流程图，总之是有形状的，当然也少不了形状上的说明（或许可以叫tag）。

也就是说，A的思考过程是一个带标注的图。

我们假设A就差一点X就完成了题目的解答，而B，其他都和A一样，唯独在后半段，

它看到了Q中的P，想到了P和X有关，然后它想到了X这个方向，最终成功解答了题目Q。

我们最开始做数学大师，启发就是用稀疏矩阵，这个稀疏矩阵，记录的就是各种“启发”，就是为了让Agent在看到P的时候，可以想到X。

而Agent A背后的LLM，在训练的时候，并没有让它获得看到P想到X这个能力。

但是如果一旦通过我们的提示，告诉它看到P应该想到X，那么它就能成功解答题目Q。

所以我在想，会不会真实案例中，未来的Agent M是这样工作的：

首先，它面对Q，独立去解答。如果失败了，我们就建模它的思维图。

我们的稀疏矩阵，记录了所有的启发，这些启发其实是一些二元关系，甚至是多元关系。

所谓的二元关系，就是看到了P，就应该想到X。

所谓的多元关系，就是看到了P和R，就应该想到X、S、T等。

但是如果把PR=(P, R)看成一个整体，那么XST=(X, S, T)，那么就成了高阶的二元关系，看到PR想到XST。

其实，本质上**模式识别**就是一种泛二元关系——看到了P，想到X。看到了PR想到了XST。前者和（或）后者甚至可以是一种带有时序的存在。

## 什么是题目呢？

通常而言，我们认为题目是固定的，预先给出来的。但是其实题目是动态的，任何Agent M的思考过程的中间状态，都是题目，因为我们完全可以把Agent M之前的思考过程，全部补充到原题的后面，作为一道新的题目，再让AI做这道新的题目。

所以，题目是动态的，只要没有解答完成，题目就一直在变化。

我们从大量的素材中提取了稀疏矩阵的元素，这些元素用来启发AI，但是如何有效地启发AI呢？毕竟，内容是很多的。

所以我们是不是可以通过一种过程性的方式来逐步启发AI呢？
