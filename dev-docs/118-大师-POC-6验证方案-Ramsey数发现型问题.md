# dev-docs/118-大师-POC-6验证方案-Ramsey数发现型问题

## 一、目的

三次POC证明：增量只在AI"不会"区出现。POC-1成功因为指数错误需要数值检验才能发现。POC-4/5失败因为问题是"证明已知定理"在AI"会"区。

POC-6改用**"发现型"问题**——不给定理陈述让AI证明，而是给背景信息让AI猜测未知结果。这是AI最不擅长的事——从有限信息推断未知规律。

## 二、问题来源

**arXiv:2608.02537** "Multicolor Ramsey numbers of odd cycles are superexponential"（Raphael Steiner, 2026-08-03）

核心结果：R_k(O_p) >= (log^{(p-1)} k)^{k/3-o(k)}，其中log^{(p-1)}是(p-1)次迭代对数。

- p=1: R_k(O_1) = R_k(C_3) >= k^{k/3-o(k)}（OpenAI的突破）
- p=2: R_k(O_2) >= (log k)^{k/3-o(k)}（Steiner的新结果）
- p=3: R_k(O_3) >= (log log k)^{k/3-o(k)}

**关键"发现陷阱"**：从C_3到C_5，下界从k^{k/3}暴跌到(log k)^{k/3}。AI不知道这个下降——它会倾向猜C_5和C_3"差不多"（都是奇环， Ramsey数应该同阶），但实际差了一个迭代对数层。

## 三、POC问题

### 给AI的信息（A/B组共同）

1. Ramsey数定义
2. OpenAI的突破：R_k(C_3) >= k^{k/3-o(k)}
3. 上界：R_k(C_l) <= k^{2k/(l-1)+o(k)}（Axenovich et al.）
4. 迭代对数定义：log^{(0)} k = k, log^{(1)} k = log k, log^{(2)} k = log log k, ...

### 问题

**不给出Steiner的定理。** 问AI：

"基于OpenAI对R_k(C_3)的突破性下界k^{k/3-o(k)}，你认为R_k(C_5)（5-环的多色Ramsey数）的下界增长阶应该是什么形式？请给出你的猜测，并用数值论证。"

### 陷阱分析

| 猜测 | 理由 | 正确? |
|---|---|---|
| R_k(C_5) >= k^{k/3-o(k)} | "C_3和C_5都是奇环，应该差不多" | ❌ 错误（高估） |
| R_k(C_5) >= c^k | "指数增长就够了" | ❌ 低估 |
| R_k(C_5) >= (log k)^{k/3-o(k)} | "从C_3到C_5，递归构造多了一层，导致下降一层迭代对数" | ✅ 正确 |

**正确答案**：(log k)^{k/3-o(k)}

### 数值检验的关键作用

用k=10^6比较不同猜测：
- k^{k/3}: (10^6)^{333333} = 10^{2000000}（天文数字）
- (log k)^{k/3}: (13.8)^{333333} ≈ 10^{375000}（小很多但仍然超大）
- c^k: 2^{10^6} ≈ 10^{300000}

数值检验能帮助AI意识到：不同猜测之间差异巨大，不能随便猜"和C_3一样"。

## 四、依赖图设计（B组独有）

### 节点（10节点）

| node_id | type | 内容 |
|---|---|---|
| R_k(C_5)下界猜测 | step | 猜测R_k(C_5)的增长阶 |
| C_3结果分析 | substep | 分析R_k(C_3)>=k^{k/3-o(k)}的含义和证明结构 |
| 递归构造机制 | substep | OpenAI证明用递归构造——每层递归嵌入一个C_3-free图 |
| C_5的递归障碍 | substep | C_5比C_3多2个顶点——递归构造需要避免C_5，比避免C_3更难 |
| 迭代对数概念 | concept | log^{(0)}k=k, log^{(1)}k=log k, log^{(2)}k=log log k——每多一层递归障碍，下界降一层迭代对数 |
| 增长阶比较 | substep | 比较k^{k/3} vs (log k)^{k/3} vs (log log k)^{k/3}的差异 |
| 数值论证 | substep | 用k=10^3,10^6,10^9等值比较不同猜测的数量级 |
| 上界约束检验 | substep | 检查猜测是否与已知上界k^{2k/4+o(k)}相容 |
| 递归深度与迭代对数 | concept | 递归深度p→下界(log^{(p-1)}k)^{k/3}——递归每深一层，下界降一层迭代对数 |
| 增长阶下降原理 | concept | 从C_3到C_5：避免更长的环需要更深的递归→下界下降 |

### 意识节点（复用已有）

| cog_id | 在本POC中的作用 |
|---|---|
| numerical_check | 用k=10^6等数值比较不同猜测——差距巨大，不能随便猜"同阶" |
| extreme_testing | 在k→∞极限下检验：k^{k/3}和(log k)^{k/3}的比值→∞，说明它们完全不同 |
| invariant_thinking | k/3指数是不变量——C_3和C_5的下界都有k/3指数，但底数从k变为log k |

### 边（12条）

```
R_k(C_5)下界猜测 → C_3结果分析 (depends_on)
C_3结果分析 → 递归构造机制 (depends_on)
递归构造机制 → C_5的递归障碍 (depends_on)
C_5的递归障碍 → 迭代对数概念 (depends_on)
迭代对数概念 → 增长阶下降原理 (depends_on)
增长阶下降原理 → R_k(C_5)下界猜测 (depends_on)  ← 回到起点=螺旋
增长阶比较 → 数值论证 (depends_on)
数值论证 → R_k(C_5)下界猜测 (depends_on)  ← 数值验证反馈
R_k(C_5)下界猜测 → 上界约束检验 (depends_on)
迭代对数概念 → 增长阶比较 (depends_on)
递归构造机制 → 递归深度与迭代对数 (depends_on)
递归深度与迭代对数 → 增长阶下降原理 (depends_on)
```

### 螺旋环路

**增长阶下降原理 ↔ R_k(C_5)下界猜测 ↔ 数值论证**：
- 第一圈：从递归机制推出"下降一层迭代对数"→猜(log k)^{k/3}
- 第二圈：用数值验证→k=10^6时(log k)^{k/3}远小于k^{k/3}→确认下降合理
- 第三圈：用上界检验→(log k)^{k/3} < k^{2k/4+o(k)}→相容
