## 一、模块功能概览

devin_cli_adapter连接12步运行时和真实devin cli实例，每turn调用`devin -p`，在Solver工作目录运行，支持`--export`导出。

## 二、审计检查项

### 2.1 连接稳定性

| 检查项 | 说明 | 标准 |
|---|---|---|
| 调用成功 | 每turn的returncode为0 | response不以[ERROR开头 |
| 超时处理 | 超时返回[TIMEOUT]不崩溃 | 有超时处理 |
| 工作目录正确 | cwd是Solver工作目录 | sessions.db中working_directory是/data/math-agent-glm5.2-* |
| export路径绝对 | export路径是绝对路径 | 不因cwd变化而失败 |

**判定**：通过=4项全通过；有缺陷=调用成功但export有小问题；失败=调用失败或工作目录错误

### 2.2 数据完整性

| 检查项 | 说明 | 标准 |
|---|---|---|
| session_id获取 | 第1turn后session_id非空 | session_id字段有值 |
| conversation.json生成 | export文件存在且大小>0 | 文件可读 |
| token_metrics记录 | final_metrics有值 | prompt/completion tokens有记录 |
| turn_log保存 | save_turn_log生成turn_log.json | 文件存在 |

**判定**：通过=4项全通过；有缺陷=session_id获取但metrics缺失；失败=export文件未生成或session_id为空

### 2.3 Solver行为约束

| 检查项 | 说明 | 标准 |
|---|---|---|
| 无web_search | tool_call_state中无web_search | 搜索是作弊 |
| 无工作系统劫持 | response不含"加载认知种子"/"CP1-CP3"/"七步骤" | Solver直接做数学 |
| 有数学内容 | response包含数学公式或推理 | 不是空回复或元讨论 |

**判定**：通过=3项全通过；失败=使用了web_search或被工作系统劫持

### 2.4 多实例支持

| 检查项 | 说明 | 标准 |
|---|---|---|
| 三个工作目录可用 | math-agent-glm5.2-{1,2,3}都存在且有AGENTS.md | 3个目录可用 |
| 自动选择 | 无work_dir参数时自动选择 | 选第一个可用目录 |
| 并行不冲突 | 不同run用不同工作目录 | 不共用同一目录 |

**判定**：通过=3项全通过；有缺陷=可用但不自动选择；失败=目录不存在或AGENTS.md缺失
