# 68-xishujuzhen POC-4 验证方案

## 1. 背景：POC-3 的结论与下一步

### 1.1 POC-1→POC-2→POC-3 的分数轨迹

| | POC-1 | POC-2 | POC-3 |
|---|---|---|---|
| B 组综合 | 4.50 | 5.00 | 5.00 |
| A 组综合 | 4.70 | 4.85 | 4.85 |
| B-A | -0.20 | +0.15 | +0.15 |

POC-2 和 POC-3 的 B-A 差距都是 +0.15，没有扩大。原因是**命宫分析场景已彻底接近天花板**——B 组在 POC-2 中已满分 5.00，POC-3 保持 5.00，无提升空间。

### 1.2 POC-3 的核心结论

> 命宫分析场景已彻底接近天花板。依赖图提示（无论有没有自解读）的边际增益主要在结构感上。依赖图的最大价值在更复杂的场景中。

### 1.3 POC-3 的过程价值

虽然分数未提升，但 POC-3 验证了三步流程的可行性：
- AI 自解读质量极高（转译忠实 100%，大师语言 5 分）
- 双重对照审计更严格（14/14 路径忠实）
- 自解读引导了更深思考（"宫主泄气反哺度主"洞察）

### 1.4 POC-4 的目标

**换更复杂的场景，让依赖图提示的边际增益不再被天花板遮蔽。**

POC-4 从命宫分析（单宫）扩展到**双宫联动（命宫+官禄）**，增加跨宫依赖。在复杂场景中：
- A 组不知道该在什么时候用什么、按什么顺序思考 → B 组的依赖图优势会显现
- B 组的自解读环节会引导更长的思维路径 → 深度和逻辑性的优势可能放大
- 满分天花板不会被触及 → 分数差异能真正体现

## 2. 场景选择：双宫联动（命宫+官禄）

### 2.1 为什么选命宫+官禄

**命宫+官禄是七政四余中最核心的双宫联动**：
- 命宫是整个星盘的根基（命主、命度、恩用仇难）
- 官禄宫是事业/功名的核心（官主、官禄星曜、官禄格局）
- 两者之间有显式的跨宫依赖：命主星的强弱影响官禄宫的判断（命主强则能承官禄之重，命主弱则官禄虽好也难以发挥）

**跨宫依赖是 POC-1/POC-2/POC-3 中完全没有的**：
- POC-1/2/3 的依赖图只覆盖命宫内部（12 节点 16 边）
- POC-4 的依赖图覆盖命宫+官禄两个宫位，增加跨宫依赖边

### 2.2 为什么不选格局+大限

- 格局判断依赖规则库（`rules_library.json`），不是纯依赖图能引导的
- 大限推演是推运，不是分析——xishujuzhen 当前设计针对分析任务
- 双宫联动更直接地扩展当前依赖图，不需要引入新的系统组件

### 2.3 官禄宫在简化盘中的位置

简化盘的十二宫排布（从命宫寅起，逆时针）：

| 宫位 | 地支 | 五行 | 与命宫关系 |
|---|---|---|---|
| 命宫 | 寅 | 木 | 自身 |
| 相貌宫 | 丑 | 土 | 命宫前一宫 |
|福德宫 | 子 | 土 | |
|官禄宫 | 亥 | 木 | **与命宫同五行（木）** |
|迁移宫 | 戌 | 火 | |
|疾厄宫 | 酉 | 金 | |
|夫妻宫 | 申 | 水 | |
|奴仆宫 | 未 | 水 | |
|男女宫 | 午 | 火 | |
|田宅宫 | 巳 | 水 | |
|兄弟宫 | 辰 | 金 | |

**关键发现：官禄宫在亥，亥属木，与命宫寅（木）同五行。** 这意味着：
- 官禄宫主也是木星（和命主星相同）
- 命主星=官主星=木星——这是"命官同主"的特殊格局
- 命主木星极强（庙旺比和昼生三得）→ 官主也极强 → 官禄宫根基也稳固

这个设计让跨宫依赖非常自然：命主星判断的结果直接决定官禄宫的根基判断。

### 2.4 官禄宫星曜配置

简化盘中，需要确定哪些星曜落入官禄宫（亥宫）。根据简化盘的黄经数据：

| 星曜 | 黄经 | 所在宿 | 所在宫 |
|---|---|---|---|
| 木星 | 315° | 尾宿 | 寅宫（命宫） |
| 太阳 | 354° | 尾宿末 | 寅宫（命宫） |
| 月亮 | 300° | 心宿 | 寅宫（命宫） |
| 火星 | 330° | 尾宿 | 寅宫（命宫） |
| 水星 | 345° | 尾宿末 | 寅宫（命宫） |
| 土星 | 120° | 巳宫 | 巳宫（田宅宫） |
| 金星 | 10° | 卯宫 | 卯宫（财帛宫） |
| 罗睺 | 90° | 巳宫 | 巳宫（田宅宫） |
| 计都 | 270° | 丑宫 | 丑宫（相貌宫） |

**官禄宫（亥宫）内没有星曜落入。** 这是一个"空宫"——官禄宫本身无星，其判断完全依赖：
1. 宫主星（木星）的状态——而木星在命宫，所以命宫分析直接决定官禄宫判断
2. 命宫对官禄宫的"照射"——命宫五星是否对官禄宫有相位/拱照关系
3. 其他宫位星曜对官禄宫的间接影响

**空宫设计的好处**：官禄宫的分析几乎完全依赖跨宫依赖——不能独立分析，必须从命宫分析结果"传递"过来。这最大化了跨宫依赖的价值。

## 4. 知识内容嵌入

### 4.1 新增意识节点的 knowledge_content

**官禄庙旺判断**：
```
官禄宫在亥，亥属木。官主星为木星（与命主星相同——命官同主）。
木星在寅宫为庙（已在命宫分析中判断），寅亥同属木，木星对亥宫的力量关系与对寅宫一致。
官禄宫为空宫（无星曜落入），官禄宫的力量主要看官主星（木星）的状态。
官主木星极强（庙旺比和昼生三得俱全）→ 官禄宫根基极强。
```

**命官关系判断**：
```
命宫与官禄宫的联动关系：
1. 命官同主：命宫寅属木，官禄亥属木，宫主同为木星。命主=官主，命强则官强。
2. 命主承载：命主极强则能承官禄之重——官禄虽好，命主弱则难以发挥；命主强则官禄可充分发挥。
3. 恩用仇难跨宫：恩星（月、水）生命主也扶官主；用星（日、火）泄命主也泄官主；仇星（金）克命主也克官主。
4. 颠倒颠跨宫：命主极强则能承受用星之泄（不被泄垮），官禄之泄同理——命主强则官禄之泄为输出而非消耗。
5. 仇难外避对官禄的影响：仇星金星在卯宫（财帛宫），不在官禄宫；难星土星在巳宫（田宅宫），不在官禄宫。官禄宫也是纯净的。
```

**官禄三方四正**：
```
三方四正：官禄宫（亥）的三合宫为卯（财帛）、未（奴仆），对宫为巳（田宅）。
- 卯宫（财帛）：仇星金星在此，火克金，仇星受宫克
- 未宫（奴仆）：无星
- 巳宫（田宅）：难星土星、用星罗睺在此
- 巳宫属水，水生木（官禄亥木），巳宫水气暗助官禄

三方四正总评：官禄宫三方四正中有仇星（金星在卯）和难星（土星在巳），但：
- 金星在卯受火克，力量被削
- 土星在巳，巳宫水气反生官禄木气
- 三方四正整体对官禄宫的影响为中性偏吉
```

### 4.2 空宫判断的知识

**官禄宫星曜配置**（空宫判断）：
```
官禄宫（亥）为空宫——无星曜落入。
空宫的含义：
1. 官禄宫本身无星，其力量完全依赖官主星（木星）的状态。官主木星极强→官禄宫虽空但不弱。
2. 空宫不代表无事业——而是事业的力量来源不在官禄宫本身，而在命宫（因为命官同主）。
3. 空宫的吉凶取决于三方四正和宫主星：宫主极强+三方四正中性偏吉→官禄宫虽空但格局不差。
4. 命主木星在命宫寅，不在官禄亥——命主"照临"官禄（寅亥同属木，同气相求），命主的力量通过同气关系传递到官禄宫。
```

## 5. 三步流程（复用 POC-3）

### 5.1 第一步：经典计算生成 JSON（系统做）

扩展依赖图（19 节点 25 边）+ 知识嵌入 + 解读要求 + 双重对照审计要求。

### 5.2 第二步：AI 解读 JSON 生成大师级提示词（AI 做）

AI 解读扩展依赖图，重点解读**跨宫依赖**：
- 命宫分析如何传递到官禄宫分析
- 命主星判断如何决定官主星判断
- 恩用仇难和颠倒颠如何跨宫影响命官关系

### 5.3 第三步：AI 在 JSON + 大师级提示词共同提示下分析（AI 做）

AI 分析命宫+官禄，输出结果文件 + 审计文件（双重对照）。

### 7.4 "显著优于"的定义

B 组显著优于 A 组需要同时满足：
1. B 组结果文件综合评分比 A 组高 **0.50 分以上**
2. B 组在**至少 3 个维度**上不低于 A 组
3. B 组在**至少 2 个维度**上比 A 组高 1 分以上
4. B 组审计 JSON 覆盖完备性 ≥ 90%
5. B 组审计思考路径忠实性 ≥ 80%
6. B 组解读转译忠实性 = 100%

### 7.5 POC-4 的核心假设

> **在双宫联动（命宫+官禄）场景中，A 组不知道该在什么时候分析官禄宫、命宫分析如何传递到官禄宫，而 B 组的依赖图（含跨宫依赖）显式引导了这一传递。因此 B 组在完整性和逻辑性上的优势会比 POC-3 更大，从而拉开 0.50 分以上的差距。**

具体预期：
- **完整性**：A 组可能遗漏官禄宫分析或命官联动分析（因为没有依赖图告诉它"命宫分析完后还要分析官禄宫"）。B 组不会遗漏（依赖图有跨宫边）。
- **逻辑性**：A 组的命宫→官禄宫过渡可能生硬或缺失。B 组的过渡由跨宫依赖引导，自然流畅。
- **深度**：A 组可能不深入命官联动（恩用仇难跨宫、颠倒颠跨宫）。B 组由依赖图引导深入。
- **结构感**：B 组继续保持优势（依赖图对应）。
- **准确性**：两组可能持平（知识充足时准确性不依赖图）。

## 8. 成功/失败定义

### 8.1 成功

B 组满足"显著优于"的全部 6 个条件。

含义：在双宫联动场景中，依赖图（含跨宫依赖）+ 自解读 + 双重提示 + 双重对照审计的组合，使 B 组在完整性和逻辑性上显著优于 A 组，证明了依赖图在复杂场景中的导航价值。

后续行动：扩展到更复杂的场景（三宫联动、格局+大限），引入真实星盘。

### 8.2 部分成功

**情况 A**：B 组结果评分达到"显著优于"，但解读或审计不达标。

含义：结果好但流程不忠实——需要加强解读和审计约束。

**情况 B**：解读和审计达标，但结果评分未达到"显著优于"。

含义：双宫联动场景仍不够复杂，或跨宫依赖的设计不够好。需要进一步增加复杂度。

### 8.3 失败

B 组结果评分未达到"显著优于"，且解读或审计不达标。

## 10. 诚实声明

POC-4 仍有以下局限：

1. **仍用简化盘**：不验证真实天文数据下的表现
2. **双宫联动可能仍不够复杂**：如果 A 组在补充知识后也能自发做命官联动分析，B 组的优势可能仍不够大
3. **空宫设计可能过于极端**：官禄宫完全空宫，分析几乎完全依赖跨宫依赖——这最大化了跨宫依赖的价值，但也可能让 A 组直接放弃官禄宫分析（"空宫没什么好分析的"），从而让 B 组的"完整性"优势过于容易地体现
4. **跨宫依赖只有 5 条**：可能不足以体现复杂场景中依赖图的导航价值
5. **命官同主可能过于特殊**：命主=官主=木星，这让跨宫依赖非常直接（命主星判断直接决定官主星判断）——但真实场景中命官不同主更常见，跨宫依赖更复杂
