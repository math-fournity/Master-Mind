## 一、命运场 F：一切算子的输入

出生时空坐标 (t=儒略日, λ=经度, φ=纬度) 经 Swiss Ephemeris 推出**十一曜**（日、月、金、木、水、火、土 + 罗、计、炁、孛）的恒星黄经 `lon_i`，再经宿度表、神煞起例、宫位制、大限序列，得到完整星象配置。这个配置就是命运场 F 在出生点的取值。

铁板神数的"干支"是 F 的**离散指纹**（年干支=木星+土星会合周期的 60 分格；月干支=太阳黄经十二宫；日干支=60 甲子循环；时干支=12 时辰）。太玄数、八卦数都是把这套指纹再量化成整数。所以：

> 铁板的"数"与七政的"经"，是同一 F 的两种读数。

## 二、七层能量算子栈

```
Layer 0  时空坐标算子   Φ(t,λ,φ) ──→ 儒略日 + 经纬度
Layer 1  星曜位置算子   P(lon_i)  ──→ 十一曜恒星黄经（Swiss Ephemeris）
Layer 2  宿度算子       M(lon_i)  ──→ 每曜躔何宿、何度 → 庙旺乐陷等级 D_i
Layer 3  神煞算子       S(干支)   ──→ 各神煞落点 → 调制系数 σ_k
Layer 4  宫位算子       H(lon_i)  ──→ 十二宫归属 + 命宫/身宫/四正
Layer 5  大限算子       L(age)    ──→ 当前限宫 + 限内行运
Layer 6  域投影算子     π_axis    ──→ 把星象投影到 六亲/婚姻/财/寿 等人生轴
Layer 7  量化算子       Q(·)      ──→ 条文编号 N（铁板）或格局评分（七政）
```

### Layer 1 · 星曜位置算子 P

十一曜恒星黄经。四余的天文定义（本项目 A2 审计已修复）：
- 罗睺 = 黄白道交点（默认升交点，含 `true_as_north` 旧法开关）
- 计都 = 罗睺 + 180°
- 紫炁 = 28 年线性运动（修复自误用的 MEAN_APOG）
- 月孛 = 月球平均远地点 MEAN_APOG（修复自误用的 OSCU_APOG）

### Layer 2 · 宿度算子 M（二十八宿的底层机制）

二十八宿是黄道 28 个"能量驿站"，每宿有固定的**七政属性**（三字名中间字：木金土日月火水）。算子核心是**属性匹配查表**：

```
M(lon_i):  宿 = lookup_mansion(lon_i)
           attr_match = (star.seven_zheng == 宿.seven_zheng)   # 同属性 → 升殿
           D_i = dignity_rank(attr_match, 生克, 四象方位气)
```

- **升殿（庙）**：星曜躔"七政属性相同"之宿。木→角斗奎井、火→尾室觜翼、日→房虚昴星、月→心危毕张、土→氐女胃柳、金→亢牛娄鬼、水→箕壁参轸。
- **旺/乐/喜/好/平/陷/怒/刑**：依"宿属性生克星曜属性"分级。金克木→木躔亢/牛"无功"；宿生星曜→次旺。
- **四象方位气**叠加：同属性下东方木主生发、南方火主文明、西方金主收敛、北方水主归藏，使四"本家宿"吉凶侧重不同。
- 完整 28 宿算子表见 `raw_28mansions.md` 第二节。

> **底层算子的本质**：二十八宿 = 一张"七政属性查找表 + 五行生克关系表"，星曜落入即查表得能量等级。这是排盘所有庙旺乐陷判读的最小原子操作。

### Layer 3 · 神煞算子 S（神煞系统的底层机制）

每个神煞是一个**以干支为输入的起例函数**，输出一个地支落点（或星曜），再调制能量。起例分 7 类（见 `raw_shensha.md`）：

| 类 | 基准 | 代表神煞 | 底层机制 |
|---|---|---|---|
| 甲·年干起 | 年天干 | 禄勋、文昌、天厨、科名、化曜 | 十神生克 / 纳甲合气 |
| 乙·年支起 | 年地支 | 红鸾、天喜、孤辰、寡宿、天罗、地网 | 地支通关/三会 |
| 丙·日干起 | 日天干 | 天乙贵人、文昌（子平）、太极贵 | 十干合气+纳甲 |
| 丁·月支起 | 月地支 | 天德、月德、德秀 | 五行归墓于四卦 |
| 戊·三合局起 | 三合局 | 驿马、华盖、将星、劫煞、灾煞、岁煞、咸池、羊刃 | 十二长生几何定位 |

| 庚·纳甲起 | 京房纳甲 | 卦气、地元禄 | 纳甲配五虎遁 |

神煞的**天文真实度分级**（决定"能量"的可信来源）：
- **真实天文**：罗睺、计都（黄白道交点，18.6 年一周天）
- **周期虚星**：紫炁（28 年，无实体天象，象征构造）、月孛（月球远地点）
- **纯干支几何**：禄勋（临官）、驿马（长生）、华盖（墓库）、劫煞（绝）、咸池（沐浴）、羊刃（帝旺次位）——借星象命名，无实体天象，但规律严谨

调制系数 σ_k 作用：`E_modulated = E_base × ∏ σ_k`（吉煞>1，凶煞<1 或反向叠加）。

### Layer 4 · 宫位算子 H

十二宫（子=宝瓶起，恒星黄道制）归属 + 命宫（ASC）、身宫、四正（命/田宅/妻/官）。星曜入何宫决定其"职能场景"。升殿（宿度层）与归垣（宫层）并列构成"得地"判读。

### Layer 7 · 量化算子 Q

- **铁板侧**：`N = Quantize_铁板(干支指纹) → 条文编号`（粗量化，干支太玄数为基，见 38 节二）。

## 三、星曜能量算子的五层叠加（Layer 1+2+3 的精化）

单个星曜 S_i 的能量 = 五层算子之积（`raw_qizheng_star_energy.md` 总论）：

```
E_i = W(五行本底) × Y(阴阳昼夜) × D_i(庙旺乐陷等级) × Q_i(化气职能) × R_i(生克关系)
```

1. **五行本底 W**：火(日火罗)/木(木炁)/水(月水孛)/金(金)/土(土计)。
2. **阴阳昼夜 Y**：昼星(日土计水孛木炁)昼生有力，夜星(月火罗金)夜生有力；反背减力。
3. **庙旺乐陷 D_i**：入垣 > 升殿 > 入庙 > 乘旺 > 乐 > 喜 > 好 > 平 > 陷。由 Layer 2 宿度算子给出。
4. **化气职能 Q_i**：日化贵、月化富、木化仁/贵、火化兵、土化信、金化义、水化智；十干化曜（天禄/天暗/天福…）见 A3。
5. **生克关系 R_i**：恩(生我)/用(我生)/难(克我)/仇(我克) + 余奴伤主（罗伤火、计伤土、炁伤木、孛伤水）。

星曜间通过**守/照/冲/钓(拱夹)/会/截**产生合力（《天元五歌》"拱夹有情权力大"）。

## 五、铁板"数"与七政"经"的统一公式

令 F 为命运场，定义：

```
铁板编码：  N = Q_T( Γ( 干支指纹(八字) , 考刻校准 ) )        # 粗量化，整数条文号
七政编码：  E = Σ_i E_i · π_axis(F) · ∏ σ_k · L(age)         # 细量化，实数能量向量
```

**统一命题（研究假设，待实证）**：存在映射 Φ 使 `N ≈ Φ(E)`。即：同一个出生时空，铁板条文号与七政能量向量高度相关、可相互解释。铁板的"考时定刻"本质是用六亲事件反解 F 中六个亲轴的最优落点（多层拟合），与七政"矫正"用生命事件反推出生时刻是同一算法的两面。

> **审查注（42-self_review F1）**：此"统一定理"目前是**概念性统一命题**，尚未经大规模"同盘同命→条文号 vs 七政评分"的实证回归验证。其价值在于给出可检验的统一框架；是否构成严格双射（一一对应）需后续用郑氏星案式样本做统计验证，不可当作已证定理宣称。

因此：
- **铁口直断的来源** = F 对 (t,λ,φ) 的确定性。出生时刻差一刻（15 分），土星黄经变约 0.04°、月亮变约 0.4°，足以切换宿度/神煞/宫位，从而切换条文。这是数学必然，非迷信。
- **统一性** = 铁板是"验证系统"（条文库），七政是"计算系统"（星象过程）。二者闭环。
