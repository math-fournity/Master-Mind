## 实验目的

验证281号思想（高Level Hint系统化Low Level化）的power。两层验证：
1. **静态四组对照**：bare vs abstract vs dictionary vs matched
2. **脉络继承实验**：给AI解答到转折点之前的脉络，让它从关键翻译点继续

## 实验设计

### 字典

离线建好24个翻译方向的字典（`runs/vms_poc_0/vms8_translation_dictionary.json`），覆盖数论/代数/组合/几何/跨域。字典在不看任何具体题目的情况下建立，建立后冻结。

### 题目

6道OlympiadBench奥赛题：1843(Algebra), 1738(NT), 1962(NT), 1766(NT), 1631(Algebra), 1974(Combinatorics)

### 五组对照

| 组 | 给AI什么 | 验证什么 |
|---|---|---|
| **bare** | 只给题目 | baseline |
| **abstract** | 题目 + "翻译到另一种语言"（抽象方向） | 抽象hint是否有用 |
| **dictionary** | 题目 + 完整字典 + "遍历字典找翻译方向" | AI能否自己从字典中找到正确翻译 |
| **matched** | 题目 + 字典中匹配到的具体翻译 | 匹配对了效果如何 |
| **lineage** | 题目 + 解答脉络（到转折点之前）+ 方向引导 | **脉络继承+方向注入**——引导树的真正用法 |

## 关键发现

### 1. 脉络继承100%成功（lineage组）

两道脉络继承实验都成功了：
- **1766-lineage**：✅ 正确答案 (0,±2),(4,±23)。proof中明确使用了2-adic赋值（字典T02方向）
- **1631-lineage**：✅ 正确答案 k=2。proof中明确使用了Legendre符号+Euler准则（字典T03方向）

**这是本POC的核心结果**：给AI解答到转折点之前的脉络+方向引导，AI 100%成功完成了证明。

### 2. 静态hint组没有显著差异（bare=abstract=matched=33%, dictionary=17%）

- bare和abstract通过率相同（33%）——抽象hint没有帮助，和7g-v3结论一致
- matched和bare通过率相同（33%）——匹配对了的具体翻译也没有显著帮助
- dictionary反而最低（17%）——遍历字典可能让AI分散注意力

### 3. 1766和1738对bare AI不够难

1766-bare和1738-bare都成功了——这两道题对GLM-5.2来说不够难，不需要翻译方向hint就能解。只有1631、1843、1962、1974是bare AI失败的题。

### 4. 1766-dictionary的proof明确提到了字典方向

1766-dictionary的proof中写道：
> "T01：将原方程模2^x... T02：利用2-幂模下y²≡1的解的结构..."

**AI读了字典后，自己选择了T01和T02方向，并成功解题。** 这证明字典是可以被AI遍历使用的——但只在这道题bare也能做的情况下。

### 5. 1631是关键案例——bare失败但lineage成功

1631是唯一一道bare/abstract/dictionary/matched全失败但lineage成功的题。这说明：
- 1631的关键转折点（x₃≡7(mod 8) → 二次剩余 → Euler准则）对AI来说非显然
- 给脉络到转折点之前 + 方向引导，AI能完成后续证明
- 不给脉络只给hint（dictionary/matched组），AI到不了转折点

## 分析

### 为什么lineage 100%但静态组只有33%？

**脉络继承解决了两个问题**：
1. **到达转折点**——静态组的AI可能根本到不了需要翻译的那个点（如1631的x₃≡7(mod 8)）
2. **知道何时翻译**——脉络中明确标注了"请从这里继续"，AI知道这是转折点

**静态hint只解决了一个问题**：
- 给了翻译方向，但AI不知道在什么时候用这个方向
- AI可能走了完全不同的路径，到不了需要翻译的点

### 这验证了什么？

**281号思想的power在于脉络继承+方向注入的组合**：
- 字典提供了"翻译到什么"（Low Level化的具体形式）
- 脉络提供了"何时翻译"（到达转折点的路径）
- 两者结合才是引导树的真正用法

**单独给字典（dictionary组）不够**——AI不知道何时用字典中的方向。
**单独给脉络不够**——没有方向引导，AI到转折点后不知道往哪走。
**脉络+方向（lineage组）= 100%成功**。

### 与引导树的关系

引导树的核心操作就是脉络继承+方向注入：
1. 父节点AI解题到某个点卡住了
2. 系统采集父节点的推理脉络
3. 系统从字典中检索匹配的翻译方向
4. 启动子节点AI，给它脉络+方向，从卡点继续

lineage组验证了这个操作的有效性——100%成功。

## 局限性

1. **样本太小**——lineage只有2道题，需要更多题目验证
2. **选题偏差**——lineage的2道题是我选的"翻译是关键转折点"的题，可能不具代表性
3. **脉络是我写的**——真实引导树中脉络应该由父节点AI的thinking自动采集，不是我手写的
4. **方向是我匹配的**——真实引导树中方向应该由检索系统从字典中匹配，不是我人工匹配的
