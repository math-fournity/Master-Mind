### 星曜顺序异常注记

对比已考据的兄弟宫（auto.40）、田宅宫（auto.41）、男女宫、妻妾宫，标准星曜顺序为：**木→火→土→金→水→日→月→炁→孛→罗→计**（11星各一）。

本段星曜出现顺序为：**水→火→土→金→水德→日→月→炁→孛→罗→计**，其中：
- **水星出现两次**（规则1"水星"+ 规则5"水德"）
- **木星缺失**

与财帛宫（auto.39区域）的异常模式一致——财帛宫同样以水星开头、水星出现两次、木星缺失。这暗示两种可能：
1. **OCR 系统性误读**：木→水（木字旁与水字旁在 OCR 中易混），规则1原文应为"木星解散照其宫"
2. **底本变体**：该版本《星平会海》在此类宫位中确实以水星代木星

**考据判定**：基于内容分析，规则1"解散照其宫，可免平生患难凶。财禄更招多润泽，堂堂人品赛终童"——"解散"（消解散去）可属水星（水主智、化解），"赛终童"（终军弱冠驰名）也可属水星（智秀）。但木星（木主仁、文才）同样可解释"赛终童"。**暂以原文为准（水星），标注存疑**。

## 规则提取与形式化五问

本段包含 **11 条规则**（11星曜各照疾厄宫一条）+ 1 段释云总注。每条规则以四句七言诗形式呈现。

### 规则 1：水星照疾厄宫

> 水星解散照其宫，可免平生患难凶。财禄更招多润泽，堂堂人品赛终童。

| 形式化五问 | 回答 |
|---|---|
| **算子** | 照/解散（水星落入疾厄宫，且以"解散"方式照临——消解凶险） |
| **输入** | 水星位置 ∈ 疾厄宫（第八宫） |
| **输出** | 吉——可免平生患难凶；财禄润泽；人品出众如终童（弱冠成名） |
| **可求值** | ✅ 是。判定水星是否在第八宫 → 输出免灾+财禄+人品判定 |
| **与规则库一致** | ✅ 水星主智，"解散"与水星化解属性一致。与命宫水星"文术多智能"方向一致——水星在疾厄宫以智解灾 |

**释云对应**："终童名运，弱冠驰名"——终军弱冠成名，对应"赛终童"。"清洁多智"——水星清洁多智的本性。

**存疑**：此规则可能原为木星（标准顺序第一星应为木），OCR 误读木→水。若为木星，则"解散"可解为木性舒达消解壅滞。

### 规则 2：火星照疾厄宫

> 火星八位忧血难，灾来非命祸难禁。腰驼背曲缺唇齿，恶煞不犯厄减轻、

| 形式化五问 | 回答 |
|---|---|
| **算子** | 照/忧（火星落入疾厄宫第八位，主血难之忧） |
| **输入** | 火星位置 ∈ 疾厄宫（第八宫）；是否有恶煞同宫/侵犯 |
| **输出** | 凶——血难、非命之灾、身体残缺（腰驼背曲缺唇齿）；若无恶煞→厄减轻 |
| **可求值** | ✅ 是。判定火星是否在第八宫 + 是否有恶煞同宫 → 输出血难程度判定 |
| **与规则库一致** | ✅ 火星主燥急血热，在疾厄宫主血难。与命宫火星"燥急"、妻妾宫火星"克妻"方向一致——火星在各宫均主凶性爆发 |

**定量化思考**："恶煞不犯厄减轻"——存在**恶煞乘数**：有恶煞→满厄；无恶煞→厄减轻。可量化为：
```
厄度 = base(火星在疾厄宫) × modifier(恶煞)
- 有恶煞: modifier = 1.0（满厄）
- 无恶煞: modifier = 0.4-0.6（减轻）
```

### 规则 3：土星照疾厄宫

> 土德来临疾厄时，凶星焰焰定灾危。多树华哑双睛翳，不是驼腰必病脾。

| 形式化五问 | 回答 |
|---|---|
| **算子** | 来临/定（土德落入疾厄宫，若有凶星焰焰则定灾危） |
| **输入** | 土星位置 ∈ 疾厄宫（第八宫）；是否有凶星同宫（焰焰=凶星炽盛） |
| **输出** | 凶——多病：喑哑（OCR"华哑"疑为"喑哑"）、双目翳、驼腰或脾病 |
| **可求值** | ✅ 是。判定土星是否在第八宫 + 凶星状态 → 输出灾危+具体病候判定 |
| **与规则库一致** | ✅ 土星主脾胃（释云"土主脾胃"），在疾厄宫主脾病+形体残缺。与命宫土星"救厚肥大"不同——在疾厄宫表现为病态土性 |

**释云对应**："土主脾胃"——直接给出土星→脾胃的五行对应。

**定量化思考**：土星在疾厄宫的病候有**多发性**——"多树华哑双睛翳，不是驼腰必病脾"——不是单一病而是**多病并发或二选一**。可形式化为：
```
病候集 = {喑哑, 目翳, 驼腰, 脾病}
土星在疾厄宫 ∧ 凶星焰焰 → 病候集非空（至少一个病候命中）
```
"不是...必..."的句式暗示**排他性选择**——不是A就是B，是**二选一**逻辑而非同时发生。

### 规则 4：金星照疾厄宫

> 疾厄金临本是良，英雄气概少灾殃。若教火孛来郊会，骨痛筋疼不可当。

| 形式化五问 | 回答 |
|---|---|
| **算子** | 临/郊会（金星落入疾厄宫=本良；火孛来郊会=条件凶化） |
| **输入** | 金星位置 ∈ 疾厄宫（第八宫）；火星和月孛是否同宫/三合（郊会） |
| **输出** | 本良→英雄气概少灾殃；火孛郊会→骨痛筋疼不可当 |
| **可求值** | ✅ 是。判定金星是否在第八宫 + 火孛是否郊会 → 输出良/凶判定 |

**开放性发现**：**郊会**——新算子变体。"郊"在七政四余中指同宫或三合方位相遇，"会"指合相。**郊会 = 空间接近性判定**，不同于简单的"同宫"，可能包括三合对照。

### 规则 5：水德（水星）照疾厄宫

> 第八官中水德临，温柔情性足人钦。忌星凶曜来侵犯、沈溺波涛坠井深。

| 形式化五问 | 回答 |
|---|---|
| **算子** | 临/侵犯（水德落入第八宫=吉；忌星凶曜侵犯=条件凶化） |
| **输入** | 水星位置 ∈ 疾厄宫（第八宫）；忌星凶曜是否侵犯 |
| **输出** | 本吉→温柔情性足人钦；忌星侵犯→沈溺波涛坠井深 |
| **可求值** | ✅ 是。判定水星是否在第八宫 + 忌星是否侵犯 → 输出吉/凶判定 |
| **与规则库一致** | ✅ 水星本吉（温柔多智），但被凶星侵犯则凶化为水难（沈溺波涛）。水难与水星属性直接对应——水星凶化时主水厄 |

**全息思考**：水星在疾厄宫被凶星侵犯→"沈溺波涛坠井深"——**星曜凶化时回归其五行本厄**。水星→水厄（溺亡），火星→血厄（血难），土星→脾厄（脾胃病）。这与八字中"十神凶化回归本气"的模式同构：**凶化 = 回归五行本源的危险面**。

**注**：此规则与规则1均为水星，但角度不同——规则1强调"解散"（化解灾厄的正面能力），规则5强调"温柔"（本性吉但被凶星侵犯则水厄）。可能是同一水星的两个面向，也可能是 OCR 导致的木星缺失后水星重复。

### 规则 9：月孛照疾厄宫

> 疾厄宫中月李来，少年伏剑染非灾。草事不闻年岁久，近来常听哭声哀。

| 形式化五问 | 回答 |
|---|---|
| **算子** | 来（月孛落入疾厄宫，OCR"月李"应为"月孛"） |
| **输入** | 月孛位置 ∈ 疾厄宫（第八宫） |
| **输出** | 凶——少年伏剑（非正常死亡）、非灾；久无音信、近来哭声哀 |

**时代性思考**："少年伏剑染非灾"——古代"伏剑"指自刎或战死。在现代社会，可映射为：

- 青年时期突发性疾病
- 暴力事件受害

**星象是条件不是宿命**：月孛在疾厄宫提示**少年期健康风险偏高**，需注意安全防护和定期体检，而非宿命式的"非灾"。

### 规则 10：罗喉照疾厄宫

> 天首罗喉第八宫，世间何事比其凶。直饶食禄重重贵，面日须防有病玫。

| 形式化五问 | 回答 |
|---|---|
| **算子** | 照/守/防（罗喉落入疾厄宫，世间最凶） |
| **输入** | 罗喉位置 ∈ 疾厄宫（第八宫） |
| **输出** | 极凶——世间无比之凶；即使食禄重重贵→面/口（"面日"疑为"面目"或"面口"）须防有病（"病玫"疑为"病疾"或"瘢痕"） |
| **可求值** | ✅ 是。判定罗喉是否在第八宫 → 输出极凶+面疾判定 |
| **与规则库一致** | ✅ 罗喉为天首凶曜，在疾厄宫主极凶。与兄弟宫罗喉"悖逆乖为"、妻妾宫罗喉"灾屯孤寡"方向一致——罗喉在各宫均主大凶 |

**定量化思考**："世间何事比其凶"——这是**最高级凶性描述**，暗示罗喉在疾厄宫的凶度是所有星曜在疾厄宫中最高的。可建立**凶度排序**：
```
罗喉在疾厄宫 = 凶度最高（世间无比）
月孛在疾厄宫 = 凶度次高（少年非灾）
火星在疾厄宫 = 凶度高（血难）
土星在疾厄宫 = 凶度中（多病并发）
```

### 规则 11：计都照疾厄宫

| **输出** | 凶→多刑克；吉曜加临→无病却为衣食道（以疾厄宫为谋生之道） |
| **可求值** | ✅ 是。判定计都是否在第八宫 + 吉曜是否加临 → 输出刑克/衣食道判定 |

## 定量化思考

### 1. 疾厄等级量化模型

11条规则的吉凶分布：

| 等级 | 星曜 | 判定 | 凶度 |
|---|---|---|---|
| 吉（无条件） | 紫炁 | 解灾免祸、寿延 | -2（最吉） |
| 吉（本良，条件凶化） | 水星(1) | 解散免灾、财禄润泽 | -1 |
| 吉（本良，条件凶化） | 金星 | 英雄气概少灾殃 | -1 |
| 吉（本良，条件凶化） | 水德(5) | 温柔情性足人钦 | -1 |
| 吉（本良，条件凶化） | 太阳 | 身体康宁福自生 | -1 |
| 吉（本良，条件凶化） | 太阴 | 毕世灾危杳不闻 | -1 |
| 凶（条件减轻） | 火星 | 血难非命，无恶煞则减轻 | +2 |
| 凶（条件凶化） | 土星 | 多病并发（喑哑/目翳/驼/脾） | +2 |
| 凶 | 月孛 | 少年伏剑非灾 | +3 |
| 极凶 | 罗喉 | 世间何事比其凶 | +4（最高） |
| 凶（可转化） | 计都 | 多刑克，吉曜加临则转衣食道 | +2→0 |

**发现**：疾厄宫的吉凶分布比兄弟宫更**两极化**——6星本吉（条件凶化），5星本凶。吉星需要"无凶星侵犯"才能保持吉性，一旦被凶星侵犯则凶化。这说明**疾厄宫是一个"条件敏感"宫位**——吉凶高度依赖星曜组合条件。

### 2. 条件凶化模式量化

本段出现**统一的条件凶化模式**：
- 水星(5)：忌星凶曜来侵犯 → 沈溺波涛
- 金星：火孛来郊会 → 骨痛筋疼
- 太阳：忌星多犯克 → 反伤眼目
- 太阴：忌曜莫郊同此位 → 双眸月遮云
- 火星：恶煞不犯 → 厄减轻（反向条件）

**形式化**：
```
吉星在疾厄宫:
  无凶星侵犯 → 保持吉性（本良效果）
  有凶星侵犯 → 凶化（回归五行本厄或对应器官受损）
```

**凶化目标与星曜本性的对应**：
| 吉星 | 本性 | 凶化后果 | 对应关系 |
|---|---|---|---|
| 水星 | 水/智 | 沈溺波涛 | 水→水厄 |
| 金星 | 金/义 | 骨痛筋疼 | 金→骨筋（金主筋骨） |
| 太阳 | 火/光 | 眼目不光明 | 日→眼目（日主眼） |
| 太阴 | 水/明 | 双眸月遮云 | 月→眼目（月主眼） |

**发现**：**凶化后果 = 星曜本性对应的器官/五行厄**。这是"全息对应"的体现——星曜的吉凶不是任意的，而是与其五行本性严格对应。

### 3. 恶煞乘数模型

火星规则中"恶煞不犯厄减轻"首次明确给出**恶煞对凶度的乘数效应**：
```
实际凶度 = 基础凶度(星曜×宫位) × 恶煞乘数
- 有恶煞: 乘数 = 1.0（满凶度）
- 无恶煞: 乘数 = 0.4-0.6（减轻）
```

这与兄弟宫中"吉星遇着甚相宜，只恐中间恶曜随"的**条件修饰模式**一致，但方向相反——兄弟宫是"吉星+恶曜→吉转凶"，疾厄宫是"凶星+无恶煞→凶减轻"。

## 开放性思考

### 新算子发现：郊会

规则4金星"若教火孛来郊会"和规则7太阴"忌曜莫郊同此位"中出现**"郊"**——这不是普通的"照/临/守"，而是指**星曜在空间上的接近性相遇**。

**"郊"的形式化**：
- 输入：(星曜A位置, 星曜B位置)
- 输出：布尔值——A与B是否"郊"（同宫或三合方位接近）
- 语义：比"同宫"更宽泛，可能包括三合对照

**与已有算子的关系**：
- 照：单星→宫位（1对1）
- 郊：星→星（1对1的空间接近性）
- 会：星→星合相（1对1的精确合相）
- 郊会 = 郊 + 会 = 空间接近性 + 合相（复合算子）

**待发现**：郊与同宫/三合/对照的精确关系需要从更多规则中验证。

### 新概念发现：星曜-器官对应

本段首次系统性地展现**星曜与人体器官的对应关系**：
- 太阳 → 眼目（"反伤眼目不光明"）
- 太阴 → 双眸（"双眸浑似月遮云"）
- 土星 → 脾胃（"土主脾胃"、"必病脾"）
- 火星 → 血（"忧血难"）
- 金星 → 骨筋（"骨痛筋疼"）
- 水星 → 水/溺（"沈溺波涛坠井深"）

**待发现**：完整的星曜-器官对应表。当前6星有明确器官对应，紫炁/月孛/罗喉/计都的器官对应尚未在本段明确出现。

### 新概念发现：凶星转化模式

规则11计都"若逢吉曜更加临，无病却为衣食道"——**凶星遇吉曜不仅减轻凶性，更转化为正面能力**。计都的"刑克"能量在吉曜加持下变为"衣食道"（以疾厄领域为谋生手段）。

**形式化**：
```
凶星在疾厄宫:
  无吉曜 → 凶（刑克）
  有吉曜 → 转化（凶性→生计能力）
```

这与八字中"七杀有制化为权""伤官配印化为贵"的模式同构——**凶煞力量在有制化条件下转为正用**。

### 新概念发现：高强位

规则8紫炁"解灾脱难鼓高强"——"高强"指宫位的**强弱状态**。疾厄宫本是"次弱之宫"（规则11），但紫炁在高强位时解灾效果更强。

**待发现**：宫位高强/次弱的判定标准。当前已知疾厄宫=次弱，但"高强"是宫位本身的属性还是星曜在宫位中的状态？

### 2. 卷三·论疾厄的理论阐释

《星平会海》卷三"论疾厄"（第174-182行）：
> "八煞之宫，非特主人疾厄，亦主人一生操权。"

**对照**：
- 卷三"火罗计孛...诸凶并会→重疾" ↔ 卷一火星"血难"、罗喉"世间何事比其凶"、月孛"少年伏剑"、计都"多刑克"

- 卷三"八煞...亦主人一生操权" ↔ 卷一计都"无病却为衣食道"（煞宫转化为权力/生计）

**结论**：卷三论疾厄是卷一星曜照宫歌疾厄段的**理论阐释**。卷一给出"11星→疾厄宫→具体病候"的歌诀，卷三给出"八煞宫的本质属性+判断方法论"。两者形成**歌诀-理论**的互补结构。

| 星曜 | 星平会海器官 | 中医五行 | 八字十神对应 |

吉星在疾厄宫被凶星侵犯→凶化→回归五行本厄。这与八字中"用神被克→回归本气之凶"的模式同构：

- 星平：水星被忌星犯→温柔凶化→水厄（沈溺）

**底层模式**：**吉性是"克制"状态，凶化是"释放"状态**。吉星被凶星侵犯=克制被解除=五行本厄释放。

## 时代性思考

### 1. "血难"在现代社会的兑现

火星在疾厄宫主"血难"——古代指刀伤、战伤、血疾（肺痨等）。在现代：
- 外科手术（主动"血难"）
- 心血管疾病（高血压、心脏病）
- 血液系统疾病
- 交通事故伤害

**时代性修正**：古代"血难"=致命性出血，现代"血难"=可干预的循环系统疾病。能量单位不变（火=血=急症），但医疗进步使"非命祸难禁"的凶度大幅降低。

### 2. "少年伏剑"的当代解读

月孛在疾厄宫主"少年伏剑染非灾"——古代指少年死于非命（战死、自刎、意外）。在现代：
- 青少年意外伤害（交通事故最高）
- 青年期突发疾病
- 心理健康危机

**星象是条件不是宿命**：月孛在疾厄宫提示少年期健康风险偏高，需加强安全教育和定期体检。古代的"伏剑"在现代可以转化为"对危险的高度警觉"。

### 3. "多疾贫苦"的社会学映射

释云"多疾贫苦"——疾病导致贫困。这在古代和现代都是**普遍的社会学规律**：
- 古代：疾病→丧失劳动能力→贫困
- 现代：重大疾病→医疗支出→因病致贫

**时代性差异**：现代社会有医疗保险体系，"多疾贫苦"的因果链可以被社会保障部分截断。但在缺乏保障的环境中，这条因果链依然有效。**星象揭示的是结构性风险，社会保障是人为干预手段**。

### 4. "衣食道"的现代职业映射

计都在疾厄宫逢吉曜→"无病却为衣食道"——以疾厄相关领域为谋生手段。古代指：
- 医者、药师
- 僧道（以宗教消解疾厄）
- 殡葬业

现代可扩展为：
- 医疗健康行业（医生、护士、药剂师）
- 心理咨询
- 保险业（健康险/意外险）
- 殡葬服务业
- 康复理疗

**时代性扩展**：古代"衣食道"范围窄（医、僧、殡），现代范围宽（整个大健康产业）。计都的"刑克"能量在现代社会有更多正面出口。

## SOP 汇报三要素

### 维度汇报

**新算子发现**：
1. **郊/郊会**（规则4、7）：星曜间空间接近性判定算子。输入=(星曜A,星曜B)，输出=是否"郊"（同宫或三合方位接近）。比"同宫"更宽泛，与"会"（合相）复合为"郊会"。与已有"照"（星→宫）不同，"郊"是星→星的关系算子。
2. **守**（规则11）：计都"守此"——"守"比"照/临"更强调**持续驻留**的语义。输入=(星曜,宫位)，输出=星曜是否持续驻留该宫。与"照"（经过/照临）有时态差异。
3. **犯克**（规则6）：忌星"犯克"太阳——凶星对吉星的**主动攻击性**算子。输入=(忌星,目标星)，输出=是否犯克。与"郊"（中性接近）不同，"犯克"带有方向性和敌意。

**新维度发现**：
1. **星曜-器官对应维度**：太阳→眼目、太阴→双眸、土星→脾胃、火星→血、金星→骨筋、水星→水/溺。这是首次系统性展现星曜与人体器官的对应映射，需建立完整的"星曜-器官"对照表（当前6/11星有明确对应）。
2. **凶化回归本厄维度**：吉星被凶星侵犯→凶化→回归五行本厄（水星→水厄、金星→骨筋厄、日→目厄、月→目厄）。这是"凶化=释放五行本源危险面"的系统性模式。
3. **凶星转化维度**：计都遇吉曜→"无病却为衣食道"——凶星遇吉不仅减凶，更转化为正面能力。与八字"七杀有制化为权"同构。
4. **恶煞乘数维度**：火星"恶煞不犯厄减轻"——恶煞对凶度有乘数效应（有→满凶，无→减轻）。

**已有维度验证**：
- 算子维度：照/临/来/守/犯克/郊/郊会/解/免——9种算子变体，其中"郊/郊会""犯克"为新发现
- 集合维度：11星曜×疾厄宫=11条规则，集合完整（注：水星重复、木星缺失，疑OCR问题）
- 命题维度：吉凶二分+条件凶化+条件转化——三层判定结构

### 成熟度汇报

- **覆盖率**：已提升——从兄弟宫（auto.40）、田宅宫（auto.41）的星曜照宫，扩展到疾厄宫的11星照宫。星曜照宫歌已完成8/12宫=66.7%。新增"星曜-器官对应"维度，从纯命理判定扩展到医学映射领域。
- **一致性**：已验证——11条规则之间无矛盾。6吉星本良+条件凶化，5凶星本凶+条件减轻/转化，与卷三"火罗计孛诸凶并会→重疾""八煞主守照得所→主贵"完全一致。与已有规则库（命宫/财帛宫/兄弟宫/田宅宫）的"照"算子体系一致。星曜-器官对应与中医五行-脏腑体系一致。
- **可求值性**：已实现——11条规则全部可求值。给定星盘实例，判定各星曜是否在第八宫 + 条件修饰（凶星侵犯/吉曜加临/恶煞有无）→ 输出疾厄判定。条件凶化规则（水星忌星侵犯→水厄、金星火孛郊会→骨筋疼、太阳忌星犯克→伤目、太阴忌曜同郊→目模糊）均可求值。

### 可计算性汇报

- **形式可计算**：已实现——11条规则的算子、输入、输出全部明确，可算法化。`qizheng/core.py` 中 `calc_all_bodies()` 可计算各星曜宫位，`calc_dignity()` 可计算庙旺状态。新增"郊会"算子需实现星曜间三合/对照判定（当前代码有 `degree_gap()` 可支撑）。
- **定量可计算**：待建设——疾厄等级量化模型（凶度排序+恶煞乘数）需要建立完整的"星曜×宫位×条件→凶度值"映射表。星曜-器官对应表需要从6星扩展到11星。这些在当前代码中尚未实现。
- **推演可计算**：部分实现——条件凶化的推理链可形式化为决策树（吉星→有无凶星侵犯→吉/凶化→具体病候）。但"郊会"算子的精确空间判定（同宫 vs 三合 vs 对照）需要从更多规则中验证后才能实现。
- **暂时不可计算**：星曜-器官完整映射——当前仅6星有明确器官对应，紫炁/月孛/罗喉/计都的器官对应尚未在本段明确出现，需从其他段落或典籍中补充。凶化回归本厄的完整模型需要验证更多宫位的规则后才能确认。
