# 51 · AGENTS.md 重构方案

**创建时间**：2026-08-03
**状态**：待用户审阅
**目的**：将 AGENTS.md 从"工程开发阶段"重构为"学习阶段"，推出工程细节到外部文档，保留认知层和实践关键信息

---

## 一、论证

### 1.1 问题陈述

AGENTS.md 当前 1884 行，是 always-on 加载的——每个 session 启动时全文注入。问题在于，它是工程开发阶段积累的产物：约 1200 行是 Master-Worker 架构、脚本调用关系、审计流程、Worker 提示词设计、TODO 管理工具等工程细节。2026-08-03 项目方向转向学习七政四余认知后，这些工程细节：

1. **稀释认知层内容**——形式化思维、解释框架、铁板神数时代性这些真正帮助理解七政四余的内容，被夹在 800 行工程细节中间，难以被 AI session 优先注意到
2. **增加上下文负担**——约 1200 行工程细节在每次 session 中 always-on，学习阶段用不到，挤占了可用于学习和对话的上下文空间
3. **模糊项目当前重心**——读者会以为项目还在工程开发阶段，而不是已经转向认知积累

### 1.2 重构原则

AGENTS.md 应该是**跨 session 的认知一致性保证**，不是工程手册。它的核心职责是：

- 让新 session 的 AI 快速理解"项目是什么、为什么、当前在做什么"
- 让 AI 在学习和实践七政四余时，能找到正确的思维方法和工作模式
- 让 AI 能定位到所有详细文档，但不把详细文档的内容全部内联

工程细节不丢——全部迁移到 dev-docs/ 的专门文档中，AGENTS.md 保留索引指针。
