## 1. 题海战术的总思路

为评测AI数学能力，需要从两个维度获取题海：

1. **抗污染维度**：AI训练数据中罕见的题（日文/中文老书、未公开竞赛题）——定位AI的真实推理能力而非记忆能力
2. **大规模快速测试维度**：数据干净、直接可用的电子化题库（JSON/Parquet/LaTeX）——快速定位AI在各数学领域的能力分布

两类来源互补。纸质来源适合抗污染，电子化来源适合大规模快速测试。

## 4. ArangoDB数据库——数据集详情入口

**所有数据集的详细信息都在ArangoDB中，不在本文档重复。**

- **数据库**：`xishujuzhen_math_glm52`
- **集合**：`math_datasets`

- **完整目录JSON**：`knowledge/problem_banks/math_datasets_catalog_v2.json`

### 4.1 Schema（9类字段）

```
1. 标识:       repo_id, platform, title, doc_id
2. 价值描述:   description, unique_value, notes
3. 内容属性:   problem_count, data_size, format, source_type, math_domain,
              difficulty_level, has_solutions, solution_format, year_range
4. 来源归属:   institution, publisher, language, country
5. HF/GitHub:  downloads, likes, tags, task_categories, size_categories,
              license, last_modified, created_at, tier
6. 获取:       url, access_method, access_difficulty
7. 下载状态:   download_status, download_date, local_path, local_size,
              file_count, download_notes
8. 项目相关:   priority, test_layer, anti_contamination, ai_baseline_score
9. 入库管理:   ingest_source, ingest_date, last_updated
```

### 4.2 常用查询

```python
from arango import ArangoClient
client = ArangoClient(hosts='http://localhost:8529')
db = client.db('xishujuzhen_math_glm52', username='root', password='REDACTED-DB-PASSWORD')

# 已下载完成的数据集
db.aql.execute('FOR d IN math_datasets FILTER d.download_status == "completed" RETURN {title: d.title, path: d.local_path, size: d.local_size}')

# Tier 1核心题库（按下载量排序）
db.aql.execute('FOR d IN math_datasets FILTER d.tier == 1 SORT d.downloads DESC RETURN d')

# 有题量信息的竞赛题库（按题量排序）
db.aql.execute('FOR d IN math_datasets FILTER "competition" IN d.source_type AND d.problem_count != null SORT d.problem_count DESC RETURN {title: d.title, count: d.problem_count}')

# 适合抗污染测试的数据集
db.aql.execute('FOR d IN math_datasets FILTER d.anti_contamination == true RETURN {title: d.title, desc: d.description}')

# 形式化数学数据集
db.aql.execute('FOR d IN math_datasets FILTER "formal" IN d.source_type RETURN {title: d.title, desc: d.description, url: d.url}')
```

## 5. 题海战术执行方案

### 5.1 分层测试策略

```
第一层：抗污染测试（纸质来源 · AI没见过的题）
  → 笹部系列15000题 + 吉米多维奇5000题
  → 定位AI在"没见过的题"上的真实能力

第二层：大规模快速测试（电子化来源 · 数据干净）
  → MathNet 30K竞赛题 + NuminaMath 11万证明题
  → 定位AI在竞赛数学各领域的能力分布

第三层：抗污染+时间戳验证（AoPS-Instruct）
  → LiveAoPSBench按时间戳分割
  → 检测AI是否因预训练暴露而"假会"

第四层：研究级（丘成桐+Berkeley+ConjectureBench+FATE）
  → 定位AI在研究级问题上的能力边界
  → ConjectureBench测试猜想提出能力
  → FATE测试形式化代数证明（最强模型0%）

第五层：竞赛最难题（CMO/JMO/KMO/IMO P6）
  → compfiles提供Lean 4形式化验证
```

### 5.2 执行流程

```
Phase 1: 下载（当前进行中）
Phase 2: 数据预处理（电子化直接加载，纸质OCR）
Phase 3: Baseline测试（5个sub agent并行，每题3次，SymPy+Lean验证）
Phase 4: 分析（生成AI能力边界图谱）
Phase 5: 进入系统引导实验池
```
