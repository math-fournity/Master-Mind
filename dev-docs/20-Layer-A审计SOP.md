## 一、审计流程（5步）

### Step 1：审计准备
- 确认TODO依赖已满足（20.1/20.2等）
- 明确审计项编号（A27-A29/A30等）
- 确定参考文献位置（dev-docs/原典/）

### Step 2：搜索原文
- 使用Exa/Serper/Jina搜索术语定义
- 获取权威原文段落
- 记录来源（书名/卷号/章节）

### Step 3：对照实现
- 检查Java MOIRA原版实现（base/目录）
- 检查Python当前实现（qizheng/core.py）
- 对比两者差异

### Step 4：记录发现
- 按统一格式写入考据记录（dev-notes/AUDIT-LAYER-A-xx.md）
- 判定：✅一致 / ⚠️部分一致 / ❌不一致 / ❓无法确认
- 如有修正建议，明确记录

### Step 5：状态同步
- 更新TODO状态：`python3 todo.py update <id> --status completed --result "..." --commit <hash>`
- 更新AGENTS.md审计日志
- Git提交：`git add <files> && git commit -m "audit: ..."`
