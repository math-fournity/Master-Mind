## 0 · 使用说明

- **状态标记**：`[ ]` 待执行 / `[~]` 进行中 / `[x]` 已完成 / `[!]` 阻塞
- **优先级**：P0=阻塞后续 / P1=高 / P2=中 / P3=低
- **验收标准**：每条 item 必须有可客观判定的完成条件
- **执行顺序**：Phase 5 → 6 → 7 → 8 → 9，但 Phase 6/7 可与 Phase 5 后半段并行
- **更新规则**：完成一条立即标记 `[x]` 并记录完成日期；发现新问题追加 item
