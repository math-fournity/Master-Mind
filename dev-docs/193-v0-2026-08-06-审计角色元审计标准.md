## 一、模块功能概览

auditor子系统是审计角色本身——审计其他模块的输出，执行盲评，管理能力令牌和可见性标签。

| 模块 | 功能 |
|---|---|
| auditor | 审计角色，接收9类输入，输出7项裁决，不参与Hint设计或Solver答题 |
| blind_evaluator | 盲评流程，打乱运行顺序隐藏处理组标签，评分后揭晓检查盲评完整性 |
| capability_tokens | 能力令牌，8字段令牌实现collection级/字段级/写入控制/运行隔离/自动失效 |
| visibility_labels | visibility label检查器，8角色×14collection可见性矩阵 |

## 二、审计检查项

### 2.1 审计角色独立性（auditor.py）

| 检查项 | 说明 | 标准 |
|---|---|---|
| 不参与Hint设计 | Auditor不设计Hint | 无Hint设计操作 |
| 不参与Solver答题 | Auditor不答题 | 无答题操作 |
| 7项裁决完整 | 泄漏/越过卡点/数学进展/语言重复/副作用/归因/规则生命周期 | 7项都有输出 |
| truth_vault仅auditor可读 | 只有Auditor能读truth_vault | 其他角色无访问权限 |
| 规则升validated条件 | 需DYN-3通过+泄漏门通过 | 两个条件都满足 |
| 9类输入 | frozen_manifest/treatment_assignments/actual_hints/pre_post_states/outputs/ground_truth/tool_evidence/hashes/isolation_records | 9类输入都有接收 |

**判定**：通过=6项全通过；有缺陷=7项裁决有小遗漏；失败=Auditor参与了Hint设计或答题或truth_vault被越权访问

### 2.2 盲评完整性（blind_evaluator.py）

| 检查项 | 说明 | 标准 |
|---|---|---|
| 评分者不知处理组 | 打乱顺序隐藏标签 | 评分时不知道哪些run接受了哪些Hint |
| 角色隔离 | 同一Master不同时持有答案/设计Hint/运行Solver/评分 | 4个角色不重叠 |
| 猜对率<50% | 猜对率应低于50% | 猜对率高说明盲评失效 |
| 揭晓后检查 | 评分后揭晓并检查盲评完整性 | 有完整性验证 |

**判定**：通过=4项全通过；有缺陷=打乱了但猜对率高；失败=评分者知道处理组或角色重叠

### 2.3 能力令牌（capability_tokens.py）

| 检查项 | 说明 | 标准 |
|---|---|---|
| collection级控制 | 令牌定义可读collection | granted_collections生效 |
| 字段级控制 | 令牌定义可读字段 | granted_fields生效 |
| 写入控制 | 令牌定义可写collection | write_collections生效 |
| 运行隔离 | 令牌绑定run_id | 不同run的令牌不互通 |
| 自动失效 | expires_at过期自动失效 | 过期令牌不可用 |
| truth_vault仅auditor | truth_vault只在auditor令牌中 | 其他角色令牌无truth_vault |

**判定**：通过=6项全通过；有缺陷=控制生效但失效机制缺失；失败=令牌可跨run使用或truth_vault被越权

### 2.4 可见性标签（visibility_labels.py）

| 检查项 | 说明 | 标准 |
|---|---|---|
| 8角色×14collection矩阵 | 矩阵完整定义 | 8×14=112个条目 |
| truth_vault隔离 | truth_vault仅auditor可读 | 其他角色不可读 |
| R/W区分 | 区分读和写权限 | access_type=R或W |
| 角色边界落实 | 落实为collection和visibility label | 不只写在prompt里 |

**判定**：通过=4项全通过；有缺陷=矩阵完整但R/W不区分；失败=truth_vault被其他角色读取或矩阵不完整

## 三、已细化项

1. **7项裁决判定标准**：LEAKAGE(泄漏), PASSED_STALL(越过卡点), MATH_PROGRESS(数学进展), LANGUAGE_REPETITION(语言重复), SIDE_EFFECT(副作用), ATTRIBUTION(归因), RULE_LIFECYCLE(规则生命周期)（auditor.py:22-29）
2. **14个collection完整列表**：tasks, workspaces, raw_events, semantic_events, obligations, evidence, representations, heuristic_rules, activation_packets, truth_vault, manifests, audit_verdicts, dg_nodes, dg_edges（visibility_labels.py:61-66）
3. **盲评猜对率计算**：guess_rate=n_correct/len(results)，integrity_ok当guess_rate<0.5（blind_evaluator.py:116-124）
4. **能力令牌过期时间**：expires_at字段，通过is_expired()检查（capability_tokens.py:35, 51-56）
5. **元审计自举问题**：代码中未定义解决方案，需后续设计
