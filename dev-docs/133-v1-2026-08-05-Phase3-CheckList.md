# 133-Phase 3 Check List：离线候选启发

> **文档定位**：从124号拆出的Phase 3独立Check List。Phase 3目标——发现候选规则，但绝不在线自动提示。
>
> **入口门**：Phase 2出口门全部通过（132号P2-EXIT-1/2/3）。
>
> **出口门**：至少一个候选在多个运行中可重复匹配，且Hint不唯一确定答案。
>
> **来源追溯**：123号§48 + §21(启发规则定义) + §23(最小提示受约束多目标选择)；系统探讨.md§16(Phase 3) + §10(H图稀疏结构)；plan"新Phase 3：状态对齐、候选时序模式—动作规则，禁止在线发布"
>
> **措辞规范**：本Check List已按140号诊断后的Check List措辞规范标注实现深度等级（D1-D4）+ 边界情况清单 + 覆盖标准。勾选格式：`[D1]/[D2]/[D3]/[D4]/[ ]`。
