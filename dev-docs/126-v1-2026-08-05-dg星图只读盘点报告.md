## 2. P0-3.1：type/label/edge_type/graph分布

### 2.1 dg_nodes type分布

| type | 数量 | 占比 |
|---|---|---|
| concept | 867 | 50.4% |
| domain_concept | 599 | 34.8% |
| paradigm | 165 | 9.6% |
| problem | 53 | 3.1% |
| substep | 27 | 1.6% |
| 意识 | 5 | 0.3% |
| step | 3 | 0.2% |

**观察**：
- `concept`和`domain_concept`合计占85.2%，是知识库主体
- `paradigm`（范式级跨领域映射）占9.6%，是L3范式思维的体现
- `意识`节点只有5个，对应5个数学意识（不变量/局部-全局/逼近论/极端检验/数值检验）
- `step`/`substep`只有30个，是POC-1/POC-2的矩条件极差题解题步骤节点
- `problem`有53个，是题库中的题目节点

### 2.2 dg_edges edge_type分布

| edge_type | 数量 | 占比 |
|---|---|---|
| unknown | 1431 | 96.5% |
| depends_on | 38 | 2.6% |
| calls | 13 | 0.9% |
| invokes | 1 | 0.1% |

**重要发现**：96.5%的边`edge_type`为`unknown`。真实的边类型信息存储在`mapping_type`字段中，不在`edge_type`字段。这是一个schema设计问题——`edge_type`字段未被大规模使用，`mapping_type`才是实际承载边语义的字段。

### 2.3 dg_edges mapping_type分布（实际边语义）

| mapping_type | 数量 | 说明 |
|---|---|---|
| solution_path | 837 | 解法路径边（题库主体） |
| invokes | 259 | 调用关系 |
| structural_analogy | 136 | 结构类比 |
| equivalence | 87 | 等价关系 |
| generalization | 30 | 泛化关系 |
| specialization | 13 | 特化关系 |
| identification | 15 | 识别关系 |
| 其他（各1-3条） | ~50 | 多种细粒度映射类型 |
| none | 52 | 无mapping_type |

**观察**：`mapping_type`字段有40+种值，远比`edge_type`丰富。这反映了题库建设过程中从多题多解中提取的细粒度跨领域映射关系。

### 2.4 loops graph分布

| graph | 数量 |
|---|---|
| dependency_graph | 2 |
| unfold_topo | 2 |

**观察**：4个环路，2个在依赖图中，2个在展开图中。对应POC-1/POC-2的2个螺旋环路（极端检验↔数值检验意识）。

## 3. P0-3.2：五类初步归类

按123号第十四节的五类（is_knowledge/is_trace/is_heuristic/is_evidence/is_execution）对`dg_nodes`做初步归类。当前数据没有显式的五类标签，以下按`type`字段做映射：

| 五类 | 对应type | 数量 | 说明 |
|---|---|---|---|
| knowledge | concept, domain_concept, paradigm, problem, step, substep | 1714 | 知识节点（含概念、范式、问题、步骤） |
| heuristic | 意识 | 5 | 启发意识节点 |
| trace | — | 0 | 无轨迹节点（Phase 1才建） |
| evidence | — | 0 | 无证据节点（Phase 1才建） |
| execution | — | 0 | 无执行节点（Phase 1才建） |

**观察**：当前`dg_*`集合完全是知识图（K视图），没有T（轨迹）、H（启发规则的效果证据）和E（执行）节点。这符合Phase 0之前的状态——只有静态知识图，没有事件溯源运行时。

## 4. P0-3.3：Schema字段清单

### 4.1 dg_nodes字段

| 字段 | 类型 | 说明 | 覆盖率 |
|---|---|---|---|
| `node_id` | string | 节点标识符（中文或英文） | 100% |

### 4.2 dg_edges字段

| 字段 | 类型 | 说明 | 覆盖率 |
|---|---|---|---|
| `_from` | string | ArangoDB内部from引用 | 100% |
| `_to` | string | ArangoDB内部to引用 | 100% |
