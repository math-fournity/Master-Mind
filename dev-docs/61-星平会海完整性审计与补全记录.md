# 61 · 星平会海完整性审计与补全记录

## 1 · 缘起

2026-08-03，项目吸收范围收敛到《星平会海》和《星学大成》两部典籍。星学大成已有 epub 版转换为结构化 Markdown（34 个 md 文件，1.2MB）。星平会海原有资料是从 suanzhun.net 抓取的 10 卷 txt，但完整性未经审计。

用户提出关键问题："星平会海，如何确定我们要处理的是完整版呢？"

本文档记录审计过程、发现的问题、补全操作和最终验证结果。

## 2 · 原书版本信息

### 内容结构

- **卷首**：星命基础理论（三才妙论、太阳太阴行度、十一曜二十八宿、四余变曜、格局分野、限运理论等）

- **卷六~卷十**：子平命理（八字）——八字基础、赋文、女命、经典、格局

## 3 · 审计方法论

### 步骤

1. **获取权威篇目列表**：从四库全书总目提要、书墨居古籍网、豆瓣、方广古籍网等多个来源，提取完整的篇目描述
2. **与已有 schema.json 对比**：逐项核对期望篇目 vs 已有 sections
3. **在 txt 中搜索"缺失"篇目**：有些"缺失"实际是名字差异或 OCR 变体，需在原文中搜索确认
4. **定位 suanzhun.net 上的缺失页面**：用 web_search 找到正确的 book ID
5. **补抓并验证**：抓取后再次核对完整性

## 7 · 方法论复用指引

未来如果需要对星学大成或其他典籍做完整性审计，可复用以下流程：

1. **获取权威篇目列表**：从四库全书提要、出版社描述、学术数据库提取
2. **与已有索引对比**：用 schema.json 或目录树逐项核对
3. **搜索"缺失"项**：在已有 txt 中搜索关键词，排除名字差异/OCR 变体
4. **定位源页面**：用 `site:suanzhun.net` 搜索找到正确 book ID
5. **补抓**：复用 `fetch_juanshou.py` 模式（curl + article 提取 + 分页支持）
6. **转换**：复用 `convert_to_structured_md.py`（清理 + 合并 + 加标题层级）
7. **验证**：补抓后再次与权威列表核对，确认全覆盖

### 注意事项

- suanzhun.net 的 book ID 不完全连续（如 1442/1443 是 404，实际内容在 1535/1536）
- 有些篇目在 suanzhun.net 上合并为一页（如"后天口诀/至宝论"）
- 有些篇目分散在多卷中（如"袁天罡小儿关煞"在卷五和卷八各有一部分）
- 网上描述的篇目名可能与原文标题有 OCR 变体差异（如"入"→"人"、"咸"→"成"）
- jina reader 格式的 txt 中可能嵌入 JSON 残留，需要专门清理
