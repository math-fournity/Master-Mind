# 主数据扩展指南

## 1. rules_library.json 扩展
- 每条规则必须包含：id、name、priority、condition、exclude、comment
- 新规则需先用 `core.eval_rules()` 验证零异常
- 模板展开后必须测试

## 2. constants.json 扩展
- dignity_states 补充“殿”状态
- lunar_mansions 宿度可根据岁差微调

## 3. shen_sha_complete.json 扩展
- 从《协纪辨方书》补充择吉神煞

## 4. 验证流程
1. 编辑 JSON
2. 运行 `python -m qizheng` 验证
3. 更新本指南
