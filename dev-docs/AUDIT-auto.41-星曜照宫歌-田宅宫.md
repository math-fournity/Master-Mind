2. **火星入田宅**: 火宿加临第四宫，祖基破尽受贫穷。 若是庙方当发福，不然孤苦一生中。
3. **土星入田宅**: 土星尊位为阳德，高占强官为福泽。 或在当生四杀中，起祸生灾岂能灭。
4. **金星入田宅**: 金星吉曜成奇局，田宅逢之主厚福。 上下加临不见刑， 一世安荣自丰足。
5. **水星入田宅**: 善星一曜是辰星，得入强宫福转精。 不见当年刑忌照，便须万顷与千赢。
6. **太阳入田宅**: 田宅宫中有太阳， 须知安位最高强。 膏腴万顷连阡陌，荣祖荣宗福禄昌。
7. **太阴入田宅**: 太阴田宅若相逢，自喜荣华万事通。 阴贵又增招满益，迁移三处振家风。
8. **紫气入田宅**: 当生紫气四宫行，福荫双亲保寿龄。 看取耆年精力健，都缘强位老人星。
9. **月孛入田宅**: 第四宫中月李临，定遭疫病气相侵。 忧煎失业田庄尽，到老仓箱乏寸金。
10. **罗喉入田宅**: 罗喉天首最凶残，祖业虽多守则难。 可惜田园千万顷，都因凶曜见阑珊。
11. **计都入田宅**: 强宫之上计都侵，福禄消亡祸自深。 祖业到头都不管，空劳计较没身心。

### 2. 定量化分析

#### 程度描述量化思考

1. **"喜庆重"（木星）**: "重"表示程度深。可量化为吉星强度权重——木星入田宅的吉度可设为高权重值。但"重"本身是定性描述，需要引入**吉凶强度向量**来量化。

2. **"福丰隆"（木星）**: "丰隆"表示丰厚隆盛。可考虑用**庙旺等级**（殿/垣/庙/旺/乐/喜/怒）映射到数值权重——庙旺则福丰隆，陷则减。

3. **"祖基破尽"（火星）**: "破尽"表示完全破败。这是**二元判定**（破尽 vs 未破尽），但程度上可量化为破败比例——注释说"逢破败劫从减半"，暗示破败程度可按比例递减。

4. **"厚福"（金星）**: "厚"表示程度深。与"喜庆重"类似，需吉凶强度向量。

5. **"万顷与千赢"（水星）**: "万顷"是夸张修辞，但暗示了**田产规模**的可量化性。古代以顷为单位，现代可映射为资产规模等级。

6. **"膏腴万顷连阡陌"（太阳）**: 同上，田产规模的夸张表达。

7. **"减半"（注释）**: 注释"逢破败劫从减半"——这是一个**明确的定量规则**！破败程度减半，可用乘数 0.5 表达。

#### 量化框架建议

- **吉凶强度向量**: 每颗星入田宅可赋一个基础吉凶值（吉星 +1~+3，凶星 -1~-3），再乘以庙旺修饰符（庙旺 ×1.5，陷 ×0.5）
- **破败递减模型**: 注释"逢破败劫从减半"暗示田宅破败非全有全无，而是按凶星数量和强度递减
- **条件修饰符**: 多条规则含条件子句（"若是庙方""不见刑忌""或在四杀中"），可形式化为 `base_score * condition_modifier`

### 5. 时代性分析

#### 历史背景

- **"田宅昌荣须守祖"**: 古代社会以土地为核心财富，祖业传承是主要经济模式。"守祖"即继承祖产。
- **"膏腴万顷连阡陌"**: 万顷田地是古代顶级富豪的象征。阡陌为田间小路，连阡陌即田地连片。
- **"荣祖荣宗"**: 光宗耀祖是古代社会的核心价值——个人成功体现为家族荣耀。
- **"仓箱乏寸金"**: 仓箱为粮仓，寸金为少量金钱——到老粮仓空、无积蓄。

#### 现代诠释

- **"田宅昌荣"** → 不动产投资顺利、房产增值
- **"祖基破尽"** → 家庭经济基础薄弱、无继承资产
- **"膏腴万顷"** → 大规模资产持有、多元化投资
- **"福荫双亲保寿龄"** → 父母健康长寿、家庭关系和谐
- **"仓箱乏寸金"** → 老年经济困窘、储蓄不足

#### 时代性思考

- 古代"田宅"=土地+房屋，现代"田宅"=不动产+投资资产+家庭根基
- "守祖"在古代是继承土地，在现代可能是继承家族企业/资产
- "破败"在古代是失去土地，在现代可能是破产/投资失败
- 星象是条件不是宿命——现代人有更多工具管理资产风险，"火入田宅"不必然等于破产，而是提示需谨慎管理不动产

## 规则库一致性检查

### 与现有 rules_library.json 的关系

现有规则库（283条）中与田宅相关的规则：

| 规则ID | 名称 | 与照宫歌关系 |
|---|---|---|
| 86 | 日月拱田 | 拱算子，非照算子 |
| 87 | 日月夹田 | 夹算子，非照算子 |
| 105 | 田财殿垣 | 殿垣算子，非照算子 |
| 112 | 田守各宫 | 守算子——"田宅宫主星守某宫"，与照宫歌"某星入田宅"方向相反 |
| 256 | 火孛临田 | 火孛同临田宅——与照宫歌火星/月孛入田宅相关但为组合规则 |
| 308 | 田财夹命 | 夹算子 |
| 383 | 禄主临田 | 官禄宫主临田宅——与照宫歌相关但为宫主星规则 |

**关键发现**：现有规则库的"守"算子是"宫主星守某宫"（如田宅宫主守命宫），方向是**宫主→宫位**。而照宫歌的"照/入"算子是**任意星→特定宫**（如木星入田宅），方向是**星→宫**。两者算子方向不同但互补：

- **守** = 宫主星落入某宫（`@{田宅}[1]=@{目标宫}`）
- **照/入** = 任意星落入某宫（`@{星}=@{田宅}` 或 `@{星}[0]=@{田宅}[0]`）

照宫歌的11条规则在现有规则库中**没有直接对应**，属于**新增规则类型**。

### 一致性验证

- 火孛临田（规则256: `@火[0]=@{田宅}[0] & @孛[0]=@{田宅}[0]`）与照宫歌中火星入田宅（凶）+ 月孛入田宅（凶）方向一致——两凶星同临更凶
- 田守各宫（规则112: `@{田宅}[1]=@{}`）与照宫歌不矛盾——一个是田宅主守他宫，一个是他星入田宅
- 禄主临田（规则383: `@{官禄}[1]=@{田宅}`）与照宫歌中太阳入田宅主福方向一致——官禄主（太阳相关）入田宅主福禄

**判定**: 无矛盾。照宫歌规则是现有规则库的**补充类型**（星入宫），与现有守/拱/夹/殿/垣算子正交。

## 发现总结

### 新维度发现

1. **算子维度——"照/入"算子**: 照宫歌的核心算子是"照"（星曜照临某宫），即任意星曜落入特定宫位。与现有"守"算子（宫主星守某宫）方向相反但互补。形式化为 `@{星}[0]=@{目标宫}[0]`（星曜地支=宫位地支）。

2. **条件修饰维度**: 多条规则含条件子句——"若是庙方当发福"（火星）、"不见刑忌照"（水星）、"或在四杀中"（土星）、"不见刑"（金星）。这些条件修饰符可形式化为 `base_rule & condition_modifier`。

3. **邻宫修饰维度**: "上下加临不见刑"（金星）引入了邻宫检查——不仅看本宫，还看前后宫位是否有刑星。这是新算子候选。

4. **流年叠加维度**: "当年刑忌照"（水星）引入了流年叠加——本命吉但流年凶可减福。

5. **破败递减维度**: 注释"逢破败劫从减半"——破败程度可按比例递减，这是定量规则。

### 成熟度提升

- **覆盖率**: 从"宫主星守宫"扩展到"任意星照宫"——覆盖了11星×12宫的完整矩阵（本Section完成11星×1宫=11条）
- **一致性**: 11条照宫规则与现有规则库无矛盾；吉星（木/金/水/日/月/气）入田宅主吉，凶星（火/孛/罗/计）入田宅主凶，与五行生克和星曜本性一致
- **可求值性**: 所有11条规则均可求值（检查星曜地支=田宅宫地支）；含条件子句的规则需额外检查庙旺/刑忌/四杀状态

### 可计算性

- **形式可计算**: 给定星盘，计算各星曜宫位，判定是否落入田宅宫（第四宫）——已可通过 `core.py` 的 `calc_houses()` + 宫位匹配实现
- **定量可计算**: 基础吉凶判定已可实现；但条件修饰符（庙方/刑忌/四杀/上下加临）需额外定义和实现——**待建设**
- **推演可计算**: 可推演大限/流年中星曜是否照临田宅宫——`compute_limits()` 已有限运推演能力
- **暂时不可计算**: "四杀"位置定义不明确；"上下加临"邻宫检查逻辑未实现；"当年刑忌照"流年叠加未实现
