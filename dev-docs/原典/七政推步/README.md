## 与本项目的关系

《七政推步》是明代钦天监回回历法的官方计算白皮书。虽然它是回回历（伊斯兰天文）系统，不是七政四余（中国星命）系统，但：

1. **历史背景**：七政四余的"四余"概念（罗睺/计都/紫炁/月孛）源自印度→阿拉伯天文传入，与回回历有共同的渊源
2. **计算方法参考**：卷1的"释用数例"给出了周天度数划分（360度/12宫/60分/60秒/60微/60纤），与七政四余的度数体系一致
3. **立成表结构**：卷2-7的立成表结构（总年/零年/月分/日分）对理解古代天文计算方法有参考价值
