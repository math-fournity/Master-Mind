# 星平会海结构化版 Markdown 规整化标准

## 任务目标

对 `dev-docs/原典/星平会海-结构化版/` 下的指定卷文件进行完整重整，产出干净、统一、结构清晰的 Markdown 文件。

## 输入

- **原典 txt**：`dev-docs/原典/星平会海/卷X.txt`（suanzhun.net 网页抓取的原始文本，含网页元数据）
- **当前结构化版**：`dev-docs/原典/星平会海-结构化版/0X-星平会海卷X.md`（已有但质量不高的版本）
- **纸质书目录**：`dev-docs/62-星平会海纸质书目录OCR审计与缺失分析.md`（可参考篇目列表）

## 输出格式标准

### 1. 文件结构

```markdown
# 星平会海卷X

---

## 篇目名称1

正文内容...

---

## 篇目名称2

正文内容...

---
```

### 2. 标题层级

- `#` 只用于卷标题（如 `# 星平会海卷四`），每个文件只有一个 `#`
- `##` 用于篇目标题（如 `## 心授玉衡赋`）
- `###` 用于篇目内的子章节（如论十二宫下的 `### 论女命`）
- 不使用 `####` 及以下层级

### 3. 标题格式

- **去除所有后缀**：不要 `-卷X-星平会海`、`-算准网` 等后缀
- **去除网页标题前缀**：不要 `Title:`、`URL Source:` 等
- **去除 `**` 加粗标记**：标题用 `##` 标记，不用 `**篇名**`
- **多个相关篇目**：如果原典中多个篇目合在一个页面（如"日月合格/日月忌格"），用 `/` 连接作为一个 `##` 标题
- **零宽字符**：删除所有零宽字符（`\u200b` `\u200c` `\u200d` `\ufeff`）

### 4. 篇目分割

- 从原典 txt 的 `Title:` 行提取篇目名称和分界
- 每个 `Title:` 行对应一个新篇目的开始
- `Title: 404 Not Found` 表示该页面抓取失败，跳过该篇目（内容缺失）
- `Title: 1579-卷四-星平会海-算准网` 这种只有数字ID的，说明标题在页面内容中，从内容第一行提取

### 5. 正文清理

- **删除所有网页元数据**：`Title:`、`URL Source:`、`Published Time:`、`Markdown Content:`
- **删除导航元素**：`首页 > 典籍 > 星平会海 > 正文`、`上一篇：`、`下一篇：`、`相关文章` 及其后内容
- **删除发布信息**：`日期:2023.10.13  发布者:算准网`
- **删除 JSON 残留**：`{"code":200,...}` 及所有 JSON 格式的残留
- **删除 404 错误块**：`Warning: Target URL returned error 404` 及 `The requested URL was not found on this server.`
- **删除"算准网"文字残留**
- **保留原文内容**：不修改原文文字，只做格式清理

### 6. OCR 乱码修复

修复 suanzhun.net 网页文本中常见的 OCR 错误：

| 错误 | 正确 | 说明 |
|---|---|---|
| 已卯 | 己卯 | 天干"己"误为"已" |
| 已巳 | 己巳 | 同上 |
| 已亥 | 己亥 | 同上 |
| 已寅 | 己寅 | 同上 |
| 王寅 | 壬寅 | 天干"壬"误为"王" |
| 王子 | 壬子 | 同上 |
| 面合 | 酉合 | 地支"酉"误为"面" |
| 乙Ⅱ | 乙壬 | "壬"误为"Ⅱ" |

**注意**：只修复干支组合中的错误，不修复正常用语中的"已经"等。

### 7. 分隔符

- 篇目之间用 `---` 分隔
- `---` 前后各空一行
- 文件开头 `# 卷标题` 后用 `---` 分隔

### 8. 空行

- 段落之间空一行
- 不要出现连续 3 个以上空行
- 文件末尾保留一个空行

## 工作流程

1. 完整读取原典 txt 文件
2. 完整读取当前结构化版 md 文件
3. 从原典 txt 的 `Title:` 行提取篇目列表和分界
4. 逐个篇目提取正文内容，清理网页残留
5. 修复 OCR 乱码
6. 按标准格式重新组装
7. 写入结构化版 md 文件
8. 输出处理报告（篇目列表、行数、发现的问题）
