## 实验目标

验证比POC-VMS-9更高标准的场景：**在拓扑相同的情况下，如果两个tell的"距离"极其相近怎么办？**

具体验证：
1. Pipe 1（大概念过滤）对拓扑相同的tell给同分——大概念无法区分
2. Pipe 2（小概念标记分辨）能区分拓扑相同但小概念不同的tell
3. 交叉验证：干扰tell在错误题目上无效

---

## 关键发现

### 1. 大概念无法区分拓扑相同的tell——验证了用户的核心预判

POC-VMS-9中两个tell的拓扑不同（tell-1是discrete+continuous，tell-2是structural+enumeration），Pipe 1能精确区分（4 vs 0）。

POC-VMS-10中两个tell的拓扑完全相同（都是structural+enumeration+mismatch），Pipe 1给同分（4 vs 4）——**大概念无法区分**。这验证了用户的核心预判："随着tell数量的积累，大的概念描述对应的相同形式化的tell数量将会逐渐变多，此时大的概念已经不足以有效区别不同的tell。"

### 2. 小概念标记分辨成功——验证了"定义新概念区分tell"的路径

当Pipe 1给同分时，Pipe 2用小概念标记分辨成功区分了两个tell：
- 1631题：tell-A的小概念（mersenne/primality/covering_system）命中856次，tell-B的小概念（largest_odd_divisor/divisibility_4/p_adic）只命中12次
- 1709题：tell-B的小概念命中41次，tell-A的小概念命中0次

这验证了用户的核心洞察："无论两个tell多么相似，我们都可以用更为细化（小）的概念去进一步区分不同的tell。因为毕竟我们可以用语言表达tell之间的区别，就可以借助定义新的概念这种手段去区分tell。"

### 3. 小概念信号词是tell的语言描述的标准化

小概念信号词本质上是tell的标准化语言描述的关键词提取：
- tell-A的标准化语言描述："AI在枚举序列参数a的值，试图用covering system覆盖所有情况，但问题是Mersenne素数的存在性，需要用二次剩余/Euler准则"
- tell-B的标准化语言描述："AI在枚举差分参数a的值，试图逐一验证条件，但问题是最大奇因子差的整除性判定，需要用2-adic赋值分case分析模4行为"

从这些描述中提取的关键词（mersenne/primality/covering vs largest_odd_divisor/divisibility_4/p_adic）就是小概念信号词。这验证了用户说的"通过标准化对tell的语言描述来应对"。

### 4. 干扰tell在错误题目上确实无效——即使拓扑相同

两个tell拓扑相同且距离极近，但干扰tell在错误题目上仍然无效：
- 1631+T05（2-adic赋值）：AI尝试用2-adic赋值分析Mersenne素数，但2-adic赋值不适用于素数性判定
- 1709+T03（二次剩余）：AI尝试用Legendre符号分析最大奇因子，但二次剩余不适用于整除性判定

这验证了**即使两个tell拓扑相同，它们的hint也是不可互换的**——小概念的不同意味着需要的结构方法不同，错误的方法无法解决问题。

### 5. 完整的三层Pipe架构验证通过

```
Pipe 0 拓扑化 → 大概念拓扑
Pipe 1 大概念过滤 → 同分候选（大概念无法区分）
Pipe 2 小概念标记分辨 → 精准识别（小概念能区分）
```

这验证了287号文档定义的完整三层Pipe架构，以及用户第六次原文提出的"大概念→小概念→概念树"的设计哲学。

## 局限与下一步

### 局限

1. **小概念信号词仍然是手工设计的**——mersenne/primality/covering vs largest_odd_divisor/divisibility_4/p_adic是手工构造的。当tell数量增加时，小概念信号词需要自动化提取。

2. **只有2个拓扑相同的tell**——验证了2个tell的区分。当同一拓扑下有10个、100个tell时，小概念标记分辨的精度是否仍然足够？

3. **1709+T05的正确hint没有验证**——只验证了1709 bare失败和1709+T03干扰失败，没有验证1709+T05的正确hint能成功。需要补充这个实验。

4. **概念树管理还没有验证**——当概念数量膨胀时，概念树的层次结构和概念文件的加载机制还没有验证。

### 下一步

1. **补充1709+T05正确hint实验**——验证1709题在正确hint（T05 2-adic赋值）下能成功
2. **扩大同一拓扑下的tell数量**——从2个tell扩展到5-10个拓扑相同的tell，验证小概念标记分辨的精度
3. **自动化小概念提取**——用NLP方法从tell的标准化语言描述中自动提取小概念信号词
4. **验证概念树管理**——当小概念数量膨胀时，验证概念文件的层次结构和按需加载机制
