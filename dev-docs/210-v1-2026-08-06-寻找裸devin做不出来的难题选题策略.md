## 1. 问题定义

### 1.1 为什么要找这种题

本项目的核心假设（123号§DYN-0）是：

> 在部分问题族和研究状态上，**确定性结构计算+AI引导**能选择一个低成本、低泄漏、能增加已验证进展的最小干预。

要验证这个假设，必须找到**裸devin cli做不出来、但加了系统引导后能做出来**的题。如果题本身裸devin就能做，系统引导的增益无法体现（209号205-E实验已经看到：简单题裸devin也能做）。

### 1.2 "裸devin cli做不出来"的判定标准

不是"AI答不对"——任何AI都可能因为随机性答不对。真正的判定标准是：

| 维度 | 判定 |
|------|------|
| **正确性** | 裸devin cli给出的证明/解答在数学上是错的或不完整 |
| **稳定性** | 多次运行（≥3次）都做不对——不是偶然失败 |
| **卡点类型** | 卡在"不知道该用什么工具/方向"而非"计算错误"——后者是能力问题，不是引导能解决的 |
| **可引导性** | 卡点类型属于系统能给提示的范畴（lack_knowledge/uncertain/strategy_exhaustion），不是"需要全新数学发现" |

**关键区分**：
- "裸devin做不出来"≠"人类也做不出来"——我们找的是**AI能力边界内的题，但需要正确的方向引导**
- 不是找最难的题（如千禧年难题）——那些人类也没做出来，系统引导也没用
- 是找**AI有知识储备但不知道该调用什么**的题

## 2. 选题策略——三层漏斗

### 第一层：从已有题库中筛选候选

项目已有4个难题集，按"裸devin可能做不出来"的概率排序：

| 题源 | 路径 | 特征 | 候选概率 |
|------|------|------|----------|
| **Schweitzer竞赛** | `knowledge/competitions/hardest/Schweitzer/` | 研究级、开放书卷、10天考试、需研究生知识 | **高**——最接近"需要方向引导" |
| **Putnam A6/B6** | `knowledge/competitions/hardest/Putnam_A6_B6/` | 每场最难两题、需巧妙构造 | **中高**——需要非显然的构造 |
| **IMO Shortlist N6/G8等** | `knowledge/competitions/hardest/IMO_Shortlist/` | 难度5题、需要特殊技巧(如Vieta jumping) | **中**——技巧性强，AI可能见过 |
| **Arnold Trivium** | `knowledge/mathematicians/Arnold/trivium_100.md` | 计算型、考察直觉 | **低**——多数是计算题，AI擅长 |

**推荐**：优先从Schweitzer和Putnam A6/B6中选——这两类题需要"知道该用什么高级工具"，正是引导能发力的地方。

### 第二层：裸devin cli baseline测试

对第一层筛出的候选题，跑**裸devin cli baseline**（无系统引导，直接给devin cli做题）：

1. 每题跑**3次**（稳定性判定）
2. 用`/data/math-agent-glm5.2-{1,2,3}`三个Solver工作目录（AGENTS.md硬约束5）
3. 判定标准：
   - 3次全错/不完整 → **入选**（裸devin做不出来）
   - 3次中1次对 → **边缘**（需扩大样本到5次）
   - 3次全对 → **淘汰**（裸devin能做，不需要引导）

4. 验证标准：用`auto_audit_report`判定正确性，不能只看"AI说自己做对了"

### 第三层：卡点类型分析

对第二层入选的题，分析裸devin的**卡点类型**：

- 卡在"不知道用什么工具" → **适合系统引导**（入选实验组）
- 卡在"计算错误" → 不适合引导（是能力问题）
- 卡在"需要全新概念" → 不适合引导（超出系统知识库）

分析方法：看裸devin的response内容，用205-A的AI诊断分类：
- `lack_knowledge` → 适合（系统可以给知识候选）
- `uncertain` → 适合（系统可以给方向验证）
- `strategy_exhaustion` → 适合（系统可以给新策略）
- `response_too_short` + 内容空洞 → 不适合（能力问题）

## 3. 具体执行方案

### Phase 1: 候选题筛选（从题库中选10-15题）

从Schweitzer和Putnam A6/B6中按以下标准选：

1. **知识门槛高**：需要研究生水平工具（如测度论、表示论、代数拓扑）
2. **有明确正确答案**：能判定对错（不是开放问题）
3. **卡点可引导**：卡在"方向"而非"计算"
4. **领域多样**：覆盖代数/分析/组合/几何/数论，避免单一领域偏置

### Phase 2: 裸devin baseline测试（10-15题 × 3次 = 30-45次运行）

```
对每道候选题:
  for solver_dir in [math-agent-glm5.2-1, -2, -3]:
    裸devin cli做题（无系统引导）
    auto_audit判定正确性
  if 3次全错/不完整:
    入选实验组
  elif 3次中1次对:
    再跑2次（共5次），多数错则入选
  else:
    淘汰
```

**预算估计**：每次devin cli运行约2-5分钟（根据complex_001-005的经验），30-45次约1.5-4小时。

### Phase 3: 卡点分析（对入选题，5-10题）

分析裸devin的response，判定卡点类型是否适合引导。

### Phase 4: 系统引导对比实验（对最终入选题，3-5题）

对最终入选的题，跑**有系统引导**的版本（GuidedLoop），对比：
- 裸devin: 3次全错
- 系统引导: 是否能做对？（209号205-E已验证引导提示更针对性）

## 4. 风险与边界

### 4.1 可能的风险

| 风险 | 应对 |
|------|------|
| 裸devin对Schweitzer题全做对（AI训练数据可能包含） | 退到Putnam A6/B6，或找更新的Schweitzer题（2020年后） |
| 裸devin对所有题全做错（题太难） | 降低难度，退到Putnam A1-A5或IMO Shortlist难度4题 |
| 入选题太少（<3题） | 扩大候选池，或降低"做不出来"的判定门槛（从3次全错降到2次错） |
| 系统引导也做不对 | 这是有效结果——说明当前系统引导能力不足，需迭代 |

### 4.2 不做什么

- **不找千禧年难题级别的题**——人类也没做出来，验证不了系统价值
- **不找纯计算题**——AI计算能力已经很强，引导帮不上
- **不找AI训练数据必然包含的经典题**——如费马小定理（complex_005已验证裸devin能做）
- **不找开放性研究问题**——无法判定对错

## 5. 推荐方案

### 推荐：从Schweitzer 2020-2023年题开始

**理由**：
1. Schweitzer题是研究级难度，最可能卡在"方向"而非"计算"
2. 2020年后的题不太可能在AI训练数据中被详细解答
3. 开放书卷设计意味着这些题**允许查资料**——但裸devin cli禁止web_search（AGENTS.md硬约束5），所以正好测试"没有外部知识检索时的能力边界"
4. 项目已有Schweitzer题库（`knowledge/competitions/hardest/Schweitzer/`），不用从零收集

**备选**：如果Schweitzer题裸devin全做对，退到Putnam 2023-2024 A6/B6。

### 执行顺序

1. **先读Schweitzer题库**，选5道知识门槛高、有明确答案的题
2. **跑裸devin baseline**（5题×3次=15次运行）
3. **分析卡点类型**，筛出3道适合引导的题
4. **跑系统引导对比**（3题×3次=9次运行）
5. **落盘实验报告**

> **v1更新**：原推荐从Schweitzer开始，但211号搜索发现了一个更优的切入点——**各国数学奥林匹克决赛最难题**（CMO/VMO/USAMO/JMO/KMO）。理由见下面§6。Schweitzer仍然有效，但优先级降到第二梯队。

## 6. 找题方法论（v1新增）

### 6.1 核心发现：从一道题到一类题

发现CMO 2024第6题（矩条件极差题）后，搜索思路的打开方式是：

```
一道题（CMO 2024 P6）
    ↓ 这是什么水平？
全国最难的中学竞赛最后一题
    ↓ 哪些竞赛有这个水平的题？
各国数学奥林匹克决赛最难题
    ↓ 系统搜索各国2024-2025年决赛
CMO / VMO / USAMO / JMO / KMO / Iran MO
    ↓ 同时搜索国际竞赛
IMO P6 / IMO Shortlist A6/N6
    ↓ 同时搜索大学级竞赛
IMC / Putnam / Schweitzer
```

**关键洞察**：不要只在一个题库里找——要按"**这个难度级别有哪些系统性来源**"打开维度。每个国家的数学奥林匹克决赛最后一题，都是这个水平的题。

### 6.2 "这个水平"的定义

CMO 2024第6题（矩条件极差题）的特征定义了"这个水平"：
- **全国最难的中学竞赛最后一题级别**
- **需要构造性洞察**（如q(x)=x²+x-1）
- **需要跨领域工具**（如badly approximable解代数题）
- **有明确正确答案**
- **不是纯技巧题或纯计算题**

### 6.5 三个关键筛选原则

1. **时间新优先**：2024-2025年题 > 2020-2023年题 > 2020年前
   - 理由：AI训练数据有时间截止，新题不太可能被详细解答过

2. **AI训练数据缺口优先**：中文/日文/韩文题 > 英文题；AoPS讨论少的题 > 讨论多的题
   - 理由：英文AI训练数据中英文竞赛题讨论多，AI可能"记住"解法
   - 日文/韩文/中文论坛讨论的题，英文AI训练数据少

3. **构造性洞察+跨领域工具优先**：需要构造辅助对象的题 > 纯技巧题
   - 理由：构造性洞察是系统引导能发力的地方；纯技巧题引导帮不上

### 6.6 反向筛选——用"全员零分"找极难题

JMO 2025 P5平均分0.00——全员零分。这种"全员零分"的题正是我们要找的：
- 它证明这道题需要**非常规的洞察**，不是靠技巧能解的
- 连该国顶尖选手都做不出来，裸AI大概率也做不出来
- **搜索方法**：查各国竞赛的官方成绩分布，找平均分接近0的题

### 6.7 找题工作流（可复用）

```
Step 1: 选一个国家/竞赛
Step 2: 查2024-2025年决赛最后一题
Step 3: 查官方成绩分布——平均分是否接近0？
Step 4: 看题面——是否需要构造性洞察+跨领域工具？
Step 5: 查AoPS讨论热度——讨论少则AI不易见过
Step 6: 确认有明确正确答案
Step 7: 收录到 knowledge/competitions/hardest/<竞赛名>/
Step 8: 进入baseline测试池
```

## 7. 批量测试方案（v1新增）

### 7.1 方案A：Ramanujan全集批量测试

**核心思路**：Ramanujan的190个恒等式全部由后世数学家（Berndt 1985-1998五卷本 + Andrews-Berndt遗失笔记本）验证并证明。用这些恒等式作为测试集，让sub agent不许联网独立证明，有标准答案校验，记录解不出来的题目。

**项目已有资料**：

| 资料 | 路径 | 数量 |
|------|------|------|
| 三本笔记关键恒等式 | `knowledge/mathematicians/Ramanujan/notebooks/key_identities.md` | 139个 |
| 遗失笔记本关键公式 | `knowledge/mathematicians/Ramanujan/lost_notebook/key_contents.md` | 51个 |
| 后续证明链 | `knowledge/mathematicians/Ramanujan/subsequent_proofs/chains.md` | 499行 |

**恒等式分类与难度**：

| 难度 | 类别 | 数量 | 预期AI表现 |
|------|------|------|-----------|
| 简单 | 代数恒等式和根式、级数求和公式 | ~20 | AI大概率能做 |
| 中等 | q-级数恒等式、theta函数、分拆函数 | ~80 | AI可能能做 |
| 难 | 连分数恒等式、模形式 | ~40 | AI可能做不出来 |
| 极难 | Mock theta函数、Hecke-type表示 | ~50 | AI大概率做不出来 |

**执行方式**：
1. 从`key_identities.md`和`key_contents.md`提取190个恒等式，转成证明题格式
2. 5个sub agent并行（`subagent_explore` profile，无web_search），每个分38个
3. 每个恒等式要求：给出证明或明确说"我无法证明"
4. 校验：SymPy数值验证 + 人工抽查
5. 记录"解不出来"的题目 → 进入系统引导实验池

**方案优点**：
- 题目数量大（190个），系统化批量测试
- 有标准答案（Berndt五卷本）
- 难度跨度大，可精确定位AI能力边界
- 需要构造性洞察（知道该用什么工具），正是系统引导能发力的地方
- 可以并行化

**需解决问题**：
- 校验方法：SymPy数值验证恒等式是否正确 + 人工抽查证明过程
- 题目格式：把恒等式转成"证明以下恒等式"格式
- 建议先做小规模pilot（20个恒等式，1个sub agent），验证流程可行后再扩大

**执行方式**：
1. 从325篇论文中提取主定理（每篇1-3个关键定理）
2. 筛选"需要构造性洞察"的定理（排除纯计算/纯存在性证明）
3. 用sub agent测试能否独立证明
4. 校验：论文本身有完整证明，可对比

**方案优点**：
- 题目最新（2023-2026年），AI训练数据几乎不可能包含完整证明
- 覆盖全部数学领域，可全面定位AI能力边界
- 论文有完整证明，校验标准明确
- 可以发现"哪个领域的定理AI最做不出来"

**方案缺点**：
- 需要先从论文中提取定理（工作量比Ramanujan大）
- 部分定理可能依赖论文中的前置定义/记号，不能直接作为独立测试题
- 部分前沿定理可能太难（超出AI能力范围，也超出系统引导能发力的范围）

**筛选建议**：
- 优先选math.NT（数论）、math.CO（组合）、math.CA（经典分析）——这些领域更可能有"构造性洞察"型定理
- 排除math.HO（数学史）、math.GM（一般数学）——不是证明题
- 排除依赖大量前置定义的论文——不适合作为独立测试题

### 7.3 两个方案对比

| 维度 | 方案A（Ramanujan） | 方案B（arXiv） |

### 7.4 方案C：知名数学家难题集批量测试

**核心思路**：数学史上有一些知名数学家专门编写了"难题+解答"的书籍。这些书本身就是为训练数学思维而设计的，题目经过精心挑选，有完整解答，难度跨度大，且很多题需要构造性洞察——正是系统引导能发力的地方。

| **规模** | 2卷约2000题 |

| **特点** | 按方法组织（不是按领域），每章一个主题 |
| **难度** | 从本科到研究级 |
| **与本项目契合度** | ★★★ Pólya是"启发式数学"创始人——这本书的设计目的就是教人"如何想到解法"，与系统引导AI想到解法的目标完全一致 |

### 7.5 方案D：笹部贞市郎《问题解法》系列数学辞典

**核心思路**：日本数学家笹部贞市郎（1887-）编著的"问题解法"系列数学辞典，是数学史上最庞大的"难题+解答"题库之一。覆盖代数、几何、三角、微积分、解析几何全部初等数学领域，题量极大，每题都有详细解答。中文版由上海教育出版社1982-1989年翻译出版，相对容易获取。

#### 笹部贞市郎系列全貌

| 编号 | 书名 | 中文版出版社/年份 | 页数 | 题量 | 内容 |
|------|------|-------------------|------|------|------|
| D-1 | **代数学辞典·问题解法**（上） | 上海教育出版社1982 | ~986页 | **3613题** | 数和式的运算/倍数约数/函数图像/方程/不等式/最大最小值/方程理论/指数对数/计算尺 |
| D-2 | **代数学辞典·问题解法**（下） | 上海教育出版社1982 | ~986页 | **3115题** | 复数/向量/数列级数/收敛发散连分数/排列组合/二项式定理/概率统计/线性代数/集合代数结构/论证 |
| D-3 | **几何学辞典·问题解法** | 上海教育出版社1984 | 973页 | ~3000+题 | 平面几何/立体几何/构造性证明 |
| D-4 | **微积分学辞典·问题解法** | 上海教育出版社1989 | 1745页 | ~4000+题 | 微分/积分/级数/应用 |
| D-5 | **解析几何学辞典·问题解法** | 上海教育出版社 | — | ~2000+题 | 坐标几何/二次曲线/二次曲面 |
| D-6 | **三角法辞典·问题解法** | 上海教育出版社1983 | 748页 | ~2000+题 | 平面三角/球面三角/双曲函数/测量 |

**总题量估算**：约15000-18000题（六本合计）

#### 系列特点

1. **题量极大**——仅代数学一本就有6728题，全系列约15000-18000题，是Pólya & Szegő的7-9倍
2. **全部有解答**——每题都有详细解答，很多解答有多种方法
3. **覆盖初等数学全部领域**——代数/几何/三角/微积分/解析几何
4. **难度跨度大**——从基础计算题到需要构造性洞察的难题
5. **构造性问题多**——尤其是几何学和代数学中的证明题
6. **中文版可获取**——上海教育出版社翻译，Z-Library等平台有PDF
7. **日文原版**——AI训练数据中可能较少（中文翻译版可能有，但题量太大不可能全部记住）

#### 与其他方案对比的独特价值

| 维度 | 笹部系列 | 其他方案 |
|------|----------|----------|
| 题量 | 15000-18000 | Ramanujan 190 / Pólya 2000 / arXiv 300-600 |
| 领域覆盖 | 初等数学全领域 | 各方案各有侧重 |
| 难度定位 | 中学→大学初等 | 其他方案偏研究级 |
| 构造性问题 | 极多（尤其几何） | 各方案不同 |
| AI训练数据风险 | 低-中（题量太大，日文原版） | 各方案不同 |

**独特价值**：笹部系列是唯一一个覆盖**初等数学全领域**的巨型题库。其他方案（Ramanujan/Pólya/Arnold/arXiv）都偏向研究级，而笹部系列可以从**基础题**开始，精确定位AI在哪个难度级别开始做不出来——这对系统引导实验非常重要：

- 如果AI在初等几何构造题上就做不出来 → 系统引导的发力点在初等数学
- 如果AI在初等题能做但微积分做不出来 → 系统引导的发力点在大学初等
- 如果AI在大学初等都能做但研究级做不出来 → 系统引导的发力点在研究级

#### 获取方式

- **中文版**：上海教育出版社1982-1989年翻译出版，Z-Library等平台有PDF
- **日文原版**：聖文社出版，明倫館書店有6册セット
- **优先获取**：代数学辞典（上下）+ 几何学辞典——题量最大，构造性最强

#### 执行方式

1. 获取中文版PDF（优先代数学+几何学）
2. 从PDF中提取题目（可以用OCR或手动）
3. 按难度分级筛选——基础计算题跳过，重点选证明题/构造题
4. 预计可筛选出2000-3000道"需要构造性洞察"的题
5. 用sub agent批量测试
