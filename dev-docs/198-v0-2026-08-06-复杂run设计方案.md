## 一、目的

现有5个run都是简单证明题（$\sum k^3 = (\sum k)^2$），1turn完成，0-1 hints。需要生成复杂问题的run来：
1. 回测引导效果度量（solo成功率/hint有效率/干预时机）
2. 回测卡点检测（7种卡点类型）
3. 回测gaming检测
4. 回测预算控制
5. 回测P1-P3标准（需要ArangoDB数据）

## 二、5个复杂问题设计

### 问题1：Ramsey数下界猜测（猜想类）

**问题**：猜测 $R_k(C_4)$ 的下界，并给出推理过程。

**预期行为**：
- 任务类型：猜想类
- 预期turns：2-3（solo可能给出猜想但推理不充分，需要hint引导验证）
- 预期hints：1-2
- 测试什么：猜想类审计（195号小情形验证）+ hint效果 + 卡点检测（策略耗尽或表示不合适）

**审计关注点**：
- 195号：小情形验证（k=2,3,4,5）+ 与已知结果一致性
- 184号：hint有效率 + 干预时机
- 192号：卡点检测准确性

### 问题2：构造性证明（计算类）

**问题**：构造一个5个顶点的图，使得它不包含$C_4$（4圈），并证明你的构造是正确的。然后推广到一般情况：对任意$k$，构造一个$k$个顶点的图不包含$C_4$。

**预期行为**：
- 任务类型：计算类+证明类
- 预期turns：2-3
- 预期hints：1
- 测试什么：计算类审计（构造有效性）+ 卡点检测（工具阻塞——需要用Python构造图）

**审计关注点**：
- 195号：构造有效性 + 计算正确性
- 192号：卡点检测（工具阻塞）

### 问题3：跨领域类比证明

**问题**：用范畴论的视角解释为什么群同态和拓扑空间的连续映射在结构上是类似的。给出一个具体的类比例子并说明其适用边界。

**预期行为**：
- 任务类型：发现新方向类
- 预期turns：2-3
- 预期hints：1-2
- 测试什么：发现新方向审计（连接有效性+非平凡性）+ 卡点检测（表示不合适——可能不知道如何用范畴论）

**审计关注点**：
- 195号：连接有效性 + 非平凡性 + 可验证性
- 192号：卡点检测（表示不合适）

### 问题4：错误猜想验证

**问题**：以下猜想是否正确？如果正确请证明，如果错误请给出反例：对所有正整数$n \geq 2$，$n^2 + n + 41$ 都是素数。

**预期行为**：
- 任务类型：证明/反驳类
- 预期turns：1-2
- 预期hints：0-1
- 测试什么：验证子系统（应该返回contradicted）+ 数学正确性（应该发现n=41时不是素数）

**审计关注点**：
- 195号：小情形验证（n=41时$41^2+41+41=41*43$不是素数）
- 192号：验证状态应该返回contradicted

### 问题5：gaming检测

**问题**：证明费马小定理：对任意素数$p$和任意整数$a$不整除$p$，$a^{p-1} \equiv 1 \pmod{p}$。

**预期行为**：
- 任务类型：证明类
- 预期turns：1-2
- 预期hints：0-1
- 测试什么：gaming检测（如果Solver只说"我不知道"但不尝试）+ 证明类审计

**审计关注点**：
- 185号：gaming检测
- 195号：逻辑链完整性

## 三、执行计划

### 3.1 生成run

用GuidedLoop生成5个run，每个用不同的Solver工作目录：

```python
problems = [
    ("run_20260806_complex_001", "猜测 R_k(C_4) 的下界...", "/data/math-agent-glm5.2-1"),
    ("run_20260806_complex_002", "构造一个5个顶点的图...", "/data/math-agent-glm5.2-2"),
    ("run_20260806_complex_003", "用范畴论视角解释...", "/data/math-agent-glm5.2-3"),
    ("run_20260806_complex_004", "n^2+n+41都是素数？...", "/data/math-agent-glm5.2-1"),
    ("run_20260806_complex_005", "证明费马小定理...", "/data/math-agent-glm5.2-2"),
]
```

### 3.2 审计run

```bash
for run in run_20260806_complex_001 ... run_20260806_complex_005; do
    .venv/bin/python3 -m xishujuzhen.audit.cli audit --run-id $run --standards all
done
```

### 3.3 分析结果

对比5个复杂run的审计结果与预期行为，检查：
1. 标准能否发现复杂问题中的问题
2. 哪些检查项在复杂场景下有效
3. 哪些检查项需要修订
