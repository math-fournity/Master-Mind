  - 中元（1924-1983）：阳男阴女干×100+支×10，阳女阴男支×100+干×10

  - 五鼠遁元：日干→时干（甲己甲子起/乙庚丙子起/丙辛戊子起/丁壬庚子起/戊癸壬子起）
  - 修复 `tieban_enum.py` 中月干固定甲/时干固定甲的 bug

### 0.3 多学派实现层（`tieban/schools/`）

- [ ] **0.3.1 南派基础（`school_nanpai.py`）**
  - 主算：日干支太玄数 + 时干支太玄数
  - 算法A：太玄数直接合数（四柱太玄数相加→舍十位个位）
  - 展开：±48×{2,4,8,16}（北派也用此法，需确认南派是否也用）
  - 性别秘数：男+7130，女+7600（占位值，需考据修正）
  - 考刻：父母生肖→基本数（144组合，需秘数全表）

- [ ] **0.3.2 北派基础（`school_beipai.py`）**
  - 主算：月干支太玄数 + 时干支太玄数（与南派不同）
  - 算法B1：先天基本卦（年柱+月柱→上卦下卦→先天数）
  - 算法B2：后天基本卦（日柱+时柱→上卦下卦→后天数+互卦）
  - 展开：±96×{1,2,3,4}（江南派也用此法）
  - 八卦滚法：基本数÷9和÷6的余数→变爻位置→变卦

- [ ] **0.3.3 江南派基础（`school_jiangnan.py`）**
  - 八卦加则：天干配卦+地支配卦+生成数
  - 甲流度考刻（需进一步研究具体算法）
  - 展开：±96×{1,2,3,4}
  - 与北派的差异点需明确

- [ ] **0.3.4 中州派基础（`school_zhongzhou.py`）**（可选 · 最封闭）
  - 算盘数法（需进一步研究）
  - 与南派/北派的差异点需明确

- [ ] **0.3.5 学派统一接口**（抽象基类）
  - `TiebanSchool` 基类：`compute_base()` / `expand()` / `gender_secret()` / `kaoke()`
  - 各学派实现此接口
  - 支持同一八字在不同学派下的对比推演

> **核心理念**：铁板神数和七政四余是两套独立系统，对同一出生时间并行运行，比较产出，挖掘术数原理性内容。

- [ ] **1.1.1 设计并行推演的数据结构**
  - 输入：出生时间（公历）+ 性别 + 父母生肖
  - 铁板输出：数序集合 + 条文内容 + 分类统计
  - 七政输出：`build_chart()` 的22字段完整命盘
  - 对比维度：六亲/婚姻/事业/财运/健康 各维度的两套系统判定

- [ ] **1.1.2 实现 `parallel_deduction()` 函数**
  - 输入：出生时间参数

  - 输出：结构化对比报告（JSON）
  - 在 `qizheng/` 下新增 `parallel.py`

### 1.2 180年全周期枚举+并行推演

  - 修正框架中的问题

- [ ] **1.2.2 中规模枚举**（1000个八字）

- [ ] **1.2.3 全周期枚举**（180年 ≈ 65,745天）
