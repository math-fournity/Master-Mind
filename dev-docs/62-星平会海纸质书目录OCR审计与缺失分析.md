## 1 · 缘起

61 号文档记录了基于 suanzhun.net 网页版本的完整性审计，结论是"全部覆盖"。但用户提出了更权威的验证方式：用纸质书目录拍照 OCR，与本地原典逐项对比。

## 2 · 数据来源与处理

### 纸质书信息

用户拥有的纸质书版本（从照片内容判断）：
- 书名：《增补星平会海命学全书》
- 结构：卷首 + 卷一~卷十（共 11 卷）
- 目录页数：22 张照片

### 处理流程

1. **压缩**：22 张 3MB JPG → sips 压缩到 50-85KB/张（formatOptions 30, -Z 1200）
2. **OCR**：MinerU v3.4.4 vlm-engine 后端，逐张识别（约 12 分钟）
3. **去重合并**：22 张 OCR 结果 → 326 行目录（11 卷级 + 313 篇目级）
4. **对比**：逐项在本地原典中搜索（精确匹配 + 模糊匹配 + OCR 变体检查）

### MinerU 使用备注

- pipeline 后端因模型文件缺失（unimernet_hf_small_2503 无 safetensors）不可用
- vlm-engine 后端正常工作，支持图片输入
- 命令：`conda run -n mineru mineru -p <dir> -o <outdir> -m ocr -b vlm-engine -l ch`
- 输出在 `<outdir>/IMG_XXXX/vlm/IMG_XXXX_content_list.json`，type=text 的 items 是识别文本
- `.md` 文件为空，实际内容在 content_list.json 中

## 6 · 根因分析

### 为什么 61 号文档说"全部覆盖"但纸质书审计发现缺失？

61 号文档的审计基于 suanzhun.net 网页版本与网上描述的篇目列表对比。suanzhun.net 的卷首版本比纸质书简略很多：

- 纸质书卷首有 ~40 个细粒度篇目
- suanzhun.net 只提供了 18 个（合并了子篇目，省略了歌诀和表格类内容）
- 网上描述的篇目列表本身就不完整，没有覆盖纸质书目录的全部条目

**结论**：suanzhun.net 的卷首内容不完整，不是我们抓取遗漏，而是源站本身的内容就比纸质书少。
