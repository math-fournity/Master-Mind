# 111-知识搜集优先级方案——最难的、最妙的、最新的

> **文档定位**：109号列了十三大来源（~325000节点），110号解决了可操作性。本方案解决"先搜集什么"——优先级逻辑。
>
> **核心洞察（来自用户）**：数学大师系统的价值不在于装AI已经会的东西，而在于装AI不会的。越是难、妙、新，越是AI本身可能不会的，越应该优先装入。标准教材内容AI已经会了，装入的边际价值低。

## 一、优先级逻辑

### 1.1 反直觉原则

直觉上，应该先装"基础"知识（教材定理），再装"高级"知识（前沿论文）。但这是错的。

**正确的逻辑**：

| 内容类型 | AI是否已会 | 装入边际价值 | 优先级 |
|---|---|---|---|
| 标准教材定理（Cayley-Hamilton, 微积分基本定理...） | **已会** | 低 | P3 |
| 基础竞赛题（IMO P1-P3） | **已会** | 低 | P3 |
| 常见数学概念（群/环/域/拓扑空间） | **已会** | 低 | P3 |
| Wikipedia数学条目 | **已会** | 低 | P3 |
| Ramanujan笔记中冷僻恒等式 | **不会** | **高** | **P0** |
| 2024-2026 arXiv最新论文 | **不会**（训练截止后） | **高** | **P0** |
| Schweitzer研究级竞赛题 | **大概率不会** | **高** | **P0** |
| Erdős冷僻问题 | **大概率不会** | **高** | **P0** |
| Arnold Trivium 100题 | **部分不会** | **高** | **P0** |
| 数学家如何思考的元知识 | **浅层会，深层不会** | **高** | **P0** |

### 1.2 三级优先级

**P0（第一批，立即搜集）——AI最不可能会的**：
1. Ramanujan全集（笔记+遗失笔记本+后续证明链条）
2. 最新arXiv关键论文（2023-2026，训练截止后）
3. 最难竞赛题（IMO P5/P6 + Schweitzer + Putnam A6/B6）
4. 近期数学突破（2022菲尔兹奖+2023-2025突破奖）
5. Erdős问题清单
6. Arnold Trivium + Arnold散文
7. 数学思想书核心内容（Hadamard/Poincaré/Lakatos/Thurston/Grothendieck/Rota）
8. Conway深度工作（ONAG + Winning Ways + Sphere Packings细节）
9. 开放问题清单（千禧年+Erdős+Smale+Arnold的详细进展）

**P1（第二批）——AI浅层知道但深度不够的**：
- MathLib形式化定理（机器验证的依赖链）
- Proofs from THE BOOK剩余（精妙证明）
- OEIS带公式子集（经验模式）
- 关键数学家工作（Grothendieck EGA/SGA, Serre, Tao blog）
- Bourbaki Seminar综述
- IMO Shortlist（比正赛更难）
- 各国奥赛最难题

**P2（第三批）——AI基本会的，补充完善**：
- 标准教材核心定理+习题
- Wikipedia数学条目
- 基础竞赛题
- 百科条目

**P3（远期）——AI完全会的，只做索引**：
- 初等数学
- 常见概念定义
- 历史人物传记（只做索引，不做内容）

### 1.3 "难、妙、新"三准则

| 准则 | 含义 | 判断标准 |
|---|---|---|
| **难** | 超出AI常规推理能力 | 需要多步跨领域推理/需要深层直觉/需要非显然构造 |
| **妙** | 证明方法出人意料 | 连接看似无关领域/用简单工具解决复杂问题/揭示隐藏结构 |
| **新** | AI训练数据中不存在 | 2023年后发表/冷僻文献/非主流但深刻的工作 |

**三准则满足越多，优先级越高。**

## 二、第一批搜集计划（P0）

### 2.1 Ramanujan全集

**为什么是最高优先级**：Ramanujan是"妙"的极致——他的恒等式很多至今仍让人惊叹。AI知道著名的几个（如Rogers-Ramanujan恒等式），但3000+笔记条目中大部分AI不会。而且Ramanujan的工作有完整的后续链条（mock theta函数→Bringmann-Folsom-Ono），这些链条本身就是依赖图的精华。

**搜集内容**：
1. 三本笔记的条目清单（~3000条恒等式/公式/猜想）
2. 遗失笔记本的条目清单（~600条）
3. Berndt注解中的关键证明和背景
4. 后续发展链条：
   - Mock theta函数：17个原始→Andrews→Hickerson→Cohen→Zagier→Bringmann-Folsom-Ono-Rolen
   - 分拆函数：Hardy-Ramanujan-Rademacher→Lehner→Newman→Atkin→Andrews→Bruinier-Ono
   - Ramanujan同余式：p(5n+4)≡0等→后续推广
   - q-级数：Rogers-Ramanujan→Slater→Andrews→Shanks
   - 连分数：Rogers-Ramanujan连分数→后续
   - Circle method：Hardy-Littlewood-Ramanujan→后续解析数论应用
5. Hardy的12篇讲义核心内容

**搜集方式**：AI内在知识还原（我确实知道Ramanujan的工作）+ 维基百科交叉校验

**存档位置**：`knowledge/mathematicians/Ramanujan/`

### 2.2 最新arXiv关键论文（2023-2026）

**为什么是最高优先级**：这是"新"的极致——AI训练截止后的内容，AI**完全不会**。

**搜集内容**：
- 2023-2026年各领域高引论文/突破性论文
- 重点关注：
  - 解析数论：Maynard, Maynard's recent work on primes
  - 代数几何：Scholze/Clausen condensed mathematics进展
  - 组合学：近期突破
  - 拓扑：近期突破
  - PDE：近期突破
  - Langlands纲领：近期进展

**搜集方式**：arXiv API + ar5iv fetch

**存档位置**：`knowledge/arxiv/2023_2026/`

### 2.3 最难竞赛题

**为什么是P0**：IMO P5/P6级别的题目是"难"的极致——需要深层直觉和非显然构造。AI在P1-P3级别表现好，但P5/P6级别经常失败。Schweitzer是研究级竞赛，比IMO更难。

**搜集内容**：
1. IMO 1985-2025 P5/P6（~40年×2题=80道最难题）
2. Schweitzer竞赛 1985-2025（~40年×~10题=400道研究级题）
3. Putnam 1985-2025 A6/B6（~40年×2题=80道最难题）
4. IMO Shortlist中最难的题（每年最难3-5题×40年=120-200道）

**存档位置**：`knowledge/competitions/hardest/`

### 2.4 近期数学突破

**搜集内容**：
- 2022菲尔兹奖得主工作：
  - Duminil-Copin：统计力学/Ising模型/渗流
  - Maynard：素数间隔/Linnik问题
  - Viazovska：8维和24维球填充
  - June Huh：组合学与代数几何的Hodge理论
- 2023-2025突破奖数学奖
- 2023-2025其他重要突破

**存档位置**：`knowledge/breakthroughs/`

### 2.5 Erdős问题清单

**为什么是P0**：Erdős维护了1000+开放问题，很多冷僻但深刻。AI知道著名的几个（如Erdős conjecture on arithmetic progressions），但大部分不会。

**搜集内容**：Erdős问题清单（从Nesetril-Graham "The Mathematics of Paul Erdős"还原）

**存档位置**：`knowledge/open_problems/erdos/`

### 2.6 Arnold Trivium + 散文

**为什么是P0**：Arnold的100题trivium是"大师认为每个数学家都应该能做的题"——这本身就是数学意识的精华。Arnold的散文充满了数学直觉和美学判断。

**搜集内容**：
1. Arnold Trivium 100题（完整还原）
2. Arnold "On teaching mathematics"（经典散文）
3. Arnold "Mathematical Understanding of Nature"核心内容
4. Arnold "Yesterday and Long Ago"
5. Arnold关于数学教育的观点

**存档位置**：`knowledge/mathematicians/Arnold/`

### 2.7 数学思想书核心内容

**为什么是P0**：这是L3意识节点的直接来源。AI浅层知道"数学家靠直觉"，但深层不知道Hadamard如何分析发明心理学、Poincaré如何描述下意识工作、Thurston如何定义"理解"。

**搜集内容**：
1. Hadamard "Psychology of Invention"核心章节
2. Poincaré "Science and Method"核心章节（含著名的Fuchsian函数发现描述）
3. Lakatos "Proofs and Refutations"核心论证
4. Thurston "On Proof and Progress in Mathematics"全文
5. Rota "Indiscrete Thoughts"核心章节
6. Grothendieck "Récoltes et Semailles"核心段落
7. Manin "Mathematics as Metaphor"核心章节
8. Atiyah散文核心内容
9. Gowers "The Two Cultures of Mathematics"

**存档位置**：`knowledge/thinking_books/`

### 2.8 Conway深度工作

**为什么是P0**：Conway是"妙"的另一个极致——从游戏中发现surreal numbers，从对称性发现Conway群。AI知道Conway的名字和Game of Life，但ONAG和Winning Ways的深层内容AI不会。

**搜集内容**：
1. ONAG (On Numbers and Games) 核心理论
2. Winning Ways核心内容
3. Sphere Packings, Lattices and Groups核心内容
4. Conway的数论工作（15定理/300定理）
5. Conway的纽结工作
6. Angel Problem

**存档位置**：`knowledge/mathematicians/Conway/`

### 2.9 开放问题清单（详细进展）

**为什么是P0**：开放问题标记数学的边界。AI知道问题陈述，但不知道详细进展和为什么难。

**搜集内容**：
1. 千禧年7问题（每个问题的详细背景+已知进展+为什么难）
2. Erdős问题（与2.5交叉）
3. Smale 18问题（详细进展）
4. Arnold 200+问题（详细进展）
5. 各领域核心开放问题

**存档位置**：`knowledge/open_problems/`
