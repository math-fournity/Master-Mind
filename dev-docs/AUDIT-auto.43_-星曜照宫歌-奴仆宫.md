> 奴仆惟推最弱宫，李星临照愈为凶。当生禄主如金陷，衣食奔波守困穷。

**关键发现**：本规则首次出现"**最弱宫**"概念——"奴仆惟推最弱宫"。奴仆宫不仅是弱宫，而且是**最弱**的宫位。这建立了宫位强度的** ordinal 级别**：
- 奴仆宫 = 最弱宫（比兄弟宫、疾厄宫等弱宫更弱）
- 这与 `shen_sha_complete.json` 中奴仆宫标注"弱、恶宫"一致——既是弱宫又是恶宫

**定量化思考**："当生禄主如金陷"引入了**叠加凶象**模型：
```
凶度 = base(月孛在最弱宫) + modifier(禄主落陷)
- 月孛在最弱宫：base = 高凶
- 禄主又落陷：modifier = +凶（叠加）
- 总凶度 = base + modifier = 极凶→衣食奔波守困穷
```
这是**多条件叠加**的量化模型——不是简单的AND逻辑，而是凶度累加。

**时代性思考**：这是"事在人为"在星曜照宫歌中的直接体现——星象是条件，但人的道德选择可以改变兑现方式。罗喉在奴仆宫的"凶"不会消失，但其兑现从"怒号为祸"变为"安贫乐道"。**能量单位不变（罗喉的破坏力），但兑现方式因人的行为而改变**。

```
破坏度 = f(计都) + f(月孛) + interaction(计都×月孛)
- f(计都) = 消耗/破田园
- f(月孛) = 偷盗散
- interaction = 协同放大效应（双凶>单凶之和）
```

## 定量化思考

### 1. 宫位强度 ordinal 级别

本段首次出现"**最弱宫**"概念（规则9："奴仆惟推最弱宫"），建立了宫位强度的序数级别：

| 级别 | 宫位 | 依据 |
|---|---|---|
| 最弱 | 奴仆宫 | "奴仆惟推最弱宫"（规则9）+ "号陷方"（规则6） |
| 弱 | 兄弟宫、疾厄宫、迁移宫、相貌宫 | `shen_sha_complete.json` 标注"弱宫"或"弱、恶宫" |
| 强 | 命宫、官禄宫、福德宫、田宅宫、财帛宫、夫妻宫、男女宫 | `shen_sha_complete.json` 标注"强宫"或"强、正宫" |

**量化方案**：
```
宫位强度 = ordinal_level ∈ {最弱, 弱, 强, 最强}
吉凶修正 = base_effect(星曜) × palace_modifier(宫位强度)
- 最弱宫：palace_modifier = 0.3（吉星减力70%，凶星加力）
- 弱宫：palace_modifier = 0.5
- 强宫：palace_modifier = 1.0
- 最强宫：palace_modifier = 1.2（吉星加力20%）
```

### 2. 多值输出模型

金星在奴仆宫出现两首诗诀（规则4+规则5），输出4个不同维度的判定：克妻、背非、文章空废、薄禄走西东。这意味着星曜×宫位映射是**多值函数**：

```
效果(星曜X, 宫位Y) = {
    维度1: 人际关系 → 判定1,
    维度2: 事业成就 → 判定2,
    维度3: 健康/寿元 → 判定3,
    ...
}
```

当前规则库中每条规则只有一个输出判定，需要扩展为**多维度输出**结构。

### 3. 凶度累加模型

规则9（月孛+禄主陷）和规则11（计都+月孛会）都体现了**多条件叠加**的凶度模型：

```
总凶度 = Σ(各条件凶度) + Σ(交互效应)
- 不是简单AND（全满足才凶）
- 而是累加（每多一个凶条件，凶度增加）
- 交互效应：双凶协同 > 单凶之和
```

### 4. 吉凶能量等级

11条规则的吉凶分布：

| 等级 | 星曜 | 判定 |
|---|---|---|
| 凶（条件反转） | 罗喉 | 崇道德→安贫乐道（凶转安贫） |
| 凶（得时减凶） | 太阴 | 夜生→减凶 |
| 凶（世俗凶/方外吉） | 土星 | 世俗无成/方外有名 |
| 凶（多维度） | 金星(×2) | 克妻+背非+文章空废+薄禄 |
| 凶 | 木星 | 一生无寸禄（吉星反转） |
| 凶 | 火星 | 害刑多灾/得地专权自祸 |
| 凶 | 太阳 | 寿早伤（君父陷方） |
| 凶 | 紫炁 | 孤高欠情/奴仆难保 |
| 凶（叠加） | 月孛 | 最弱宫+禄主陷→奔波困穷 |
| 凶（叠加） | 计都 | 损寿+月孛会→偷盗破田园 |

**发现**：奴仆宫是**全凶宫**——11星中无一为吉，仅罗喉有"崇道德"的条件反转、太阴有"夜生"的得时减凶、土星有"方外"的领域转换。这比兄弟宫（9凶+2条件吉）更加极端，确认了奴仆宫=最弱宫的定位。

## 开放性思考

### 新概念发现：陷方

规则6"奴仆之宫号陷方"——"陷方"不是某星在某宫的落陷状态，而是**宫位本身的性质标签**。奴仆宫对所有星曜而言都是"陷方"。

**与兄弟宫"陷"算子的区别**：
- 兄弟宫的"陷"=特定星曜（太阳）在特定宫位（第三宫）的落陷状态——是**星曜×宫位**的交互属性
- 奴仆宫的"陷方"=宫位本身的性质——是**宫位**的固有属性

**形式化**：
- "陷"算子：输入=(星曜, 宫位)，输出=布尔值（该星在该宫是否落陷）
- "陷方"标签：输入=宫位，输出=布尔值（该宫是否为陷方）

`qizheng/shen_sha_complete.json` 已有宫位强度标注（"弱、恶宫"），但尚未建立"陷方"的正式标签。**待发现**：是否还有其他宫位被标注为"陷方"？还是只有奴仆宫是陷方？

### 新概念发现：最弱宫

规则9"奴仆惟推最弱宫"——"最弱"是比"弱"更低的强度级别。这建立了宫位强度的**序数级别**（ordinal level），不仅是强弱二分，而是有梯度。

**待发现**：是否有"最强宫"的对应概念？各宫位的精确强度排序是什么？

### 新概念发现：多值输出

金星在奴仆宫有两首诗诀、四个输出维度——这是11星中唯一的多值输出案例。说明星曜×宫位的映射不是单值函数，而是多值函数。

**待发现**：其他宫位是否也有星曜出现多首诗诀？如果有，需要建立"星曜×宫位→多维度输出"的完整映射矩阵。

**待发现**：在其他宫位的星曜照宫歌中，是否也有"道德/行为修转化"的概念？如果有，需要建立"命主行为因子"的形式化维度。

规则3土星照奴仆宫出现"世俗无成/方外有名"的双值输出——同一星曜在同一宫位，在不同人生领域有相反判定。

**待发现**：是否需要建立"评价领域"维度？如：世俗/方外、事业/健康、人际/内心等。星曜效果可能是`效果(星曜, 宫位, 领域)`的三元函数。

## 时代性思考

### 1. "无寸禄"在现代社会的兑现

木星照奴仆宫"决主一生无寸禄"——古代"无寸禄"指无官职俸禄。在现代社会：
- 不再是"无官职"，而是"收入不稳定"或"缺乏固定薪酬"
- 可能映射为自由职业、零工经济、非稳定就业
- **能量单位不变**（木星在奴仆宫=吉星在最弱宫=才能难以兑现），但兑现方式从"无官职"变为"收入不稳定"

### 2. "奴仆"概念的当代演变

古代"奴仆"指家奴仆从。在现代社会：
- "奴仆宫"可重新解读为"下属/员工/服务关系宫"或"外包合作宫"
- "奴仆成行难保住"→员工流失率高/合作关不稳定
- "奴仆不安"→团队管理困难/下属不满
- "招贼盗财"→商业欺诈/信任背叛

**星象是条件不是宿命**：奴仆宫的"弱/陷方"性质不变，但"奴仆"的内涵从"家奴"变为"职场关系/合作关系"。

### 3. "释道归林"的当代解读

土星照奴仆宫"不如释道归林教，高卧山中有大名"——古代指出家修行。在现代：
- 不一定是宗教出家，可以是"非主流生活方式选择"
- 如：远离职场竞争、选择自由职业、追求精神生活
- "高卧山中有大名"→在非主流领域获得声望（如独立学者、艺术家、修行者）

**时代性修正**：古代"释道归林"是世俗失败的退路，现代可以是主动选择的生活方式。

### 4. "克妻/克父/克母"的当代解读

金星照奴仆宫"少年还须克少妻"、太阴照奴仆宫"月守是宫先克父…母先凶"——古代"克"指刑克死亡。在现代社会：
- "克妻"→婚姻关系紧张/离异/配偶健康问题
- "克父/克母"→与父母关系疏远/父母健康隐患
- **能量单位不变**（星曜在弱宫对六亲的负面影响），但"克"的兑现从"死亡"变为"关系问题/健康隐患"

### 5. "崇道德→安贫乐道"的当代意义

罗喉照奴仆宫"崇道德→陋巷箪瓢"——在古代是颜回式的安贫乐道。在现代：
- 道德修养仍然可以转化凶象的兑现方式
- "陋巷箪瓢"→简朴生活但内心安宁
- **事在人为的边界**：罗喉的凶性不会消失，但人可以选择"如何面对"——被动受祸 vs 主动安贫
