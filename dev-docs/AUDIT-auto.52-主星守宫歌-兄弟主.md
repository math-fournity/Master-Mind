## 形式化分析

### 1. 形式化五问

#### 规则: 闲极主入命宫 → 纵为告曜总成空

- **算子**: 入（宫主星进入另一宫位，即"守宫"算子）
- **输入**: 闲极主（兄弟宫主星）+ 命宫
- **输出**: 凶——纵为告曜总成空（即使该星为吉曜/告曜，也终究成空，无实际成就）；白日只宜闲袖手（白天只适合闲着袖手旁观）；不知衣禄自何从（不知衣食俸禄从何而来）
- **可求值性**: 是——给定星盘，可检查兄弟宫（闲极宫）的主星是否落入命宫
- **一致性**: 与七政四余主星守宫体系一致。闲极宫为弱宫之一，其主星入命宫，意味着弱宫之主侵入本命宫位，纵有吉星之形，亦无吉星之实。与《星平会海》内部"身命居之，无悦快乐"（闲极主入身命→闲散）的注释完全一致。

#### 关键术语考辨

1. **"闲极主"**: 即兄弟宫主星。在《星平会海》体系中，兄弟宫又名"闲极宫"，其宫主星称"闲极主"。代号"三"（命宫主为"一"）。
2. **"告曜"**: 此词仅见于《星平会海》此段，他处未见。"告"疑为"吉"之通假或刻误，"告曜"即"吉曜"（吉星）。另一种可能："告"通"皓"，意为明耀之星。无论哪种解释，歌诀的核心逻辑是"纵使是吉星，入命也成空"——即闲极主本身性质使吉星失效。
3. **"闲袖手"**: 闲着手、袖手旁观，形容无所事事。
4. **"衣禄"**: 衣食俸禄，指基本生活保障。

### 2. 定量化分析

#### 宫位编号体系
- 闲极主代号"三"——在《星平会海》的宫主编号体系中，命宫主为"一"，闲极主为"三"，官禄主对应另一个编号。这是一种**序号化的宫主标识系统**。
- 闲极宫=午位=离卦=狮子宫=三河（周地分野），有完整的天文-地理-卦象对应链。

#### 量化可能性
- **宫位距离**: 闲极宫（兄弟宫）为命宫顺数第三宫，与命宫相隔两个宫位（60°）。闲极主入命宫，意味着该宫主星"逆行"回到命宫——这是一种"宫主离宫"的格局。
- **兄弟数量推断**: 果老星宗"閑極三人手足隨"提供了量化对应——闲极宫星曜状态→兄弟数量。但《星平会海》此段不关注兄弟数量，而关注命主自身命运。
- **"总成空"的量化**: 歌诀用"纵……总……"的让步句式，表明这是一种**无条件凶断**——无论闲极主是什么星、什么状态，入命宫即为凶。量化上可视为概率=1的凶断规则。

### 3. 开放性分析

#### 待考证概念
1. **"告曜"**: 此词为孤例，需进一步考证：
   - 假说A："告"="吉"之通假/刻误 → "告曜"="吉曜"
   - 假说B："告"通"皓"（明也） → "告曜"=明耀之星
   - 假说C："告"为"吉"的方言/俗写
   - **倾向假说A**，因歌诀逻辑为"纵为吉曜也成空"，让步句式需要"吉"与"成空"形成对比。

2. **"闲极"与"兄弟"的宫位对应**: 《星平会海》将兄弟宫称为"闲极宫"，这一命名逻辑值得注意——兄弟宫在命理实践中主兄弟关系，但"闲极"之名强调的是"闲散到极点"，暗示兄弟宫的能量性质为"闲/弱"。这与《星学大成》将闲极归为"陷地"一致。

3. **宫主编号系统**: "一"（命宫主）、"三"（闲极主）的编号体系是否扩展到全部十二宫？若存在完整的1-12编号，则这是一套**序号化宫主系统**，可用于形式化建模。

#### 新发现
1. **"三河"=闲极宫=午位**: 这是天文分野体系与宫位体系的交叉点。午位=离卦=三河=周地=狮子宫，形成"宫位-卦象-分野-星座"的四重对应。
2. **"主欺三"格局**: 卷三"先贫后富主欺三"——命宫主（一）克闲极主（三）→先贫后富。这是宫主之间的相克关系规则，可形式化为宫主互动算子。

### 4. 全息分析（跨体系）

#### 与八字体系的对应
- **兄弟宫→比肩/劫财**: 八字中以比肩、劫财为兄弟星。闲极主入命宫，类似八字中"比劫夺财"——兄弟星过旺则夺命主之财，导致"不知衣禄自何从"。
- **"纵为告曜总成空"**: 类似八字中"比劫虽为同辈，然夺财则凶"——即使比劫为喜神，在某些条件下也主破财。

#### 与紫微斗数的对应
- **兄弟宫**: 紫微斗数亦有兄弟宫，主兄弟关系及同辈助力。
- **"闲极"概念**: 紫微斗数中无"闲极"之名，但有"闲"的概念（如某些星曜的"闲"地）。
- **宫主入命**: 紫微斗数中无"宫主星"概念（以宫内星曜论断为主），但"兄弟宫星曜冲照命宫"的逻辑与此类似。

#### 与果老星宗的对应
- **闲极宫=兄弟宫**: 两书一致。
- **算子方向差异**: 果老星宗"星入闲极"（星→闲极宫）vs 星平会海"闲极主入命"（闲极主→命宫），方向相反但共享同一宫位体系。
- **天耗星=兄弟主**: 果老星宗以天耗星为兄弟主（"耗财之神，故以兄弟当之"），与星平会海以"闲极主"为兄弟主，命名逻辑不同但功能相似——都强调兄弟宫的"耗散/闲散"性质。

### 5. 时代性分析

#### 历史背景
- **"衣禄"**: 古代指官俸或基本生活保障。"不知衣禄自何从"反映古代社会对"有稳定收入来源"的重视。
- **"白日只宜闲袖手"**: "白日"指白天/日常，"闲袖手"形容无所事事。在农耕社会，白天不劳动意味着没有产出，是严重的负面评价。
- **"闲极"的社会含义**: 在古代社会，"闲"并非现代的"休闲"之意，而是"无业/无用"的贬义。闲极主入命→一生无用，是社会价值观的投射。

#### 现代诠释
- "纵为告曜总成空" → 即使有好的天赋或资源，也难以转化为实际成就
- "白日只宜闲袖手" → 缺乏行动力，倾向于被动等待
- "不知衣禄自何从" → 经济来源不稳定，缺乏职业方向
- **现代对应**: 可能对应"有天赋但缺乏执行力"或"高潜力低成就"的人格类型

1. **算子维度**: "入"（宫主星进入另一宫位）——主星守宫歌的核心算子，与星曜交会歌的"会"算子互补
