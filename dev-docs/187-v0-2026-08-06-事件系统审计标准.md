## 一、模块功能概览

events子系统负责从Solver输出捕获原始事件、抽取语义事件、存储事件和checkpoint。

| 模块 | 功能 |
|---|---|
| capture | 从Solver公开输出/工具调用/分支选择创建RawEvent，不捕获隐藏CoT |
| extractor | 规则based语义抽取，从RawEvent推断SemanticEvent类型 |
| store | ArangoDB存储原始/语义事件 + 内容寻址checkpoint |

## 二、审计检查项

### 2.1 事件捕获完整性（capture.py）

| 检查项 | 说明 | 标准 |
|---|---|---|
| 不捕获隐藏CoT | 不捕获LLM内部thinking/隐藏推理 | 只捕获公开产物（文本输出/工具调用/草稿） |
| causal_predecessors链 | 每个事件自动链接到上一个事件 | 事件链是完整的DAG |
| 事件类型覆盖 | 工具调用/代码执行/分支选择/回退/命题/停滞/运行开始结束 | 7类事件都有捕获 |
| run_id关联 | 每个RawEvent关联到run_id | run_id字段非空 |

**判定**：通过=4项全通过；有缺陷=捕获了大部分但漏了某类事件；失败=捕获了隐藏CoT或因果链断裂

### 2.2 语义抽取质量（extractor.py）

| 检查项 | 说明 | 标准 |
|---|---|---|
| 抽取失败不丢证据 | 无语义抽取的RawEvent保留原始证据 | 返回None时RawEvent仍存储 |
| 置信度标注 | 每个SemanticEvent有confidence | confidence字段非空 |
| 批量抽取支持 | 支持从RawEvent列表批量抽取 | 批量模式正常工作 |
| 覆盖度 | 语义抽取覆盖的RawEvent比例 | 统计指标，目标>50%（176号审计基线52%） |

**判定**：通过=4项全通过；有缺陷=覆盖度<50%但抽取正确；失败=抽取失败时丢失原始证据

### 2.3 事件存储与checkpoint（store.py）

| 检查项 | 说明 | 标准 |
|---|---|---|
| append-only | 原始事件不允许修改或删除 | 无update/delete操作 |
| DAG验证 | 事件因果图是有向无环图 | 自环检查通过，无环 |
| checkpoint不含隐藏状态 | checkpoint不含LLM隐藏内部状态 | checkpoint只有task/workspace/event_prefix/model_config/budget |
| 内容寻址 | checkpoint用内容哈希标识 | content_hash字段存在且唯一 |
| 完整度度量 | 事件存储完整度可度量 | 有完整度度量方法 |
| 单调增长验证 | 事件存储单调增长 | 有单调增长验证方法 |
| 追溯验证 | 事件可追溯到原始来源 | 有追溯验证方法 |

**判定**：通过=7项全通过；有缺陷=存储正确但度量缺失；失败=事件被修改/删除或因果图有环或checkpoint含隐藏状态
