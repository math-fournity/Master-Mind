## 零、先说结论（给编码者）

铁板神数从"生辰八字"到"条文编号"的完整链路有两条性质不同的阶段：

1. **可编码阶段（确定性）**：八字 + 刻 → 太玄数 → 先天/后天基本卦 → 基本数（四位数）。这一步没有任何秘传，纯算术，可以 100% 枚举。
2. **半编码 / 不可编码阶段（秘传）**：基本数 → 条文编号，需要叠加**秘数（调整数 / 分项秘数 / 父母生肖考刻表）**。这些秘传表至今未完整公开，因此"八字×刻 → 具体条文正文"**无法仅凭八字全自动算出**。我们能枚举出的是"基本数及其 ±48/±96 展开的数序集合"，以及用公开公式推出的"分项秘数候选"。

所以本文交付的是：**阶段 1 的完整算法 + 阶段 2 中已公开部分的公式 + 缺口清单**。后续若拿到秘数全表，把阶段 2 接上即可。

口诀：`爻从三十起，乾卦六为头，兑为后少女，只中一网收，变知六八止，应世两同俦，遇十当不用，玄玄妙法周。`
- `爻从三十起`：每个爻基础数 = 30。
- `乾卦六为头`：乾卦初爻从 6 起累加。

- `遇十当不用`：运算中逢整十则舍去/不取（具体细则流派内才全，见缺口）。

### 表 9：八刻分配（时辰 → 8 刻的五行/地支归属）
口诀（360doc 入门一）：`亥子水作初刻，巳午火作两刻，寅卯木作三刻，申酉金作四刻，辰土作五刻，未土作六刻，戌土作七刻，丑土作八刻。`
即：初刻=水(亥子)、二刻=火(巳午)、三刻=木(寅卯)、四刻=金(申酉)、五刻=土(辰)、六刻=土(未)、七刻=土(戌)、八刻=土(丑)。
> "刻"是卦气深浅，不是钟点；同一时辰 8 刻对应不同五行/地支组，进而影响数序。

## 二、阶段 1（可编码）：八字 → 基本数 的两条主算法

### 算法 A：太玄数直接合数法（江湖速成 / 入门法）
最常见公开版，最简单，可完整枚举。

1. 四柱各配太玄数：每柱 = `干太玄×100 + 支太玄×10 + 0`。
2. 四柱相加得一个四位数；**舍弃十位数**（"十位数舍去不用"），仅取千、百位为基数。
3. 例：戊寅(570) + 辛酉(760) + 丁卯(660) + 甲辰(950) = 2940 → 取 **2900** 为条文基数。

```
base_a = (sum(干太玄*100 + 支太玄*10) // 100) * 100   # 去十位个位后两位为零
```

### 算法 B：先天/后天基本卦法（江南派 / 石破天惊所述，较权威）
产出"先天基本数"与"后天基本数"两个四位数，分别查不同条文集。

**B1 先天基本卦 + 先天基本数**
1. 定阴阳：`阳男阴女` 与 `阴男阳女` 取上下卦的顺序相反。
   - 阳男/阴女：上卦 = `(年干太玄 + 年支太玄) mod 8`；下卦 = `(月干太玄 + 月支太玄) mod 8`。
   - 阴男/阳女：上卦 = `(月干太玄 + 月支太玄) mod 8`；下卦 = `(年干太玄 + 年支太玄) mod 8`。
2. 余数查表 2（先天八卦数）得卦。
3. 先天基本数 = `千位:上卦先天数, 百位:下卦先天数`（十位/个位来源公开资料未统一：一说取互卦的先天数作十/个位，一说留 0；见缺口 G2）。
4. 求先天基本卦的**互卦**（二至四爻为下卦、三至五爻为上卦）备用。

**B2 后天基本卦 + 后天基本数**
1. 上卦 = `(日干太玄 + 日支太玄 − 10)`，查表 3（后天八卦数）得卦。
2. 下卦 = `(时干太玄 + 时支太玄 − 10)`，查表 3 得卦。
3. 求后天基本卦的互卦。
4. 后天基本数 = `千位:上卦后天数, 百位:下卦后天数, 十位:互卦上卦后天数, 个位:互卦下卦后天数`。
5. 实例校验：日甲(9)+午(9)−10 = 8 → 艮(后天数8)；时乙(8)+亥(4)−10 = 2 → 坤(后天数2)；山地剥(艮上坤下)，互卦坤为地(2,2) → 后天基本数 **8222**。✅ 与公开案例吻合。

```
xian_tian = qian(上卦先天) * 1000 + kun(下卦先天) * 100   # 十/个位按缺口处理
hou_tian  = 上卦后 * 1000 + 下卦后 * 100 + 互上后 * 10 + 互下后
```

## 三、阶段 2（半编码）：基本数 → 数序（条文候选）的三种展开

"刻"在这里以"±秘数"的形式参与。给定基本数，展开出 8 条（或 48 条）数序去查条文。

### 展开法 1：±48×n（石破天惊 / 北派常见）
以基本数 N 为心，取 n ∈ {2,4,8,16}：
```
N+96, N+192, N+384, N+768, N−96, N−192, N−384, N−768
```
实例：N=8222 → 8318, 8414, 8606, 8990, 8126, 8030, 7838, 7454（与公开 8 条条文一一对应）。✅

### 展开法 2：±96×{1,2,3,4}（sozai 视频 / 入门一派）
```
N±96, N±192, N±288, N±384
```
即"组合数加本命卦数，逐条减 96，最多减四次"（视频原话）。与法 1 数值不同（法1是 48×2=96 起跳但只取 2/4/8/16 倍，法2是 96×1..4），**两派公式不同，见缺口 G1**。

### 展开法 3：±100（江湖速成）
`N±100, N±200, ...` 扩展检索。属简化民间用法，精度低。

### 展开法 4：八卦滚 → 48 条（360doc「教你铁版神数」）
1. 基本卦 → 互卦 → 变卦（基本数 + 年干支数，和 ÷6 余定变爻，阳变阴/阴变阳）→ 上下卦对调出新卦，共得 8 卦。
2. 每卦取「八卦排列洛书数序 / 先天洛书数序 / 后天洛书数序」三组两位数。
3. 三组两两组合 `A×100 + B` → 每卦 6 条数序，8 卦共 **48 条数序**。
4. 实例：基本卦天地否=4410，加出生年乙丑(8×10+8×1=88)得 4498，÷9 余定变爻……最终得 48 条。

## 四、阶段 2（并行起数法）：其他可编码的取数入口

这些方法各自独立产出一组 8 条数序，与 ±48 展开叠加，构成"最少 48 条数序"的命书原料。

### D1 八卦加则取数（入门一）
对每个卦，把六个爻的干支换算成太玄数求和：
- 上卦三爻（干太玄+支太玄）之和 = 上卦和；下卦三爻之和 = 下卦和。
- 数序 = `上卦和×100 + 下卦和`（取各自千位百位）。
- 例：风山渐 上和39 下和42 → **3942**；山水蒙 → 4236；地火明夷 → 3345。
- 一套八字可排出 8 个卦 → 8 条数序。

### D2 四柱天干取数（表 7 权重法）
用表 7 权重对四柱天干加权，配合"日主变卦""前后变卦"等，产出又一组 8 条数序。具体加权公式公开资料未给全，仅留口诀与权重表。

### D3 考刻取数（定刻分）
- 工具：八刻天干数表、乾宫甲流度（考父生肖）、坤宫甲流度（考母生肖）、甲乙斗宫秘数（兜底）。
- 流程：先用八刻天干数考；考不到则考父生肖（乾宫甲流度）→ 得"刻"；再考不到则考母生肖（坤宫甲流度）；再不行用甲乙斗宫秘数。
- 父母生肖考刻表（核心秘表）：**父生肖 × 母生肖的 12×12 = 144 组合 → 144 个条文基数，范围 9024–10454，步长 10**。
  - 已知实例：乾宫甲流度「子」→ 9003；坤宫甲流度「亥」→ 10155。
  - 得基数后以基数 ±96×{1,2,3,4} → 8 条数序（与展开法 2 同源）。
- **关键限制**：刻不是由八字算出的，而是由"已知父母生肖"反查出来的。所以"八字×刻"枚举时，刻必须作为**外部输入**逐刻枚举（每时辰 8 刻），不能从八字内部推出。

### D4 秘数加减（调整数 / 分项秘数）——流派秘传
- **性别固定秘数（主流派）**：男命 +7130（或 +7600），女命 +7600（或 +7130）；超 10000 取后四位。例：先天基本数 2253 + 7130 = 9383。
- **动态秘数（小众派）**：父生肖数 + 母生肖数 + 兄弟数×10 + 时辰数×100，相加后叠加到基本数。
- **分项秘数（网易案例）**：基本数 × 秘数 = 条文号。已知：兄弟 79、父 314、母 315、总格 558。例：基本数 13 × 79 = 1027（兄弟条文）。**这些秘数只是零散泄露，完整秘数表未公开。**

## 五、最终"条文编号 = ?"推导链条（汇总）

以江南派（算法 B + 展开法 1）为例，给定八字 + 性别 + 父母生肖：

```
1. 八字四柱 → 各柱太玄数（表1）
2. 按算法 B 求：
     先天基本卦 → 先天基本数 X (四位数)
     后天基本卦 → 后天基本数 Y (四位数, 含互卦)
3. 性别秘数叠加：Y' = (Y + (7130 if 男 else 7600)) % 10000
4. 考刻：用父母生肖查「乾/坤宫甲流度」得刻 k ∈ {1..8}，并查父母生肖考刻表得基数 Z（9024–10454）
5. 数序集合 = {
       八字直查: 算法A基数,
       先天系: X ± 48×{2,4,8,16},
       后天系: Y' ± 48×{2,4,8,16},
       八卦加则: 8 个卦的 上和×100+下和,
       考刻系: Z ± 96×{1,2,3,4},
       八卦滚: 48 条 (若启用)
   }
6. 每一条数序 → 查《铁板神数》条文库（坤集）→ 条文正文
```

## 七、对"刻"的处理方式（编码要点）

1. **刻不能从八字内部算出**。铁板神数的"刻"是卦气深浅，靠已知六亲（父母生肖等）**反推**（考刻）。因此做"八字×刻"枚举时，刻必须作为**外部循环变量**，每时辰枚举 8 刻（初/二/…/八刻，对应 §表9 的五行地支组）。
2. **刻影响数序的两条路径**：
   - 路径 a（考刻表）：父母生肖 → 乾/坤宫甲流度 → 刻序号 → 考刻表基数 Z → ±96 展开。
   - 路径 b（八刻天干数表）：直接用八刻天干数考六亲，命中即定刻。
3. **枚举规模参考**：年60 × 月12 × 日30 × 时12 × 刻8 × 分15 × 种4 × 男女2 ≈ 2.49 亿种命盘组合（入门一原文数据）。这解释了"为何铁板号称比八字精确 480 倍"。

## 八、研究缺口（阻碍"八字×刻 → 条文正文"全自动化的原因）

1. **秘数全表未公开**：分项秘数（兄弟/父/母/总格/夫妻/子女/财官…）、性别秘数、八卦滚的卦→数序换算全表，均只在师承内流传。目前仅零散泄露几个（79/314/315/558/7130/7600）。**这是最核心的阻断**。
2. **父母生肖考刻表（144 基数）只知范围与 2 个样例**（9003、10155），缺 142 个。无法据此反推刻。
3. **太玄数合数法的"十位舍去"规则**：舍去后是否还参与其他运算，公开表述含糊。
4. **八卦加则逐爻细则**（遇十当不用、变知六八止的具体进位/去位）缺完整算法。
5. **先天基本数十/个位来源**未统一。
6. **南北派算法二进制不兼容**：同一八字在不同派别得到不同数序集合，需分别实现。
7. **条文库本身**（坤集 12000 条）是版权/秘传材料，未公开数字化；没有它，数序无法映射到可读断语。
