## 4. 不做什么

- **不删 Master tmux 脚本**（start/enter/stop-master.sh）：Master 在 tmux 中工作本身有价值（持久 session、断线保护），只是不再为 Supervisor 服务
- **不删 dev-docs/003 和 004**：它们是审计方案和审计执行方案，有独立价值，只移除其中的 Supervisor 交互节
- **不动 dev-docs/116**：其中的"监督"是 POC 测试的 tmux 监督，不是 Supervisor Agent
- **不动 knowledge/arxiv/**：学术论文内容，与本项目无关
- **不删 commit 历史**：git log 中的 Supervisor commit 保留，是历史记录

## 5. 风险

- **Supervisor 目录删除不可逆**：该目录是独立 git 仓库，没有 remote，删除后无法恢复。如果未来想恢复 Supervisor 系统，需要从本 repo 的 commit 历史中重建。
- **dev-docs/002 删除**：该文档包含审计需求梳理内容，但审计需求已在 146/147 号文档中覆盖，删除不影响审计工作。
