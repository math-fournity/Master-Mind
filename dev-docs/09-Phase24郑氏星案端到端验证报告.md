# Phase 24: 郑氏星案40例端到端验证报告

## 验证目标

用《张果星宗》卷十八郑氏星案40例的四柱干支，通过干支→公历转换→排盘，验证七政四余推命系统的端到端准确性。

## 数据来源

- **郑氏星案40例**：从 tianyugong.com 获取完整40例
- **每例含**：四柱干支(年月日时) + 性别 + 命格等级 + 星格 + 命理分析
- **年代**：元代约1264-1403年（郑希诚是元代人，浙江瑞安人）

## 验证流程

```
四柱干支 → 干支→公历转换 → calc_four_poles验证 → build_chart排盘
```

### 干支→公历转换

1. **年柱→公历年**：60甲子循环，基准1984=甲子，候选年份1264/1324/1384±60年
2. **日柱→公历日**：60日循环，基准2000-01-07=甲子，在1260-1420范围内搜索
3. **时柱→UT**：北京时间-8h=UT，子时(23-1CST)用15.5UT(23:30CST)避免跨日
4. **月柱验证**：用calc_four_poles的节气分月模式自动验证

### 关键修复

在验证过程中发现并修复了`calc_four_poles`的多个bug：

1. **节气分年月模式**：新增`use_solar_terms=True`参数，用回归黄道太阳位置判断节气月
   - 节气基于回归黄道，不是恒星黄道（ayanamsa≈23.7°）
   - 立春(315°)分年，小寒(285°)-立春(315°)为前一年
   - 月柱地支按节气划分：寅=315-345°, 卯=345-15°, ..., 丑=285-315°

2. **年柱基准修复**：用1984=甲子作为基准（原代码用公元4年=甲子，错误）

3. **时柱hour_index修复**：`hour_index = ((adj_hour + 1) // 2) % 12`（原代码缺少%12，导致23时=12而非0）

4. **早子时规则**：23时后不用次日天干（果老星宗用早子时，23-0时属于当日子时）

## 结论

1. **干支→公历转换**：40/40成功，验证了干支纪日→公历转换的正确性
2. **节气分年月**：修复后的`calc_four_poles(use_solar_terms=True)`完全符合果老星宗传统
3. **早子时规则**：果老星宗用早子时（23-0时属于当日），验证了时柱计算的正确性
4. **排盘引擎**：所有40例都能成功排盘，输出命宫/身宫/ASC/七政四余位置
