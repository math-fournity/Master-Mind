## 一、规则语法扩展指南（18.1）

### 规则文件位置

`qizheng/rules_library.json` — 134 条格局规则。

### 规则结构

```json
{
  "id": 1,
  "sign": "+",           // "+" 吉格, "-" 凶格
  "name": "&{日,月,金,木,水,火,土}垣",
  "priority": "2.0.1",   // 优先级（越大越优先）
  "condition": "@{}[1]={}",  // 条件表达式
  "excludes": [],        // 互斥规则ID
  "comment": "入垣"      // 说明
}
```

### 条件表达式语法

| 符号 | 含义 | 示例 |
|---|---|---|
| `@{行星}` | 行星黄经 | `@{日}` = 太阳黄经 |
| `%{行星}` | 行星所在宫位 | `%{日}[1]` = 太阳所在宫的宫主 |
| `${函数}` | 内置函数调用 | `${生{日}}` = 太阳的五行生曜 |
| `?{变量}` | 布尔标志 | `?{日顺}` = 太阳是否顺行 |
| `&{...}` | 集合匹配 | `&{日,月,金}` = 匹配日/月/金 |
| `!{...}` | 否定 | `!@{罗}` = 罗睺不在... |
| `func()` | 函数调用 | `test()`, `map()` |

### 新增规则示例

```json
{
  "id": 135,
  "sign": "+",
  "name": "紫炁朝斗",
  "priority": "3.1.1",
  "condition": "@{炁}=$北斗",
  "excludes": [],
  "comment": "紫炁入北斗宫，主贵"
}
```

### 新增规则步骤

1. 在 `rules_library.json` 末尾添加新规则，ID 递增
2. 确保条件表达式语法正确（参考 `_eval_simple_condition` in core.py）
3. 如需新函数，在 `_call_builtin_function` 中注册
4. 用 `python3 -m qizheng.chart --json '{...}'` 测试

## 二、常量格式扩展指南（18.2）

### 常量文件位置

`qizheng/constants.json` — 主数据常量。

### 顶层结构

```json
{
  "_source": "来源说明",
  "_note": "备注",
  "ayanamsa": {"mode": "Lahiri", "offset": 0},
  "zodiac": {"signs": [...]},
  "house": {...},
  "life_sign": {...},
  "limits": {"limit_seq": [...], "child_seq": [...], ...},
  "lunar_mansions": {"width_yellow": {...}, ...},
  "sheng_zhang_12_stages": {...},
  "dignity_states": {...},
  "na_yin_60": {...},
  "ten_god_transform": {...},
  "stem_stars": {...},
  "branch_stars": {...}
}
```

### 新增常量示例

```json
{
  "_new_field_source": "《星学大成》卷五",
  "new_field": {
    "key1": "value1",
    "key2": ["a", "b", "c"]
  }
}
```

### 新增常量步骤

1. 在 `constants.json` 中添加新字段，以 `_` 前缀记录来源
2. 在 `core.py` 的 `_c()` 函数中无需修改（直接读取）
3. 在使用处用 `core._c()["new_field"]` 访问
4. 如需校验，添加到 `test_phase13.py` 或新建测试

## 三、神煞格式扩展指南（18.3）

### 神煞文件位置

`qizheng/shen_sha_complete.json` — 完整神煞体系。

### 顶层结构

```json
{
  "star_sky_earth_key": "...",   // 天干地支神煞
  "star_sky_qi_key": "...",      // 天干气神
  "star_sky_key": "...",         // 天干神煞
  "star_earth_key": "...",       // 地支神煞
  "star_month_key": "...",       // 月神煞
  "star_month_hour_key": "...",  // 月时神煞
  "star_sign_key": "...",        // 宫位神煞
  "year_sign_key": "...",        // 年神煞
  "year_star_map": {...},        // 年星映射
  "year_star_seq": [...],        // 年星序列
  "birth_year_signs": [...],     // 60甲子年名
  ...
}
```

### 新增神煞示例

```json
{
  "new_star": {
    "name": "新神煞",
    "type": "年神",
    "calc": "year_branch_index % 12",
    "effect": "主贵",
    "source": "《协纪辨方书》卷二十三"
  }
}
```

### 新增神煞步骤

1. 在 `shen_sha_complete.json` 中添加新字段
2. 在 `core.py` 的 `_load_shen_sha()` 确认加载
3. 在 `get_star_signs()` 中添加计算逻辑
4. 用测试用例验证神煞出现在正确位置
