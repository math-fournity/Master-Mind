## 宫位性质定位

迁移宫（第九宫）在七政四余宫位体系中是**弱宫、恶宫**——`qizheng/shen_sha_complete.json` 明确标注：`"迁移": "92, 福食, 弱、恶宫"`。

这与前一段疾厄宫（弱宫）和奴仆宫（弱、恶宫）属于同一弱宫阵营，但与妻妾宫（强、正宫）形成对比：

| 宫位 | 强度 | 神煞值 | 性质 |
|---|---|---|---|
| 命宫 | 强、正宫 | 99, 权印 | 最强 |
| 妻妾宫 | 强、正宫 | 94, 荫偏 | 强 |
| **迁移宫** | **弱、恶宫** | **92, 福食** | **弱** |
| 疾厄宫 | 弱宫 | 98, 囚枭 | 弱 |
| 奴仆宫 | 弱、恶宫 | 96, 刑杀 | 最弱 |

**关键矛盾发现**：迁移宫的数值（92）与福德宫（92）和财帛宫（92）相同，但后两者标注为"强宫"，迁移宫却标注为"弱、恶宫"。这说明**宫位强弱不仅取决于数值，还取决于宫位本身的性质**——迁移宫涉及奔波离乡，天然带有"不稳定"的恶宫属性，即使数值不低也被归为弱宫。这是"**宫位性质≠宫位数值**"的重要发现。

然而，与奴仆宫（最弱宫）不同的是，迁移宫的判定并非全凶——因为"迁移"本身可以是积极的（荣迁、调任、商贾得财）。**弱宫中的迁移宫具有双面性**：凶星主漂荡破家，吉星主荣迁得贵。这是迁移宫区别于其他弱宫的独特性质。

## 规则提取与形式化五问

本段包含 **11 条规则**（11星曜各照迁移宫一条）+ 1 段释云总注。每条规则以四句七言诗形式呈现。

### 文本异常记录：星曜序列偏差

在标准11星序列（木/火/土/金/水/日/月/气/孛/罗/计）中，本段出现两个偏差：

1. **位置1应为木星，实际为水星**："水星得地九宫存"——与疾厄宫（第8段）位置1同为"水星解散照其宫"一致。妻妾宫（第7段）位置1正确为"木宿游"。推测为OCR系统性误读（木→水），或原典在后期宫位段省略了木星条目而以水星代之。
2. **位置5亦为水星**："水星合照最为珍"——与疾厄宫位置5"第八官中水德临"一致。
3. **位置8为"寿星"**："第九宫中有寿星"——非标准11星名称。对照疾厄宫位置8明确为"紫气"，且"寿星"的描述（"清高秀""有道人"）与紫炁的清孤修道本性完全一致。星学大成第63行"若是寿星临照着，也须为福不为凶"亦佐证寿星=紫炁的清修吉性。**判定：寿星=紫炁别名**。

**结果**：本段实际覆盖 10 颗独立星曜（水×2, 火, 土, 金, 日, 月, 紫炁, 孛, 罗, 计），缺木星。以下按文本顺序提取11条规则。

### 规则 1：水星照迁移宫（第一位）

> 水星得地九宫存，三方傍照命宫门。更得高高明健处，荣迁真得贵人尊。

| 形式化五问 | 回答 |
|---|---|
| **算子** | 得地（水星落入迁移宫且得地）+ 三方傍照（三方关系照临命宫）+ 高高明健（庙旺高强条件） |
| **输入** | 水星位置 ∈ 迁移宫（第九宫）；水星是否得地/庙旺；迁移宫与命宫的三方关系 |
| **输出** | 吉——三方傍照命宫门；若高高明健→荣迁真得贵人尊 |
| **可求值** | ✅ 是。判定水星是否在第九宫 + 水星庙旺状态 + 三方是否照临命宫 → 输出荣迁判定 |
| **与规则库一致** | ✅ 水星主智慧，在迁移宫得地则吉——智慧用于迁移/出行则得贵人。三方傍照命宫=迁移宫的星曜通过三方关系影响命宫 |

**关键发现**：本规则首次在星曜照宫歌中明确使用"**三方傍照**"概念——迁移宫（第九宫）与命宫（第一宫）通过三方（120°相位）关系互相影响。形式化：`三方(第九宫) ∋ 第一宫`（第九宫是第一宫的三方宫之一）。这不是简单的宫位编号，而是**宫位间的相位几何关系**——三方=120°和谐相位。

### 规则 2：火星照迁移宫

> 火星照位入迁移，迁变东西土产移。家舍亦须防火厄，末年有屋可安居。

| 形式化五问 | 回答 |
|---|---|
| **算子** | 照位入（火星落入迁移宫） |
| **输入** | 火星位置 ∈ 迁移宫（第九宫） |
| **输出** | 凶中有吉——迁变东西土产移（奔波变动）；家舍防火厄；末年有屋可安居（条件性减凶） |
| **可求值** | ✅ 是。判定火星是否在第九宫 → 输出迁变/火厄/末年安居判定 |
| **与规则库一致** | ✅ 火星主燥急刑害，在弱宫（迁移=弱、恶宫）主奔波变动。但"末年有屋可安居"是条件性减凶——火星的凶性在迁移宫随时间递减 |

**释云对应**："主不安，谓火性摇动"——火星本性摇动不安，在迁移宫则表现为迁变东西。

**关键发现**："迁变东西土产移"中的"土产移"疑为"土产移"=产业迁移，或OCR变体。火星在迁移宫的凶性表现为**空间位移**（迁变东西）和**财产损失**（土产移/家舍火厄），但末年可安居——凶性有时间衰减特征。

### 规则 3：土星照迁移宫

> 土德当生在九宫，命星合照莫相逢。男人漂荡他乡里，女子*奔外姓中。

| 形式化五问 | 回答 |
|---|---|
| **算子** | 当生在（土星落入迁移宫）+ 命星合照莫相逢（命主星不应与土星合照）+ 性别条件 |
| **输入** | 土星位置 ∈ 迁移宫（第九宫）；命主星是否与土星合照；命主性别 |
| **输出** | 凶——命星合照则男人漂荡他乡，女子外奔外姓 |
| **可求值** | ✅ 是。判定土星是否在第九宫 + 命主星是否与土星合照 + 性别 → 输出漂荡/外奔判定 |
| **与规则库一致** | ✅ 土星主镇重孤高，在弱宫（迁移=弱、恶宫）主漂荡。与妻妾宫中土星"夜生不可逢"的凶判一致——土星在弱宫更凶 |

**释云对应**："忌命星犯"——命主星不应与迁移宫的土星合照，犯则漂荡。

**关键发现**：本规则有**性别条件分支**——与妻妾宫规则2"女人以火为夫位"类似，土星在迁移宫对男女有不同兑现：
- 男人：漂荡他乡（空间位移）
- 女子：外奔外姓（社会身份变更——嫁外姓/离家）

这是"**性别条件迁移兑现**"概念——同一星曜在迁移宫的凶性，对男命兑现为空间漂泊，对女命兑现为社会身份脱离。

### 规则 4：金星照迁移宫

> 金星得地照迁移，调任荣迁福自宜。若更命无凶曜照，仰观平地上云梯。

| 形式化五问 | 回答 |
|---|---|
| **算子** | 得地照（金星落入迁移宫且得地）+ 命无凶曜条件 |
| **输入** | 金星位置 ∈ 迁移宫（第九宫）；金星是否得地；命宫是否有凶曜 |
| **输出** | 吉——调任荣迁福自宜；若命无凶曜→仰观平地上云梯（步步高升） |
| **可求值** | ✅ 是。判定金星是否在第九宫 + 金星庙旺状态 + 命宫是否有凶曜 → 输出荣迁/云梯判定 |
| **与规则库一致** | ✅ 金星主义，在迁移宫得地则吉——金星的吉性在迁移宫兑现为调任荣迁。"仰观平地上云梯"=步步高升的隐喻 |

**关键发现**：金星在迁移宫是**纯粹吉判**（无条件凶分支，仅有加吉条件）——即使迁移宫是弱宫，金星的吉性仍可兑现。这与奴仆宫（最弱宫）中金星"吉性反转"形成对比。说明**迁移宫虽为弱宫，但其"弱"不同于奴仆宫的"反转"**——迁移宫的弱在于不稳定性，而非完全反转星曜本性。迁移宫的吉星可为吉（荣迁），凶星主凶（漂荡），更接近"中性偏弱"而非"反转弱"。

### 规则 5：水星合照照迁移宫（第二位）

> 水星合照最为珍，更看当生命位星。宾主和同无恶犯，迁移出处总欢宁。

**关键发现**：本规则首次出现"**宾主**"概念——"宾主和同"中的"宾"=迁移宫星曜（水星），"主"=命主星。这是**宫位主客关系**概念——迁移宫的星曜为"宾"（外来因素），命主星为"主"（内在根本），宾主和同则吉。

**释云对应**："限主为主度，主为宾"——释云中的"主为宾"与此呼应，但释云的表述更复杂：限主=主度（大限主星为本度），主=宾（命主星反而为宾？）。这涉及**限运与迁移的主客反转**——在限运推演中，限主为主，命主为宾；在星曜照宫中，迁移宫星为宾，命主为主。主客关系随语境而变。

### 规则 7：太阴照迁移宫

> 太阴得在九宫中，三合加临照命同。偏利迁移商贾客，必因阴贵得财丰。

**关键发现**：本规则首次将太阴与**商贾**（商人）关联——"偏利迁移商贾客"。太阴主财，在迁移宫（出行/贸易宫）则兑现为**经商得财**。这是"**星曜×宫位=职业倾向**"概念——太阴在迁移宫→商贾，太阳在迁移宫→对策天庭（学者/仕途），形成了星曜在迁移宫的职业分化。

**全息思考**：太阴在迁移宫利商贾，与八字中"偏财主经商"同构——太阴=阴财=偏财，迁移=动=经商。底层模式：阴柔之星在动态宫位→流动获利。

| **可求值** | ✅ 是。判定紫炁是否在第九宫 → 输出有道人判定 |
| **与规则库一致** | ✅ 紫炁为清孤修道之星，在迁移宫主"有道人"——紫炁的"孤"属性在迁移宫兑现为"清高超脱"而非"克凶"。与妻妾宫中紫炁"克凶/出家"不同——迁移宫的紫炁是**吉判**（有道人=正面评价），而非妻妾宫的凶判（克妻=负面评价） |

**关键发现**：紫炁在迁移宫是**吉判**——这是紫炁在已审计宫位中的**第二个吉判**（第一个是田宅宫"福荫双亲"）。紫炁的"孤"属性在迁移宫转化为"清高超脱/有道"——迁移宫的"远离"性质与紫炁的"孤"性质形成**同向叠加**，反而产生了正面效果：远离世俗=修道之人。

**定量化更新**：紫炁在6个已审计宫位的表现光谱：

| 宫位 | 宫位强度 | 紫炁表现 | "孤"的面向 | 吉凶 |
|---|---|---|---|---|
| 命宫 | 强 | 清孤修仙 | 自身孤独→超脱 | 中性偏吉 |
| 田宅宫 | 强 | 福荫双亲 | 孤性转化为福荫 | 吉 |
| 兄弟宫 | 弱 | 两分离 | 手足孤独→分离 | 凶 |
| 奴仆宫 | 最弱 | 孤高欠情 | 仆从孤独→无人伺候 | 凶 |
| 妻妾宫 | 强 | 克凶/出家 | 伴侣孤独→克妻 | 凶 |
| **迁移宫** | **弱** | **有道人** | **远离世俗→修道** | **吉** |

**新发现**：紫炁在迁移宫（弱宫）为吉，打破了"强宫吉、弱宫凶"的简单模型。紫炁的吉凶不取决于宫位强度，而取决于**宫位性质与孤性的契合度**：
- 迁移宫=远离故乡→与紫炁的"孤"同向→吉（修道）
- 妻妾宫=伴侣关系→与紫炁的"孤"逆向→凶（克妻）
- 田宅宫=家庭根基→与紫炁的"孤"部分同向（清静家宅）→吉（福荫）

形式化：`紫炁吉凶 = f(宫位性质, 孤性契合度)`，而非简单的`f(宫位强度)`。

### 规则 9：月孛照迁移宫

> 李到迁移为恶宿，口舌阴谋被辱凌。屯厄败家他处死，路横尸首不能兴。

| 形式化五问 | 回答 |
|---|---|
| **算子** | 到（月孛落入迁移宫） |
| **输入** | 月孛位置 ∈ 迁移宫（第九宫） |
| **输出** | 凶——口舌阴谋被辱凌，屯厄败家他处死，路横尸首不能兴 |
| **可求值** | ✅ 是。判定月孛是否在第九宫 → 输出辱凌/败家/路死判定 |
| **与规则库一致** | ✅ 月孛为凶曜，在迁移宫主口舌阴谋/败家/客死他乡。与命宫中月孛为凶、妻妾宫中月孛"望门克妇"一致——月孛在所有宫位都主凶 |

**关键发现**：月孛在迁移宫的凶性兑现为**最极端的空间后果**——"他处死""路横尸首"=客死他乡。迁移宫的"远离"性质与月孛的"凶"性质叠加，产生了**最凶的迁移宫判定**。这是迁移宫11条规则中最凶的判定——月孛在迁移宫=客死他乡。

### 规则 10：罗喉照迁移宫

> 罗喉凶曜号权星，临照迁移回禄惊。得在旺宫为禄主，必因提荐贵荣身。

| 形式化五问 | 回答 |
|---|---|
| **算子** | 临照（罗喉落入迁移宫）+ 旺宫条件（罗喉是否在旺宫） |
| **输入** | 罗喉位置 ∈ 迁移宫（第九宫）；罗喉是否在旺宫 |
| **输出** | 凶中有吉——回禄惊（火灾惊恐）；若在旺宫为禄主→必因提荐贵荣身（条件反转） |
| **可求值** | ✅ 是。判定罗喉是否在第九宫 + 罗喉是否在旺宫 → 输出回禄惊/提荐贵荣判定 |
| **与规则库一致** | ✅ 罗喉为凶曜但号权星，在迁移宫有条件反转——旺宫则转为禄主，主提荐贵荣。与已有规则库中罗喉"贵权星"的双重性一致 |

**释云对应**："回禄火星也"——回禄=火神=火星，但此处释云将罗喉的"回禄惊"与火星关联。罗喉在迁移宫的凶性与火星在迁移宫的凶性（规则2"家舍防火厄"）有同源性——都涉及火厄。

**关键发现**：罗喉在迁移宫是**凶+条件反转**模式——基础为凶（回禄惊），旺宫则反转为吉（提荐贵荣）。这与妻妾宫中罗喉"不占高强对官守，一世有灾屯"不同——妻妾宫中罗喉需要"不占高强"才凶，迁移宫中罗喉需要"在旺宫"才吉。**条件反转的方向取决于宫位性质**：
- 妻妾宫（强宫）：罗喉默认凶，需高强才减凶
- 迁移宫（弱宫）：罗喉默认凶，需旺宫才转吉

### 规则 11：计都照迁移宫

> 计都天尾照迁移，利害之端仔细推。出外迎祥因庙旺，不然平照定倾危。

| 形式化五问 | 回答 |
|---|---|
| **算子** | 照（计都落入迁移宫）+ 庙旺条件 |
| **输入** | 计都位置 ∈ 迁移宫（第九宫）；计都是否庙旺 |
| **输出** | 凶中有条件吉——利害仔细推；庙旺则出外迎祥；不庙旺（平照）则定倾危 |
| **可求值** | ✅ 是。判定计都是否在第九宫 + 计都是否庙旺 → 输出迎祥/倾危判定 |
| **与规则库一致** | ✅ 计都为凶曜，在迁移宫有庙旺条件反转——庙旺则出外迎祥，平照则倾危。与罗喉（规则10）的条件反转模式一致——罗计在迁移宫都需要旺宫/庙旺才转吉 |

**关键发现**：计都和罗喉在迁移宫都是"**凶+庙旺条件反转**"模式——这与妻妾宫中罗计"纯粹凶"（无条件反转）不同。迁移宫的弱宫性质使得罗计的凶性更需条件修饰——**弱宫中的凶星更需要庙旺来反转，否则凶性加剧**。

### 释云总注

> 旺相之地，主如是也。主不安，谓火性摇动。忌命星犯。主迁西方。限主为主度，主为宾。若有禄马责人极好。如害破败。回禄火星也。出入不利。

释云对11条规则的总结：
- **旺相条件**：旺相之地，主如是也——以上判定在旺相条件下成立
- **火星不安**：主不安，谓火性摇动——火星在迁移宫主不安（规则2）
- **命星禁忌**：忌命星犯——命主星不应与迁移宫土星合照（规则3）
- **迁移方向**：主迁西方——迁移宫主西方迁移
- **主客关系**：限主为主度，主为宾——限运中限主为主，命主为宾
- **禄马贵人**：若有禄马贵人极好——有禄马贵人则吉
- **回禄=火星**：回禄火星也——回禄（火神）即火星
- **出入不利**：出入不利——总体出入需谨慎

## 定量化思考

### 1. 迁移宫"弱而不反"的交互模型

迁移宫虽为弱宫，但其吉凶分布为 **5吉+6凶**（5条吉判：水星/金星/水星合照/太阳/太阴/紫炁=6吉，5条凶判：火星/土星/月孛/罗喉/计都=5凶），与奴仆宫（最弱宫）的**全凶**（11凶）截然不同。

| 宫位 | 强度 | 吉凶分布 | 模式 |
|---|---|---|---|
| 妻妾宫 | 强、正宫 | 6吉+5凶 | 强宫：吉星吉、凶星凶 |
| **迁移宫** | **弱、恶宫** | **6吉+5凶** | **弱而不反：吉星可为吉、凶星主凶** |
| 疾厄宫 | 弱宫 | 待审计 | — |
| 奴仆宫 | 弱、恶宫 | 0吉+11凶 | 最弱宫：全反转（吉星亦凶） |

**发现**：迁移宫的"弱"与奴仆宫的"弱"性质不同——
- 奴仆宫=**反转弱**：吉星入此宫反转为凶（吉星"无寸禄"）
- 迁移宫=**不反弱**：吉星入此宫仍可为吉（金星"调任荣迁"），凶星入此宫主凶（月孛"客死他乡"）

**量化方案**：
```
判定(星曜, 宫位) = base_effect(星曜本性) × palace_modifier(宫位类型) + condition_modifier(条件)

宫位类型有两种弱宫模式：
- 反转弱（奴仆宫）：palace_modifier = -0.7（吉星反转70%）
- 不反弱（迁移宫）：palace_modifier = 0.8（吉星保留80%本性，但凶星加凶20%）
```

### 2. 三方/三合照临模型

迁移宫（第九宫）与命宫（第一宫）的关系在本段被多次强调：
- 规则1水星："三方傍照命宫门"
- 规则7太阴："三合加临照命同"

**量化方案**：
```
三方照临影响度 = f(星曜在第九宫) × aspect_weight(三方相位)
- 三方/三合 = 120°相位 → aspect_weight = 0.6（约为同宫影响的60%）
- 对宫 = 180°相位 → aspect_weight = 0.7（约为同宫影响的70%，见妻妾宫审计）
- 吉星三方照命 → 加吉（荣迁/商贾得财）
- 凶星三方照命 → 减吉（但本段未出现凶星三方照命的凶判）
```

### 3. 紫炁孤性契合度模型

紫炁在迁移宫为吉（有道人），在妻妾宫为凶（克妻），在田宅宫为吉（福荫）——紫炁的吉凶不取决于宫位强度，而取决于宫位性质与孤性的契合度。

**量化方案**：
```
紫炁吉凶 = base_loneliness(紫炁) × affinity(宫位性质, 孤性)
- affinity(迁移宫, 孤) = +1.0（同向叠加：远离=孤→吉）
- affinity(妻妾宫, 孤) = -1.0（逆向冲突：伴侣≠孤→凶）
- affinity(田宅宫, 孤) = +0.5（部分同向：清静家宅→吉）
- affinity(命宫, 孤) = 0.0（中性：自身孤独→超脱，吉凶不定）
- affinity(兄弟宫, 孤) = -0.7（逆向冲突：手足≠孤→凶）
- affinity(奴仆宫, 孤) = -0.5（部分逆向：仆从≠孤→凶）
```

### 4. 性别条件迁移兑现矩阵

规则3土星在迁移宫有性别条件分支：
- 男人：漂荡他乡（空间位移）
- 女子：外奔外姓（社会身份变更）

**形式化**：`迁移兑现(星曜, 性别) → {空间位移, 社会身份变更}`

| 性别 | 土星在迁移宫 | 兑现方式 |
|---|---|---|
| 男命 | 漂荡他乡 | 空间位移（地理迁移） |
| 女命 | 外奔外姓 | 社会身份变更（嫁外姓/离家） |

**待发现**：其他星曜在迁移宫是否也有性别条件分支？完整的性别×星曜×迁移兑现矩阵需要更多数据。

## 开放性思考

### 新概念发现：三方傍照

规则1"三方傍照命宫门"和规则7"三合加临照命同"——首次在星曜照宫歌中明确使用"三方/三合"概念。迁移宫（第九宫）与命宫（第一宫）通过三方（120°相位）关系互相影响。

**与已有算子的区别**：
- 已有算子（见/逢/守/临/游/入）描述星曜**在**某宫
- 妻妾宫发现"对宫冲射"描述星曜**在**某宫→通过180°对照影响对宫
- 三方傍照描述星曜**在**某宫→通过120°三方影响三方宫

**形式化**：`三方照临(星曜, 宫位A) → 影响宫位B`，其中`B ∈ 三方宫(A)`。

**待发现**：12宫的三方完整映射是什么？三方照临的影响度与对宫冲射的影响度的定量关系是什么？

### 新概念发现：宾主和同

规则5"宾主和同无恶犯"——首次出现"宾主"概念。迁移宫星曜为"宾"（外来因素），命主星为"主"（内在根本），宾主和同则吉。

**与已有算子的区别**：
- 已有算子的输入=(星曜, 宫位)，输出=吉凶判定
- 宾主和同的输入=(迁移宫星曜, 命主星, 关系类型)，输出=和谐/冲突判定

**形式化**：`宾主关系(迁移宫星曜, 命主星) → {和同, 犯克}`

**待发现**：宾主和同的判定标准是什么？是五行相生？是庙旺一致？还是其他关系？

### 新概念发现：弱宫分化（反转弱 vs 不反弱）

迁移宫（弱、恶宫）的吉凶分布为6吉+5凶，与奴仆宫（弱、恶宫）的全凶截然不同。同为"弱、恶宫"，但星曜的吉凶兑现模式完全不同。

**与已有模型的区别**：
- 已有模型：宫位强度=二分（强/弱），强宫吉星吉、弱宫吉星凶
- 新模型：弱宫有子类型——反转弱（奴仆宫：吉星反转）vs 不反弱（迁移宫：吉星不反转）

**待发现**：12宫的弱宫子类型完整分类是什么？哪些弱宫是反转弱，哪些是不反弱？分类标准是什么？

### 新概念发现：紫炁孤性契合度

紫炁在迁移宫（弱宫）为吉——打破了"强宫吉、弱宫凶"的简单模型。紫炁的吉凶取决于宫位性质与孤性的契合度，而非宫位强度。

**形式化**：`紫炁吉凶 = f(宫位性质, 孤性契合度)`，而非`f(宫位强度)`

**待发现**：12宫的孤性契合度完整排序是什么？其他"超宫位"星曜（如月孛的"凶"是否也有契合度模型？）是否也有类似的契合度判定？

### 新概念发现：星曜×宫位=职业倾向

太阴在迁移宫→商贾（规则7），太阳在迁移宫→对策天庭/仕途（规则6）——同一宫位中不同星曜兑现为不同职业倾向。

**形式化**：`职业倾向(星曜, 迁移宫) → {商贾, 仕途, 修道, ...}`

**待发现**：11星在迁移宫的完整职业倾向映射是什么？其他宫位是否也有职业倾向映射？

## 全息思考

### 1. 迁移宫=弱宫的跨体系对应

| 体系 | 迁移宫名称 | 性质 |
|---|---|---|
| 星平会海 | 第九宫/迁移宫 | 弱、恶宫 |
| 果老星宗 | 第九宫/"他鄉得意歸" | 远行/他乡 |

| 紫微斗数 | 迁移宫 | 对宫=命宫，主外出 |

**全息对应**：《果老星宗》卷十二第26行"第九他鄉得意歸"——第九宫主他乡得意归，与《星平会海》迁移宫的"荣迁""调任"吉判一致。《星学大成》第7行"变为福者属财帛福德迁移"——天福星与迁移宫同推，与太阴在迁移宫"必因阴贵得财丰"一致。《星平会海》卷三第192-198行"论迁移"专篇："迁移主星守命，主迁居""凡看迁移必以马星为主"——迁移宫以驿马星为主，与八字的驿马概念同构。

### 2. "三方照临"的跨体系同构

《星平会海》迁移宫"三方傍照命宫门""三合加临照命同"——迁移宫与命宫的三方关系。

在紫微斗数中：迁移宫与命宫是对宫关系（180°），但三方宫（120°）也互相影响——三方宫是紫微斗数的基本相位关系。
在八字中：三合局（申子辰、亥卯未、寅午戌、巳酉丑）是120°相位关系的地支版本。
在果老星宗中：卷六第11行"三方位曰拱"——三方称为"拱"，是基本的相位关系。

**底层模式**：120°三方/三合是跨体系通用的相位关系——三方宫之间互相影响，影响度约为同宫的60%。迁移宫（第九宫）是命宫（第一宫）的三方宫之一。

### 3. "紫炁孤性契合度"的跨体系同构

紫炁在迁移宫（远离故乡）为吉（有道人）——孤性与远离同向叠加则吉。

在八字中：华盖星（孤高之星）在驿马位→出家/修道为吉，在妻位→克妻为凶。
在紫微斗数中：天梁星（孤星）在迁移宫→外地发展/清高为吉，在夫妻宫→孤克为凶。

**底层模式**：孤星在"远离"宫位→孤性同向叠加→吉（修道/清高）；孤星在"亲密"宫位→孤性逆向冲突→凶（克妻/分离）。这是跨体系通用的"孤性契合度"模型。

### 4. "宾主和同"的跨体系同构

《星平会海》迁移宫"宾主和同无恶犯"——迁移宫星曜（宾）与命主星（主）和谐则吉。

在八字中：日主（主）与月令（宾）的关系——日主得月令则吉，日主失月令则凶。
在紫微斗数中：命宫主星（主）与迁移宫主星（宾）的关系——命迁主星和则吉，冲则凶。

**底层模式**：内在核心（主）与外在环境（宾）的和谐度决定吉凶——主宾和同则吉，主宾犯克则凶。这是跨体系通用的"主客关系"模型。

## 时代性思考

### 1. "荣迁真得贵人尊"的当代解读

水星照迁移宫"荣迁真得贵人尊"——古代指升迁远行得贵人扶持。在现代：
- "荣迁"→职业晋升/调任/海外发展
- "贵人尊"→得到上级/导师/人脉的提携
- **能量单位不变**（吉星在迁移宫=远行得贵），但"荣迁"从"官职升迁"扩展为"职业发展/跨国发展"

### 2. "对策天庭谒帝王"的当代解读

太阳照迁移宫"好将平日胸中学，对策天庭谒帝王"——古代指以学养对策于朝廷、面见帝王。在现代：
- "对策天庭"→参加高级别竞争（考试/面试/项目竞标）
- "谒帝王"→面见最高决策者/顶级平台展示才能
- **能量单位不变**（太阳在迁移宫=以学养远行见贵），但"天庭/帝王"从"朝廷/皇帝"变为"顶级平台/决策层"

### 3. "偏利迁移商贾客"的当代解读

太阴照迁移宫"偏利迁移商贾客，必因阴贵得财丰"——古代指利于外出经商，因女性贵人得财。在现代：
- "商贾客"→国际贸易/跨境电商/外出创业
- "阴贵"→女性合作伙伴/隐性人脉/间接资源
- **能量单位不变**（太阴在迁移宫=外出经商得财），但"商贾"从"传统行商"扩展为"全球化商业"

### 4. "男人漂荡他乡里，女子外奔外姓中"的当代解读

土星照迁移宫"男人漂荡他乡里，女子外奔外姓中"——古代指男命离乡漂泊，女命嫁外姓/私奔。在现代：
- "漂荡他乡"→外出务工/异地发展/移民
- "外奔外姓"→跨地区婚姻/外嫁/独立离家
- **时代性修正**：古代"女子外奔"是负面判定（违背礼教），现代"女子离家"可以是正面（独立/自主选择）。星象定义的是"远离原生环境"的能量，其吉凶评价随时代而变。

### 5. "路横尸首不能兴"的当代解读

月孛照迁移宫"屯厄败家他处死，路横尸首不能兴"——古代指客死他乡、路死。在现代：
- "他处死"→异地意外/出行事故
- "路横尸首"→交通事故/旅途意外
- **能量单位不变**（月孛在迁移宫=最凶的出行风险），但"路横尸首"从"路死荒野"变为"交通事故"——出行安全风险仍然存在，但现代交通管理和保险制度提供了缓冲。

### 6. "有道人"的当代解读

紫炁照迁移宫"下照尘寰有道人"——古代指修道之人/出家人。在现代：
- "有道人"→学者/哲学家/精神追求者/独立研究者
- 不一定是宗教人士，可以是"远离世俗追求精神"的任何职业
- **时代性扩展**：古代"有道人"≈道士/僧人，现代可以是"数字游民/独立思考者/精神探索者"
