## 宫位性质定位

妻妾宫（第七宫/夫妻宫）在七政四余宫位体系中是**强宫、正宫**——`qizheng/shen_sha_complete.json` 明确标注：`"夫妻": "94, 荫偏, 强、正宫"`。

这与前一段奴仆宫（弱、恶宫/最弱宫/陷方）形成鲜明对比：
- 奴仆宫 = 最弱宫/陷方 → 所有星曜入此宫基础判定偏凶，吉星减力反转
- **妻妾宫 = 强宫/正宫** → 星曜入此宫保留本性，吉星可为吉，凶星仍为凶

这是理解本段11条规则的基础前提：**强宫不反转星曜本性，而是让星曜本性得到充分表达**。

### 规则 1：木星照妻妾宫

> 第七宫中木宿游，聪明俊雅备祥休。更饶娶得高贤妇，偕老同心到白头。

| 形式化五问 | 回答 |
|---|---|
| **算子** | 游（木星落入妻妾宫） |
| **输入** | 木星位置 ∈ 妻妾宫（第七宫） |
| **输出** | 吉——聪明俊雅，娶高贤妇，偕老同心到白头 |
| **可求值** | ✅ 是。判定木星是否在第七宫 → 输出妻贤偕老判定 |
| **与规则库一致** | ✅ 木星为吉曜，入强宫（妻妾宫=强、正宫）则吉性充分表达。与命宫中木星主仁寿、财帛宫中木星主富的逻辑一致——吉星入强宫=吉性兑现 |

**释云对应**："木主仁，故主妻贤"——木星本性仁，在妻妾宫（强宫）则仁性兑现为妻贤。

**关键发现**：这是星曜照宫歌系列中**首次出现的纯粹吉判**（在强宫中）。对比奴仆宫中木星"决主一生无寸禄"（吉星入最弱宫→反转），妻妾宫中木星"娶得高贤妇"（吉星入强宫→本性兑现）。这验证了"**星曜属性=宫位函数**"维度——同一星曜在不同强度宫位有截然相反的判定。

### 规则 2：火星照妻妾宫

> 火入妻宫定克妻，高强非忌作珍奇。女人以火为夫位，祸福同源一例推。

| 形式化五问 | 回答 |
|---|---|
| **算子** | 入（火星落入妻妾宫）+ 高强判定（是否高强非忌）+ 性别条件（男命/女命） |
| **输入** | 火星位置 ∈ 妻妾宫（第七宫）；火星是否高强非忌；命主性别 |
| **输出** | 男命凶——定克妻；若高强非忌则作珍奇（条件反转）；女命——火为夫位，祸福同源一例推 |
| **可求值** | ✅ 是。判定火星是否在第七宫 + 火星庙旺状态 + 命主性别 → 输出克妻/珍奇/夫位判定 |
| **与规则库一致** | ✅ 火星主燥急刑害，在强宫（妻妾宫）仍主克妻——强宫不反转凶星本性。但"高强非忌作珍奇"是条件分支——庙旺时凶性可转 |

**释云对应**："女火为夫"——女命以火星为夫星。

**关键发现**：本规则首次出现**性别条件分支**——同一星曜在同一宫位，对男命和女命有完全不同的角色定义：
- 男命：火星在妻妾宫 → 克妻（火星=刑克星）
- 女命：火星在妻妾宫 → 火为夫位（火星=夫星，祸福同源）

这是"**性别条件星曜角色**"概念——星曜的命理角色不是固定的，而是`角色(星曜, 性别)`的函数。这是形式系统中的新维度。

- 弱宫：凶基础 + 凶条件叠加（忌星加力）

**定量化思考**：紫炁在5个已审计宫位的表现形成完整光谱：
| 宫位 | 宫位强度 | 紫炁表现 | "孤"的面向 |
|---|---|---|---|
| 命宫 | 强 | 清孤修仙 | 自身孤独→超脱 |
| 田宅宫 | 强 | 福荫双亲 | 孤性转化为福荫（唯一吉） |
| 兄弟宫 | 弱 | 两分离 | 手足孤独→分离 |
| 奴仆宫 | 最弱 | 孤高欠情 | 仆从孤独→无人伺候 |

紫炁在强宫（命/田宅/妻妾）和弱宫（兄弟/奴仆）都主孤，但**强宫的孤指向超脱/福荫/克妻，弱宫的孤指向分离/欠情**。宫位强度不改变"孤"的本质，但改变"孤"的兑现面向。

## 定量化思考

### 1. 宫位强度×星曜吉凶的交互模型

妻妾宫（强宫）与奴仆宫（最弱宫）的对比揭示了**宫位强度×星曜吉凶**的交互模型：

| 星曜本性 | 强宫（妻妾） | 最弱宫（奴仆） |
|---|---|---|
| 吉星（木/金/水） | 吉性兑现（妻贤/共荣/富贵） | 吉性反转（无禄/空废/奔波） |
| 凶星（火/孛/罗/计） | 凶性保留但有条件反转（高强非忌/对望） | 凶性加剧（愈凶/不堪言） |
| 孤星（紫炁） | 孤性保留（克凶/出家） | 孤性保留（孤高欠情） |
| 尊星（日/月） | 吉性兑现（贵崇/明静） | 凶性加剧（寿早伤/克父） |

**量化方案**：
```
判定(星曜, 宫位) = base_effect(星曜本性) × palace_modifier(宫位强度) + condition_modifier(条件)
- 强宫：palace_modifier = 1.0（吉星吉性兑现，凶星凶性保留）
- 最弱宫：palace_modifier = -0.7（吉星反转70%，凶星加凶70%）
- 紫炁例外：palace_modifier = 1.0（不受宫位强度调节，始终主孤）
```

### 3. 对宫冲射模型

妻妾宫（第七宫）与命宫（第一宫）的对宫关系在本段被多次强调：
- 规则5水星："对照命"

《星平会海》释云"男金为妻，女火为夫"——男命以金星为妻星，女命以火星为夫星。

在八字中：
- 男命以"财星"为妻（我克者为财=妻）
- 女命以"官星"为夫（克我者为官=夫）

在七政四余中：
- 男命以金星为妻星（金星=阴柔=妻）
- 女命以火星为夫星（火星=阳刚=夫）

**底层模式**：男命以"阴柔之物"为妻，女命以"阳刚之物"为夫。八字用五行生克定义（财/官），七政四余用星曜阴阳定义（金/火）。**同构关系**：`男命妻星 = 阴柔属性 = 金(七政) / 财(八字)`，`女命夫星 = 阳刚属性 = 火(七政) / 官(八字)`。

### 3. "对宫冲射"的跨体系同构

《星平会海》妻妾宫（第七宫）与命宫（第一宫）的对宫关系——"对照命""对官守""加临对命宫"。

在紫微斗数中：夫妻宫与命宫是对宫关系，互为"迁移"——夫妻宫是命宫的对面。
在八字中：日支（妻宫）与月支的关系也有"冲"的概念。
在果老星宗中：卷六第11行"在第七宮曰對"——明确称第七宫为"对"。

**底层模式**：第七宫=第一宫的对面=伴侣宫。伴侣是自我的镜像——对宫的星曜从对面影响自我。这是跨体系通用的宫位几何关系。

### 4. "紫炁超宫位孤性"的跨体系同构

紫炁在妻妾宫（强宫）仍主克凶/出家——不受宫位强度调节。在5个已审计宫位中，紫炁始终主孤。

在八字中：孤辰寡宿星不受旺衰影响——孤性是"超格局"的。
在紫微斗数中：天梁星（孤星）在任何宫位都有"孤"的底色。

**底层模式**：某些星曜有"超宫位"的核心属性——不受宫位强度调节，在所有宫位都保持一致底色。紫炁=孤，是"超宫位"孤星。

## 时代性思考

### 1. "克妻"在现代社会的兑现

火星照妻妾宫"定克妻"、月孛照妻妾宫"望门克妇"——古代"克妻"指刑克妻子致死。在现代社会：
- "克妻"→婚姻关系紧张/离异/配偶健康问题
- "望门克妇"→婚前已见不谐/配偶家境困窘
- **能量单位不变**（凶星在妻妾宫对配偶的负面影响），但"克"的兑现从"死亡"变为"关系问题/健康隐患/经济压力"

### 2. "娶得高贤妇"的当代解读

木星照妻妾宫"更饶娶得高贤妇，偕老同心到白头"——古代指娶到贤德妻子。在现代：
- "高贤妇"→能力出众、品德优秀的伴侣
- "偕老同心"→长期稳定的关系
- **能量单位不变**（吉星在强宫=伴侣优秀），但"高贤"的标准从"贤德顺从"变为"能力品德兼备"

### 3. "方袍圆顶"的当代解读

紫炁照妻妾宫"方袍圆顶或孤从"——古代指出家为僧（方袍圆顶=僧服）。在现代：
- 不一定是宗教出家，可以是"独身主义/不婚主义"
- "孤从"→选择独处/社交圈子极小
- **时代性修正**：古代"出家"是世俗失败的退路，现代可以是主动选择的生活方式

### 4. "婚姻皇族也平中"的当代解读

太阳照妻妾宫"婚姻皇族也平中"——古代指即使与皇族通婚也仅平平。在现代：
- "皇族"→社会顶层/权贵阶层
- "平中"→即使与社会顶层联姻，关系质量也一般
- **能量单位不变**（太阳在妻妾宫+忌星=婚姻减吉），但"皇族"的参照系从皇室变为社会精英

### 5. "男金妻/女火夫"的当代意义

"男金为妻，女火为夫"——古代严格的性别角色定义。在现代：
- 性别角色更加流动，但底层逻辑仍有参考价值
- 男命以"阴柔属性"为伴侣星→寻找互补型伴侣
- 女命以"阳刚属性"为伴侣星→寻找互补型伴侣
- **事在人为的边界**：星曜定义的是"自然倾向"，人的选择可以超越或调整这种倾向
