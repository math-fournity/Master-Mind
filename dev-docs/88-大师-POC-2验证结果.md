## 五、核心发现

### 5.1 三个梯度层次清晰

评分者总结的三组特征：

| 组别 | 特征 | 核心表现 |
|---|---|---|
| A组（教材Markdown） | **识别工具但无法连接** | 概念正确，证明不完整，仅有思路罗列 |
| B'组（依赖图JSON） | **覆盖框架但无法深入** | 结构完整，关键技术不完整，指数推导错误（得到n^(-1)而非n^(-3/2)） |
| B组（七步骤工作流） | **完成核心技术但最后一步有gap** | 稳定性方程完整，BA应用正确，指数来源正确，E→delta转换有gap |

### 5.2 B组的唯一关键突破：稳定性方程

评分者指出："回答Z是三份回答中唯一接近完成证明的。其核心突破在于完整导出了稳定性方程 5D = 3*sqrt(5)*(B_r-B_s) + 2*C_3——这是连接数论量（D，与sqrt(5)逼近相关）和分析量（E，与极差差额相关）的枢纽，也是X和Y都未能完成的关键步骤。"

这个突破来自七步骤工作流的完整流程：
1. G'_topo 规划了证明的完整拓扑结构
2. TopologyVerifier 保证了拓扑覆盖的完整性
3. KC忠实审计保证了每个节点的知识内容被忠实转译
4. normal AI 在完整的知识结构引导下，能够完成稳定性方程的代数推导

A组和B'组虽然也知道"需要做扰动分析"和"需要导出稳定性方程"，但缺乏完整的知识内容（KC）和结构引导（G'_topo），无法完成具体的代数推导。

### 5.3 指数 -3/2 的正确来源

| 组别 | 指数推导 | 正确性 |
|---|---|---|
| A组 | 猜测 n^(-2)*n^(1/2)=n^(-3/2)，自标"不严格" | ❌ 方向不正确 |
| B'组 | Cauchy-Schwarz 得到 n^(-1)，承认无法修正 | ❌ 得到错误指数 |
| B组 | n^(-1)（BA经稳定性方程传递到E）× n^(-1/2)（Cauchy-Schwarz开方转换）= n^(-3/2) | ✅ 方向正确 |

### 5.4 七步骤工作流的增量来源

B组 vs B'组的边际增益 +2.34（10分制）来自：

| 增量来源 | 说明 |
|---|---|
| G'_topo 拓扑规划 | B'组有依赖图但无 G'_topo，无法保证展开的拓扑完整性 |
| TopologyVerifier 拓扑验证 | B'组无拓扑覆盖验证，可能遗漏关键节点 |
| KC忠实审计 | B'组无 KC 审计，知识内容可能不忠实 |
| meta/normal分离 | B'组的转译和分析在同一个AI中，无独立审计 |

**关键洞察**：B'组 vs A组的边际增益只有 +0.93——依赖图JSON本身带来的增量有限。真正的增量来自七步骤工作流的完整流程（G'_topo + TopologyVerifier + KC审计 + meta/normal分离），而非仅仅是依赖图数据结构。

## 八、诚实面对的局限

1. **A组和B'组回答由主 Agent 生成**：由于 background subagent 无法写入 /Volumes 路径，A组和B'组回答由主 Agent 根据各自的参考材料生成。这不是完全的双盲——主 Agent 知道哪个是 A 哪个是 B。但评分 subagent 是盲的，且评分基于客观的数学判断。

2. **B组回答由 normal AI subagent 生成**：B组的步骤6（分析）是由前台 subagent 生成的，这是真实的独立 AI 输出。

3. **第二问完整证明的最后一步有gap**：B组虽然完成了稳定性方程和BA性质应用，但从 E 的下界到极差差额 delta 的精确转换缺乏严格论证。评分者标注了这一点。

4. **单次实验的统计效力不足**：一次 POC 的结果不能确证或否证核心信念。
