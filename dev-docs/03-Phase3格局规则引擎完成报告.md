## 一、本轮完成内容

### 3.1 EvalRule 引擎结构研究

**研究文件**：
- `base/EvalRule.java` (800行) - 规则引擎主类
- `base/RuleParse.java` (1019行) - 规则解析器（BYACC/J 生成）
- `base/Rule.yacc` (431行) - 规则语法定义
- `base/RuleEntry.java` (1697行) - 规则条目类

**引擎架构**：
```
EvalRule (主类)
  ├─ birth_table / now_table (符号表)
  ├─ good / bad (吉凶格局列表)
  └─ computeRules() → 遍历规则 → RuleEntry.evalRule()
                                    ↓
                              RuleParse (解析器)
                                    ↓
                              Rule.yacc (语法)
                                    ↓
                              返回 "t"/"f"/集合
```

**规则语言特性**：
- `@var` - 黄道星座变量
- `%var` - 恒星宿度变量
- `$var` - 字符串/集合变量
- `?var` - 布尔变量
- `& | !` - 逻辑运算
- `&func(args)` - 函数调用
- `expr[index]` - 索引
- `~` - 排斥/隐含
- `[level.rank.sub]` - 优先级标记

## 四、技术要点

### 规则语言 → Python 映射

| 规则语言 | Python 实现 |
|---|---|
| `?变量` | `sym["?变量"] == "t"` |
| `?{规则名}` | `sym["?规则名"] == "t"` |
| `@变量[0]=值` | `sym["@变量[0]"] == "值"` |
| `@变量=@变量` | `sym["@变量1"] == sym["@变量2"]` |
| `&` | `and` |
| `\|` | `or` |
| `!` | `not` |

### 同宫判定

七政四余的"会"（同宫）= 两行星在同一30°区间（同一地支），不是西方占星的合相（orb<8°）。
