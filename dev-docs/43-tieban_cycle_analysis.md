# 铁板神数命格全排列周期结构分析

**文件**：`dev-docs/43-tieban_cycle_analysis.md`
**日期**：2026-07-08
**作者**：子研究员
**定位**：搞清楚铁板神数"每一刻命格都不同"的全排列到底横跨多少年、子周期如何嵌套。这是设计枚举策略和两套系统并行推演的前提。

---

## 零、核心结论（先放结论）

1. **铁板神数的元周期是129,600年**（1元 = 12会 × 30运 × 12世 × 30年），来自《皇极经世》。
2. **八字（四柱）的周期是60年**（六十甲子），这是元周期内的一个子周期。
3. **刻（卦气深浅）的周期嵌套在日/年之内**，不独立成周期。
4. **全排列空间 = 60 × 12 × 60 × 12 × 8 = 4,147,200 种命格**，但这些命格不是均匀分布在129,600年中的——它们以60年为周期重复出现。
5. **两套系统并行推演的正确做法**：以60年八字周期为主轴（因为这是命格的自然重复周期），在每个八字内枚举8刻，对每种命格同时运行铁板推演和七政推演。

## 一、子周期拆解

### 1.1 年柱周期：60年

年柱 = 年干(10) × 年支(12) = 60种组合，60年一循环。

这是最外层的周期。六十甲子年：
```
甲子(1) → 乙丑(2) → ... → 癸亥(60) → 甲子(61)
```

**每60年，年柱回到起点。**

### 1.2 月柱周期：12年（在60年内循环5次）

月支 = 12种（寅卯辰巳午未申酉戌亥子丑），每年固定12个月。

月干由年干推出（五虎遁元）：
```
甲己年 → 丙寅起
乙庚年 → 戊寅起
丙辛年 → 庚寅起
丁壬年 → 壬寅起
戊癸年 → 甲寅起
```

所以**年干支+月支的组合**有 60 × 12 = 720 种，在60年内遍历完毕。

### 1.3 日柱周期：60天（独立于年月）

日柱 = 日干(10) × 日支(12) = 60种组合，60天一循环。

**关键**：日柱的循环**不依赖年月**。任何一天都是六十甲子之一，60天后必然重复。

这意味着：在60年（≈21,915天）内，日柱循环了 ≈21,915 / 60 ≈ 365.25 次。

### 1.4 时柱周期：2天（5天内60时辰）

时支 = 12种（子丑寅卯辰巳午未申酉戌亥），每个日柱下12个时辰。

时干由日干推出（五鼠遁元）：
```
甲己日 → 甲子起
乙庚日 → 丙子起
丙辛日 → 戊子起
丁壬日 → 庚子起
戊癸日 → 壬子起
```

日干+时支的组合有 10 × 12 = 120 种，5天遍历（因为日干10种 × 时支12种 = 120，每天12时辰，5天=60时辰，覆盖所有10种日干×12种时支）。

### 1.5 刻：非独立周期，嵌套在时辰内

刻 = 8种（初刻到八刻），每个时辰8刻。

**刻不是时钟上的刻度，而是"卦气深浅"**。它代表该时辰内五行能量的8个层级：
- 初刻 = 水(亥子)
- 二刻 = 火(巳午)
- 三刻 = 木(寅卯)
- 四刻 = 金(申酉)
- 五刻 = 土(辰)
- 六刻 = 土(未)
- 七刻 = 土(戌)
- 八刻 = 土(丑)

刻的"周期"就是时辰本身（2小时）。但它不是独立变量——它在铁板推演中通过考刻表与父母生肖挂钩。

## 三、全排列空间计算

### 3.1 各维度独立计数

| 维度 | 取值范围 | 数量 | 周期 |
|---|---|---|---|
| 年干 | 甲乙丙丁戊己庚辛壬癸 | 10 | 10年 |
| 年支 | 子丑寅卯辰巳午未申酉戌亥 | 12 | 12年 |
| 月支 | 寅卯辰巳午未申酉戌亥子丑 | 12 | 1年 |
| 日干 | 甲乙丙丁戊己庚辛壬癸 | 10 | 10天 |
| 日支 | 子丑寅卯辰巳午未申酉戌亥 | 12 | 12天 |
| 时支 | 子丑寅卯辰巳午未申酉戌亥 | 12 | 1天 |
| 刻 | 初二三四五六七八 | 8 | 2小时 |

### 3.2 但维度不完全独立

- **月干**不独立：由年干通过五虎遁元决定。所以"年干×月干"不占10×10=100，而只占10（年干决定了月干的起始）。
- **时干**不独立：由日干通过五鼠遁元决定。同理。
- **年支和月支**：年支12种，月支12种，但月支的含义（寅月=正月等）在年支层面不产生额外约束。

### 3.3 实际独立变量

真正独立的变量是：
1. **年干支**：60种（年干+年支联合决定）
2. **月支**：12种（正月到十二月，月干由年干推出）
3. **日干支**：60种（日干+日支联合决定）
4. **时支**：12种（时干由日干推出）
5. **刻**：8种

所以**独立命格数 = 60 × 12 × 60 × 12 × 8 = 4,147,200**。

### 3.4 这个数字的含义

4,147,200 是**在60年周期内所有不重复的八字×刻组合数**。

因为八字以60年为周期重复，所以**任何一个人的命格，在60年前和60年后都有另一个人拥有完全相同的八字×刻组合**。

## 四、129,600年与4,147,200的关系

### 4.1 为什么是129,600年？

《皇极经世》的元会运世是邵雍建立的**宇宙时间模型**：
```
1元 = 12会 × 30运 × 12世 × 30年 = 129,600年
```

这个周期来自**天文观测**：地球岁差周期约25,800年（大年），129,600 ≈ 5 × 25,800，是5个岁差周期。邵雍将其数学化为12×30×12×30的结构。

### 4.2 129,600 / 60 = 2,160

在129,600年的元周期内，八字的60年周期重复了2,160次。

这意味着：**同一个命格（相同的八字×刻），在129,600年内会出现2,160次**。

但每次出现时，虽然八字相同，**天文背景（七政四余的实际行星位置）不同**——因为行星周期与60年不完全同步：
- 木星周期 ≈ 11.86年
- 土星周期 ≈ 29.46年
- 金星周期 ≈ 224.7天
- 水星周期 ≈ 87.97天
- 火星周期 ≈ 686.97天

所以**同一八字在不同世纪出生的人，七政四余的行星配置不同**——这就是为什么铁板神数需要"考刻"来区分同八字的人。

### 4.3 铁板的"精细度"来源

铁板神数号称比八字精确48倍（或更多），来源：
- 八字：60 × 12 × 60 × 12 = 518,400 种（不含刻）
- 铁板：518,400 × 8 = 4,147,200 种（含刻）
- 倍数：4,147,200 / 518,400 = 8 倍（仅含8刻）
- 如果含分（每刻15分）：518,400 × 8 × 15 = 62,208,000
- 倍数：62,208,000 / 518,400 = 120 倍

但铁板的"48倍"可能指八卦滚法的48条数序，不是指分辨率倍数。

## 五、对枚举策略的影响

### 5.1 暴力全乘的问题

之前的 `tieban_enum.py` 用60×12×60×12×8暴力枚举，得到4,147,200种配置。但这有两个问题：

1. **没有考虑日干支与年月的实际约束**：不是所有60个日干支都能出现在任意年月的任意一天。公历日期到干支日的映射是固定的（日柱连续递增），所以日柱在60年内的分布是确定的，不需要额外枚举。

2. **刻不是独立变量**：刻由考刻过程确定（通过父母生肖等已知信息反推），不能从八字内部推出。枚举时应把刻作为**外部循环**。

### 5.2 正确的枚举策略

**按周期结构分层枚举**，而不是暴力全乘：

```
第一层：60年周期（年干支循环）
  └── 对每个年干支：
      第二层：12个月（月支循环，月干由年干定）
        └── 对每个月支：
            第三层：该年该月内的所有日干支（≈30天，日柱连续递增）
              └── 对每个日干支：
                  第四层：12个时辰（时支循环，时干由日干定）
                    └── 对每个时支：
                        第五层：8个刻（外部枚举）
                          → 计算该命格的铁板数序 + 七政星盘
```

**优势**：
- 日柱不再盲目枚举60个，而是按实际日历遍历（每个年月约30天）
- 月干由年干正确推出（五虎遁元）
- 时干由日干正确推出（五鼠遁元）
- 刻作为最内层外部变量

### 5.3 实际枚举规模

按公历实际天数：
- 60年 ≈ 21,915 天
- 每天12时辰 × 8刻 = 96 种时辰×刻组合
- 总计 ≈ 21,915 × 96 ≈ 2,103,840 种实际命格

比4,147,200少，因为不是所有60个日干支都均匀分布在每个月中。

### 5.4 两套系统并行的组织方式

```
遍历 60年周期（21,915天）：
  对每一天：
    计算该日的八字四柱
    对每个时辰（12个）：
      对每个刻（8个）：
        ├─ 铁板推演：算法A/B → 基本数 → ±48/±96展开 → 条文数序集合
        └─ 七政推演：build_chart() → 星曜位置 → 宫位 → 神煞 → 大限 → 能量评分
        
        对比两套产出：
        - 铁板条文说的六亲/婚姻/事业，与七政星盘的宫位/星曜是否一致？
        - 铁板数序的周期性，与七政能量的周期性是否同步？
        - 同一命格在不同世纪出现时（60年重复），七政差异如何影响铁板判定？
```

## 七、对"命格的全排列到底横跨了多少年"的直接回答

**答案：要看从哪个层面说。**

| 层面 | 周期 | 说明 |
|---|---|---|
| **八字四柱** | **60年** | 年干支60年一循环，月干由年干定，日柱60天循环（在60年内重复≈365次），时干由日干定。整个八字配置60年后必然重复。 |
| **八字×刻** | **60年** | 刻嵌套在时辰内（不独立成周期），所以八字×刻的完整配置也以60年为周期。 |
| **铁板条文** | **60年** | 同一八字×刻组合，在60年后出现相同条文。但考刻结果（父母生肖）不同的人，即使八字×刻相同，条文也不同。 |
| **元会运世** | **129,600年** | 这是邵雍定义的宇宙大周期。129,600 / 60 = 2,160，即八字周期在元周期内重复2,160次。 |
| **七政四余** | **不循环** | 行星周期与60年不完全同步，所以严格说七政配置不会精确重复（但近似重复的周期约为数百年）。 |

**结论：铁板神数的枚举周期是60年，不是129,600年。** 129,600是宇宙论层面的大周期，而实际操作中，八字×刻以60年为周期重复。枚举60年的所有日历日，就能覆盖全部4,147,200种命格。

## 八、子周期嵌套的数学结构

### 8.1 周期的最小公倍数

各子周期的最小公倍数决定总周期：
- 年柱周期 = 60年
- 月柱周期 = 12年（月干由年干定，月支12年循环5次）
- 日柱周期 = 60天 = 60/365.25 年 ≈ 0.1644年
- 时柱周期 = 5天 = 5/365.25 年 ≈ 0.0137年

**总周期 = LCM(60, 12, 60/365.25, 5/365.25)**

因为60年是12年的整数倍，所以年月周期合并为60年。

日柱周期 = 60天，时柱周期 = 5天。60天和5天的LCM = 60天。

所以**八字周期 = LCM(60年, 60天) = 60年**（因为60年 = 21,915天，21,915 / 60 = 365.25，是整数）。

### 8.2 周期嵌套的层级

```
Level 0: 元（129,600年）——宇宙大周期
  └── Level 1: 会（10,800年）——大运周期
      └── Level 2: 运（360年）——中运周期
          └── Level 3: 世（30年）——小运周期
              └── Level 4: 年（60年八字周期）——命格重复周期
                  └── Level 5: 月（12个月/年）——月柱变化
                      └── Level 6: 日（60天/日柱循环）——日柱变化
                          └── Level 7: 时（12时辰/日）——时柱变化
                              └── Level 8: 刻（8刻/时辰）——卦气深浅
                                  └── Level 9: 分（15分/刻）——最精细刻度
```

铁板神数的操作范围主要在 Level 4-9（年刻分），而元会运世是 Level 0-3（元世）。两者通过《皇极经世》的数学关系连接。

## 九、对并行推演框架的影响

### 9.1 枚举应以60年为周期

因为60年覆盖了所有不重复的八字×刻组合，枚举60年的日历日就够了。

### 9.2 七政推演需要真实天文时间

七政四余的行星位置是连续的天文量，不能用干支近似。所以：
- 对每个枚举出的命格，需要用其**真实公历日期时间**（不是干支）调用 `build_chart()`
- `build_chart(y, mo, d, h, lon, lat)` 已经支持从公历直接计算

### 9.3 两套系统的"对齐点"

铁板和七政的对齐点是**同一个出生时间**：
- 铁板：出生时间 → 八字 → 太玄数 → 数序 → 条文
- 七政：出生时间 → 星历 → 星曜位置 → 宫位 → 神煞 → 能量

**同一个时间点，两套系统各自独立计算，然后对比产出。**

### 9.4 周期性验证

如果铁板的条文数序和七政的能量评分都具有周期性，那么：
- 在60年周期内，应该能看到条文数序和能量评分的周期性变化
- 木星11.86年和土星29.46年的周期应该在七政能量中体现
- 铁板的刻（8种卦气）应该在七政能量中也有对应的周期性

这就是30.11要做的事：采样验证周期性。

## 十、todo 更新建议

基于本分析，枚举策略应改为：
1. 遍历60年的日历日（≈21,915天）
2. 对每天计算正确的八字四柱（月干由年干推，时干由日干推）
3. 对每个时辰枚举8刻
4. 对每种命格同时运行铁板推演和七政推演
5. 对比两套产出，验证周期性

这比原来的暴力全乘（4,147,200）更精确，因为：
- 月干/时干正确推导（不是固定甲）
- 日柱按实际日历分布（不是盲目枚举60个）
- 真实公历时间用于七政计算
