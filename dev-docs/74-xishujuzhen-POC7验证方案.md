# 74 · xishujuzhen POC-7 验证方案

## 一、实验定位

POC-7在POC-5/POC-6基础上做两个维度的扩展：

1. **规模维度**：从当前单限分析扩展到**12限全量分析**。前6个POC都只深入分析当前限（命主35岁所在限），POC-7要测试依赖图在大规模动态分析中的表现——12限全量分析意味着节点数和边数大幅增加。
2. **螺旋维度**：在动态分析中引入**动态螺旋环路**——"限运吉凶→回到命主星判断→修正限运吉凶"。前6个POC的螺旋环路只在静态分析中（五行生克↔阴阳昼夜），POC-7要测试螺旋环路在动态分析中的表现。

### 核心假设

1. **大规模依赖图可行**：12限全量分析的依赖图（预计60+节点80+边）仍然可以被AI完整处理，覆盖率≥95%。
2. **动态螺旋环路有效**：动态螺旋环路（限运吉凶→命主星判断→修正限运吉凶）能让AI在动态分析中产生更精确的判断，而非一次性线性分析。
3. **大规模场景下B组优势持续**：12限全量分析中B组的边际增益应持续大于A组。

### 与POC-5/POC-6的对比

| 指标 | POC-5 | POC-6 | POC-7 |
|---|---|---|---|
| 分析范围 | 静态+当前限 | 静态+当前限 | **静态+12限全量** |
| 节点数 | 30 | 30 | **60+（预计）** |
| 边数 | 40 | 40 | **80+（预计）** |
| 螺旋环路 | 1个（静态） | 1个（静态） | **2个（静态+动态）** |
| A组知识状态 | 充分 | 缺失 | **充分（恢复充分，隔离规模变量）** |
| 第2步审计 | AI自审 | 交叉审计 | **交叉审计** |

### 设计决策：A组知识恢复充分

POC-6测试了A组知识缺失的情况，POC-7恢复A组知识充分——这样可以隔离"规模"变量，纯粹测试大规模依赖图的影响。如果POC-7同时改A组知识状态和规模，就无法区分哪个因素影响了结果。

### 依赖图扩展设计

**静态分析节点**（复用POC-5/POC-6的19个静态节点）：
- 命宫分析、命主星判断、度主星判断、庙旺平陷、升殿判断、宿位泄气、五行生克、阴阳昼夜、恩用仇难定局、颠倒颠、仇难外避分析、间接影响分析
- 官禄宫分析、官主星判断、官禄宫星曜配置、官禄庙旺判断、命官关系判断、官禄三方四正、官禄整体格局

**动态分析节点**（新增12限全量节点）：
- 大限框架计算（1个）
- 逐限分析节点（12限×4子节点=48个）：
  - 限宫位判断、限宫主判断、限内星曜配置、限运吉凶
- 动态螺旋环路节点（2个）：
  - 限运回溯命主、限运修正
- 限运综合排序（1个）

**预计节点数**：19（静态）+ 1（大限框架）+ 48（12限×4）+ 2（动态螺旋）+ 1（综合排序）= **71个节点**

**预计边数**：
- 静态边：25条（复用POC-5）
- 静态→动态跨宫边：4条（复用POC-5）
- 大限框架→逐限：12条
- 逐限内部边：12限×3=36条
- 逐限→动态螺旋：12条
- 动态螺旋环路：2条（限运回溯命主→限运修正→限运回溯命主）
- 逐限→综合排序：12条
- **预计总边数**：25+4+12+36+12+2+12 = **103条边**

### 动态螺旋环路设计 ★新增

**螺旋环路结构**：
```
限运吉凶 → 限运回溯命主 → 限运修正 → 限运吉凶（修正后）
```

**第一圈**：对每个限，初步判断限运吉凶（基于限宫主、限内星曜、限宫五行）。
**第二圈**：带着初步限运吉凶回到命主星判断——命主极强则修正凶限为"可承之凶"，命主弱则修正吉限为"虚浮之吉"。
**第三圈**：带着修正后的限运判断回到限运吉凶，给出最终判断。

这个螺旋环路模拟了大师推命的真实思维过程——不是一次性线性分析12限，而是在12限之间反复回溯命主力量，修正判断。

### A组知识恢复充分

A组参考材料恢复为POC-5的material_a_v5.md（含大限流年知识），以隔离规模变量。

## 四、核心假设与验证条件

### 假设1：大规模依赖图可行

**验证条件**：B组审计报告的节点覆盖率≥95%（71个节点中至少68个已处理），边覆盖率≥95%（103条边中至少98条已沿其思考）。

**如果成立**：说明依赖图在大规模场景下仍然可行，AI可以完整处理60+节点80+边的复杂依赖图。
**如果不成立**：说明依赖图规模有上限，超过某个阈值后AI无法完整处理。

### 假设2：动态螺旋环路有效

**验证条件**：动态螺旋环路显式走了三圈，且第三圈的限运判断与第一圈有明确差异（修正了判断）。

**如果成立**：说明动态螺旋环路能让AI在动态分析中产生更精确的判断。
**如果不成立**：说明动态螺旋环路没有实际效果，AI只是走形式。

### 假设3：大规模场景下B组优势持续

**验证条件**：B组总分 - A组总分 > 0（B组仍优于A组）。

**如果成立**：说明大规模场景下B组优势持续。
**如果不成立**：说明大规模场景下B组优势消失（可能因为大规模依赖图的复杂性抵消了B组的优势）。
