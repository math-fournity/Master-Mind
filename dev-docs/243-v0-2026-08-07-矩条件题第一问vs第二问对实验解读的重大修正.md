## 1. 发现

### 1.1 题目有两问

矩条件极差题的完整题面（来自2026-03-06文档）：

```
已知 a1, a2, ..., an 为实数，且
sum ai = n, sum ai^2 = 2n, sum ai^3 = 3n。

(1) 求最大的常数 C，使得对所有 n >= 4，
    max{a1,...,an} - min{a1,...,an} >= C。

(2) 证明存在常数 C2 > 0 使得
    max{a1,...,an} - min{a1,...,an} >= C + C2 n^(-3/2)。
```

### 1.2 guided_001和guided_003只测了第一问

- guided_001的problem_text：`"已知a1,...,an为实数，Σai=n, Σai²=2n, Σai³=3n。求最大常数C使得对所有n≥4，max(ai)-min(ai)≥C。"`
- guided_003的problem.txt：同样只有第一问
- 两个实验的标准答案都是`C=√5`——第一问的答案

### 1.3 用户确认：GLM-5.2裸跑能做出第一问

用户明确确认："第一问AI总是可以做出来的"——指GLM-5.2裸跑（无引导）就能做出第一问C=√5。

| 项 | 修正后的解读 |

### 2.3 guided_001/003仍然证明了什么

虽然不能证明"激活了做不出来的能力"，但仍然证明了：

1. **引导改变路径**：guided_001走中心化+q(x)路径，guided_003走(a_i-m)(a_i-M)²路径——不同的引导方式导致不同的证明路径
2. **非特定引导有效**：纯非特定引导（不引用AI选的特定方向）同样能让AI完成证明——非特定性作为"纯形式"是tested的
3. **隐含筛选非关键**：guided_003（无隐含筛选）和guided_001（有隐含筛选）都成功——隐含筛选不是成功的必要条件
4. **效率差异**：guided_001用4轮/1440秒，guided_003用6轮/2040秒——隐含筛选可能提高效率

### 2.4 guided_001/003不能证明什么

1. **不能证明认知激活**——因为AI裸跑就能做第一问，"引导后做出来了"不等于"激活了做不出来的能力"
2. **不能证明最小知识传递**——因为不知道引导是否真的"最小"，还是AI本来就不需要引导
3. **不能证明连续发问框架的必要性**——因为AI可能一轮就能做出来

## 3. 第二问才是真正的测试

### 3.1 第二问的难度

第二问要求证明：存在C2>0使得max-min≥√5+C2·n^(-3/2)

从2026-03-06文档看，第二问的证明需要：

1. **紧性归约**：δ≤1时所有x_i在固定紧区间内
2. **把每个点投到最近的根上**：ζ_i=r或s，e_i=x_i-ζ_i
3. **稳定性方程**：5D=3√5(B_r-B_s)+2C
4. **二次无理数的badly approximable性质**：p=(5-√5)/10的连分数部分商有界，|p-k/n|≥c₀/n²
5. **从Σe_i²到δ的下界**：柯西不等式+q(x)在根附近一阶消失

**关键难点**：第4步需要知道二次无理数是badly approximable——这是数论知识，不是纯思维模式能推出来的。

### 3.2 第二问作为新实验的题目

- **裸跑测试**：先测试GLM-5.2裸跑能否做出第二问
- **如果裸跑做不出来**：再用引导测试，验证认知激活是否真的能"激活做不出来的能力"
- **如果裸跑能做出来**：需要找更难的题

### 3.3 第二问的Level分析

第二问的证明依赖中，关键步骤"二次无理数的badly approximable性质"的Level：
- 这是具体数论知识（连分数理论），不是通用思维模式
- Level→0（纯知识）
- 但"稳定性方程"和"紧性归约"是较高Level的思维模式

所以第二问是一个**混合Level**的题——部分需要知识（badly approximable），部分需要思维模式（稳定性分析）。这使它成为测试"最小知识传递"的好题目——引导者需要决定是否传递badly approximable这个知识。

## 6. 教训

1. **实验题目选择必须先验证裸跑基线**——不能假设"AI做不出来"而不测试
2. **"30道做不出来的题"是MathArena竞赛题**——不能把竞赛题的难度泛化到其他题目
3. **矩条件题第一问是AI能做的题**——用它做引导实验，不能证明"激活做不出来的能力"
4. **第二问才是真正的能力边界测试**——需要badly approximable等数论知识
5. **未来的引导实验必须先做裸跑对照**——确认AI裸跑做不出来，再测引导
