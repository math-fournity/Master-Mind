# 242号：guided_003实验方案——纯非特定Q序列对照实验

## 实验目标

回答218号提出的核心问题：**纯非特定Q序列（不引用AI选的特定方向、不筛选、不确认执行路径）能否激活AI能力做出矩条件极差题？**

这是guided_001的对照实验。guided_001的Q3-Q4被218号判定为发生了隐含筛选——通过引用AI自己选的"最看好的5个方向"和"执行顺序30→{4,29}→{8,9}"，隐含地确认了正确路径。guided_003用纯非特定Q序列，不引用任何AI输出的特定内容。

## 实验设计

### 变量控制

| 维度 | guided_001 | guided_003 | 区别 |
|---|---|---|---|
| 题目 | 矩条件极差题第(1)问 | 同一道题 | 无 |
| 模型 | GLM-5.2 High | GLM-5.2 High | 无 |
| 工作目录 | /data/math-agent-glm5.2-1 | /data/math-agent-glm5.2-2 | 隔离 |
| Q1 描述形状 | 完全通用 | 完全通用（相同） | 无 |
| Q2 列方向 | 引用AI的"矩约束到逐点极值的鸿沟" | 不引用任何AI内容 | 引用vs不引用 |
| Q3 描述第一步 | 引用AI的"最看好的5个方向" | "对你觉得最有希望的方向" | 筛选vs不筛选 |
| Q4 试着做 | 引用AI的"执行顺序30→{4,29}→{8,9}" | "选一个方向试着做" | 确认路径vs不确认 |
| Q5 推进 | 无（guided_001在Q4完成） | "你得到了什么？和结论之间还有什么差距？" | 新增 |
| Q6 卡住时 | 无 | "你卡在哪里了？" | 新增 |

### 纯非特定Q序列（6轮，全部Level=1.0）

| 轮次 | Q文本 | Level | 类型 | 非特定性检查 |
|---|---|---|---|---|
| Q1 | "请读取当前目录下的problem.txt文件。不要解题。请描述这道题的结构形状：结论是什么类型？已知条件是什么类型？条件和结论之间的距离有多远？" | 1.0 | 元认知指令-L1观察 | ✓ 完全通用 |
| Q2 | "列出你能想到的所有可能方向——不要求正确，不要求完整，只要列出你脑中浮现的任何方向。" | 1.0 | 元认知指令-L2联想 | ✓ 完全通用 |
| Q3 | "对你觉得最有希望的方向，描述第一步会做什么。不要求真的做，只描述。" | 1.0 | 元认知指令-L3描述 | ✓ 完全通用（不引用具体方向） |
| Q4 | "选一个方向，试着做第一步。做多少算多少，做不出来也没关系。" | 1.0 | 元认知指令-L4尝试 | ✓ 完全通用（不引用执行顺序） |
| Q5 | "你得到了什么？这个结果和你要证明的结论之间还有什么差距？下一步你想怎么走？" | 1.0 | 元认知指令-L5推进 | ✓ 完全通用 |
| Q6（卡住时） | "你卡在哪里了？是不知道下一步该做什么，还是知道方向但做不下去？" | 1.0 | 元认知指令-诊断 | ✓ 完全通用 |

### 非特定性保证

每个Q都不引用AI输出的特定内容：
- Q1：只引用problem.txt（题目本身），不引用AI输出
- Q2：不引用Q1的回复内容，只给通用指令"列出方向"
- Q3：不引用Q2中AI列出的具体方向，只说"你觉得最有希望的方向"——让AI自己选
- Q4：不引用Q3中AI描述的执行顺序，只说"选一个方向"——让AI自己选
- Q5：不引用Q4中AI的具体结果，只问"你得到了什么"——让AI自己说
- Q6：不引用任何特定内容，只问"你卡在哪里了"

**关键区别**：guided_001的Q3说"对最看好的5个方向"（引导者筛选了5个），Q4说"选最有希望的方向"（引导者确认了路径）。guided_003的Q3说"对你觉得最有希望的方向"（AI自己选），Q4说"选一个方向"（AI自己选）。引导者不做任何筛选。

### 停止条件

1. AI给出完整证明（成功叶）——停止
2. 6轮Q全部发完仍未完成——停止
3. AI明确说"我不知道"且Q6后仍无法推进——停止（死路叶）
4. 超时（每轮Q等待120秒，总超时15分钟）——停止（截断叶）

## 预测与判定

### 如果guided_003成功（AI做出C=√5）

说明纯非特定Q序列也能激活AI能力——认知激活不依赖于隐含筛选。这会：
- 升级 `cognitive-activation` 的验证状态（效应tested + 机制不依赖隐含筛选）
- 升级 `non-specificity` 的验证状态（纯非特定引导有效）
- 降级 `implicit-filtering` 的重要性（隐含筛选不是成功的关键因素）

### 如果guided_003失败（AI做不出）

说明纯非特定Q序列不足以激活AI能力——认知激活至少部分依赖于隐含筛选。这会：
- 保持 `cognitive-activation` 的争议状态（效应tested但机制可能依赖隐含筛选）
- 保持 `non-specificity` 的tested_negative状态
- 确认 `implicit-filtering` 的重要性（隐含筛选是成功的关键因素之一）
- 对239号的闭环设计有启示：闭环需要某种形式的"方向引导"，不能完全非特定

### 如果guided_003部分成功（AI有进展但未完成）

最有信息量的结果。说明纯非特定Q序列能激活部分能力但不够——隐含筛选提供了关键的"最后一公里"。这会：
- 细化 `cognitive-activation` 的验证状态（激活效应真实但不充分）
- 细化 `implicit-filtering` 的角色（不是"作弊"而是"必要的最后一公里"）
- 对Pipe框架有启示：模式识别引擎可能需要某种"方向筛选"能力
