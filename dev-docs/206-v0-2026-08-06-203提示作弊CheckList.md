## 203-C 诚实降级实验

> 来源：200号§五.6.3 + 203号§五.5.3 + AGENTS.md核心假设§6

- [ ] **203-C.0**：实验设计文档 [预期D1]
  - 定义三组实验：A组（无提示）/ B组（完整提示）/ C组（去知识提示，只保留strategy+meta）
  - 每组定义：问题集、提示内容、测量指标
  - 测量指标：完成率、turn数、提示有效率、数学正确性
  - 覆盖标准：三组全部定义，指标明确

- [ ] **203-C.1**：准备实验问题集 [预期D2]
  - 选择10个问题（覆盖证明类/猜想类/反驳类/构造类）
  - 每个问题有标准答案（写入truth_vault）
  - 边界情况：问题太简单（所有组都完成→无法区分）/ 太难（所有组都失败→无法区分）

- [ ] **203-C.2**：A组实验——无提示 [预期D2]
  - 10个问题，每个问题1turn，不给任何提示
  - 记录完成率、turn数、数学正确性
  - 边界情况：Solver在solo explore就完成（记录为"无需提示完成"）

- [ ] **203-C.3**：B组实验——完整提示 [预期D2]
  - 10个问题，每个问题最多3turns/2hints
  - 提示包含knowledge+strategy+meta（完整提示）
  - 记录完成率、turn数、提示有效率、数学正确性

- [ ] **203-C.4**：C组实验——去知识提示 [预期D2]
  - 10个问题，每个问题最多3turns/2hints
  - 提示只包含strategy+meta（去掉knowledge级提示）
  - 记录完成率、turn数、提示有效率、数学正确性
  - 边界情况：Solver需要knowledge级提示才能完成（C组完成率显著低于B组）

- [ ] **203-C.5**：比较三组表现 [预期D3]
  - 统计：A组完成率 vs B组完成率 vs C组完成率
  - 统计：A组turn数 vs B组turn数 vs C组turn数
  - 统计：B组提示有效率 vs C组提示有效率
  - 深度标准：有可执行的统计分析代码，输出对比表

- [ ] **203-C.6**：判断增益来源 [预期D4]
  - 如果C≈A → 增益主要来自knowledge → 降级为编译器
  - 如果C≈B → 增益主要来自strategy → 不是作弊
  - 如果A < C < B → 部分来自strategy，部分来自knowledge → 需要进一步细分
  - 深度标准：判断结论有数据支撑，不是主观推断
  - 边界情况：样本量不足（10个问题可能不够——标注"初步结论，需扩大样本"）

### 完整性标准

- [ ] **203-C.COMP**：三组实验使用相同问题集和相同Solver配置 [预期D2]
  - 边界情况：三组使用不同问题集（应被拒绝——不是对比实验）

- [ ] **203-C.COMP2**：实验结果记录完整可审计 [预期D3]
  - 覆盖标准：每个run的guided_loop_result.json包含完整的提示级别和审计结果

- [ ] **203-C.COMP3**：降级判断有数据支撑 [预期D4]
  - 边界情况：数据不足以做出判断（标注"不确定"，不强行降级也不强行保持）
