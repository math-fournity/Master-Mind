## AI runtime

This repository now includes a MOIRA-specific AI Work Runtime for nonlinear research work. The current opencode flow remains supported, and future Workers or Auditors can be launched through Devin CLI with `--provider devin` or `MOIRA_AGENT_PROVIDER=devin`.

Start from `AGENTS.md`, `dev-docs/46-Devin-CLI非线性运行时改造.md`, `ai-runtime/README.md`, and `python3 tools/moira_runtime.py capsule --format text`.
