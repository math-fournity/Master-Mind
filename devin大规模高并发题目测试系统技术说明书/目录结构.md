# 目录结构

## 文档组织

本说明书采用章节编号制（01-09），每章自包含——可直接定位阅读，不依赖前后章节上下文。

```
devin大规模高并发题目测试系统技术说明书/
├── README.md              # 索引与导航
├── 目录结构.md            # 本文件
├── 编写方案.md            # 编写方法论
├── 01-系统概述.md         # 系统定位、目标、核心概念
├── 02-架构设计.md         # 4+1服务架构、Redis队列、数据流
├── 03-数据存储.md         # ArangoDB + Redis + 文件系统三层存储
├── 04-服务详解.md         # 五服务逐一详解
├── 05-控制与运维.md       # pipe_control.py、启动停止、健康检查、断电恢复
├── 06-验证与审计.md       # 完备性验证、运行完整性、双向追溯、并发安全
├── 07-失败分析与Profile.md # 13类verdict、失败分类、Profile构建
├── 08-并发与性能.md       # 3秒铁律、并发基准、实时调整
└── 09-附录.md             # 文件清单、已知问题、规则索引
```

## 章节依赖关系

```
01 系统概述（入口）
  ├── 02 架构设计（理解结构）
  │     ├── 03 数据存储（理解存储层）
  │     └── 04 服务详解（理解服务层）
  ├── 05 控制与运维（操作层）
  │     └── 08 并发与性能（调优层）
  ├── 06 验证与审计（质量层）
  └── 07 失败分析与Profile（产出层）
        └── 09 附录（参考层）
```

## 编写原则

1. **自包含** — 每章可独立阅读，关键概念在章首定义
2. **代码引用精确到行** — 用 `<ref_file>` / `<ref_snippet>` 标签引用源码
3. **人话优先** — 技术描述用人话写，不堆砌术语
4. **可操作性** — 每个操作步骤给出确切命令
5. **证据驱动** — 性能数据、并发基准来自实测，标注日期
