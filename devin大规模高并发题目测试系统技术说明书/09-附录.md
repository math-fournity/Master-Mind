## 9.5 常用命令速查

### 启动

```bash
cd ~/master-mind-glm5.2-worktree
set -a; source .env; set +a
PYTHONPATH=xishujuzhen/solver_harness/pipe .venv/bin/python3 \
  xishujuzhen/solver_harness/pipe/pipe_control.py start --concurrency 60
```

### 停止

```bash
python pipe_control.py stop                    # 优雅停止
python pipe_control.py stop --kill-harness     # 停止 + kill 解题 session
```

### 状态

```bash
python pipe_control.py status                  # 基本状态
python pipe_control.py status -v               # 含 running 详情
python pipe_control.py health                  # 完备健康检查
```

### 调整

```bash
python pipe_control.py concurrency 50          # 调整并发
python pipe_control.py poll-interval 3         # 调整 poll 间隔
```

### 恢复

```bash
python pipe_control.py recover --dry-run       # 检查
python pipe_control.py recover                 # 执行恢复
python pipe_control.py recover --auto-restart  # 恢复后重启
```

### 查询

```bash
python query_failures.py --summary             # 失败汇总
python query_failures.py --by-verdict          # 按 verdict 分类
python build_profile.py --summary              # Profile 汇总
python build_profile.py --by-dataset           # 按数据集
```

### 验证

```bash
python verify_completeness.py --all            # 数据完备性
python verify_run_integrity.py --all           # 运行完整性
python audit_trace.py --all                    # 双向追溯
```

### 日志
