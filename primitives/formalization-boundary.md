# 形式化边界（formalization-boundary）

## 定义

数学知识中存在一条本质性的分界线——形式化边界。边界以内是可以被精确写下来、可检查、可审计的东西（定理依赖、证明步骤、证书目标、恒等式、不等式、类型）；边界以外是不能被精确写下来的东西（"这个表示不对劲"、"这个方向感觉有希望"、"这个式子像平方差"）。这条边界是本质性的，不是"暂时无法形式化，未来可以"。

## 验证状态

**[borrowed_unoperationalized]**

形式化边界作为一个哲学概念是清晰的，有数学哲学的正当性。但在本系统中，它从未被操作化——我们没有一个程序化的方法来判断"某个东西在边界以内还是以外"。

239号给出了边界的移动机制（AI感知→压缩成目标→经典计算验证→结果回写），但这个机制本身也未被实现和测试。

**部分操作化的尝试**：
- 239号的"执行契约"是边界跨越的操作性协议——四个字段对应边界跨越的四个环节。但执行契约也未被实际使用过。
- 239号的"证书系统"是边界以内的显式记录——证书单调增长=边界推进不可逆。但证书系统也未被实现。

## 使用经验

### 作为思考工具的价值

即使未操作化，形式化边界作为思考工具已经很有价值：
- 它解释了为什么AI能感知"不自然"但说不清为什么——感知在边界以外，说不清是边界以外的特征
- 它解释了为什么经典计算不知道该算什么——它在边界以内有能力，但边界以内不知道边界以外在感知什么
- 它解释了为什么闭环能推进——把边界以外的感知压成边界以内的形式化，边界向前推进一步

### 对238框架的解释

形式化边界可以解释guided_001的"提问激活"效应：AI裸跑时，它试图一步跨越边界（从题目直接到完整证明），跨度太大就放弃了。连续发问把跨越分解成多步——每步只跨越一小段边界，AI不会面对"一步跨越整个边界"的压力。

但这个解释是事后的理论推测，不是实验验证的。

### 239号的三层视角

239号§14把形式化边界放在三层视角的中心：
- 现象层：处境生长 → 语义移动 → 证书目标 → 结果回流
- 边界层：边界以外感知 → 跨越边界 → 边界以内验证 → 边界推进
- 结构层：Σ中的移动 → V产生证书目标 → C中验证 → C增长

三层是同一过程的三个视角。结构层只有在忠实描述现象层和边界层时才获得正当性。

## 关系

- **与 two-computations 组合**：AI计算处理边界以外（感知、模式识别、直觉），经典计算处理边界以内（验证、求解、检查）。形式化边界定义了两种计算的分工。
- **与 boundary-advancement 组合**：边界推进是形式化边界的移动机制——闭环每一次运行把边界以外的东西拉到边界以内。
- **与 non-specificity 关系**：239号把非特定性深化为"边界以外可用性"——一个方法是非特定的当且仅当它能从边界以外使用。形式化边界给非特定性提供了深层定义。
- **与 cognitive-activation tension**：238的"提问激活"效应在形式化边界框架里没有明确位置——提问是边界以外的交互，但形式化边界框架关注的是边界跨越，不是边界以外的交互如何激活能力。
- **与 data-pedestal 关系**：数据基座是形式化边界的显式记录——每个数学工程单元标记着边界的一个位置。
- **被细化 by**：233号（边界移动机制）、239号§5（完整定义+移动机制+推进性质）

## 开放问题

### 1. 边界是本质性的还是暂时的？

222号断言边界是本质性的——"不自然"是一种感知，不是规则，无法形式化。但这个断言本身是否可证伪？如果未来AI变得更强，它能不能把"不自然的感知"本身也形式化？

222号的回答是：即使AI能模拟感知，"看到红色是什么感觉"和"模拟看到红色"仍然是不同的。但这个论证依赖哲学立场，不是数学证明。

### 2. 边界在哪里？

形式化边界是一个隐喻，不是一个可测量的线。我们没有一个程序化的方法来判断"某个东西在边界以内还是以外"。"恒等式在边界以内"是清楚的，"不自然的感知在边界以外"也是清楚的，但"考虑对称性"在边界哪一侧？"找单调性"呢？

Level连续谱（238号）试图回答这个问题——Level→0是边界以内（知识），Level→1是边界以外（思维模式），中间是灰色地带。但Level本身也是经验的、模糊的、相对的。

### 3. 边界推进真的不可逆吗？

239号断言"数据基座单调增长——证书只加不删。一旦某个东西被形式化了，它就永久地成为了形式化知识的一部分。"但如果一个证书被发现是基于错误的前提呢？如果AI的感知后来被修正了呢？

239号的回答是：反例也是证书（反驳证书），它和正向证书一样硬。但"基于错误前提的正向证书被撤销"这种情况，似乎违反了单调增长。

### 4. 如何操作化？

形式化边界要从一个哲学概念变成系统设计原语，需要操作化：
- 怎么判断一个东西在边界哪一侧？
- 怎么测量边界推进了多少？
- 怎么判断一次边界跨越是成功的还是失败的？

239号的执行契约和证书系统是操作化的尝试，但都未实现。
