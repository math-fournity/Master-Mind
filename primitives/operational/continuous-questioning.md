# 连续发问（continuous-questioning）

## 定义

不要求AI一步到位给出完整解答，而是连续地发问，让AI渐进地从观察走向探索走向尝试。每一步都是安全的小任务，每一步的输出都为下一步提供context。六层渐进框架：观察→联想→描述→尝试→推进→卡点处理。

## 验证状态

**[tested]**

guided_001实验中，4轮连续发问（Q1观察→Q2联想→Q3描述→Q4尝试）引导AI从"描述形状"走到"完整证明C=√5"。AI从未面对"空白页"——每轮都是安全子任务。

**重要细节**：guided_001验证了连续发问框架的有效性，但Q3-Q4发生了特定化（见 [non-specificity](non-specificity.md)）。所以验证的是"连续发问+某种特定化引导"的组合，不是"纯非特定连续发问"。纯非特定版本待guided_003测试。

## 使用经验

### 六层渐进框架

| 层 | 问题 | 安全性 |
|---|---|---|
| L1 观察 | "这道题的结论是什么类型？已知条件是什么类型？" | 必然安全 |
| L2 联想 | "这些条件让你想到了什么？不要求正确，列出所有方向。" | 几乎安全 |
| L3 描述 | "对每个方向，如果走这个方向，第一步会做什么？只描述。" | 仍然安全 |
| L4 尝试 | "在你觉得最有希望的方向上，试着做第一步。做不出来也没关系。" | 开始有风险但可控 |
| L5 推进 | "你得到了什么？和结论之间还有什么差距？下一步想怎么走？" | 有产出后自然过渡 |
| L6 卡点处理 | "你卡在哪里了？是不知道下一步该做什么，还是知道方向但做不下去？" | 如果卡住 |

### 为什么能避免卡死

AI卡死的根本原因是**任务粒度太大**——"解这道题"是一个巨大的任务，AI不知道从哪开始就放弃了。连续发问把大任务分解成一系列小问题：
- 每个小问题AI都能回答
- 每个回答都产生信息，为下一个问题提供context
- AI在回答过程中逐渐"热身"，思维从被动观察过渡到主动探索
- AI不会意识到"我正在解题"——它只是在回答一系列看起来很简单的问题

### guided_001的实际Q序列

| 轮次 | Q | AI回复 |
|---|---|---|
| Q1 | "描述这道题的结构形状" | 识别为前三阶矩固定→极差下确界问题 |
| Q2 | "列出你能想到的所有可能方向" | 列出30个方向 |
| Q3 | "对最看好的5个方向，描述第一步" | 描述5个方向第一步，发现执行顺序 |
| Q4 | "选最有希望的方向，试着做第一步" | 完整推导出C=√5 |

### 关键性质

1. **每一步都比前一步要求更多，但增量很小**——AI不会突然面对巨大的跳跃
2. **每一步的输出都是下一步的context**——信息在层与层之间流动和积累
3. **AI不会意识到"我正在解题"**——每一步的问题看起来都很简单、很具体、很安全
4. **系统可以在任何一层介入给提示**——如果AI在L3列出的方向都不好，系统可以给一个思维模式提示
5. **渐进不等于线性**——AI可能在L4尝试后发现走不通，回到L3换方向

## 组合关系

- **组合了 safe-first-step**：连续发问框架的第一步（L1观察）就是安全第一步
- **与 non-specificity tension**：连续发问框架本身是非特定的（六层渐进是通用框架），但guided_001的Q3-Q4在执行中滑向了特定化
- **与 cognitive-activation 关系**（见 structural/cognitive-activation.md）：连续发问是认知激活的具体实现机制之一——通过控制每步粒度来激活AI能力
- **与 pipe 关系**（见 structural/pipe.md）：连续发问框架可以是模式识别引擎Pipe的输出协议——它定义了Pipe发给下游的提示的形式
- **约束于**：level-spectrum评估（见 concepts/level-spectrum.md）——每步Q的Level值影响激活效果

## 开放问题

### 1. 纯非特定连续发问够不够？

guided_001用了Q1-Q4（含特定化的Q3-Q4），验证了"连续发问+特定化"有效。但纯非特定连续发问（Q1-Q6，不引用AI选的特定方向）够不够？这是guided_003要回答的。

### 2. 六层框架是通用的还是特定于矩条件极差题？

六层渐进框架（观察→联想→描述→尝试→推进→卡点处理）看起来是通用的，但它基于guided_001这一道题的经验。换一道需要"先尝试再观察"的题，框架是否适用？需要更多实验。

### 3. 层与层之间的过渡时机

什么时候从L2进L3？什么时候从L3进L4？guided_001是引导者人工判断的。如果要做Pipeline，需要定义自动判断的规则——AI的输出满足什么条件才进下一层？
