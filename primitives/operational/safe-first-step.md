# 安全第一步（safe-first-step）

## 定义

不要求AI解题，而是让AI先描述题目的结构形状——结论是什么类型、已知条件是什么类型、条件和结论之间的距离、想到的方向。这一步AI必然可以完成，因为它不要求任何创造性，只是"读题并描述"，不是"解题"。

## 使用经验

### 为什么这一步AI必然可以完成

| 要求 | 解题 | 描述形状 |
|---|---|---|
| 创造性 | 需要 | 不需要 |
| 具体知识 | 需要 | 不需要 |
| 正确性 | 必须 | 不要求（方向可以错） |
| 操作性质 | 构造 | 观察 |
| 失败风险 | 高（卡死） | 极低（读题即可） |

描述形状是**元认知观察**——不是"怎么解题"，而是"这道题长什么样"。这是最高Level的思维模式之一：不依赖任何知识，跨所有领域适用，是所有其他思维模式的前置条件。

### 具体设计

给AI的指令不是"解这道题"，而是：
1. 结论是什么类型？（求常数/证明存在性/证明不等式/计数/...）
2. 已知条件是什么类型？列出每个条件及其类型。
3. 条件和结论之间的"距离"有多远？是直接代入就能得到，还是需要构造/反证/深层变换？
4. 你想到了哪些可能的方向？不要求正确，只要列出你能想到的所有方向。
5. 这道题让你联想到了什么类型的其他问题？

### 产出怎么用

AI给出的形状描述是系统匹配提示的依据：
- "这是极值问题" → 极值构型探测
- "结论需要证明存在性" → 反证法
- "条件是代数恒等式" → 恒等式挖掘
- "多个约束需要同时满足" → 寻找统一编码

### 和传统"先理解题意"的区别

传统做法：让AI"理解题意"然后"开始解题"——理解和解题是分开的，理解完直接跳到解题，AI在解题阶段卡死。

安全第一步：让AI做结构分析，然后用结构分析的产出来选择提示——分析和提示是耦合的。AI永远不会面对"从零开始解题"的空白状态。

## 关系

- **被组合 by continuous-questioning**：安全第一步是连续发问框架的第一层（L1观察）
- **与 cognitive-activation 关系**：安全第一步是认知激活的入口——它把AI从"试图解题"切换到"观察结构"，激活了元认知模式
- **与 non-specificity 关系**：安全第一步是完全非特定的——"描述形状"不依赖任何特定题目的特定解答路径
- **与 level-spectrum 关系**：安全第一步是Level→1的操作——纯元认知观察，不依赖任何具体知识

## 开放问题

### 1. 描述形状的产出质量怎么评估？

AI给出了形状描述，但描述的质量参差不齐。guided_001中AI的描述很好（识别了矩约束→极差下确界的结构），但如果AI的描述很差（只说"这是一个不等式"），系统怎么判断描述够不够好、能不能进下一层？

### 2. 安全第一步对所有题型都有效吗？

guided_001是一道不等式证明题。对于存在性命题、计数问题、构造问题，安全第一步的五个问题是否同样有效？特别是"条件和结论之间的距离"这个问题，对于构造题可能不好回答。
