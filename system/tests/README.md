# system/tests/ — 系统测试目录

本目录存放系统各模块的测试资产。**这些不是"用完就扔"的临时文件**，是系统测试的永久存档。每次架构改动后都要重跑验证，确保不退化。

## 目录结构

```
system/tests/
├── README.md                  # 本文件
└── vein_analysis/             # 脉络分析模块的测试
    ├── poc_no_loss_plan.md    # POC验证方案——三阶段架构不丢东西验证
    ├── poc_no_loss_report.md  # 测试报告（运行后生成/更新）
    ├── baseline/              # 基线产出（当前架构的产出，作为对比基准）
    ├── new_arch/              # 新架构产出（三阶段架构的产出）
    └── run_poc_no_loss.py     # POC验证脚本
```

## 测试规则

1. **每个模块一个子目录**——按模块组织，如`vein_analysis/`、`enter/`、`solve/`等
2. **每个测试有方案文档**——说明测试目标、方法、判定标准
3. **每个测试有测试报告**——记录测试结果，运行后自动生成或更新
4. **基线产出永久保存**——作为对比基准，不能删除
5. **新架构产出永久保存**——作为测试记录，不能删除
6. **每次架构改动后重跑验证**——确保不退化
