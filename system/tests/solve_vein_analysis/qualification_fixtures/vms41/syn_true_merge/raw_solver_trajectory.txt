I first isolate a parity lemma. In any trail that starts at a vertex (s), every intermediate visit to a different vertex consumes one entering and one leaving edge. If a maximal trail ended at a vertex (v\ne s), it would have used an odd number of edges incident to (v). Since the total degree of (v) is even, an unused incident edge would remain and the trail would not be maximal. Hence a maximal trail starting at (s) must return to (s).

This parity lemma gives a closed trail, but it does not yet show that the trail uses every edge. I set aside the incomplete argument while keeping the lemma.

Independently, take a closed trail (C) that is maximal under insertion of additional unused-edge trails. If an edge of the connected graph is unused, connectivity gives a vertex (w) of (C) incident to an unused edge. Starting at (w), follow unused edges without repetition to form a maximal unused-edge trail (P). The missing step is to prove that (P) returns to (w).

Now reuse the parity lemma from the first line of attack: in the subgraph of unused edges, every vertex except possibly vertices already met by (C) still has even unused degree, and the same entering-leaving parity argument forces the maximal trail (P) to return to (w). Splicing the closed trail (P) into (C) creates a strictly longer closed trail. This combines the parity branch with the maximal-trail splicing branch and contradicts the maximality of (C).

Therefore no unused edge remains. The resulting closed trail uses every edge exactly once, so it is an Euler circuit.
