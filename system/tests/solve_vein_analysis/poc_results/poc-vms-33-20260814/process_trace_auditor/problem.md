# Problem

For Fibonacci numbers defined by `F_0=0`, `F_1=1`, and
`F_{k+1}=F_k+F_{k-1}`, prove that

`gcd(F_m,F_n)=F_gcd(m,n)`

for all nonnegative integers `m,n`, not both zero.

The accompanying file is a recorded Solver exploration. The task in this POC is
to analyze the exploration, not to supply or improve the proof.
