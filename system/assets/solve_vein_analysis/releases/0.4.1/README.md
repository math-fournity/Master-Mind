# Solve-side Event Extractor asset release 0.4.1

This release is the frozen candidate role asset for POC-VMS-41R1. It supersedes
the VMS-41 `0.4.0` extractor asset only for new VMS-41R1 attempts.

Release contents:

- `AGENTS_event_extractor.md`: short role, authority, V2 occurrence extraction,
  typed-path source-span and merge-contribution contract;
- `TASK_event_extractor.template.md`: mechanically rendered per-case task;
- `reasoning-trajectory-candidate-v2.md`: candidate-visible strict object shape.

The hidden acceptable set, reference candidates, negative checks, thresholds and
blind review rubric are not part of the candidate workspace. They remain in the
qualification pack and are used only by trusted graders/auditors after the model
attempt is sealed.

This release is not a role qualification PASS. The preexecution freeze may bind
this asset, but live use still requires explicit authorization, a fresh attempt
lineage and blind manual audit.
