# Solve-side Event Extractor asset release 0.4.0

This release is the frozen candidate role asset for POC-VMS-41. It supersedes
the Event Extractor text in 0.3.0 only for new VMS-41 attempts; historical
VMS-38 evidence remains bound to 0.3.0 and must not be rewritten.

- `AGENTS_event_extractor.md`: short role, authority, extraction, source-span,
  relation and output contract;

- `reasoning-trajectory-v1.md`: candidate-visible strict object shape.

The hidden acceptable set, grader, reference candidates and thresholds are not
part of this asset release and must never be copied into a candidate workspace.
The release is not a qualification PASS until all four preregistered VMS-41
attempts and independent semantic audits have completed.
