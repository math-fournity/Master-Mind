# POC-VMS-33：解题侧 Devin 角色启动器修订验证协议

> 状态：`PREREGISTERED`  
> 类型：`REVISION_FIT_AND_REGRESSION`  
> 上游反例：POC-VMS-32  
> 不属于：未见 holdout、跨题泛化或生产 capability qualification

---

## 1. 修订假设

POC-VMS-32 没有评价到三个认知角色的内容能力，因为：

1. sandbox 下 `accept-edits` 被 CLI 忽略，写文件工具被拒绝；
2. 相邻角色共享 Devin carrier 配额但没有 cooldown，后两个调用触发 overall message rate limit。

本轮假设是：只修改 launcher profile 与 carrier-global 调度，即可让同一冻结角色资产产生可评价输出。

---

## 2. 唯一允许的修订

```yaml
permission_mode:
  old: accept-edits
  new: dangerous
sandbox: required
workspace: fresh isolated temporary directory
repo_read: denied by dedicated Devin config
volumes_read: denied by dedicated Devin config
subagents: disabled
resume_or_continue: forbidden
inter_role_cooldown_seconds:
  old: 0
  new: 75
cooldown_chunk_seconds: <= 30
model_uid: glm-5-2
normalized_effort: high
```

`dangerous` 只表示非交互工具自动批准；它不是安全结论。该 POC 的安全边界仍依赖：只给最小文件视图、全新临时工作区、OS sandbox、repo/Volumes read deny、无凭据、无DB、无Solver，以及运行后完整工具事件审计。

三份角色 AGENTS、problem、raw trajectory、normalizer input、auditor candidate trace 和 evaluator gold 均保持与 POC-VMS-32 相同，不得在看过旧输出后改题或改判据。

---

## 3. 运行顺序

```text
Event Extractor one-shot
  → 75s carrier-global cooldown
State Normalizer one-shot
  → 75s carrier-global cooldown
Trace Auditor one-shot
  → evaluator-only scoring
```

cooldown 是预先冻结的资源策略，不根据输出好坏动态增加。每个角色仍只有一个 POC-VMS-33 scientific attempt；任何 rate limit、无效输出或错误判断都直接封存，不重试。

---

## 4. 判据

内容判据完全继承348号：

- Extractor：strict schema、source/span hashes、occurrence recall 1.0、typed edge recall至少0.80、revisit identity、两父 merge、零 false merge；
- Normalizer：历史不变、三个预注册修正 recall 1.0、零无关变更、零虚构事件/边；
- Auditor：真 revisit PASS、伪 single-parent merge FAIL、整体 verdict 为 FAIL。

附加 launcher 判据：

```yaml
all_exit_codes_zero: true
all_exports_present: true
all_effective_model_uids_exactly_glm_5_2: true
all_expected_output_files_present: true
all_done_markers_present_and_hash_correct: true
all_retry_counts_zero_within_poc_vms_33: true

```

## 5. Verdict

- 三个 launcher 判据和三个内容判据全部通过：`PASS_WITHIN_REVISION_FIT_CALIBRATION_SCOPE`；
- launcher 通过但内容有部分缺失：按各角色 `PARTIAL/FAIL`；
