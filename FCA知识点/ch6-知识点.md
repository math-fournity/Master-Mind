# ch6 知识点提取：Properties of concept lattices

## 知识点清单

**P1 N^c_k-free / B(k)-free (contranominal-free context / B(k)-free lattice)**
- **是什么**：一个形式背景如果不包含任何与 contranominal scale N^c_k 同构的子背景，就叫 N^c_k-free。对偶地，一个完备格如果不包含 B(k)（k 个原子的 Boolean 格）作为子序嵌入，就叫 B(k)-free。这两个概念通过 Prop 112 精确对应：背景 N^c_k-free 当且仅当其概念格 B(k)-free。注意"子序嵌入"比"子格"弱——B(k) 可以作为子序出现而不作为子格出现（Fig 6.1 的例子），所以定义用的是 order-embed 而非 sublattice。
- **为什么需要它**：FCA 经常被批评"概念格大小关于背景大小是指数级的"。这个批评的根源是什么？Albano & Chornomaz 的工作回答了：**唯一让概念格爆炸的原因就是 contranominal 子背景**。如果背景不含 N^c_k，概念格的大小就被 f(n,k)（n 元集合中大小 < k 的子集数）控制住。N^c_k-free 这个概念把"不爆炸"精确化了——它让你能说清楚"什么样的背景是安全的"。
- **关键关系**：与 P2（Thm 44）共同构成"contranominal = 爆炸源"的理论核心；P3（breadth）是 N^c_k-free 的定量版本——breadth = b 意味着 N^c_{b+1}-free 但不 N^c_b-free；依赖 ch1 的 contranominal scale 定义（p.46）和子背景概念
- **崩塌条件**：当 k 很小时（k=1,2），几乎所有非平凡背景都含 N^c_k，所以 N^c_k-free 变得几乎无意义——它只在 k 足够大时才提供有信息量的约束。无限背景中，"子背景同构于 N^c_k"需要更小心地处理（有限 vs 无限子背景）
- **书内定位**：Def 90, 行 46; Prop 112, 行 56

**P2 最小外延生成元 ↔ contranominal 子背景 (minimal extent generator ↔ contranominal subcontext)**
- **是什么**：Thm 44 说：一个对象子集 A 是某个外延的最小生成元（即 A'' 是一个外延，且去掉 A 中任何一个元素 g 后 (A\{g})'' 都严格变小），当且仅当 A 是某个 contranominal 子背景的对象集。这个等价把两个看似无关的东西锁死了：闭包系统里的"最小生成元"和形式背景里的"contranominal 结构"。Corollary 8 进一步说：背景 N^c_k-free 当且仅当所有最小外延生成元的大小 < k。
- **为什么需要它**：这是连接"背景结构"和"格的大小"的关节。最小生成元的大小决定了你需要多少对象才能不可约地生成一个外延——这直接关系到格的"宽度"。而 Thm 44 说这个大小恰好等于 contranominal 子背景的规模。所以"格有多大"这个问题被翻译成了"背景里藏了多大的 contranominal"——一个关于交叉表结构的问题，比直接数概念容易得多。
- **关键关系**：是 P1（N^c_k-free）的证明引擎；推出 P3（breadth = 最大最小生成元大小 = 最大 contranominal 规模）；依赖 ch0 的闭包算子/最小生成元概念（Def 16, p.14）
- **崩塌条件**：对偶地，最小意图生成元对应 contranominal 子背景的属性集。在无限背景中，"最小生成元"可能不存在（外延可能没有有限生成元），定理的有限版本不直接推广
- **书内定位**：Thm 44, 行 98; Cor 8, 行 115

**P3 广度 (breadth)**
- **是什么**：一个有限格的 breadth 是最小的整数 b，使得任何超过 b 个元素的 join 都可以化简为其中 b 个元素的 join。等价地，它是最大的"不可约 join 表示"的大小——即存在 b 个元素 x₁,...,x_b，去掉任何一个都会让 join 变小。Cor 9 把它和 FCA 连起来：概念格的 breadth = 最大最小外延生成元的大小 = 最大最小意图生成元的大小 = 能序嵌入的最大 Boolean 格 B(b) 的原子数。
- **为什么需要它**：breadth 是"格有多宽"的精确度量。它把 P1 和 P2 的定性描述变成了一个数字。有了这个数字，Thm 45 给出了大小界：2^b ≤ |L| ≤ f(n, b+1)，其中 n 是 join-不可约元素数。这意味着 breadth 直接控制了格的大小的量级——breadth 小的格不会爆炸，breadth 大的格必然大。它是"contranominal 让格爆炸"这个故事的定量终点。
- **关键关系**：由 P2（Thm 44）直接推出；Thm 45 给出 breadth 控制大小的界；Boolean 格自对偶所以 breadth = 对偶 breadth（Cor 9 末尾）；与 ch0 的 join-不可约元素概念相关
- **崩塌条件**：定义依赖有限性（"最小的整数 b"）。在无限格中，breadth 可以是无限基数，大小界公式不再适用。chain 的 breadth = 1（任何 join 都是一个元素），所以 breadth=1 意味着格是一条链或接近链
- **书内定位**：Birkhoff 定义, 行 136; Cor 9, 行 145; Thm 45, 行 189; Cor 10, 行 200

**P4 分配律与完全分配律 (distributivity and complete distributivity)**
- **是什么**：分配律说 x∧(y∨z) = (x∧y)∨(x∧z)（及对偶形式），这是格论中最经典的结构约束。完全分配律是它对任意 inf/sup 的推广：∧_{s∈S} ∨_{t∈T} x_{s,t} = ∨_{ϕ:S→T} ∧_{s∈S} x_{s,ϕ(s)}，即"先取所有再取存在"可以交换为"对每个选择函数取所有再取存在"。不等号 ≥ 方向在任意完备格中都成立，分配律要求 ≤ 方向也成立。Prop 113 给出分配格的简洁刻画：a∧x=a∧y 且 a∨x=a∨y 蕴含 x=y（即 meet 和 join 联合能唯一确定元素）。
- **为什么需要它**：分配律是"没有意外"的形式化。在非分配格里，两个元素可以有相同的 meet 和 join 但本身不同——这意味着格的结构有"冗余路径"，信息丢失。分配格没有这个问题：结构是透明的，每个元素的位置被它与任何参考元素的 meet/join 唯一确定。完全分配律进一步要求这种透明性在无限运算下也成立。FCA 关心分配性是因为：分配的概念格结构简单、可读性强，而且可以完全用交叉表的箭头关系来判定（见 P6）。
- **关键关系**：P5（Birkhoff 定理）给出完全分配格的结构表示；P6（Thm 48）给出 doubly founded 概念格中分配性的箭头关系刻画；P9（半分配律）是它的弱化；P13（层次图）展示所有推广的关系
- **崩塌条件**：分配但不完全分配的完备格存在，但 Thm 48 说在 doubly founded 概念格中两者等价——所以对于有限概念格，"分配"和"完全分配"没有区别。去掉 doubly founded 假设后，分配 ≠ 完全分配
- **书内定位**：Def 14 回顾, 行 217; 完全分配律, 行 225; Prop 113, 行 281; Thm 47, 行 332

**P5 Birkhoff 定理：完全分配格 ↔ 序理想格 (completely distributive ↔ order ideals)**
- **是什么**：Thm 46 说：如果一个完备格 D 完全分配，且其 join-不可约元素 J(D) 在 D 中 sup-dense（每个元素都是 J(D) 中某些元素的 sup），那么映射 x ↦ (x] ∩ J(D) 是 D 到 (J(D),≤) 的所有序理想构成的闭包系统上的同构。反过来，任意偏序集 P 的序理想格都是完全分配的，且主理想 (x] 是其 join-不可约元素，sup-dense。
- **为什么需要它**：这给出了完全分配完备格的**完全结构分类**——它们就是序理想格。这意味着如果你有一个完全分配的概念格，它的结构完全被其 join-不可约元素之间的偏序关系决定。你不需要看整个格，只需要看不可约元素的序关系。这是"用少量基本元素编码整个格"思想的典范——和 FCA 用对象概念编码概念格的精神完全一致。
- **关键关系**：是 P6（Thm 48 条件 7）的理论基础——distributive 概念格同构于序滤子格（序理想的对偶）；依赖 ch0 的 join-不可约元素和 sup-dense 概念；与 P18（集合表示）相关——powerset 格是完全分配的典范
- **崩塌条件**：要求 J(D) sup-dense。在非 doubly founded 的格中，join-不可约元素可能不 sup-dense，定理不适用。去掉完全分配性（只保留分配性），定理不成立——存在分配但不完全分配的完备格
- **书内定位**：Thm 46, 行 286

**P6 Doubly founded 分配概念格的刻画 (characterization of distributive doubly founded concept lattices)**
- **是什么**：Thm 48 给出 doubly founded 概念格 L = B(G,M,I) 的九个等价条件，其中包括：L 分配、L 完全分配、箭头关系条件（g ↗ m 且 g ↗ n 蕴含 μ_m = μ_n；g ↗ m 且 h ↙ m 蕴含 γ_g = γ_h）、L 是二元格的完全子直积、L 是 powerset 格的完全子格、L 同构于某偏序集的序滤子格。在 reduced 背景下还等价于：每个 proper premise 是单元素集、所有箭头都是双箭头且每行每列恰好一个。
- **为什么需要它**：这是 FCA 把抽象格论性质翻译成交叉表可读条件的核心成果。分配性是一个抽象的代数性质，但 Thm 48 说你只需要看箭头关系——具体来说，在 reduced 背景中，分配性等价于"所有箭头都是双箭头，且每行每列恰好一个双箭头"。这意味着你可以**直接从交叉表读出概念格是否分配**，不需要计算整个格。双箭头在分配格中构成对象和属性之间的双射——这就是为什么分配概念格的 standard context 是方形的。
- **关键关系**：依赖 P4（分配律）、P5（Birkhoff 定理，条件 7）；箭头关系来自 ch1（Def 12）；条件 5（子直积）连接 ch5 的子直积分解；条件 8（proper premise 是单元素集）连接 ch2 的蕴含基
- **崩塌条件**：去掉 doubly founded 假设后，条件 1（分配）不再等价于条件 2（完全分配），箭头关系刻画也不再充分。Thm 47 给出了不假设 doubly founded 的版本，但条件更复杂
- **书内定位**：Thm 48, 行 465; Thm 47, 行 332

**P7 半模格 / 模格 / 分次格 (semimodular / modular / graded lattices)**
- **是什么**：模格满足模律：x ≤ z ⇒ x∨(y∧z) = (x∨y)∧z——这是分配律的弱化，允许"条件分配"（当 x ≤ z 时分配成立）。半模格更弱：x∧y ≺ y（y 的下邻是 x∧y）蕴含 x ≺ x∨y（x 的上邻是 x∨y）——即"如果 y 在 meet 处刚好比 x∧y 高一步，那么 x∨y 也刚好比 x 高一步"。分次格有一个秩函数 r，满足 r(0)=0 且 x ≺ y ⇒ r(y)=r(x)+1。还有弱半模性和强半模性两个中间条件。Prop 114 给出模格的刻画（类似 Prop 113 对分配格的刻画）。Prop 115 给出层次：分配 ⇒ 模 ⇒ 强半模 ⇒ 半模。
- **为什么需要它**：这些性质来自代数——子空间格（向量空间的子空间）是模格的典范例子。FCA 关心它们是因为它们描述了概念格的"几何规则性"。半模格有均匀的层次结构（如果分次的话，秩函数满足子模不等式 r(x)+r(y) ≥ r(x∧y)+r(x∨y)），使得格图可以画得整齐。模格保证"维度"行为良好（Dilworth 定理：有限模格的 join-不可约数 = meet-不可约数）。在概念格中，半模性对应于"没有向下的真箭头"（g ↗ m 蕴含 g ↗↗ m），模性对应于"所有箭头都是双箭头"——但这些只是必要条件，不充分。
- **关键关系**：P8（Thm 50）给出半模性的背景刻画；Prop 115 给出层次关系分配⇒模⇒半模；与 P6 对比——分配性有充分必要的箭头刻画，模性/半模性只有必要条件；Dilworth 定理连接 join/meet-不可约元素数相等
- **崩塌条件**：半模性的箭头条件（无向下真箭头）不是充分的——书中明确说"these conditions are by no means sufficient for semimodularity"。模格中箭头都是双箭头也不是充分的。Doerfel 的 Thm 49 给出了模格中一个有限的推广，但范围很窄
- **书内定位**：Def 91, 行 557; Prop 114, 行 573; Prop 115, 行 579

**P8 半模性的背景刻画 (context characterization of semimodularity)**
- **是什么**：Thm 50 给出 doubly founded 概念格半模性的等价条件，其中最可读的是交换条件（条件 3）：g• ⊆ A, h ∈ (A∪{g})'' 且 h ∉ A'' 蕴含 g ∈ (A∪{h})''。这里 g• = {x ∈ G | γ_x < γ_g}（所有对象概念严格小于 γ_g 的对象）。在 atomistic 情况下 g• = ∅，交换条件简化为经典形式：h ∈ (A∪{g})'' 且 h ∉ A'' 蕴含 g ∈ (A∪{h})''——这正是拟阵/拟阵交换公理的形式。条件 4 用箭头关系表达。对于有限格，还等价于分次 + 秩函数满足子模不等式。
- **为什么需要它**：它把半模性——一个关于格的邻域关系的性质——翻译成了关于背景中对象生成外延的交换性质。这个交换性质是拟阵理论的核心公理，揭示了半模概念格与拟阵/拟阵结构的深层联系。在 atomistic 情况下，概念格的半模性恰好对应于对象集上的拟阵结构。这使得 FCA 可以直接借用拟阵论的丰富结果。
- **关键关系**：依赖 P7（半模性定义）；交换条件在 atomistic 情况下退化为拟阵交换公理；强半模性在模格中平凡成立（Prop 115 证明：模律使前提矛盾）；因子格保持半模性（需要双 foundedness）
- **崩塌条件**：需要 doubly founded。只单方 founded 时，条件 4 中的 (h,p)∉I 可以加强为 h ↗ p，从而证明因子格保持半模性——但没有双重 foundedness 时，定理的某些方向不成立
- **书内定位**：Thm 50, 行 636; g• 记号, 行 631

**P9 半分配律 (semidistributivity SD∨/SD∧)**
- **是什么**：半分配律是分配律的弱化。join-半分配 (SD∨) 说：如果 x∨y = x∨z，那么 x∨y = x∨(y∧z)——即"两个 join 相同时，join 它们的 meet 也一样"。注意这比分配律弱：分配律说 x∨(y∧z) = (x∨y)∧(x∨z) 恒成立，而 SD∨ 只在 x∨y = x∨z 的前提下要求 x∨(y∧z) = x∨y。meet-半分配 (SD∧) 是对偶。半分配律不要求等式恒成立，只要求在"join 撞了"的时候 meet 能把撞了的值拉回来。
- **为什么需要它**：分配律太强——很多重要的格不分配但"差不多分配"。半分配律捕捉了"join 的行为局部确定"这个核心直觉：如果两个元素和 x 的 join 相同，那么它们的 meet 也和 x 的 join 相同。这意味着 join 的结果不会因为"选择哪个等价表示"而摇摆。半分配律在自由格理论中至关重要（Jónsson & Kiefer），而且有干净的箭头关系刻画（见 P11），使得它可以直接从交叉表判定。
- **关键关系**：P11（Thm 51）给出 join-半分配的箭头关系刻画；P12（Thm 52）给出 meet-分配（更强的条件）的刻画；P13（层次图）中 SD∨ 和 SD∧ 是独立的条件，合在一起才是半分配；分配 ⇒ 半分配但反之不然
- **崩塌条件**：SD∨ 和 SD∧ 是独立的——一个格可以满足 SD∨ 但不满足 SD∧，反之亦然。两者合在一起仍不蕴含分配性。在无限格中，半分配性可能有微妙差异
- **书内定位**：Def 92, 行 779

**P10 规范 ∨-表示 / 极端点 / 基点 (canonical ∨-representation / extremal points / base points)**
- **是什么**：在有限格中，一个元素 a 的 ∨-表示 a = ∨X 是不可约的，如果去掉 X 中任何一个元素 join 就变小。如果 a 恰好有一个通过 join-不可约元素的不可约 ∨-表示，称 a 有唯一不可约 ∨-表示。一个不可约 ∨-表示 a = ∨X 是规范的（canonical），如果对任何不可约表示 a = ∨Y 和任何 x∈X，存在 y∈Y 使 x ≤ y——即规范表示被所有不可约表示"细化"。极端点（extremal point）是 a 的 join-不可约下界中"不可替代"的：去掉它后 a 无法被剩余的 join-不可约元素生成。基点（base point）是更强的概念：b ≤ a 是 join-不可约的，且 b 不被 a 的其他所有 join-不可约下界的 join 覆盖。在概念格中，极端点和基点都可以直接用外延和对象来描述。
- **为什么需要它**：这些概念是理解"一个元素如何被基本砖块组装"的工具。极端点是每个 ∨-表示都必须包含的——它们是真正不可替代的组件。基点则更强：它们不仅不可替代，而且"独立"于其他所有不可约元素。这些概念在 P11 和 P12 中成为判定半分配性和 meet-分配性的背景条件：join-半分配性等价于"每个元素有规范 ∨-表示"，meet-分配性等价于"每个外延是其极端点的闭包"。
- **关键关系**：P11（Thm 51 条件 3,4）用规范表示和基点刻画 join-半分配性；P12（Thm 52 条件 3,6）用极端点和唯一表示刻画 meet-分配性；依赖 ch0 的 join-不可约元素和 sup-dense 概念
- **崩塌条件**：规范表示在有限格中如果存在则由 join-不可约元素组成。但在无限格中，不可约表示可能不存在（需要链有限性保证）。极端点和基点在概念格中的描述依赖 doubly foundedness
- **书内定位**：规范表示/极端点/基点定义, 行 786-844

**P11 Join-半分配性的背景刻画 (context characterization of join-semidistributivity)**
- **是什么**：Thm 51 给出 doubly founded 概念格满足 (SD∨) 的等价条件。最简洁的是条件 2：g ↗ m 且 h ↗ m 蕴含 g' = h'——即如果两个对象都和同一个属性构成向上箭头，那么这两个对象不可区分（有相同的对象意图）。在有限格（或满足额外条件 (*) 的格）中，还等价于：每个元素有规范 ∨-表示（条件 3）、每个外延是其基点的闭包（条件 4）。
- **为什么需要它**：和 P6 对分配性的刻画一样，这把抽象格性质翻译成了交叉表上的箭头条件。join-半分配性等价于"向上箭头在属性列上唯一确定对象"——这是一个可以在交叉表上直接检查的局部条件。条件 4（每个外延是基点的闭包）更有构造性意义：它说每个概念的外延都可以用一组"独立的"对象生成，这些对象不被其他对象"覆盖"。
- **关键关系**：依赖 P9（SD∨ 定义）和 P10（规范表示/基点）；P12 的条件 1 蕴含本定理的条件 2，所以 meet-分配 ⇒ join-半分配；local doubling 保持半分配性（行 942-944）
- **崩塌条件**：条件 3,4 需要额外条件 (*)（每个 x < a 有下邻 u 使 x ≤ u ≺ a），这在有限格中自动满足但无限格中不一定
- **书内定位**：Thm 51, 行 845

**P12 Meet-分配性与反交换公理 (meet-distributivity and the anti-exchange axiom)**
- **是什么**：meet-分配格（也叫 join-分配格，即对偶的局部分配格）是满足对偶半模性且每个模子格都分配的格。Thm 52 给出多个等价刻画，其中最深刻的是反交换公理（条件 4）：g ∉ A'', g ∈ (A∪{h})'' 蕴含 h ∉ (A∪{g})''——即如果 g 可以被 h 帮助生成，那么 h 不能被 g 帮助生成。这排除了"互相帮助"的循环。其他等价条件包括：每个外延是其极端点的闭包（条件 3）、每个元素有唯一不可约 ∨-表示（条件 6）、有保邻域的 ∧-嵌入到 powerset 格（条件 2）。
- **为什么需要它**：反交换公理是凸几何（convex geometry）和反拟阵（antimatroid）的核心公理。它捕捉了"生成过程有方向性"的直觉：如果 h 帮助生成 g，那么 g 不能反过来帮助生成 h。这在很多自然结构中出现——凸集的闭包系统满足反交换公理（一个点在凸包外但加入另一个点后在凸包内，反过来不成立）。所以 meet-分配概念格恰好对应于那些有"几何方向性"的闭包系统。这使得 FCA 与凸几何、学习空间（learning spaces）等领域建立了桥梁。
- **关键关系**：反交换公理连接凸几何/反拟阵理论；条件 2（保邻域 ∧-嵌入 powerset）连接 P18（集合表示）；条件 5（meet-分配）蕴含 P11 的条件（join-半分配）；在 atomistic 背景中，SD∨ + 无向上真箭头 ⇔ meet-分配（行 1080-1082）
- **崩塌条件**：反交换公理在非有限格中需要链有限性保证唯一表示的等价性。convex-ordinal scale 是 meet-分配的典范例子（行 1366-1370），但不是所有 meet-分配格都来自凸序
- **书内定位**：Def 92 (locally/meet-distributive), 行 784; Thm 52, 行 946

**P13 分配律推广的层次图 (the hierarchy of distributivity generalizations)**
- **是什么**：Figure 6.2 展示了 doubly founded 完备格中各种分配律推广之间的蕴含关系。完整的层次（从强到弱）：分配 ⇒ 模 ⇒ 半模；分配 ⇒ join-半分配 (SD∨)；分配 ⇒ meet-半分配 (SD∧)；SD∨ + 对偶半模 ⇒ meet-分配；SD∧ + 半模 ⇒ join-分配；半模 + 半凸 (semiconvex) 也在图中。半凸条件 (C) 是：x∧y = x∧z 且 x∨y = x∨z 蕴含 x ≤ z。属性 B 指的是自由格的有界同态像，等价于 reduced 背景的对象和属性可以排序使得所有双箭头在对角线上、所有 ↗ 在对角线下、所有 ↙ 在对角线上。
- **为什么需要它**：这张图是本章的结构地图。当你遇到一个概念格想知道它"有多接近分配"，这张图告诉你有哪些中间站。每个节点都是一个可识别的结构性质，有对应的箭头关系刻画。这张图也揭示了哪些性质是独立的（SD∨ 和 SD∧ 互相独立、半模和 SD∨ 互相独立），哪些可以组合出更强的性质（SD∨ + 对偶半模 = meet-分配）。
- **关键关系**：汇总 P4, P7, P9, P11, P12 之间的所有蕴含关系；半凸和属性 B 是图中的额外节点；local doubling 保持半分配性，是构造例子的工具
- **崩塌条件**：整个层次图假设 doubly founded。去掉这个假设后，很多等价关系断裂（如分配 ≠ 完全分配）。属性 B 的对角线排序刻画只在 reduced 背景中成立
- **书内定位**：Figure 6.2, 行 1358; 半凸定义, 行 1360; 属性 B, 行 1362

**P14 序维数 (order dimension)**
- **是什么**：一个偏序集 (P,≤) 的序维数是最小的 n，使得 P 可以序嵌入到 n 条链的直积中。直积上的序是分量序：x ≤ y 当且仅当每个分量 x_t ≤ y_t。序嵌入要求 x ≤ y 在 P 中当且仅当在每个分量中都成立。k-维数是变体：限制每条链的基数 ≤ k。Thm 53 说序维数等于其概念格 B(P,P,≤) 的序维数——所以研究偏序集的维数可以转化为研究概念格的维数，反之亦然。
- **为什么需要它**：维数衡量了"需要多少个线性序才能编码这个偏序"。维数高的偏序集结构复杂——有很多不可比的方向需要被不同的链区分。FCA 的价值在于：序维数可以被翻译成 Ferrers 维数（P16），从而变成一个关于交叉表覆盖的问题，可以用 FCA 的工具来处理。
- **关键关系**：P16（Thm 54）建立序维数 = Ferrers 维数；P17（k-维数）是细化版本；Thm 53 把偏序集维数转化为概念格维数；依赖 ch0 的序嵌入定义（Def 6）和 Dedekind 完备定理（Thm 4）
- **崩塌条件**：维数可以是无限的（存在任意高有限维数的偏序集）。k-维数在 k=1 时退化为"P 是否是链"。计算维数是 NP-hard 的（k≥3 时 NP-complete）
- **书内定位**：Def 93, 行 1526; Thm 53, 行 1540; k-维数, 行 1533

**P15 Ferrers 关系与 Ferrers 维数 (Ferrers relation and Ferrers dimension)**
- **是什么**：Ferrers 关系是 G×M 上的关系 F，满足：(g,m)∈F, (h,n)∈F, (g,n)∉F 蕴含 (h,m)∈F。直观上，如果把 F 画成交叉表，重排行列后它呈阶梯形——不包含 2×2 的"对角叉"子模式 ××/××（一个对角有一对，另一对角缺一对）。Prop 118 说 F 是 Ferrers 关系当且仅当 B(G,M,F) 是一条链。Ferrers 维数 fdim(G,M,I) 是覆盖 I 所需的最少 Ferrers 关系数（I = ∩ F_t）。Ferrers 关系的补也是 Ferrers 关系，所以等价地是覆盖空格所需的最少 Ferrers 关系数。
- **为什么需要它**：Ferrers 关系是"链"在交叉表上的对应物——一个 Ferrers 关系的概念格是一条链。所以"用多少个 Ferrers 关系覆盖 I"就等于"用多少条链的直积嵌入概念格"——这就是序维数。Ferrers 维数把抽象的序嵌入问题变成了具体的交叉表覆盖问题，可以用 FCA 的组合工具来处理。Ferrers 关系还与区间序（interval orders）有深刻联系——一个偏序集的 < 关系是 Ferrers 关系当且仅当它是区间序。
- **关键关系**：P16（Thm 54）建立 fdim = dim；Prop 118 给出 Ferrers = 链的对应；P17（k-step Ferrers）是长度受限版本；与区间序理论的联系（Notes 节）
- **崩塌条件**：Ferrers 关系要求行列可重排成阶梯形——如果行列有重复模式（如循环结构），可能无法成为 Ferrers。计算 Ferrers 维数在 k≥3 时 NP-complete
- **书内定位**：Def 94, 行 1579; Prop 118, 行 1589

**P16 序维数 = Ferrers 维数 (order dimension = Ferrers dimension, Thm 54)**
- **是什么**：Thm 54 说：概念格 B(G,M,I) 的序维数等于背景 (G,M,I) 的 Ferrers 维数。即 dim B(G,M,I) = fdim(G,M,I)。对偏序集也有 dim(P,≤) = fdim(P,P,≤)。这是 Prop 117（概念格序嵌入 ⇔ 背景关系分解为子背景关系的交）和 Prop 118（Ferrers 关系 ⇔ 链）的直接推论——因为嵌入链的直积就是用 Ferrers 关系覆盖 I。
- **为什么需要它**：这是连接序论和 FCA 的关节定理。序维数是序论的核心概念，Ferrers 维数是 FCA 的组合概念。Thm 54 说它们是同一件事——这意味着所有关于序维数的序论结果都可以用 FCA 语言重新表述，反之亦然。这种翻译不只是美学上的——它使得序维数的计算可以转化为交叉表上的覆盖问题，有直接的组合算法。
- **关键关系**：由 Prop 117（序嵌入 ⇔ 关系交分解）和 Prop 118（Ferrers ⇔ 链）直接推出；P17（Thm 55）推广到 k-维数；Thm 56 进一步简化为只需覆盖双箭头
- **崩塌条件**：对 doubly founded 背景，Thm 56 说只需覆盖双箭头对应的空格——这进一步简化了计算。非 doubly founded 时需要覆盖所有空格
- **书内定位**：Thm 54, 行 1605; Prop 117, 行 1556; Thm 56, 行 1711

**P17 k-维数与 k-step Ferrers 关系 (k-dimension and k-step Ferrers relations)**
- **是什么**：Ferrers 关系的长度是其概念格 B(G,M,F) 的长度（链的长度）。k-step Ferrers 关系是其阶梯形恰好有 k 个台阶的 Ferrers 关系。fdim_k(G,M,I) 是覆盖 I 所需长度 ≤ k 的 Ferrers 关系的最少数数。Thm 55 说 dim_k B(G,M,I) = fdim_k(G,M,I)——k-维数的 FCA 翻译。Prop 119 说 k-step Ferrers 关系的补是长度 k 的 Ferrers 关系，所以 fdim_k 也等于覆盖空格所需的 ≤(k-1)-step Ferrers 关系数。特别地，2-维数等于覆盖空格所需的 1-step Ferrers 关系数——即矩形数。
- **为什么需要它**：k-维数细化了维数概念，限制了嵌入链的长度。2-维数特别重要因为：二元链的直积就是 powerset 格，所以 2-维数等于概念格可嵌入的最小集合表示的大小。这直接连接到 Boolean 矩阵分解（P19）——2-维数就是 Boolean 分解所需的最少因子数。k-维数还提供了从"纯序嵌入"到"有限长度链嵌入"的谱系，让你可以按需选择精度。
- **关键关系**：P16（Thm 54）的细化；P18（集合表示）在 k=2 时等价；P19（Boolean 矩阵分解）在 k=2 时等价；Thm 56 在 k-版本下也成立
- **崩塌条件**：k=1 时退化为"概念格是否是链"。k≥3 时计算 NP-complete。2-维数虽然也 NP-complete 但有更多结构可利用（矩形覆盖）
- **书内定位**：Def 95, 行 1645; Thm 55, 行 1660; Prop 119, 行 1656

**P18 集合表示 (set representation)**
- **是什么**：背景 (G,M,I) 在集合 T 上的集合表示是一对映射 α: G→P(T), β: M→P(T)，给每个对象和属性分配 T 的子集，使得 g I m ⇔ α_g ∩ β_m ≠ ∅。互补集合表示则要求 g I m ⇔ α_g ∩ β_m = ∅。Prop 120 说三个条件等价：背景有 T 上的互补集合表示、概念格有 T 上的集合表示、dim_2 B(G,M,I) ≤ |T|。所以 2-维数就是集合表示所需的最小底层集合大小。
- **为什么需要它**：集合表示把"对象-属性关联"翻译成了"集合相交"——一个更直观、更可计算的语言。每个对象和属性都被表示为一个子集，关联关系变成子集相交的非空性。这不仅是理论翻译——它是很多数据表示方法的基础。互补集合表示特别自然：对象和属性各对应一个子集，关联当且仅当子集不相交。
- **关键关系**：与 P17（2-维数）等价（Prop 120）；与 P19（Boolean 矩阵分解）相关——集合表示的维度就是 Boolean 分解的因子数；ch1 的自由分配格背景就是用集合表示定义的
- **崩塌条件**：集合表示总是存在的（取 T = G×M 的所有关联对），问题是最小化 |T|。最小化是 NP-complete 的
- **书内定位**：Def 96, 行 1678; Prop 120, 行 1687

**P19 Boolean 矩阵分解 (Boolean matrix factorization)**
- **是什么**：Boolean 矩阵分解把背景 (G,M,I) 分解为 (G,F,I_GF)·(F,M,I_FM) 的 Boolean 矩阵乘积，其中 F 是"因子"集，目标是因子数最少。每个因子 f 对应一个 preconcept（f^{I_GF} × f^{I_FM} ⊆ I），所有因子的 preconcept 覆盖整个 I。因为每个 preconcept 可扩展为概念，所以因子数也等于覆盖 I 所需的最少概念数。Thm 57 说这个最少因子数等于 K^c（互补背景）的 2-维数。
- **为什么需要它**：Boolean 矩阵分解是数据科学中的热门话题——它把高维二元数据分解为低维二元因子表示，类似 SVD 但在 Boolean 域上。FCA 的贡献是给出了精确的理论刻画：Boolean 分解的因子数 = 互补背景的 2-维数 = 覆盖关联关系所需的最少矩形（preconcept）数。这使得 Boolean 分解不再只是启发式算法的对象，而是有了精确的组合理论基础。析取属性表示（disjunctive attribute representation）是另一个视角：把原始属性表示为更简单属性的析取。
- **关键关系**：Thm 57 连接 P17（2-维数）；每个因子 = 一个 preconcept（ch1 概念）；覆盖 I 的最少概念数 = 因子数；与 P18（集合表示）通过 2-维数连接；七段数码管例子（Fig 6.6-6.7）展示实际计算
- **崩塌条件**：精确分解（覆盖整个 I）可能需要很多因子；实践中常用近似分解。triadic 推广（Glodeanu, Belohlavek）结构更复杂。因子数 = 2-维数是精确分解的理论，近似分解没有这个等价
- **书内定位**：Thm 57, 行 1822; 析取属性表示, 行 1828; 七段数码管例子, 行 1766

**P20 ∨-维数与 ∨-秩 (∨-dimension and ∨-rank)**
- **是什么**：∨-维数是有限格 L 可 ∨-保持嵌入（injective, ∨-preserving）的最少链数直积的链数。∨-秩是这种嵌入的最短总长度。Thm 58 说：L 可 ∨-嵌入到 n 条长度 l₁,...,l_n 的链的直积中，当且仅当 M(L)（meet-不可约元素集）可被 n 条基数 m₁,...,m_n 的链覆盖（m_i ≤ l_i）。Cor 11 用 Dilworth 定理推出：∨-维数 = M(L) 的宽度（最大反链大小），∨-秩 = |M(L)|。
- **为什么需要它**：∨-保持嵌入比序嵌入弱（不要求 ∧ 保持），所以 ∨-维数 ≤ 序维数。它主要用于格图的绘制——∨-保持嵌入到链的直积给出了格图的自然坐标系统。Dilworth 定理把 ∨-维数归结为 M(L) 的宽度，这是一个纯组合参数，比直接计算嵌入容易得多。这展示了 FCA/格论中"用不可约元素编码整个格"思想的又一个实例。
- **关键关系**：∨-维数 ≤ 序维数（P14），因为 ∨-嵌入弱于序嵌入；依赖 Dilworth 链覆盖定理；M(L) = meet-不可约元素集（ch0）；详细理论在 ch7（Prop 132, 134）
- **崩塌条件**：只对有限格成立（Dilworth 定理需要有限性）。∨-嵌入不保持 ∧，所以不能用于需要 meet 信息的场景。∨-维数 = 1 意味着格可 ∨-嵌入到一条链——这比"格是链"弱得多
- **书内定位**：Thm 58, 行 1876; Cor 11, 行 1890
