# ch8 知识点提取：Contextual concept logic

## 知识点清单

**P1 复合属性 (Compound attributes)**
- **是什么**：在形式背景 (G, M, I) 中，除了原始属性集 M 里的属性，还可以用逻辑连接词 ¬（否定）、∧（合取）、∨（析取）反复组合 M 中的属性，生成"复合属性"。一个对象 g 是否拥有某个复合属性，按命题逻辑的标准规则判定：g 拥有 ¬m 当且仅当 g 不拥有 m；g 拥有 ∧A 当且仅当 g 拥有 A 中每个属性；g 拥有 ∨B 当且仅当 g 拥有 B 中至少一个属性。关键区别：和数学逻辑不同，这里的 A 和 B 不要求有限——因为形式背景的对象集和属性集本身可以无限。每个复合属性都有一个外延（extent），即拥有它的对象集合，由上述规则递归确定。
- **为什么需要它**：形式背景的原始属性是"原子"的——每个属性单独描述对象的一个特征。但人类推理时用的判断往往是复合的："会游泳且不会飞的"、"要么食肉要么食草的"。如果不引入复合属性，FCA 只能处理原子属性的概念格，无法表达逻辑组合。复合属性把 Boole 的逻辑代数引入 FCA：Boole 当年谈的"符号、类、论域"，在 FCA 语言里就是属性、概念外延、形式背景。引入复合属性后，FCA 不再只是"提取概念格"的工具，还能做逻辑推理——判断哪些逻辑规则在给定数据中成立。
- **关键关系**：是本章全部属性逻辑的地基；P3（等价关系）定义在复合属性上；P4（序列）是复合属性的规范表示；P7（全外延）把复合属性从"属性"翻转为"规则"；依赖前章的形式背景和概念格基本概念
- **崩塌条件**：如果把所有可能的复合属性都加入背景，概念格会爆炸性增长（书中明确警告"not a good idea to add all possible compound attributes"）。另外，复合属性的否定 ¬m 的外延是 G\m'，这在概念格通常没有补元的情况下不对应任何形式概念——复合属性不一定是概念，这是 P10-P12 引入弱化概念的动机
- **书内定位**：行 42-84（无正式 Definition 编号，在 8.1 节开头引入）

**P2 布尔扩充 (Boolean enrichment)**
- **是什么**：给定形式背景 K := (G, M, I) 和一组复合属性 C，把 C 加入属性集，得到新背景 (G, M∪C, I∪I_C)，其中 I_C 按复合属性的定义实现外延。这个新背景是 K 和 (G, C, I_C) 的 apposition（并置）。扩充后的背景拥有 K 的所有概念外延，通常还有更多——具体多多少取决于 C 的选择。
- **为什么需要它**：它把"复合属性"从理论概念变成可操作的工具。你想在概念格里看到"会游泳且不会飞"这个复合属性对应的概念节点？布尔扩充就是实现方式：把复合属性加进背景，重新算概念格。但它是有代价的：加得越多，概念格越大。这个知识点捕捉了一个核心张力——表达力 vs 复杂度。FCA 的实践智慧在于：选择性地加入有意义的复合属性，而不是全加。
- **关键关系**：依赖 P1 复合属性；是 P22（术语属性）的类比——前者加逻辑复合属性，后者加关系复合属性；扩充后的概念格包含原概念格的概念外延作为子集
- **崩塌条件**：加入所有可能的复合属性 → 概念格急剧膨胀，实际不可行。书中明确说这"usually not a good idea"
- **书内定位**：行 85-95（无正式 Definition 编号）

**P3 外延等价 vs 全局等价 + 测试背景 (Extensional vs global equivalence + test context)**
- **是什么**：两个复合属性在某个具体背景 (G, M, I) 中"意思一样"（外延等价），如果它们在这个背景中有相同的外延。它们"在所有背景中都意思一样"（全局等价），如果对于任何拥有属性集 M 的背景，它们的外延都相同。Prop 142 给出了一个判据：两个复合属性全局等价，当且仅当它们在测试背景 (P(M), M, ∋) 中外延等价——这个背景的对象集是 M 的全部子集，一个对象（子集）X 拥有属性 m 当且仅当 m ∉ X。
- **为什么需要它**：复合属性可以用不同的逻辑表达式写同一个意思——¬(m∧n) 和 ¬m∨¬n 在任何背景中都等价（De Morgan 律），但 m∧¬m 和 ⊥ 也等价，而后者只在"这个背景中 m 和 ¬m 互斥"时才成立。区分"在这个背景中碰巧等价"和"在逻辑上必然等价"至关重要：前者是数据驱动的，换一批数据就不等价了；后者是逻辑必然的，不管什么数据都成立。测试背景 (P(M), M, ∋) 是一个"万能背景"——它包含了所有可能的属性组合作为对象，所以如果两个复合属性在它里面等价，就没有任何背景能区分它们。这把"全局等价"这个抽象概念变成了一个可操作的判定方法。
- **关键关系**：依赖 P1 复合属性；测试背景是 P5（合取范式）和 P6（子句逻辑）的基础工具；与 ch5 的蕴含逻辑形成对比——蕴含逻辑描述概念内涵之间的关系，子句逻辑描述对象内涵之间的关系（书中行 170-171 明确对比）
- **崩塌条件**：测试背景 (P(M), M, ∋) 的对象集是 P(M)，当 M 无限时这是不可数无穷——测试背景本身可能不可计算。另外，全局等价只考虑属性集 M 的结构，不考虑对象集 G 的特殊性——两个在逻辑上不等价但在这个特定背景中外延相同的复合属性，全局等价会漏掉这种"数据驱动的等价"
- **书内定位**：行 96-104，Prop 142 在行 101

**P4 序列 / 子句 (Sequent / clause)**
- **是什么**：一个序列 (A, S) 是一种特殊形式的复合属性，由两个不相交的属性子集 A, S ⊆ M 表示，全局等价于 ∨(S ∪ {¬m | m ∈ A})。意思是："拥有 S 中至少一个属性，或者不拥有 A 中至少一个属性"。可以写成 ∧A → ∨S（如果拥有 A 中所有属性，那么必须拥有 S 中至少一个），这让序列看起来像一条规则。只考虑不相交序列（A∩S=∅），因为非不相交的序列全局等价于 ⊤（恒真）。序列有自然偏序：(A₁,S₁) ≤ (A₂,S₂) 当且仅当 A₁⊆A₂ 且 S₁⊆S₂。满序列 (full sequent) 是 S = M\A 的序列，它的外延在测试背景中是 P(M)\{A}——即"除了 A 以外的所有子集"。
- **为什么需要它**：复合属性可以任意复杂（逻辑连接词可以无限嵌套），但 Prop 66（合取范式定理）保证每个复合属性都全局等价于一个唯一的不相交满序列的合取。这意味着序列是复合属性的"规范形式"——不管多复杂的复合属性，都可以化简为序列的合取。这把无穷可能的复合属性压缩到了一个可管理的表示。序列的形式 ∧A → ∨S 还自然连接到蕴含——它是"如果 A 中所有属性都满足，那么 S 中至少一个必须满足"的规则形式。
- **关键关系**：依赖 P1 复合属性 + P3 测试背景；是 P5（合取范式）的表示单元；是 P6（子句逻辑）的基本构件；P8（特殊子句类型）是序列的特例；形式上连接到 ch5 的蕴含 A→B
- **崩塌条件**：序列只能表达"合取范式"形式的复合属性——虽然每个复合属性都有等价的合取范式，但合取范式可能指数膨胀（NP-hard）。这就是为什么书中说"one quickly encounters intractable problems"
- **书内定位**：Def 109, 行 109-124

**P5 合取范式定理 (Conjunctive normal form)**
- **是什么**：Thm 66 断言：每个复合属性都全局等价于一个唯一的不相交满序列的合取。也就是说，不管复合属性多复杂，都能写成若干个 (A, M\A) 的合取，而且这个表示是唯一的。
- **为什么需要它**：这是复合属性理论的"坐标定理"。没有它，复合属性的空间是无结构的——同一个意思可以用无穷多种写法表达，你无法判断两个复合属性是否等价。有了它，每个复合属性都有一个唯一的"标准形"（满序列合取），等价判定变成了标准形比较。这和布尔代数里的 CNF（合取范式）是同一件事，但 FCA 的版本更精确——它给出了唯一性，而一般布尔代数的 CNF 不唯一（需要"素子句"才唯一）。
- **关键关系**：依赖 P4 序列 + P3 测试背景（满序列的外延在测试背景中计算）；是 P6（子句逻辑）的理论前提——子句逻辑就是"哪些序列在给定背景中恒真"
- **崩塌条件**：唯一性依赖于"不相交满序列"的限制。如果去掉"满"的要求，表示不再唯一；如果去掉"不相交"的要求，会有冗余。另外，合取范式可能指数长——实践中不一定高效
- **书内定位**：Thm 66, 行 131-132

**P6 子句逻辑 + 正则子句集 (Clause logic + regular clause sets)**
- **是什么**：一个复合属性在背景 (G, M, I) 中是"全外延的"（all-extensional），如果它的外延是全部对象 G。背景的子句逻辑就是所有全外延的序列的集合——即所有在这个背景中"恒真"的规则 ∧A→∨S。一个子句集 C（不相交序列的集合）是"正则的"（regular），如果 (A,S)∈C 当且仅当所有包含 (A,S) 的满序列也在 C 中。Thm 67 断言：一个子句集是正则的，当且仅当它是某个形式背景的子句逻辑；而且这个背景（在澄清和同构意义下）是唯一的。
- **为什么需要它**：这是属性逻辑的"表示定理"。它说明：子句逻辑完全编码了形式背景的对象内涵系统——就像蕴含逻辑完全编码了概念内涵系统一样（书中行 170-171 明确做这个对比）。正则性条件是关键：它不是任意一堆子句，而是满足"向下封闭于满序列包含关系"的结构化集合。正则子句集构成闭包系统（正则子句集的交集仍正则），对应背景是各背景的 subposition。这个定理把"背景"和"子句逻辑"锁定为一一对应（模澄清和同构），和 ch5 中"背景和蕴含逻辑的一一对应"平行。
- **关键关系**：依赖 P4 序列 + P5 合取范式 + P7 全外延；与 ch5 蕴含逻辑形成对偶——蕴含逻辑编码概念内涵，子句逻辑编码对象内涵；正则子句集构成闭包系统（连接 ch0 闭包系统概念）
- **崩塌条件**：子句逻辑的计算是 NP-complete（书中行 203 明确说"one quickly encounters intractable problems"）。对于大背景，算出完整子句逻辑不可行——需要 SAT-solver 等实用算法。另外，子句逻辑不能区分有相同对象内涵的对象，也不编码对象名称信息
- **书内定位**：行 147-174，Thm 67 在行 157

**P7 全外延复合属性 = 逻辑规则 (All-extensional compound attributes as logical rules)**
- **是什么**：一个复合属性如果在背景 (G, M, I) 中的外延是全部对象 G，就叫做"全外延的"（all-extensional）。所有全外延复合属性的集合叫做这个背景的"布尔属性逻辑"（Boolean attribute logic）。关键的概念翻转在于：复合属性可以从两个角度理解——(1) 作为"广义属性"，问"哪些对象拥有它"；(2) 作为"逻辑规则"，问"它是否对所有对象成立"。全外延 = 规则成立。具体地，序列 (A,S) 全外延当且仅当 ∧A 蕴含 ∨S——也就是说，"如果拥有 A 中所有属性，就必须拥有 S 中至少一个"这条规则在背景中成立。
- **为什么需要它**：这是复合属性理论的核心概念翻转。没有这个翻转，复合属性只是"更多的属性"——加了它们概念格变大，但本质上和原始属性没有区别。有了这个翻转，复合属性同时是"属性"和"规则"——同一个数学对象，两种解读。这让 FCA 能同时做两件事：提取概念结构（属性视角）和发现逻辑规则（规则视角）。这个翻转是 P6 子句逻辑的概念基础——子句逻辑就是"所有成立的规则的集合"。
- **关键关系**：依赖 P1 复合属性 + P4 序列；是 P6 子句逻辑的概念前提；与 ch5 的蕴含 A→B 直接对应——序列 (A,S) 全外延 ⟺ ∧A 蕴含 ∨S
- **崩塌条件**：全外延依赖于具体背景——一个复合属性在这个背景中全外延（规则成立），换个背景可能就不成立了。只有全局等价的复合属性的全外延性才不依赖于具体背景
- **书内定位**：行 133-146

**P8 特殊子句类型及其自由外延 (Special sequent types: inconsistency, disjunction, implication, surmise relationship)**
- **是什么**：Def 110 定义了序列的四种特殊形式：(A,∅) 叫"不一致"（inconsistency）——因为同时拥有 A 中所有属性的对象违反这条子句；(∅,S) 叫"析取"（disjunction）——每个对象必须拥有 S 中至少一个属性；(A,{m}) 叫"单结论蕴含"（implication with singleton conclusion）——拥有 A 中所有属性就必须拥有 m；({m},S) 叫"猜测关系"（surmise relationship）。Prop 144 给出了这四种特殊子句的"自由外延"（在测试背景中的外延）分别对应什么结构：不一致的自由外延 = 序理想（order ideal）；析取的自由外延 = 序滤子（order filter）；蕴含的自由外延 = 闭包系统；猜测关系的自由外延 = 核系统（kernel system）。
- **为什么需要它**：这把"逻辑规则类型"和"序论结构"锁定了一一对应。之前你知道"不一致"是一种规则类型，"闭包系统"是一种序论结构——它们看起来毫不相干。Prop 144 告诉你它们是同一件事的两个面。这不仅统一了两个领域，还给出了一个判定工具：给定一个子集族，问"它是不是闭包系统"，等价于问"它是不是某组蕴含规则的自由外延"。这和 ch5 的蕴含逻辑直接连接——蕴含 (A,{m}) 的自由外延是闭包系统，正是 ch5 蕴含逻辑的数学基础。
- **关键关系**：依赖 P4 序列 + P3 测试背景 + P7 全外延；与 ch5 蕴含逻辑直接连接（蕴含→闭包系统）；连接 ch0 的序理想/序滤子/闭包系统/核系统；不一致+析取的自由外延的交集 = 凸子集（行 197-198）
- **崩塌条件**：这些对应关系在测试背景 (P(M), M, ∋) 中成立——在具体背景中，自由外延和实际外延可能不同。另外，"单结论蕴含"是蕴含的特例（结论只有一个属性），一般蕴含 A→B（B 可以多个属性）需要用多条单结论蕴含表示
- **书内定位**：Def 110, 行 178-184；Prop 144, 行 189-193

**P9 累积子句 (Cumulated clauses)**
- **是什么**：累积子句是形如 ∧A → ∨_{t∈T} ∧A_t 的表达式——前提是"拥有 A 中所有属性"，结论是"至少有一组 A_t 中的属性全部满足"。它是序列的推广：序列的结论是 ∨S（析取单个属性），累积子句的结论是 ∨(∧A_t)（析取属性合取）。累积子句包含了序列（当每个 A_t 是单元素集时退化为序列），所以表达力相同，但有时更直观。
- **为什么需要它**：实际推理中，有些规则用纯序列表示不自然。书中的例子："需要水才能活的生物，要么住在陆上，要么需要叶绿素，要么能移动且有四肢"——写成序列需要拆成多条，写成累积子句 a → b∨d∨(g∧h) 就一条。累积子句在形式上和蕴含惊人地相似（都是 ∧A → ... 的形式），这让它在某些场景比纯子句更直观。代价是：算法复杂度比蕴含高（因为包含了子句的全部表达力，而子句是 NP-complete 的）。
- **关键关系**：是 P4 序列的推广；形式上连接 ch5 蕴含（∧A → ...）；表达力 = 序列（互相可表示），但算法复杂度更高
- **崩塌条件**：和子句一样是 NP-complete 的。虽然比纯蕴含更直观，但失去了蕴含逻辑的高效算法（蕴含可以用 Next Closure 等多项式算法处理，子句和累积子句不行）
- **书内定位**：行 199-230

**P10 前概念 (Preconcept)**
- **是什么**：在形式背景 (G, M, I) 中，一个前概念是满足 A×B ⊆ I 的对象集-属性集对 (A, B)——即 A 中每个对象都拥有 B 中每个属性。用交叉表的直觉说：前概念就是一个"满子矩形"（full subrectangle），矩形内每个格子都有叉。等价条件：A ⊆ B'（A 中每个对象都拥有 B 中所有属性）且 B ⊆ A'（B 中每个属性都被 A 中所有对象拥有）。前概念不要求最大化——任何满子矩形都是前概念，包括空矩形。
- **为什么需要它**：形式概念是"最大满矩形"——既要求满（A×B⊆I），又要求最大（A=B', B=A'）。但人类思考时经常用不完整的概念："一些对象和一些属性，它们之间有交叉关系，但我不需要知道完整的范围"。前概念捕捉了这种"部分概念"的直觉：你只需要一些对象和一些属性，它们形成一个满矩形，就够了。它是 P11（原概念）和 P12（半概念）的基础——后两者是在前概念上加不同最大化条件得到的。
- **关键关系**：是 P11 原概念和 P12 半概念的基础（前概念 ⊇ 原概念 ⊇ 半概念 ⊇ 形式概念）；P13 前概念格的元素；P14 前概念代数的元素；用"矩形"直觉统一理解 pre/proto/semi/concept 的层次
- **崩塌条件**：前概念太弱了——任何满子矩形都是前概念，包括 (∅, ∅)。前概念的数量通常远大于形式概念（书中小例子有 47 个前概念但只有 10 个形式概念）。前概念本身没有有意义的代数运算——需要 proto/semiconcept 才有运算结构
- **书内定位**：Def 111, 行 243-249

**P11 原概念 (Protoconcept)**
- **是什么**：原概念是满足 A' = B'' 且 B' = A'' 的前概念 (A, B)。用矩形的直觉：原概念是"一边最大化"的满矩形——要么 A 已经是 B 的全部对象（A = B'），要么 B 已经是 A 的全部属性（B = A'），但不要求两边同时最大化。等价条件 A'=B'' 和 B'=A'' 意味着：如果你对 A 取全部公共属性得到 A'，再取这些属性的全部公共对象得到 A''，结果等于原来的 A'——即"一边已经闭合"。原概念恰好是那些"小于等于恰好一个极大元素"的前概念——在矩形包含序下，它只属于一个形式概念。
- **为什么需要它**：形式概念要求两边同时最大化，这在实践中太严格——你可能知道一个概念的完整外延但不知道完整内涵（或反过来）。原概念放松了这个要求：只要一边闭合就够了。这更接近人类实际使用概念的方式——"我知道这些对象都有这些属性，这足以确定是哪个概念，但我不需要列出全部属性"。原概念还有代数运算结构（P14 前概念代数的运算在原概念上有定义），这使得它不只是描述工具，还能做代数推理。
- **关键关系**：是 P10 前概念的特殊情况，P12 半概念的特殊情况（半概念 ⊆ 原概念）；P14 前概念代数的运算结果总是半概念（原概念的运算结果落在半概念中）；在矩形包含序下恰好属于一个形式概念
- **崩塌条件**：原概念的运算（meet/join）不满足幂等律——(A,B)⊓(A,B) 不一定等于 (A,B)。这意味着原概念不能形成格，只能形成更弱的代数结构（P15 双布尔代数）
- **书内定位**：Def 111, 行 246

**P12 半概念 (Semiconcept)**
- **是什么**：半概念是满足 A' = B 或 B' = A 的前概念 (A, B)——即一边不仅最大化而且"等于"另一边的导出。分为两种：u-半概念（A' = B，属性侧闭合）和 t-半概念（B' = A，对象侧闭合）。每个半概念要么是 u-型要么是 t-型（或两者皆是，即形式概念）。所有半概念的集合 H(K) 分裂为两部分：H_u(K)（所有 u-半概念）和 H_t(K)（所有 t-半概念）。H_u(K) 同构于幂集格 (P(G), ⊆)，H_t(K) 同构于 (P(M), ⊇)——两个布尔格。它们的交集恰好是全部形式概念。
- **为什么需要它**：半概念是前概念/原概念层级中唯一有干净代数结构的层。u-半概念和 t-半概念各自形成布尔格，合在一起形成"双布尔代数"（P15）。这个分裂结构是 FCA 处理概念否定的数学基础：否定运算 ¬ 把一个概念变成一个 u-半概念，对立运算 ⌐ 把它变成一个 t-半概念——否定和对立分别落在两个布尔格中。没有半概念的分裂结构，就无法定义概念的否定（P16）。
- **关键关系**：是 P10 前概念和 P11 原概念的特殊情况；H_u 和 H_t 各自同构于幂集格（连接 ch0 布尔格）；交集 = 形式概念；是 P15 双布尔代数的元素；是 P14 前概念代数运算的值域
- **崩塌条件**：半概念的 meet/join 仍不幂等（u-半概念做 meet 后是 u-半概念，但做 join 后可能不是半概念——实际上 join 结果总是 u-半概念，所以 t-半概念做 join 后不再是自身类型）。只有在形式概念上 meet/join 才恢复幂等性。这就是为什么半概念代数是"双布尔代数"而非"布尔代数"
- **书内定位**：Def 111, 行 247-249

**P13 前概念格 (Preconcept lattice)**
- **是什么**：所有前概念 V(K) 在偏序 ≼ 下（(A₁,B₁) ≼ (A₂,B₂) 当且仅当 A₁⊆A₂ 且 B₁⊇B₂——即"对象更多、属性更少"是更大的概念）形成一个完备分配格。Prop 145 证明了这个格同构于一个特定形式背景的概念格：背景 V(K) = (G∪̇M, G∪̇M, I∪(≠\(G×M)))，其中对象集和属性集都是 G∪̇M，incidence 关系是：G 中的元素作为对象时，和 G 中除自己外的所有元素关联，且和 M 中在原背景中关联的属性关联；M 中的元素作为对象时，和 G∪M 中除自己外的所有元素关联。inf 和 sup 的计算很简单：inf(A_t,B_t) = (∩A_t, ∪B_t)，sup(A_t,B_t) = (∪A_t, ∩B_t)。Thm 68 给出了完全刻画：前概念格恰好是"所有原子的 sup ≥ 所有余原子的 inf"的完备分配格。
- **为什么需要它**：它把前概念从"松散的满矩形集合"变成了一个有结构的格——可以用 Next Closure 等已有算法生成。同构于概念格意味着前概念格继承了概念格的全部算法工具。但要注意：概念格只是前概念格中的极大元素，不是子格——前概念格中两个形式概念的 meet/join 不一定是形式概念。这个"不是子格"的性质是引入 P14（前概念代数）的动机——需要不同的运算才能让形式概念在代数中闭合。
- **关键关系**：依赖 P10 前概念 + ch0 完备分配格；同构于特定背景的概念格（连接 ch1 概念格）；Thm 68 的刻画条件连接 ch0 的原子/余原子；概念格嵌入但不是子格——这引出 P14
- **崩塌条件**：前概念格的数量通常远大于概念格（47 vs 10 在小例子中），实际计算开销大。概念格不是子格——形式概念在前概念格中的 meet/join 可能不是形式概念，所以前概念格不能直接替代概念格做概念运算
- **书内定位**：Prop 145, 行 289-343；Thm 68, 行 388-389

**P14 前概念代数 (Preconcept algebra)**
- **是什么**：前概念代数 V(K) 是所有前概念上定义的代数结构 (V(K); ⊓, ⊔, ¬, ⌐, ⊥, ⊤)，运算定义为：meet (A₁,B₁)⊓(A₂,B₂) = (A₁∩A₂, (A₁∩A₂)')，join (A₁,B₁)⊔(A₂,B₂) = ((B₁∩B₂)', B₁∩B₂)，否定 ¬(A,B) = (G\A, (G\A)')，对立 ⌐(A,B) = ((M\B)', M\B)，⊥ = (∅, M)，⊤ = (G, ∅)。每个运算的结果都是半概念——所以半概念形成子代数。对于形式概念，meet 和 join 与概念格运算一致。但对一般前概念，这些运算不幂等、双重否定不等于恒等——不满足通常的布尔代数性质。
- **为什么需要它**：前概念格（P13）虽然是一个格，但概念格不是它的子格——形式概念在前概念格中的 meet/join 可能跑出形式概念的范围。前概念代数换了一组运算：meet 的结果取 (A₁∩A₂)' 作为属性侧（强制闭合），join 的结果取 (B₁∩B₂)' 作为对象侧。这组运算保证了：对形式概念做运算的结果仍是形式概念（形式概念在这组运算下闭合）。同时，否定和对立运算给出了前概念层面的"否定"和"对立"——这是 FCA 处理概念否定的第一步（后面 P16 在概念层面做第二步）。
- **关键关系**：依赖 P10-P12 前概念层级；运算结果落在 P12 半概念中（半概念 = 子代数）；对形式概念退化为概念格运算；否定/对立是 P16 弱否定/弱对立的前身（P16 = 先做否定/对立再闭合到形式概念）
- **崩塌条件**：运算不幂等、双重否定≠恒等——不是布尔代数，甚至不是格（meet/join 不幂等就不是格运算）。这些"坏性质"是本质的，不是可以通过限制消除的——它们反映了"部分概念"做运算后结果可能更"部分"
- **书内定位**：Def 112, 行 397-416

**P15 双布尔代数 (Double Boolean algebra)**
- **是什么**：双布尔代数是满足"在所有原概念代数中成立的等式"的泛代数 (D; ⊓, ⊔, ¬, ⌐, ⊥, ⊤)。半概念代数 H(K) 是一个"纯"双布尔代数——因为 H(K) 分裂为 H_u(K) 和 H_t(K) 两个布尔格，覆盖所有元素。Thm 69 表明：在任何双布尔代数中，D_u = {x | x⊓x=x} 在适当定义的运算下形成布尔代数，D_t = {x | x⊔x=x} 也形成布尔代数。纯双布尔代数要求每个元素满足 x⊓x=x 或 x⊔x=x（即属于 u-部或 t-部）。
- **为什么需要它**：半概念代数的运算不幂等，所以它不是布尔代数。但它也不是完全无结构——它分裂为两个布尔格（u-部和 t-部），各自有完整的布尔代数结构。双布尔代数捕捉了这个"两个布尔代数粘在一起"的结构。它是 FCA 为概念否定找到的代数框架：否定落在 u-部，对立落在 t-部，两个布尔格的交集是形式概念。这个结构比布尔代数弱（不幂等），但比"无结构"强得多——它有丰富的等式理论。
- **关键关系**：是 P12 半概念代数的抽象化；D_u 和 D_t 各自是布尔代数（连接 ch0 布尔代数）；交集 = 形式概念；比布尔代数弱（不幂等），比原概念代数强（有等式刻画）；Vormbrock & Wille 给了 Basic Theorem 刻画原概念和半概念代数
- **崩塌条件**：不是每个双布尔代数都同构于某个原概念代数——双布尔代数比原概念代数更一般。从双布尔代数到原概念代数需要额外的完备性条件（Basic Theorem）。另外，不幂等性意味着不能直接用布尔代数的推理工具
- **书内定位**：Def 113, 行 453-460；Thm 69, 行 463-483

**P16 弱否定与弱对立 (Weak negation and weak opposition)**
- **是什么**：对形式概念 (A, B)，弱否定定义为 (A,B)^△ = ((G\A)'', (G\A)')，弱对立定义为 (A,B)^▽ = ((M\B)', (M\B)'')。直觉上：弱否定是"取补集再闭合到形式概念"——先取对象补集 G\A，再做闭包（取导出再取导出的导出）得到形式概念。弱对立是属性侧的对应操作。这两个运算可以用前概念代数的运算表示：x^△ = (¬x)⊔(¬x)，x^▽ = (⌐x)⊓(⌐x)——即先做前概念层面的否定/对立（得到半概念），再做一次 join/meet 把半概念闭合到形式概念。
- **为什么需要它**：形式概念没有真假值，概念格通常没有补元——所以标准的布尔否定不适用于形式概念。但人类思维中确实有"否定"和"对立"的概念。Wille 的方案分两步：(1) 在前概念层面定义否定和对立（P14），结果得到半概念；(2) 把半概念闭合到形式概念——这就是弱否定和弱对立。之所以叫"弱"，是因为它们不满足布尔否定的全部性质：双重弱否定不恢复原概念（x^△△ ≤ x，不是 x^△△ = x），弱否定和弱对立也不一定相等。但它们满足一组弱化的性质（Prop 146, 147），足以捕捉"概念否定"的核心直觉。
- **关键关系**：依赖 P14 前概念代数（¬x 和 ⌐x）+ P12 半概念（中间结果）；是 P17 概念代数的核心运算；P18 双补格和 P19 弱双补格的运算就是 △ 和 ▽；x^△△ 是内部算子，x^▽▽ 是闭包算子（Prop 147）
- **崩塌条件**：弱否定不满足双重否定律（x^△△ ≤ x 而非 = x），不满足排中律（x∨x^△ = 1 成立但 x∧x^△ = 0 不一定成立——实际上 Prop 147 给的是 x∨x^△=1 和 x∧x^▽=0）。当 △ = ▽ 且满足 x^△=1⟹x=0 时，退化为布尔代数（Thm 70）——这就是"崩塌到布尔"的边界
- **书内定位**：Def 114, 行 498-520

**P17 概念代数 (Concept algebra)**
- **是什么**：形式背景 K 的概念代数 A(K) = (B(K); ∧, ∨, △, ▽, 0, 1)，其中 B(K) 是概念格，∧ 和 ∨ 是概念格运算，△ 和 ▽ 是弱否定和弱对立（P16），0 和 1 是最小和最大概念。概念代数是概念格加上两个补运算——它把概念格从纯序结构升级为带否定/对立的代数结构。
- **为什么需要它**：概念格本身只有序结构（子概念-超概念关系），没有否定运算。但 FCA 的目标是支持人类思维——而人类思维中否定和对立是基本操作。概念代数把这两个操作加进了概念格，使得 FCA 不只能提取概念结构，还能在概念结构上做逻辑推理（带否定的推理）。概念代数是布尔代数的推广：在布尔代数中，补运算满足双重否定律和排中律；在概念代数中，弱否定和弱对立只满足弱化版本——但概念格通常不是布尔格，所以这种弱化是必要的。
- **关键关系**：依赖 P16 弱否定/弱对立 + ch1 概念格；是 P18 双补格的实例（双补格 = 满足概念代数全部等式的代数）；Thm 70 表明当 △=▽ 且满足条件时退化为布尔代数——概念代数是布尔代数的真推广
- **崩塌条件**：概念代数的代数理论尚未完全理解——是否存在等式刻画（P18 的问题）、哪些双补格同构于概念代数（P19 的问题），都是开放问题。完备性是必要条件但不充分（Kwuida & Machida 反例）
- **书内定位**：Def 114, 行 513-520

**P18 双补格 (Dicomplemented lattice)**
- **是什么**：双补格是一个有界格加上两个一元运算，满足"在所有概念代数中成立的全部等式和准等式"（Def 115）。它是概念代数的代数抽象——就像"格"是"概念格"的代数抽象一样。概念代数是双补格的实例，但不是每个双补格都同构于某个概念代数（完备性是必要条件但不充分）。
- **为什么需要它**：概念代数依赖于具体形式背景，而泛代数的研究需要脱离具体背景、只看代数结构。双补格就是"脱掉背景外衣的概念代数"——它只保留代数运算和它们满足的等式。有了它，才能用泛代数的方法研究概念否定的结构：问"双补格的等式基是什么"、"哪些双补格同构于概念代数"。这些问题的答案会告诉我们概念否定的本质结构是什么。但书中明确说这个理论"not yet fully understood"——双补格是否能用纯等式定义（而非准等式）是开放问题。
- **关键关系**：是 P17 概念代数的代数抽象；P19 弱双补格是它的候选等式刻画；Thm 71 给出部分结果：直积、完备子代数、双奠基同态像都是概念代数；Thm 72：有限分配弱双补格都是概念代数
- **崩塌条件**：概念代数不能形成等式类（完备性不能用等式表达），所以双补格用"等式+准等式"定义而非纯等式。是否能纯等式定义 = 开放问题。不是每个双补格都同构于概念代数
- **书内定位**：Def 115, 行 532-534

**P19 弱双补格 (Weakly dicomplemented lattice)**
- **是什么**：弱双补格是有界格加上两个一元运算 △ 和 ▽，满足 Prop 146 的六条条件：(1) x^△△ ≤ x，(1') x^▽▽ ≥ x，(2) x≤y⟹x^△≥y^△，(2') x≤y⟹x^▽≥y^▽，(3) (x∧y)∨(x∧y^△)=x，(3') (x∨y)∧(x∨y^▽)=x。这六条都是等式可表达的。弱双补格是双补格的"候选"——它用明确的等式定义，而双补格用"所有概念代数中成立的等式"隐式定义。是否每个弱双补格都是双补格 = 开放问题。
- **为什么需要它**：双补格的定义是隐式的（"满足所有概念代数的等式"），不好操作。弱双补格给出了显式的六条等式，可以直接验证。如果弱双补格 = 双补格（即这六条等式就是完整的等式基），那么概念否定的代数理论就有了简洁的等式刻画。Prop 147 从这六条推导出更多等式（如 x∨x^△=1, x∧x^▽=0, x^△△ 是内部算子, x^▽▽ 是闭包算子），说明这六条已经蕴含了丰富的结构。
- **关键关系**：是 P18 双补格的显式候选；六条条件来自 Prop 146（概念代数的性质）；Prop 147 从这六条推导出更多等式；Thm 72：有限分配弱双补格都是概念代数——这是"弱双补格 = 双补格"的部分验证
- **崩塌条件**：弱双补格 = 双补格 尚未证明——存在"弱双补格不是双补格"的可能性。一个格可以有多个弱双补结构（Kwuida 证明 2×n 格有 n² 个），所以弱双补结构不唯一
- **书内定位**：Def 116, 行 571-573；Prop 146, 行 548-562；Prop 147, 行 581-636

**P20 关系形式背景 (Relational formal context)**
- **是什么**：关系形式背景是一个形式背景 (G, M, I) 加上 G 上的一组关系 R——即 R 是 G×G 的子集的集合（每个关系是 G 上的二元关系）。这把形式背景从"对象-属性"的静态结构扩展为"对象-属性-对象间关系"的结构。关系可以是任意元（k-ary），但实践中二元关系最常用。
- **为什么需要它**：经典 FCA 的形式背景只有对象和属性——它描述"什么对象有什么属性"，但不能描述"对象之间的关系"。现实中很多知识是关系性的："这个状态之后是哪个状态"、"这个零件是哪个零件的一部分"、"这个人认识那个人"。没有关系，FCA 只能做静态的概念分析，不能处理过程、层次、网络等关系性知识。关系形式背景把关系引入 FCA，为 P22（术语属性）提供了载体，使得 FCA 能表达"所有邻居都是..."、"存在一个邻居是..."这类关系性判断。
- **关键关系**：是 P21 角色 + P22 术语属性的基础载体；连接 Description Logics（DL）的知识表示框架；与 ch1 的形式背景是推广关系（加了关系集 R）
- **崩塌条件**：书中承认定义"remains somewhat vague"——没有指定关系背景的具体记号表示，因为文献中有不同记法。这种模糊性是故意的（兼容不同学派），但意味着不同实现可能不兼容。另外，加入关系后表达力大增但复杂度也大增——P23 角色深度和 P24 描述逻辑族就是为了控制这个复杂度
- **书内定位**：Def 117, 行 777

**P21 角色 (Role)**
- **是什么**：角色就是对象集 G 上的二元关系——G×G 的一个子集。一个角色 R 确定了哪些对象对 (g, h) 有 R 关系。"角色"这个名字来自 Description Logics 的术语传统。
- **为什么需要它**：在关系形式背景中，"二元关系"是使用最频繁的关系类型，给它一个专门的名字"角色"便于讨论。角色是术语属性（P22）的量化对象——∀R.m 和 ∃R.m 中的 R 就是角色。用"角色"而非"二元关系"的说法，建立了 FCA 和 Description Logics 之间的术语桥梁，使得 DL 的算法和结果可以移植到 FCA 中。
- **关键关系**：是 P20 关系形式背景的组成部分；是 P22 术语属性的量化对象；名字来自 Description Logics，是 FCA-DL 桥梁的术语
- **崩塌条件**：只覆盖二元关系——k-ary 关系（k≠2）不是角色，需要更一般的处理（如 power context families，书中在 Notes 节提到但未展开）
- **书内定位**：行 780-782

**P22 术语属性 ∀R.m 和 ∃R.B (Terminological attributes)**
- **是什么**：给定角色 R 和属性 m，∀R.m 是一个复合属性，其外延是"所有 R-后继都拥有 m 的对象"：{g ∈ G | ∀h (g,h)∈R ⟹ hIm}。∃R.B 是"存在一个 R-后继拥有 B 中所有属性的对象"：{g ∈ G | ∃h (g,h)∈R ∧ h∈B'}。当 B={m} 时简写为 ∃R.m。这些属性可以递归嵌套——∀R₂.(∃R₁.m) 是合法的，意思是"所有 R₂-后继都存在一个 R₁-后继拥有 m"。递归嵌套可以生成无穷多个术语属性。
- **为什么需要它**：经典 FCA 的复合属性（P1）只能做逻辑组合（¬, ∧, ∨），不能跨越对象间的关系。术语属性把关系量化引入了属性语言：∀R.m 说"沿着关系 R 走，所有目的地都满足 m"，∃R.m 说"沿着 R 走，至少一个目的地满足 m"。书中的例子：披萨是素食的 ⟺ ∀has-topping.vegetarian；披萨是非素食的 ⟺ ∃has-topping.non-vegetarian。这让 FCA 能表达关系性知识——这是经典 FCA 做不到的。术语属性来自 Description Logics，是 FCA 和 DL 的核心接口。
- **关键关系**：依赖 P20 关系形式背景 + P21 角色；递归嵌套引出 P23 角色深度（控制复杂度）；是 P24 描述逻辑族的表达构件；∀R.m 对应 DL 的全称量化，∃R.m 对应存在量化
- **崩塌条件**：递归嵌套可以生成无穷多术语属性——即使属性集 M 有限，也可能有无穷多不同的外延（当对象集无限时）。即使对象集有限，外延有限但属性数量可能爆炸。没有像 P3 测试背景那样的"万能测试背景"来判断两个术语属性是否全局等价——书中明确说"we have no test context for terminological attributes"（行 872-873）
- **书内定位**：Def 118, 行 788-813

**P23 角色深度 (Role depth)**
- **是什么**：角色深度衡量一个术语属性中角色量化的嵌套层数。原始属性（不含量词符号）的角色深度为 0。布尔组合的角色深度 = 各分量角色深度的 sup。∃R.m 和 ∀R.m 的角色深度 = m 的角色深度 + 1。限制角色深度就限制了术语属性的复杂度。
- **为什么需要它**：术语属性可以无限嵌套（P22），生成无穷多属性。但属性探索（attribute exploration）需要有限步终止——如果属性无穷多，探索可能永远跑不完。限制角色深度把无穷截断为有限：深度 ≤ d 的术语属性只有有限多个（当 M 和 R 有限时）。Rudolph 证明了对于有界角色深度的 FLE 属性，属性探索可以有限步终止。这是把 FCA 的属性探索算法扩展到关系背景的关键技术条件。
- **关键关系**：依赖 P22 术语属性；是 P24 FLE 属性的定义参数（FLE = 有界角色深度的 ∀+∃）；保证属性探索的可终止性（Rudolph 的结果）；Distel 的工作用 EL（不限制角色深度但只用 ∃）实现可终止性——两种路线
- **崩塌条件**：限制角色深度会丢失表达力——深度 d 截断后，深度 >d 的属性无法表达。不限制角色深度时，可终止性不保证（除非用更弱的逻辑如 EL）
- **书内定位**：Def 119, 行 832-840

**P24 描述逻辑族 ALC, EL, FLE (Description logics ALC, EL, FLE)**
- **是什么**：描述逻辑（Description Logics, DL）是一族限制表达力以换取可计算性的逻辑。Def 120 定义了三种从关系形式背景生成的属性族：ALC 属性 = 加 ⊤和⊥ + 递归使用否定、有限合取/析取、∃R.m 和 ∀R.m；EL 属性 = 加 ⊤ + 递归使用有限合取和 ∃R.m（没有否定、没有 ∀）；FLE 属性 = 加 ⊤ + 递归使用有限合取和 ∃R.m, ∀R.m（没有否定、没有析取）。表达力：ALC > FLE > EL。复杂度也随之递增。
- **为什么需要它**：术语属性（P22）可以无限嵌套，需要选择"用多少表达力"。描述逻辑族给出了菜单：ALC 最强但最复杂，EL 最弱但最可计算，FLE 居中。每种逻辑都有成熟的推理算法（reasoner）——FCA 可以直接借用。这是 FCA 和 DL 的实质性接口：FCA 提供概念分析框架，DL 提供关系推理算法。Rudolph 证明 FLE + 有界角色深度的属性探索可终止；Distel 证明 EL + 无界角色深度的属性探索可终止——两条路线分别用不同 DL 实现了 FCA 的关系扩展。
- **关键关系**：依赖 P22 术语属性 + P23 角色深度；ALC 是最完整的（包含否定和 ∀+∃），EL 是最弱的（只有 ∃+合取），FLE 居中（∀+∃+合取，无否定无析取）；连接 Description Logics 的推理算法（SAT-solver, reasoner）；是 OWL（Web Ontology Language）的基础
- **崩塌条件**：表达力递增导致复杂度递增——ALC 的可满足性问题是 PSPACE-complete，更强的逻辑很快达到不可判定（undecidable）。EL 虽然可计算但表达力弱（没有否定和 ∀，不能表达"所有邻居都是..."）。FLE 是实用折中但仍有局限性。FCA 目前没有术语属性的"测试背景"（行 872），所以全局等价判定需要借助 DL 的 reasoner 而非 FCA 自身的工具
- **书内定位**：Def 120, 行 848-857
