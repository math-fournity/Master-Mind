## 题目

找出所有正整数三元组 (a,b,c)，使得 ab−c、bc−a、ca−b 全为 2 的幂（允许 2⁰=1）。

## 约定与记号

- "2 的幂"指形如 2^k 的数，k 为非负整数。2 的幂中唯一的奇数是 1 = 2⁰。
- 记 ab − c = 2ˣ, bc − a = 2ʸ, ca − b = 2ᶻ，其中 x, y, z ≥ 0。
- v₂(n) 表示 n 的 2-adic 赋值（n 中因子 2 的个数）。

## 第 0 步：WLOG 与坐标下界

三个表达式构成的集合 {ab−c, bc−a, ca−b} 在 (a,b,c) 的任何置换下不变（例如交换 a,b：ab−c 不动，bc−a 与 ca−b 互换）。因此不妨设 **a ≤ b ≤ c**。

**断言 0.1：a, b, c ≥ 2。**
若 a = 1，则 ab−c = b−c 与 ca−b = c−b 都必须是 2 的幂，即都为正；但两者互为相反数，不可能同时为正。故坐标全 ≥ 2。∎

## 第 1 步：排序引理

**引理 1.1**：x ≤ z ≤ y；且 2ˣ=2ᶻ ⟺ c=b，2ᶻ=2ʸ ⟺ a=b，2ˣ=2ʸ ⟺ c=a。

证明：逐对作差：
- 2ᶻ − 2ˣ = (ca−b) − (ab−c) = (c−b)(a+1) ≥ 0；
- 2ʸ − 2ᶻ = (bc−a) − (ca−b) = (b−a)(c+1) ≥ 0；
- 2ʸ − 2ˣ = (bc−a) − (ab−c) = (c−a)(b+1) ≥ 0。

由于指数非负且底相同，等值当且仅当差为零，而上式各因子为正，故分别等价于 c=b、a=b、c=a。∎

由此，问题分为两大类：

- **类 I**：某两个坐标相等；
- **类 II**：三坐标两两异，此时 a < b < c 且 **x < z < y 严格成立**。

以下三条差恒等式反复使用（直接展开可验）：

- (I) (b−a)(c+1) = 2ʸ − 2ᶻ
- (II) (c−b)(a+1) = 2ᶻ − 2ˣ
- (III) (c−a)(b+1) = 2ʸ − 2ˣ

## 第 2 步：类 I——两坐标相等，只有 (2,2,2) 与 (2,2,3)

由对称性设 a = b。则 bc − a = ac − a = a(c−1) 且 ca − b = a(c−1)，于是 a(c−1) = 2ʸ，故存在 u,v ≥ 0 使 **a = 2ᵘ, c − 1 = 2ᵛ**（u ≥ 1，因 a ≥ 2）。代入第一式：

2ˣ = ab − c = 2²ᵘ − 2ᵛ − 1。

**情形 v ≥ 1**：左边 2²ᵘ − 2ᵛ − 1 为奇数，故 2ˣ = 1，即 2²ᵘ − 2ᵛ = 2。若 v > 2u 则左边为负；v ≤ 2u 时左端可分解为 2ᵛ(2^{2u−v} − 1) = 2。内括号是奇的非负整数（取零时左边为零，舍去），故必 v = 1 且 2^{2u−v} − 1 = 1，得 2u − v = 1，于是 u = 1。此时 a = 2, c = 3，即 **(2,2,3)**。验证：4−3=1，6−2=4，6−2=4，均为 2 的幂 ✓。

**情形 v = 0**：c = 2。此时 2ˣ = 2^{2u} − 2 = 2(2^{2u−1} − 1)，内括号为正奇数，故它必须是 1，得 u = 1，即 **(2,2,2)**。验证：各式均为 2 ✓。

所以两坐标相等的解恰为 (2,2,2) 及 (2,2,3) 的全部置换。∎

## 第 3 步：类 II 预备——奇偶性 dispatch

设 a < b < c，则 x < z < y 严格。每个指数为 0 当且仅当对应表达式为奇数。按 (a,b,c) 的奇偶模式逐一计算三式的奇偶（偶记 E、奇记 O；"偶"表示对应指数 ≥ 1，"奇"表示对应指数 = 0）：

| 模式 (a,b,c) | ab−c | bc−a | ca−b | 结论 |
|---|---|---|---|---|
| (E,E,E) | 偶 | 偶 | 偶 | 存活 → 第 5 步 |
| (E,E,O) | **奇（x=0）** | 偶 | 偶 | 存活 → 第 4 步 |
| (E,O,E) | 偶 | 偶 | **奇（z=0）** | 死：z=0 违反 x<z |
| (E,O,O) | 奇（x=0） | 奇（y=0） | 奇（z=0） | 死：违反 x<z |
| (O,E,E) | 偶 | **奇（y=0）** | 偶 | 死：y=0 违反 z<y |
| (O,E,O) | 奇（x=0） | 奇（y=0） | 奇（z=0） | 死：违反 x<z |
| (O,O,E) | 奇（x=0） | 奇（y=0） | 奇（z=0） | 死：违反 x<y |
| (O,O,O) | 偶 | 偶 | 偶 | 存活 → 第 6 步 |

（逐行验算示例：(E,O,E) 中 ca−b = 偶·偶 − 奇 = 奇；(O,E,O) 中三式分别为 偶·奇−奇、偶·奇−奇、奇·奇−偶，全为奇。其余同理。）

五个模式被纯奇偶性秒杀。幸存者：(E,E,E)、(E,E,O)、(O,O,O)。

## 第 4 步：(E,E,O) 定理——唯一解 (2,6,11)

设 a < b < c，a,b 偶，c 奇。此时 x = 0，即 **ab − c = 1，c = ab − 1**。（理由：恒等式 (II) 取 v₂，左边 v₂(2ᶻ−2ˣ) = x（因 z>x，2^{z−x}−1 为奇）；右边 = v₂(c−b) + v₂(a+1)；c 奇 b 偶 ⟹ c−b 奇，a 偶 ⟹ a+1 奇，故 x = 0。）

代回另两式：

- 2ᶻ = ca − b = a²b − a − b，
- 2ʸ = bc − a = ab² − b − a。

### 第 4.1 步：v₂(a) = v₂(b)

记 p := v₂(a), q := v₂(b)（均 ≥ 1）。

**和**：2ʸ + 2ᶻ = a²b + ab² − 2a − 2b = (a+b)(ab − 2)。左边 = 2ᶻ(2^{y−z} + 1)，括号为奇，故 v₂(左边) = z。右边中 ab ≡ 0 (mod 4) ⟹ ab − 2 ≡ 2 (mod 4)，v₂(ab−2) = 1。于是

　　z = v₂(a+b) + 1.　　(*)

**差**：由恒等式 (I) 及 c + 1 = ab：2ʸ − 2ᶻ = (b−a)·ab，其 v₂ = z。而 v₂((b−a)ab) = p + q + v₂(b−a)。于是

　　z = p + q + v₂(b−a).　　(**)

若 p < q：写 a = 2ᵖα, b = 2^q β（α,β 奇），则 b − a = 2ᵖ(2^{q−p}β − α)，括号为 偶−奇 = 奇，v₂(b−a) = p；a + b = 2ᵖ(α + 2^{q−p}β)，括号为 奇+偶 = 奇，v₂(a+b) = p。(**) 与 (*) 联立给 p + q + p = p + 1，即 p + q = 1，与 p,q ≥ 1 矛盾。p > q 情形对称地导出 q + p = 1，同矛盾。故 **p = q**。∎

### 第 4.2 步：参数化与精确方程

写 a = 2ᵖα, b = 2ᵖβ，α < β 均奇。由 (*)：z = p + v₂(α+β) + 1。记 v := v₂(α+β)。另一方面直接展开：

2ᶻ = b(a² − 1) − a = 2ᵖ[2^{2p}α²β − (α + β)].

对 N := 2^{2p}α²β − (α+β) 按 v 分情况：

- **v < 2p**：N = 2ᵛ(2^{2p−v}α²β − γ')，γ' = (α+β)/2ᵛ 为奇；括号为 偶−奇 = 奇 ⟹ v₂(N) = v ⟹ z = p + v ≠ p + v + 1，矛盾。
- **v > 2p**：N = 2^{2p}(α²β − 2^{v−2p}γ')，括号为 奇−偶 = 奇 ⟹ z = 3p；但 (*) 给 z = p + v + 1 ≥ 3p + 2 > 3p，矛盾。
- 故 **v = 2p**：α + β = 2^{2p}γ（γ 奇），且 z = 3p + 1，同时 2ᶻ = 2^{3p}(α²β − γ)。

由于 2ᶻ 是纯 2 的幂，α²β − γ 必须是 2 的幂，且其 v₂ 为 z − 3p = 1，于是恰好

　　**(★) α²β − γ = 2。**

同理用 2ʸ = a(b²−1) − b = 2^{3p}(αβ² − γ) 得

　　**(★★) αβ² − γ = 2^{y−3p}。**

（机器抽查：解 (2,6,11) 对应 α=1, β=3, p=1, γ=1：α²β−γ = 2 ✓，αβ²−γ = 8 = 2³ ✓。穷举 α,β < 2000、p < 8 内方程组 (★)(★★) 无其它解。）

### 第 4.3 步：尺寸论证收口

由 (★)：β = (γ+2)/α²。
- α < β ⟹ α³ < α²β = γ + 2 ⟹ **α³ ≤ γ + 1**（整除性取整）。
- α + β = 4ᵖγ ≥ 4γ（p ≥ 1），而 β = (γ+2)/α² ≤ γ + 2（因 α² ≥ 1），故 **α ≥ 4γ − (γ+2) = 3γ − 2**。

若 γ ≥ 3：则 (3γ−2)³ ≤ α³ ≤ γ+1，但 g(γ) := (3γ−2)³ − (γ+1) 在 γ ≥ 3 上递增且 g(3) = 343 − 4 > 0，矛盾。

故 **γ = 1**。此时 α²β = 3 且 α < β 均奇：α² 整除 3 强制 α = 1，β = 3；再由 α + β = 4 = 4ᵖ 得 p = 1。

于是 a = 2¹·1 = 2, b = 2¹·3 = 6, c = ab − 1 = 11。验证：12−11=1=2⁰，66−2=64=2⁶，22−6=16=2⁴ ✓。

**(E,E,O) 既约解唯一：(2,6,11)。** ∎

## 第 5 步：c 偶引理——杀死 (E,E,E)

**引理 5.1**：在两两异的情形，c 必为奇数。

证明：设 c 偶。对恒等式 (I) 取 v₂：左边 = v₂(b−a) + v₂(c+1) = v₂(b−a) + 0（c 偶 ⟹ c+1 奇）；右边 = v₂(2ʸ − 2ᶻ) = z（因 y > z，2ʸ − 2ᶻ = 2ᶻ(2^{y−z} − 1)，括号为奇）。故 v₂(b−a) = z，即 2ᶻ 整除 b − a；又 b > a ⟹ b − a ≥ 1，从而 **b − a ≥ 2ᶻ**。

另一方面断言 2ᶻ = ca − b > b − a：这等价于 a(c+1) > 2b。若 a ≥ 3，则 a(c+1) ≥ 3(b+1) > 2b；若 a = 2，则 2(c+1) > 2b ⟺ c ≥ b，而实际 c > b，成立。

合并得 2ᶻ = ca − b > b − a ≥ 2ᶻ，矛盾。∎

此引理独立杀掉全部 c 偶模式；在幸存者中它杀死 **(E,E,E)**。

## 第 6 步：(O,O,O) 定理——唯一解 (3,5,7)

设 a < b < c 全奇。则 a ≥ 3，b ≤ c − 2，x < z < y，三指数均 ≥ 1。

**代入恒等式**：由 c = ab − 2ˣ 代入 ca − b = 2ᶻ：

　　ca − b = a(ab − 2ˣ) − b = b(a² − 1) − 2ˣa = 2ᶻ ⟹ b(a²−1) = 2ᶻ + 2ˣa = 2ˣ(2^{z−x} + a).

括号 2^{z−x} + a 为 偶+奇 = 奇，b 为奇，故 **x = v₂(a² − 1)**。

对称地，由 b = ca − 2ᶻ 代入 bc − a = 2ʸ：

　　bc − a = c(ca − 2ᶻ) − a = a(c² − 1) − 2ᶻc = 2ʸ ⟹ a(c²−1) = 2ʸ + 2ᶻc = 2ᶻ(2^{y−z} + c).

括号为奇，a 为奇，故 **z = v₂(c² − 1)**。

**上界**：c 奇 ⟹ c² − 1 = (c−1)(c+1)，两因子 gcd = 2，其一 ≡ 2 (mod 4) 其一 ≡ 0 (mod 4)，故 min(v₂(c−1), v₂(c+1)) = 1，max = z − 1。携带赋值 z−1 的因子不超过 c + 1，且被 2^{z−1} 整除，故

　　**2^{z−1} ≤ c + 1，即 2ᶻ ≤ 2c + 2。**

**下界**：2ᶻ = ca − b ≥ 3c − (c − 2) = **2c + 2**（用 a ≥ 3 与 b ≤ c − 2；两个不等式必须同时取等才能使最终等式成立，因为两端已夹逼相等）。

夹逼迫使处处取等：

　　**2ᶻ = 2c + 2，a = 3，b = c − 2，且 c + 1 = 2^{z−1}。**

最后由 x = v₂(a² − 1) = v₂(8) = 3 得 ab − c = 8。代入 a = 3, b = c − 2：

　　3(c − 2) − c = 2c − 6 = 8 ⟹ **c = 7, b = 5**。

验证 (3,5,7)：15 − 7 = 8 = 2³，35 − 3 = 32 = 2⁵，21 − 5 = 16 = 2⁴ ✓（且 x=3 < z=4 < y=5 与严格序一致）。

**(O,O,O) 既约解唯一：(3,5,7)。** ∎

## 第 7 步：汇总

全部情形已穷尽：

1. 两坐标相等 ⟹ (2,2,2) 或 (2,2,3)（第 2 步）；
2. 三坐标两两异时，五个奇偶模式被奇偶性秒杀（第 3 步），(E,E,E) 被 c 偶引理杀死（第 5 步），(E,E,O) 唯一解 (2,6,11)（第 4 步），(O,O,O) 唯一解 (3,5,7)（第 6 步）。

既约（按 a≤b≤c）解集为 {(2,2,2), (2,2,3), (2,6,11), (3,5,7)}，连同各自全部置换，共 1 + 3 + 6 + 6 = 16 个有序三元组。
