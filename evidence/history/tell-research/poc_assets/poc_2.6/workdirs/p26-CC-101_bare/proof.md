# CC-101 / polymath_00146 解答

## 题目

求最小正整数 $n$，使得可以用 $n$ 种颜色给每个正整数着色，且方程
$$w + 6x = 2y + 3z$$
在正整数中没有同色解（$w, x, y, z$ 不必互异）。

## 答案

$$\boxed{4}$$

## 解答

### 第一步：方程不是分划正则的

方程 $w + 6x = 2y + 3z$ 即 $w + 6x - 2y - 3z = 0$，系数为 $\{1, 6, -2, -3\}$。

由 Rado 定理，线性方程是分划正则的当且仅当某个非空子集的系数之和为零。检查所有非空子集：

| 子集 | 和 |
|------|-----|
| $\{1\}$ | $1$ |
| $\{6\}$ | $6$ |
| $\{-2\}$ | $-2$ |
| $\{-3\}$ | $-3$ |
| $\{1, 6\}$ | $7$ |
| $\{1, -2\}$ | $-1$ |
| $\{1, -3\}$ | $-2$ |
| $\{6, -2\}$ | $4$ |
| $\{6, -3\}$ | $3$ |
| $\{-2, -3\}$ | $-5$ |
| $\{1, 6, -2\}$ | $5$ |
| $\{1, 6, -3\}$ | $4$ |
| $\{1, -2, -3\}$ | $-4$ |
| $\{6, -2, -3\}$ | $1$ |
| $\{1, 6, -2, -3\}$ | $2$ |

没有子集的和为零，故方程不是分划正则的。因此存在有限色数的正常着色。下面证明最小色数为 $4$。

### 第二步：2-正则性（任意 2-着色都有同色解）

**断言**：对任意 2-着色 $c: \mathbb{Z}^+ \to \{A, B\}$，都存在同色解。

**证明**：考虑以下三个解：

1. $(w, x, y, z) = (1, 1, 2, 1)$：$1 + 6 = 7 = 4 + 3$ ✓
   - 若 $c(1) = c(2)$，则 $c(w) = c(x) = c(y) = c(z) = c(1)$，同色解。故 $c(1) \neq c(2)$。

2. $(w, x, y, z) = (3, 1, 3, 1)$：$3 + 6 = 9 = 6 + 3$ ✓
   - 若 $c(1) = c(3)$，同色解。故 $c(1) \neq c(3)$。

3. $(w, x, y, z) = (3, 2, 3, 3)$：$3 + 12 = 15 = 6 + 9$ ✓
   - 若 $c(2) = c(3)$，同色解。故 $c(2) \neq c(3)$。

因此 $c(1), c(2), c(3)$ 两两不同，需要至少 3 种颜色。2 种颜色不可能。$\square$

### 第三步：3-正则性（任意 3-着色都有同色解）

**断言**：对任意 3-着色 $c: \mathbb{Z}^+ \to \{A, B, C\}$，都存在同色解。

**证明**：由第二步的论证，$c(1), c(2), c(3)$ 两两不同。不妨设 $c(1) = A$，$c(2) = B$，$c(3) = C$。

**初始约束**：以下解中三个变量已同色，迫使第四个变量不同色：

- $(2, 2, 4, 2)$：$2 + 12 = 14 = 8 + 6$ ✓。$c(2) = c(2) = c(2) = B$，故 $c(4) \neq B$。
- $(3, 3, 3, 5)$：$3 + 18 = 21 = 6 + 15$ ✓。$c(3) = c(3) = c(3) = C$，故 $c(5) \neq C$。
- $(3, 3, 6, 3)$：$3 + 18 = 21 = 12 + 9$ ✓。$c(3) = c(3) = c(3) = C$，故 $c(6) \neq C$。

因此 $c(4) \in \{A, C\}$，$c(5) \in \{A, B\}$，$c(6) \in \{A, B\}$。

另外，$(6, 2, 6, 2)$：$6 + 12 = 18 = 12 + 6$ ✓。若 $c(6) = B$，则 $c(6) = c(2) = c(6) = c(2) = B$，同色解。故 **$c(6) \neq B$**，即 $c(6) = A$。

现在分两种情况讨论 $c(4)$。

---

**情况 1：$c(4) = A$**

由 $(5, 1, 4, 1)$：$5 + 6 = 11 = 8 + 3$ ✓。$c(1) = c(4) = c(1) = A$，故 $c(5) \neq A$，即 $c(5) = B$。

此时 $c(6) = A$，$c(4) = A$。由 $(6, 4, 6, 6)$：$6 + 24 = 30 = 12 + 18$ ✓。$c(6) = c(4) = c(6) = c(6) = A$，**同色解**。矛盾。

---

**情况 2：$c(4) = C$**

此时 $c(6) = A$（已确定），$c(5) \in \{A, B\}$。

**子情况 2a：$c(5) = A$**

此时 $c(1) = A, c(2) = B, c(3) = C, c(4) = C, c(5) = A, c(6) = A$。

逐步推导：

1. **$c(7) = B$**：
   - $(3, 4, 3, 7)$：$3 + 24 = 27 = 6 + 21$ ✓。$c(3) = c(4) = c(3) = C \Rightarrow c(7) \neq C$。
   - $(7, 1, 5, 1)$：$7 + 6 = 13 = 10 + 3$ ✓。$c(1) = c(5) = c(1) = A \Rightarrow c(7) \neq A$。
   - 故 $c(7) = B$。

2. **$c(9) = B$**：
   - $(3, 4, 9, 3)$：$3 + 24 = 27 = 18 + 9$ ✓。$c(3) = c(4) = c(3) = C \Rightarrow c(9) \neq C$。
   - $(9, 1, 6, 1)$：$9 + 6 = 15 = 12 + 3$ ✓。$c(1) = c(6) = c(1) = A \Rightarrow c(9) \neq A$。
   - 故 $c(9) = B$。

3. **$c(8) = B$**：
   - $(6, 5, 6, 8)$：$6 + 30 = 36 = 12 + 24$ ✓。$c(6) = c(5) = c(6) = A \Rightarrow c(8) \neq A$。
   - $(4, 4, 8, 4)$：$4 + 24 = 28 = 16 + 12$ ✓。$c(4) = c(4) = c(4) = C \Rightarrow c(8) \neq C$。
   - 故 $c(8) = B$。

4. **$c(10) = C$**：
   - $(2, 7, 7, 10)$：$2 + 42 = 44 = 14 + 30$ ✓。$c(2) = c(7) = c(7) = B \Rightarrow c(10) \neq B$。
   - $(6, 6, 6, 10)$：$6 + 36 = 42 = 12 + 30$ ✓。$c(6) = c(6) = c(6) = A \Rightarrow c(10) \neq A$。
   - 故 $c(10) = C$。

5. **$c(12) = C$**：
   - $(8, 7, 7, 12)$：$8 + 42 = 50 = 14 + 36$ ✓。$c(8) = c(7) = c(7) = B \Rightarrow c(12) \neq B$。
   - $(6, 6, 12, 6)$：$6 + 36 = 42 = 24 + 18$ ✓。$c(6) = c(6) = c(6) = A \Rightarrow c(12) \neq A$。
   - 故 $c(12) = C$。

6. **$c(11) = C$**：
   - $(7, 7, 8, 11)$：$7 + 42 = 49 = 16 + 33$ ✓。$c(7) = c(7) = c(8) = B \Rightarrow c(11) \neq B$。
   - $(1, 6, 11, 5)$：$1 + 36 = 37 = 22 + 15$ ✓。$c(1) = c(6) = c(5) = A \Rightarrow c(11) \neq A$。
   - 故 $c(11) = C$。

7. **矛盾**：$(8, 2, 7, 2)$：$8 + 12 = 20 = 14 + 6$ ✓。$c(8) = c(2) = c(7) = c(2) = B$，**同色解**。矛盾。

**子情况 2b：$c(5) = B$**

此时 $c(1) = A, c(2) = B, c(3) = C, c(4) = C, c(5) = B, c(6) = A$。

逐步推导：

1. **$c(7) = A$**：
   - $(3, 4, 3, 7)$：$c(3) = c(4) = c(3) = C \Rightarrow c(7) \neq C$。
   - $(7, 2, 2, 5)$：$7 + 12 = 19 = 4 + 15$ ✓。$c(2) = c(2) = c(5) = B \Rightarrow c(7) \neq B$。
   - 故 $c(7) = A$。

2. **$c(9) = B$**：
   - $(3, 4, 9, 3)$：$c(3) = c(4) = c(3) = C \Rightarrow c(9) \neq C$。
   - $(9, 1, 6, 1)$：$c(1) = c(6) = c(1) = A \Rightarrow c(9) \neq A$。
   - 故 $c(9) = B$。

3. **$c(10) = C$**：
   - $(6, 6, 6, 10)$：$c(6) = c(6) = c(6) = A \Rightarrow c(10) \neq A$。
   - $(5, 5, 10, 5)$：$5 + 30 = 35 = 20 + 15$ ✓。$c(5) = c(5) = c(5) = B \Rightarrow c(10) \neq B$。
   - 故 $c(10) = C$。

4. **$c(8) = B$**：
   - $(1, 6, 8, 7)$：$1 + 36 = 37 = 16 + 21$ ✓。$c(1) = c(6) = c(7) = A \Rightarrow c(8) \neq A$。
   - $(10, 3, 8, 4)$：$10 + 18 = 28 = 16 + 12$ ✓。$c(10) = c(3) = c(4) = C \Rightarrow c(8) \neq C$。
   - 故 $c(8) = B$。

5. **$c(12) = C$**：
   - $(6, 6, 12, 6)$：$c(6) = c(6) = c(6) = A \Rightarrow c(12) \neq A$。
   - $(9, 5, 12, 5)$：$9 + 30 = 39 = 24 + 15$ ✓。$c(9) = c(5) = c(5) = B \Rightarrow c(12) \neq B$。
   - 故 $c(12) = C$。

6. **$c(11) = B$**：
   - $(11, 3, 10, 3)$：$11 + 18 = 29 = 20 + 9$ ✓。$c(3) = c(10) = c(3) = C \Rightarrow c(11) \neq C$。
   - $(11, 1, 7, 1)$：$11 + 6 = 17 = 14 + 3$ ✓。$c(1) = c(7) = c(1) = A \Rightarrow c(11) \neq A$。
   - 故 $c(11) = B$。

7. **矛盾**：$(12, 4, 3, 10)$：$12 + 24 = 36 = 6 + 30$ ✓。$c(12) = c(4) = c(3) = c(10) = C$，**同色解**。矛盾。

---

所有情况均导致矛盾，故 3 种颜色不可能。$\square$

### 第四步：4-着色存在

**构造**：定义着色 $c: \mathbb{Z}^+ \to \{0, 1\} \times \{1, 2\}$ 为
$$c(n) = \bigl(v_3(n) \bmod 2,\; (n / 3^{v_3(n)}) \bmod 3\bigr),$$
其中 $v_3(n)$ 是 $n$ 的 3-adic 赋值（即 $n$ 中因子 3 的幂次）。由于 $n / 3^{v_3(n)}$ 不被 3 整除，第二分量取值为 1 或 2。共 $2 \times 2 = 4$ 种颜色。

**断言**：此着色下没有同色解。

**证明**：设 $(w, x, y, z)$ 为同色解，$w + 6x = 2y + 3z$。记 $v_w = v_3(w)$，$u_w = w / 3^{v_w}$，等。

同色意味着：
- $v_w \equiv v_x \equiv v_y \equiv v_z \pmod{2}$（奇偶性相同）
- $u_w \equiv u_x \equiv u_y \equiv u_z \equiv r \pmod{3}$，其中 $r \in \{1, 2\}$

令 $t = \min(v_w, v_x, v_y, v_z)$，令 $a = v_w - t$，$b = v_x - t$，$c = v_y - t$，$d = v_z - t$。则 $a, b, c, d \geq 0$，至少一个为 0，且由于 $v_w, v_x, v_y, v_z$ 奇偶性相同而 $t$ 也有相同奇偶性，故 $a, b, c, d$ 均为**偶数**。

方程两边除以 $3^t$ 得：
$$u_w \cdot 3^a + 6 u_x \cdot 3^b = 2 u_y \cdot 3^c + 3 u_z \cdot 3^d. \quad (\star)$$

**关键观察**：由于 $a, b, c, d$ 均为偶数，非零者 $\geq 2$，故 $3^a, 3^b, 3^c, 3^d$ 在非零时被 $9$ 整除（从而被 $3$ 整除）。

对 $(\star)$ 取模 $3$：

- 若某项的指数为 0，该项贡献 $u \cdot 1 \equiv r \pmod{3}$（或 $6u \equiv 0$，或 $2u \equiv 2r$，或 $3u \equiv 0$）。
- 若某项的指数 $\geq 2$，该项被 $9$ 整除，模 $3$ 为 $0$。

逐种检查 $a, b, c, d$ 中哪些为 0：

**情形 1：$a = b = c = d = 0$（所有赋值相等）**

$(\star)$ 变为 $u_w + 6u_x = 2u_y + 3u_z$。模 $3$：$r + 0 \equiv 2r + 0 \pmod{3}$，即 $r \equiv 2r$，故 $r \equiv 0 \pmod{3}$，与 $r \in \{1, 2\}$ 矛盾。

**情形 2：恰好一个为 0**

- $a = 0$（$b, c, d \geq 2$）：模 $3$：$r + 0 \equiv 0 + 0$，$r \equiv 0$，矛盾。
- $b = 0$（$a, c, d \geq 2$）：模 $3$：$0 + 0 \equiv 0 + 0$，无矛盾。模 $9$：$0 + 6r \equiv 0 + 0 \pmod{9}$，即 $6r \equiv 0 \pmod{9}$。但 $r \in \{1,2\}$ 时 $6r \in \{6, 12\}$，均不被 $9$ 整除，矛盾。
- $c = 0$（$a, b, d \geq 2$）：模 $3$：$0 + 0 \equiv 2r + 0$，$2r \equiv 0$，矛盾。
- $d = 0$（$a, b, c \geq 2$）：模 $3$：$0 + 0 \equiv 0 + 0$，无矛盾。模 $9$：$0 + 0 \equiv 0 + 3r \pmod{9}$，即 $3r \equiv 0 \pmod{9}$。但 $r \in \{1,2\}$ 时 $3r \in \{3, 6\}$，均不被 $9$ 整除，矛盾。

**情形 3：恰好两个为 0**

- $a = b = 0$：模 $3$：$r + 0 \equiv 0 + 0$，$r \equiv 0$，矛盾。
- $a = c = 0$：模 $3$：$r + 0 \equiv 2r + 0$，$r \equiv 2r$，矛盾。
- $a = d = 0$：模 $3$：$r + 0 \equiv 0 + 0$，$r \equiv 0$，矛盾。
- $b = c = 0$：模 $3$：$0 + 0 \equiv 2r + 0$，$2r \equiv 0$，矛盾。
- $b = d = 0$：模 $3$：$0 + 0 \equiv 0 + 0$，无矛盾。模 $9$：$0 + 6r \equiv 0 + 3r \pmod{9}$，即 $3r \equiv 0 \pmod{9}$，矛盾。
- $c = d = 0$：模 $3$：$0 + 0 \equiv 2r + 0$，$2r \equiv 0$，矛盾。

**情形 4：恰好三个为 0**

- $a = b = c = 0, d \geq 2$：模 $3$：$r + 0 \equiv 2r + 0$，$r \equiv 2r$，矛盾。
- $a = b = d = 0, c \geq 2$：模 $3$：$r + 0 \equiv 0 + 0$，$r \equiv 0$，矛盾。
- $a = c = d = 0, b \geq 2$：模 $3$：$r + 0 \equiv 2r + 0$，$r \equiv 2r$，矛盾。
- $b = c = d = 0, a \geq 2$：模 $3$：$0 + 0 \equiv 2r + 0$，$2r \equiv 0$，矛盾。

所有情形均导致矛盾，故不存在同色解。$\square$

### 结论

- 2-正则性：任意 2-着色都有同色解（第二步），故 $n \geq 3$。
- 3-正则性：任意 3-着色都有同色解（第三步），故 $n \geq 4$。
- 4-着色存在：第四步构造的 4-着色没有同色解，故 $n \leq 4$。

因此最小正整数 $n = \boxed{4}$。
