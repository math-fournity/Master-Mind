## 3. 已确认的结论

### 3.1 Type-1 不变量 $S$（来源：step 7 / thinking 行19-124）

**核心不变量**：$S = 32c_1 + 16c_2 + 8c_3 + 4c_4 + 2c_5 + c_6$ 在 Type 1 操作下不变。

- 推导：取权重 $w_i = 2^{6-i}$（即 $w_1=32, w_2=16, w_3=8, w_4=4, w_5=2, w_6=1$），满足 $-w_j + 2w_{j+1} = 0$，故 Type 1 的 $\Delta S = 0$。
- 这是**唯一**（差常数倍）的 Type-1 线性不变量。
- **初始值** $S = 32+16+8+4+2+1 = 63$。
- **目标值** $S = N = 2010^{2010^{2010}}$（因为 $B_1=\cdots=B_5=0$ 时 $S = c_6$）。
- 因此 Type 2 操作必须把 $S$ 从 63 改变到 $N$，总变化 $\Delta S_{\text{total}} = N - 63$。

### 3.2 Type 2 对 $S$ 的改变公式（来源：thinking 行317-341）

$$\Delta S(\text{Type 2 on } B_k) = -\frac{w_k}{4}\bigl(4 + c_{k+1} - c_{k+2}\bigr), \quad k=1,2,3,4$$

其中 $w_k/4 = 2^{4-k}$，即系数为 $8, 4, 2, 1$（对应 $k=1,2,3,4$）。

- 显式：
  - $k=1$: $\Delta S = -8(4 + c_2 - c_3)$
  - $k=2$: $\Delta S = -4(4 + c_3 - c_4)$
  - $k=3$: $\Delta S = -2(4 + c_4 - c_5)$
  - $k=4$: $\Delta S = -1(4 + c_5 - c_6)$
- **$S$ 增加的条件**：$c_{k+2} > c_{k+1} + 4$（右侧盒子比左侧多至少5个硬币时，swap 把大堆左移，因 $w_{k+1} > w_{k+2}$ 而 $S$ 增加）。
- $\gcd(8,4,2,1)=1$，故 $S$ 的单步改变原则上可取任意整数（但受状态约束）。

### 3.3 不存在被两种操作同时保持的非平凡线性不变量（来源：thinking 行289-309）

设 $\sum w_i c_i \bmod m$ 被 Type 1 和 Type 2 同时保持：
- Type 2 保持要求 $w_{k+1} \equiv w_{k+2} \pmod m$ 对 $k=1..4$，即 $w_2 \equiv w_3 \equiv w_4 \equiv w_5 \equiv w_6 \equiv v \pmod m$。
- Type 1 保持要求 $2w_{j+1} \equiv w_j \pmod m$。对 $j=2$：$2v \equiv v$，故 $v \equiv 0 \pmod m$，进而 $w_1 \equiv 0$。
- **结论**：所有权重 $\equiv 0 \pmod m$，只有平凡不变量。**没有模不变量同时约束两种操作。**

### 3.4 模分析（来源：thinking 行188-231, 353-381, 1003-1037）

| 模 | 初始 $S$ | 目标 $N$ | 需要 $\Delta S$ | 是否阻碍 |
|---|---|---|---|---|
| mod 2 | $63\equiv 1$ | $N\equiv 0$（2010偶） | $\equiv 1$ (奇) | 否——Type 2 on $B_4$ 可改变 $S \bmod 2$ |
| mod 3 | $63\equiv 0$ | $N\equiv 0$（2010≡0 mod 3） | $\equiv 0$ | 否——各 Type 2 的 $\Delta S \bmod 3$ 依赖状态，可取任意剩余 |
| mod 7 | $63\equiv 0$ | $N\equiv 1$（2010≡1 mod 7） | $\equiv 1$ | 否——各 Type 2 的 $\Delta S \bmod 7$ 依赖状态，可取任意剩余 |

**没有发现干净的模不变量阻碍。** 但状态约束可能隐式阻碍（未排除）。

### 3.5 简单策略的最大值（来源：thinking 行386-695）

**仅用 Type 2 on $B_4$ 的策略**：配置 $(0,0,0,d,0,n)$，$4d+n=63$，做 $d$ 次 Type 2 on $B_4$（每次把 $B_6$ 的堆 swap 到 $B_5$ 再 pump 回 $B_6$，每次翻倍），得 $B_6 = 2^d \cdot n$。

- 最大化 $g(d) = 2^d(63-4d)$：$g'(d)=0 \Rightarrow d \approx 14.06$。
- **最优**：$d=14, n=7$，$B_6 = 2^{14} \cdot 7 = 114688$。
- 次优：$d=15, n=3$，$B_6 = 2^{15} \cdot 3 = 98304$。

**交换率分析**：无论硬币放在哪个盒子，1 单位 $S$ 用于"reload coins"在指数中贡献 $1/4$；1 单位 $S$ 留在 $B_6$ 在底数中贡献 1。因此多轮分配不改善单轮最优。

### 3.6 $B_1$ 单调非增与过程的终止性（来源：thinking 行1049-1082）

- **没有任何操作能增加 $B_1$**（Type 1 on $B_1$ 减 $B_1$；Type 2 on $B_1$ 减 $B_1$；其他操作不涉及 $B_1$）。
- 一旦 $B_1=0$，$B_2$ 也单调非增（只有 Type 1/2 on $B_2$ 影响它，都减；无操作从右侧补充 $B_2$，因为 $B_1=0$ 时不能 Type 1 on $B_1$）。
- 依此类推：空盒波从左向右传播。$B_1 \to 0 \to B_2 \to 0 \to \cdots \to B_5 \to 0$。
- **过程必然终止**，$B_6$ 的最大值有限。
- 但硬币总数可因 Type 1 增长，故操作总数不被初始硬币数简单界定。

### 3.7 全循环策略的失效（来源：thinking 行804-923）

**全循环**：把 $B_6$ 的堆经 4 次 Type 2（on $B_4, B_3, B_2, B_1$）移到 $B_2$，再 pump 回 $B_6$（$16\times$）。需要 $B_1,B_2,B_3,B_4$ 各至少 1 个硬币。

- 从 $(a,b,c,d,0,n)$ 出发，一轮后得 $(a-1,0,0,0,0,\, 16n+8b+4c+2d-14)$。
- $\Delta S = 15n - 8b - 4c - 2d - 46$。$S$ 增加需要 $15n > 8b+4c+2d+46$。
- 但 $a=b=c=d=1$ 时 $n=3$，$15\cdot 3 = 45 < 60$，**$S$ 反而减少**。
- 无法在初始 $S=63$ 下既满足全循环前置条件又让 $S$ 增长。**全循环不可行。**

### 3.8 部分循环策略的失效（来源：thinking 行925-977）

**部分循环**：仅用 Type 2 on $B_4$ 和 $B_3$（把堆从 $B_6$ 移到 $B_4$，pump 回 $B_6$ 得 $4\times$）。
