**分析对象**：IMO 2009 Problem 6（蚱蜢跳跃问题）的标准归纳解答
**输入性质**：线性输入（过程B——已有题目和解答记录，一条完整证明路径，无折返）

## 题目概要

给定 n 个不同正整数 a₁,...,aₙ 和一个不含 s=Σaᵢ 的 n-1 元正整数集合 M。蚱蜢从 0 出发向右跳 n 步，步长为 a₁,...,aₙ 的某种排列。证明：存在一种排列使得蚱蜢从不落在 M 中的任何点上。

**解答的核心策略**：WLOG 排序 → 定义关键变量 x=去掉最大元素后的和 → 对 n 做强归纳 → 按 x 与 M 的关系分三种情况 → 每种情况归约到更小规模 → 还原到一般（无序）情形。

## 1. 段划分（Level 0）

将解答分成最细的 10 段：

| 段 | 内容 | 段特征 |
|---|---|---|
| 段1 | WLOG 排序 a₁ < a₂ < ... < aₙ（通过复合一个排列置换实现） | WLOG 排序、归约简化 |
| 段2 | 定义关键变量 x = a₁ + ... + a_{n-1}（去掉最大元素后的和） | 定义辅助变量、抓住归纳枢纽 |
| 段3 | 决定对 n 做强归纳 | 选择强归纳 |
| 段4 | 按 M 中元素相对 x 的位置分三种情况（两个二元判据：x∈M? 和 ∃y>x?） | 情况分析、分类框架 |
| 段5 | Case 1 条件（x∈M 且 ∃y>x∈M，故 n≥3）；定义"坏指标" i：x-aᵢ∈M 或 s-aᵢ∈M | 定义坏指标、约束翻译 |
| 段6 | Case 1 鸽巢论证：构造坏指标→M\{x} 的注入映射，由 \|M\{x}\|=n-2 < n-1 得出至少一个好指标 r 存在 | 注入映射+计数（鸽巢）、存在性证明 |
| 段7 | Case 1 构造：令 t=x-aᵣ，M'=M∩(-∞,t]，对剩余 n-2 个元素用归纳得 p'，拼接 p'+aᵣ+aₙ（交换使 aₙ 倒数第二），验证所有前缀和避开 M | 递归构造+拼接+验证 |
| 段8 | Case 2（x∉M 且 ∃y>x）：M'=M∩(-∞,x]，对 a₁,...,a_{n-1} 直接归纳，aₙ 放最后，验证 | 直接归纳延拓 |
| 段9 | Case 3（所有 m≤x）：z=max(M)，M'=M\{z}，对前 n-1 个归纳得 p'；若某前缀和命中 z 则把 aₙ 换到该位置跳过 z，否则 p' 已避开 M | 交换技巧、归纳后修复 |
| 段10 | 一般（无序）情形通过复合排序置换归约到有序情形 | 归约还原 |

**段划分说明**：段1-3 是准备阶段（排序、定义变量、选归纳）；段4 是分类框架；段5-7 是 Case 1（最复杂的情况，内部有"找好指标"+"构造"两个子论证）；段8、段9 分别是 Case 2、Case 3（各自较简洁）；段10 是收尾还原。段5/段6/段7 的细分依据是 Case 1 内部有清晰的三步结构（定义坏指标 → 鸽巢证存在 → 构造验证），每步是独立的思维单元。

### 审计项1：段划分完备性论证

**为什么是 10 段而不是更多？**

我考虑过进一步细分的地方：
