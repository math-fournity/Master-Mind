## W4.8: 四余定义审计

### 当前实现

| 四余 | 实现方式 | Swiss Ephemeris | 模式 |
|---|---|---|---|
| 罗睺 | TRUE_NODE（真交点） | swe.TRUE_NODE | true_as_north=True（升交点） |
| 计都 | 罗睺+180° | 计算 | inv_true_node |
| 紫炁 | 匀速线性运动 | 无（虚星） | ZIQI_PERIOD=10227天≈28年 |
| 月孛 | MEAN_APOG（平均远地点） | swe.MEAN_APOG | yuebei_mode="mean" |

### 与传统定义对照

| 四余 | 传统定义 | 当前实现 | 一致性 |
|---|---|---|---|
| 罗睺 | 月亮升交点（新法）/降交点（旧法） | TRUE_NODE, true_as_north=True | ✓ 新法（Java MOIRA默认） |
| 计都 | 罗睺对宫（+180°） | 罗睺+180° | ✓ |
| 紫炁 | 木之余，28年周期匀速运动 | 线性运动，周期28年 | ✓（匹配Java参数） |
| 月孛 | 水之余，远地点 | MEAN_APOG | ✓（匹配Java MOIRA） |

### 双模式支持

代码已实现双模式切换：
```python
core.set_four_yu_mode(true_as_north=True, yuebei_mode="mean")  # Java模式（默认）
core.set_four_yu_mode(true_as_north=False, yuebei_mode="oscu")  # 天文模式
```

**结论**: 四余定义与Java MOIRA一致，双模式支持完整。

## W4.9: 觜参顺序审计

### 传统顺序 vs 现代天文

| 顺序 | 二十宿排列 | 来源 |
|---|---|---|
| 传统 | ...毕→觜→参→井... | 中国传统（觜在前） |
| 现代天文 | ...毕→参→觜→井... | 西方天文（参在前） |

### 当前实现

`constants.json → lunar_mansions → width_yellow` 的顺序为：
```
[角,亢,氐,房,心,尾,箕, 斗,牛,女,虚,危,室,壁, 奎,娄,胃,昴,毕,觜,参, 井,鬼,柳,星,张,翼,轸]
```

**序号19=觜(1度), 序号20=参(11度)** — 觜在前，符合中国传统顺序。

### 历史背景

- 中国传统天文学中觜参顺序为觜→参
- 清代以后受西方影响，部分文献改为参→觜
- 七政四余传统典籍（明代）均用觜→参顺序

**结论**: 当前实现使用觜→参顺序，与七政四余传统典籍一致。
