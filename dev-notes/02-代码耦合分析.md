### CS41.py 现状

- 函数库部分（`計算分數`、`optimize_state_scores`、`計算太陽分數` 等）是七政四余命理评分 + scipy 矫正优化，**可复用**。
- 但 `main()` 是**写死 CSV 路径的批处理脚本**（`/Users/jacky/Desktop/alldata_29.csv`），**不是 CLI 工具**，无 JSON in/out 接口。
- 需要重新包装成 JSON in/out 的命令行小工具。

### 重构关键障碍

1. **ChartData.java 9424 行上帝类**：核心数据与绘制混在一起，是重构最大难点。
2. **Resource.java 全局静态状态**：核心层（Calculate、ChartData）大量调用 `Resource.getPrefInt`/`getString`，不解决则核心层无法脱离 GUI 独立运行。
3. **ChartData 单例模式**：`getData()` 全局单例，不利于并发与 pipeline 化。
4. **CS41.py 不是 CLI**：需重新包装接口。
