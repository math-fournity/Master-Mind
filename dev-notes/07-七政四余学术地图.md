## 七政四余学术地图（Schema）


**目的**：通过学术/网络搜索建立七政四余这门学问的完整知识结构，作为 repo 功能覆盖度分析的参照系。

**资料来源**：维基百科"七政四馀"、百度百科"七政四余"、《果老星宗》目录（鼎稔道学馆/中文百科全书）、周新春易学网、杰赫星命、馥灵之钥等。

### 1. 学科定位与历史

- **学科性质**：中国古代星命学（星占推命），以实际天体运行推人禄命，区别于紫微斗数（全虚星）。
- **核心天体**：七政（日月水金火木土）+ 四余（罗睺=月球降交点、计都=升交点、紫气=虚星28年一周、月孛=月球远地点）。
- **历史源流**：印度九曜术（Navagraha）唐传入 → 宋真宗崇道后十一曜流行 → 明《果老星宗》集大成 → 清康熙历狱（四余定义之争）。
- **三大流派**：琴堂五星（最古，传出一行）、果老星宗（唐代张果老，批琴堂而立）、天官五星（耶律楚才，最晚）。
- **与紫微斗数关系**：七政四余是紫微斗数的前身，紫微斗数的"四化星"源自七政四余的"十干化曜"。

### 2. 七政四余推命的完整流程（学术 Schema）

这是七政四余推命从输入到输出的完整步骤链，每一步都是 repo 需要覆盖的功能：

```

  ↓
[Step 1] 历法转换
  - 公历 → 农历（年月日 + 闰月标记）
  - 定节气（24 节气，定月份边界）
  - 定朔望（新月日期，定农历月）
  ↓
[Step 2] 星历计算
  - 七政四余 11 天体的恒星黄道位置（黄经/黄纬/距离/速度）

  ↓
[Step 3] 宫位系统

  - ASC/MC
  - 宫主（每宫的主星：子丑土、寅亥木、卯戌火、辰酉金、巳申水、午日、未月）
  ↓
[Step 4] 命宫/身宫
  - 命宫：太阳所在宫起生时顺数至卯（传统算法）
  - 身宫：月亮相关算法
  - 命度主/身度主（命宫所在宿度的主星）
  - 昼生/夜生判定（影响命主/身主权重）
  ↓
[Step 5] 童限/大限
  - 童限：(9 + 命宫度数/3) 年
  - 洞微大限：12 限逆数，每限 30°，limit_seq=[11,10,11,15,8,7,11,4.5,4.5,4.5,5,5]
  - 大限行度诀：每限内每年行多少度
  - 小限：命宫 + (age-1)*30°
  - 月限：小限宫起生月逆寻
  - 飞限：童限前后不同序列，阴阳命宫不同
  ↓
[Step 6] 化曜/十神
  - 十干化曜：年干 → 天禄/天暗/天福/天耗/天荫/天贵/天刑/天印/天囚/天权
    （对应子平的比肩/劫刃/食神/伤官/偏财/正财/七煞/正官/枭印/印绶）
  - 化曜配六亲（财官印食等）
  ↓
[Step 7] 神煞系统
  - 天干神煞：禄勋/天乙/玉堂/斗杓/卦气/唐符/国印 等
  - 地支神煞：岁驾/阳刃/剑锋/天雄/地雌/飞廉/的煞/劫煞/亡神/四耗/四符 等
  - 太岁神煞：丧门/白虎/吊客/病符/死符/岁破 等（流年用）
  - 神煞从年柱干支排布（与子平八字不同）
  ↓
[Step 8] 星曜状态
  - 庙旺利陷（每星在每宫/每宿的强弱状态）
  - 入垣/升殿/喜乐（吉局）
  - 逆顺迟疾（行星速度状态：留/顺/伏/逆）
  - 得地/失时
  ↓
[Step 9] 格局分析
  - 三方四正（三合 + 对宫）
  - 夹拱/冲照/会合（相位关系）
  - 星格：贵格/富格/贫格/贱格/寿格/天格/贤格/愚格/女命格
  - 灵台星格（42 种吉凶星格）
  - 日月合格/日月忌格/五星合格/四余合格/政余合格/政余忌格
  ↓
[Step 10] 限运推演
  - 行大限：当前年龄在哪一限，限内度数
  - 流年：太岁 + 流年星辰到限
  - 流月：月限宫 + 月将
```

### 3. 七政四余的核心概念体系

| 概念层 | 元素 | 说明 |
|---|---|---|
| **天体层** | 七政（日月水金火木土）+ 四余（罗计紫孛） | 实星 + 虚星 |
| **坐标层** | 黄道十二宫 + 二十八宿 | 宫（太阳系立极）+ 殿（宇宙立极） |
| **宫位层** | 后天十二宫 | 命/财帛/兄弟/田宅/男女/奴仆/妻妾/疾厄/迁移/官禄/福德/相貌 |
| **主星层** | 宫主 + 度主 | 宫主（十二宫主星）+ 度主（二十八宿主星） |
| **限运层** | 童限/大限/小限/月限/飞限 | 洞微大限法 + 行年小限 + 月限 + 飞限 |
| **化曜层** | 十干化曜（10 化） | 天禄/天暗/天福/天耗/天荫/天贵/天刑/天印/天囚/天权 |
| **神煞层** | 天干神煞 + 地支神煞 + 太岁神煞 | 数十种吉凶神煞，从年柱排布 |
| **状态层** | 庙旺利陷/入垣升殿/逆顺迟疾 | 星曜强弱判定 |
| **格局层** | 三方四正/夹拱冲照/星格 | 星盘格局分析 |
| **流年层** | 太岁/流年星辰/限路 | 动态运势推演 |

### 4. 三大流派的差异

| 维度 | 琴堂五星 | 果老星宗 | 天官五星 |
|---|---|---|---|
| 侧重 | 宫位（十二宫） | 宿度（二十八宿） | 天官（官星） |
| 宫主/度主 | 重宫主 | 重度主（"宫主如州，度主如县"） | 重官星 |
| 源流 | 最古，传出一行 | 批琴堂而立，托名张果 | 源自耶律楚才，最晚 |

**MOIRA 的流派定位**：从 prop 的 `limit_seq`（洞微大限）和 `life_mode=0`（传统命宫算法）看，MOIRA 偏向果老星宗派（重宿度 + 洞微大限）。
