## 一、四余总论

### 1.1 四余的定义

七政四余中"四馀"是古代天文学构拟出来的虚星（隐曜、暗曜），指罗睺、计都、紫炁、月孛。

- **罗睺**（Rāhu）：吞食日月的阿修罗神，即日食/月食
- **计都**（Ketu）：阿修罗神的蛇尾半身，即彗星
- **紫炁**（紫气）：木星之余气，虚星无天文对应体
- **月孛**：月球远地点，阻碍月球运行的隐曜

四馀与七政合称"十一曜"。星命家对应关系：
- 罗睺 = 火馀
- 计都 = 土馀
- 紫炁 = 木馀
- 月孛 = 水馀

### 1.2 四余的传入与演变

来源：学术论文《从"罗、计"到"四余"：外来天文概念汉化之一例》

| 时代 | 事件 |
|---|---|
| 三国时期 | 《摩登伽经》首次将罗睺、计都与七曜并列 |
| 唐初 | 瞿昙悉达译《九执历》，罗睺=升交点，计都=月球远地点 |
| 唐末宋初 | 罗睺/计都定义发生变动：罗睺=降交点（交初），计都=升交点（交中） |
| 宋真宗 | 崇奉道教，十一曜广泛流行，紫气/月孛加入 |
| 元明 | 紫气、月孛成为官方天文观测和历法推算项目 |
| 清初 | 汤若望推行新法，罗睺=升交点，计都=降交点（与旧法相反） |
| 康熙历狱 | 新法旧法在四余定义上的冲突成为导火线之一 |

**关键结论**：罗睺/计都的升交点/降交点定义在历史上发生过反转。传统星命家沿袭旧法（罗睺=降交点），清初新法改为罗睺=升交点。Java MOIRA 默认用新法（`true_as_north=1`）。

## 二、罗睺 / 计都

### 2.1 天文定义

| 来源 | 罗睺 | 计都 | 备注 |
|---|---|---|---|
| 《七曜攘灾诀》（唐初，印度传入） | 升交点 | 月球远地点 | 原始定义 |
| 唐末宋初（旧法/星命家法） | **降交点**（交初） | **升交点**（交中） | 传统星学大成/果老星宗用此 |
| 清初汤若望（新法） | **升交点** | **降交点** | Java MOIRA 默认用此 |

### 2.2 道教称号

来源：《上清十一大曜灯仪》
- 罗睺 = "交初建星罗㬋隐曜星君"
- 计都 = "交终神尾坠星计都星君"

### 2.3 运行速度

来源：《星平会海》/《三辰通载》
- 罗睺：18天行1度，18个月过1宫，18年行1周天
- 计都：与罗睺同（对宫关系）

### 2.4 Java MOIRA 实现

- `SE_TRUE_NODE`（真交点，非平均交点）
- `true_as_north=1`（默认）：罗睺=升交点（新法）
- `true_as_north=0`：交换罗睺/计都 → 罗睺=降交点（旧法）
- 计都 = 罗睺 + 180°（`INV_TRUE_NODE`）

## 三、紫炁（紫气）

### 3.1 本质：虚星，无天文对应体

**紫炁没有可靠的天文对应体。** 这是学术界的共识。

- 近代有人认为紫炁=月亮近地点 → **被否定**（近点周期27.55天，与28年周期对不上）
- 有人认为紫炁=白道离黄道最远的点 → 存疑，无确证
- 可能源自闰法：19年7闰，28年约10闰
- 可能仿太岁：一年一辰12年周天→设想一年一宿28年周天

来源：维基百科"七政四馀" + 学术论文

### 3.2 性格意象（命理属性）

来源：用户提供资料
- 属木，为木星之余气
- 象征仁慈、清高、玄学、福寿
- 命盘中通常为吉星与"君子星"
- 代表清高、淡泊、宅心仁厚、喜欢宗教玄学或艺术

### 3.3 运行周期（文献对照）

| 来源 | 周期 | 每日行度 | 备注 |
|---|---|---|---|
| 《星平会海》 | 29年 | 29天行1度 ≈ 0.0345°/天 | "29天行一度，29个月过一宫，29年行一周天" |
| 《授时历》 | ≈27.6年 | 一年行13.050460度 ≈ 0.0357°/天（古度） | 1280年数据点：紫气在女二度 |
| Java MOIRA | 28.0年 | 0.03520034°/天 | 周期10227.1792天 |
| 《时宪历》/《御定星历考原》 | 28年 | 每日行3分57秒 ≈ 0.0352°/天 | "28年行一周天，每日行3分57秒" |
| 用户提供参考代码 | 28年 | 0.03520032°/天 | 周期10227.1797天，J2000.0基准290.1584° |

**结论**：28年是主流说法，《星平会海》的29年是少数派。Java MOIRA 的10227.1792天与《时宪历》的"每日3分57秒"一致。

### 3.4 计算方法

紫炁是虚星，**不能用 Swiss Ephemeris 计算**。使用匀速顺行公式：

```
degree = base_degree + (360 / period) * (jd - base_jd)
```

sidereal 模式下减去 ayanamsa（岁差修正）。

### 3.5 基准点对照

| 基准 | 参数 | 用《授时历》1280年验证 | 误差 |
|---|---|---|---|
| **Java MOIRA** | 1975-03-13 16:00 UT, 230.5° | 推算1280年紫炁=291.05°（恒星黄道） | **+6.05°**（694年外推，可接受） |
| J2000.0 参考 | JD 2451545.0, 290.1584° | 推算1280年紫炁=31.79°（恒星黄道） | -106.79°（完全错误） |

**结论**：Java MOIRA 基准更接近《授时历》数据，采用 Java 基准作为默认。

### 3.6 《授时历》数据点

来源：360doc.com 七政四余在线排盘系统

> 据《授时历》上记载的数据，公元1280年12月14日 1:29:36，此时紫气位于女二度。
> 紫气一年行13.050460度，每天行13.050460/365.2425=0.0357度（古度）。
> 以这个时间点紫气所在的位置为基准，根据紫气运行速率进行加减运算，从而求得任意一个时间点紫气的位置。
> 这样计算出来的数据，和《郑氏星案》上的数据也是基本吻合的。

**这个数据点可用于 Phase 24 历史命例验证。**

### 3.7 进阶修正（商用级精度）

来源：用户提供资料

1. **岁差修正**：古法平黄经 + 标准岁差公式（每年约增50.29角秒=0.01396°）→ 对应某一年的二十八宿
2. **定气与平气**：四余有平曜（匀速）和定曜（考虑太阳视运动修正）之分。多数排盘软件（如果老星宗排盘）默认用平紫气（平曜匀速）算法。

## 四、月孛

### 4.1 天文定义

| 来源 | 定义 | 备注 |
|---|---|---|
| 《七曜攘灾诀》（原始） | 计都=月球远地点 | 月孛继承自此 |
| 传统星命 | 月孛=月球远地点 | "月孛9天一度，9个月一宫，9年一周天" |
| 汤若望 | "月孛是一片白气在月之上" | 存疑，见杨光先《不得已》 |
| 西方占星 | Lilith = 月孛 | 即月球远地点 |
| Java MOIRA | `SE_MEAN_APOG`（平均远地点） | 周期≈8.85年 |

### 4.2 运行速度

来源：《星平会海》
- 月孛：9天行1度，9个月过1宫，9年行1周天

### 4.3 MEAN_APOG vs OSCU_APOG

| 类型 | Swiss Ephemeris 常量 | 特点 |
|---|---|---|
| 平均远地点 | `SE_MEAN_APOG` | 平滑运动，周期≈8.85年 |
| osculating远地点 | `SE_OSCU_APOG` | 有波动，更精确但非传统 |

Java MOIRA 用 `SE_MEAN_APOG`（平均远地点），与"9年1周天"的传统说法接近。我们的 Python 已修正为与 Java 一致。

## 六、与本项目实现的对照

### 6.1 当前实现（A2 审计修复后）

| 四余 | 计算方式 | 参数 | 模式 |
|---|---|---|---|
| 罗睺 | `swe.TRUE_NODE` | 真交点 | 默认新法（升交点），可切换旧法 |
| 计都 | 罗睺 + 180° | 对宫 | 跟随罗睺模式 |
| 紫炁 | 匀速线性运动 | 周期10227.1792天，基准1975-03-13 230.5° | 唯一模式（虚星无天文替代） |
| 月孛 | `swe.MEAN_APOG` | 平均远地点 | 默认mean，可切换oscu |

### 6.2 待验证项（Phase 24 历史命例验证）

1. 用《郑氏星案》40例验证紫炁位置是否与古人排盘一致
2. 用《授时历》1280年数据点做精确校准（当前误差6°，可能需要微调基准）
3. 验证罗睺旧法（降交点）是否与星学大成/果老星宗的命例一致
4. 验证月孛 MEAN_APOG 是否与"9年1周天"的传统说法在精度上可接受

### 6.3 基准点微调可能性

当前 Java 基准在1280年有6°误差。可能原因：
- 角宿起点近似值（174°）不准确
- 28年周期本身是近似值
- 历元漂移

如果 Phase 24 验证发现系统性偏差，可考虑：
- 用《授时历》1280年数据点反推更精确的基准
- 或用《郑氏星案》多个命例做最小二乘拟合
