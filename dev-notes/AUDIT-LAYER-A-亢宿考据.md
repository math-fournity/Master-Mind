## 七、定量化思考

### 1. 亢宿度数的量化

亢宿有9度（或10度36分），这是一个精确的数值。在七政四余中，星曜躔入某宿的度数不同，吉凶程度可能不同。

**量化可能性**：
- 可以建立"躔度-吉凶强度"的函数关系
- 例如：木星躔亢宿1度 vs 木星躔亢宿9度，吉凶程度可能不同
- 需要更多命例数据来验证

### 2. 五行生克的量化

亢宿属金，各星曜五行与金的关系：
- 木克金（木→亢）：但木躔亢反得吉格"天城"，说明有特殊机制
- 火克金（火→亢）：火躔亢得凶格"天戈"，符合"火金相战"
- 土生金（土→亢）：土躔亢得吉格"天仁"，符合"有生养之义"
- 金比和（金→亢）：金躔亢得吉格"天昌"，符合"比和为福"
- 金生水（亢→水）：水躔亢得吉格"天津"，符合"水润金明"

**量化可能性**：
- 可以建立"五行生克强度"的量化模型
- 生我（土生金）= +1
- 我生（金生水）= +0.5
- 比和（金金）= +0.8
- 克我（火克金）= -1
- 我克（木克金）= -0.5（但实际为吉，说明有特殊机制）

### 3. 吉凶程度的量化

从11条规则的诗句中，可以提取吉凶程度的关键词：

**吉格（7条）**：
- 天城：财禄荣华、学问操修、辅赞豪英 → 大吉
- 天仁：文章达帝畿、官极贵、安镇清宁 → 大吉
- 天昌：英才姓字香、文武兼全、旌节受恩光 → 大吉
- 天津：容貌清奇、通道术、多智多能善音律 → 中吉
- 天柱：学问文章、欢乐贤豪、性识孤高 → 中吉
- 天玑：富贵荣华、好异、安乐丰荣、妻妾容颜奇美 → 大吉
- 天僮：性善文章艺术、为官富旺、神仙快乐福无穷 → 大吉

**凶格（4条）**：
- 天戈（火）：妻妾折磨、好色损妻、衣食奔波 → 中凶
- 天微：心毒如蛇、易喜易嗔、损妻儿 → 大凶

- 天戈（计）：军阵成功福未多、自缢与投河 → 大凶

**量化可能性**：
- 可以建立"吉凶等级"的量化模型
- 大吉 = +3
- 中吉 = +2

## 十五、重要发现：亢宿度数差异

### 发现

在考据过程中发现亢宿度数存在差异：

| 来源 | 亢宿度数 |
|---|---|
| 《星平会海》亢宿解释 | "亢属金得九度" |
| 《星学大成》二十八宿度数 | "亢九日光辉" |
| constants.json | width_yellow: 11度 |
| schema.json | 未明确标注度数 |

### 分析

1. **《星平会海》和《星学大成》一致**：两部古籍都明确记载亢宿为9度
2. **constants.json为11度**：这可能是根据《汉书·律历志》赤道宿度 + 黄道宿度（合计360°制）计算的结果
3. **差异原因**：可能是不同历法体系的差异（赤道宿度 vs 黄道宿度）

### 影响

这个差异可能影响：
1. 星曜躔入亢宿的判定范围
2. 命盘计算的精确度
3. 与古籍原文的一致性

### 建议

建议在后续工作中：
1. 核实constants.json中亢宿度数的来源
2. 与《星平会海》《星学大成》等古籍保持一致
3. 如果确实需要使用11度，应在代码中添加注释说明差异原因
