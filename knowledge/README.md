# Knowledge Assets

`knowledge/` contains small, curated knowledge notes that are safe to keep in this repository and pointers to
large external corpora that live on D disk.

## In-Repo Notes

- `breakthroughs/`: prize and breakthrough notes.
- `thinking_books/`: mathematical thinking and invention references.
- `competitions/`, `open_problems/`, `mathematicians/`: small curated reference notes when present in the
  working tree.

## External Data

Large corpora are not kept as active Git working-tree content. Their canonical local copy for this governance
alignment is:

`/data/master-mind-glm5.2-worktree-external-data/2026-08-24/knowledge/`

Pointers:

- `arxiv/README.md`: arXiv fulltext corpus pointer.
- `problem_banks/README.md`: problem-bank and benchmark-data pointer.

Verification evidence is recorded under:

- `dev-docs/governance-alignment-manifests/external-large-data-pre-offload-sha256.tsv`
