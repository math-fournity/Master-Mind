# Approximation Algorithms for Geometric Maximum Coverage

**arXiv ID**: 2607.29160v1
**Authors**: Sujoy Bhore, Timothy M. Chan, Pasin Manurangsi
**Published**: 2026-07-31
**Categories**: cs.CG, cs.CC, cs.DS

## Abstract

We study the maximum coverage problem for geometric set systems: given a set of points, a set of geometric objects, and a number $k$, select $k$ objects maximizing the number of points inside their union.   - We present a polynomial-time approximation algorithm with approximation factor strictly better than $1-1/e$ for any set system with linear 2-shallow cell complexity (or any set system that can be decomposed into a constant number of such set systems). The result also holds for the weighted maximum coverage problem, where objects have weights and we want to select objects with total weight within a given budget. The result applies to many types of geometric objects, including pseudodisks in 2D, fat axis-aligned rectangles in 2D, similar-size fat triangles in 2D, axis-aligned unit cubes in 3D.   - For small $k$, we obtain a $(1-ε)$-approximation algorithm more generally for any set system with constant VC dimension, running in time exponential in $\tilde{O}(k/ε)$. This simplifies and improves Badanidiyuru, Kleinberg, and Lee's parameterized approximation scheme [SoCG'12] running in time exponential in $\tilde{O}(k^2/ε^5)$.   - A continuous version of the geometric maximum coverage problem asks for $k$ objects maximizing the volume of their union. We give better approximation algorithms for this problem for certain families of objects; e.g., we obtain an EPTAS for fat convex objects in any constant dimension.   - We complement our algorithms with several hardness results, e.g., APX-hardness for fat axis-aligned rectangles in 2D, $(1-1/e+ε)$-approximation hardness for axis-aligned boxes in a dimension dependent on $ε$, and a lower bound ruling out $n^{\mathop{\rm poly}(1/ε)}$-time PTASs for the continuous problem for axis-aligned boxes in 3D.

## 1Introduction

Themax coverageproblem is one of the most fundamental optimization problems in combinatorial optimization. In its classical form, we are given a collectionSSof sets over a universePPtogether with an integerkk, and the goal is to select at mostkksets fromSSwhose union has maximum cardinality. A simple greedy algorithm achieves an approximation factor of1−1/e1-1/e[28,36,38], and so does LP rounding[2], while the celebrated result of Feige[35]shows that this guarantee is optimal unlessP=NP\mathrm{P}=\mathrm{NP}.

Weighted extensions of the problem can also be considered. Allowing elements inPPto have weights does not really make the problem more challenging: we can just treat weights inPPas multiplicities.111Objects with weights smaller than1/nc+11/n^{c+1}times the largest weight may be removed, while worsening the approximation factor by only1−O​(1/nc)1-O(1/n^{c})for an arbitrary large constantcc. Then by rescaling, all weights become integers bounded bync+1n^{c+1}.More interesting is to allow the sets inSSto have (positive) weights: the goal is now to select sets fromSSwith total weight
at most a given budget whose union has maximum cardinality. This version is sometimes called thebudgeted max coverageproblem in the literature, although we will refer to it simply as theweightedversion of max coverage.
A variant of the greedy algorithm[42]or LP rounding[50,32]is also known to achieve approximation factor of1−1/e1-1/efor this weighted problem.

Over the past three decades, max coverage has become a central primitive across approximation algorithms, submodular optimization, machine learning, and computational geometry, among others. A major research direction has been to understand whether additional structure in the input allows one to circumvent the general1−1/e1-1/ebarrier[5,18,40].
Geometric set systems provide one of the most prominent examples,
a common setting of which is whenPPis a given finite set of points and
the sets ofSSare geometric objects such as disks, rectangles, etc. (or,
more precisely, a set inSSconsists of all points ofPPinside an object).

The main question addressed in this paper is the following:

When does geometry help for the (unweighted or weighted) max coverage problem? In other words, for what types of geometric objects can we obtain approximation guarantees strictly better than1−1/e1-1/e?

## Prior work on geometric discrete independent set and other related problems.

Another basic optimization problem,discrete independent set, shares
a similar story: here, we want to find the largest (or, in the weighted case, the
largest-weight) subcollection of objects inSSso that no two chosen
objects contain a common point inPP. Known techniques similarly include:
- •

Local search PTASes: Ene, Har-Peled, and Raichel[33]obtained a PTAS via local search for the unweighted discrete independent set problem for objects that satisfy

- •

algorithms for unweighted and weighted discrete independent set for objects with linear union complexity. In AppendixA, we note that their analysis
actually extends to objects with linear 2-shallow cell complexity; and it similarly extends to the case when the objects can be partitioned intoO​(1)O(1)subsets each with linear 2-shallow cell complexity.

LP-rounding approaches for geometric set cover have also been adapted
to solve a number of related problems, e.g.,set multicover[19,49],partial set cover[39,20], andonlinevariants of set cover[6]. Partial set cover seems especially relevant, as it can be viewed as an “inverse” to max coverage (it asks for the minimum number of objects inSSto cover at leastkkpoints inPP); in fact, the two problems are equivalent for exact algorithms, though not for approximation algorithms.

## Prior work on geometric max coverage.

Returning to the max coverage problem, we see a far less complete
picture on when geometry helps, in contrast to the extensive literature on geometric set cover.
Badanidiyuru, Kleinberg, and Lee[5]studied the case whenkkis small, which we will discuss more later (see also[29,41]for more specialized results for smallkk). For generalkk, the only major prior work is by Chaplick, De, Ravsky, and Spoerhase[18],
who obtained a local-search-based PTAS for unweighted max coverage for objects that satisfy a planar graph support property444Chaplick et al.[18]required the “support graph” to have balanced sublinear-size separators instead of being planar.similar to Mustafa and Ray’s[48].
This takes care of the types of objects in the first row of Table2, but not the other types of objects.
Also, local search inherently does not work well for the weighted problem.
There has been no prior work on LP-rounding-based approaches that beat1−1/e1-1/efor geometric max coverage. The problem seems more challenging because the target range is narrower (we aim for a constant approximation factor above1−1/e1-1/e), unlike minimization problems such as set cover, set multicover, or partial set cover (where any constant approximation factor would be an improvement over the general logarithmic bound).
