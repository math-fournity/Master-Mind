## Abstract

In this concise paper, we investigate a computational class of random inverse problems that incorporates model uncertainties through random variable parameters nonlinearly in the forward model as well as additive observational uncertainty. Random inverse problems with nonlinear parameter dependencies may arise in engineering, geophysics, image processing or uncertainty quantification. We introduce a new perspective on structural ambiguities due to the non-injectivity of the forward model together with probabilistic ambiguities by assigning mixture model densities with separate components to the parameters, which leads to a possibly complex forward model, observation model and posterior. As a result, the mixture-model parameters in the forward model can be interpreted as simultaneously describing aspects of both the nonlinear ambiguity and the uncertainty of the inverse problem. The underlying solution algorithm is presented based on Bayesian inversion for three observation scenarios leading to posterior densities for the input for given output samples or an observed output density. By applying the derived algorithms to 1D and 2D quadratic models, we numerically demonstrate in which scenarios the proposed algorithm can resolve probabilistic ambiguities in the solution of the random inverse problem. It is demonstrated that making the residual structural ambiguities visible in the posterior and showing the interplay with probabilistic ambiguities is a relevant perspective, including cases with a finite and an infinite number of solutions.

## 1Introduction

Inverse problems are an important class of problems in applied mathematics and are defined by an input space, an output space, and a forward model which maps elements of the input to the output space. Given an output observation the goal is to find the corresponding inputs that fit best to that output. The main challenge is that the inverse problem is often ill-posed, which typically means that the forward model is in theory or in numerical practice not readily invertible[1]. Incorporating uncertainties further increases the problem difficulty and the demanded solution is typically described by an input probability density. A common approach for such uncertainty-driven inverse problems is regularization in the framework ofBayesian inverse problems[1,2,3]. These approaches typically use assumptions that we want to relax in this publication:

First assumption: the forward model itself is known deterministically (only observational noise introduces uncertainty) and it is smooth to some degree. In this work we regard the forward model itself as stochastic, i.e. it depends on random variable parameters which have possibly different realizations for every forward model evaluation which we call arandom forward / inverse problem(highlighting the close relation torandom equations). Further, we allow for nonlinear and only piecewise continuous forward models.

Second assumption: stochastic uncertainty is typically introduced only by additive observational noise at the output which is a comparably simple way of introducing uncertainty. In this work, we allow the (possibly nonlinear) incorporation of uncertainty in the forward model as part of a challenging uncertainty propagation. This relates to inverse problems with Monte Carlo simulators[4]although we utilize mixture models in order to capture the forward model complexity instead of a black box simulator.

Third assumption: only simple density functions for observational uncertainty are typically investigated and more complicated non-Gaussian and non-uniform distributions are rarely explored. In this work we investigate complicated probability densities by mixture models, which represent a flexible class of multi-modal densities.

In particular, we focus on non-injective ill-posed inverse problems, i.e. different inputs may lead to the same output of the forward model which introduces ambiguity in the solution of the inverse problem, e.g. see[5]and introduce probabilistic ambiguities by utilizing random parameter densities inside the forward model that contain mixture models with separated components or distinct modes. Investigating these two types of ambiguities simultaneously is part of the special setup of the work and motivates the general formulation in this study. We further differentiate between three observational scenarios (i)-(iii) which illustrates the flexibility of the presented methodology and provides deeper practical insights on how structural and probabilistic ambiguities interact in the solution of inverse problems.
With these extensions in mind, we introduce a general modeling and computational framework for random inverse problems which relates to previously presented likelihood / posterior formulations considered in very different application areas, such as random equations[6], stochastic dynamical systems[7], model fitting[8]and computer vision[9]. Although these works provide an instructive context, they are not directly concerned with inverse problems and their specific characteristics.

The outline of the paper is as follows: In the methods section, the definition, general posterior derivation and observation scenarios as well as algorithmic implementations are presented. In the results section, simulation results for straightforward and illustrative examples are presented which help for a deeper understanding of this methodology.

## 2.1Random Inverse Problem Formulation and Observation Scenarios

Random inverse problemscontain random variables (nonlinearly) in the forward model (i.e. the system function) as well as additive observational uncertainties following the general equation𝒚=𝑴​(𝒙;𝑨)+𝑩,\displaystyle\boldsymbol{y}=\boldsymbol{M}(\boldsymbol{x};\boldsymbol{A})+\boldsymbol{B}\;,(1)

with𝒚∈ℝR\boldsymbol{y}\in\mathbb{R}^{R}the given output of the system,𝒙∈ℝn\boldsymbol{x}\in\mathbb{R}^{n}the input we want to reconstruct,𝑨\boldsymbol{A}aKK-dimensional random variable vector and𝑩\boldsymbol{B}anRR-dimensional observational uncertainty/noise random variable vector. The system function𝑴:ℝn×ℝK→ℝR\boldsymbol{M}:\mathbb{R}^{n}\times\mathbb{R}^{K}\rightarrow\mathbb{R}^{R}is at least piecewise continuous and in general nonlinear with respect to𝒙\boldsymbol{x}and𝑨\boldsymbol{A}. We deliberately distinguish between additive observational uncertainties in𝑩\boldsymbol{B}and inherent model randomness in𝑨\boldsymbol{A}since we regard this as different sources of uncertainties. The goal of the inverse problem is to find𝒙\boldsymbol{x}which explains𝒚\boldsymbol{y}under𝑴\boldsymbol{M}considering𝑨\boldsymbol{A}and𝑩\boldsymbol{B}. In classical Bayesian inverse problems this relation is described with a deterministic system function𝑴\boldsymbol{M}, a random variable input𝒙\boldsymbol{x}and only additive random noise, i.e.𝒚=𝑴​(𝒙)+𝑩\boldsymbol{y}=\boldsymbol{M}(\boldsymbol{x})+\boldsymbol{B}. Another difference is that we consider𝒙\boldsymbol{x}not a random variable in the forward model but it becomes a random variable when solving the inverse problem by Bayesian methods. In this sense, we also consider the definition of a typically non- or weakly informative prior for𝒙\boldsymbol{x}pragmatically as part of the solution method.

For a clear understanding, therandom forward problemis stated as follows: Given𝑴\boldsymbol{M},𝑨\boldsymbol{A}and𝑩\boldsymbol{B}, how does a given input𝒙\boldsymbol{x}map to outputs𝒚\boldsymbol{y}?
We differentiate between three observation scenarios:
- (i)

We assume to have independently observed output samples𝒚^l\hat{\boldsymbol{y}}_{l}with individual observational uncertainties𝑩l\boldsymbol{B}_{l}as well as individual model parameters𝑨l\boldsymbol{A}_{l}(l=1,…,Ll=1,\dots,L) which leads to different outputs even for the same deterministic input𝒙\boldsymbol{x}, i.e.𝒚^l=𝑴​(𝒙;𝑨l)+𝑩l\hat{\boldsymbol{y}}_{l}=\boldsymbol{M}(\boldsymbol{x};\boldsymbol{A}_{l})+\boldsymbol{B}_{l}.
- (ii)

Contrary to scenario (i) we assume a single true model parameter set for all observations, but which is still a realization of an unknown parameter variable𝑨\boldsymbol{A}, i.e.𝒚^l=𝑴​(𝒙;𝑨)+𝑩l\hat{\boldsymbol{y}}_{l}=\boldsymbol{M}(\boldsymbol{x};\boldsymbol{A})+\boldsymbol{B}_{l}.
- (iii)

In this scenario we are observing not samples or realizations, but an output density functionf𝒚^f_{\hat{\boldsymbol{y}}}which contains also all observation uncertainties, i.e.𝒚^=𝑴​(𝒙;𝑨)\hat{\boldsymbol{y}}=\boldsymbol{M}(\boldsymbol{x};\boldsymbol{A}).

We assume all observation random variables asindependentwith respect toll, such as𝑩l\boldsymbol{B}_{l}in scenarios (i) and (ii), and specifically in scenario (i) all𝑨l\boldsymbol{A}_{l}arei.i.d.with the densityf𝑨f_{\boldsymbol{A}}.

In this work we are focusing on two sources of ambiguities in the inverse problem: First, since𝑴\boldsymbol{M}is a general non-invertible function, a single𝒚\boldsymbol{y}may be the result of many𝒙\boldsymbol{x}just by the non-injectivity, which we call thestructural ambiguityof the inverse problem. Second, using mixture model random variables with separated components in𝑨\boldsymbol{A}this additionally introduces aprobabilistic ambiguityin𝒚\boldsymbol{y}under the condition that𝑴\boldsymbol{M}propagates these mixture model components. This probabilistic ambiguity may contain a combinatorial side since all mixture model components of different parameters interact with each other for the calculation of𝒚\boldsymbol{y}.

Remark:This places𝑨\boldsymbol{A}conceptually between the properties of𝑴\boldsymbol{M}, with ambiguities of the solution, and𝑩\boldsymbol{B}, which introduces uncertainty in the inverse problem. In consequence, we consider the investigation of inverse problems with such random parameters𝑨\boldsymbol{A}as an original perspective in this work.

## 4Discussion

This work broadens the perspective on uncertainty-driven inverse problems by investigatingrandom inverse problems. As a main contribution we subdivide ambiguities of the inverse problem as structural, due to non-injectivity of the forward problem, and probabilistic, due to multi-modal mixture model parameters acting nonlinearly within the forward model. It is a key observation that these two types of ambiguities interact with each other, depending on observation scenarios at the output. This perspective goes beyond classical Bayesian inversion since it typically treats deterministic forward problems with classical additive noise.

In the simulation results for the inversion of 1D and 2D quadratic functions (which contain structural ambiguities by design), we distinguish between three observation scenarios: (i) For each observation not only random noise is newly sampled but also the parameter random variable which is a fundamental uncertainty in the forward problem. It is demonstrated that this scenario makes it possible that the probabilistic ambiguities can be resolved leaving only structural ambiguities in the posterior. (ii) In this scenario there is one true but unknown parameter set and only observational noise is sampled for each observation. This leads to a backpropagation of the multi-modal uncertainty about the parameters in the posterior, showing a practically irresolvable combination of structural and probabilistic ambiguities. (iii) Contrary to the previous scenarios, not samples but a full output density is observed. In this case probabilistic ambiguities can also be resolved but with a much lower credibility level compared to (i). In total, this scenario-dependent behavior demonstrates different interaction patterns of these two types of ambiguities which have not been presented in the literature before to the best of the author’s knowledge.

The primary limitation of this methodology in the presented form is computational scalability: Due to the grid-based structure of the input spaceℝn\mathbb{R}^{n}and the Monte Carlo integration in the parameter spaceℝK\mathbb{R}^{K}, large dimensions in either of those may lead to scalability problems as discussed in Subsection2.3. To address this, a natural extension would be going from grid-based to problem-specific basis function representations of a high-dimensional input space and smart sampling approaches, such as importance sampling or Markov chain Monte Carlo, e.g. see[14,15]. Further questions are: how to deal with situations when the forward model parameter densities are not known well and need to be approximated, and how these extensions play out in practice with higher-dimensional forward models that exhibit a high degree of nonlinear uncertainty propagation?
