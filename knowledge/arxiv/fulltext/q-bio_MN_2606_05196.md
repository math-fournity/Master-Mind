## Abstract

Boolean networks are widely used to model gene regulatory systems, where ensembles of Boolean functions serve as null models for assessing structural and dynamical properties. A common approach generates canalizing and nested canalizing functions by sampling their defining parameters uniformly at random. However, because multiple parameterizations can represent the same Boolean function, this induces a non-uniform distribution over distinct functions and systematically biases random ensembles.   Here, we develop efficient algorithms for uniform sampling of Boolean functions with prescribed exact or minimal canalizing depth that correct this bias. Our approach combines dynamic programming for sampling canalizing layer structures with rejection-based methods and is implemented in BoolForge.   We show that the sampling scheme substantially affects commonly studied function-level metrics. Under traditional parameter-uniform sampling, the expected average sensitivity of nested canalizing functions equals one independent of the number of variables. In contrast, under function-uniform sampling, the expected sensitivity increases with system size and numerically approaches approximately 1.183. This discrepancy arises from an exponential suppression of high-sensitivity functions under parameter-based sampling.   These differences propagate to Boolean network models, affecting conclusions about robustness, stability, attractor structure, and baseline dynamical expectations. Revisiting 122 published Boolean gene regulatory network models, we show that function-uniform null models reveal a substantially stronger enrichment of low-sensitivity canalizing architectures than previously inferred. Our results demonstrate that widely used null models systematically underestimate baseline sensitivity and can therefore distort assessments of the stabilizing role of canalization in biological networks.

## Abstract

A common approach is to generate canalizing and nested canalizing functions by sampling their defining parameters uniformly at random. However, this procedure induces a non-uniform distribution over the space of distinct Boolean functions due to combinatorial multiplicity, systematically biasing random ensembles. Here, we develop efficient algorithms for uniform sampling of Boolean functions with exact and minimal canalizing depth that correct this bias.

## IIntroduction

Boolean networks are a widely used framework for modeling gene regulatory systems, where nodes represent genes and Boolean functions encode regulatory logic[15]. A central component of such analyses is the construction of appropriate null models: ensembles of Boolean functions or networks against which structural and dynamical properties can be compared. In particular, canalizing and nested canalizing functions (NCFs) have received sustained attention due to their biological relevance and their association with robustness and stability in network dynamics[6,7,14,11,17,16,19]. Random ensembles of such functions are frequently used to assess whether observed features of gene regulatory networks deviate from randomness[1,2,8,13].

Canalizing depth and canalizing layer structure constitute two frequently used statistics to quantify canalization[6,11,18].
Preserving such properties during random function generation is important for constructing biologically informed null models of Boolean gene regulatory networks.
Such ensembles allow investigators to test whether observed structural or dynamical features can be explained solely by prescribed canalization properties, or whether additional organizational principles are required.
A common approach to generating random canalizing Boolean functions with prescribed summary statistics is to sample their defining parameters (canalizing inputs, canalized outputs, and variable orderings) uniformly at random[7,8,19], implemented e.g. in the popularBoolNetpackage[21].
While this procedure produces valid functions, it generally induces a non-uniform distribution over the space of distinct Boolean functions.
The underlying reason is combinatorial: the mapping from parameterizations to Boolean functions is many-to-one, and different functions admit vastly different numbers of representations.
We show that parameter-uniform sampling systematically overrepresents structures with large canalizing layers and few total layers, and that ensembles generated in this way are biased toward low-sensitivity, highly canalizing functions.

Prior work has characterized the enumeration and stratification of canalizing functions according to layer structure and canalizing depth[4,6,12,19].
However, these results do not yield scalable algorithms for uniform random generation within specific canalizing function classes.
To address this problem, we develop efficient exact samplers for Boolean functions with fixed or minimal canalizing depth.
First, we introduce a recursive dynamic programming algorithm that samples functions with fixed canalizing depth, including NCFs, uniformly at random by assigning canalizing layer structures probabilities that exactly compensate for their combinatorial multiplicities.
Second, we extend this framework to generalkk-canalizing functions through an efficient rejection-sampling correction that ensures uniform sampling over functions with prescribed minimal canalizing depth.

Beyond providing efficient sampling algorithms, we demonstrate that the choice of sampling measure has concrete consequences for commonly studied properties of Boolean functions and networks.
Under parameter-uniform sampling, NCFs exhibit an expected average sensitivity equal to one, independent of the number of variables — a value that, in classical random Boolean network theory, is associated with the boundary between ordered and chaotic dynamics[23].
In contrast, under uniform sampling over Boolean functions, we show that the expected average sensitivity increases with the number of variables and converges to a value strictly larger than one.
More generally, we find that the sampling weight of a function decays approximately exponentially with its average sensitivity, revealing a simple and robust relationship between combinatorial canalizing layer structure and dynamical behavior.
These findings imply that widely used null models systematically underestimate baseline sensitivity and overestimate the stabilizing effect of canalization in random ensembles.

At the network level, such biases propagate to conclusions about robustness, attractor structure, and the organization of dynamical states.
Because parameter-uniform sampling favors low-sensitivity, highly canalizing functions, it generates Boolean networks with systematically enhanced stability relative to function-uniform ensembles.
Consequently, comparisons between biological gene regulatory networks and parameter-uniform null models may underestimate the extent to which biological systems are enriched for stabilizing regulatory mechanisms.
By providing principled and efficient methods for uniform sampling over Boolean functions, and by quantifying the resulting shifts in key function- and network-level properties, this work establishes a foundation for more accurate and interpretable analyses of Boolean network models in systems biology.

## IIICombinatorial structure and source of sampling bias

The construction of canalizing and nested canalizing Boolean functions is typically carried out via parameterizations that specify canalizing inputs, outputs, variable orderings, and core function. While such procedures generate valid functions, they do not, in general, induce a uniform distribution over the space of distinct Boolean functions.

The underlying reason is combinatorial.
The mapping from parameter space to Boolean functions is many-to-one, and different functions admit vastly different numbers of representations.
Consequently, sampling parameters uniformly induces a non-uniform distribution over functions.

## III.2Parameter-uniform versus function-uniform sampling

- •

Parameter-uniform sampling:all parameterizations (i.e., choices of canalizing inputs,

## III.4Implications

The combinatorial multiplicity of layer structures has two immediate consequences.

First, parameter-uniform sampling induces a biased distribution over Boolean functions, favoring canalizing functions with few, large layers.
Second, correcting this bias requires assigning probabilities inversely proportional to the multiplicity of each structure.

In the following section, we develop a recursive dynamic programming scheme that implements this correction efficiently, avoiding the need to explicitly enumerate all layer structures or solve linear systems that grow exponentially in the number of input variables.

## IVUniform sampling algorithms

We now develop efficient algorithms for sampling Boolean functions uniformly at random from specific function classes.
We begin with functions with a prescribed canalizing depthkk(e.g., NCFs), for which a direct combinatorial correction suffices, and then extend the approach to anykk-canalizing functions (i.e., functions with a prescribed minimal canalizing depth) where an additional rejection sampling step becomes necessary.

## IV.1Uniform sampling of functions with exact canalizing depth

As shown in the previous section, uniform sampling over Boolean functions requires sampling layer structuresλ=(k1,…,kr)\lambda=(k_{1},\dots,k_{r})with probability proportional toω​(λ)=1/∏i=1rki!\omega(\lambda)=1/\prod_{i=1}^{r}k_{i}!.
For a given canalizing depthkk, the number of different layer structures is2k−22^{k-2}[11]. Directly enumerating all such structures is thus impractical for largekk.
Instead, we construct layer structures sequentially using a dynamic programming (DP) approach.

## VImpact of sampling bias on Boolean function and network analyses

The choice of sampling scheme has a direct and systematic impact on the properties of randomly generated Boolean functions.
Under parameter-uniform sampling, where canalizing inputs, outputs, and variable orderings are selected uniformly at random, the induced distribution over canalizing Boolean functions is biased toward layer structures with large layers and few total layers.
In contrast, uniform sampling over Boolean functions assigns probabilities inversely proportional to the number of representations of each function, thereby generating each distinct function with equal probability.
As a result, the two sampling schemes induce qualitatively different distributions over function space.

## V.1Impact on function-level properties

This bias has measurable consequences for commonly studied function-level metrics.
As a representative example, we consider the average sensitivity of NCFs, a quantity closely linked to dynamical stability and perturbation propagation[3,23].
Under parameter-uniform sampling, the expected average sensitivity of NCFs is equal to one, irrespective of the number of variables (Fig.1).
In contrast, under uniform sampling over Boolean functions, the expected average sensitivity increases with the number of variables and converges to approximately 1.183.

## V.2Impact on Boolean network dynamics

Differences in the distribution of sampled Boolean functions propagate to the level of Boolean networks, where ensembles of functions are commonly used to define random network models and baseline ensembles for dynamical analyses.
Many network-level properties, including robustness to perturbations, attractor structure, and the relative stability of attractor and basin states, depend sensitively on the distribution of underlying Boolean functions.
Because parameter-uniform sampling favors low-sensitivity, highly canalizing functions, it generates Boolean networks with systematically different dynamical properties than function-uniform sampling.

To quantify these effects, we generated random Boolean networks composed exclusively of NCFs — the predominant type of regulatory update rule observed in published biological Boolean network models[8]— sampled under either function-uniform or parameter-uniform sampling.

## VIConclusion

Our findings highlight that the construction of null models is not merely a technical detail but a central component of Boolean network analysis.
Different sampling schemes correspond to different implicit assumptions about the underlying distribution over functions, and these assumptions can materially affect both quantitative estimates and qualitative conclusions.
For studies that aim to assess whether observed network properties deviate from randomness, uniform sampling over Boolean functions provides a principled baseline that avoids biases introduced by representational multiplicity.
In contrast, sampling uniformly over parameterizations reflects a specific generative model and should be interpreted accordingly.
Recognizing and accounting for this distinction is essential for the accurate analysis and interpretation of Boolean models of biological systems.

## Appendix BThe Weight Function and the Uniform Sampling Algorithm

As mentioned in the main paper, there are two distinct ways to samplekk-canalizing Boolean functions.
In parameter-uniform sampling, all parameterizations — that is, all choices of canalizing inputs, canalized outputs, variable orderings, and core function — are chosen with equal probability.
The goal of function-uniform sampling, our contribution here, is to generate all distinct Boolean functions with equal probability. As shown above and in the main text, different layer structures correspond to different numbers of distinct canalizing Boolean functions: layer structures with many small layers correspond to more distinct functions. The layer structureλ=(k1,…,kr)\lambda=(k_{1},\ldots,k_{r})of akk-canalizing Boolean function is completely determined by the canalized output valuesb1,…,bkb_{1},\ldots,b_{k}[11]. Thus, to achieve function-uniform sampling, we can chooseb1b_{1}uniformly at random but need to identify sampling probabilitiesℙ​(bi=bi−1)\mathbb{P}(b_{i}=b_{i-1})that correctly compensate for the
combinatorial multiplicities of the layer structures. To achieve this, we developed a dynamic programming (DP) algorithm that identifies the correct sampling probabilities and enables function-uniform sampling of all Boolean functions onnninputs with exact canalizing depthkk.

## Appendix FSampling k-canalizing functions uniformly at random

The DP algorithm yields a canalizing layer structureλ=(k1,…,kr)\lambda=(k_{1},\ldots,k_{r})for thekkcanalizing variables. That is,k1+⋯+kr=kk_{1}+\cdots+k_{r}=k.

Whenk<nk<n, the remainingn−kn-kvariables define a core function that is only evaluated when all canalizing variables receive their respective non-canalizing input values. If the goal is to sample uniformly from all Boolean functions withexactcanalizing depthkk, we can simply draw the core function uniformly at random from the set of all non-canalizing functions inn−kn-kvariables, using rejection sampling (note that functions with exact canalizing depthk=n−1k=n-1do not exist, since a Boolean function with a single-variable core necessarily has canalizing depthnn). This is efficient because the probability that a function is canalizing decreases exponentially as the number of inputs increase[6,8].

However, if the goal is to sample uniformly from all Boolean functions with canalizing depthat leastkk(i.e., from allkk-canalizing functions), then the core function itself may be canalizing.
