## Abstract

This article introduces a new implementation for computing anumerical irreducible decompositionfor a system of polynomial equations. The implementation is part of the software packageHomotopyContinuation.jl[6]written in the programming languageJulia[4].

Keywords:homotopy continuation, numerical algebraic geometry.

## 1Introduction

Consider a system of polynomials with complex coefficientsF​(x)=(f1​(x)⋮fk​(x)),x=(x1,…,xn).F(x)\ =\ \begin{pmatrix}\;f_{1}(x)\;\;\\
\vdots\\

## 2Witness sets

In NID irreducible components are encoded bywitness sets.N=nid(F)computes a list of witness sets – one for each irreducible component.witness_sets(N)returns a dictionary containing these witness sets.

In this section, we give a brief introduction to witness sets. For more details see[3,22].

Recall that a varietyXXis irreducible if every decompositionX=X′∪X′′X=X^{\prime}\cup X^{\prime\prime}into varietiesX′X^{\prime}andX′′X^{\prime\prime}implies thatX=X′X=X^{\prime}orX=X′′X=X^{\prime\prime}.

## Remark 2.5.

The implementation is restricted to reduced witness sets. Non-reduced components are discarded. If the Jacobian is rank-deficient at a pointxx, predictor-corrector methods in homotopy continuation fail atxx. Therefore, neitheruu-regeneration nor monodromy decomposition can handle multiplicities, because they both take witness points as starting points for homotopy continuation. A numerical treatment of non-reduced structure would require numerical primary decomposition[13,7,17], which is beyond the scope of this article.

Irreducibility of witness sets may not be known at construction time. When we only compute the witness pointsP=X∩LP=X\cap L, we do not know whetherPPrepresents an irreducible variety or not. We have this information only after we have run the decomposition step (Section5.2).
InHomotopyContinuation.jleach witness set records whether it has been verified to be irreducible.

## 3uu-regeneration

The implementation ofnidis based on an algorithm calleduu-regeneration, which was introduced in[8]. Regeneration is the name for a class ofequation-by-equationsolvers. Instead of solving a system of polynomials directly, we successively intersect witness sets with hypersurfaces. Compared to directly solving the full system this can significantly reduce the number of paths that need to be tracked, especially when a system of equations has components in multiple dimensions.

## 4Moving linear spaces

In theuu-intersection step, in membership testing[22]and in the monodromy decomposition algorithm we move linear spaces. The implementation inHomotopyContinuation.jlis based on geodesics in the Grassmannian. This section explains the theoretical background.

Recall from (2.1) the definition of the affine GrassmannianGaff​(j,n)G_{\mathrm{aff}}(j,n). In our implementation we are dealing with so-calledslice systems.

## Definition 4.1(Slice systems).

Consider a system of polynomialsF​(x)F(x)and an affine linear spaceL∈Gaff​(j,n)L\in G_{\mathrm{aff}}(j,n). We define theslice system(F,L)(F,L).
- (1)

The slice system consists of two specific families of polynomial systems:
- •

theintrinsic systemsF​(A​v+b)F(Av+b), whereL={A​v+b∣v∈ℂj}L=\{Av+b\mid v\in\mathbb{C}^{j}\};

Since the representation ofLLas the image or the kernel of a matrix is not unique, we get a family of systems for each bullet point.
- (2)

When we say that we solve the slice system(F,L)(F,L)it means that depending on the context we pick one of the intrinsic systems or one of the extrinsic systems in(F,L)(F,L)and compute its zeros.

Homotopy paths between slice systems inHomotopyContinuation.jluse geodesics in thelinear GrassmannianG​(j,n)={ℒ⊂ℂn∣ℒ​is linear of dimension​j}.G(j,n)=\{\mathcal{L}\subset\mathbb{C}^{n}\mid\mathcal{L}\text{ is linear of dimension }j\}.

The stress test for the implementation of numerical irreducible decomposition is the introductory example (1.2). We ran10,00010,000sequentialnidcomputations for this system and counted how often the output deviated from the true answer (one degree-2 surface, two degree-4 curves and 8 points).
