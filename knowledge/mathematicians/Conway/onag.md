# On Numbers and Games（ONAG）核心理论

> John H. Conway 的《On Numbers and Games》（1976年）是数学史上最独特的著作之一。在这本书中，Conway 从组合博弈论出发，"自然地"发现了一个包含实数、序数和大量新数的数系——**超现实数（Surreal Numbers）**。同时，这本书建立了组合博弈论的代数基础。

---

## 1. 超现实数的构造

### 1.1 {L | R} 记法

Conway 的核心创新是一种**递归构造**。每个超现实数 $x$ 由两个集合定义：
$$x = \{ x^L \mid x^R \},$$
其中 $x^L$ 是"左集"（left set）中的元素，$x^R$ 是"右集"（right set）中的元素，满足：
- 所有 $x^L < $ 所有 $x^R$（左集元素都小于右集元素）；
- 左集和右集是先前已构造的超现实数集合。

**构造规则（Conway 的"构造公理"）**：
1. **构造**：若 $L, R$ 是先前构造的超现实数的集合，且 $L$ 中每个元素 $< R$ 中每个元素，则 $\{L \mid R\}$ 是一个新的超现实数。
2. **等价**：$x = \{x^L \mid x^R\}$ 和 $y = \{y^L \mid y^R\}$ 相等当且仅当 $x \leq y$ 且 $y \leq x$（其中 $\leq$ 的定义见下文）。

### 1.2 递归构造的层级

超现实数按"生日（birthday）"分层：

- **第 0 天**：$\{\mid\} = 0$（空集左右，即零）。
- **第 1 天**：
  - $\{0 \mid \} = 1$（左集含 0，右集空）；
  - $\{ \mid 0\} = -1$（左集空，右集含 0）。
- **第 2 天**：
  - $\{1 \mid \} = 2$；
  - $\{0 \mid 1\} = \frac{1}{2}$（最简的"中间值"）；
  - $\{-1 \mid 0\} = -\frac{1}{2}$；
  - $\{ \mid -1\} = -2$；
  - $\{-1 \mid 1\} = 0$（但这与第 0 天的 0 相等，不是新数）。
- **第 3 天**：产生 $3, \frac{3}{2}, 1, \frac{3}{4}, \frac{1}{4}, -\frac{1}{4}, -\frac{3}{4}, -1, -\frac{3}{2}, -3$ 等。

**关键原则**：每个超现实数是"最简"的——在所有满足左集 $<$ 右集条件的数中，选择生日最早的。

### 1.3 序的定义

**定义**：$x \leq y$ 当且仅当：
- 不存在 $x^L \in x^L$ 使得 $y \leq x^L$（即 $y$ 不小于等于 $x$ 的任何左选项），且
- 不存在 $y^R \in y^R$ 使得 $y^R \leq x$（即 $x$ 不小于等于 $y$ 的任何右选项）。

$x < y$ 定义为 $x \leq y$ 且 $y \not\leq x$。

$x = y$ 定义为 $x \leq y$ 且 $y \leq x$。

### 1.4 加法和乘法的定义

**加法**：
$$x + y = \{ x^L + y,\, x + y^L \mid x^R + y,\, x + y^R \}.$$

**加法逆元**：
$$-x = \{ -x^R \mid -x^L \}.$$

**乘法**：
$$x \cdot y = \{ x^L y + x y^L - x^L y^L,\, x^R y + x y^R - x^R y^R \mid x^L y + x y^R - x^L y^R,\, x^R y + x y^L - x^R y^L \}.$$

**乘法逆元**：定义更复杂，但存在。

## 2. 超现实数的代数结构

### 2.1 全序域

**定理（Conway）**：所有超现实数构成一个**全序域（real-closed field）**，记为 $\mathbf{No}$。

具体性质：
1. **域公理**：$(\mathbf{No}, +, \cdot)$ 满足域的所有公理（加法、乘法满足交换律、结合律，有分配律，有加法逆元和乘法逆元）。
2. **全序**：$\leq$ 是与域运算兼容的全序（$a \leq b \Rightarrow a+c \leq b+c$；$a \geq 0, b \geq 0 \Rightarrow ab \geq 0$）。
3. **实闭（real-closed）**：每个奇数次多项式有根，每个正元素有平方根。等价地，$\mathbf{No}$ 满足实数的一阶理论。

### 2.2 与实数的关系

**嵌入**：实数 $\mathbb{R}$ 自然嵌入 $\mathbf{No}$ 中。每个实数 $r$ 可以表示为：
- 若 $r$ 是二进有理数（$r = k/2^n$），则在第 $n$ 天之前被构造；
- 若 $r$ 是一般实数，则 $r = \{ r - \epsilon_n \mid r + \epsilon_n \}$，其中 $\epsilon_n \to 0$（需要无穷多天）。

更精确地，实数对应于**生日为 $\omega$（或更小）的超现实数**。

### 2.3 与序数的关系

**嵌入**：所有序数嵌入 $\mathbf{No}$ 中。序数 $\alpha$ 对应于：
$$\alpha = \{ \text{所有小于 } \alpha \text{ 的序数} \mid \} = \{ 0, 1, 2, \ldots, \alpha-1 \mid \}.$$

特别地：
- $\omega = \{0, 1, 2, 3, \ldots \mid \}$（所有自然数在左，右空）；
- $\omega + 1 = \{\omega \mid \}$；
- $\omega - 1 = \{0, 1, 2, \ldots \mid \omega\}$（这是一个**非序数**的超现实数！）。

**关键洞察**：$\mathbf{No}$ 包含了实数和序数，还包含它们之间的"中间物"，如 $\omega - 1$, $\sqrt{\omega}$, $1/\omega$ 等。

### 2.4 超现实数的"大小"

$\mathbf{No}$ 是一个**真类（proper class）**，而非集合。它包含：
- 所有实数；
- 所有序数；
- 无穷小量（如 $\epsilon = 1/\omega = \{0 \mid 1, 1/2, 1/4, \ldots\}$）；
- 无穷大量（如 $\omega, \omega^2, \omega^\omega$ 等）。

## 3. 博弈论基础

### 3.1 游戏作为超现实数

Conway 的关键洞察：**组合博弈**可以用与超现实数相同的 $\{L \mid R\}$ 记法表示。

**游戏**：$G = \{G^L \mid G^R\}$，其中 $G^L$ 是左方（Left）走一步后到达的游戏，$G^R$ 是右方（Right）走一步后到达的游戏。

**区别**：
- **数（Number）**：要求所有 $G^L < $ 所有 $G^R$，此时 $G$ 是一个超现实数。
- **游戏（Game）**：不要求此条件，因此游戏比数更一般。

### 3.2 游戏的分类

对于游戏 $G$，根据其结果分类：

| 类型 | 定义 | 意义 |
|------|------|------|
| $G > 0$ | 左方有必胜策略 | 左方赢 |
| $G < 0$ | 右方有必胜策略 | 右方赢 |
| $G = 0$ | 后手有必胜策略 | 后手赢 |
| $G \parallel 0$（模糊，fuzzy） | 先手有必胜策略 | 先手赢 |

### 3.3 游戏值

每个游戏 $G$ 有一个**值（value）**，是某个超现实数或"非数游戏"。

- **数的游戏**：若 $G$ 满足数条件，则 $G$ 的值就是对应的超现实数。
- **非数游戏**：如 $\{0 \mid 0\} = \ast$（star），这是**模糊**的——先手赢。

**关键定理（Conway 的简化定理）**：每个游戏可以"简化"为一个**最简形式**——删除"被支配"的选项后得到的规范表示。

### 3.4 Nim 值

**Nim 游戏**：若干堆物品，每步从一堆中取任意正数个，取到最后一个的赢。

**Bouton 定理（1901）**：Nim 位置 $(n_1, n_2, \ldots, n_k)$ 是 P-位置（后手赢）当且仅当
$$n_1 \oplus n_2 \oplus \cdots \oplus n_k = 0,$$
其中 $\oplus$ 是**按位异或（Nim 和）**。

**在 ONAG 框架中**：
- 一堆大小为 $n$ 的 Nim 对应于游戏值 $\ast n$（nimber）；
- $\ast 0 = 0$，$\ast 1 = \ast$，$\ast 2 = \{0, \ast \mid 0, \ast\}$，等等；
- Nim 和 $\ast m + \ast n = \ast(m \oplus n)$；
- $\ast n + \ast n = 0$（每个 nimber 是自己的加法逆元）。

### 3.5 关键定理

**定理（Conway）**：

1. **加法**：游戏可以相加（$G + H$ 表示两个游戏同时进行，每步选一个走），且加法满足结合律和交换律。

2. **负游戏**：$-G = \{-G^R \mid -G^L\}$（交换左右方角色）。

3. **比较**：$G \geq 0$ 当且仅当右方没有必胜策略（作为先手或后手）。

4. **简化**：每个游戏有唯一的**最简形式**（canonical form）。

## 4. 关键例子

### 4.1 基本数

| 记法 | 值 | 生日 |
|------|-----|------|
| $\{\mid\}$ | $0$ | 0 |
| $\{0\mid\}$ | $1$ | 1 |
| $\{\mid 0\}$ | $-1$ | 1 |
| $\{1\mid\}$ | $2$ | 2 |
| $\{0\mid 1\}$ | $\frac{1}{2}$ | 2 |
| $\{0\mid\frac{1}{2}\}$ | $\frac{1}{4}$ | 3 |
| $\{\frac{1}{2}\mid 1\}$ | $\frac{3}{4}$ | 3 |

### 4.2 无穷小和无穷大

| 记法 | 值 | 说明 |
|------|-----|------|
| $\{0\mid 1, \frac{1}{2}, \frac{1}{4}, \ldots\}$ | $\epsilon = 1/\omega$ | 正无穷小 |
| $\{0, 1, 2, \ldots\mid\}$ | $\omega$ | 第一无穷序数 |
| $\{\omega\mid\}$ | $\omega + 1$ | |
| $\{0, 1, 2, \ldots\mid\omega\}$ | $\omega - 1$ | 非序数 |

### 4.3 非数游戏

| 记法 | 值 | 类型 |
|------|-----|------|
| $\{0\mid 0\}$ | $\ast$（star） | 模糊（先手赢） |
| $\{0, \ast\mid 0, \ast\}$ | $\ast 2$ | 模糊 |
| $\{0\mid \ast\}$ | $\uparrow$（up） | 正（左方赢） |
| $\{\ast\mid 0\}$ | $\downarrow$（down） | 负 |
| $\{0\mid \uparrow\}$ | $\frac{1}{2}\uparrow$（半 up） | |

### 4.4 Hackenbush

**Hackenbush** 是 ONAG 中的核心例子。给定一个由边组成的"花束"图（边连接到地面，边分为左方蓝色边和右方红色边）：

- 玩家轮流切断自己颜色的边；
- 切断后，不再与地面相连的部分消失；
- 最后走的赢。

**关键**：Hackenbush 位置的值恰好是超现实数（当图是"串"时）或更一般的游戏值。

**例子**：
- 单条蓝边 = $1$；
- 单条红边 = $-1$；
- 蓝边上方接蓝边 = $2$；
- 蓝边上方接红边 = $\{0 \mid 1\} = \frac{1}{2}$；
- 蓝边上方接红边再接蓝边 = $\{0 \mid \frac{1}{2}\} = \frac{1}{4}$。

这给出了**二进有理数的自然组合解释**。

## 5. ONAG 的深远影响

### 5.1 数学统一性

ONAG 展示了惊人的数学统一性：
- **博弈论** $\to$ **数系构造**：从游戏规则自然产生数；
- **实数 + 序数**：统一在一个框架下；
- **代数 + 组合**：域运算有组合解释。

### 5.2 对各领域的影响

1. **组合博弈论**：ONAG 奠定了组合博弈论的代数基础，与 Winning Ways 一起成为该领域的奠基之作。
2. **非标准分析**：超现实数提供了非标准分析的另一种基础（与 Robinson 的超幂构造不同），包含真正的无穷小和无穷大。
3. **计算机科学**：超现实数的构造启发了**博弈树搜索**和**程序验证**中的方法。
4. **数理逻辑**：超现实数作为真类，涉及集合论的基础问题。

### 5.3 后续发展

- **Alling（1987）**：将超现实数严格化为集合论基础（使用 Grothendieck 宇宙）。
- **Ehrlich**：系统研究了超现实数与实数、序数的关系，证明了 $\mathbf{No}$ 是"最大"的全序域（在某种精确意义下）。
- **Rubinstein-Salzedo**：超现实数在分析和概率中的应用。
