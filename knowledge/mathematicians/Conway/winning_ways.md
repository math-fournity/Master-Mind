# Winning Ways for Your Mathematical Plays 核心内容

> 《Winning Ways for Your Mathematical Plays》（简称 WW）是 Elwyn Berlekamp、John Conway、Richard Guy 三人合著的经典著作（1982年初版，四卷）。与 ONAG 侧重理论不同，WW 侧重于**具体组合博弈的分析**，将 ONAG 的理论应用于大量具体游戏。WW 是组合博弈论的奠基之作。

---

## 1. 组合博弈论基础

### 1.1 组合博弈的定义

**组合博弈（Combinatorial Game）**具有以下特征：
1. **两人博弈**：左方（Left）和右方（Right）轮流走步；
2. **完全信息**：双方都知道完整博弈状态；
3. **无随机性**：没有骰子、洗牌等随机元素；
4. **有限性**：博弈必须在有限步内结束（通常通过"无重复位置"或"单调递减"保证）；
5. **正常玩法（normal play）**：最后走的赢（无法走的人输）。（WW 也讨论了**misère 玩法**——最后走的输——但更复杂。）

### 1.2 游戏的递归定义

与 ONAG 一致，游戏 $G = \{G^L \mid G^R\}$，其中：
- $G^L$：左方走一步后所有可能的后续游戏集合；
- $G^R$：右方走一步后所有可能的后续游戏集合。

**终止条件**：$\{\mid\} = 0$ 是终止游戏（无人可走），当前玩家输。

### 1.3 游戏的加法

**定义**：$G + H$ 表示同时进行 $G$ 和 $H$，每步选择其中一个游戏走一步：
$$G + H = \{G^L + H,\, G + H^L \mid G^R + H,\, G + H^R\}.$$

**关键性质**：
- 加法满足**结合律**和**交换律**；
- $G + 0 = G$；
- $-G = \{-G^R \mid -G^L\}$（交换左右角色）；
- $G + (-G) = 0$（不一定！只有当 $G$ 是数时才成立。一般 $G + (-G)$ 是"第二玩家赢"，即值为 0，但形式不一定为 $\{\mid\}$）。

### 1.4 游戏的等价

**定义**：$G = H$ 当且仅当 $G - H = 0$（即 $G + (-H)$ 是第二玩家赢的游戏）。

**等价类**构成一个**Abel 群**（游戏的值群），记为 $\mathcal{G}$。

## 2. Sprague-Grundy 定理

### 2.1 定理陈述

**Sprague-Grundy 定理（1935, 1939）**：每个**公平（impartial）**组合博弈（即双方可走的步相同）等价于一个 Nim 堆。

更精确地：每个有限 impartial 游戏的值是一个 **nimber** $\ast n$，其中 $n$ 是该位置的 **Grundy 值（nim 值）**。

### 2.2 Grundy 值的计算

**定义**：位置 $P$ 的 Grundy 值 $\mathcal{G}(P)$ 递归定义为：
$$\mathcal{G}(P) = \text{mex}\{\mathcal{G}(Q) : Q \text{ 是 } P \text{ 的后继位置}\},$$
其中 $\text{mex}(S)$ 是不在集合 $S$ 中的最小非负整数（minimum excludant）。

**性质**：
- $\mathcal{G}(P) = 0$ 当且仅当 $P$ 是 P-位置（前手输，后手赢）；
- 若 $P$ 的后继的 Grundy 值为 $\{0, 1, 3\}$，则 $\mathcal{G}(P) = \text{mex}\{0,1,3\} = 2$。

### 2.3 Nim 和

**Nim 和** $\oplus$ 是按位异或（二进制下不进位加法）：
$$3 \oplus 5 = 011_2 \oplus 101_2 = 110_2 = 6.$$

**Bouton 定理**：Nim 位置 $(n_1, \ldots, n_k)$ 的 Grundy 值为 $n_1 \oplus \cdots \oplus n_k$，是 P-位置当且仅当此值为 0。

### 2.4 Sprague-Grundy 定理的推广

**和的 Grundy 值**：若 $G$ 和 $H$ 是 impartial 游戏，则
$$\mathcal{G}(G + H) = \mathcal{G}(G) \oplus \mathcal{G}(H).$$

**WW 的贡献**：WW 将此定理置于 ONAG 的框架中，展示了 nimber $\ast n$ 就是游戏 $\{0, \ast, \ast 2, \ldots, \ast(n-1) \mid 0, \ast, \ast 2, \ldots, \ast(n-1)\}$，且 $\ast m + \ast n = \ast(m \oplus n)$。

## 3. 具体游戏分析

### 3.1 Nim

**规则**：$k$ 堆物品，每步从一堆中取任意正数个，取到最后一个的赢。

**分析**：
- 位置 $(n_1, \ldots, n_k)$ 的值为 $\ast(n_1 \oplus \cdots \oplus n_k)$；
- P-位置（后手赢）：Nim 和为 0；
- 策略：找到使 Nim 和变为 0 的走法。

### 3.2 Hackenbush

**规则**：一个"花束"图，边连接到地面（底线）。边分为蓝色（左方）和红色（右方）。玩家切断自己颜色的边，切断后不与地面相连的部分消失。最后走的赢。

**分析**：
- **串 Hackenbush（stalk Hackenbush）**：值为超现实数。例如：
  - 蓝边 = $1$，红边 = $-1$；
  - 蓝-红串 = $\{0 \mid 1\} = \frac{1}{2}$；
  - 蓝-红-蓝串 = $\{0 \mid \frac{1}{2}\} = \frac{1}{4}$。
- **森林 Hackenbush**：多个串的和，值为各串值之和。
- **带绿边的 Hackenbush**：绿边双方都可切，引入 nimber 成分。

**关键洞察**：Hackenbush 是理解超现实数的**最佳直观模型**——每个串的值恰好对应一个超现实数，且"最简形式"原则有直接的图论解释。

### 3.3 Blue-Red Hackenbush 与数的对应

| Hackenbush 串 | 值 | 说明 |
|---|---|---|
| 蓝 | $1$ | 左方走一步赢 |
| 红 | $-1$ | 右方走一步赢 |
| 蓝-蓝 | $2$ | |
| 蓝-红 | $\frac{1}{2}$ | 左方优势但不如 $1$ |
| 红-蓝 | $-\frac{1}{2}$ | |
| 蓝-红-蓝 | $\frac{1}{4}$ | |
| 蓝-红-红 | $\frac{1}{8}$ | |

### 3.4 其他经典游戏

**Toads and Frogs（蟾蜍与青蛙）**：
- 棋盘上的蟾蜍（左方）向右走，青蛙（右方）向左走；
- 可走一步或跳过对方；
- WW 中详细分析了此游戏，展示了**非数游戏值**的出现。

**Domineering（多米诺骨牌）**：
- 在网格上放 $1 \times 2$ 骨牌；
- 左方竖放，右方横放；
- WW 分析了小棋盘上的值，展示了分数和非数值的混合。

**Kayles**：
- 保龄球瓶排成行，每步可击倒一个或相邻两个；
- impartial 游戏，Grundy 值有周期性模式。

**Col**：
- 在图上着色，每步将一个无色顶点染成自己颜色，相邻不能同色；
- WW 中分析了 Col 的值。

**Snort**：
- Col 的"敌对"版本——相邻必须同色（或不能异色）。

## 4. 冷游戏 vs 热游戏

### 4.1 定义

**冷游戏（Cold Game）**：游戏 $G$ 是**数（number）**——即所有左选项 $<$ 所有右选项。冷游戏中，**双方都不想走**（走会使自己的位置变差）。

**热游戏（Hot Game）**：游戏 $G$ 不是数——至少一方想走。热游戏中，**至少一方急于走**。

**温度（Temperature）**：衡量游戏"热度"的量。$G$ 的温度 $t(G)$ 是双方"争先"的激烈程度。

### 4.2 冷游戏

**性质**：
- 若 $G = x$ 是数，则 $G$ 是冷的；
- 冷游戏的和是冷的：$x + y$ 是数；
- 冷游戏中，**先走不利**——双方都希望对方先走。

**策略**：在冷博弈中，最优策略是"等待"——让对方先走。最终结果由各游戏值的和决定。

### 4.3 热游戏

**性质**：
- 热游戏中至少一方有"先手优势"；
- 温度 $t(G) > 0$ 表示游戏是热的。

**左停止值（Left stop）**和**右停止值（Right stop）**：
- $L(G)$：左方先走时，双方最优对弈的结果值；
- $R(G)$：右方先走时的结果值；
- 若 $L(G) > R(G)$，则 $G$ 是热的。

**温度**：$t(G) = \frac{L(G) - R(G)}{2}$（简化定义，实际更复杂）。

### 4.4 热博弈的策略

**降温（Cooling）**：将热游戏 $G$ "降温"温度 $t$ 得到 $G_t$，是更"冷"的游戏。

**定理**：存在临界温度 $t^*$，使得 $G_{t^*}$ 变为数（冷游戏）。此 $t^*$ 就是 $G$ 的温度。

**策略**：
1. 计算各子游戏的温度；
2. **最热优先**：先在温度最高的游戏中走；
3. 在温度相同的游戏中，选择"最有利"的。

### 4.5 WW 中的温度理论

WW 系统发展了**温度理论（thermography）**：
- **热图（Thermograph）**：绘制游戏值随温度变化的图；
- **Mean 值**：$G$ 的"平均"值（降温到无穷大的极限）；
- **温度**：$G$ 的"激烈程度"。

这套理论给出了**热博弈的近似最优策略**——虽然精确策略可能复杂，但温度理论提供了实用的指导。

## 5. Misère 玩法

### 5.1 定义

**Misère 玩法**：最后走的**输**（而非赢）。

Misère 组合博弈比正常玩法**困难得多**：
- Sprague-Grundy 定理**不直接适用**；
- 游戏的值不形成简单的群结构。

### 5.2 Misère Nim

**Misère Nim 的策略**（Bouton, 1901）：
- 当所有堆大小 $\leq 1$ 时：P-位置是堆数为奇数（与正常玩法相反）；
- 当存在大小 $\geq 2$ 的堆时：P-位置仍是 Nim 和为 0（与正常玩法相同）。

### 5.3 WW 的贡献

WW 系统讨论了 misère 玩法，但承认其理论远不如正常玩法完整。后续 **Plambeck（2005）** 的 **misère quotient** 理论部分弥补了这一缺陷。

## 6. WW 的影响与遗产

### 6.1 组合博弈论的建立

WW 与 ONAG 一起，将组合博弈论从零散的游戏分析提升为**系统的数学理论**：
- 建立了游戏的代数结构（群、序）；
- 提供了分析任意组合博弈的通用方法；
- 引入了温度理论等实用工具。

### 6.2 对计算机科学的影响

- **博弈树搜索**：WW 的理论影响了人工智能中的博弈算法；
- **组合博弈软件**：基于 WW 理论的程序（如 CGSuite）可以分析复杂游戏。

### 6.3 对数学教育的影响

WW 以大量具体、有趣的游戏为例，使组合博弈论成为**数学教育的优秀载体**——既有深刻理论，又有直观实例。
