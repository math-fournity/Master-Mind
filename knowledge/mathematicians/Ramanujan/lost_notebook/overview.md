# Ramanujan 遗失笔记本概览

## 发现历史

Ramanujan 的"遗失笔记本"(The Lost Notebook) 是 20 世纪数学史上最戏剧性的发现之一。

### 时间线

| 年份 | 事件 |
|------|------|
| 1919–1920 | Ramanujan 在印度马德拉斯（今金奈）的最后岁月写成此笔记，期间他给 Hardy 写了最后一封信（1919年1月12日），其中首次公开了 mock theta 函数 |
| 1920年4月26日 | Ramanujan 去世，年仅 32 岁 |
| 1920s–1930s | 笔记的副本/原件在 Hardy 的遗物中辗转，最终存入剑桥 Trinity College 的 Wren Library |
| 1976年 | **George E. Andrews** 在 Trinity College 查阅 Hardy 遗稿时，发现了一份约 100 页的手稿，其中包含 Ramanujan 最后一年（1919–1920）的大量未发表成果 |
| 1978年 | Andrews 在 *Notices of the AMS* 上公开宣布此发现，引起轰动 |
| 1988年 | Narosa 出版社出版影印版 *Ramanujan's Lost Notebook and Other Unpublished Papers* |
| 2005–2018 | Andrews 和 Berndt 出版 *Ramanujan's Lost Notebook* 五卷本（Springer），系统整理和验证全部内容 |

### Andrews 的发现经过

1976年春天，Andrews 在剑桥参加学术会议期间，到 Trinity College 的 Wren Library 查阅 Hardy 的遗稿。在一份标注为 "Ramanujan's unpublished manuscript" 的文件中，他发现了约 100 页的 Ramanujan 手稿，内容涵盖 mock theta 函数、q-级数、连分数、分拆函数等。这份手稿后来被称为"遗失笔记本"。

Andrews 后来回忆说，当他翻阅这些手稿时，意识到自己正在看的是 Ramanujan 最后一年——也就是他发现 mock theta 函数那一年——的工作记录。这些内容在 Ramanujan 去世后近 60 年间几乎无人系统研究。

## 内容概述

### 规模

- **总条目数**：约 600 条公式、恒等式和猜想
- **页数**：约 100 页手稿
- **时间跨度**：1919–1920 年（Ramanujan 最后一年）

### 主要内容分类

#### 1. Mock Theta 函数（核心内容）

遗失笔记本最重要的内容是 **mock theta 函数** 的系统定义和研究。Ramanujan 在最后给 Hardy 的信中列出了 17 个 mock theta 函数（4 个 3 阶、10 个 5 阶、3 个 7 阶），但在遗失笔记本中，他给出了更多细节：

- 17 个原始 mock theta 函数的详细定义
- mock theta 函数之间的关系式
- mock theta 函数与 theta 函数的线性组合给出模形式
- 偶数阶 mock theta 函数（6, 8, 10 阶）的雏形
- mock theta 函数在单位根处的行为

#### 2. q-级数恒等式

大量新的 q-级数恒等式，包括：

- Rogers-Ramanujan 类型恒等式的推广
- 新的 Bailey 对
- 双和恒等式
- 与 mock theta 函数相关的 q-级数变换

#### 3. 分拆函数

- 分拆函数的新同余式
- crank 的暗示性描述
- 分拆函数的精确公式和渐近展开
- 与 mock theta 函数相关的分拆枚举

#### 4. 连分数

- Rogers-Ramanujan 连分数的新性质
- 其他连分数的变换公式
- 连分数在单位根处的值

#### 5. 模方程

- 高阶模方程
- 模方程与 $\pi$ 级数的关系
- 椭圆函数的变换

#### 6. 其他

- $\theta$ 函数恒等式
- 超几何级数
- 数值恒等式和近似公式

### 遗失笔记本与三本笔记的关系

| 特征 | 三本笔记 (1903–1914) | 遗失笔记本 (1919–1920) |
|------|----------------------|------------------------|
| 时间 | 赴英前，印度独立工作 | 回印度后，最后一年 |
| 成熟度 | 早期到成熟期 | 最成熟期 |
| 核心创新 | q-级数、分拆、模方程 | Mock theta 函数 |
| 证明 | 几乎无证明 | 几乎无证明，但更多暗示 |
| 发现 | 一直在印度 | 1976年才在剑桥发现 |

### 遗失笔记本的独特价值

1. **Mock theta 函数的诞生地**：这是 Ramanujan 发现和系统研究 mock theta 函数的唯一原始记录。
2. **最后的思想**：反映了 Ramanujan 在生命最后几个月的数学思考，许多结果超越了当时的数学发展水平数十年。
3. **启发未来**：遗失笔记本中的许多结果直到 21 世纪才被理解和证明，推动了 mock 模形式理论的发展。
