# 2018年菲尔兹奖得主及其工作

> 2018年国际数学家大会（ICM）在巴西里约热内卢举行。四位菲尔兹奖得主为：Caucher Birkar、Alessio Figalli、Peter Scholze、Akshay Venkatesh。

---

## 1. Caucher Birkar（1978– ）

**机构**：剑桥大学

**颁奖理由**：对最小模型纲领（MMP）和 Fano 簇的丰富性的深刻贡献。

### 1.1 研究领域概述

Birkar 的工作核心在**双有理几何（birational geometry）**，特别是高维代数簇的最小模型纲领（Minimal Model Program, MMP）。MMP 的目标是：给定一个代数簇，通过一系列"收缩"和"翻转（flip）"操作，将其化简为一个"最简"形式——最小模型或 Mori 纤维空间。

### 1.2 Fano 簇的丰富性

**Fano 簇**：满足 $-K_X$ 为丰沛（ample）的代数簇，是代数几何中最基本的三类（Fano、Calabi-Yau、一般型）之一。

**核心问题**：Fano 簇是否"有界"？即，在固定维数下，是否只有"有限多种"Fano 簇（模掉形变）？

**Birkar 的贡献**：

1. **与 Cascini, Hacon, McKernan 合作（2010）**：证明了**一般型簇的最小模型的存在性**（在维数任意时，条件性地依赖于翻转的终止性）。这是 MMP 的重大突破。

2. **Birkar（2016）**：证明了**光滑 Fano 簇的有界性**（在固定维数下，Fano 簇的"复杂度"有界）。更精确地：
   - 定义 Fano 簇的"丰富性（b-regularity）"；
   - 证明了固定维数下丰富性有界的 Fano 簇只有有限多个形变族。

3. **Fano 簇的奇点**：Birkar 系统研究了**有奇点的 Fano 簇**（klt 奇点），证明了这类簇的体（volume）有下界，这是 Fano 簇分类的关键步骤。

### 1.3 方法论

Birkar 的方法核心在于**MMP 技术的精细化**，特别是：
- **翻转（flip）和除子式收缩（divisorial contraction）**的构造；
- **奇点理论**（klt, plt, lc 奇点的性质）；
- **典范除子的正性**与 Fano 条件的相互作用。

## 2. Alessio Figalli（1984– ）

**机构**：苏黎世联邦理工学院（ETH Zürich）

**颁奖理由**：对 Monge-Ampère 方程、最优传输理论和及其应用的深刻贡献。

### 2.1 研究领域概述

Figalli 的工作横跨**偏微分方程、最优传输理论和几何不等式**。最优传输理论起源于 Monge 问题：如何以最小代价将一个质量分布运输到另一个？

### 2.2 Monge-Ampère 方程

Monge-Ampère 方程
$$\det(D^2 u) = f$$
是非线性椭圆方程中最重要的一类，与最优传输理论密切相关（Brenier 映射的梯度满足 Monge-Ampère 方程）。

**Figalli 的贡献**：

1. **Monge-Ampère 方程的正则性**：与 De Philippis, Schmidt 合作，研究了 Monge-Ampère 方程解的**二阶导数的正则性**，证明了在一般源项下解的 $W^{2,1}$ 正则性。

2. **最优传输映射的正则性**：研究了 Brenier 最优传输映射 $T = \nabla u$ 的正则性，特别是在目标测度不光滑时的情形。

### 2.3 几何不等式与稳定性

Figalli 在**几何不等式的稳定性（stability）**方面有重要贡献：

- **等周不等式的稳定性**：与 Fusco, Maggi, Pratelli 合作，证明了等周不等式的**定量稳定性**——如果一个集合的等周亏差很小，则它接近一个球（在 Fraenkel 偏差意义下）。Figalli 进一步改进了定量界。

- **Alexandrov-Fenchel 不等式的稳定性**：与 Mogilner 合作。

### 2.4 随机矩阵与自由概率

Figalli 还在**随机矩阵理论**中做出贡献：
- 与 Guionnet 合作，研究了**非交换最优传输**和自由概率中的传输问题；
- **非交换 Monge-Ampère 方程**。

### 2.5 应用

Figalli 的工作有广泛的应用：
- **经济学**：匹配理论中的最优传输；
- **气象学**：半地转方程（semigeostrophic equations）；
- **图像处理**：基于传输的图像配准。

## 3. Peter Scholze（1987– ）

**机构**：波恩大学 / 马普学会数学研究所

**颁奖理由**：将 p-adic 几何引入代数几何和表示论的工具，特别是完美空间（perfectoid spaces）的发明。

### 3.1 研究领域概述

Scholze 的核心贡献是**完美空间（perfectoid spaces）**理论的创立，这是一种全新的 $p$-adic 几何框架，解决了 $p$-adic Hodge 理论中的根本困难。

### 3.2 完美空间

**动机**：$p$-adic Hodge 理论研究 $p$-adic 域上的 Galois 表示与代数几何对象（如 $p$-divisible 群、étale 上同调）之间的关系。Fontaine 等人提出了各种"周期环"（$B_{\text{dR}}, B_{\text{crys}}, B_{\text{st}}$ 等）来分类这些表示，但理论极其复杂。

**Scholze 的洞察**：在 $p$-adic 几何中，有一种"倾斜（tilt）"操作：对于完美域 $K$（完备非阿基米德域，满足 Frobenius 自同构在 $K^\circ/p$ 上满射），可以构造其**倾斜** $K^\flat$，使得 $K^\flat$ 是特征 $p$ 的完美域，且 $K$ 和 $K^\flat$ 的拓扑结构密切相关。

**完美空间**：Scholze 将此推广到空间层面：
- 定义了**完美代数（perfectoid algebra）**和**完美空间（perfectoid space）**；
- 建立了**倾斜等价（tilting equivalence）**：特征 0 和特征 $p$ 的完美空间范畴等价；
- 这使得可以在特征 $p$（Frobenius 自同构可用）和特征 0 之间自由切换。

### 3.3 关键应用

1. **Weight-monodromy 猜想**：Scholze 利用完美空间证明了 **de Jong 对 weight-monodromy 猜想的情形**（对于某些非 Abel 簇）。

2. **$p$-adic Hodge 理论的简化**：完美空间为 Fontaine 的 $p$-adic Hodge 理论提供了几何框架，大大简化了理论。

3. **局部 Langlands 对应**：Scholze 与 Fargues 合作，利用完美空间研究了**局部 Langlands 对应**的几何化（Fargues-Scholze 几何化）。

### 3.4 Diamond 与 Prism

- **Diamond**：Scholze 引入了"diamond"概念，作为完美空间上的"代数空间"类似物，用于处理非完美对象。

- **Prism（棱镜）**：与 Bhatt 合作，提出了**棱柱上同调（prismatic cohomology）**，这是对 $p$-adic 上同调理论的统一框架，将 crystalline、de Rham、Hodge-Tate 等各种 $p$-adic 上同调统一在一个框架下。这是继完美空间后又一重大突破。

### 3.5 凝聚数学（Condensed Mathematics）

Scholze 与 Clausen 合作提出了**凝聚数学**框架（详见 `recent_breakthroughs.md`），这是对拓扑代数结构的重新基础化。

## 4. Akshay Venkatesh（1981– ）

**机构**：普林斯顿高等研究院（IAS）/ 斯坦福大学

**颁奖理由**：综合解析数论、代数几何、拓扑和表示论的方法，解决长期悬而未决的问题。

### 4.1 研究领域概述

Venkatesh 的工作极其广泛，横跨**解析数论、自守形式、代数几何、拓扑和动力系统**。他的特点是能将不同领域的深刻工具结合起来。

### 4.2 核心贡献

1. **L-函数的亚凸性（subconvexity）**：
   - L-函数在中心点 $s = 1/2$ 的值的上界问题是解析数论的核心。凸性界给出 $L(1/2) \ll q^{1/4+\epsilon}$，亚凸性界是改进。
   - Venkatesh 在多种情形下给出了亚凸性界，特别是**高阶 L-函数**和**GL(n) L-函数**的亚凸性。

2. **等分布与量子唯一遍历（QUE）**：
   - 与 Lindenstrauss, Michel, Venkatesh 合作，研究了**负曲率流形上的量子唯一遍历**问题；
   - 证明了在算术曲面上，Laplace 算子的特征函数的 $L^2$ 质量等分布（在某些条件下）。

3. **同余计数问题**：
   - 与 Ellenberg, Westerland 合作，证明了**函数域上的同余计数**结果，将 Cohen-Lenstra 启发式与拓扑（同伦论）联系起来；
   - 具体地，研究了函数域上二次扩张的类群的分布，利用**稳定同伦论**中的工具（映射类群的作用）。

4. **子convexity 和 equidistribution 的统一**：Venkatesh 发展了一套将**周期积分**与**表示论/动力系统**结合的方法，统一了许多亚凸性和等分布结果。

### 4.3 方法论特点

Venkatesh 的工作体现了**数学统一性**：
- 将解析数论（L-函数、亚凸性）与**代数几何**（Shimura 簇）、**表示论**（自守表示）、**动力系统**（遍历理论）、**拓扑**（同伦论）结合；
- 特别擅长利用**算术群的作用**和**遍历理论**来解决数论问题。
