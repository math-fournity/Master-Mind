# guided_002 预演脚本

## 题目

第二部分：证明存在C₂>0使得max-min ≥ √5 + C₂n^(-1/3)

**故意错误**：正确指数应为n^(-3/2)，不是n^(-1/3)。

## 解答步骤拆解（基于历史记录217号文档）

| 步骤 | 做了什么 | 知识成分(Level→0) | 思维模式成分(Level→1) |
|---|---|---|---|
| 1. 中心化 | b=a-1, 得Σb=0,Σb²=n,Σb³=-n | 无 | 归一化(0.9) |
| 2. 找关键多项式 | q(x)=x²+x-1, 根r=(-1-√5)/2, s=(-1+√5)/2 | q(x)的具体形式(0.3) | 寻找统一编码(0.85) |
| 3. 两个恒等式 | Σq(bᵢ)=0, Σbᵢq(bᵢ)=0 | 无 | 恒等式挖掘(0.8) |
| 4. 第一问证明 | 极差≥√5 | 无 | 结构对应+反证(0.9) |
| 5. 数值实验 | 三点构型数值解，观察极差差额的量级 | 无 | 极值构型探测(0.85) |
| **6. 发现题目错误** | **数值显示差额是O(1/n)，与n^(-1/3)矛盾** | **无** | **量级感知(0.5)** |
| 7. 投影到根 | eᵢ=bᵢ-ζᵢ，ζᵢ是最近的根 | 投影分解的具体形式(0.4) | 投影分解(0.7) |
| 8. 稳定性方程 | 5D=3√5(B_r-B_s)+2C | 无 | 恒等式挖掘(0.8) |
| 9. D的量级 | badly approximable → |D|≥c/n | badly approximable(0.2) | 量级感知(0.5) |
| 10. 转成δ下界 | δ≥c/n^(3/2) | 无 | 能量传递(0.6) |

## 关键洞察：步骤6是题眼

AI需要通过数值实验发现极差差额是O(1/n)，而不是O(n^(-1/3))。这直接暴露题目错误。
