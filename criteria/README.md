# 性质标准与探索性隐喻

> 判断原语好坏的标准，和启发思考的想象工具。不是原语（不能执行/放置），不是概念框架（不是观察视角）——是元层面的工具。

## 为什么有这个目录

原语目录（`../primitives/`）记录构造系统的积木，概念目录（`../concepts/`）记录理解系统的视角。但还有一类东西既不是积木也不是视角：

- **性质标准**：用来判断原语是否合格的标准——"这个方法在表示变换下保持意义吗？"（自然性）
- **探索性隐喻**：用来启发思考的比喻——"数学问题是会生长的语义场"（语义场）

它们是元层面的工具——不是用来构造系统的，也不是用来理解系统的，是用来**检查和启发**的。
