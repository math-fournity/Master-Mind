# 第1步要求：格化（段划分+所有特征标注）

## 你要做的

读取 `input.md` 中的解答文本，做完整的格化——段划分+标注所有特征（常规思维特征+关键实体角色特征）。

**这是完整的格化认知**——段划分和特征标注是同一个认知过程。你可以在划段的同时考虑特征变化。

## 背景知识

### 脉络和段

**脉络**是一条解题路径上所有思维步骤的序列。我们把脉络切成最细的"段"——每段是一个不可再分的思维步骤。

**段是最细的粒度**——如果你能把一段再分成两段，就应该分。但不要分到"一句话一段"——段是"一个思维步骤"，不是"一句话"。

### FCA和Hasse图——"格"的结构

形式概念分析（FCA）提供了一种数学化描述"段和特征"关系的方法：
- **形式上下文 (G, M, I)**：G是对象集合（所有段），M是属性集合（所有段特征），I是关系矩阵
- **闭元素**：段集合A满足A''=A，则(A, A')是闭元素
- **你不需要枚举闭元素**——你只需要构造形式上下文(G,M,I)，程序会自动枚举

## V8的格化方式——跨闭元素元模式引导

V8在V7的基础上增加了"跨闭元素元模式"的引导。在格化阶段，这意味着你在标注段特征时，需要特别注意**那些可能贯穿多个闭元素的关键变量/技巧/策略**。

### 段划分的原则

- 最细粒度——如果能再分就应该分
- 每段是一个"思维步骤"，不是"一句话"
- **如果某段中关键实体的角色变化了，可以因此把段分得更细**——这是V8的特色

### 标注两类特征

对每个段，标注两类特征：

**1. 常规思维特征**——如"排序"、"定义变量"、"归纳假设"、"鸽巢论证"、"情况分析"、"构造性证明"、"反证法"、"WLOG归约"等。特征是思维特征，不是操作内容。

**2. 关键实体角色特征**——关键实体是证明中贯穿多个段的变量/技巧/策略。对每个段，标注关键实体在这个段中的角色：
- 如果某段使用了关键变量x，标注"x的使用"
- 如果某段使用了aₙ的最大性，标注"aₙ的最大性"
- 如果某段使用了swap技巧，标注"swap技巧"
- 角色特征要具体——"x的使用"太泛，"x的分类标准角色"更具体

### 特征标注原则

- 每个段可以有多个特征（常规+角色）
- 同一思维特征用同一名称（不要有时写"鸽巢论证"有时写"鸽巢原理"）
- 特征粒度适中——太粗导致特征太少，太细导致特征太多
- **关键实体的角色特征要标注**——这是V8的特色，使得形式上下文能捕获跨闭元素元模式

## 产出格式

填充 `segments.json`，格式如下：

```json
{
  "version": "V8",
  "phase": "grading",
  "step": 1,
  "segments": [
    {
      "id": "段1",
      "content": "这段在做什么（简述）",
      "features": ["排序", "WLOG归约", "x的使用"]
    },
    {
      "id": "段2",
      "content": "这段在做什么（简述）",
      "features": ["定义变量", "x的使用", "aₙ的使用"]
    }
  ]
}
```

**features包含常规思维特征和关键实体角色特征**——两类特征都在同一个features数组中。

## 完成后

填充完 `segments.json` 后，创建 `step1_done.md`（空文件）作为完成标记。
