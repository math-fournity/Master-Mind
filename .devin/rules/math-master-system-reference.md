# math-master-system-reference rule

当任务涉及以下场景时，加载 `math-master-system-reference` skill：

- 操作数学大师系统：七步骤工作流、依赖图导入、arXiv查询、G'_topo生成、TopologyVerifier、三层提取、数学意识节点
- 参考星学项目的方法论证据链、POC验证方案、知识系统结构
- 查种子推荐表（数学问题类型→推荐意识种子映射）
- 执行认知图查询与审计命令
- 了解方法论的认识论位置（与专家系统/LLM/RAG/CoT的区别）

skill 中包含：星学参考索引（63-107号文档索引）、数学大师系统技术说明、种子推荐表、认知图查询命令、认识论位置表。
