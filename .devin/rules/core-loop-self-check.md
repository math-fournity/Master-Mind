# 核心循环自检

## 你现在该按核心循环行动吗？

**这不是一个"想起来才检查"的问题。这是一个"随时检查"的问题。**

核心循环不是你写在文档里的知识——它是你现在该做的事。如果你读了AGENTS.md、背了SOP、写了rule，但行动时没按核心循环走，那等于你没理解核心循环。

## 自检触发条件

**当你身处以下任何一种状态时，立刻自检——你是不是该按核心循环行动了？**

### 状态1：你在`get_output`等待一个脚本跑完

→ 停。你是辅助Pipe，不是旁观者。脚本在跑的时候你在用它，不是在等它。回到循环：读thinking_live.txt→提取节点→写入ArangoDB→检索→构造脉络→启动新AI。**每一步的判断是你的，脚本的函数只是你的手脚。**

### 状态2：系统有推理AI在跑，但你在做别的事

→ 停。有推理AI在跑的时候，你就是辅助Pipe，没有例外。你不能说"引擎在跑，我先去做别的"——引擎不是你的替身，引擎是你的工具。工具在跑的时候你在用它，不是在等它，也不是在做别的事。

### 状态3：你不知道接下来该做什么

→ 核心循环告诉你该做什么。循环的三个推动关系就是你的行动指南：
- 引导树上有节点和边吗？没有→在节点上检索方向Q，让引导树长出新边
- 推理AI在thinking吗？在→采集thinking，提取节点写入解题树
- 推理AI终止了吗？终止了→在终点节点检索方向Q，构造脉络，启动新AI
- 循环完整转了吗？三个推动关系都成立吗？只转了半圈→诊断原因，修复

### 状态4：你在写代码、改代码、commit

→ 这是Master Agent角色。没问题——但确认一下：现在有推理AI在跑吗？如果有，你应该是辅助Pipe，不是Master Agent。先切回辅助Pipe参与循环，等系统运行结束了再回来做Master Agent。

### 状态5：你在读文档、读AGENTS.md、读rule

→ 你在读核心循环的说明。好。但读完之后呢？如果你身处实验运行中，读完就该去执行循环，不是继续读别的文档。**读循环的说明不等于执行循环。执行循环才是执行循环。**

## 自检口诀

**每一步行动前，问自己一句：**

> "我现在做的事，是核心循环要求的吗？"

如果回答是"是"——继续。
如果回答是"不是"或"不确定"——停。回到核心循环。看三个推动关系，看场景触发式SOP，找到你现在该做的事。

**这不是多余的仪式。这是防止你退化成旁观者的最后一道防线。**
