# 三个核心问题原则

**触发条件**：设计或修改six/中任何Pipe时。
**来源文档**：314号（三个核心问题）、`six/references.py`的`CORE_PROBLEMS`

## 规则

设计或修改任何Pipe时，检查是否涉及314号定义的三个核心问题：

1. **非局部tell库缺失**——tell不只在卡点，可以在脉络上任意点或跨多节点范围（来源：303/305号）
2. **推理脉络格化**——脉络分成段后段的不同合并方式形成不同Level视图（来源：314号问题2/319号step_2_grid_vein）
3. **Tell分类学**——建立第六代Tell的分类体系（来源：313号）

如果涉及，在`six/references.py`的`CORE_PROBLEMS`中记录对应关系，在Pipe函数docstring中标注涉及哪个核心问题。
