# work-system-language rule

当任务涉及以下场景时，加载 `work-system-language` skill：

- Think in 工作系统、设计工作系统新机制
- 盘点 hook/认知图/CP 检查点能力
- 讨论"用什么语言表达工作系统思想"
- 设计动态埋点与批量反思等新机制
- 需要了解 Devin hooks、git hooks、认知图 ArangoDB、SDK 的表达能力

skill 中包含：Devin Hooks（3个）、Git Hooks（2个）、认知图 collection、CP1-CP6、SDK 方法、dev-docs 索引、表达能力总表、当前缺失的表达能力、元组 Skill 总表。
