# Tell分类学研究过程文档存放规则

**触发条件**：产生Tell分类学相关的研发过程文档时（探索性、讨论性、评审性、方案演进性内容）。

## 核心约束

1. Tell分类学相关的研发过程文档，记录到 `Tell分类学研究过程文档/` 目录，不放在 `第六代系统研发过程文档/`。
2. **每次新增文档到本目录时，必须同步更新 `Tell分类学研究过程文档/README.md` 的文档索引。** 不更新README.md索引 = 违反rule。

## 为什么要独立目录

Tell分类学研究已经从第六代系统研发中自然分化为独立的研究块（见研发轨迹拆分方案）。它有自己的探索轨迹、迭代闭环和优先级动态。独立目录让这块研究的文档自成体系，不被第六代系统研发过程文档的其他内容淹没。

## 什么放这里

- Tell分类学研究中探索性、讨论性、评审性、方案演进性的文档
- 高Level概念分类研究的设计思想记录（333-340号系列及后续）
- FCA再分析过程中的阶段性总结、问题讨论、方案修正
- Tell分类学拆分方案、优先级调整等研究管理性文档

## 什么不放这里

- 分类学本体（08号）→ `FCA学习笔记/`
- FCA再分析SOP模板和单题产出 → `FCA学习笔记/`（已有目录结构）
- 迭代审计铁律、Schema维护规则 → `.devin/rules/`
- 技术说明书内容 → `第六代系统技术说明书/`
- 第六代系统其他研发过程文档 → `第六代系统研发过程文档/`

## 编号规则

延续三位编号，从341号开始。编号格式：`NNN-v0-YYYY-MM-DD-标题.md`。

333-340号已从 `第六代系统研发过程文档/` 迁移至本目录（2026-08-10）。

## README.md索引维护

`Tell分类学研究过程文档/README.md` 是本目录的索引文档。每次新增文档时必须更新：

1. 在README.md的文档索引表中添加新文档的行（编号、文件名、核心内容）
2. 如果新文档属于某个思想链条，更新思想链条图
3. 如果新文档开启了新的研究子块，在索引中建立新的分组小节
