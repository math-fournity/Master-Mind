# 提示词原则+三处对齐同步

**触发条件**：设计或修改six/中任何Pipe函数时；新增/改进/验证提示词时。
**来源文档**：321号（提示词是核心资产）、325号（多套提示词并发）、326号（三处对齐同步）、`six/prompts.py`

## 规则

### 提示词管理

设计或修改任何Pipe函数时，考虑这个Pipe的AI需要什么提示词——在`prompts.py`的`PROMPTS`清单中记录提示词（prompt_id/pipe/版本/内容位置/验证POC/来源文档），在`第六代系统提示词积累目录/`中积累完整提示词文本（按`Pipe阶段/子pipe/set_<编号>_<描述>/v<版本>.md`+`README.md`结构）。

提示词改进时新增版本，旧版本保留。同一Pipe阶段可以有多套提示词（set_A/set_B/...），并发给AI处理，结果汇总或各自流向下一个Pipe。提示词是核心资产，和代码同等重要。

### 三处对齐同步（326号硬约束）

提示词在三个地方有记录，三处必须对齐同步：

- **A：目录**（`第六代系统提示词积累目录/`）——提示词的完整文本
- **B：代码清单**（`six/prompts.py`的`PROMPTS`）——提示词的索引
- **C：POC验证文档**（`第六代系统研发过程文档/3xx号`）——提示词的验证结果

新增/改进/验证完成时三处同步更新，prompt_id/pipe/版本/内容位置/验证POC必须一致。
