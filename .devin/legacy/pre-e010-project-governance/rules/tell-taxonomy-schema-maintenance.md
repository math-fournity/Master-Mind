# tell-taxonomy-schema-maintenance rule

## 核心铁律

**AGENTS.md中的"Tell分类学Schema"节是跨压缩边界保真的核心。分类学修正后必须同步更新该节。如果08号文件和AGENTS.md Schema节不一致，就是违反本rule。**

### 结构知识与内容知识分离铁律（336号）

**分类学Schema中维护的是结构知识（坐标轴和刻度），不是内容知识（坐标系中的点）。**

- **结构知识**（在Schema中维护）：domain定义、段结构模式定义、子模式定义（如"同构之桥"是"跨域桥接"的子模式）、高Level概念的三种解释文本索引
- **内容知识**（在tell库/hint库中维护）：具体tell条目、具体hint条目，每个条目有{domain, 段结构模式}属性和`case_source`标记

**修改结构知识等于修改分类学的维度**——影响所有使用该分类的tell，需要更高级别的审计（iteration-audit的7条铁律全部适用）。

**修改内容知识只是增删tell条目**——不影响分类学的维度，只需要常规审计。

**高Level概念（如同构之桥）是结构知识（坐标轴），不是内容知识（点）。** 高Level概念降低Level后的具体形式（如"构造Frey曲线"）才是内容知识（点）。

## 本rule与iteration-audit的关系

**本rule是`tell-taxonomy-iteration-audit`修正流程的一部分——具体是铁律7的执行细则。**

- `tell-taxonomy-iteration-audit.md`锁定整个修正流程（7条铁律）
- 铁律7说"AGENTS.md Schema节必须同步更新，具体维护SOP见本rule"
- 本rule提供Schema同步更新的具体SOP（判断→更新→验证→更新关键文件表）
- **两个rule不是平行的——本rule是iteration-audit铁律7的子流程，在iteration-audit的修正流程中被调用**

## 触发条件

当Tell分类学（`FCA学习笔记/08-先验Tell分类学.md`）发生以下任何变化时，必须同步更新AGENTS.md的"Tell分类学Schema"节：

1. **版本号变化**——v3→v4等
2. **段结构模式变化**——新增/删除/重命名/降级/升级任何段结构模式
3. **domain变化**——新增/删除/重命名任何domain
4. **结构框架变化**——属性维度的层数/层级关系变化
5. **观察Level参数变化**——"局部/非局部/全局"的定义或角色变化
6. **关键修正认知变化**——新的修正带来新的关键洞察

## 维护SOP

### 步骤1：判断是否需要更新Schema节
当08号文件发生修正时，按上面的"触发条件"判断。如果只是补充例子、修正错别字、调整格式，不需要更新Schema节。

### 步骤2：更新Schema节的具体内容
根据修正内容，更新AGENTS.md"Tell分类学Schema"节中的对应部分：

| 修正类型 | 更新Schema节的哪部分 |
|---|---|
| 版本号变化 | 版本历史摘要表追加新行 + 更新"分类学结构"中的版本标注 |
| 段结构模式变化 | "5大类段结构模式"表更新 + "分类学结构"中第二层更新 |
| domain变化 | "分类学结构"中第一层更新 |
| 结构框架变化 | "分类学结构"整体更新 |
| 观察Level参数变化 | "分类学结构"中观察Level部分更新 |
| 关键修正认知变化 | "两个关键修正认知"追加新洞察（改为"三个""四个"等） |

### 步骤3：验证一致性
更新后验证AGENTS.md Schema节与08号文件的一致性：
- 版本号一致
- 段结构模式数量和名字一致
- domain数量和名字一致
- 结构框架一致
- 关键修正认知一致

### 步骤4：更新关键文件表
如果修正涉及新文件或文件路径变化，更新Schema节中的"关键文件"表。

## 不做什么

- **不在Schema节放完整分类学**——Schema节只放最紧要的结构，完整分类学在08号文件
- **不在Schema节放形式背景表格**——形式背景在08号文件，Schema节只放结构框架
- **不在Schema节放具体tell列举**——具体tell在08号文件的第三层，Schema节只放5大类模式的名字和一句话定义
- **不跳过同步更新**——08号文件修正后必须同步更新Schema节，不能"先改08号，Schema节以后再说"
- **不让Schema节和08号文件不一致**——如果发现不一致，立即修正使其一致
