### 原语：三层知识分层（L1/L2/L3）
- **ID**：105-P1
- **类型**：结构原语
- **描述**：将数学解题经验分为三个抽象层次——L1（具体解法路径）、L2（思维模式）、L3（范式思维），每层比下层更抽象、更可跨题复用。
- **溯源**：105-大师-POC-3验证方案.md, 第3行, 原文引用："83号文档设计了三层提取（L1/L2/L3）的POC验证方案"
- **依赖关系**：依赖：无（基础结构） / 支撑：105-P23（分层提示材料构造）、105-P24（L1结构）、105-P25（L2结构）、105-P26（L3结构）
- **与检索机制的关系**：直接支撑检索的分层索引结构。253号第6.4节提出"按思维模式分类索引"和"多级索引"——L1/L2/L3天然构成三级索引层级。检索时可先按L3范式粗筛（跨领域），再按L2思维模式精排（领域内），最后按L1路径匹配（具体题目）。Pattern存储时可标注其所属层级，检索时按层级递进。

### 原语：跨题复用性核心假设
- **ID**：105-P2
- **类型**：概念框架
- **描述**：从题库解法中通过AI多次分析提取的L2/L3思维点，比仅提取L1的解题思路，具有显著更高的跨题复用性和分析质量增益。
- **溯源**：105-大师-POC-3验证方案.md, 第9行, 原文引用："从题库解法中通过AI多次分析提取的L2/L3思维点，比仅提取L1的解题思路，具有显著更高的跨题复用性和分析质量增益。"
- **依赖关系**：依赖：105-P1（三层知识分层） / 支撑：105-P3（可证伪性标准）
- **与检索机制的关系**：直接定义了检索的价值排序——高复用性的Pattern（L2/L3）应在检索中被优先考虑。253号问题中，"此刻最需要的Pattern"不一定是文本最相似的，而是抽象层次最匹配的。此假设为检索系统提供了Pattern优先级的理论基础：L2/L3 Pattern的检索命中权重应高于L1。

### 原语：可证伪性标准
- **ID**：105-P3
- **类型**：性质标准
- **描述**：验证方案必须是可证伪的——如果L2/L3在跨题分析中不优于L1，则三层提取方案价值不成立；如果远迁移C组不显著优于B组，则L3跨领域迁移价值不成立。
- **溯源**：105-大师-POC-3验证方案.md, 第13-14行, 原文引用："如果L2/L3提取的思维点在跨题分析中不比L1有优势 → 三层提取方案价值不成立" / "如果题3（远迁移）C组不显著优于B组 → L3范式思维的跨领域迁移价值不成立"
- **依赖关系**：依赖：105-P2（跨题复用性核心假设） / 支撑：105-P17（成功/失败阈值定义）
- **与检索机制的关系**：为检索机制的验证提供性质标准。检索系统的效果必须可通过实验证伪——如果检索到的Pattern不能显著提升工作智能体的表现，则检索机制本身的价值不成立。这要求检索系统的设计必须包含可量化的成功/失败判据。

### 原语：三组对照实验设计
- **ID**：105-P4
- **类型**：操作原语
- **描述**：设置A组（仅L1）、B组（L1+L2）、C组（L1+L2+L3）三组对照，面对同一道新题，比较不同提取层次的提示效果差异。
- **溯源**：105-大师-POC-3验证方案.md, 第20-24行, 原文引用："A组（对照组）| 题目 + L1解法路径 | 仅L1" / "B组（L2组）| 题目 + L1路径 + L2思维模式 | L1+L2" / "C组（L3组）| 题目 + L1路径 + L2思维模式 + L3范式思维 | L1+L2+L3"
- **依赖关系**：依赖：105-P1（三层知识分层） / 支撑：105-P17（成功/失败阈值定义）
- **与检索机制的关系**：为检索机制的效果评估提供实验范式。检索系统可以类似地设置对照组——"无检索辅助"vs"仅L1检索"vs"L1+L2+L3分层检索"——来验证分层检索是否优于无分层检索。三组对照的方法论可直接复用于检索系统的A/B测试。

### 原语：提取-复用链条
- **ID**：105-P5
- **类型**：结构原语
- **描述**：从一道题（提取题）中提取L1/L2/L3思维点，作为提示材料注入另一道题（复用题），形成"提取→存储→复用"的完整链条。
- **溯源**：105-大师-POC-3验证方案.md, 第28-39行, 原文引用："题1（Cayley-Hamilton定理）——提取题 ↓ 三层提取 ↓ L1路径 + L2思维模式 + L3范式思维 ↓ 作为提示材料 ↓ 题2（近迁移）→ A/B/C三组对照 → 评分 ↓ 题3（远迁移）→ A/B/C三组对照 → 评分"
- **依赖关系**：依赖：105-P1（三层知识分层） / 支撑：105-P6（跨题提示注入）
- **与检索机制的关系**：直接对应253号检索问题的核心流程——Pattern从历史经验中提取（提取题），存储在稀疏矩阵中，在新的解题状态下被检索并复用（复用题）。提取-复用链条就是检索系统的数据流骨架：提取端定义Pattern如何入库，复用端定义Pattern如何被检索和使用。

### 原语：跨题提示注入
- **ID**：105-P6
- **类型**：操作原语
- **描述**：提示中包含从其他题提取的L1/L2/L3思维点，而非当前题的解法——测试跨题复用性，即提取的思维点是否能在不同题目中生效。
- **溯源**：105-大师-POC-3验证方案.md, 第44行, 原文引用："提示中包含从其他题提取的L1/L2/L3思维点——测试跨题复用性"
- **依赖关系**：依赖：105-P5（提取-复用链条） / 支撑：无
- **与检索机制的关系**：直接定义了检索的核心场景——检索到的Pattern来自其他题目的经验，而非当前题目。253号问题中，稀疏矩阵存储的Pattern来自系统积累的所有经验，检索的目的是找到"来自其他题目但适用于当前状态"的Pattern。跨题提示注入验证了这种跨题检索的可行性。

### 原语：盲评机制
- **ID**：105-P7
- **类型**：性质标准
- **描述**：评分AI不知道哪组是A/B/C，消除评分者偏见，确保评估结果的客观性。
- **溯源**：105-大师-POC-3验证方案.md, 第45行, 原文引用："盲评：评分AI不知道哪组是A/B/C"
- **依赖关系**：依赖：105-P4（三组对照实验设计） / 支撑：无
- **与检索机制的关系**：为检索系统的效果评估提供客观性保障。评估检索到的Pattern是否有效时，评估者不应知道Pattern的来源和检索方法，否则会产生确认偏见。盲评机制可用于验证"检索到的Pattern是否真的比随机Pattern更有效"。

- **溯源**：105-大师-POC-3验证方案.md, 第46行, 原文引用："三组用三个独立subagent，background模式并行执行"

- **与检索机制的关系**：为检索系统提供角色隔离的执行模型。253号第三层"知识悖论"提到"引入第三个角色——一个专门做Pattern匹配的组件"。独立subagent的执行模式可直接用于实现这种角色隔离——检索组件作为独立subagent运行，与工作智能体和助理智能体隔离，避免知识泄漏。

### 原语：近迁移与远迁移区分
- **ID**：105-P9
- **类型**：概念框架
- **描述**：将近迁移（同领域跨题）和远迁移（跨领域跨题）作为两个独立的测试层次，分别验证L2和L3的复用价值。
- **溯源**：105-大师-POC-3验证方案.md, 第34-38行, 原文引用："题2（近迁移）——另一道线性代数题" / "题3（远迁移）——非线代领域的题"

- **与检索机制的关系**：为检索系统提供"检索距离"的概念框架。253号问题中，检索到的Pattern可能来自同领域（近）或跨领域（远）。近迁移/远迁移的区分直接对应检索的"匹配距离"——L2 Pattern适用于近迁移检索（同领域内），L3 Pattern适用于远迁移检索（跨领域）。检索系统可按迁移距离分层匹配。

### 原语：提取题选择标准
- **ID**：105-P10
- **类型**：概念框架
- **描述**：提取题应满足：有多种经典解法（适合提取跨领域映射）、L3范式思维清晰、已有完整的三层分析。
- **溯源**：105-大师-POC-3验证方案.md, 第52-55行, 原文引用："83号文档第五节已有完整的三层分析" / "有三种经典解法（矩阵法/模论法/行列式法），适合提取跨领域映射" / "L3范式思维清晰：矩阵=模等价"

- **与检索机制的关系**：为Pattern的入库质量提供标准。不是所有题目都适合作为Pattern来源——只有具有多种解法、清晰范式思维的题目才能产出高质量Pattern。检索系统中，Pattern入库时应标注其来源题目的质量特征，低质量来源的Pattern在检索时可降权。

### 原语：近迁移复用题选择标准
- **ID**：105-P11
- **类型**：概念框架
- **描述**：近迁移复用题应满足：同属提取题的领域、需要用到L2思维模式（如不变量思维）、有多种证明路径可验证L2跨题复用、难度适中。

- **与检索机制的关系**：为检索系统的测试用例设计提供标准。验证检索系统时，近迁移测试题应满足这些条件——同领域、需要特定L2思维模式、多路径——才能有效检验检索是否能命中正确的L2 Pattern。

### 原语：远迁移复用题选择标准
- **ID**：105-P12
- **类型**：概念框架
- **描述**：远迁移复用题应满足：属于不同领域（跨领域）、L3跨领域映射思维方式应能帮助看到结构对应、需要用到L2思维模式（如拓扑不变量）、有多种证明路径、难度适中。

- **依赖关系**：依赖：105-P9（近迁移与远迁移区分） / 支撑：无
- **与检索机制的关系**：为检索系统的跨领域测试用例设计提供标准。远迁移测试验证检索系统能否跨领域命中Pattern——这是检索最难的场景，也是253号"稀疏矩阵中分散的Pattern"问题的核心。

### 原语：L1结构——具体解法路径
- **ID**：105-P13
- **类型**：结构原语
- **描述**：L1是具体的解题步骤序列，包含每一步的具体操作（如"设A是n×n矩阵，特征多项式p(λ)=det(λI-A)"），是最低抽象层的经验。
- **溯源**：105-大师-POC-3验证方案.md, 第91-107行, 原文引用："路径A（矩阵证明）：1. 设A是n×n矩阵，特征多项式p(λ)=det(λI-A) 2. 要证p(A)=0 3. 对任意非零向量v，构造Av的序列 4. 用Cayley-Hamilton直接代入验证"
- **依赖关系**：依赖：105-P1（三层知识分层） / 支撑：105-P23（分层提示材料构造）
- **与检索机制的关系**：L1 Pattern对应253号中Level→0的Pattern（纯知识，绑定特定领域）。L1 Pattern的检索匹配度最低（因为具体解法路径难以跨题复用），但在同题或极相似的题目中检索价值最高。检索系统应将L1 Pattern作为最细粒度的匹配层。

### 原语：L2结构——思维模式（含来源路径与适用领域）
- **ID**：105-P14
- **类型**：结构原语
- **描述**：L2是AI二次分析提取的数学思维模式，每个L2 Pattern包含三个字段：思维模式名称、来源路径（从哪条解法路径提取）、适用领域（哪些数学领域可用）。
- **溯源**：105-大师-POC-3验证方案.md, 第110-115行, 原文引用："| 思维模式 | 来源路径 | 适用领域 | | 多项式恒等式检验 | 路径A | 代数、数论 | | 局部-全局 | 路径B | 代数、拓扑、数论 | | 恒等式构造 | 路径C | 代数、分析 | | 不变量思维 | 三条路径共有 | 全部数学领域 |"
- **依赖关系**：依赖：105-P1（三层知识分层） / 支撑：105-P15（不变量思维弥漫性）、105-P23（分层提示材料构造）
- **与检索机制的关系**：直接定义了Pattern的数据结构——每个Pattern应包含"来源路径"（provenance）和"适用领域"（domain tag）。253号中Pattern包含"触发条件、Q内容、Level、历史记录"，L2的三字段结构可扩展为Pattern的标准元数据：来源路径→provenance tracking，适用领域→domain-based indexing（253号6.4节"按数学结构分类索引"）。

### 原语：不变量思维的弥漫性
- **ID**：105-P15
- **类型**：概念框架
- **描述**：不变量思维是弥漫性最强的思维模式——特征多项式是不变量，无论用什么方法都应该得到同一个。弥漫性越强的思维模式，适用领域越广。
- **溯源**：105-大师-POC-3验证方案.md, 第117行, 原文引用："关键L2：不变量思维——特征多项式是不变量，无论用什么方法都应该得到同一个。这是弥漫性最强的思维模式。"
- **依赖关系**：依赖：105-P14（L2结构） / 支撑：105-P16（跨领域映射思维方式）
- **与检索机制的关系**：为检索系统提供Pattern权重排序的概念——"弥漫性"即Pattern的跨领域适用广度。弥漫性强的Pattern在检索中应被赋予更高的基础权重（因为它们更可能在各种状态下被需要）。253号中，当多个Pattern部分匹配时，弥漫性可作为tie-breaking标准：弥漫性强的Pattern优先。

### 原语：L3结构——范式思维与跨领域映射
- **ID**：105-P16
- **类型**：结构原语
- **描述**：L3是AI三次分析提取的范式思维，揭示不同领域之间的结构等价（如"矩阵=模等价"），一旦被提取，为整个领域增加一层跨领域映射边。
- **溯源**：105-大师-POC-3验证方案.md, 第121-126行, 原文引用："L3范式：矩阵=模等价" / "L3一旦被提取，不只服务于Cayley-Hamilton，而是为整个线性代数增加了一层跨领域映射边" / "跨领域映射思维方式：看到A领域的结构，联想B领域是否有对应——这是比'不变量思维'更高一层的范式"
- **依赖关系**：依赖：105-P1（三层知识分层）、105-P15（不变量思维弥漫性） / 支撑：105-P27（跨领域映射边）
- **与检索机制的关系**：直接对应253号中Level→1的Pattern（纯思维模式，跨领域通用）。L3 Pattern是检索系统中跨领域检索的核心——当工作智能体的状态在某个领域卡住时，L3 Pattern可以引导它看到其他领域的对应结构。L3 Pattern的检索匹配不依赖领域相似性，而依赖结构对应性。

### 原语：跨领域映射边
- **ID**：105-P27
- **类型**：结构原语
- **描述**：L3范式思维一旦被提取，不只服务于原题，而是为整个知识领域在稀疏矩阵（认知图/依赖图）中增加了一层跨领域映射边——连接不同领域的认知单元。
