## 提取总览

201号文档核心讨论的是：大师数学系统的稀疏矩阵应该存储多层知识（L1直接知识/L2思维模式/L3跨领域范式/L4哲学洞察），但当前只存储了L1，高阶知识提取未常态化、未集成、未入库。这一主题与253号检索问题的关联在于：**检索的前提是存储——稀疏矩阵中存什么、怎么分层、怎么标注，直接决定了检索时能匹配什么、按什么维度索引、用什么判据筛选。** 201号提出的知识分层模型、弥漫性标准、审计机制、节点schema、跨领域边等，都是构造检索系统的底层积木。

### 原语：多层知识结构（K维度四层模型）
- **ID**：201-P1
- **类型**：结构原语
- **描述**：稀疏矩阵的K维度应区分L1（解题路径）/L2（思维模式）/L3（跨领域范式）/L4（哲学洞察）四个层级，不同层级以不同图元素存储（边/节点/边/节点）。
- **溯源**：201-v0-2026-08-06-AI在知识吸收中的缺位.md, 第97-104行, 原文引用："| L1 | 解题路径 | 具体证明步骤 | … | K维度·requires/uses边 | | L2 | 思维模式 | 弥漫性数学思维 | … | K维度·awareness节点 | | L3 | 范式 | 跨领域映射 | … | K维度·cross_domain边 | | **L4** | **哲学/世界观** | **数学哲学洞察** | … | **K维度·philosophy节点（新增）** |"
- **依赖关系**：依赖：123号架构K/T/H三维度定义 / 支撑：检索时可按知识层级分维度检索
- **与检索机制的关系**：直接支撑检索第二层（Pattern提取）。Pattern本身按Level（0到1）标注抽象度，而存储层按L1-L4分层——Level与L层级形成对应关系，检索时可先按Level确定目标L层级，再在该层内做匹配，大幅缩小搜索空间。

- **与检索机制的关系**：直接支撑检索第一层（状态感知）。工作智能体的推理输出本质上是L1层步骤的序列，检索时可将当前推理步骤与存储的L1路径做结构匹配——"当前走到了哪一步，下一步可能是什么"。

### 原语：弥漫性要求（Diffuseness Standard）
- **ID**：201-P6
- **类型**：性质标准
- **描述**：L2思维模式必须满足弥漫性——至少覆盖2个领域；L3范式必须跨领域映射且改变图结构。这是区分L2与L3的质量门槛。
- **溯源**：201-v0-2026-08-06-AI在知识吸收中的缺位.md, 第35-36行, 原文引用："| L2 | 数学思维模式 | 从L1中抽象出的弥漫性思维模式，标注evidence_step和applicable_domains | 至少覆盖2个领域 | | L3 | 范式级思维 | 必须改变图结构，连接不同领域，不是元思维模式 | 跨领域映射 |"
- **依赖关系**：依赖：领域分类体系 / 支撑：Pattern质量分级、检索时的可信度过滤
- **与检索机制的关系**：直接支撑检索第二层（Pattern提取）。弥漫性是Pattern质量的度量标准——检索时可以优先返回弥漫性高的Pattern（跨领域通用性强），或根据当前问题所属领域过滤掉不适用的Pattern。弥漫性要求也可作为"匹配度计算"的一个维度。

- **依赖关系**：依赖：L1解题路径 / 支撑：Pattern的触发条件溯源、检索时的证据链验证
- **与检索机制的关系**：直接支撑检索第一层（状态感知）和第二层（Pattern提取）。evidence_step建立了"思维模式→具体步骤"的回溯链——检索时，如果当前状态匹配了某个L2思维模式，可以通过evidence_step回溯到L1的具体步骤，验证该Pattern是否真的适用于当前推理阶段。这为"近似匹配"提供了验证手段。

- **依赖关系**：依赖：AI阅读理解能力 / 支撑：Pattern的生成pipeline、检索时从具体到抽象的回溯路径
- **与检索机制的关系**：间接支撑检索。逐层提取流程意味着存储的Pattern之间有"从具体到抽象"的层级链。检索时可以利用这条链做双向遍历：从当前具体状态（L1层）向上抽象到L2思维模式，再在L2层做匹配；或从识别到的L2思维模式向下回溯到L1具体步骤验证适用性。

### 原语：AI在各层级的价值递增规律
- **ID**：201-P14
- **类型**：概念框架
- **描述**：L2/L3/L4的提取难度递增，但对AI的价值也递增。L1可被规则部分自动化，但L2/L3/L4几乎完全依赖AI的数学理解力和创造力。
- **溯源**：201-v0-2026-08-06-AI在知识吸收中的缺位.md, 第158行, 原文引用："关键观察：L2/L3/L4的提取难度递增，但对AI的价值也递增。L1可以被规则/脚本部分自动化，但L2/L3/L4几乎完全依赖AI的数学理解力和创造力。"
- **依赖关系**：依赖：多层知识结构（201-P1） / 支撑：检索时的人工/AI分工策略
- **与检索机制的关系**：间接支撑检索第三层（知识悖论）。这个规律暗示：高Level（→1）的Pattern（思维模式类）更容易被AI识别和匹配（因为弥漫性强、跨领域通用），而低Level（→0）的Pattern（知识类）更难匹配（因为需要具体领域知识）。这与253号的知识悖论相关——助理智能体可能更容易在高Level做匹配，在低Level遇到知识瓶颈。

### 原语：L4哲学洞察影响判断方向

- **描述**：哲学洞察不是具体问题的解法，但影响Solver面对新问题时的判断方向——如果Solver内化了"等价性比相等性更深刻"，面对难以直接解决的问题时会更主动寻找等价转化。

- **依赖关系**：依赖：L4哲学洞察存储（201-P5） / 支撑：检索时的元方向引导
- **与检索机制的关系**：间接支撑检索第一层（状态感知）。当状态感知无法精确识别"需要什么具体Pattern"时，L4哲学洞察可以提供方向性引导——"当前问题难以直接解决→优先检索等价转化类Pattern"。这是一种从最高抽象层向下指导检索的机制。

### 原语：K维度内部层级区分
- **ID**：201-P16
- **类型**：结构原语
- **描述**：123号架构定义了K/T/H三个维度，但K维度内部缺少层级区分——需要明确L1边 vs L2节点 vs L3边 vs L4节点的存储结构差异。
- **溯源**：201-v0-2026-08-06-AI在知识吸收中的缺位.md, 第176-180行, 原文引用："K维度当前定义：按requires/uses/generalizes/analogous/verified_by等关系拆分的稀疏视图 / 缺少的：K维度内部的层级区分（L1边 vs L2节点 vs L3边 vs L4节点）/ 缺少的：从L1到L2到L3到L4的提取流程定义"
- **依赖关系**：依赖：123号架构 / 支撑：检索时的分层索引结构
- **与检索机制的关系**：直接支撑检索第二层（Pattern提取）。K维度内部层级区分定义了Pattern在图数据库中的存储拓扑——不同层级的Pattern以不同的图元素类型存储（边/节点），检索时可以根据目标层级选择不同的图遍历策略（遍历边 vs 遍历节点 vs 遍历跨领域边）。

### 原语：L4节点schema（philosophy_insight / applicable_principle / source_evidence）
- **ID**：201-P17

## 关键发现
