# 原语提取：星学遗留文件清单-待删除.md

## 文档概述

本文件是项目从"星学（七政四余/MOIRA）"转向"数学大师系统"后，对遗留文件进行清理管理的清单文档。文档将所有遗留文件分为三类（待删除/待决策/保留），对保留的文件逐一标注保留原因，并记录了已删除文件的批次信息。文档本身不是检索机制的设计文档，但其中涉及的多项数据结构、分类机制、依赖追踪思想可作为检索机制的原语来源。

## 文档与检索机制的关系

本文档（星学遗留文件清单-待删除.md）从表面看是一个文件清理管理文档，与253号检索问题没有直接关联。但深入分析后，可以提取出13个原语，它们从不同角度间接支撑检索机制的构建：

**直接支撑的原语（4个）**：
- **misc01-P04（认知单元定义）**：这是检索机制最底层的结构原语——253号文档明确指出稀疏矩阵的节点是"认知单元/数学元素/思维模式"，而`cognition_units_math.json`正是这些节点的定义来源。没有认知单元定义，就没有检索的对象。

- **misc01-P06（环检测）**：保障图遍历检索方案的正确性，防止遍历陷入无限循环。
- **misc01-P02（保留原因标注）**：直接对应253号第三层知识悖论的破解方向——"Pattern自带适用性描述"，每个Pattern携带解释自身适用性的元数据标注。
