# 原语提取：69-xishujuzhen-POC4验证结果

## 文档概述

本文档记录了 POC-4 的验证结果，在 POC-3 三步流程基础上引入"双宫联动+跨宫依赖"场景，验证依赖图在复杂场景下的可行性和边际增益。文档详细描述了依赖图扩展（跨宫依赖边）、审计覆盖机制、评分维度以及核心发现。与检索机制的关系在于：依赖图本身就是检索的底层数据结构，跨宫依赖边扩展了检索的跨域能力，审计覆盖机制提供了检索完整性的验证手段，评分维度则定义了检索质量的衡量标准。

## 提取的原语

### 原语：跨宫依赖边
- **ID**：69-P1
- **类型**：结构原语
- **描述**：依赖图中连接不同"宫"（领域/子图）的边，使依赖图可以表达跨域依赖关系，AI可沿这些边传递分析结果。
- **溯源**：69, 第5-10行, 原文引用："引入**双宫联动+跨宫依赖**场景，验证依赖图在复杂场景下的可行性和边际增益" / "依赖图 | 19节点，25边，4条跨宫依赖边"
- **依赖关系**：
  - 依赖：依赖图基础结构（节点+边）
  - 支撑：跨宫依赖覆盖审计（69-P4）
- **与检索机制的关系**：跨宫依赖边是检索机制中跨域检索的结构基础——当检索需要从一个知识域跳转到另一个相关域时，跨宫依赖边提供了显式的跨域路径，使检索不限于单一子图内部。

### 原语：螺旋环路处理
- **ID**：69-P2
- **类型**：操作原语
- **描述**：依赖图中存在循环依赖（如五行生克↔阴阳昼夜），通过"上下文变化"来区分环路的不同圈次，使AI能在环路中迭代而不陷入死循环。
- **溯源**：69, 第11行, 原文引用："螺旋环路 | 1个（五行生克↔阴阳昼夜）" / 第37行："环路处理：1螺旋环路，2圈，上下文变化明确"
- **依赖关系**：
  - 依赖：依赖图基础结构
  - 支撑：路径忠实性审计（69-P5）
- **与检索机制的关系**：检索过程中可能遇到循环依赖的Pattern（A依赖B，B又依赖A），螺旋环路处理机制使检索能在循环中通过上下文变化区分不同迭代层级，避免无限递归，同时保留循环依赖的语义信息。

### 原语：三步流程（JSON→解读→分析+审计）
- **ID**：69-P3
- **类型**：操作原语
- **描述**：将依赖图序列化为JSON（含依赖结构+解读要求+审计要求），AI先解读JSON生成大师级提示词，再在JSON+提示词共同引导下进行分析和审计，实现"结构化输入→中间表示→分析+验证"的三阶段流程。
- **溯源**：69, 第12行, 原文引用："三步流程 | JSON（含跨宫依赖+解读要求+审计要求）→ AI解读JSON → AI在JSON+大师提示词共同提示下分析+审计"
- **依赖关系**：
  - 依赖：依赖图序列化（JSON化）
  - 支撑：审计覆盖机制（69-P4）、路径忠实性（69-P5）
- **与检索机制的关系**：这是检索机制的执行流程模板——将图结构序列化为可检索的中间表示，再通过中间表示引导AI的分析过程。检索机制可以复用这个"序列化→中间表示→引导分析"的三阶段架构。

### 原语：审计覆盖机制（节点/边/跨宫/环路全覆盖）
- **ID**：69-P4
- **类型**：操作原语
- **描述**：对依赖图的分析结果进行全覆盖审计——节点覆盖率、边覆盖率、跨宫依赖覆盖率、环路处理情况，确保分析过程没有遗漏图中的任何元素。
- **溯源**：69, 第35-39行, 原文引用："节点覆盖：19/19 = 100%" / "边覆盖：25/25 = 100%" / "环路处理：1螺旋环路，2圈，上下文变化明确" / "跨宫依赖覆盖：4/4 = 100%"
- **依赖关系**：
  - 依赖：依赖图结构（节点+边+跨宫边+环路）、三步流程（69-P3）
  - 支撑：可审计性评分维度（69-P7）
- **与检索机制的关系**：审计覆盖机制是检索完整性的验证手段——检索机制必须确保从认知图中检索到的Pattern覆盖了所有相关节点和边，审计覆盖机制提供了"检索是否完整"的量化验证方法。

### 原语：路径忠实性审计
- **ID**：69-P5
- **类型**：操作原语
- **描述**：逐条审计AI是否忠实沿依赖图的引导路径进行分析，统计引导点的忠实率，确保分析过程没有偏离图结构指定的路径。
- **溯源**：69, 第39行, 原文引用："路径忠实性：25/25引导点，忠实率100%"
- **依赖关系**：
  - 依赖：依赖图引导路径、三步流程（69-P3）
  - 支撑：可审计性评分维度（69-P7）
- **与检索机制的关系**：路径忠实性是检索机制执行质量的验证——检索机制不仅需要检索到正确的Pattern，还需要确保后续分析沿检索到的路径执行。路径忠实性审计提供了"检索路径是否被正确遵循"的量化验证。

### 原语：双宫联动场景（多域联动检索）
- **ID**：69-P6
