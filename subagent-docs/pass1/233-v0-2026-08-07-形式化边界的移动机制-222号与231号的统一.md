# 原语提取：233-v0-形式化边界的移动机制——222号与231号的统一

## 文档概述

本文档统一了222号（形式化边界与AI边界智能）和231号（数据基座转向）两个核心认识，提出"形式化边界的移动机制"：数学知识有形式化边界两侧的两种成分（可形式化的进入数据基座，不可形式化的进入AI训练），闭环的每次运行将边界以外的AI感知压缩成可检查目标、经经典计算验证后回写数据基座，从而推进形式化边界。文档对检索机制的贡献在于：它定义了检索的分区逻辑（边界内外）、检索源的双路径结构（AI黑盒 vs 数据基座白盒）、检索结果的验证-回写闭环、以及数据基座作为"已征服领土"的单调增长不变量。

## 提取的原语

### 原语：形式化边界分区——可形式化 vs 不可形式化的知识二分
- **ID**：233-P1
- **类型**：概念框架
- **描述**：数学知识本身有形式化边界两侧的两种成分，边界以内可以显式化（数据基座），边界以外只能隐式化（AI参数），这是知识分区的本质依据。
- **溯源**：233-v0, 第74-78行, 原文引用："数学知识本身有形式化边界两侧的两种成分：可以形式化的成分（定理依赖、证明步骤、证书目标、恒等式、不等式、类型）→ 进入数据基座（抽取路径）；不可形式化的成分（"不自然"的感知、模式识别、直觉、类比、结构感）→ 进入AI训练（训练路径）。这不是工程方便，是形式化边界的必然结果。边界两侧的东西需要不同的处理方式——边界以内可以显式化（数据基座），边界以外只能隐式化（AI参数）。"
- **依赖关系**：
  - 依赖：222号形式化边界认识（第12行引用）
  - 支撑：233-P2（双重知识生产）、233-P3（数据基座作为已征服领土）
- **与检索机制的关系**：这是检索机制最底层的分区逻辑——检索系统需要知道哪些知识可以从数据基座精确检索（边界以内），哪些只能依靠AI模糊匹配（边界以外）。检索策略的选择取决于目标知识落在边界的哪一侧。

### 原语：双重知识生产——同一语料的训练路径与抽取路径
- **ID**：233-P2
- **类型**：结构原语
- **描述**：同一批数学语料有两条生命路径：训练路径（语料→AI模型参数→黑盒模式识别能力）和抽取路径（语料→结构化数据→白盒可执行数学记忆），两者互补构成完整的检索源。
- **溯源**：233-v0, 第53-55行, 原文引用："同一批数学语料有两条生命路径：训练路径：语料→AI模型参数→黑盒模式识别能力；抽取路径：语料→结构化数据→白盒可执行数学记忆（数据基座）"
- **依赖关系**：
  - 依赖：233-P1（形式化边界分区）
  - 支撑：233-P4（互补性质）、233-P5（闭环动力学）
- **与检索机制的关系**：检索机制有两个互补的检索源——AI黑盒（模糊匹配、泛化、联想）和数据基座白盒（精确定位、可检查、可版本化）。检索系统需要设计双路径检索策略，根据查询性质选择或组合两个源。

### 原语：边界移动机制的四步精确表述
- **ID**：233-P8
- **类型**：操作原语
- **描述**：形式化边界的移动机制是一个四步流程：①AI从边界以外感知"不自然"（侦察）→ ②AI把"不自然"压缩成可检查目标（跨越边界）→ ③经典计算在边界以内验证（操作）→ ④验证结果回写数据基座（边界向前推进）。
- **溯源**：233-v0, 第113-129行, 原文引用："步骤1：AI从形式化边界以外感知到"不自然"（AI的黑盒能力——边界以外的侦察）；步骤2：AI把"不自然"压缩成可检查目标（跨越形式化边界——从感知到对象）；步骤3：经典计算在形式化边界以内验证（经典计算——边界以内的操作）；步骤4：验证结果回写数据基座（扩大形式化边界的已征服领土）……AI从边界以外感知到"不自然" → 压缩成可检查目标（跨越边界）→ 经典计算在边界以内验证 → 结果回写数据基座（边界向前推进）"
- **依赖关系**：
  - 依赖：233-P5（闭环动力学）、233-P6（AI侦察兵）、233-P7（经典计算验证器）、233-P3（数据基座作为已征服领土）
  - 支撑：233-P10（边界推进的不可逆性）
- **与检索机制的关系**：这是检索机制最核心的操作原语——检索不是简单的查询，而是一个"感知→压缩→验证→回写"的四步流程。步骤②"压缩成可检查目标"是检索机制的关键环节：将AI的模糊感知转化为可精确检索/验证的对象。

### 原语：数据基座单调增长——边界推进的不可逆性
- **ID**：233-P9
- **类型**：性质标准
- **描述**：数据基座是单调增长的——证书只加不删，这意味着形式化边界的推进是不可逆的，一旦某个东西被形式化了（从边界以外拉到边界以内），它就永久留在边界以内。
- **溯源**：233-v0, 第142-145行, 原文引用："数据基座是单调增长的（230号§1.3）——证书只加不删。这意味着形式化边界的推进是不可逆的——一旦某个东西被形式化了（从边界以外拉到边界以内），它就留在边界以内了。这和数学的实际历史一致——一旦一个定理被证明了，它就永久地成为了形式化知识的一部分。形式化边界只前进不后退。"
- **依赖关系**：
  - 依赖：233-P3（数据基座作为已征服领土）、230号§1.3
  - 支撑：233-P10（非单调感知与单调形式化的统一）
- **与检索机制的关系**：这是检索源的一致性不变量——数据基座只增不删，检索结果具有持久性。检索机制可以依赖这一不变量做缓存和索引优化：已检索并验证的条目不会消失。

### 原语：非单调感知与单调形式化的统一——闭环作为稳定化机制
- **ID**：233-P10
- **类型**：概念框架
- **描述**：边界以外的AI感知是非单调的（AI可以改主意，感知是模糊的、可变的、可修正的），边界以内的形式化是单调的（证书只加不删）。闭环的作用就是把非单调的感知不断压成单调的形式化。
- **溯源**：233-v0, 第148-151行, 原文引用："但AI的感知是非单调的——AI可能今天感知到"这个方向有希望"，明天发现不对，换一个方向。这是边界以外的特征——感知是模糊的、可变的、可修正的。这不矛盾——边界以外的感知是非单调的（AI可以改主意），边界以内的形式化是单调的（证书只加不删）。闭环的作用就是把非单调的感知不断压成单调的形式化。"
- **依赖关系**：
  - 依赖：233-P9（单调增长不变量）、233-P8（边界移动机制）
  - 支撑：无直接下游
- **与检索机制的关系**：这定义了检索机制中模糊检索与精确检索的关系——AI的模糊检索结果是非单调的（可能修正），但经过验证回写后变成单调的精确检索源。检索机制需要处理这种"非单调输入→单调输出"的稳定化过程。

### 原语：角色隔离——分离模式识别与答案知识

- **描述**：让不知道答案的AI做感知（模式识别），防止知道答案的引导者通过引用特定方向隐含泄露正确路径——这是"分离模式识别和答案知识"的原则。

- **依赖关系**：
