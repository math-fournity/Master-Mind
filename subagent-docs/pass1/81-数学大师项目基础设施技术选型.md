# 原语提取：81-数学大师项目基础设施技术选型

## 文档概述

本文档是数学大师项目的基础设施技术选型文档，在 79 号文档（星学项目 ArangoDB 选型）基础上，针对数学领域更新和新增了基础设施组件。文档涵盖了主数据库选型（ArangoDB 多模型）、形式化证明助手（Lean 4 + MathLib）、符号计算引擎（SageMath）、数学文献管道（arXiv HTML 接入）三大新增组件，以及更新后的 ArangoDB Collections 设计和建设路径。与检索机制的关系极为密切——文档直接描述了向量索引语义检索、图遍历依赖路径查询、依赖图数据导入、文献结构化提取、跨领域映射边类型等检索机制的核心构造积木。

## 提取的原语

### 原语：多模型数据库统一存储（图+文档+键值+向量）
- **ID**：81-P1
- **类型**：结构原语
- **描述**：用单一数据库（ArangoDB）同时存储图结构（依赖图/展开图）、文档内容（知识/审计/分析）、键值对和向量索引，统一管理检索所需的异构数据。
- **溯源**：81, 第29行, 原文引用："ArangoDB 主数据库 | 多模型（图+文档+键值+向量）对数学同样适用。数学依赖图、知识内容、审计报告、分析结果都可以用一个数据库处理。Apache 2.0 不变。向量索引对数学文献检索更有用"
- **依赖关系**：
  - 依赖：无（基础设施层）
  - 支撑：81-P2（AQL统一查询）、81-P8（向量索引语义检索）、81-P14（Collections设计）
- **与检索机制的关系**：检索机制的数据底座——图遍历、文档查询、向量相似度三种检索模式在同一存储引擎内完成，无需跨数据库联接。

### 原语：AQL 统一查询（图遍历+文档查询+集合差集）
- **ID**：81-P2
- **类型**：操作原语
- **描述**：用 AQL（ArangoDB Query Language）统一执行图遍历（依赖路径检索）、文档查询（知识内容检索）和集合差集运算（拓扑覆盖验证），作为检索机制的统一查询接口。
- **溯源**：81, 第30行, 原文引用："AQL 统一查询 | 图遍历（依赖路径）+ 文档查询（知识内容）+ 集合差集（拓扑覆盖验证）的需求不变"
- **依赖关系**：
  - 依赖：81-P1（多模型数据库）
  - 支撑：81-P12（拓扑覆盖验证）
- **与检索机制的关系**：检索的查询语言层——一次查询可以同时做图遍历（找依赖路径）和文档过滤（按内容筛选），是混合检索的核心操作原语。
