- **描述**：启发模式匹配的形式化表示为(P,R,C,F,τ)→A——前提条件P、规则R、上下文C、频率F、阈值τ，输出动作A。

- **依赖关系**：依赖：无 / 支撑：253号第二层——Pattern的触发条件形式化和匹配算法
- **与检索机制的关系**：直接相关。这是Pattern检索最核心的结构原语。253号中每个Pattern包含"触发条件"和"Q内容"，HeuristicRule schema将触发条件形式化为(P,R,C,F,τ)五元组：前提条件P对应工作智能体的当前状态特征，规则R对应匹配逻辑，上下文C对应累积context，频率F对应历史使用记录，阈值τ对应匹配的严格程度。匹配算法就是计算当前状态是否满足(P,R,C)且置信度超过τ，输出动作A就是Q内容。

### 原语：Hint选择公式a_t=W^T*p_t——加权检索的数学形式
- **ID**：166-P16
- **类型**：操作原语
- **描述**：Hint的选择通过加权向量W和状态向量p_t的内积来计算——将状态编码为向量，将Pattern编码为权重向量，内积最大者为最优匹配。
- **溯源**：166-v1-2026-08-05-Phase0-6-CheckList-v4.2维度22预防性审计报告.md, 第200行, 原文引用："a_t=W^T*p_t公式 → Phase 5 Check List P5-9.4已覆盖（149号F8修正）"
