# 原语提取：86-从星学项目同步下一代工作流基础设施

## 文档概述

本文档记录从星学项目同步到数学项目的下一代工作流基础设施，核心是 HoTT（同伦类型论）化的依赖图/展开图/覆盖验证理论，以及配套的 ArangoDB 基础设施、七步骤工作流、meta/normal 角色分离原则和 G'_topo 拓扑骨架数据结构。这些内容与检索机制高度相关——依赖图是检索的数据源，G'_topo 是结构化检索结果的表示，AQL 集合差集是覆盖验证算法，ArangoDB 索引是检索的底层支撑，meta/normal 分离是检索流程中的角色隔离机制。
