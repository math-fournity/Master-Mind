# 原语提取：94-POC验证体系设计·工作系统有效性验证

## 文档概述

本文档设计了验证数学项目工作系统（cognition基座）有效性的POC验证体系，包括POC-R1-Math（工作系统有效性回归验证）、POC-3-Math（经典计算展开验证）、POC-4-Math（两套图共享验证）三个实验，以及8条验证设计原则。文档与检索机制的关系非常密切：其核心声称就是"图遍历能找到所有前置工作认知"和"集合差集能验证覆盖"——这正是检索机制的核心功能和验证方法。文档中的评分维度、假设检验、回归验证流程、图遍历隔离、版本链检查等都可以作为检索机制的构造原语或验证原语。

## 提取的原语

### 原语：图遍历检索前置认知
- **ID**：94-P1
- **类型**：操作原语
- **描述**：从种子认知单元出发，沿 depends_on 边遍历，确定性找到任务所需的全部前置工作认知
- **溯源**：94, 第13行, 原文引用："图遍历能找到所有前置工作认知：从种子认知单元出发，沿 depends_on 边遍历，能确定性找到任务所需的全部前置工作认知"
- **依赖关系**：
  - 依赖：认知图数据结构（cognition_units + cog_edges），种子选择机制
  - 支撑：集合差集覆盖验证（94-P2），图遍历完整性检查（94-P8）
- **与检索机制的关系**：这是检索机制的核心操作原语——图遍历就是检索的执行方式，从种子节点出发沿依赖边遍历就是检索的过程

### 原语：集合差集覆盖验证
- **ID**：94-P2
- **类型**：操作原语
- **描述**：用 AQL 集合差集计算"任务所需认知集 - 图遍历找到的认知集"，结果为空集即证明完全覆盖
- **溯源**：94, 第14行, 原文引用："集合差集能验证覆盖：用 AQL 集合差集计算"任务所需认知集 - 图遍历找到的认知集"，结果为空集即证明完全覆盖"
- **依赖关系**：
  - 依赖：图遍历检索前置认知（94-P1），AQL查询能力
  - 支撑：数学确定性原则（94-P22），回归验证（94-P10）
- **与检索机制的关系**：这是验证检索结果完整性的核心机制——通过集合差集可以确定性地判断检索是否遗漏了任何认知单元，而非依赖文字模糊匹配
