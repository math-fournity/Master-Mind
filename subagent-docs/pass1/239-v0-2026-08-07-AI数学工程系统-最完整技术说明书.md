# 原语提取：239-v0-AI数学工程系统——最完整技术说明书

## 文档概述

本文档是AI数学工程系统的技术说明书，系统性地呈现了系统的理念层（形式化边界推进）、核心概念（两种计算、闭环、数据基座、非特定性）、技术争论与路线选择、系统架构（三层视角、候选数学结构、执行契约、闭环动力学、证书系统、数据基座工程规范）、实验与验证设计以及实现路径。文档与检索机制高度相关——§7.5和§19.4直接定义了检索机制（路径结构匹配而非embedding相似度），§7.3和§19.1定义了检索目标的数据结构（数学工程单元），§18定义了证书系统（检索匹配的维度之一），§15定义了依赖图（检索的图查询基础），多个奠基性观念和核心概念为检索机制提供了相似性度量、匹配维度、索引结构和反馈闭环的原语。

## 提取的原语

### 原语：路径结构匹配检索（三阶段检索管线）
- **ID**：239-P1
- **类型**：操作原语
- **描述**：检索不是找相似文本，而是找相似的边界推进路径，通过粗筛（结构化字段匹配）→精化（图查询在依赖图中找连通路径）→排序（可选向量检索）三阶段管线实现。
- **溯源**：239-v0, 第409-420行, 原文引用："检索不是找相似文本，是找**相似的边界推进路径**。两个处境'相似' = 面临相似的不自然 + 需要相似的跨越 + 产生相似的证书目标。工程实现：1. **粗筛**：结构化字段匹配（处境类型+移动类型+证书类型）2. **精化**：图查询在依赖图中找连通路径 3. **排序（可选）**：向量检索在剩余候选中排序。核心是路径结构匹配，不是embedding相似度。"
- **依赖关系**：
  - 依赖：239-P2（数学工程单元结构，提供粗筛的结构化字段）、239-P7（依赖图，提供精化的图查询基础）、239-P6（证书系统，提供证书类型匹配维度）
  - 支撑：检索机制的核心管线
- **与检索机制的关系**：这是检索机制的核心操作原语——定义了检索的目标（相似边界推进路径）、相似性度量（路径结构相似度而非embedding相似度）和执行管线（三阶段过滤）。

### 原语：数学工程单元结构（四阶段数据结构）
- **ID**：239-P2
- **类型**：结构原语
- **描述**：数据基座的基本单位，按与形式化边界的关系组织为四阶段：边界标记（处境描述+表示图册）、跨越边界（语义移动+表示变换）、边界以内（证书目标+证书结果+依赖关系+经典任务）、边界以外的感知沉淀（模式模板+自然性测试+反例边界）。
- **溯源**：239-v0, 第372-395行, 原文引用："按与形式化边界的关系组织为四阶段：**阶段1：边界标记（处境的当前状态）** 处境描述：对象、关系、条件、目标、领域；表示图册：原始表示、规范化表示、对偶表示、形式化表示。**阶段2：跨越边界（从感知到形式化的过程）** 语义移动：每一步为什么做、改变了什么、属于哪类移动；表示变换：中心化、换基、归一化、对偶化、构造辅助对象。**阶段3：边界以内（已形式化的产物）** 证书目标…证书结果…依赖关系…经典任务…**阶段4：边界以外的感知沉淀** 模式模板…自然性测试…反例边界…"
- **依赖关系**：
  - 依赖：239-P6（证书系统，阶段3的字段来源）、239-P3（处境描述，阶段1的核心内容）
  - 支撑：239-P1（检索管线，粗筛字段来自此结构）、239-P5（模式模板，阶段4内容）、239-P12（工程单元与数学结构对应表）
- **与检索机制的关系**：这是检索目标的完整数据结构——检索的粗筛字段（处境类型、移动类型、证书类型）直接来自此结构的字段定义，精化的图查询也依赖此结构中的依赖关系字段。

- **依赖关系**：

### 原语：分层形式化（五层成熟度共存）
- **ID**：239-P4
- **类型**：结构原语
- **描述**：不要求所有材料一开始就完全形式化，五层成熟度（结构化→规范化→可执行化→局部证书化→完整形式化证明）允许不同成熟度的材料共存。
- **溯源**：239-v0, 第397-407行, 原文引用："不要求所有材料一开始就完全形式化。五层：1. **结构化**：拆成对象/条件/目标/步骤/依赖 2. **规范化**：同类操作统一命名 3. **可执行化**：编译成计算任务 4. **局部证书化**：计算结果写成可复查证书 5. **完整形式化证明**：最高层，不是所有材料都能达到。系统允许不同成熟度的材料共存。"
- **依赖关系**：
  - 支撑：239-P2（数学工程单元，不同成熟度的单元共存）、239-P1（检索管线，检索需考虑材料的成熟度层级）
- **与检索机制的关系**：分层形式化意味着检索库中存在不同成熟度的条目，检索机制需要能够处理和利用不同成熟度的材料——低成熟度的材料可作为粗筛候选，高成熟度的材料可提供更精确的路径匹配。

### 原语：证书偏序的层级结构
- **ID**：239-P6
- **类型**：结构原语
- **描述**：证书不能压成单一偏序——在固定claim和scope的纤维里强度形成偏序，在固定结论强度时适用范围按反方向排序，依赖链是审计图不直接和结论强度混成一个序。范围收缩不是加强。
- **溯源**：239-v0, 第895-903行, 原文引用："证书不能压成单一偏序。- 在固定claim和scope的纤维里，强度形成偏序 - 在固定结论强度时，适用范围按反方向排序 - 依赖链是审计图，不直接和结论强度混成一个序。**为什么重要**：范围收缩不是加强——'对n≥4且n偶数成立'不能替代'对n≥4成立'。"
- **依赖关系**：
  - 依赖：239-P5（证书对象结构）
  - 支撑：239-P7（依赖图，证书偏序构成图的边）、239-P8（系统状态，向下封闭理想）
- **与检索机制的关系**：证书偏序定义了检索结果的排序逻辑——检索到的证书需要按偏序关系组织，强证书可以替代弱证书（在固定scope的纤维里），但范围收缩不能替代范围更广的证书。

### 原语：换基子模式（通用思维拓扑的分类体系）
- **ID**：239-P14
- **类型**：概念框架
- **描述**：换基作为通用思维拓扑有四个子模式：冗余（约分）、隐藏乘积（因式分解）、虚假自由度（换坐标）、隐藏直和（分解）——这些子模式可作为检索的细粒度匹配维度。
- **溯源**：239-v0, 第142-148行, 原文引用："换基——'在保持本质不变的前提下，找到让结构最清晰的表示'——是一个从小学到范畴论的通用数学模式。**子模式**：- 冗余（约分）——表示中有不必要的自由度 - 隐藏乘积（因式分解）——表示隐藏了乘积结构 - 虚假自由度（换坐标）——表面自由度大于实际自由度 - 隐藏直和（分解）——表示隐藏了直和结构"

- **与检索机制的关系**：换基子模式为检索提供更细粒度的匹配维度——当AI感知到"冗余"时，检索可以精确匹配历史中处理冗余的模式模板，而非泛泛匹配所有"换基"类移动。

### 原语：模式识别=元拓扑（从问题拓扑到思维拓扑的映射）
- **ID**：239-P15
