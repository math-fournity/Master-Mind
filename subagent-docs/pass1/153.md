## 一、状态表示原语

### 原语：Checkpoint七字段状态表示
- **ID**：153-P1
- **类型**：结构原语
- **描述**：用7个预定义字段完整描述工作智能体在某一时刻的可观测状态，作为状态匹配的基本单元。
- **溯源**：153-v1-2026-08-05-Phase4三文件审计与修正报告.md, 第86行, 原文引用："§39 checkpoint定义7字段 ✅ 已实现 checkpoint_layer.py"
- **依赖关系**：依赖：123号§39的checkpoint定义 / 支撑：状态感知层（第一层）——检索的输入"工作智能体当前状态"需要一种结构化表示，7字段checkpoint提供了这种表示的模板
- **与检索机制的关系**：直接相关。253号第一层"状态感知"的核心问题是"思维状态怎么表示"。Checkpoint的7字段定义提供了一种已验证的结构化状态表示方案，可作为Pattern触发条件和当前状态之间的匹配基础。

### 原语：Checkpoint不包含LLM隐藏内部状态
- **ID**：153-P2
- **类型**：性质标准
- **描述**：状态表示只使用可观测的外部输出，不依赖LLM的隐藏内部状态（如注意力权重、激活值），确保状态表示的可复现性和跨模型兼容性。
- **溯源**：153-v1-2026-08-05-Phase4三文件审计与修正报告.md, 第121行, 原文引用："checkpoint不包含LLM隐藏内部状态 母本无 ✅ 已遵守"
- **依赖关系**：依赖：无 / 支撑：状态感知层——约束了状态表示的边界，检索系统只能基于可观测输出来匹配，不能用内部状态
- **与检索机制的关系**：直接相关。253号检索的输入是"工作智能体的当前推理输出（自然语言+数学公式）+累积context"，这个原语明确了状态表示只能基于可观测输出，排除了依赖模型内部状态的方案。

### 原语：Checkpoint一致性检查
- **ID**：153-P3
- **类型**：操作原语
- **描述**：在进行状态匹配或因果估计前，先检查不同来源的checkpoint是否一致（取交集），不一致时拒绝操作，防止在不可比的状态间做匹配。
- **溯源**：153-v1-2026-08-05-Phase4三文件审计与修正报告.md, 第22行, 原文引用："在`estimate_ate()`中增加checkpoint交集检查，不一致时拒绝估计 123号§39边界情况"
- **依赖关系**：依赖：153-P1（Checkpoint七字段状态表示）/ 支撑：Pattern提取层——在从稀疏矩阵提取Pattern前，需要验证当前状态与Pattern触发条件之间的可比性
- **与检索机制的关系**：直接相关。检索系统在匹配当前状态与Pattern触发条件时，需要先检查两者的状态表示是否在同一个"坐标系"下可比。一致性检查提供了一种防错机制。

### 原语：同一可观测Checkpoint分层内随机生成多个非确定Continuation
- **ID**：153-P4
- **类型**：操作原语
- **描述**：从同一可观测checkpoint出发，随机生成多个不同的推理延续（continuation），用于在同一状态下探索不同路径，为因果推断提供对照基础。
- **溯源**：153-v1-2026-08-05-Phase4三文件审计与修正报告.md, 第52行, 原文引用："实验模式在同一可观测checkpoint分层内随机生成多个非确定continuation ✅ 已实现 checkpoint_layer.py"
- **依赖关系**：依赖：153-P1（Checkpoint七字段）/ 支撑：Pattern提取层——同一状态可以对应多个不同的后续Pattern，需要从同一checkpoint出发探索多条路径
- **与检索机制的关系**：直接相关。253号DFS架构中，同一节点（状态）可以生成多个候选Q（边），这本质上是"从同一checkpoint生成多个continuation"。这个原语为"同一状态下提取多个候选Pattern"提供了已验证的实现模式。

## 五、泄漏检测原语

### 原语：泄漏检测四门逻辑
- **ID**：153-P17
- **类型**：操作原语
- **描述**：通过四门检测——字面匹配、等价映射、候选空间缩减、盲审恢复——判断提示Q是否泄漏了答案信息，综合评分而非单一阈值。
- **溯源**：153-v1-2026-08-05-Phase4三文件审计与修正报告.md, 第27行, 原文引用："改进`audit_leakage()`——实现字面匹配/等价映射/候选空间缩减/盲审恢复四门 123号§23"
- **依赖关系**：依赖：无 / 支撑：知识悖论层——检测检索到的Pattern的Q内容是否泄漏了答案
- **与检索机制的关系**：直接相关。253号第三层"知识悖论"的一个关键风险是：检索到的Pattern的Q内容可能泄漏答案。泄漏检测四门提供了一种已验证的多层检测机制——字面匹配（Q是否直接包含答案文字）、等价映射（Q是否等价于答案）、候选空间缩减（Q是否大幅缩小了答案空间）、盲审恢复（去掉Q后能否恢复答案）。这可以作为Pattern入库和检索后的质量门。

### 原语：Agent依赖代理三种指标
- **ID**：153-P18
- **类型**：操作原语
- **描述**：用三种代理指标检测工作智能体是否对提示产生了不当依赖（如只会做被提示的题、离开提示就不会做）。
- **溯源**：153-v1-2026-08-05-Phase4三文件审计与修正报告.md, 第79行, 原文引用："§23 Agent依赖代理3种 ✅ 已实现 side_effect_logger.py复用Phase 3"
- **依赖关系**：依赖：无 / 支撑：效果度量——评估检索到的Pattern是否导致工作智能体产生依赖
- **与检索机制的关系**：间接相关。检索系统如果总是给工作智能体提供高度特定的Pattern，可能导致工作智能体产生依赖（离开提示就不会做）。依赖检测三种指标提供了一种评估检索系统长期副作用的方法。

### 原语：非泄漏干预阶梯（Ramsey阶梯）
- **ID**：153-P19
