# 原语提取：116-POC隔离测试方案-独立目录+tmux监督

## 文档概述

116号文档定义了POC对照实验的隔离测试方案，核心解决三个问题：（1）subagent不能看到数学大师项目方法论（防作弊）；（2）subagent不能用网络搜索（测内在能力）；（3）master agent能观察subagent完整工作过程（审计行为）。方案采用"独立目录+AGENTS.md软限制+tmux监督"的组合策略，包含A/B两组对照实验设计（A组无依赖图提示，B组有依赖图提示），通过tmux capture-pane实现全程审计。

文档虽然是一个测试隔离方案，但其中包含的多项设计决策——角色知识隔离、过程可观察性、依赖图作为检索提示、A/B对照实验设计、违规检测审计——均可作为构造253号检索机制的原语。特别是：角色知识隔离直接关联知识悖论层，依赖图提示直接关联Pattern提取层，tmux过程观察直接关联状态感知层，A/B对照设计直接关联检索效果度量。

### 原语：隔离环境下的能力边界测试——在剥夺外部辅助条件下测量真实能力

- **与检索机制的关系**：直接支撑253号检索系统的效果评估方法论。253号第7.3节提到需要"实验验证：用原型跑guided实验，验证检索的准确率和延迟"。116号提供了一种系统的能力边界测试方法论：先在隔离条件下测量agent的纯内在能力（A组baseline），再在有辅助条件下测量agent的增强能力（B组），两者的差值就是辅助系统（检索系统）的净效果。这为检索系统的效果度量提供了实验范式：检索系统的价值 = 有Pattern辅助时的表现 - 无Pattern辅助时的表现。这个差值越大，检索系统越有价值。如果差值不显著，说明检索系统提取的Pattern没有真正帮助agent——要么提取了错误的Pattern，要么Pattern的形式不对，要么知识悖论导致Pattern无法被有效利用。
