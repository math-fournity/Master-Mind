> **提取目的**：从111号文档中提取所有可能作为检索机制原语的思想片段

## 提取总览

111号文档定义了知识搜集的优先级逻辑——"先搜集什么"。其核心洞察是：系统价值在于装AI不会的东西，越难、越妙、越新，越应优先。文档包含三级优先级体系（P0-P3）、"难妙新"三准则、结构化存档格式（含元数据+依赖关系+L1/L2/L3提取）、并行subagent搜集策略等。

这些内容与253号检索问题的关联在于：111号定义了**知识/Pattern存储的结构、索引维度、优先级排序逻辑、角色分工**——这些正是检索机制底层所需的数据结构、索引结构和排序机制原语。

共提取 **28个原语**。

### 原语：反直觉优先级原则
- **ID**：111-P1
- **类型**：概念框架
- **描述**：优先装入AI不会的知识而非AI已会的基础知识，因为装入AI已会内容的边际价值低。
- **溯源**：111-知识搜集优先级方案-最难最妙最新.md, 第9-11行, 原文引用："直觉上，应该先装"基础"知识（教材定理），再装"高级"知识（前沿论文）。但这是错的。"
- **依赖关系**：依赖：无 / 支撑：AI已知度作为优先级信号（111-P2）、边际价值原则（111-P6）
- **与检索机制的关系**：直接支撑检索的排序逻辑——检索系统在多个候选Pattern中做选择时，应优先返回AI最不可能会的Pattern。这为检索结果的排序提供了价值导向：不是返回最相似的，而是返回边际价值最高的。

### 原语：AI已知度作为优先级信号
- **ID**：111-P2
- **类型**：性质标准
- **描述**：用"AI是否已会"（高/中/低/无）作为知识优先级的判据，AI越不会的越优先。
- **溯源**：111-知识搜集优先级方案-最难最妙最新.md, 第15-26行, 原文引用："| 标准教材定理（Cayley-Hamilton, 微积分基本定理...） | **已会** | 低 | P3 |" 及 "| Ramanujan笔记中冷僻恒等式 | **不会** | **高** | **P0** |"
- **依赖关系**：依赖：反直觉优先级原则（111-P1） / 支撑：三级优先级分层（111-P3）、AI已知度分类字段（111-P9）
- **与检索机制的关系**：AI已知度可作为Pattern的元数据标签，检索时用于过滤和排序——当多个Pattern匹配当前状态时，优先返回AI已知度低的Pattern（即AI自身不大会用的那个），这正是稀疏矩阵检索的价值所在。

### 原语：三级优先级分层（P0/P1/P2/P3）
- **ID**：111-P3
- **类型**：结构原语
- **描述**：将知识按"AI最不可能会的→AI基本会的"分为P0/P1/P2/P3四级，P0立即搜集，P3只做索引。
- **溯源**：111-知识搜集优先级方案-最难最妙最新.md, 第28-59行, 原文引用："**P0（第一批，立即搜集）——AI最不可能会的**" ... "**P3（远期）——AI完全会的，只做索引**"
- **依赖关系**：依赖：AI已知度作为优先级信号（111-P2） / 支撑：优先级作为元数据字段（111-P12）、只做索引不做内容策略（111-P15）
- **与检索机制的关系**：为Pattern存储提供分层索引结构——P0级Pattern做全量存储+精细索引，P3级Pattern只做索引条目。检索时可按优先级层级逐层搜索：先在P0中找，找不到再降级。这是多级索引的原型。

### 原语："难妙新"三准则
- **ID**：111-P4
- **类型**：概念框架
- **描述**：用"难"（超出AI常规推理能力）、"妙"（方法出人意料）、"新"（训练数据中不存在）三个准则判断知识的优先级。
- **溯源**：111-知识搜集优先级方案-最难最妙最新.md, 第61-69行, 原文引用："| **难** | 超出AI常规推理能力 | 需要多步跨领域推理/需要深层直觉/需要非显然构造 | | **妙** | 证明方法出人意料 | 连接看似无关领域/用简单工具解决复杂问题/揭示隐藏结构 | | **新** | AI训练数据中不存在 | 2023年后发表/冷僻文献/非主流但深刻的工作 |"
- **依赖关系**：依赖：无 / 支撑：多准则满足度评分（111-P5）、难准则定义（111-P26）、妙准则定义（111-P27）、新准则定义（111-P28）
- **与检索机制的关系**：三准则可作为Pattern的特征维度，用于Pattern的分类索引和检索排序。检索系统可先识别当前状态"需要什么类型的知识"（难的/妙的/新的），再在对应特征维度上做检索。

### 原语：多准则满足度评分
- **ID**：111-P5
- **类型**：操作原语
- **描述**：三准则满足越多，优先级越高——用准则满足计数作为排序分值。
- **溯源**：111-知识搜集优先级方案-最难最妙最新.md, 第69行, 原文引用："**三准则满足越多，优先级越高。**"
- **依赖关系**：依赖："难妙新"三准则（111-P4） / 支撑：无
- **与检索机制的关系**：提供了一种多维度评分排序机制——当多个Pattern与当前状态匹配时，可按多准则满足度（而非单一相似度）排序候选Pattern。这是检索结果精排的评分模型原型。

### 原语：边际价值原则
- **ID**：111-P6
- **类型**：概念框架
- **描述**：系统价值不在于装AI已会的东西，而在于装AI不会的——装入的边际价值决定优先级。
- **溯源**：111-知识搜集优先级方案-最难最妙最新.md, 第5行, 原文引用："数学大师系统的价值不在于装AI已经会的东西，而在于装AI不会的。越是难、妙、新，越是AI本身可能不会的，越应该优先装入。标准教材内容AI已经会了，装入的边际价值低。"
- **依赖关系**：依赖：无 / 支撑：反直觉优先级原则（111-P1）、AI已知度作为优先级信号（111-P2）
- **与检索机制的关系**：为检索系统提供价值导向——检索的目标不是返回"最相似"的Pattern，而是返回"边际价值最高"的Pattern。这区别于普通检索的相关性排序，引入了基于知识缺口的效用排序。

## 备注

1. 111号文档是知识搜集的优先级方案，其核心关注点是"先搜集什么"而非"怎么检索"。但其中定义的数据结构（元数据模式、依赖关系字段、L1/L2/L3提取）、排序逻辑（优先级分层、难妙新三准则、多准则评分）、索引维度（领域、难度、AI已知度、来源）、角色分离模式（搜集者vs验证者）和图结构概念（依赖链、ArangoDB存储）都是构造检索机制的原语。

2. 111号文档与253号检索问题的最直接连接点是：111号定义了**存什么、怎么存、存成什么结构**，而253号问的是**怎么从存储中检索**。前者是后者的前置条件——没有111号定义的存储结构，253号的检索问题无从谈起。

3. 特别值得注意的是111-P24（角色分离）与253号第三层"知识悖论"的关联——111号已经实践了"搜集者"和"验证者"的角色分离，这个模式可直接迁移为253号中"匹配器"角色的设计原型。
