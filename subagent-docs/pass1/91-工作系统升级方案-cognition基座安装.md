# 原语提取：91-工作系统升级方案·cognition基座安装到数学项目

## 文档概述

本文档是将"稀疏矩阵/依赖图/拓扑验证/ArangoDB"认知基座安装到数学项目AI自身工作系统的元层面升级方案。文档定义了认知单元图的数据结构（~30个认知单元+依赖边+版本链）、CP1-CP6检查点工作流、Hook集成机制（SessionStart+PostCompaction+git post-commit）、三层维护机制，以及与数学依赖图的交叉引用设计。文档与检索机制高度相关——其核心就是"从种子认知单元出发，通过图遍历检索所有前置认知"的完整检索流程设计。
