### 原语：三层漏斗筛选架构
- **ID**：210-P1
- **类型**：结构原语
- **描述**：通过三层逐步收窄的漏斗（候选筛选→baseline测试→卡点分析）从海量候选中精确定位目标，每层用不同判据过滤，前一层输出是后一层输入。
- **溯源**：210-v1-2026-08-06-寻找裸devin做不出来的难题选题策略.md, 第38行, 原文引用："## 2. 选题策略——三层漏斗"
- **依赖关系**：依赖：无（顶层架构）/支撑：多级索引检索（P19）、候选Pattern分阶段过滤
- **与检索机制的关系**：直接支撑检索第二层（Pattern提取）。253号§3.3第二层提到"全量扫描O(n)不可行"，三层漏斗提供了一种分阶段过滤架构——先用粗粒度判据快速筛掉大部分不相关Pattern，再用细粒度判据精排，避免全量扫描。253号§6.4的"多级索引"方向与此同构。

### 原语：卡点类型分类体系
- **ID**：210-P2
- **类型**：概念框架
- **描述**：将AI的卡住状态分为四种类型（lack_knowledge、uncertain、strategy_exhaustion、response_too_short+内容空洞），每种类型对应不同的干预适配性。
- **溯源**：210-v1-2026-08-06-寻找裸devin做不出来的难题选题策略.md, 第74-78行, 原文引用："用205-A的AI诊断分类：lack_knowledge → 适合（系统可以给知识候选）/ uncertain → 适合（系统可以给方向验证）/ strategy_exhaustion → 适合（系统可以给新策略）/ response_too_short + 内容空洞 → 不适合（能力问题）"
- **依赖关系**：依赖：无/支撑：状态感知分类索引（P20）、触发条件类型化（P3）
- **与检索机制的关系**：直接支撑检索第一层（状态感知）。253号§3.3第一层问"助理智能体怎么看到工作智能体需要什么"，卡点类型分类提供了一种状态分类方案——先识别当前状态属于哪种卡点类型，再在该类型下检索Pattern。这可以作为状态感知的第一步粗分类。

### 原语：可引导性判定标准
- **ID**：210-P3
- **类型**：性质标准
- **描述**：区分"卡在不知道用什么工具/方向"（可引导）与"卡在计算错误"或"需要全新概念"（不可引导），只有前者适合系统引导干预。
- **溯源**：210-v1-2026-08-06-寻找裸devin做不出来的难题选题策略.md, 第28-29行, 原文引用："卡点类型 | 卡在'不知道该用什么工具/方向'而非'计算错误'——后者是能力问题，不是引导能解决的 | 可引导性 | 卡点类型属于系统能给提示的范畴（lack_knowledge/uncertain/strategy_exhaustion），不是'需要全新数学发现'"
- **依赖关系**：依赖：卡点类型分类体系（P2）/支撑：触发条件适用性过滤、Pattern检索的前置门控
- **与检索机制的关系**：支撑检索第一层（状态感知）。可引导性判定是检索的前置门控——如果当前状态不可引导（计算错误或需要全新概念），则不需要检索Pattern，直接跳过。这减少了检索系统的无效调用。

### 原语：稳定性判定（多次运行）
- **ID**：210-P4
- **类型**：操作原语
- **描述**：通过多次（≥3次）独立运行判定结果是稳定的还是偶然的——3次全错才算"做不出来"，1次对需扩大样本到5次。
- **溯源**：210-v1-2026-08-06-寻找裸devin做不出来的难题选题策略.md, 第57-62行, 原文引用："每题跑3次（稳定性判定）/ 3次全错/不完整 → 入选（裸devin做不出来）/ 3次中1次对 → 边缘（需扩大样本到5次）/ 3次全对 → 淘汰（裸devin能做，不需要引导）"
- **依赖关系**：依赖：无/支撑：Pattern效果度量的统计可靠性（P5）
- **与检索机制的关系**：间接相关。稳定性判定方法可用于Pattern历史使用记录的效果度量——一个Pattern的效果不能只看一次使用，需要多次使用统计才能判定其可靠性。253号§1.5提到Pattern包含"历史使用记录"，稳定性判定提供了历史记录的统计方法。

### 原语：auto_audit正确性判定
- **ID**：210-P5
- **类型**：操作原语
- **描述**：用auto_audit_report判定AI输出的正确性，不能只看"AI说自己做对了"——需要独立验证机制。
- **溯源**：210-v1-2026-08-06-寻找裸devin做不出来的难题选题策略.md, 第64行, 原文引用："验证标准：用auto_audit_report判定正确性，不能只看'AI说自己做对了'"
- **依赖关系**：依赖：无/支撑：Pattern效果度量、历史使用记录的客观评估
- **与检索机制的关系**：间接相关。253号§1.5 Pattern包含"历史使用记录：这个Pattern过去在什么情况下用过、效果如何"。auto_audit提供了一种客观效果评估机制——Pattern的效果不能依赖AI自评，需要独立审计。这支撑了Pattern存储中效果字段的数据质量。

### 原语：候选概率排序
- **ID**：210-P6
- **类型**：操作原语
- **描述**：对候选来源按"裸devin可能做不出来"的概率排序，优先从高概率来源开始检索。

- **依赖关系**：依赖：无/支撑：Pattern检索的优先级排序、候选Pattern的预排序
- **与检索机制的关系**：支撑检索第二层（Pattern提取）。在从海量Pattern中检索时，可以按"与当前状态匹配的概率"对Pattern来源预排序，优先在高概率区域检索。这与253号§6.4的"按思维模式分类索引"方向一致——先在高概率类别下检索。

### 原语：构造性洞察优先原则
- **ID**：210-P7
- **类型**：性质标准
- **描述**：需要构造辅助对象的题（如构造q(x)=x²+x-1）优先于纯技巧题——构造性洞察是系统引导能发力的地方，纯技巧题引导帮不上。
- **溯源**：210-v1-2026-08-06-寻找裸devin做不出来的难题选题策略.md, 第235-236行, 原文引用："构造性洞察+跨领域工具优先：需要构造辅助对象的题 > 纯技巧题 / 理由：构造性洞察是系统引导能发力的地方；纯技巧题引导帮不上"
- **依赖关系**：依赖：无/支撑：Pattern优先级排序、触发条件特征标注
- **与检索机制的关系**：支撑检索第二层（Pattern提取）。Pattern可以按"是否涉及构造性洞察"标注，检索时优先返回构造性洞察类Pattern。253号案例中Q2（寻找统一编码，Level 0.85）和Q5（投影分解，Level 0.7）都涉及构造性洞察，这类Pattern应优先检索。

### 原语：跨领域工具识别
- **ID**：210-P8
- **类型**：概念框架
- **描述**：识别需要跨领域工具的题（如用badly approximable解代数题），这类题的卡点往往是知识瓶颈，需要特定知识注入而非思维模式提示。
- **溯源**：210-v1-2026-08-06-寻找裸devin做不出来的难题选题策略.md, 第193行, 原文引用："需要跨领域工具（如badly approximable解代数题）"
- **依赖关系**：依赖：无/支撑：知识瓶颈识别（P9）、Pattern的Level标签校准
- **与检索机制的关系**：支撑检索第一层（状态感知）和第三层（知识悖论）。跨领域工具识别帮助状态感知判断"当前卡点是知识瓶颈还是思维方向问题"——如果是知识瓶颈（如253号案例Q9的badly approximable），需要检索Level→0的Pattern；如果是思维方向问题，需要检索Level→1的Pattern。这也直接关联知识悖论：跨领域知识是最容易触发知识悖论的场景。

### 原语：知识瓶颈与思维方向二分
- **ID**：210-P9
- **类型**：概念框架
- **描述**：卡点分为"不知道该用什么工具/方向"（思维方向问题，可引导）和"需要特定知识"（知识瓶颈，需知识注入）两类，干预策略不同。
- **溯源**：210-v1-2026-08-06-寻找裸devin做不出来的难题选题策略.md, 第70-72行, 原文引用："卡在'不知道用什么工具' → 适合系统引导（入选实验组）/ 卡在'计算错误' → 不适合引导（是能力问题）/ 卡在'需要全新概念' → 不适合引导（超出系统知识库）"
- **依赖关系**：依赖：卡点类型分类体系（P2）、跨领域工具识别（P8）/支撑：Pattern按Level分层检索、知识悖论破解方向
- **与检索机制的关系**：直接支撑检索三层。第一层：状态感知先做二分判断（知识瓶颈vs思维方向）；第二层：根据二分结果在不同Level区间检索Pattern；第三层：知识瓶颈场景是知识悖论最尖锐的场景——253号§3.2.4难点3正是这个问题。253号案例中Q9（Level 0.2, 非特定性0.9）是知识瓶颈，Q1-Q5（Level 1.0, 非特定性≤0.1）是思维方向。

### 原语：时间新优先（AI训练数据缺口）
- **ID**：210-P10
- **类型**：操作原语
- **描述**：优先选择AI训练数据中不太可能包含的内容——时间上新（2024-2025>2020-2023>2020前），语言上非英文（中文/日文/韩文>英文），讨论度低（AoPS讨论少>讨论多）。
- **溯源**：210-v1-2026-08-06-寻找裸devin做不出来的难题选题策略.md, 第228-233行, 原文引用："时间新优先：2024-2025年题 > 2020-2023年题 > 2020年前 / 理由：AI训练数据有时间截止，新题不太可能被详细解答过 / AI训练数据缺口优先：中文/日文/韩文题 > 英文题；AoPS讨论少的题 > 讨论多的题"
- **依赖关系**：依赖：无/支撑：Pattern新鲜度索引、Pattern来源可信度标注
- **与检索机制的关系**：间接相关。时间新优先原则可迁移到Pattern检索——新积累的Pattern（近期实验中验证的）可能比早期Pattern更可靠，因为系统在迭代中改进了。同时，AI训练数据缺口概念关联知识悖论：如果Pattern涉及的数学知识在AI训练数据中稀缺，助理智能体更不可能自己提出该Q，知识悖论更尖锐，但也意味着Pattern存储的价值更大。

- **依赖关系**：依赖：无/支撑：Pattern效果度量的极端值信号、高价值Pattern定位
- **与检索机制的关系**：间接相关。反向筛选思路可迁移到Pattern检索——如果一个Pattern在历史使用中从未成功过（效果"零分"），它可能是一个无效Pattern需要淘汰；反之，如果一个Pattern在极难场景下唯一成功，它是高价值Pattern需要优先索引。极端信号是Pattern质量评估的快速定位手段。

### 原语：从一道题到一类题的维度展开
- **ID**：210-P12
- **类型**：概念框架
- **描述**：不要只在一个题库里找——要按"这个难度级别有哪些系统性来源"打开维度，从单个实例出发，逐层向上抽象到类别，再在类别下系统搜索。
- **溯源**：210-v1-2026-08-06-寻找裸devin做不出来的难题选题策略.md, 第186行, 原文引用："关键洞察：不要只在一个题库里找——要按'这个难度级别有哪些系统性来源'打开维度。每个国家的数学奥林匹克决赛最后一题，都是这个水平的题。"
- **依赖关系**：依赖：无/支撑：Pattern聚类与泛化（P13）、索引维度设计
- **与检索机制的关系**：支撑检索第二层（Pattern提取）。维度展开思路可迁移到Pattern组织——不要把每个Pattern当作孤立条目，而要按"这个Pattern属于哪个思维模式类别"展开维度，在类别下系统组织。253号§6.4的"按思维模式分类索引"正是这种维度展开。检索时先定位类别（维度），再在类别下检索具体Pattern。
