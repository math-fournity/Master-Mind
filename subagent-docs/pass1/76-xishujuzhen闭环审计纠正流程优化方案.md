# 原语提取：76-xishujuzhen闭环审计-纠正流程优化方案

## 文档概述

本文档提出了将"开环审计"（审计发现问题后即结束）升级为"闭环审计-纠正循环"（审计→反馈→修正→再审→...→无瑕疵→结束）的优化方案。文档详细描述了循环终止条件、结构化反馈格式、审计严格程度一致性、审计轨迹记录、评分调整、subagent调用策略、风险缓解等设计点。与检索机制的关系在于：闭环审计-纠正循环本身就是一种"检索→验证→修正→再检索"的反馈闭环原语，其结构化反馈格式、版本迭代管理、全量审计策略、审计轨迹追踪等均可作为检索机制质量保证环节的构造积木。

### 原语：闭环审计-纠正循环
- **ID**：76-P1
- **类型**：操作原语
- **描述**：审计不是终点而是循环的起点，通过"审计→反馈→修正→再审"的迭代循环，直到无瑕疵才终止，实现过程纠偏而非事后验尸。
- **溯源**：76, 第25-27行, 原文引用："审计的目的之一是发现问题，之二是引导纠正问题。发现问题、纠正问题是一个循环，直至完美才能结束。" + "审计不是终点，是循环的起点。审计→反馈→修正→再审→...→无瑕疵→结束。"
- **依赖关系**：
  - 依赖：结构化反馈格式（76-P3）、循环终止条件（76-P2）
  - 支撑：检索结果的质量保证闭环——检索到的Pattern经过验证后如果发现问题，反馈修正并重新检索/验证
- **与检索机制的关系**：检索机制可以采用类似的闭环结构——初次检索结果经过验证/审计后，如果发现检索不完整或有错误，反馈给检索模块进行修正并重新检索，直到检索结果通过验证。这为检索机制提供了自纠偏的能力。
