# 原语提取：75-xishujuzhen-POC7验证结果

## 文档概述

本文档记录了xishujuzhen验证体系POC-7的实验结果。POC-7在规模维度（12限全量，71节点106边）和螺旋维度（动态螺旋环路）上做了最大规模扩展，验证了大规模依赖图的可处理性、动态螺旋环路的有效性、以及B组（依赖图+交叉审计+动态螺旋）相对于A组（纯知识）的持续优势。文档中的依赖图结构、交叉审计机制、覆盖率验证、动态螺旋迭代修正、KC嵌入、评分维度体系等均可作为检索机制的原语。
