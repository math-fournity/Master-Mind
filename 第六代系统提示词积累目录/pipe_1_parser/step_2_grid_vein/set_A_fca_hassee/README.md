# 套A：用FCA/Hasse图启发

## 设计思路

用FCA闭包算子和Hasse图的概念启发AI的直觉，让AI理解"格"的结构。不运行FCA算法，只用作理论指导。

## 和其他套的区别

- 套B（纯直觉）：不用FCA概念，直接让AI用数学直觉
- 套C（例子引导）：用具体例子引导，不用FCA概念
- 套D（反模式）：用反模式引导，先说对的再说错的

## 版本演进

- V1：只给FCA闭包算子定义（320号§2.3）
- V2：+Hasse图启发+例子+8种复杂情况（322号§1）
- V3：+为什么+影响例子+7种反模式（323号§1）
- V4：+树状/线性输入区分，方案C一份基础+两个附加章节（324号§1）

## 验证状态

## 并发使用

可以和套B/C/D并发使用——多套提示词各自给AI处理同一输入，结果汇总（取并集得到更完整的trace集合）或各自流向下一个Pipe（各自驱动引导树长出不同分支）。
