# 套A：用FCA/Hasse图启发

## 设计思路

用FCA闭包算子和Hasse图的概念启发AI的直觉，让AI理解"格"的结构。不运行FCA算法，只用作理论指导。

## 和其他套的区别

- 套B（纯直觉）：不用FCA概念，直接让AI用数学直觉
- 套C（例子引导）：用具体例子引导，不用FCA概念
- 套D（反模式）：用反模式引导，先说对的再说错的

## 并发使用

### 套内4并发（V5/V7/V8/V9）——已决定为Pipe 1运行时架构

2026-08-10决定：Pipe 1 step_2 grid_vein在运行时采用4并发——V5/V7/V8/V9四个版本并发跑同一道题，取trace并集。

4个版本各有所长，不是简单的子集关系：
- V5独有"归纳递降三种方式"（自由直觉发现）
- V7独有"预防性vs修复性避障"+"Case间递进"（结构化约束让注意力分布不同）
- V8独有"x贯穿"+"aₙ作为工具"（跨闭元素元模式引导）
- V9独有"WLOG闭环"+"r的生命周期"（元反思步骤）

每个版本的结构化约束既是引导也是盲区，4并发取并集覆盖所有优势区。

详见技术说明书`06-五代继承/02-第六代的独特贡献.md` "4并发方案"节。

降级选项：成本瓶颈时可降为2并发（V5+V9），覆盖大部分独有发现。

### 套间并发（套A/B/C/D）

可以和套B/C/D并发使用——多套提示词各自给AI处理同一输入，结果汇总（取并集得到更完整的trace集合）或各自流向下一个Pipe（各自驱动引导树长出不同分支）。
