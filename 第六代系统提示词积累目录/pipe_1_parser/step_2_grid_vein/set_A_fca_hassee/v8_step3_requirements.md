# 第3步要求：关键实体角色特征标注

## 你要做的

读取 `segments.json`（你已经在第1步划好的段），识别证明中的**关键实体**，对每个段标注关键实体的**角色特征**。

**这是V8的特色步骤**——关键实体角色特征使得形式上下文能捕获跨闭元素元模式。后续的综合分析阶段会从这些特征中识别跨闭元素元模式。

## 什么是关键实体角色特征

关键实体是证明中贯穿多个段的变量、技巧或策略。对每个段，标注关键实体在这个段中扮演了什么角色。

### 识别关键实体

先通读整个证明，识别出关键实体——那些贯穿多个段的变量/技巧/策略。常见的关键实体类型：

- **关键变量**：如x、aₙ、s、z等——在多个段中被使用的变量
- **关键技巧**：如swap技巧、鸽巢论证、注入映射等——在多个段中被使用的技巧
- **关键策略**：如归纳-缩减-构造-验证、避障策略等——贯穿多个段的策略

### 标注角色特征

对每个段，标注关键实体在这个段中的角色。角色特征的命名规范：

- `"{实体}的使用"`——如"x的使用"、"aₙ的使用"、"swap技巧"
- `"{实体}的{角色}"`——如"aₙ的最大性"、"x的分类标准角色"、"aₙ的跳过障碍角色"

### 例子

如果关键变量x在段4中用作分类标准，在段6中用作bad index基准，在段9中用作M'缩减边界：

- 段4：`["x的使用", "x的分类标准角色"]`
- 段6：`["x的使用", "x的bad index基准角色"]`
- 段9：`["x的使用", "x的M'缩减边界角色"]`

如果aₙ在段11中用作跳过障碍，在段19中用作修复性swap：

- 段11：`["aₙ的使用", "aₙ的跳过障碍角色"]`
- 段19：`["aₙ的使用", "aₙ的修复性swap角色"]`

## 标注原则

- 先识别关键实体（通常3-8个），再对每个段标注角色特征
- 不是每个段都有关键实体角色特征——如果某段没有使用任何关键实体，留空数组
- 同一关键实体的角色特征用统一的命名规范
- 角色特征要具体——"x的使用"太泛，"x的分类标准角色"更具体

## 产出格式

填充 `role_features.json`，格式如下：

```json
{
  "version": "V8",
  "phase": "grading",
  "step": 3,
  "key_entities_identified": ["x", "aₙ", "s", "swap技巧"],
  "features": {
    "段1": [],
    "段2": ["x的使用", "aₙ的使用"],
    "段3": [],
    "段4": ["x的使用", "x的分类标准角色"],
    "段6": ["x的使用", "x的bad index基准角色"],
    "段9": ["x的使用", "x的M'缩减边界角色"],
    "段11": ["aₙ的使用", "aₙ的跳过障碍角色", "swap技巧"]
  }
}
```

**key_entities_identified**：列出你识别出的所有关键实体。

## 完成后

填充完 `role_features.json` 后，创建 `step3_done.md`（空文件）作为完成标记。
