# 第2步要求：常规思维特征标注

## 你要做的

读取 `segments.json`（你已经在第1步划好的段），对每个段标注**常规思维特征**。

## 什么是常规思维特征

常规思维特征是段的思维特征——如"排序"、"定义变量"、"归纳假设"、"鸽巢论证"、"情况分析"、"构造性证明"、"反证法"、"WLOG归约"等。

特征是思维特征，不是操作内容。比如"构造注入映射"是操作内容，"鸽巢论证"是思维特征。

## 标注原则

- 每个段可以有多个常规思维特征
- 同一思维特征用同一名称（不要有时写"鸽巢论证"有时写"鸽巢原理"）
- 特征粒度适中——太粗导致特征太少，太细导致特征太多
- 如果某段没有明显的常规思维特征，可以留空数组

## 产出格式

填充 `conventional_features.json`，格式如下：

```json
{
  "version": "V8",
  "phase": "grading",
  "step": 2,
  "features": {
    "段1": ["排序", "WLOG归约"],
    "段2": ["定义变量"],
    "段3": ["归纳假设"],
    "段4": ["情况分析"],
    "段5": []
  }
}
```

## 完成后

填充完 `conventional_features.json` 后，创建 `step2_done.md`（空文件）作为完成标记。
