# 第1步要求：段划分

## 你要做的

读取 `input.md` 中的解答文本，把解答分成最细的段。

## 段划分的原则

**脉络**是一条解题路径上所有思维步骤的序列。我们把脉络切成最细的"段"——每段是一个不可再分的思维步骤。

**段是最细的粒度**——如果你能把一段再分成两段，就应该分。但不要分到"一句话一段"——段是"一个思维步骤"，不是"一句话"。

## 产出格式

填充 `segments.json`，格式如下：

```json
{
  "version": "V8",
  "phase": "grading",
  "step": 1,
  "segments": [
    {
      "id": "段1",
      "content": "这段在做什么（简述）",
      "features": []
    },
    {
      "id": "段2",
      "content": "这段在做什么（简述）",
      "features": []
    }
  ]
}
```

**features留空数组**——特征标注是后续步骤的事，这一步只做段划分。

## 完成后

填充完 `segments.json` 后，创建 `step1_done.md`（空文件）作为完成标记。
