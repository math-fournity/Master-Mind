## 2. 数据流

```
推理AI的thinking文本
     │
     ▼ mitmproxy流式截获
[Pipe 0] 拓扑化
     │  信号词频次统计 → 拓扑维度取值判定
     ▼ TopologyResult(problem_type, ai_method_type, gap_type, signal_counts)
[Pipe 1] 形式化过滤
     │  AQL查询tell_db → 大概念字段匹配 → 计算匹配分数 → 排序
     ▼ List[TellCandidate]（候选tell列表，允许无效≤50%）
[Pipe 2] 小概念标记分辨
     │  加载概念文件 → 小概念信号词在thinking中标记 → combined_score排序
     ▼ TellResult（精准识别的tell）
方向匹配
     │  tell.hint_ids → hint_db查询 → 获取hint方向
     ▼ hint方向（如T01模算术）
脉络构造
     │  path_from_root → construct_path_text → 脉络文本
     ▼ 脉络+方向
启动新AI
     │  solver-harness launch → 新devin cli实例
     ▼ 新AI在全新Session中探索新方向
```
