## 1. 概念文件的JSON格式

```json
{
  "concept_file_id": "CF-structural-enumeration-mismatch",
  "parent_big_concept": {
    "problem_type": "structural_existence",
    "ai_method_type": "enumeration_brute_force",
    "gap_type": "method_problem_mismatch"
  },
  "small_concepts": [
    {
      "name": "素数存在性",
      "standard_description": "AI在枚举序列参数a的值，试图用covering system覆盖所有情况，但问题是Mersenne素数的存在性，需要用二次剩余/Euler准则",
      "signal_markers": ["mersenne", "primality", "covering", "covering_system"],
      "related_tell_ids": ["tell-A-1631"]
    },
    {
      "name": "整除性判定",
      "standard_description": "AI在枚举差分参数a的值，试图逐一验证条件，但问题是最大奇因子差的整除性判定，需要用2-adic赋值分case分析模4行为",
      "signal_markers": ["largest_odd_divisor", "divisibility_4", "p_adic", "difference"],
      "related_tell_ids": ["tell-B-1709"]
    }
  ],
  "version": 2,
  "last_updated": "2026-08-08"
}
```

## 2. 文件命名规范

`concept_files/<大概念简述>.json`

如：`concept_files/CF-structural-existence-enumeration_brute_force-method_problem_mismatch.json`

## 3. POC-VMS-10中的概念文件示例

两个tell的大概念拓扑完全相同，放入同一个概念文件。Pipe 2加载后用信号词区分：
- 1631题thinking中mersenne/primality/covering命中856次→选tell-A
- 1709题thinking中largest_odd_divisor/divisibility_4/p_adic命中41次→选tell-B

## 4. 概念文件与concept_tree集合的同步

文件系统中的概念文件和ArangoDB中的concept_tree集合保持一致。修改一处时同步更新另一处。

## 5. 版本管理

随tell数量增长更新——新增小概念或新增信号词时版本号递增。
