## 1. 为什么需要标准化语言描述

**有些tell不适合形式化描述**——它们的特征无法用拓扑结构（problem_type/ai_method_type/gap_type）完全捕捉。这些tell必须用**语言**去处理。

用户在287号第六次原文中明确指出：

> "还有一些不适合形式化的，必须要语言去处理的，我们可以通过标准化对tell的语言描述来应对。"

形式化（拓扑结构匹配）和语言描述不是对立的，而是**互补的**：
- 形式化处理能形式化的tell特征 → 在Pipe 0+Pipe 1中完成
- 标准化语言描述处理不能形式化的tell特征 → 在Pipe 2中通过小概念标记分辨完成

## 2. 标准化语言描述的格式

一个tell的标准化语言描述包含三个部分：

1. **AI在做什么**——AI当前使用的方法描述
2. **问题是什么**——AI面临的问题结构描述
3. **正确的方向是什么**——应该往什么方向探索

### POC-VMS-10中的例子

**tell-A**（来自1631题）：
> "AI在枚举序列参数a的值，试图用covering system覆盖所有情况，但问题是Mersenne素数的存在性，需要用二次剩余/Euler准则"

- AI在做什么：枚举序列参数a的值，用covering system覆盖
- 问题是什么：Mersenne素数的存在性
- 正确方向：二次剩余/Euler准则

**tell-B**（来自1709题）：
> "AI在枚举差分参数a的值，试图逐一验证条件，但问题是最大奇因子差的整除性判定，需要用2-adic赋值分case分析模4行为"

- AI在做什么：枚举差分参数a的值，逐一验证
- 问题是什么：最大奇因子差的整除性判定
- 正确方向：2-adic赋值分case分析

## 3. 从标准化语言描述中提取小概念信号词

标准化语言描述是**小概念信号词的来源**。Pipe 2的小概念标记分辨需要信号词来在thinking中做匹配，这些信号词就是从标准化语言描述中提取的关键词。

### 提取方法

从标准化语言描述中提取具有区分能力的关键词：

**tell-A**的标准化语言描述中的关键词：
- mersenne（Mersenne素数——tell-A特有，tell-B没有）
- primality（素数性——tell-A特有）
- covering_system / covering（covering system——tell-A的AI方法特征）

**tell-B**的标准化语言描述中的关键词：
- largest_odd_divisor（最大奇因子——tell-B特有）
- divisibility_4（被4整除——tell-B特有）
- p_adic（2-adic赋值——tell-B的正确方法）
- difference（差分——tell-B的AI方法特征）

这些关键词就是小概念信号词。它们在thinking中的出现频次决定了Pipe 2的combined_score。

## 4. 标准化语言描述与概念树的关系

标准化语言描述是概念树的**输入**——同一大概念下的不同小概念的标准化语言描述被收集到同一个概念文件中。

例如，大概念"structural_existence + enumeration_brute_force + method_problem_mismatch"下有两个小概念：
- 小概念A（素数存在性）：标准化语言描述和信号词来自tell-A
- 小概念B（整除性判定）：标准化语言描述和信号词来自tell-B

这两个小概念被放入同一个概念文件。当Pipe 1用大概念缩小到这个大概念范围后，Pipe 2加载这个概念文件，用其中所有小概念的信号词做标记分辨。

## 5. 形式化与语言描述的分工

| | 形式化 | 标准化语言描述 |
|---|---|---|
| 适用对象 | 适合形式化的tell特征（拓扑维度） | 不适合形式化的tell特征（具体内容） |
| 处理方式 | 拓扑结构匹配（Pipe 0+Pipe 1） | 概念标记分辨（Pipe 2） |
| 所在Pipe | Pipe 0 + Pipe 1 | Pipe 2 |
| 粒度 | 大概念（粗粒度，3个维度） | 小概念（细粒度，信号词级） |
| 规模应对 | 缩小搜索空间（从10万到数百） | 在缩小的空间内精准识别（从数百到1） |
| 膨胀应对 | 拓扑维度细化 | 概念树管理 |

## 6. 两个tell能用语言表达出区别就能定义概念区分

这是标准化语言描述可行性的理论基础。用户在287号中指出：

> "无论两个tell多么相似，我们都可以用更为细化（小）的概念去进一步区分不同的tell。因为毕竟我们可以用语言表达tell之间的区别，就可以借助定义新的概念这种手段去区分tell。"

这意味着：标准化语言描述的区分能力没有上限。只要两个tell有区别（而它们一定有区别，否则就是同一个tell），就能从它们的标准化语言描述中提取出区分性的关键词，定义为小概念信号词，用Pipe 2区分。

## 7. 标准化语言描述的生成

在当前实现中，标准化语言描述是人工编写的——辅助AI读thinking后，用语言描述tell的三个部分（AI在做什么/问题是什么/正确方向是什么）。

未来的自动化方向：
1. 用NLP方法从AI的thinking中自动提取"AI在做什么"和"问题是什么"
2. 从tell关联的hint中提取"正确方向是什么"
3. 从完整的标准化语言描述中自动提取小概念信号词
