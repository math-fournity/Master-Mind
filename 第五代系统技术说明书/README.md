## 1. 第五代系统是什么

第五代系统是一个**引导式数学解题系统**。它的核心思想是：

> 一个AI（称为"推理AI"）在做数学题时可能会走错路——它选了一个方向走下去，但还有很多方向它没走。另一个AI（称为"辅助AI"）观察推理AI的完整思维过程，识别出那些"可以分叉但AI没分叉"的位置，在这些位置上匹配一个新的探索方向，然后启动一个新的推理AI走这个新方向。这样，一道题的探索过程就长成了一棵树——而不是一条路。

这个系统的核心技术可以概括为一个二元组和三层过滤架构：

- **tell + hint 二元组**：tell 是从推理AI的思维过程中读出的信号——"AI没考虑什么方向"；hint 是给新AI的翻译方向——"应该往什么方向走"。
- **三层 Pipe 架构**：Pipe 0 把思维文本编码为结构化拓扑 → Pipe 1 用大概念做形式化过滤缩小范围 → Pipe 2 用小概念做标记分辨精准识别。

## 2. 系统全景图

```
推理AI在解题（走了一条路，产生了thinking）
     │
     ▼
[Pipe 0] 拓扑化——将thinking变成带有结构和标注的拓扑结构
     │     提取 problem_type / ai_method_type / gap_type
     ▼
[Pipe 1] 形式化过滤——用拓扑相似缩小tell范围（大概念匹配）
     │     从10万级tell中筛出一部分候选（允许无效≤50%，不能漏掉真的）
     ▼
[Pipe 2] 小概念标记分辨——在同分候选中用小概念精准识别
     │     加载概念文件→用小概念信号词做标记分辨→选出真tell
     ▼
识别出的tell → 多对多映射 → hint方向（从字典中匹配的翻译方向）
     │
     ▼
构造脉络（从根到当前节点的路径+方向Q）
     │
     ▼
启动新推理AI（给它脉络+方向，在全新Session中运行）
     │
     ▼
新AI走新分支 → 两棵树生长（引导展开树+解题记录树）
     │
     ▼
在终点节点检索 → 识别新tell → 匹配新hint → 启动新AI → ...
     │
     ▼
某条脉络到达正确解答 → 停机
```

## 3. 五代演进定位

数学大师系统经历了五代演进，第五代是集大成者：

| 代际 | 神话名 | 核心理念 | 在第五代中的角色 |
|---|---|---|---|
| 第一代 | 盘古 | 静态图前置——Master预先知道路线 | 提供拓扑覆盖验证、meta/normal分离、确定性图遍历 |
| 中间代 | 女娲 | 动态控制+角色隔离 | 提供外显思维图T、W_t六类分量、8角色隔离、Hint梯度 |
| 第二代 | 燧人 | 非特定元认知提问——不给答案给启发 | 提供形状匹配、Level连续谱、DFS引导架构、回溯铁律 |
| 第三代 | 伏羲 | 形式化边界推进 | 提供识别"不自然"、两种计算、数据基座、路径结构匹配 |
| **第五代** | **（待命名）** | **集大成者** | **tell+hint二元组 + 三层Pipe架构 + 概念树** |

## 5. 文件格式约定

每个文件包含以下结构：

- **标题**：文件的主题
- **前置阅读**：理解本文件需要先读的文件（如有）
- **关联文件**：与本文件有概念交叉的文件
- **正文**：自包含的内容，不依赖其他文件即可理解
- **来源**：内容来自哪些已加载文档（dev-docs编号）

## 6. 关键约定

- **自包含原则**：每个文件可以独立阅读。新概念在首次出现时给出完整解释，不假设读者已经读过其他文件。
- **术语一致性**：tell/hint/Pipe/拓扑/概念树等术语在全说明书中的定义一致，详见09-附录/01-术语表.md。
- **代码引用**：涉及工程实现的内容会引用具体代码文件和函数名，但不包含完整代码。代码文件清单见291号文档第七节。
