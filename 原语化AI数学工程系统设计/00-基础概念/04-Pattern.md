## 什么是Pattern

Pattern是稀疏矩阵中存储的"什么时候该提示什么"的经验单元。每个Pattern描述一个"当推理智能体处于某种状态时，应该发送什么提示"的关系。

Pattern是检索的基本单位——当推理智能体停在某个状态时，系统从稀疏矩阵中检索与当前状态匹配的Pattern，找到后发送Pattern中记录的Q内容。

## 完整JSON Pattern示例

以下是Q8对应的完整Pattern（来自矩条件极差题第二问）：

```json
{
  "pattern_id": "P-008",
  "source": "矩条件极差题第二问-Q8",

  "触发条件": {
    "state_description": "推理智能体有了稳定性方程，方程中有一个量D取决于整数k和n的关系，D不能为零但需要估计其下界",
    "key_objects": ["稳定性方程", "量D", "整数k", "整数n"],
    "key_relations": ["D=√5(pn-k)", "p是无理数", "D≠0但|D|的量级未知"],
    "shape": {
      "conclusion_type": "渐近精细下界",
      "condition_type": "等式组（矩条件）",
      "distance": "远",
      "unnatural_types": ["隐藏乘积"],
      "unnatural_description": "稳定性方程中的D隐藏了一个无理数p与整数k/n的逼近关系"
    }
  },

  "Q内容": "你的稳定性方程里有一个量D，它取决于k和n的关系。D能等于0吗？如果D不能等于0，它至少有多大？",

  "Level": 0.5,
  "非特定性": 0.7,

  "Hint级别": "H1",
  "Hint说明": "思维操作——引导AI关注D的下界，不给具体数学知识",

  "历史使用记录": [
    {
      "case": "矩条件极差题第二问",
      "effect": "AI尝试估计|D|但有困难——识别出知识瓶颈",
      "next_pattern": "P-009（badly approximable知识注入）"
    }
  ]
}
```

## Pattern的关键组成部分

| 组成部分 | 作用 | 在检索中的角色 |
|---|---|---|
| 触发条件 | 描述"什么状态下该用这个Pattern" | 检索的查询目标——当前状态匹配触发条件 |
| Q内容 | 该发送什么提示 | 检索的输出——找到Pattern后发送的Q |
| Level | 提示的抽象度 | DFS排序依据——优先探索高Level |
| 非特定性 | 对答案知识的依赖程度 | 泄漏审计依据——非特定性高可能泄漏答案 |
| Hint级别 | 泄漏分级（H0-H4） | 泄漏审计依据——H3以上表示泄漏 |
| 历史使用记录 | 过去在什么情况下用过 | 经验积累——验证Pattern有效性 |

## 各组成部分详解

### 触发条件

触发条件描述"什么状态下该用这个Pattern"，包含：
- **state_description**：对推理智能体当前状态的自然语言描述
- **key_objects**：当前状态中的关键数学对象
- **key_relations**：这些对象之间的关键关系
- **shape**：问题的结构形状（结论类型、条件类型、距离、不自然类型等）

触发条件是检索的查询目标——系统将推理智能体的当前状态与所有Pattern的触发条件进行匹配，找到匹配的Pattern。

### Q内容

Q内容是该发送的具体提示文本。找到匹配的Pattern后，辅助智能体将Q内容发送给推理智能体。

### Level和非特定性

Level和非特定性是两个关键标签，详见 [Level与非特定性](./03-Level与非特定性.md)。在Pattern中，它们用于：
- **Level**：引导展开树中的DFS排序——优先探索高Level（更通用、更抽象）的提示
- **非特定性**：泄漏审计——非特定性高意味着发出这个Q需要知道答案路径，可能泄漏答案

### Hint级别

Hint级别是泄漏分级（H0-H4），从H0（元检查，完全不泄漏）到H4（最终答案，完全泄漏）。H3以上表示泄漏。Hint级别与非特定性相关但不同——Hint级别关注的是提示内容本身是否包含答案信息，非特定性关注的是发出提示是否需要知道答案。

### 历史使用记录

历史使用记录记录过去在什么情况下用过这个Pattern，包括：
- **case**：在哪个题目中用过
- **effect**：效果如何（AI的反应、是否成功、是否识别出后续需求）
- **next_pattern**：使用后自然衔接的下一个Pattern

历史使用记录是经验积累的载体——通过记录每次使用的效果，系统可以验证Pattern的有效性，并建立Pattern之间的衔接关系。

## Pattern与稀疏矩阵的关系

Pattern以结构化形式存储在稀疏矩阵（认知图/数据基座）中。稀疏矩阵是一个ArangoDB图数据库，节点是认知单元/数学元素/思维模式，边是依赖关系。Pattern数量巨大（随着系统积累不断增长，可能达到数十万），但在任何一个具体时刻，只有极少数Pattern与当前状态相关。详见 [稀疏矩阵](./06-稀疏矩阵.md)。
