## 什么是引导展开树

> **术语说明**：本文件使用"引导展开树"这一术语。在256号论文及历史文档中，同一概念被称为"DFS树"（深度优先搜索树）。两者是完全相同的概念——引导展开树是DFS树在本系统中的正式名称，"DFS树"是其在历史文档中的称呼。

引导过程是一棵深度优先搜索（DFS）树。辅助智能体陪着推理智能体做DFS——在每个节点生成候选Q列表，一次发一个，走不通则回溯换方向。

## 树的基本结构

- **节点** = 推理智能体的一个状态（一段推理输出 + 累积context）
- **边** = 辅助智能体发送的一个Q（一个提示/发问）
- **根节点** = 题目本身
- **叶节点** = 成功叶（正确解答）/ 死路叶（卡死或错误方向）/ 截断叶（超限停止）

## ASCII结构图

```
                    [根节点：题目]
                    /              \
              Q1 /                    \ Q1'
               /                        \
        [节点1：A1]                 [节点1'：A1']  ← 回溯后的替代分支
        /         \
    Q2 /           \ Q2'
      /              \
[节点2：A2]     [节点2'：A2']  ← 如果Q2走不通，回溯到节点1，换Q2'
    |
  Q3 |
    |
[节点3：A3]  ← 成功叶（证毕）
```

**图解说明**：
- 从根节点（题目）出发，辅助智能体发送Q1，推理智能体回复A1，到达节点1。
- 在节点1，辅助智能体发送Q2，推理智能体回复A2，到达节点2。
- 如果Q2走不通（死路叶），回溯到节点1，换Q2'，推理智能体回复A2'，到达节点2'。
- 同理，如果Q1走不通，回溯到根节点，换Q1'，进入替代分支。
- 最终到达成功叶（证毕）时，从根到叶的Q路径就是一条完整的QA序列。

## 候选Q的排序

引导者在每个节点生成候选Q列表，按Level降序排列——优先探索高Level（更通用、更抽象）的提示。这是Level SUM最大化的贪心策略。Level的定义详见 [Level与非特定性](./03-Level与非特定性.md)。

## 回溯铁律

**禁止在同一个Session中让AI回溯到某个思路岔口。**

必须启动新Session，重放Q序列到岔口，在岔口换方向。

**原因**：
1. **压缩边界风险**——同一Session中回溯会导致context混乱，AI无法区分"之前的思路"和"新的思路"。
2. **context污染**——之前思路的推理输出已经进入context，回溯后这些输出会干扰新方向的推理。
3. **不可逆性**——AI的推理过程一旦发生，其输出已经影响了对问题的理解，无法在同一Session中"假装没想过"。

**正确做法**：新Session + 重放Q序列到岔口 + 在岔口换方向。

这意味着回溯不是"在同一对话中后退"，而是"开一个新对话，把之前的Q序列重新发一遍到岔口处，然后换一个方向继续"。这样推理智能体在岔口处有一个干净的context，只包含到岔口为止的推理，不包含被回溯的分支。

## 节点同一性

采用"路径同一性为主、状态同一性为辅"的混合定义：
- **node_id由Q路径决定**（确定性）——同一个Q路径必然到达同一个节点
- **节点内容（A）是概率性的**——同一个Q路径，不同Session中推理智能体的回复可能不同
- **引导者判断**——A'和A是否"本质相同"由引导者判断

## 引导展开树与解题记录树的关系

引导展开树是过程，解题记录树是产物。系统所有组件都是为了让树长得更全。引导展开树记录的是探索过程（包括走不通的死路和回溯），解题记录树记录的是最终成功的路径。详见 `../05-两棵树/01-引导展开树.md`。
