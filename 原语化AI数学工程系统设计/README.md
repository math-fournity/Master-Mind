> **本目录是256号论文的原语化升级版。** 256-v4是单体叙事文件（1345行），本目录把同一内容拆分为原语化的文件群——每个文件描述一个概念/问题/设计/洞察，可以独立阅读，通过链接互相关联。论文的结构镜像系统的结构：系统由原语构造，论文由原语描述构造。

## 系统全景（一段话）

数学大师系统是一个引导式数学解题系统。做题AI（推理智能体）在数学题前可能卡住，引导者AI（辅助智能体）通过模式识别找到此刻应考虑的所有方向，注入提示驱动展开。**系统的本质是：在不知道答案的情况下，通过引导展开机制，让AI生长出一棵尽可能完整的解题记录树。** 检索问题——如何从海量Pattern存储中找到此刻应考虑的方向——是预演模式走向实际模式的唯一障碍。

## 文件格式约定

每个文件包含：
- **标题**：概念/问题/设计的名称
- **前置阅读**：理解本文件需要先读的文件（依赖关系）
- **关联原语**：与本文件有空间关系的文件
- **正文**：自包含的内容，不依赖其他文件即可理解
- **来源**：内容来自256号的哪个章节
