## 六、Hint作用机制分析

### 6.1 AI的推理链

1. **读题** → Read ./00128_MH_midhint.txt
2. **计算搜索** → Python搜索到best D = 54，构造0,7,2,9,4,5,8,1,10,3,6
3. **Per-interval上界分解** → D = Σ c_j，每个c_j是区间[j,j+1]的穿越次数
4. **无约束上界** → c_j ≤ max(2min(L-1,R), 2min(L,R)-1)，总和55
5. **关键步骤：lift to local representation Z/2Z** → 分析c_5 ≤ 10的约束条件
   - c_5 = 10要求路径在[5,6]两侧交替11次
   - 偶数索引位置必须在左侧（≤5）且为偶数楼层
   - 但左侧只有3个偶数楼层（0,2,4），需要6个 → 矛盾
   - 因此c_5 ≤ 9
6. **组装全局上界** → D ≤ 25 + 9 + 20 = 54
7. **构造验证** → 0,9,2,7,4,5,8,1,10,3,6 → D = 54 ✓
8. **答案** → 54 × 4 = 216米

### 6.2 Hint的作用

**Hint在这个case中直接起了关键作用。** AI在步骤5中显式写了：

> "Now we lift to the local representation Z/2Z: the parity constraint requires p_i ≡ i (mod 2)"

这正是hint说的"switch to local representation"——把全局约束（奇偶交替）lift到局部表示（Z/2Z）中分析，找到局部矛盾（c_5 ≤ 9），然后组装回全局结论（D ≤ 54）。

**与00995的对照：**
- 00995：hint引导了结构性理解（CRT、2-adic），但突破来自计算搜索
- 00128：hint直接引导了关键步骤（Z/2Z局部表示分析），导致上界证明

**这验证了Mid-Hint的核心假设：** 给一个方向性hint，AI能纠正方向——至少在"切了没提升"这种失败形态上，hint直接引导了从局部发现到全局结论的组装步骤。

### 6.3 两种失败形态的hint作用差异

| 失败形态 | hint作用 | 突破来源 |
|---|---|---|
| 从不切换（00995） | 结构性引导（理解数学结构） | 计算搜索 |
| 切了没提升（00128） | **直接引导关键步骤**（局部→全局组装） | **hint本身** |

**启示：** Mid-Hint对"切了没提升"型失败更有效——AI已经有了局部发现，hint只需要引导组装步骤。对"从不切换"型失败，hint需要引导AI进入全新方向，效果可能更依赖计算工具的辅助。
