## 一、源题

Find all pairs (k, n) of positive integers for which 7^k − 3^n divides k^4 + n^2. **Answer: (2, 4).**

## 二、解法脚本（标准解答的骨架）

1. **奇偶（mod 2）**：7^k − 3^n 为偶 → k^4 + n^2 为偶 → k, n 同奇偶。
2. **关键转折（mod 4 同余矛盾）**：若 k, n 均奇：k^4 + n^2 ≡ 1 + 1 ≡ 2 (mod 4)，而 7^k − 3^n ≡ 7 − 3 ≡ 0 (mod 4)。除数 ≡ 0 (mod 4) 不可能整除 ≡ 2 (mod 4) 的数 → 矛盾。故 k, n 均偶。
3. **强制结构后的下降**：k=2a, n=2b → 7^{2a} − 3^{2b} = (7^a−3^b)(7^a+3^b)，且 7^a−3^b 为偶 → 2(7^a+3^b) | 7^{2a}−3^{2b} | 2(8a^4+2b^2) → 7^a + 3^b ≤ 8a^4 + 2b^2。
4. **增长不等式（归纳）**：a ≥ 4 时 8a^4 < 7^a；b ≥ 3 时 2b^2 + 9 ≤ 3^b → a ≤ 3，穷举三个小 case → 唯一解 (k,n)=(2,4)。

## 三、设障脚本

- **自然入口**：指数整除问题诱导 AI 做"试小值 + 大小估计"（除数指数增长 vs 被除数多项式增长，AI 通常能感到"解必须很小"）。
- **为什么看起来合理**：大小估计确实给出 a 的界——这条路不是死的，它最终在第4步被用到。
- **失败点（结构性）**：大小估计只能处理"均偶"之后的情形；**奇偶类的排除必须靠 mod 4 同余矛盾**（奇奇类：k^4+n^2 ≡ 2 vs 除数 ≡ 0 (mod 4)）。不做局部化，奇偶类永远排除不掉，大小估计对奇数指数差无能为力（7^k − 3^n 对奇奇可以是小偶数如 7−3=4，估计不爆炸）。bare AI 完全偏离（5.4K chars——它甚至没有建立起这个框架）。
- **隐藏结构（TellCore 视角）**：全局（整除关系的存在性）→ 局部（Z/4Z 上：四次幂≡0/1，奇指数幂≡底数本身）→ 局部矛盾淘汰一整个奇偶类 → 强制"均偶"结构（差为平方差，可因式分解）→ 提升回全局（下降+穷举）。
- **证书**：唯一解 (2,4)。
