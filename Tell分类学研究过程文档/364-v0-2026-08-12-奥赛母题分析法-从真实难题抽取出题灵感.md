## 0. 结论先行

用户这个判断是对的，而且应该升级为出题主流程：

```text
真实奥赛母题
  -> 拆自然错路
  -> 抽关键转向
  -> 抽可迁移骨架
  -> 换外壳
  -> 加第二层锁
  -> bare筛选
```

前几轮新造题反复被淘汰，核心原因不是题不“高级”，而是它们的外壳太像经典定理。奥赛母题分析的价值不在于复刻题面，而在于提取那些经典外壳下面的“解题转向结构”。

一句话：

> 不能从奥赛题借题面，要从奥赛题借失败机制和转向机制。

---

## 1. 为什么奥赛题是更好的出题素材

奥赛题天然有四个适合POC的性质：

1. **入口自然**：题面通常短，AI会有自然起手式；
2. **错路稳定**：人类和AI都会被某些表面方法吸引；
3. **转向清楚**：好题往往有一个“原来要这样看”的关键动作；
4. **证明可审查**：正确解通常能在竞赛篇幅内写完，不会变成开放研究题。

这正好对应POC题需要的四个条件：

| POC需求 | 奥赛题提供什么 |
|---|---|
| bare必须有自然失败轨迹 | 奥赛题的自然错路 |
| Tell必须作用在具体瓶颈 | 奥赛题的关键转向 |
| 题目不能toy | 奥赛题的真实复杂度 |
| 结果必须可判定 | 奥赛题的标准证明 |

---

## 2. 正确用法：分析母题，不搬运母题

直接拿奥赛题或轻微改数字，会有训练数据风险。正确做法是把母题拆成六层：

| 层 | 问什么 | 用于新题时保留吗 |
|---|---|---|
| 题面对象 | 是图、数列、几何图形、整数、集合还是游戏？ | 通常要换 |
| 自然错路 | bare AI最可能先做什么？ | 要保留 |
| 失败原因 | 为什么自然错路不够？ | 要保留 |
| 关键转向 | 标准解第一处非自然动作是什么？ | 要保留 |
| 证书/不变量 | 转向后用什么对象封口？ | 要变形保留 |
| 解法篇幅 | 是否1-3页内可完成？ | 必须保留 |

目标不是生成“像某道IMO题”的题，而是生成“会让AI暴露同一种缺口”的题。

## 3. 本地profile给出的母题样本

本轮从 `problem_profiles` 中抽了若干已侧写奥赛题。下面不是复述题解，而是提炼它们作为“出题母题”的可迁移骨架。

### 3.1 IMO 1967 P5：幂和零项的主导层剥离

**problem_id**：`compfiles_imo1967p5`  
**profile key insight**：按最大绝对值分层；无限多次抵消迫使主导层符号和为0；剥离主导层后递归。

母题骨架：

```text
表面：很多项的幂和/指数和满足无限多次消失
错路：生成函数、Newton恒等式、线性递推
转向：按增长率最大层分组
证书：小层总量被主导层压倒，所以主导层必须精确抵消
递归：剥掉主导层，重复
```

可迁移出题灵感：

- 不一定用幂和，可以换成带参数的权重和、矩阵迹、路径权重、字符串权重；
- 核心锁是“无限多次等式 + 增长率分层 + 主导层整数/符号约束”；
- Tell目标是让AI从代数闭式转向“dominant layer stripping”。

风险：

- 直接出现 `sum a_i^n` 太像母题；
- 需要换掉幂和外壳，但保留“主导层无法被低层抵消”的结构。

### 3.2 IMO 1979 P6：大状态空间的对称商 + 二步递推

**problem_id**：`compfiles_imo1979p6`  
**profile key insight**：利用八边形镜面对称性把8顶点状态压成2状态，并用2步递推而不是1步递推。

母题骨架：

```text
表面：路径计数/过程计数
错路：直接枚举，或写巨大转移矩阵
转向：先按对称性取商，再按时间奇偶分块
证书：低维递推矩阵的特征值
```

可迁移出题灵感：

- 换成棋盘过程、自动机、有限状态游戏、染色演化；
- 保留“原状态空间很大，但真正状态只有少数等价类”；
- 第二层锁可以是“必须两步合并，单步商仍不闭合”。

风险：

- 如果题面直接是环图路径计数，模型可能走谱方法或转移矩阵；
- 新题应让完整矩阵可写但不可用，逼出商结构。

### 3.3 IMO 1985 P6：非线性递推的参数阈值反演

**problem_id**：`compfiles_imo1985p6`  
**profile key insight**：把 \(x_n\) 看成初值 \(x_1\) 的函数，定义逆像阈值序列，用夹逼证明唯一初值。

母题骨架：

```text
表面：非线性递推 + 存在唯一初值
错路：求闭式、直接迭代、数值猜测
转向：把每一步迭代视为关于初值的单调函数
证书：逆阈值区间嵌套/夹逼
唯一性：两个初值的差既被增长放大，又被有界性压小，矛盾
```

可迁移出题灵感：

- 换成离散动力系统、参数化构造、几何迭代；
- 让正确解不是算出对象，而是构造“可行初值集合”的嵌套结构；
- Tell目标是从“计算轨道”转向“反推可行参数区间”。

风险：

- 若题目过于分析化，会变成技术证明而非竞赛POC；
- 需要保持单调性和阈值可审查。

### 3.4 IMO 1992 P6：把表示数问题改写为“excess半群”

**problem_id**：`compfiles_imo1992p6`  
**profile key insight**：把“表示为 \(k\) 个正平方和”转成缺口 \(n^2-k\)，缺口由若干基本代价生成；最小不可表示缺口给出上界。

母题骨架：

```text
表面：对所有k的表示问题
错路：逐个k构造、贪心拆平方
转向：不看和本身，看“相对全1表示的excess”
证书：excess属于一个小生成半群；最小不可表示数给上界
构造：shift operation把一个可行表示搬到下一层
```

可迁移出题灵感：

- 换成分拆、覆盖、装箱、编码长度、能量预算；
- 核心锁是“目标参数本身难处理，差额/余量才是可加对象”；
- 第二层锁是既要证明不可达阈值，又要构造无限达到阈值的对象。

风险：

- 直接写“平方和 + k项”太贴近原题；
- 新题应隐藏excess对象，让bare自然尝试直接构造。

### 3.5 IMO 2014 P5：近满装箱中的规范化 + 容量函数

**problem_id**：`compfiles_imo2014p5`  
**profile key insight**：先用 \(1/(2m)+1/(2m)=1/m\) 和奇数面额整组提取规范化，再引入容量函数支持贪心装箱。

母题骨架：

```text
表面：总量略小于整数上限的分组/装箱
错路：普通贪心装箱、平均值、简单归纳
转向：利用对象的算术结构先规范化
证书：容量函数，不是剩余总量
封口：规范形下贪心才有足够余量
```

可迁移出题灵感：

- 换成任务调度、资源分桶、分数权重、可合并碎片；
- 关键是“总量界几乎无余量”，泛用装箱失败；
- Tell目标是从泛用贪心转向“先规范化对象，再定义容量势函数”。

风险：

- 直接用 \(1/n\) 硬币会触发IMO 2014 P5；
- 新题应替换面额系统，但保留“局部合并恒等式 + 容量函数”。

### 3.6 IMO 2020 P5：AM-GM外壳下的极值素因子

**problem_id**：`compfiles_imo2020p5`  
**profile key insight**：先除以gcd归一化，再取最大值的一个素因子和最大的不被该素因子整除的数，用AM-GM条件推出整除矛盾。

母题骨架：

```text
表面：均值条件/解析不等式
错路：代数变形、AM-GM等号条件、小样本归纳
转向：归一化后进入素因子整除世界
证书：最大元素的素因子 + 极值反例
矛盾：条件迫使“不被p整除”的极值也被p整除
```

可迁移出题灵感：

- 换成乘积/平均/闭包条件；
- 核心锁是“解析语言只是表面，真正结构是p-adic整除闭包”；
- Tell目标是跨域翻译：从不等式/平均条件转向数论极值。

风险：

- 直接出现AM=GM卡片条件会被识别；
- 需要换掉均值外壳，但保留“闭包条件迫使素因子传播”的机制。

### 3.7 IMO 1993 P6：过程模拟到 \(\mathbb F_2\) 线性化 + 加强归纳

**problem_id**：`compfiles_imo1993p6`  
**profile key insight**：把灯切换过程翻译为 \(\mathbb F_2\) 线性算子，并用四个同时不变量加强归纳，使 \(n\to 2n\) 的结构分解可执行。

母题骨架：

```text
表面：有限状态过程/循环操作
错路：模拟小n，猜周期，做普通归纳
转向：把过程线性化
第二层锁：一个不变量不够，必须同时维护一组不变量
证书：拼接公式/块分解公式
```

可迁移出题灵感：

- 换成开关、染色、令牌移动、局部规则自动机；
- 让bare可以猜到周期但无法证明；
- Tell目标是从过程语言转向线性算子，并从单不变量转向“simultaneous invariants”。

风险：

- 如果局部规则太线性，AI会直接写矩阵；
- 应让线性结构被条件规则遮住。

### 3.8 IMO 1976 P6：非线性递推中的 \(a+a^{-1}\) 隐藏闭式

**problem_id**：`compfiles_imo1976p6`  
**profile key insight**：识别 \(u_n=a_n+a_n^{-1}\) 形式，使 \((x+x^{-1})^2-2=x^2+x^{-2}\) 把非线性递推变成指数递推。

母题骨架：

```text
表面：非线性递推 + floor闭式
错路：直接归纳floor公式，或暴力展开递推
转向：寻找能把平方减常数线性化的隐藏变量
证书：一条代数恒等式把递推完全解释
```

可迁移出题灵感：

- 换成非线性迭代、矩阵迹、三角/双曲函数恒等式；
- 核心锁是“目标闭式不像递推本身，而像某个隐藏变量的影子”；
- Tell目标是从直接递推转向“寻找可线性化表示”。

风险：

- \(x+x^{-1}\) 太经典，不能直接出现；
- 新题要换恒等式族，或让隐藏变量来自组合对象。

## 4. 从母题到新题的操作模板

以后出一道竞赛级POC题，不应该从“我想一个难题”开始，而应该从以下表格开始：

```text
母题ID：
母题领域：
母题自然错路：
母题关键转向：
母题证书：

要保留的骨架：
要换掉的外壳：
要添加的第二层锁：
训练数据风险点：
预期bare thinking信号：
匹配Tell应当触发什么动作：
不匹配Tell为什么应当无效：
```

这能强制我们避免两个坏习惯：

1. 只借奥赛题的难度，不借它的思维结构；
2. 只改题面名词，不改训练数据会识别的经典外壳。

## 5. 优先用于下一轮造题的母题骨架

下一轮不要平均撒网。优先从下面三类骨架生成候选题：

| 优先级 | 母题骨架 | 为什么优先 |
|---|---|---|
| P0 | 主导层剥离（IMO 1967 P5） | 可换壳空间大，适合制造“生成函数/闭式错路” |
| P0 | excess半群（IMO 1992 P6） | 天然有直接构造错路，且可设计双锁：不可达+构造 |
| P1 | 规范化+容量函数（IMO 2014 P5） | 很适合C4/C3，能避开标准概率/Frankl-Wilson外壳 |
| P1 | 参数阈值反演（IMO 1985 P6） | 适合测试结构存在/唯一性，不靠经典定理名 |
| P2 | \(\mathbb F_2\) 线性化+同时不变量（IMO 1993 P6） | 难度高，但容易写成过复杂过程题，要谨慎 |

暂时不优先：

- 直接AM-GM/素因子传播：IMO 2020 P5较新且外壳识别风险高；
- \(a+a^{-1}\) 型递推：恒等式太经典，容易被秒杀；
- 环图路径计数：谱/转移矩阵出口太明显。

## 6. 对356号经验库的修正

356号原本已经写了“从经典题中抽思维力内核”。本轮需要把这句话改成更工程化的规则：

> 每轮新造题前，必须先选3-5道奥赛母题，填写母题拆解表；没有母题拆解表的新造题，只能算Stage A灵感题，不能进入Stage B bare筛选。

这条规则的意义是：用奥赛题的真实错路和转向给新题定骨架，用历史bare失败题给难度定标，用solver-harness给当前模型真实筛选。
