### 2.3 关键thinking观察

GLM-5.2开局直接命中经典外壳：

```text
This is a classic problem in extremal combinatorics.
This is the Frankl-Wilson theorem (or a variant).
```

随后它没有走局部集合计数，而是直接构造标准多项式证书：

```text
f_i(x) = product over ell in L of (v_{A_i} dot x - ell)
M_{ij} = f_i(v_{B_j})
```

它正确识别：

- 当 `i<j` 时，矩阵对应项为0；
- 当 `i=j` 时，对角线非零；
- 因而评价矩阵是三角非奇异矩阵；
- 多项式多重线性化后次数不超过 `s`；
- 维数为 `sum_{r=0}^s binom(n,r)`。

| 落盘层 | 失败/未完成 | Solver目录只有 `AGENTS.md` 与 `problem.txt` |

### 2.5 结论

**淘汰。**

原因：

1. 目标C4思维力没有形成bare缺口；
2. 题面“模交 + forbidden residues + 多项式次数维数”足以触发Frankl-Wilson；
3. 三角化并没有构成有效第二层锁；
4. 没有 `proof.md` 只是落盘层问题，不改变路线层成功事实。

下一版C4不能再把核心证书写成可直接评价的低次多项式空间维数题。至少需要隐藏“评价点/证书函数”的对应关系，或换到不触发Frankl-Wilson命名的对象层。

### 3.3 关键thinking观察

GLM-5.2开局就把题归入已知模型：

```text
This is a classic Ulam-Rényi type problem with lies and silence.
```

它先数出每个目标的干扰配置数：

```text
1 + q + q + q(q-1) = q^2 + q + 1
```

随后出现了本轮最有价值的中间卡点：它意识到自适应问题中“不同干扰配置是否一定产生不同transcript”并非一句话显然。thinking中先后出现了这些疑问：

```text
the questions are adaptive
the truthful answer at round i depends on the path
different configurations might produce the same transcript
we need |A(x)| = q^2 + q + 1 exactly
```

然后它自行找到正确恢复方式：

```text
given transcript tau and target x, tau determines the path
the path determines all questions
truthful answers are then determined
* determines the silence position
mismatches determine the lie position
```

这个注入性引理正是标准解中最容易漏掉的步骤。可惜GLM-5.2最终自行完成了。

### 3.4 proof.md审查

`proof.md` 给出的证明结构正确：

1. 把策略形式化为深度 `q` 的决策树；
2. 定义 `(lie position, silence position)` 配置；
3. 正确计数 `q^2+q+1` 个配置；
4. 正确计数最多 `2^q+q2^{q-1}` 个 transcript；
5. 证明固定目标 `x` 时配置到 transcript 的映射是注入的；
6. 定义每个 transcript 覆盖的目标集合 `T(tau)`；
7. 用 `sum_tau |T(tau)| = N(q^2+q+1)` 与每个叶子最多输出 `t` 个目标得到矛盾。

未发现影响结论的数学错误。

### 3.5 三层判定

| 层 | 判定 | 说明 |
|---|---|---|
| 路线层 | 成功 | 正确选择Ulam-Renyi体积计数并解决注入性 |
| 证明层 | 成功 | `proof.md` 结构完整，数学正确 |
| 落盘层 | 成功 | `proof.md`、thinking、trajectory均保留 |

### 3.6 结论

**淘汰，但保留为C6硬化参照样本。**

淘汰原因：

1. bare最终完整解决；
2. 中间卡点被模型自行修复；
3. Tell后成功无法归因于C6 Tell；
4. “一次谎言 + 一次沉默”仍然太接近经典体积界扩展。

保留价值：

- 它说明C6题不应只靠“多加一种干扰状态”来变难；
- 真正有测试价值的位置是：自适应分支下状态是否可恢复、是否会合流、每个叶子能覆盖多少状态；
- 下一版C6应该让简单体积计数不够用，迫使AI构造对抗者策略、势函数，或处理配置合流后的强下界。

Q362-C1-01是Erdos高围长高色数图。362号已自评经典风险高。结合本轮结果，应将它视为“校准题”而非主力Tell候选。

该题更适合作为边界校准题，不应消耗大量并发预算。

## 5. 写回356号的经验

本轮应写回两条经验：

1. **三角多项式证书题仍会触发Frankl-Wilson**：只把对称条件改成有序三角条件，不足以逃离经典定理识别。
2. **多干扰状态计数不等于C6硬锁**：只在Ulam/Renyi模型上加一种干扰，模型仍能沿体积界扩展；真正的C6硬题要让“状态可恢复/状态合流/叶子覆盖能力”成为非模板卡点。
