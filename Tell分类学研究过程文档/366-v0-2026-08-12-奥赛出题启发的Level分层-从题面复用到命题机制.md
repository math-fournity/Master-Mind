# 366号 · 奥赛出题启发的Level分层——从题面复用到命题机制

**日期**：2026-08-12  
**触发原因**：用户指出：看奥赛题不能只在低Level抽骨架，还应像“同构之桥”一样，从更高Level看“如何制造挑战”。奥赛题的出题思路本身也有不同启发层次。  
**前置文档**：340号高Level概念两种类型、345号Tell族与钟形曲线、346号三步法、347号Tell提示词三种形态、364号奥赛母题分析法、365号奥赛母题本体测试队列  
**核心修正**：364号和365号仍偏“从母题解法骨架拿题”。这只是中低Level。真正的命题启发应该形成“出题启发族”：同一道奥赛题在不同Level上启发不同的造题方式，峰值不一定在具体解法骨架处，而可能在更高的“命题机制”处。

---

## 0. 一句话结论

奥赛题给我们的不是一个灵感，而是一族不同Level的灵感。

```text
Level 0：换题面
Level 1：复用技巧
Level 2：复用解法骨架
Level 3：复用失败机制
Level 4：复用命题机制
Level 5：复用数学处境生成法
```

前几轮新造题的问题是：我们常在Level 1-2工作。这样容易造出“经典定理轻微变体”，被GLM-5.2直接识别。真正能制造挑战的，往往在Level 3-4：不是“这题用了什么方法”，而是“这题如何让自然方法失效，并迫使解题者换一种表示/证书/世界观”。

---

## 1. 为什么“母题骨架”还不够

364号提出“从奥赛母题抽自然错路、关键转向、证书”。这比凭空造题更好，但仍然可能太低。

例子：

- 从Frankl-Wilson类题抽出“低次多项式证书 + 维数上界”，我们造出Q362-C4-01，结果模型直接识别；
- 从Ulam-Renyi题抽出“体积计数”，我们造出Q362-C6-01，结果模型自然扩展；
- 从Chebyshev题抽“交错证书”，很可能也会被模型识别。

这些失败说明：如果我们只抽“解法骨架”，AI可能已经会这个骨架。我们需要抽更高一层：

> 这道奥赛题到底怎样制造了一个让自然方法不够用的数学处境？

这才是“如何出题”的高Level启发。

## 2. 出题启发族：同一道题的多Level视图

类比345号的Tell族：

- Tell族：同一个trace在不同去特化Level上的Tell集合；
- 出题启发族：同一道奥赛题在不同抽象Level上的出题启发集合。

两者都有钟形曲线：太低Level只是换皮，太高Level只是口号；中高Level的“命题机制”常常最有造题价值。

### 2.1 Level 0：题面复用

**它是什么**：保留对象、语境、常数，只改叙述或参数。

例：

```text
把硬币1/n改成券1/n；
把八边形青蛙改成机器人走八边形；
把线性因子擦除改成标签擦除。
```

价值：几乎没有。  
风险：训练数据/定理名直接触发。  
用途：只能做sanity check，不适合制造挑战。

### 2.2 Level 1：技巧复用

**它是什么**：抽出某个具体技巧或恒等式。

例：

```text
用 a+a^{-1} 线性化递推；
用 Chebyshev 交错点；
用低次多项式评价矩阵；
用一次谎言体积界。
```

价值：能造出有标准解的题。  
风险：技巧如果有名字或高频训练痕迹，会被模型秒杀。  
用途：适合低难度校准，不适合作为主挑战源。

### 2.3 Level 2：解法骨架复用

**它是什么**：保留“自然错路 -> 关键转向 -> 证书”的关系结构。

例：

```text
直接构造失败 -> 引入excess变量 -> 半群不可达缺口；
直接迭代失败 -> 把初值看成参数 -> 逆阈值夹逼；
普通装箱失败 -> 先规范化 -> 容量函数收尾。
```

价值：这是364号的主工作层。  
风险：如果骨架本身经典，GLM-5.2仍可能恢复。  
用途：适合生成Stage A/B候选，但不能默认足够。

### 2.4 Level 3：失败机制复用

**它是什么**：不复用解法本身，而复用“为什么自然方法会失败”。

例：

```text
平均值看起来够用，但全局余量被局部障碍吃掉；
直接递推看起来可算，但变量爆炸，必须反过来看参数空间；
直接构造看起来可行，但有一个小的不可达缺口阻断所有阈值；
对称性看起来明显，但单步商不闭合，必须换时间尺度。
```

价值：开始接近真正命题法。  
造题方式：先设计一个诱人的错误入口，再设计一个不可绕过的失败点。  
用途：这是挑战GLM-5.2的重点层。

### 2.5 Level 4：命题机制复用

**它是什么**：复用“这道题如何迫使解题者更换表示/证书/不变量”的机制。

例：

```text
把真正可加的量藏在目标量的差额里；
把真正的状态空间藏在对称商或时间块里；
把真正的不变量藏在过程的线性化坐标里；
把真正的上界证书藏在对偶对象/测试对象上；
把真正的可行集合藏在参数阈值的嵌套区间里。
```

价值：最高。它不是复用某个技巧，而是复用“命题怎样制造必要迁移”。  
用途：新造挑战题应主要从这一层出发。

### 2.6 Level 5：数学处境生成法

**它是什么**：再往上一层，不再从某一道题出发，而是从“如何生成一种数学处境”出发。

例：

```text
制造一个表面量不可控、但差额量可加的处境；
制造一个局部规则非线性、但整体坐标线性的处境；
制造一个平均量足够、但局部瓶颈需要规范化的处境；
制造一个所有自然证据都支持弱结论、但强结论需要对偶证书的处境；
制造一个AI能猜答案、却必须同时维护多个不变量才能证明的处境。
```

价值：极高但危险。  
风险：太抽象，容易变成口号，或造出不可解研究题。  
用途：作为命题人思维方向；真正落题时要降回Level 3-4。

## 3. 高Level命题启发的核心问题

以后分析奥赛题，不只问：

```text
这题怎么解？
```

而要问五个更高Level的问题：

1. **这题让解题者自然先走哪条路？**
2. **这条路为什么看起来合理？**
3. **这条路在哪里必然失败？**
4. **失败后必须换到什么新表示/新证书/新不变量？**
5. **能不能把“合理入口 + 必然失败 + 必要迁移”迁移到完全不同的题面？**

这五问才是从奥赛题里学习“如何出题”。

## 4. 三个母题的Level化重看

下面用364号中三个优先母题重看它们的高Level启发。

### 4.1 IMO 1967 P5：主导层剥离

低Level看法：

```text
幂和无限多次为零 -> 按最大绝对值分层 -> 剥离主导层。
```

高Level命题机制：

```text
制造一个“全局等式无限次成立”的处境；
让表面代数工具看起来可用，但它们不能解释为什么所有目标索引都成立；
真正的证据来自增长率分层：低层贡献终会小到无法抵消主导层；
主导层被迫精确满足一个离散约束；
剥掉主导层后，同一结构递归出现。
```

可迁移挑战制造法：

```text
设计一类由多个增长尺度叠加的对象；
要求某个输出在无限多参数上满足精确等式；
让直接闭式/递推路线很诱人；
但证明必须使用“主导层被低层无法抵消”的离散压迫。
```

真正要测试的高Level思维力：

- 从代数闭式转向渐近支配；
- 从单次等式转向无限次等式的结构后果；
- 从全局表达式转向层级剥离。

### 4.2 IMO 1992 P6：excess半群

低Level看法：

```text
平方和表示 -> 看 n^2-k -> 3a+8b 半群 -> 13不可达。
```

高Level命题机制：

```text
制造一个“对所有k都要可行”的连续阈值问题；
让直接构造每个k看起来自然，但搜索空间巨大；
真正可加的不是目标对象，而是“相对于平凡对象的差额”；
强上界来自一个小的不可达差额；
强下界来自能把可达差额整体平移/扩张的操作。
```

可迁移挑战制造法：

```text
设计一个阈值型构造问题；
让目标参数本身不可加；
藏一个可加的余量/亏损/能量变量；
让某个最小不可达余量同时控制整个阈值；
再要求构造无限多达到阈值的例子。
```

真正要测试的高Level思维力：

- 找到“真正可加的量”；
- 从对象构造转向余量空间；
- 同时处理不可达证书和无限构造。

### 4.3 IMO 2014 P5：规范化+容量函数

低Level看法：

```text
1/n硬币装箱 -> 合并偶数面额 -> 提取奇数整组 -> 容量函数。
```

高Level命题机制：

```text
制造一个总量界几乎刚好的分组问题；
平均值看起来足够，但局部大块会破坏分组；
通用贪心失败，因为对象未处于规范形；
必须先用题目内部的局部重写规则规范化对象；
规范化后，控制量不是剩余总价值，而是容量势函数。
```

可迁移挑战制造法：

```text
设计一个“总量只差一点点就够”的分配问题；
让所有通用分配算法都缺少余量；
在对象内部埋入局部合并/重写恒等式；
只有先规范化，再定义专门容量势函数，才能证明全局分配。
```

真正要测试的高Level思维力：

- 识别泛用算法失败；
- 先规范化对象再求解；
- 发明适配规范形的势函数。

## 5. 出题时如何选择Level

不能一味追求最高Level。Level 5太抽象，容易失去可操作性；Level 0-1太具体，容易被模型记忆秒杀。

推荐策略：

| 目标 | 应选Level |
|---|---|
| 做工具链sanity check | Level 0-1 |
| 做母题本体校准 | Level 1-2 |
| 造第一版候选题 | Level 2-3 |
| 造挑战GLM-5.2的题 | Level 3-4 |
| 设计长期命题方法论 | Level 4-5 |

下一批真正新题应从Level 3-4出发，而不是从365号那种Level 1-2母题本体题直接出发。

## 6. 新的母题分析表

以后每道奥赛母题分析，不只填364号的“母题骨架表”，还要填这一张Level表：

```text
母题ID：

Level 0 题面复用：
Level 1 技巧复用：
Level 2 解法骨架：
Level 3 失败机制：
Level 4 命题机制：
Level 5 数学处境生成法：

推荐用于造题的Level：
为什么不是更低Level：
为什么不是更高Level：
可操作化后的出题指令：
预期bare会先走的自然路线：
自然路线的必然失败点：
必须迁移到的新表示/证书/不变量：
```

这张表的作用是防止“只换壳”。如果一道新题说不清Level 3-4的机制，它就不应该进入bare测试。

## 7. 对365号的修正

365号准备了三道母题本体测试，这是有价值的，但它只解决一个低/中Level问题：

```text
GLM-5.2是否能解出这些母题本体？
```

它不能直接回答：

```text
如何从这些母题制造新挑战？
```

所以365号后续应降级为“母题本体校准队列”，不要把它当作主造题路线。真正的主造题路线应变成：

```text
先对母题做Level 0-5启发表
  -> 选择Level 3-4峰值
  -> 写出可操作化出题指令
  -> 再生成新题
  -> 再做bare
```

## 8. 一个高Level出题指令模板

以后给自己或另一个AI的出题指令应类似这样：

```text
不要复用母题题面，也不要复用母题具体技巧名。

请复用母题的Level 4命题机制：
“表面目标量不可加，但相对于平凡对象的差额可加；
强上界由一个最小不可达差额给出；
强下界由一个可平移/扩张的构造给出。”

请生成一个新的竞赛级题目：
- 题面领域换掉；
- 自然入口应诱导AI尝试直接构造目标对象；
- 直接构造必须在阈值附近失败；
- 正解必须发现隐藏的差额变量；
- 证明必须同时包含不可达证书和无限构造；
- 解法长度控制在1-3页。
```

这比“仿照IMO 1992 P6出一道题”高Level得多，也更不容易泄漏。

---

## 9. 读完后要记住的5句话

1. 奥赛题不是给我们一个灵感，而是给我们一族不同Level的启发。
2. Level 0-1是换皮和技巧复用，最容易被GLM-5.2秒杀。
3. Level 2是解法骨架，364号主要在这一层，但这还不够。
4. Level 3-4才是制造挑战的核心：复用失败机制和命题机制。
5. 真正的新题应先填Level 0-5启发表，再从Level 3-4生成可操作化出题指令。
