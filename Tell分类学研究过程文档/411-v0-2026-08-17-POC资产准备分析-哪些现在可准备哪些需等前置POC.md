## §1 逐个POC的资产需求分析

### 1.1 POC-0 CasePack冻结

**需要的资产**：
- 6类题的简化CaseCard（10字段）：source trace 3-5道/正迁移 4-6道/变形 3-5道/假朋友 4-6道/边界 2-4道/组合 2-3道
- 5否决项审查记录

**资产依赖**：
- 382号CasePack v0（✅已完成）——22道题的完整CaseCard（30字段），需要简化为10字段
- Pipe 3的6项POC准备数据（可选——Pipe 3未规模化运行时可用人工筛选替代）

**现在可准备？** ✅可以——382号已冻结，简化CaseCard只是格式转换+5否决项审查。Pipe 3预评是可选的加速手段，不是硬依赖。

### 1.2 POC-0.5 变形关系声明

**需要的资产**：
- 变形关系声明表（允许变换/禁止变换/边界变换的清单）
- 每个变换对应的变形题/假朋友题/边界题的case_id映射

**资产依赖**：
- 382号的source trace题（✅已完成）——4道（1631/1843/1709/1962）
- 383号的TellCore v0字段（✅已完成）——7字段最小充分集

**现在可准备？** ✅可以——382号和383号都已完成，变形关系声明是基于TellCore字段和source trace题的分析工作。

### 1.3 POC-1 因果取商增强版

**需要的资产**：
- 3个候选TellCore（A=精简版/B=baseline 7字段/C=扩展版）
- 独立审查者提取指南（让独立审查者从正确答题过程提取解题思维的操作指南）
- 8维度Pareto前沿评分表

**资产依赖**：
- 383号已完成的12字段消融结果（✅已完成）——候选C已确定
- 382号的4道source trace题的正确答题过程（✅已完成）

**现在可准备？** ✅可以——3个候选TellCore的构造基于383号已有结果（候选A删字段/候选C加字段），独立审查者提取指南是方法论文档，8维度评分表是模板。都不依赖前置POC产出。

### 1.4 POC-2 可选择

**需要的资产**：
- 小型Tell库：1个目标TellCore + 2-4个近邻TellCore + 2个错配TellCore + 1个通用反思Tell
- 12道题的预期选择决策（select/reject/abstain/boundary）

**资产依赖**：
- 383号TellCore v0候选C（✅已完成）——目标TellCore
- 近邻TellCore和错配TellCore需要构造

**现在可准备？** ✅可以——目标TellCore已有（383号候选C），近邻TellCore和错配TellCore需要基于局部-全局表示切换的理解构造（如"近邻"可以是同属局部-全局切换但不同子类型的TellCore，"错配"可以是完全不同思维力的TellCore如"构造-分析-排除"）。通用反思Tell可以现在写。

### 1.5 POC-2.5 基础因果效应验证

**需要的资产**：
- 4道正迁移题（来自POC-0的CasePack）
- 1个中等非特化程度的HintInstance（Hint-L3"当问题在自然表示下陷入困境时，切换到局部表示Z/pZ"）
- 从source trace题提取的脉络（vein）

**资产依赖**：
- POC-0的CasePack（需要POC-0完成精筛）
- Hint-L3文本（可以现在写——403号方案中已设计）
- 脉络提取——需要从source trace题提取，但提取方法在POC-1增强版的提取完备性检查中才被验证

**现在可准备？** ⚠️部分可以——Hint-L3文本可以现在写，但脉络提取建议等POC-1增强版完成后做（POC-1可能修正提取方法）。正迁移题需要POC-0完成精筛。

### 1.6 POC-3.5 Hint非特化程度验证

**需要的资产**：
- 4道正迁移题（来自POC-0的CasePack）
- 5个HintInstance的完整文本（L1极低→L5极高）

**资产依赖**：
- POC-0的CasePack（需要POC-0完成精筛）
- 5个HintInstance文本——403号方案文档中已详细设计了每个HintInstance的内容

**现在可准备？** ✅5个HintInstance文本可以现在准备——403号方案中已有每个HintInstance的示例文本，可以现在就写定最终版本。正迁移题需要POC-0完成精筛。

### 1.7 POC-3 可执行

**需要的资产**：
- 正迁移题+过程信号强的变形题（来自POC-0的CasePack）
- POC-3.5确定的峰值区间的HintInstance
- 5个对照组（bare/通用鼓励/等长空流程/错配Tell/目标Tell）

**资产依赖**：
- POC-0的CasePack
- **POC-3.5必须完成**——本POC用POC-3.5确定的峰值HintInstance

**现在可准备？** ❌必须等POC-3.5完成——HintInstance的峰值区间由POC-3.5实验确定。

### 1.8 POC-4 可终止

**需要的资产**：
- 三类场景题（有效场景/无进展场景/边界冲突场景）
- 中等非特化程度的HintInstance（POC-3.5确定的峰值）

**资产依赖**：
- POC-0的CasePack
- **POC-3必须完成**——需要POC-3确认"什么题上Tell有效/无进展/边界冲突"

**现在可准备？** ❌必须等POC-3完成——三类场景的划分需要POC-3的实验结果。

### 1.9 POC-6 可归责

**需要的资产**：
- 4道正迁移题（来自POC-0的CasePack）
- 干预矩阵的6个条件（首轮轻量矩阵）——bare/通用鼓励/等长空流程/等强度错配Tell/method only/full Tell
- "等强度错配Tell"——与目标TellCore提示长度/抽象度/强度相近但不匹配的Tell

**资产依赖**：
- POC-0的CasePack
- POC-2.5必须通过（基础因果效应存在）
- **POC-2和POC-3.5必须完成**——"等强度"需要知道目标TellCore的提示长度/抽象度/强度，这由POC-2的selector和POC-3.5的非特化程度验证确定

**现在可准备？** ❌必须等POC-2+3.5完成——"等强度错配Tell"的设计需要知道目标TellCore的提示强度参数。

### 1.10 POC-7 可持续学习简化版

**需要的资产**：
- 三类新证据（正例成功/假朋友误触发/正例未触发或执行失败）——来自前置POC的实验结果
- 前置POC的EvidenceRecord

**资产依赖**：
- **POC-2~6必须完成**——三类新证据来自这些POC的实验结果

**现在可准备？** ❌必须等POC-2~6完成——三类新证据是实验产出，不能预先准备。

### 1.11 POC-8 端到端闭环

**需要的资产**：
- 全题包（22道CasePack——来自POC-0，已有）
- 主模型（GLM-5.2 High）+ 对照模型配置
- POC-0~7的所有EvidenceRecord

**资产依赖**：
- 全题包已有（382号CasePack v0）
- **POC-0~7全部完成**——端到端闭环需要每一门的组件级证据
- 对照模型配置——部分可现在准备（确定候选模型），但最终选择可能需要POC-3.5的跨模型观察

**现在可准备？** ⚠️部分可以——全题包已有，对照模型的候选列表可以现在确定。但完整执行必须等POC-0~7全部完成。

### 1.12 POC-9 识别端验证

**需要的资产**：
- 10-20道DIRECTION_ERROR题的bare AI thinking（失败trace）
- 人类专家独立识别结果（对照基准）
- 系统识别工具（识别端分析器）

**资产依赖**：
- 382号的4道source trace题的bare AI thinking（✅已有）
- 387号错题分析系统的DIRECTION_ERROR题（✅已有1071条可选）
- 人类专家识别——需要人工做，可以现在开始
- 系统识别工具——需要开发，可以现在开始

**现在可准备？** ✅可以——失败trace来源已有（382号+387号），人类专家识别和系统识别工具开发都可以现在开始。POC-9只依赖POC-0（已有source trace题），不依赖POC-2~8。

## §3 现在准备7项资产后的执行就绪状态

```
Phase A：策略对象成形 ← 现在准备7项资产后可立即执行
  POC-0 CasePack冻结 ← 资产1就绪（简化CaseCard+5否决项审查）
  POC-0.5 变形关系声明 ← 资产2就绪（变形关系声明表）
  POC-1 因果取商增强版 ← 资产3+4就绪（3个候选TellCore+独立审查者提取指南）

Phase B：基础验证 ← 部分资产就绪，部分需等Phase A完成
  POC-2 可选择 ← 资产5就绪（小型Tell库），需POC-0完成精筛后才有12道题
  POC-2.5 基础因果效应验证 ← 资产6部分就绪（Hint-L3文本），脉络需等POC-1
  POC-3.5 Hint非特化程度验证 ← 资产6就绪（5个HintInstance文本），需POC-0完成精筛后有4道正迁移题
  POC-3 可执行 ← ❌等POC-3.5
  POC-4 可终止 ← ❌等POC-3

Phase C：归责与学习 ← ❌全部需等Phase B完成
  POC-6 可归责 ← 等POC-2+3.5
  POC-7 可持续学习 ← 等POC-2~6

Phase D：端到端 ← ❌需等Phase C完成
  POC-8 端到端闭环 ← 等POC-0~7
  POC-9 识别端验证 ← 资产7就绪，可并行执行
```

**结论**：现在准备7项资产后，Phase A的3个POC可以立即执行，POC-9可以并行执行。Phase B~D需等前置POC完成。
