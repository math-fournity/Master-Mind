## 0. 本文怎么用

每次做出题相关工作时，都要回到本文更新。尤其是以下情况必须更新：

1. 新出了一道候选题；
2. 候选题被bare做出；
3. 候选题bare失败；
4. Tell后成功或失败；
5. 发现某种题型太经典、太toy、太计算化、太泄漏；
6. 发现一种有效的题目硬化方法；
7. 发现一种AI常见失败模式；
8. 发现并发测试中的观察策略问题；
9. 某道题从候选题升级为预注册题。

本文不是题库本身，而是**出题经验库**。题目正文可以放在单独的试产文档或预注册文档中；本文记录“为什么这类题行/不行，以及下一次怎么出得更好”。

## 1. 出题哲学 v1

### 1.1 POC难题不是普通竞赛题

普通竞赛题的目标是区分人类选手的数学能力；POC难题的目标是区分**AI在某种思维力上是否缺失**。

这两者很像，但不一样：

| 类型 | 问的问题 | 好题标准 |
|---|---|---|
| 普通竞赛题 | 选手能不能做出来？ | 解法漂亮、难度合适、区分度高 |
| POC难题 | AI缺不缺某种思维力？ | bare卡在目标瓶颈，Tell后能突破，且Tell不泄漏 |

所以POC题不能只追求“难”。它必须让bare AI暴露一个**可观察的认知缺口**。

### 1.2 真正的题目来源：经典难题的思维力内核

我内在知识里确实有大量竞赛难题、经典构造、反例、极值证明、概率方法、博弈策略和几何变换。直接拿这些题来测通常不行，因为模型也可能见过。

正确用法不是复刻原题，而是抽取它们的**思维力内核**。

一个经典难题至少有六层：

| 层 | 说明 | POC出题时怎么处理 |
|---|---|---|
| 表面外壳 | 图论、数论、几何、代数等题面对象 | 要经常换掉，避免训练数据触发 |
| 条件结构 | 哪些约束彼此作用 | 尽量保留核心约束关系 |
| 自然错路 | 大多数解题者会先走的路 | 要保留，作为bare卡点 |
| 关键转向 | 解法中“原来要这样想”的一步 | 这就是目标思维力 |
| 证书/构造 | 最终证明成立的对象或不变量 | 要保留可验证性 |
| 解法长度 | 正确路线是否能在竞赛篇幅内写完 | 必须控制，不能变成研究题 |

POC出题的核心动作是：**保留第2-5层，重写第1层，控制第6层。**

### 1.3 难题不是“加复杂度”，而是“制造必要转向”

让题变难有两种方式：

1. 加很多条件、参数和计算；
2. 让自然路线走到墙上，必须换一种思维力。

第一种是噪音难度，不适合POC。第二种才是思维力难度。

一个好POC题应有这样的形状：

```text
题面看起来有自然入口
  ↓
bare AI走进去
  ↓
自然入口给出弱结果、假希望或循环
  ↓
AI需要一次目标思维力转向
  ↓
转向后证明变短、变清楚、可验证
```

如果bare AI一眼看出标准路线，题太熟。  
如果Tell后仍然不知道怎么做，题太硬。  
如果Tell必须说出具体方法名，题不纯。

### 1.4 POC题的六个零件

以后每道真正用于验证的题，都要检查这六个零件是否存在。

| 零件 | 它是什么 | 为什么需要 |
|---|---|---|
| 内核 | 从经典难题抽出的思维力结构 | 保证题有真实数学含量 |
| 外壳 | 新的题面对象和叙述 | 避免训练数据和定理名触发 |
| 诱饵 | 一条自然但不够的路线 | 让bare失败有可观察轨迹 |
| 锁 | 只有目标思维力能打开的瓶颈 | 保证Tell不是泛泛鼓励 |
| 证书 | 最终可审查的证明对象 | 防止开放题或玄学判断 |
| 余量 | 常数/条件上的缓冲 | 保证Tell后能做，不变成研究级 |

没有诱饵，bare可能随机乱走，无法分析。  
没有锁，任何提示都可能有效。  
没有余量，Tell后也可能做不出来。

### 1.5 从经典题到POC题的五步变形

**步骤1：选母题**

母题可以来自IMO/IMO Shortlist/Putnam/USAMO/数学史经典证明。选择标准不是“题目著名”，而是它有清楚的思维力转向。

**步骤2：抽骨架**

把母题改写成一句话：

```text
这题真正难的是：在______失败后，必须______，从而得到______。
```

例：

```text
在局部计数失败后，必须构造全局上界证书，从而证明构造已最优。
```

**步骤3：换外壳**

替换对象、语言、常数和叙述，避免模型直接联想到母题。

换壳不是随便改名。换壳后必须保持：

- 同一个自然错路；
- 同一个关键转向；
- 同一个证明证书；
- 相近的解法长度。

**步骤4：加锁**

加一层目标思维力必须完成的动作。

例如：

- C1不能只是随机选择，还要删除后修补；
- C4不能只是找上界，还要证明某个隐藏证书最优；
- C6不能只是信息量计数，还要对抗者维护多个候选状态。

**步骤5：裸测调参**

跑bare。根据结果调参：

| bare结果 | 说明 | 处理 |
|---|---|---|
| 一眼识别经典路线 | 外壳失败 | 深换壳 |
| 做出但很慢 | 难度不足或锁太浅 | 加第二层锁 |
| 误读题意 | 题面失败 | 重写题面 |
| 卡在目标瓶颈 | 合格候选 | 进入Tell测试 |
| 完全乱走 | 题太硬或入口不自然 | 加诱饵/降难度 |

### 1.6 三类知识不能混用

出POC题时，必须区分三类知识：

| 类型 | 可以用来做什么 | 不能做什么 |
|---|---|---|
| 母题知识 | 提供思维力骨架 | 不能直接照搬题面 |
| 解法知识 | 保证题可解、可审查 | 不能泄漏到Tell里 |
| AI失败知识 | 调整诱饵和锁 | 不能用来事后挑结果造假 |

最容易犯的错误是：因为知道标准解，就把题面设计得“恰好服务于Tell”。这会变成自己出题自己作弊。正确方式是先让题有独立数学生命，再让bare和Tell测试决定它是否可用。

### 1.7 竞赛级POC题的审美标准

一个好的竞赛级POC题，解完后应该让人说：

```text
原来不是这题计算复杂，而是我一直没换那个视角。
```

它通常具有这些审美特征：

- 题面短；
- 条件少但互相咬合；
- 错路自然；
- 正解有一个清楚转向；
- 转向后证明不长；
- 不依赖高级黑箱；
- 可被严格评分。

如果题目需要三页计算才能看到思维力，它不是好POC题。  
如果题目一看就是某个经典定理换皮，它也不是好POC题。

## 2. 核心铁律

### 铁律1：真实bare失败是入场券

人工自评“P5/P6”不够。只有真实Solver bare失败，候选题才有资格进入Tell测试。

如果bare成功：

- 题目淘汰；
- 不跑Tell；
- 记录bare为什么成功；
- 提炼硬化方向。

### 铁律2：不能用toy案例测试高Level思维力

有些思维力只在足够复杂的情境中才真正出现。比如：

- 框架创造不能用简单换元题验证；
- 概率存在不能用一眼并合界题验证；
- 对抗者博弈不能用单步策略题验证；
- 对偶证书不能用标准线性代数模板题验证。

toy题可以做工具链 sanity check，但不能作为思维力有效性的证据。

### 铁律3：经典外壳会让题目失效

如果题目外壳直接触发经典定理名、经典模型名或标准套路，GLM-5.2可能不需要目标思维力就能完成。

355号已验证：

- “无三角形图 + 顶点权重 + 边权二次型”直接触发Motzkin-Straus；
- “存在C4-free图有很多边”直接触发随机图删除法。

### 铁律4：难题要难在思维转向，不难在计算噪音

不合格的难：

- 条件很长；
- 计算很重；
- 参数很多；
- 证明步骤机械但繁琐；
- 题意晦涩导致AI误读。

合格的难：

- 自然路线会失败；
- 错误路线很诱人；
- 关键转向需要目标思维力；
- Tell只给方向，不给具体路线；
- Tell后AI仍需要自己完成数学。

### 铁律5：题目必须有可观察卡点

一题能否用于Tell验证，取决于bare thinking里能不能观察到目标卡点。

例：

- C4对偶证书：AI找到构造下界，但缺少上界证书；
- C1概率存在：AI执着显式构造，不会转随机存在；
- C6对抗者博弈：AI给静态构造，没把量词翻译成策略树。

没有可观察卡点，就无法判断Tell是否真正改变了思维方式。

### 铁律6：并发是观察能力，不是出题指标

devin cli可以最多5并发，这是实验吞吐能力，不是每轮必须凑满5题。

只有当候选题都通过最低预审时，才值得并发启动：

- 非toy；
- 可解；
- 有标准解或至少有可信证明骨架；
- 避开明显经典外壳；
- 预测bare会卡在目标思维力瓶颈；
- 已规划要观察的thinking信号。

并发运行时，不能只等最终proof。必须持续读thinking，观察AI是否：

- 直接识别经典路线；
- 找到简单短路；
- 误读题意；
- 卡在目标瓶颈；
- 在Tell应当影响的位置暴露了缺口。

如果只有两道题达到启动标准，就只开两道。为了并发而并发，会把低质量题的噪音写进经验库。

### 铁律7：bare结果要分路线、证明、落盘三层判定

不要把“没有输出文件”直接等同于“数学失败”，也不要把“路线正确”直接等同于“证明正确”。

每次bare后至少分三层判定：

| 层 | 问题 | 用途 |
|---|---|---|
| 路线层 | AI是否想到目标方法或标准短路？ | 判断是否存在目标思维力缺口 |
| 证明层 | 写出的证明是否严格正确？ | 判断是否真正解出 |
| 落盘层 | 是否按要求生成proof/solution文件？ | 判断实验数据是否完整 |

进入Tell测试的真正门槛是：**路线层失败，且失败卡点对应目标思维力。**

如果路线层成功但证明层有小错，这不是Tell候选，而是“bare已找到路线，题目需要深改”。  
如果路线层成功但落盘层失败，这也不是Tell候选，而是输出流程异常或会话结束问题。

## 3. 候选题生命周期

### 3.1 Stage A：骨架题

骨架题只表达一个思维力结构，还不保证能测试。

要求：

- 解法正确；
- 卡点清楚；
- 可写出低泄漏Tell；
- 有初步难度自评。

### 3.2 Stage B：bare筛选题

骨架题改写后进入bare筛选。

通过条件：

- 题意清楚；
- Solver没有误读；
- bare没有做出；
- bare失败不是因为格式问题或计算过重；
- bare thinking暴露目标卡点。

### 3.3 Stage C：Tell候选题

bare失败后，才进入Tell测试。

通过条件：

- 匹配Tell后能显著改变思路；
- Tell不直接泄漏方法；
- 不匹配Tell无效；
- 等强度通用反思提示无效或明显弱于匹配Tell。

### 3.4 Stage D：预注册题

Tell候选题经过多轮验证后，才能进入正式预注册题库。

必须具备：

- 题目文本；
- 标准解；
- bare失败记录；
- Tell文本；
- 不匹配Tell矩阵；
- 负对照；
- 泄漏风险评分；
- 训练数据风险说明；
- trajectory路径。

## 5. 已沉淀经验条目

### E-001：标准定理外壳会秒杀C4题

**来源**：355号 Q-C4-01 bare测试。

**现象**：GLM-5.2开局直接识别：

```text
This is a classic problem in extremal graph theory.
It's essentially Motzkin-Straus theorem.
```

**经验**：即使题目证明短而漂亮，只要外壳贴近经典定理，bare就可能直接做出。这样的题不能测试“对偶证书与不可行性证明”。

**下次怎么改**：

- 不出现“无三角形图 + 顶点权重 + 边权二次型”；
- 不让目标函数看起来像Motzkin-Straus；
- 保留“最优对象支持集被压缩”的内部结构；
- 换成非图论外壳，或让证书从题目内部生成。

### E-002：标准概率方法外壳会秒杀C1题

**来源**：355号 Q-C1-01 bare测试。

**现象**：GLM-5.2开局直接识别：

```text
This is a classic extremal graph theory problem.
The idea is to use the probabilistic method.
```

**经验**：只要题目写成“存在一个无某小子图且边数很多的图”，模型会自动调出随机图+删除坏结构。

**下次怎么改**：

- 避免标准随机图外壳；
- 加入两类坏事件，不能只删一种；
- 删除后还需要修补或二次选择；
- 让随机参数不是一眼平衡出来；
- 仍保持证明竞赛化，不引用高级定理。

### E-003：低难度完整格式会制造假安全感

**来源**：354号 Q-C4-02、Q-C6-02、Q-C1-02 的自审。

**现象**：这些题都有完整题面、证明、Tell、泄漏评分，但本质偏简单或太经典。

**经验**：格式完整不等于题目合格。文档结构只能保证可审查，不能保证题目难度。

**下次怎么改**：

- 每道题都必须真实bare；
- bare成功就淘汰；
- 不因“题目看起来像竞赛题”而跳过测试；
- 在文档里明确标注“低难度对照”和“验证候选”的区别。

### E-004：高Level思维力需要两层锁

**来源**：354/355综合。

**现象**：一层锁题目会被标准套路打开。例如C1只需要“随机+删除”，C4只需要“识别定理名”。

**经验**：高Level思维力题至少需要两层锁：

1. 第一层：自然路线失败；
2. 第二层：目标思维力不仅要被想到，还要被正确执行。

**下次怎么改**：

- C1：随机存在 + 坏事件修补；
- C4：构造下界 + 非标准上界证书；
- C6：策略建模 + 对抗者保持不可区分状态；
- C26：创造新语言 + 用新语言完成证明。

### E-005：标准谱极值外壳也会秒杀C4题

**来源**：357号 Q-C4-02 bare测试。

**现象**：循环相邻乘积上界题中，GLM-5.2很快把目标写成循环移位矩阵的Rayleigh商，在零和子空间上取最大特征值，并用Fourier向量给出等号构造。

**经验**：C4题不能只是从Motzkin-Straus换到谱定理。只要题面天然呈现“二次型 + 范数约束 + 正交约束”，模型会直接调出标准谱证书。

**下次怎么改**：

- 不让目标函数天然写成矩阵二次型；
- 不直接给出循环、路径、完全图、正交投影等标准谱外壳；
- 让上界证书由题目内部约束生成，而不是由对象名称触发；
- 局部估计可以给弱界，但不能让标准Rayleigh商一步封顶。

### E-006：弱阈值会留下贪心禁止值出口

**来源**：357号 Q-C1-02 bare测试。

**现象**：AP-free + Sidon组合存在题原本希望测试“概率存在 + 修补”，但GLM-5.2找到贪心构造：当前集合大小为 \(m\) 时，禁止加入的新值至多 \(O(m^3)\)，因此可以贪心做到 \(N^{1/3}\) 量级。

**经验**：两类坏事件不自动等于概率方法题。只要目标下界足够宽，逐点禁止值计数就可能绕开随机存在路线。

**下次怎么改**：

- 目标量级或常数要超过朴素贪心保证；
- 坏事件要有依赖结构，使单点禁止值计数不够；
- 随机后要有非平凡保留、删除或修补；
- 预审时必须主动写出“为什么贪心不够”。

### E-007：已命名的深定理外壳仍会被bare恢复

**来源**：358号 C4 skew Bollobás bare测试。

**现象**：GLM-5.2先在skew版本的排列法和普通外代数维数上卡住，但最终自己补出“随机投影到 \(\mathbb R^{a+b}\)”的关键步骤，完整证明 \(m\le {a+b\choose a}\)。

**经验**：题目即使不toy，只要它本质是已命名或高度经典的深定理，GLM-5.2仍可能通过长thinking恢复标准证书。88K thinking说明题是硬的，但bare成功说明它不能进入Tell测试。

**下次怎么改**：

- 避免Bollobás/Frankl/LYM/Fisher等已命名定理表面；
- 保留“先有弱维数上界，再压缩证书空间”的结构；
- 换成非标准对象，让证书必须从题面内部生成；
- 预审时主动问：模型是否可能说出这个定理名或作者名？

### E-008：独立随机选择加Chernoff不是合格C1锁

**来源**：358号 C1 有界和表示随机集 bare测试。

**现象**：GLM-5.2直接取 \(p=3\sqrt{\log N/N}\)，用Chernoff和union bound控制所有和表示数。虽然写出的尾界常数证明有一个可修复错误，但路线层已经成功。

**经验**：如果所有坏事件都能被独立二项尾界分别控制，再并合界扫掉，这仍然是标准概率方法外壳，不足以测试“概率存在与去随机化”。

**下次怎么改**：

- 让坏事件之间有真实依赖；
- 让独立选择只能给弱结论；
- 需要删除、修补、条件化或二阶段选择；
- 常数余量不能大到Chernoff一把梭。

### E-009：一次谎言问答太经典，且输出失败不是数学失败

**来源**：358号 C6 一次谎言问答下界 bare测试。

**现象**：GLM-5.2开头直接识别Ulam/Renyi一次谎言模型，在thinking中完整给出 \(N(q+1)\le 2^q\) 的叶子计数证明，但未生成solution文件。

**经验**：C6不能用标准一次谎言或Hamming球计数模型。另一个实验经验是：输出文件缺失要单独记录，不能把它误判成数学失败。

**下次怎么改**：

- 改成多状态、非均匀代价、或动态候选维护；
- 让信息量计数给出弱界，真正结论需要对抗者策略；
- 观察thinking中是否维护“多个可能世界”，而不是只数叶子；
- 记录solution缺失这类落盘异常，但不要把它当作Tell成功空间。

### E-010：新造题必须和历史bare失败锚题同台比较

**来源**：362号第二轮竞赛级挑战题试产。

**现象**：连续几轮新造题都有完整证明骨架，也看起来像竞赛级难题，但真实bare测试后往往被GLM-5.2通过经典外壳或标准短路做出。相反，1631、1843、1709等历史题已经有真实bare失败、匹配Tell成功或错误Tell失败的证据。

**经验**：新题不能孤立评估。每一批新造题都要和历史真实bare失败题放在同一张测试表里，用历史锚题给难度和失败形态定标。否则“题面高级”“证明漂亮”会替代“确实能卡住目标AI”的证据。

**下次怎么改**：

- 每轮新造题都配一组历史锚题；
- 新题只进入Stage B bare筛选，不直接叫Tell候选；
- 若新题bare成功，记录它的短路路线，作为下一版硬化材料；
- 若历史锚题在当前模型版本上转为bare成功，也要更新难度窗口，不能继续按旧证据使用；
- 对新题优先观察“它比历史锚题更容易还是更难被模型命名/短路”。

### E-011：三角化不能自动逃离Frankl-Wilson外壳

**来源**：363号 Q362-C4-01 bare测试。

**现象**：Q362-C4-01把经典模交条件改成有序三角条件，原本希望测试“评价证书 + 三角非奇异矩阵”的C4执行力。但GLM-5.2开局直接识别为Frankl-Wilson变体，并自然写出

```text
f_i(x)=prod_{ell in L}(v_{A_i} dot x - ell)
M_{ij}=f_i(v_{B_j})
```

随后用三角矩阵非零对角线和低次多重线性多项式空间维数完成路线。

**经验**：对称条件改成单向三角条件，不足以构成新外壳。只要题面同时出现“模交 forbidden residues + 低次多项式 + 维数上界”，模型仍会调出Frankl-Wilson/Alon-Babai-Suzuki一类记忆。

**下次怎么改**：

- 不把证书函数直接写成“对交集大小取多项式”；
- 隐藏评价对象与测试对象的配对关系；
- 换掉模交/有限域残基外壳，保留“对象-测试对象形成三角证书矩阵”的骨架；
- 或让三角矩阵只是中间层，最终还需要非模板的压缩/对偶化动作。

### E-012：多加一种干扰状态，不等于C6硬锁

**来源**：363号 Q362-C6-01 bare测试。

**现象**：Q362-C6-01在一次谎言搜索中加入一次沉默状态。GLM-5.2先直接识别为Ulam-Renyi型体积界；随后在“自适应会不会让不同干扰配置合流”处出现真实犹豫，但最终自行找到注入性引理：给定 transcript 与目标 \(x\)，transcript确定路径，路径确定问题，真实答案确定后，`*` 给出沉默位置，mismatch给出谎言位置。

**经验**：C6题不能只是在经典对抗模型中多加一个状态。只要答案仍可被固定目标逐条恢复，体积界会自然扩展，GLM-5.2能在bare中自行补上注入性。

**下次怎么改**：

- 让简单状态计数只给弱界，必须构造对抗者策略或势函数；
- 设计状态合流现象，使“每个配置一条不同transcript”失效，但仍需证明强下界；
- 让叶子覆盖能力依赖历史约束，而不是固定 `t` 的静态列表大小；
- 把卡点放在“如何维护多个可能世界”而不是“如何数干扰模式”。

### E-013：新题应从奥赛母题拆解开始

**来源**：364号奥赛母题分析法。

**现象**：连续多轮凭空新造题虽然有证明骨架，但容易落入经典外壳：Motzkin-Straus、Frankl-Wilson、Erdos随机图、Ulam-Renyi体积界等。相反，`problem_profiles` 中真实奥赛题已经记录了自然错路、key insight、bare失败预测、tell/hint对，这些信息更适合指导造题。

**经验**：出题灵感应该从奥赛题的“失败机制和转向机制”中抽，不从题面表层抽。直接搬题面有训练数据风险；只凭空造题又容易造出经典外壳。正确路径是：母题 -> 自然错路 -> 关键转向 -> 可迁移骨架 -> 换壳 -> 加第二层锁。

**下次怎么改**：

- 每轮新造题前，先选3-5道奥赛母题填写母题拆解表；
- 没有母题拆解表的新题只能算Stage A灵感题，不能直接进入Stage B bare筛选；
- 优先用主导层剥离、excess半群、规范化+容量函数、参数阈值反演这类可换壳骨架；
- 每道新题都要说明“保留母题哪一层，换掉哪一层，训练数据风险在哪里”。

### E-014：奥赛母题启发也有Level族

**来源**：366号奥赛出题启发的Level分层。

**现象**：364号的母题拆解和365号的母题本体测试仍偏Level 1-2：技巧复用和解法骨架复用。用户指出，像“同构之桥”一样，出题思路本身也有更高Level。真正制造挑战的灵感不只是“这题用了什么方法”，而是“这题如何制造一个自然方法必然失败、必须迁移表示/证书/不变量的数学处境”。

**经验**：同一道奥赛题应生成“出题启发族”：Level 0题面复用、Level 1技巧复用、Level 2解法骨架、Level 3失败机制、Level 4命题机制、Level 5数学处境生成法。挑战GLM-5.2的新题应主要从Level 3-4出发。

**下次怎么改**：

- 每个母题先填Level 0-5启发表；
- 新题必须说明自己采用哪个Level的启发；
- Level 0-1题只能做sanity check，不能进入主力bare筛选；
- Level 2题可以做母题本体校准，但不等于新挑战题；
- 进入bare测试的新造题应来自Level 3-4的可操作化出题指令。

### E-015：先用真实题库筛Level 3-4机制盲区，再从盲区造题

**来源**：367号Level 3-4奥赛机制挑战池。

**现象**：直接新造题容易不知道自己是在造“经典骨架轻微变体”还是在造真正的GLM-5.2盲区。`problem_profiles` 已经包含大量真实竞赛题的 `key_insight`、`bare_ai_error_prediction`、tell/hint结构，可以先筛选出Level 3-4机制最强且预测bare失败的题，作为直接挑战池。

**经验**：更稳的路线不是“凭空造题 -> bare淘汰 -> 再猜”，而是：

```text
题库profile筛Level 3-4机制
  -> 直接bare验证当前模型盲区
  -> 从失败thinking提取命题机制Tell
  -> 再按该机制生成新变体题
```

这样能把“出题”建立在真实模型盲区上，而不是建立在人工难度自评上。

**下次怎么改**：

- 优先测试真实题库中Level 3-4机制强、尚无复测记录的题；
- 每题记录自然错路、失败机制、命题机制，而不只是标准解；
- 只有真实bare失败的机制，才优先拿来生成新题；
- 若真实题本体bare成功，则对应机制必须继续升Level或加第二层锁。

### E-016：Level不是标签，而是命题操作

**来源**：368号奥赛出题启发层级的操作化。

**现象**：366号已经提出奥赛出题启发有Level 0-5，但如果只把Level当分类标签，仍然可能停在“这题是Level 4机制”这种描述层。用户进一步指出，像“同构之桥”一样，出题启发本身也应有不同启发层次。真正有用的不是给母题贴Level，而是说明在某个Level上保留什么关系、制造什么失败、迫使什么迁移。

**经验**：高Level出题要把一道奥赛题拆成两份脚本：

```text
解法脚本：这题怎么做？
设障脚本：这题怎样让自然方法失败，并迫使解题者换表示/证书/不变量？
```

Level 0-2主要复用解法脚本，容易被GLM-5.2的已有套路覆盖。Level 3-4主要复用设障脚本，更适合制造可观察的思维力挑战。最高Level的同构之桥不能只迁移正解，还必须迁移自然错路和失败机制。

**下次怎么改**：

- 每道新题都要写“源题角色图”和“目标题角色图”；
- 同构之桥必须检查对象、操作、自然入口、失败点、隐藏结构、证书六类角色；
- 高Level启发必须降回四件套：自然入口、失败点、隐藏结构、证书；
- 只写“仿某奥赛题”或“使用某Level 4机制”不够，必须写出具体命题操作；
- 367号题后续测试时，不只判断做没做出，还要判断GLM-5.2卡在四件套哪一件。

### E-017：第二批机制探针应避开已被秒杀的高频外壳

**来源**：369号Level 4设障脚本挑战池。

**现象**：前几轮直接新造题反复说明，GLM-5.2对若干高频外壳非常敏感：多项式维数证书、随机图删除、一次谎言体积界、谱/Rayleigh商等。一旦题面靠近这些高频骨架，bare可能路线层直接成功。继续只在这些外壳里加参数，很容易制造“复杂但不难”的题。

**经验**：下一批机制探针应选更偏Level 4的设障脚本，而不是继续在高频技巧上加锁。369号选了四类：

```text
反向坍缩：正向构造爆炸，必须从目标集反向合并；
shifty闭包：直接生成对象爆炸，必须问哪些变换保持集合；
尺度势函数：普通空间分割不降复杂度，必须设计带权势函数；
逆映射不变量：表面优化其实是同一边界的两种计数。
```

**下次怎么改**：

- 测试优先跑369的P0：shifty integers 与 polynomial collapse；
- 若bare失败，要从thinking中记录它是卡在“自然入口、失败点、隐藏结构、证书”的哪一项；
- 若bare成功，不能简单说“题不难”，要记录模型具体掌握了哪种Level 4设障脚本；
- 后续新造题应优先从真实bare失败的Level 4脚本跨领域变形，而不是凭空继续加复杂度。

## 6. 思维力到出题卡点的映射

### C4：对偶证书与不可行性证明

合格卡点：

- AI已经找到下界构造；
- AI无法证明没有更好对象；
- AI尝试局部估计但无法全局封顶；
- 需要构造一个证书限制所有对象。

不合格外壳：

- 直接是Fisher不等式；
- 直接是Motzkin-Straus；
- 直接是LP/SDP模板；
- 直接是循环矩阵、Rayleigh商、Fourier谱分解；
- 题面明显写着“最优上界”且标准证书太近。

硬化方向：

- 把证书藏在题目内部的辅助量里；
- 让构造容易，上界不自然；
- 让局部估计给出弱界，迫使寻找全局证书；
- 不让证书名称出现在题面或Tell里。

### C1：概率存在与去随机化

合格卡点：

- AI执着显式构造；
- 存在性对象空间巨大；
- 坏事件局部但多类；
- 随机选择后需要删除、修补或条件化。

不合格外壳：

- 标准随机图避小子图；
- 标准随机染色并合界；
- 只需一次期望小于1；
- 参数一眼平衡；
- 独立选择 + Chernoff + union bound即可完成。

硬化方向：

- 两类坏事件一正一负；
- 随机后需局部修补；
- 先保留足够多结构，再删除坏结构；
- 目标常数留余量，但不能太宽；
- 明确排除朴素贪心禁止值计数能达到目标。

### C6：对抗者量词博弈

合格卡点：

- AI给出静态构造但违反在线/对抗约束；
- 题目有交替量词；
- 对手能根据当前状态回应；
- 证明需要维护候选集或安全区间。

不合格外壳：

- 标准一次说谎问答；
- 标准Hamming球/叶子计数下界；
- 单步在线平衡；
- 只有普通信息量下界；
- 策略一眼可见。

硬化方向：

- 多轮；
- 双方信息不对称；
- 对抗者需要保持多个可能世界；
- 成功策略需要同时维护两个不变量。

## 7. 出题工作流

### Step 1：写骨架，不写Tell

先写题目和标准解，只问：

- 这题的真实卡点是什么？
- 如果不给Tell，AI最自然会走哪条错路？
- 这条错路为什么走不通？

### Step 2：做“经典外壳扫描”

出题后先自问：

- 题面是否直接像某个经典定理？
- 标准解第一步是否是著名套路？
- 模型是否可能开局说“This is classic...”？
- 如果换掉名词，内部结构还在吗？

### Step 3：跑bare

必须通过solver-harness运行。

bare结果分四类：

| 结果 | 处理 |
|---|---|
| bare正确做出 | 淘汰或深改 |
| bare识别经典路线但没写完 | 高风险，优先深改 |
| bare误读题意 | 重写题面 |
| bare卡在目标瓶颈 | 进入Tell测试候选 |

### Step 3.5：决定是否并发

并发只在两种情况下使用：

1. 多道题都已经通过经典外壳扫描和简单出口扫描；
2. 这些题目标思维力不同，或同一思维力的失败模式不同。

并发上限是5，但每道题都必须有独立观察目标。启动前写清：

- 这题预计卡在哪里；
- thinking中看到什么算失败；
- thinking中看到什么算标准路线秒杀；
- 什么时候应提前停止并记录淘汰。

### Step 4：硬化

硬化不是加复杂条件，而是让目标思维力更必要。

常用硬化方法：

- 换外壳：保留骨架，换领域或对象；
- 加第二层锁：目标思维力想到后还要执行一个非模板动作；
- 加错误诱饵：让自然路线给出弱界或假希望；
- 降训练痕迹：避开经典定理名、经典参数、经典常数；
- 保持可解：标准解仍应在1-3页内完成。

### Step 5：Tell测试

只有bare失败且卡点正确时，才写Tell测试。

Tell必须：

- 不含题目特定对象；
- 不含具体方法名；
- 只给思维流程；
- 不直接告诉“用随机图”“用Gram矩阵”“用Galois群”这类路线。

## 9. 读完后要记住的5句话

1. POC难题不是普通竞赛题，它要测的是AI缺不缺某种思维力。
2. 难题要从经典题中抽思维力内核，再换外壳、加诱饵、加锁。
3. toy题可以测工具链，不能测高Level思维力。
4. 好验证题必须有可观察卡点：bare卡在那里，Tell后突破那里。
5. 并发只服务于高质量观察；每一次失败出题都要写回本文，让下一题更硬。
