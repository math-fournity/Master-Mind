# 368号 · 奥赛出题启发层级的操作化：从同构之桥到挑战制造

**日期**：2026-08-12  
**文档性质**：对366号的深化。366号定义“奥赛出题启发有Level族”，本文把这些Level变成可执行的命题操作。  
**触发原因**：用户进一步指出：奥赛题不能只在低Level看“题面/技巧/骨架”，而应像“同构之桥”一样，从更高Level理解“如何制造挑战”。出题思路本身也有启发层次。  
**前置文档**：333号同构之桥、340号高Level概念两种类型、345号Tell族Level与指导力钟形曲线、346号去特化三步法、347号Tell提示词三种形态、356号出题经验库、366号奥赛出题启发Level分层、367号Level 3-4挑战池  
**一句话结论**：奥赛题给我们的最高价值不是“它怎么解”，而是“它怎样构造一个让自然思路失效、迫使解题者跨过同构之桥的数学处境”。出题Level不是标签，而是选择保留哪一种关系、制造哪一种失败、迫使哪一种迁移。

---

## 0. 核心修正：Level不是分类标签，而是命题操作

366号已经把奥赛题的启发分成Level 0-5：

```text
Level 0：题面复用
Level 1：技巧复用
Level 2：解法骨架复用
Level 3：失败机制复用
Level 4：命题机制复用
Level 5：数学处境生成法
```

这一步还不够。真正用于出题时，Level不应该只是“这题属于哪一层”的标签，而应该是一个操作问题：

```text
我从母题保留什么？
我从母题丢掉什么？
我在新题里制造什么自然错路？
我怎样让这条错路必然失败？
我怎样迫使解题者迁移到新的表示、证书或不变量？
```

也就是说，Level是命题机器的档位。

低Level保留的是题面、技巧、步骤。  
高Level保留的是角色关系、失败机制、强制迁移机制。  
最高Level保留的是一类数学处境的生成法。

## 1. 先把一道奥赛题拆成两份脚本

分析奥赛题时，不能只写“解法脚本”。还要写“设障脚本”。

### 1.1 解法脚本

解法脚本回答：

```text
这题怎么做？
第一步是什么？
关键引理是什么？
最后证书是什么？
```

这通常对应Level 1-2。它能帮我们写标准解，但不一定能帮我们制造挑战。因为GLM-5.2可能已经掌握了这个解法骨架。

### 1.2 设障脚本

设障脚本回答：

```text
这题为什么难？
题面诱导解题者先走哪条自然路？
这条路为什么看起来合理？
它在哪里失败？
失败后，必须换到什么新对象、新坐标、新证书或新不变量？
题目条件怎样保证这种迁移是必要的？
```

这对应Level 3-5。真正挑战GLM-5.2的新题，应该优先复用设障脚本，而不是复用解法脚本。

### 1.3 关键区别

同一道题可以有两种完全不同的读法：

| 读法 | 问题 | 产物 | 风险 |
|---|---|---|---|
| 解题者读法 | 我怎样把它做出来？ | 技巧、骨架、证明步骤 | 容易被模型记忆或标准套路覆盖 |
| 命题者读法 | 它怎样迫使人换视角？ | 诱饵、失败点、必要迁移机制 | 更适合制造新挑战 |

以后分析奥赛题，必须同时写这两份脚本。只写解法脚本的新题，最多算Level 2候选。

## 2. 每个Level对应的“挑战制造操作”

下面这张表是366号的操作化版本。

| Level | 保留什么 | 丢掉什么 | 制造挑战的操作 | 适合用途 |
|---|---|---|---|---|
| Level 0 题面复用 | 对象、常数、叙述 | 几乎不丢 | 换名词、换背景 | 工具链sanity check |
| Level 1 技巧复用 | 一个具体技巧 | 原题题面 | 造一个必须用同技巧的小题 | 低难度校准 |
| Level 2 解法骨架 | “自然路 -> 转向 -> 证书”的步骤 | 具体对象 | 换壳保留证明拓扑 | Stage A/B候选 |
| Level 3 失败机制 | 自然路为什么失败 | 标准解步骤 | 先设计诱饵，再设计不可绕过的失败点 | 主力挑战层 |
| Level 4 命题机制 | 题目怎样迫使迁移 | 具体技巧名、原证明顺序 | 设计一个必须换表示/证书/不变量的处境 | 主力挑战层 |
| Level 5 数学处境生成法 | 一类处境的生成规则 | 单题痕迹 | 生成一族题，再降回Level 3-4落题 | 长期命题法 |

### 2.1 Level越高，不等于题越好

Level太低的问题是训练痕迹重。  
Level太高的问题是不可操作，容易变成口号。

真正的峰值通常在Level 3-4：

```text
足够高：不只是复刻技巧；
足够具体：能落成一页到三页的竞赛题；
足够可观察：bare thinking中能看到自然错路和失败点。
```

## 3. 同构之桥：最高价值不是“像”，而是“角色关系可迁移”

用户提到“同构之桥”，这正是高Level出题的核心。

低质量类比是：

```text
这题看起来像那题。
```

真正的同构之桥是：

```text
源题中的对象、操作、障碍、证书，在目标题中都有角色对应；
并且自然错路和失败机制也一起被迁移。
```

### 3.1 一座合格的同构之桥需要保留六类角色

| 源题角色 | 目标题中必须对应什么 |
|---|---|
| 表面对象 | 一个不同领域中的本土对象 |
| 合法操作 | 目标领域中自然存在的操作 |
| 自然入口 | 目标领域中也会自然想到的第一条路 |
| 失败机制 | 这条自然路在目标领域中也必然不够 |
| 隐藏结构 | 一个需要迁移视角才能看见的表示/坐标/证书 |
| 完成证书 | 最终能严格证明的对象、势函数、不变量或对偶证书 |

最重要的是：桥不能只保留正解。桥还要保留失败机制。

如果只迁移正解，模型可能直接用另一路解掉。  
如果迁移了失败机制，模型才会在bare中暴露可观察缺口。

### 3.2 同构之桥的验证问题

每次说“从A题迁移到B题”，必须回答：

```text
A题的自然错路是什么？
B题里对应的自然错路是什么？
A题自然错路的失败点是什么？
B题里对应失败点是否仍然成立？
A题的隐藏结构是什么？
B题里这个隐藏结构是否是本土的，而不是硬塞进去的？
A题的证书是什么？
B题里的证书是否能在竞赛篇幅内写清？
```

如果这些问题答不出来，那不是同构之桥，只是表面类比。

## 4. 高Level出题的基本公式

一题是否适合挑战GLM-5.2，可以用这个公式检查：

```text
挑战 = 自然入口 + 必然失败 + 被遮蔽的可迁移结构 + 可验证证书
```

四个零件缺一不可。

### 4.1 自然入口

题目必须有一条AI自然会走的路。

没有自然入口，bare thinking会乱走，无法判断模型缺什么。自然入口不一定是错路，它可以给出弱结果、局部结果、错误直觉或假希望。

### 4.2 必然失败

自然入口必须在某个具体点失败。

失败不能只是“算起来很复杂”。合格失败应该是结构性失败：

```text
局部估计无法给全局上界；
静态构造无法满足在线量词；
显式构造无法跨过不可达缺口；
平均量足够但局部瓶颈不可忽略；
对象空间太大，必须转到参数空间；
目标量不可加，必须改看差额量。
```

### 4.3 被遮蔽的可迁移结构

正解必须依赖一个不在题面上直接显露的结构。

它可以是：

- 隐藏不变量；
- 对偶证书；
- 规范形；
- 商空间；
- 时间块；
- 势函数；
- 阈值参数；
- 可加差额；
- losing squares；
- 模循环表示；
- 线性化坐标。

关键是：这个结构必须是新题内部自然生成的，而不是从母题强行塞进去。

### 4.4 可验证证书

最后必须能严格评分。POC题不能变成开放探索。

证书可以是：

- 一个构造；
- 一个不变量；
- 一个势函数；
- 一个上界证书；
- 一个策略；
- 一个不可达证明；
- 一个同余类；
- 一个正规化算法。

没有证书，题就不能用于Tell验证。

## 5. 从奥赛母题到新挑战题的七步法

### Step 1：写母题的解法脚本

先写清楚母题怎么做。但这只是素材，不是命题法。

### Step 2：写母题的设障脚本

回答：

```text
自然路是什么？
为什么会被诱导到这里？
失败点在哪里？
正解换了什么视角？
题目条件怎样强迫这个换视角？
```

### Step 3：选择要保留的Level

如果目标是挑战GLM-5.2，默认从Level 3-4选。

不要说：

```text
仿照IMO某题出一道题。
```

要说：

```text
复用这个命题机制：
表面目标量不可加，但相对于平凡对象的差额可加；
自然构造在阈值附近失败；
强结论由一个最小不可达差额控制。
```

### Step 4：建立同构之桥

把源题角色映射到目标题角色：

```text
源对象 -> 目标对象
源操作 -> 目标操作
源自然错路 -> 目标自然错路
源失败点 -> 目标失败点
源隐藏结构 -> 目标隐藏结构
源证书 -> 目标证书
```

桥不成立，就不要出题。

### Step 5：降Level落题

高Level不能直接交给Solver。必须降回一份具体题面：

```text
题面短；
条件少；
入口自然；
正解1-3页；
不出现母题关键词；
不出现标准定理名；
常数有余量但不松垮。
```

### Step 6：写bare失败预注册

出题前先写：

```text
bare预计会走哪条路？
看到什么thinking算目标失败？
看到什么thinking算模型直接识别？
看到什么thinking算题面误导？
看到什么proof算路线成功但证明失败？
```

没有预注册，就容易事后解释。

### Step 7：真实bare测试

只有真实bare失败，题才有资格进入Tell测试。  
如果bare成功，记录成功路线，并把它反向写回出题经验库。

## 6. 一个母题的多Level启发示例

下面用“阈值构造 + 不可达差额”这一类母题机制说明。

### Level 0：题面复用

```text
仍然问平方和，换几个常数。
```

这几乎没有价值。

### Level 1：技巧复用

```text
仍然寻找一个半群不可达数，例如3a+8b无法表示13。
```

这比换皮好，但仍然太像标准技巧。

### Level 2：解法骨架复用

```text
先构造大多数情况；
再找一个小缺口；
用缺口证明阈值不能再提高。
```

这能生成候选题，但模型可能直接恢复“Frobenius/半群缺口”套路。

### Level 3：失败机制复用

```text
直接构造目标对象看起来可行；
但目标对象本身不可加，局部改造无法拼接；
必须改看某个差额/亏损/余量；
这个差额空间中存在一个小的不可达缺口，阻断强结论。
```

这开始像真正挑战。

### Level 4：命题机制复用

```text
制造一个阈值问题；
让表面目标量在操作下不闭合；
设计一个相对于平凡对象的隐藏可加量；
让一个最小不可达隐藏量同时控制必要性；
再设计一个可平移构造证明充分性。
```

这才是可以跨领域造题的命题机制。

### Level 5：数学处境生成法

```text
生成一类“表面不可加、隐藏差额可加、阈值由最小不可达缺口控制”的问题。
```

Level 5本身还不能直接测试。它需要再降回Level 3-4，生成具体题面。

## 7. 高Level启发怎样避免“太抽象”

高Level最大风险是变成漂亮口号。防止方法是要求每个高Level启发都必须能降成四个具体字段。

```text
自然入口：
失败点：
隐藏结构：
证书：
```

例如，不能只写：

```text
这题体现了同构之桥。
```

必须写成：

```text
自然入口：直接在原对象上构造；
失败点：原对象的操作不闭合，局部构造无法拼接；
隐藏结构：把对象映到差额半群；
证书：某个小差额不可达，同时所有更大差额可达。
```

如果写不出这四项，这个高Level启发暂时不能用于出题。

## 8. 对367号挑战池的重新定位

367号已经从真实profile中筛出6道Level 3-4机制题。按本文框架，它们的作用不是直接当最终题库，而是当“高Level机制探针”。

每一道367题后续bare测试都要回答两个问题：

1. GLM-5.2是否已经能跨过这道题的同构之桥？
2. 如果不能，它具体卡在四件套的哪一件？

四件套是：

```text
自然入口
失败点
隐藏结构
证书
```

只有当某道真实竞赛题bare卡在目标机制上，才把它升级为新造题种子：

```text
真实题bare失败
  -> 抽取失败机制
  -> 建立跨领域同构之桥
  -> 降Level生成新题
  -> 再bare测试
```

这比直接凭空造题更稳，因为它先用真实模型行为校准了盲区。

## 10. 读完后要记住的5句话

1. 奥赛题的最高价值不是提供一道可仿题，而是提供一套制造挑战的设障脚本。
2. Level不是标签，而是命题操作：决定保留哪种关系、制造哪种失败、迫使哪种迁移。
3. 同构之桥必须同时迁移正解和失败机制；只迁移正解不够。
4. 真正可测试的挑战题必须有四件套：自然入口、失败点、隐藏结构、证书。
5. 高Level启发必须先降回Level 3-4，写成具体题面和bare预注册，再交给Devin测试。
