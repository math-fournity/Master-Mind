# 347号 · Tell提示词的三种形态——一句话/思维流程引导式/抽象标签，与钟形曲线的修正

**日期**：2026-08-11
**触发原因**：用户在346号（三步法找钟形曲线峰值）后指出"也许未来有些Tell的提示词，不是那么短的，是启发式的，甚至是思维流程和步骤引导式的"
**前置文档**：346号（三步法）、345号（Tell族+钟形曲线）、340号（高Level概念两种类型）、335号（三种解释文本）

---

## 1. 核心发现——Tell提示词有三种形态

Tell的提示词不只是一句话——根据Level和可操作性的不同，有三种形态：

### 形态1：一句话指示

**特征**：简洁、具体、直接告诉AI做什么操作

**Level位置**：钟形曲线中间偏左（具体概念层）

**AI指导力**：中-高（可操作，但泛化范围有限）

**例子**：
- "用鸽巢论证找存在性元素"
- "定义辅助变量缩小问题规模后应用归纳"
- "用swap修复排列构造中的障碍"

**适用场景**：trace去特化到具体概念层，操作明确不需要步骤引导

### 形态2：思维流程/步骤引导式

**特征**：不是一句话，而是一段逐步引导AI思维的流程——问问题、给步骤、引导AI自己发现方向

**Level位置**：钟形曲线中间偏右（高Level，但通过步骤引导恢复可操作性）

**AI指导力**：中-高（虽然是高Level概念，但通过步骤引导可操作化，恢复指导力）

**例子**——"同构之桥"的思维流程引导式Tell：

```
你当前在什么领域打转？
  → 识别当前领域的核心对象和操作
你尝试过什么方向？
  → 列出已尝试的方向
这些方向都失败了，说明什么？
  → 当前领域可能缺少处理这个问题的工具
那哪个领域可能有？
  → 检查是否有同构对象（同样的代数结构在不同领域出现）
  → 检查是否有对偶问题（这个问题的反面在另一个领域可能更简单）
  → 检查是否有表示转换（换一种表示看问题）
如果找到一个可能的目标领域，怎么判断值不值得跨？
  → 评估跨域成本 vs 当前领域继续探索的成本
```

**适用场景**：trace去特化到段结构模式层或更高（高Level Tell），一句话不够指导，需要步骤引导才能可操作化

### 形态3：抽象标签

**特征**：只有一个抽象的分类标签，没有具体操作引导

**Level位置**：钟形曲线右端（最高抽象）

**AI指导力**：低（不可操作，AI不知道具体该怎么做）

**例子**：
- "考虑跨域桥接"（只有标签没有步骤）
- "构造-分析-排除"（只有模式名没有具体操作）

**适用场景**：不应作为Tell存储——这是分类学坐标轴的刻度名（336号），不是Tell本身。如果只有抽象标签，需要要么降低Level到具体概念层（形态1），要么可操作化为思维流程（形态2）

## 2. 钟形曲线的修正——提示词形态影响指导力

345号提出的钟形曲线描述了Level和AI指导力的关系。但345号没有考虑提示词形态的影响——**同一Level的Tell，提示词形态不同，AI指导力不同**：

```
AI指导力
  1.0 |          ██
      |        ██②██          ②=思维流程引导式（高Level但可操作化）
      |      ██      ██
      |    ①          ②       ①=一句话指示（具体概念层）
      |  ①              ③      ③=抽象标签（高Level不可操作）
  0.0 |③                  ③
      +------------------------→ Level
      0.0       0.5        1.0
```

**关键洞察**：高Level Tell不一定是低指导力的——如果它的提示词是思维流程/步骤引导式的（形态2），而不是抽象标签（形态3），它可以通过可操作化恢复指导力。

**钟形曲线的修正**：
- 345号的钟形曲线假设提示词形态固定（都是一句话）——在这个假设下，高Level确实指导力低
- 实际上，高Level Tell可以通过改变提示词形态（从形态3变为形态2）来恢复指导力
- **所以钟形曲线不是一条固定的曲线，而是一个曲线族——每条曲线对应一种提示词形态**

## 3. 和340号两种类型的深化对应

340号区分了高Level概念的两种类型，现在可以用提示词形态深化理解：

### 第一种（可展开的）——如"构造-分析-排除"

- **抽象标签形态（形态3）**："构造-分析-排除"——指导力低
- **展开为具体形式列表**：如"构造辅助函数/构造反例/构造序列"——回到形态1，恢复指导力
- **也可以展开为思维流程引导式（形态2）**：
  ```
  你需要构造什么对象？
    → 你要排除什么不可能？
    → 构造什么能帮你排除？
    → 构造的对象有什么性质可以分析？
  ```
- **可展开的高Level Tell有两种恢复指导力的方式**：展开为形态1（具体形式列表）或形态2（思维流程引导）

### 第二种（无法指定展开方向的）——如"同构之桥"

- **抽象标签形态（形态3）**："考虑跨域桥接"——指导力低
- **无法展开为具体形式列表**（目标领域开放，不能预先列举）——不能回到形态1
- **但可以展开为思维流程引导式（形态2）**：如上面的"同构之桥"思维流程引导
- **无法指定展开方向的高Level Tell只有一种恢复指导力的方式**：可操作化为形态2（思维流程引导）

**深化结论**：
- 340号说第二种类型"覆盖缺口永远存在"——这是因为不能展开为形态1（具体形式列表），不能预先列举所有可能的目标领域
- 但通过形态2（思维流程引导），第二种类型可以恢复指导力——虽然不能列举所有目标领域，但可以引导AI自己探索可能的目标领域
- **所以"覆盖缺口永远存在"不等于"指导力永远低"**——覆盖缺口是范围问题（不能覆盖所有可能的目标领域），指导力是操作问题（AI知道怎么去探索目标领域）

## 4. 和335号"三种解释文本"的对应

335号说高Level概念需要"充分解释+例子"，并定义了三种解释：
- 执行型解释（给推理AI用）——"怎么做"
- 识别型解释（给Telling AI用）——"什么时候需要"
- 判断型解释（给动态生成AI用）——"值不值得"

**现在的深化**：335号的"执行型解释"就是形态2（思维流程/步骤引导式）——告诉AI"怎么做"。335号已经预见了高Level概念需要的不只是一句话，需要"充分解释"——现在更精确地说，充分解释的形式是思维流程和步骤引导，不只是一段描述性文字。

**新增的认知**：335号没有区分形态2（思维流程引导式）和形态3（抽象标签+描述性文字）——两者都是"充分解释"但指导力不同。形态2是可操作的（引导AI逐步思维），形态3只是描述性的（告诉AI概念是什么但不引导它怎么做）。

## 5. 对去特化Pipe的设计含义

入题侧下一个Pipe（去特化+存储）的AI提示词不仅要引导三步法（346号），还要根据去特化产出的Level决定提示词形态：

1. **去特化到具体概念层（Level低-中）** → 产出形态1（一句话指示）的Tell
2. **去特化到段结构模式层或更高（Level高）** → 产出形态2（思维流程引导式）的Tell
   - 不能只产出形态3（抽象标签）——那是分类学坐标轴的刻度名，不是Tell
   - 必须把高Level概念可操作化为思维流程引导，恢复指导力
3. **判断是340号第一种还是第二种**：
   - 第一种（可展开的）→ 可以选择形态1（展开为具体形式列表）或形态2（思维流程引导）
   - 第二种（无法指定展开方向的）→ 只能选择形态2（思维流程引导），不能展开为形态1

## 6. POC验证的需求

本号的核心认知需要POC验证——尤其是"同构之桥"这个Tell：

**验证目标**：思维流程引导式Tell（形态2）是否比抽象标签Tell（形态3）有更高的AI指导力？

**验证方法**：
1. 找一道AI在某个领域打转走不出来的题
2. 给AI抽象标签Tell（"考虑跨域桥接"）→ 观察AI是否能跨域
3. 给AI思维流程引导式Tell（"同构之桥"的思维流程引导）→ 观察AI是否能跨域
4. 对比两种情况的效果

**预期结果**：形态2（思维流程引导式）比形态3（抽象标签）有更高的AI指导力——AI在步骤引导下能更有效地探索可能的目标领域。

**POC方案需要设计**——这是下一步工作。
