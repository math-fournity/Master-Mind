## 二、当前前沿（R4 的两大贡献，附推导骨架）

### 2.1 代入恒等式框架（R4 的主工具，一句话即可重建）

把 c = ab − 2ˣ 代入另外两式，展开移项得：

- b(a²−1) = 2ᶻ + 2ˣa = 2ˣ(2^(z−x) + a)；同型地 a(b²−1) = 2ʸ + 2ˣb = 2ˣ(2^(y−x) + b)；
- 把 b = ca − 2ᶻ 代入 bc−a=2ʸ 得 a(c²−1) = 2ʸ + 2ᶻc = 2ᶻ(2^(y−z) + c)。

在全异情形 z−x≥1、y−x≥1、y−z≥1，三个括号内都是"奇数加偶数"=奇数，于是取 v₂ 立刻得三条精确等式：

**x = v₂(b·(a²−1))，x = v₂(a·(b²−1))，z = v₂(a·(c²−1))。**

这三条是 R4 全部杀伤的引擎。（R4 在思考流字符位约 38489 处对第一条做过逐项 due diligence，确认无漏。）

### 2.2 五种模式的纯奇偶秒杀（R4）

对每个 (parity a,b,c) 模式直接算 ab−c、bc−a、ca−b 的奇偶：2 的幂是奇的当且仅当它等于 1。于是某式为奇就强制对应指数为 0，再与 x<z<y 严格序对照即死。逐模式结论见第一节表格。(E,E,O) 中 x=0 与已知结构一致（存活）；(O,O,O) 三式全偶（存活）；(E,E,E) 三式全偶（需引理）。此杀法使 R2 的 (O,E,O) 挤压论证成为可选的重炮，但两者不矛盾，写作时可保留任意一个。

### 2.3 (O,O,O) 定理（R4 新增，本交接最核心内容）

设全异解满足 a<b<c 且全奇，则 a≥3、b、c 奇、c−b≥2、x<z<y。推导链五步：

1. 由 2.1 第三条（此处 a 为奇数）：**z = v₂(c²−1)**。
2. c 奇时 c²−1=(c−1)(c+1)，两因子 gcd=2 且恰一个被 4 整除，故 v₂ 的两个成分中 min=1、max=z−1，而带 valuation z−1 的那个因子不超过 c+1，得 **2^(z−1) ≤ c+1，即 2ᶻ ≤ 2c+2**。
3. 另一方面 **2ᶻ = ca − b ≥ 3c − b ≥ 3c − (c−2) = 2c+2**（用 a≥3、b≤c−2）。
4. 两端夹逼迫使处处取等：**2ᶻ = 2c+2，a=3，b=c−2，且 c+1 = 2^(z−1)**（即 c = 2^(z−1)−1，c≡3 mod 4）。
5. 由 2.1 第一条（b 奇）：**x = v₂(a²−1) = v₂(8) = 3**，故 ab−c = 8；代入 a=3、b=c−2 得 2c−6=8，**c=7，b=5**。回代验证：ab−c=8=2³、bc−a=32=2⁵、ca−b=16=2⁴，全部成立。∎

结论：(O,O,O) 既约解唯一，即 **(3,5,7)**。【R4 推出，R5 观察者逐步复核无误，并经参数化深扫至 a≤30000 旁证】
