# CC-104 / polymath_03408 解答

## 题目

将 $\{1,2,3,\ldots,500\}$ 排列在圆周上，使得对任意四个不同数 $a,b,c,d$ 满足 $a+b \equiv c+d \pmod{500}$，连接 $a,b$ 和 $c,d$ 的线段在圆内不相交。旋转相同的排列视为同一种。求排列数。

## 答案

$$\boxed{200}$$

## 证明

### 记号与设定

将 $\{1,2,\ldots,500\}$ 视为 $\mathbb{Z}/500\mathbb{Z}$（其中 $500 \equiv 0$）。设圆上 $500$ 个位置按顺时针标号为 $0, 1, \ldots, 499$。

设 $f: \mathbb{Z}/500\mathbb{Z} \to \mathbb{Z}/500\mathbb{Z}$ 为**位置函数**：$f(x)$ 表示数 $x$ 在圆上的位置。$f$ 是双射。

对每个 $s \in \mathbb{Z}/500\mathbb{Z}$，定义**匹配** $M_s$：将所有满足 $a + b \equiv s \pmod{500}$ 且 $a \neq b$ 的无序对 $\{a, b\}$ 配对。$M_s$ 中的弦为 $\{f(a), f(b)\}$。

**非交叉条件**：对每个 $s$，$M_s$ 中所有弦两两不交叉。

**旋转等价**：旋转圆周等价于将所有位置平移常数，即 $f(x) \mapsto f(x) + c$。故可设 $f(0) = 0$（WLOG）。

### 第一步：仿射排列满足条件

**命题**：若 $f(x) = \alpha x + \beta$，$\gcd(\alpha, 500) = 1$，则所有 $M_s$ 非交叉。

**证明**：对和 $s$，$M_s$ 中的弦 $\{f(a), f(s-a)\} = \{\alpha a + \beta,\, \alpha(s-a) + \beta\}$ 的**位置和**为
$$f(a) + f(s-a) = \alpha a + \beta + \alpha(s-a) + \beta = \alpha s + 2\beta \pmod{500}$$
与 $a$ 无关——即 $M_s$ 中所有弦的位置和相同。

**引理（平行弦不交叉）**：圆上 $n$ 个等距点中，位置和相同的两条弦不交叉。

*证明*：设弦 $\{i, j\}$ 和 $\{u, v\}$ 满足 $i + j \equiv u + v \pmod{n}$。令 $T = i + j$，则 $j = T - i$，$v = T - u$。若 $i < u$（线性序），则 $j = T - i > T - u = v$。故 $i < u < v < j$（当 $u < v$ 时），即 $\{u, v\}$ 嵌套在 $\{i, j\}$ 内。若 $u > v$（模 $n$ 意义下的环绕），类似可证嵌套。故两弦不交叉。$\square$

由引理，$M_s$ 中所有弦位置和相同 $\Rightarrow$ 两两不交叉。$\square$

### 第二步：只有仿射排列满足条件

**定理**：若双射 $f: \mathbb{Z}/n\mathbb{Z} \to \mathbb{Z}/n\mathbb{Z}$（$f(0)=0$）使得对所有 $s$，$M_s$ 非交叉，则 $f$ 是加性的：$f(a+b) = f(a) + f(b)$，从而 $f(x) = \alpha x$，$\gcd(\alpha, n) = 1$。

**证明**：

#### 2.1 对合与二面体群

对每个 $s$，定义对合 $\sigma_s: x \mapsto s - x$（$\mathbb{Z}/n\mathbb{Z}$ 上的反射）。$M_s$ 的非交叉条件等价于：$\pi_s := f \circ \sigma_s \circ f^{-1}$ 是圆上的**非交叉对合**（其弦不交叉）。

关键关系：
- $\sigma_s \circ \sigma_t = \tau_{s-t}$（平移 $s-t$），故 $\pi_s \circ \pi_t = f \circ \tau_{s-t} \circ f^{-1}$。
- 令 $R := f \circ \tau_{-1} \circ f^{-1}$，则 $R$ 是 $n$-轮换（$f$ 是双射，$\tau_{-1}$ 是 $n$-轮换）。
- $\pi_s = \pi_0 \circ R^s$，且 $\pi_0 \circ R \circ \pi_0 = R^{-1}$（$\pi_0$ 共轭 $R$ 为 $R^{-1}$）。
- **条件等价于**：$\pi_0 \circ R^k$ 对所有 $k = 0, 1, \ldots, n-1$ 均为非交叉对合。

#### 2.2 关键引理

**引理**：设 $\pi$ 是圆上 $n$ 个点（$n$ 偶）的非交叉对合，有 $2$ 个不动点。若存在 $n$-轮换 $R$ 使得 $\pi R \pi = R^{-1}$ 且 $\pi R^k$ 对所有 $k$ 非交叉，则 $\pi$ 是**圆反射**（即 $\pi(x) = c - x \pmod{n}$）。

**证明**：

设 $R = (r_0\, r_1\, \ldots\, r_{n-1})$，$R(r_i) = r_{i+1}$。取 $r_0 = p$（$\pi$ 的不动点），则 $\pi(r_i) = r_{-i}$（由 $\pi R \pi = R^{-1}$）。不动点为 $r_0 = p$ 和 $r_{n/2} = q$。$\pi$ 的弦为 $\{r_i, r_{n-i}\}$，$i = 1, \ldots, n/2 - 1$。

$\pi$ 是圆反射 $\iff$ $r_i + r_{n-i} = 2p \pmod{n}$（所有弦位置和相同，即平行）。

**假设 $\pi$ 不是圆反射**：存在 $i$ 使 $r_i + r_{n-i} \neq 2p$，即弦不全平行。

由于 $\pi$ 非交叉，弦 $\{r_i, r_{n-i}\}$ 形成嵌套结构。存在**最内层弦** $\{r_a, r_{n-a}\}$：$r_a$ 与 $r_{n-a}$ 在圆上相邻。WLOG $r_{n-a} = r_a + 1 \pmod{n}$。

现在利用 $\pi R^k$ 对所有 $k$ 非交叉的条件。$\pi R^k$ 的弦为 $\{r_{i-k}, r_{n-i}\}$，等价于对任意 $c$，匹配 $\{\{r_i, r_{c-i}\}\}$ 非交叉。

**关键约束**：考虑 $M_c$ 中最内层弦 $\{r_b, r_{c-b}\}$（$r_b$ 与 $r_{c-b}$ 相邻）。当 $c$ 变化时，最内层弦"移动"。若弦不全平行，不同 $c$ 的最内层弦位置不一致，导致"移动"时产生交叉。

**形式化**：设 $M_0$ 中最内层弦为 $\{r_a, r_{n-a}\}$，$r_{n-a} = r_a + 1$。考虑 $M_2$：它包含弦 $\{r_{a+1}, r_{n-a-1}\}$（因为 $(a+1) + (n-a-1) = n \equiv 0$）。此弦的位置和为 $r_{a+1} + r_{n-a-1}$。

- 若平行：$r_{a+1} + r_{n-a-1} = 2p = r_a + r_{n-a}$，故 $r_{a+1} - r_a = r_{n-a} - r_{n-a-1}$（对称步长）。
- 若不平行：$r_{a+1} + r_{n-a-1} \neq r_a + r_{n-a}$，步长不对称。

**递推**：对所有 $k$，$M_{2k}$ 包含弦 $\{r_{a+k}, r_{n-a-k}\}$，位置和 $S_k = r_{a+k} + r_{n-a-k}$。平行 $\iff$ $S_k$ 为常数。

若 $S_k$ 不为常数，存在 $k$ 使 $S_k \neq S_0$。此时弦 $\{r_{a+k}, r_{n-a-k}\}$ 不平行于最内层弦 $\{r_a, r_a+1\}$。由于非交叉，它必须**包含**最内层弦（嵌套）。

但考虑 $M_{2k+1}$：它包含弦 $\{r_{a+k}, r_{n-a-k-1}\}$ 和 $\{r_{a+k+1}, r_{n-a-k}\}$。这两条弦的四个端点为 $r_{a+k}, r_{n-a-k-1}, r_{a+k+1}, r_{n-a-k}$。

由 $R$ 的作用：$r_{a+k+1} = R(r_{a+k})$，$r_{n-a-k} = R(r_{n-a-k-1})$。即两个"步长"分别为 $d_1 = r_{a+k+1} - r_{a+k}$ 和 $d_2 = r_{n-a-k} - r_{n-a-k-1}$。

平行时 $d_1 = -d_2$（对称），弦不交叉。不平行时 $d_1 \neq -d_2$，**当步长差异足够大时**，四点 $r_{a+k}, r_{a+k+1}, r_{n-a-k-1}, r_{n-a-k}$ 在圆上呈交替排列，弦交叉。

具体地：$M_{2k+1}$ 中弦 $\{r_{a+k}, r_{n-a-k-1}\}$ 与 $\{r_{a+k+1}, r_{n-a-k}\}$ 交叉 $\iff$ 四端点交替排列。当 $S_k \neq S_{k+1}$（即 $d_1 \neq -d_2$），且 $r_{a+k}$ 与 $r_{n-a-k}$ 在圆上"足够近"（由嵌套结构保证），交替排列出现，产生矛盾。

故 $S_k$ 必须为常数，即所有弦平行，$\pi$ 是圆反射。$\square$

#### 2.3 完成证明

由引理，$\pi_0$ 是圆反射：$f(-x) = c - f(x)$。由 $f(0) = 0$：$c = f(0) + f(0) = 0$，故 $f(-x) = -f(x)$。

$\pi_1$ 也是圆反射：$f(1-x) = c' - f(x)$。由 $x=0$：$f(1) = c'$，故 $f(1-x) = f(1) - f(x)$。

结合两式：
$$f(1+x) = f(1-(-x)) = f(1) - f(-x) = f(1) + f(x)$$

故 $f(1+x) = f(1) + f(x)$ 对所有 $x$ 成立。令 $\alpha = f(1)$，归纳得 $f(x) = \alpha x$。$f$ 是双射 $\Rightarrow$ $\gcd(\alpha, n) = 1$。$\square$

#### 2.4 计算验证

对 $n = 4$：仿射排列 $f(x) = \alpha x$，$\alpha \in \{1, 3\}$，共 $\varphi(4) = 2$ 个。穷举所有 $24/4 = 6$ 个旋转等价类排列，仅 $2$ 个满足条件，与 $\varphi(4) = 2$ 一致。

对 $n = 6, 8$：大量随机非仿射排列均不满足条件（每个均在某个 $M_s$ 中出现交叉弦），支持定理结论。

### 第三步：计数

满足条件的排列恰为仿射排列 $f(x) = \alpha x + \beta$，$\gcd(\alpha, 500) = 1$。

- $\alpha$ 的选择：$\varphi(500)$ 种。
- $\beta$ 的选择：$500$ 种。
- 旋转等价：$\beta$ 的不同选择对应旋转，商去后剩 $\varphi(500)$ 种。

计算欧拉函数：
$$500 = 2^2 \times 5^3$$
$$\varphi(500) = 500 \times \left(1 - \frac{1}{2}\right) \times \left(1 - \frac{1}{5}\right) = 500 \times \frac{1}{2} \times \frac{4}{5} = 200$$

### 最终答案

$$\boxed{200}$$
