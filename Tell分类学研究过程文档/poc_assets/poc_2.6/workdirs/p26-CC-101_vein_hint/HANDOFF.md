## 1. 题目

求最小正整数 $n$，使得存在一个 $n$-着色 $c : \mathbb{Z}_{>0} \to \{1, \dots, n\}$，对方程

$$w + 6x = 2y + 3z$$

的任意正整数解 $(w, x, y, z)$（不必互异），都满足 $c(w), c(x), c(y), c(z)$ 不全相同。

等价表述：求方程 $w + 6x = 2y + 3z$ 的 **degree of regularity**（正则度）$\mathrm{dor}(E)$，则 $n = \mathrm{dor}(E) + 1$。

因此 $\mathrm{dor}(E) = 3$，最小着色数 $n = 4$。

## 3. 已确认的结论

### 3.1 Rado 定理判定：方程不是分划正则的

方程 $w + 6x = 2y + 3z$ 的系数为 $\{1, 6, -2, -3\}$。

**Rado 定理**：线性方程是分划正则（partition regular）的充要条件是存在某个非空系数子集，其和为零。

检查所有非空子集：
- 单元素：$1, 6, -2, -3$ — 均不为零
- 二元素：$1+6=7,\ 1-2=-1,\ 1-3=-2,\ 6-2=4,\ 6-3=3,\ -2-3=-5$ — 均不为零
- 三元素：$1+6-2=5,\ 1+6-3=4,\ 1-2-3=-4,\ 6-2-3=1$ — 均不为零
- 四元素：$1+6-2-3=2$ — 不为零

**结论**：没有任何子集和为零，方程 **不是分划正则的**。因此存在某个有限 $n$ 使得 $n$-着色可以避免同色解，即 degree of regularity 是有限的。

### 3.2 方程是 3-regular（任何 3-着色都有同色解）

SAT solver（pysat Glucose3）验证：对 $N = 20, 50, 100, 200, 300, 500$，3-着色均 UNSAT。

**含义**：对 $\{1, \dots, N\}$（$N \le 500$）的任何 3-着色，都存在同色解 $(w, x, y, z)$。这强烈支持 $\mathrm{dor}(E) \ge 3$。

### 3.3 方程不是 4-regular（存在 4-着色避免同色解）

SAT solver 验证：对 $N = 500$，4-着色 SAT（存在合法着色）。

**含义**：$\mathrm{dor}(E) \le 3$。结合 3.2，$\mathrm{dor}(E) = 3$，最小着色数 $n = 4$。

### 3.4 关键解族与着色约束

以下解族给出了任何合法着色必须满足的约束：

| 解族 | 代入验证 | 约束 |
|------|----------|------|
| $(2k, k, k, 2k)$ | $2k + 6k = 2k + 6k = 8k$ ✓ | $c(2k) \ne c(k)$ |
| $(3k, k, 3k, k)$ | $3k + 6k = 6k + 3k = 9k$ ✓ | $c(3k) \ne c(k)$ |
| $(5k, 5k, 7k, 7k)$ | $5k + 30k = 14k + 21k = 35k$ ✓ | $c(5m) \ne c(7m)$（其中 $m = k$） |

**推论**：
- $c(2k) \ne c(k)$：乘以 2 必须换色 → $v_2(n)$ 的奇偶性影响颜色
- $c(3k) \ne c(k)$：乘以 3 必须换色 → $v_3(n)$ 的奇偶性影响颜色
- $c(5m) \ne c(7m)$：5 的倍数与 7 的倍数（相同"6-free"部分）必须不同色

这些约束说明：仅用 $v_2(n) \bmod 2$ 和 $v_3(n) \bmod 2$ 可以生成 4 种颜色，但还不够——因为存在所有变量都与 $30 = 2 \cdot 3 \cdot 5$ 互质的解（如 $(17, 1, 1, 7)$：$17 + 6 = 2 + 21 = 23$ ✓），此时 $v_2 = v_3 = v_5 = 0$ 对所有变量相同，p-adic 公式无法区分。
