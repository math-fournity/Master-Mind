## 2. 数据库追溯链

### 2.1 从"AI做不出来"找到所有158道题

**数据库**：ArangoDB（`ARANGO_HOST`/`ARANGO_DB`环境变量，见`.env`）

**Collection**：`devin_problem_runs`

**查询**：

```aql
FOR a IN devin_problem_runs
  FILTER a.status IN ["failed_no_proof", "failed_token_limit", "failed_tool_stall", "answer_leak"]
  RETURN {
    problem_id: a.problem_id,
    status: a.status,
    end_reason: a.end_reason,
    batch_id: a.batch_id,
    exp_id: a.exp_id,
    run_id: a.run_id,
    progress_key: a.progress_key,
    devin_session_id: a.devin_session_id,
    created_at: a.created_at,
    ended_at: a.ended_at,
    runtime_seconds: a.runtime_seconds,
    export_path: a.paths.export_path,
    thinking_capture_path: a.paths.tmux_pipe_path  // thinking_capture.txt在同级目录
  }
```

### 2.2 从一道题找到它的原始题目

**追溯链**：`devin_problem_runs.progress_key` → `problem_extraction_progress._key` → `problem_profiles._key`

**第1步**：从attempt找到题库进度记录

```aql
// attempt中的progress_key指向problem_extraction_progress
LET progress = DOCUMENT(CONCAT("problem_extraction_progress/", a.progress_key))
RETURN progress
```

`problem_extraction_progress`中的关键字段：
- `problem_id`：题目ID（如`compfiles_imo1963p6`）
- `source_dataset`：来源数据集（如`compfiles`）
- `external_ref.local_path`：**原始题目文件的本地路径**（如`knowledge/problem_banks/compfiles/Compfiles/Imo1963P6.lean`）
- `difficulty_tier`：难度层级
- `global_sequence`：全局序号
- `profile_doc_id`：指向`problem_profiles`的文档ID

**第2步**：从进度记录找到题目分析profile

```aql
LET profile = DOCUMENT(a.profile_doc_id)  // 如 problem_profiles/compfiles_imo1963p6
RETURN profile
```

`problem_profiles`中的关键字段：
- `problem_text`：**题目原文**
- `answer`：**标准答案**
- `solution_text`：**完整解答**
- `solution_method_type`：解题方法类型
- `key_insight`：关键洞察
- `tell_hint_pairs`：tell-hint对（用于引导树）
- `bare_ai_expected`：预期AI在无引导时的表现（如`marginal`）
- `bare_ai_error_prediction`：预期AI会犯的错误

### 2.3 从一道题找到它的运行记录

**运行记录有4层**，全部通过`attempt.paths`字段定位：

| 层 | paths字段 | 文件位置 | 内容 |
|---|---|---|---|
| **export** | `export_path` | `/data/math-agent-glm5.2-tmux-agents-trajectory/<exp_id>/exports/conversation.json` | 完整对话记录（ATIF格式），含agent最终输出、metrics |
| **pipe** | `tmux_pipe_path` | `/data/math-agent-glm5.2-tmux-agents-trajectory/<exp_id>/tmux/tmux_pipe.log` | TUI渲染流（raw，含ANSI） |
| **thinking_capture** | `tmux_pipe_path`同级目录 | `/data/math-agent-glm5.2-tmux-agents-trajectory/<exp_id>/tmux/thinking_capture.txt` | Ctrl+O展开后的完整thinking文本 |
| **solver工作目录** | `solver_dir` | `/data/math-agent-glm5.2-tmux-agents-dir/<exp_id>/` | problem.txt（题目文件）、proof.md（如有）、AGENTS.md |

**exp_id格式**：
- 旧格式：`{batch_id}-{ordinal:02d}-p{progress_key}-g{global_sequence:06d}-{problem_id}`
- 新格式（2026-08-12起）：`{batch_id}-{ordinal:02d}-p{progress_key}-r{run_id:07d}-{problem_id}`
- `run_id`是`devin_counters` collection的原子自增全局运行ID

**devin cli session**：
- `devin_session_id`字段（如`clean-toothpaste`）
- session数据在`~/.local/share/devin/cli/sessions.db`（SQLite，`message_nodes`表）
- **注意**：sessions.db只有输入（system/user消息），没有assistant输出和thinking

### 2.4 从一道题找到它的事件历史

**Collection**：`devin_run_events`

```aql
FOR e IN devin_run_events
  FILTER e.attempt_key == a._key  // 或 e.batch_id == a.batch_id
  SORT e.observed_at ASC
  RETURN e
```

事件类型包括：`attempt_launched`、`attempt_running`、`attempt_harness_stopped`、`attempt_solved`、`attempt_network_stuck`等。

## 4. 运行记录查询命令

### 4.1 查所有AI失败的题

```bash
cd ~/master-mind-glm5.2-worktree
set -a; source .env; set +a

# 按status统计
.venv/bin/python -c "
from arango import ArangoClient; import os
from collections import Counter
c = ArangoClient(hosts=os.environ.get('ARANGO_HOST','http://localhost:8529'))
db = c.db(os.environ['ARANGO_DB'], username=os.environ.get('ARANGO_USER','root'), password=os.environ.get('ARANGO_PASS',''))
for s, n in sorted(Counter(a['status'] for a in db.aql.execute('FOR a IN devin_problem_runs FILTER a.status IN [\"failed_no_proof\",\"failed_token_limit\",\"failed_tool_stall\",\"answer_leak\"] RETURN a')).items()):
    print(f'  {s}: {n}')
"
```

### 4.2 查某道题的完整追溯链

```bash
# 替换<PID>为题目ID，如compfiles_imo1963p6
.venv/bin/python -c "
from arango import ArangoClient; import os
c = ArangoClient(hosts=os.environ.get('ARANGO_HOST','http://localhost:8529'))
db = c.db(os.environ['ARANGO_DB'], username=os.environ.get('ARANGO_USER','root'), password=os.environ.get('ARANGO_PASS',''))
for a in db.aql.execute('FOR a IN devin_problem_runs FILTER a.problem_id == @pid RETURN a', bind_vars={'pid': '<PID>'}):
    print(f'status: {a[\"status\"]}')
    print(f'end_reason: {a.get(\"end_reason\")}')
    print(f'batch: {a[\"batch_id\"]}')
    print(f'exp_id: {a[\"exp_id\"]}')
    print(f'export: {a[\"paths\"][\"export_path\"]}')
    print(f'thinking_capture: {a[\"paths\"][\"tmux_pipe_path\"].replace(\"tmux_pipe.log\",\"thinking_capture.txt\")}')
    print(f'progress_key: {a[\"progress_key\"]}')
    # 原始题目
    p = db.collection('problem_extraction_progress').get(a['progress_key'])
    print(f'original_file: {p[\"external_ref\"][\"local_path\"]}')
    prof = db.collection('problem_profiles').get(a['problem_id'])
    print(f'problem_text: {prof[\"problem_text\"][:200]}')
    print(f'answer: {prof.get(\"answer\")}')
"
```

## 6. 关键数据库Collection

| Collection | 用途 | 关键字段 |
|---|---|---|
| `devin_problem_runs` | 每次解题attempt的记录 | `status`, `end_reason`, `exp_id`, `run_id`, `paths`, `progress_key`, `devin_session_id` |
| `devin_batch_runs` | 批次记录 | `batch_id`, `status`, `concurrency`, `created_at` |
| `devin_run_events` | 事件历史 | `event_type`, `attempt_key`, `observed_at` |
| `devin_counters` | 全局自增计数器 | `run_id`（原子自增，确保exp_id唯一） |
| `problem_extraction_progress` | 题库提取进度 | `problem_id`, `source_dataset`, `external_ref.local_path`, `difficulty_tier`, `profile_doc_id` |
| `problem_profiles` | 题目分析profile | `problem_text`, `answer`, `solution_text`, `tell_hint_pairs`, `bare_ai_expected` |

├── <exp_id>/

/data/math-agent-glm5.2-tmux-agents-dir/
└── <exp_id>/
