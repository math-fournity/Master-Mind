## 1. 测试目标

### 1.1 数据管理完备性

**要求**：全部历史任何时候都是可审计的，都是用唯一数字ID索引的。

- 题目有唯一ID（`_key` + `problem_hash`）
- 运行记录有唯一ID（`exp_id` + `attempt_key`）
- 所有export导出、tmux pane导出等物理文件，从目录可以查到数据库（唯一ID作为目录前缀）
- 从数据库可以查到运行记录、题目来源等信息
- **双向追溯**：DB→文件，文件→DB，remainder=0

### 1.2 计算流程管理完备性

**要求**：运行时的数据质量保证和失败分类记录。

- 答案泄漏检查：运行前检查题目数据是否因清洗疏忽导致答案进入AI上下文
- 失败分类记录：AI运行失败的各种情况必须分类记录
- 所有查询脚本化：严格限制inline脚本

## 3. 查询脚本清单

所有脚本放在`xishujuzhen/solver_harness/pipe/`目录中。

### 3.1 audit_trace.py — 双向追溯验证

```bash
# DB→文件：从DB记录的paths字段查文件存在性
python audit_trace.py --db-to-file [--limit N]

# 文件→DB：从物理目录名反查DB记录
python audit_trace.py --file-to-db [--dir <trajectory_base>]

# 题目→运行：从problem查关联的runs
python audit_trace.py --problem-to-runs [--problem-key <key>]

# 运行→题目：从run查关联的problem
python audit_trace.py --run-to-problem [--exp-id <id>]

# 全部检查
python audit_trace.py --all
```

**输出格式**：
```
=== DB→File Trace ===
Total records: 5
Files checked: 23
Expected missing: 2 (proof.md for failed attempts)
Unexpected missing: 0
VERDICT: PASS

=== File→DB Trace ===
Total dirs: 5
DB records found: 5
Orphan dirs (no DB record): 0
VERDICT: PASS
```

### 3.2 check_answer_leak.py — 答案泄漏检查

```bash
# 检查单题
python check_answer_leak.py --problem-key <key>

# 批量检查某tier
python check_answer_leak.py --batch --tier 1 [--limit 1000]

# 检查Redis pending队列中的所有题
python check_answer_leak.py --pending
```

**检查逻辑**：
1. 读取problem_extraction_progress的`problem_text`和`answer`字段
2. 如果`answer`非空且长度>3：检查`problem_text`中是否包含`answer`的值
3. 如果`solution_text`非空：检查`problem_text`中是否包含`solution_text`的前200字符
4. 输出泄漏题列表

### 3.3 query_failures.py — 失败分类统计

```bash
# 汇总
python query_failures.py --summary

# 按verdict分类
python query_failures.py --by-verdict

# 按数据集分类
python query_failures.py --by-dataset

# 查看某类失败的详情
python query_failures.py --verdict failed_connection [--limit 20]

# 导出失败列表
python query_failures.py --export --output failures.json
```

### 3.4 query_progress.py — 运行进度查询

```bash
# 当前状态
python query_progress.py

# 某题目的运行历史
python query_progress.py --problem-key <key>

# 某次运行的详情
python query_progress.py --exp-id <id>

# 某时间段内的运行
python query_progress.py --since "2026-08-12" --until "2026-08-13"
```

### 3.5 verify_completeness.py — 数据完备性验证

```bash
# 检查题目ID完整性
python verify_completeness.py --check-ids

# 检查运行记录ID完整性
python verify_completeness.py --check-attempts

# 检查Redis与DB一致性
python verify_completeness.py --check-redis-sync

# 检查tmux session一致性
python verify_completeness.py --check-tmux

# 全部检查
python verify_completeness.py --all
```
