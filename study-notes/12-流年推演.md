## 12 · 流年推演

流年推演是对特定年份的运势做精细分析。

### 12.1 流年基础

**太岁**：流年的年支
- 太岁是流年的主宰
- 太岁与原盘命宫的关系决定该年基本格调

**流年四柱**：该年的干支组合
- 年柱、月柱、日柱、时柱
- 流年天干 → 化曜（天禄、天暗等）
- 流年地支 → 神煞

**流年神煞**：基于年支推算的神煞
- 太岁、岁破、大耗等年神煞
- 叠加到原盘神煞上

### 12.2 流年-原盘叠加分析

**a. 太岁与命宫关系**
| 关系 | 含义 |
|---|---|
| 合（太岁与命宫三合或六合） | 顺遂、和谐 |
| 冲（太岁与命宫相冲） | 动荡、冲突 |
| 刑（太岁与命宫相刑） | 是非、官非 |
| 破（太岁与命宫相破） | 破损、损失 |
| 害（太岁与命宫相害） | 暗害、阻碍 |
| 值（太岁与命宫同支） | 太岁当头，大变 |

**b. 流年神煞叠加**
- 流年凶煞激活原盘凶煞 → 凶力倍增
- 流年吉煞加强原盘吉煞 → 吉力倍增
- 流年吉煞化解原盘凶煞 → 减凶

**c. 流年化曜与原盘化曜**
- 流年天干产生新的化曜
- 与原盘化曜的关系：叠加、冲突、化解

### 12.3 流年-大限叠加分析

**a. 太岁与当前大限宫位**
- 太岁入大限宫 → 该限主题被激活
- 太岁冲大限宫 → 该限受冲击
- 太岁三合大限宫 → 该限得助

**b. 流年激活大限格局**
- 流年行运星经过大限宫位 → 激活该限的潜在格局
- 流年星与大限宫主的关系 → 影响该限走势

**c. 流年行运星**
- 当年各天体的实际位置
- 行运星经过原盘敏感点（命度、命宫、身宫）→ 触发事件
- 行运星与原盘星曜形成冲合关系 → 引发变化

### 12.4 流年综合判断

综合以上分析，判断该年：
- **吉年**：太岁合命、吉煞多、行运星吉、与大限叠加好
- **凶年**：太岁冲命、凶煞多、行运星凶、与大限叠加差
- **平年**：吉凶参半，需辨主次
