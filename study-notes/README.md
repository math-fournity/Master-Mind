## 1 · 新系统定位

study-notes/ 是一个 **AI 原生的新系统**——重新组织的、有结构的、可被 AI 和经典计算高效遍历使用的知识载体。

《星平会海》、《果老星宗》、《星学大成》等典籍是相对于这个新系统的 **老系统**（参考文献、原料来源），不是产物本身。

## 2 · 新系统结构约束

1. **树状 DAG**：内容按编号组织成树/有向无环图，不是扁平大杂烩
2. **数字编号的步骤**：每个文件是一个"步骤"，有编号顺序
3. **DFS 可遍历**：经典计算和 AI 计算可按编号顺序做全遍历，不漏不重
4. **步骤视角入库**：所有内容（含产物、前置准备）都放在"步骤"视角下入库，带步骤编号
5. **不是大杂烩**：任何时候入库新内容，都要先回答"这属于哪个步骤？步骤编号是什么？"

### Check List 标记规则

```markdown
- [x] `XPATH` → study-notes/NN-步骤名（吸收方式）
- [ ] `XPATH`
- [~] `XPATH` （部分吸收，注释说明）
```

**吸收方式分类**：
- `（全文吸收）`：整条内容被吸收
- `（要点吸收）`：只吸收了要点
- `（引用吸收）`：作为典籍依据引用
- `（归纳吸收）`：被归纳进某个总结表

### XPATH 粒度原则

灵活把握，原则是"一条 XPATH 对应一个可独立吸收的知识单元"：
- 好的粒度：`星曜躔度歌/角/木-天贵`（一条躔度规则）
- 好的粒度：`入门四十四看法/一宫主`（一条看法）
- 太粗：`卷一`（一整卷，无法追踪单条吸收状态）
- 太细：`星曜躔度歌/角/木-天贵/诗句第一句`（比知识单元还小）
