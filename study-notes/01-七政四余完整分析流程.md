## 概述

七政四余是中国古代星占学体系，以实际天体位置为基础，结合中国传统命理框架（十二宫、二十八宿、神煞、化曜等），对个人命运进行系统化推断。"七政"指日月五星七个实际天体，"四余"指罗睺、计都、紫炁、月孛四个虚点。

完整的分析流程从排盘到推限，可以划分为 **十三个步骤**，每一步以前一步的输出为原料：

```
历法 → 星历 → 宫位 → 安命安身 → 四柱八字 → 化曜 → 神煞 → 状态判断 → 格局分析 → 限运系统 → 推限分析 → 流年推演 → 综合判读
```

以下逐步展开。

---

## 第一步：历法基础

排盘的第一步是确定命主的历法环境。

### 1.1 公历转农历

- 输入：命主出生公历年月日时分
- 输出：农历年月日、闰月标记、干支纪年
- 农历年以立春或正月初一为界（七政四余中多以立春为年界，但也有用正月初一的传统，需注意流派差异）
- 干支纪年：60甲子循环，以立春为切换点

### 1.2 二十四节气

- 计算出生时刻附近的24节气精确UT时间
- 节气分两类：
  - **节**（立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒）：用于月柱起算
  - **气**（中气：雨水、春分、谷雨、小满、夏至、大暑、处暑、秋分、霜降、小雪、冬至、大寒）：用于确定月将
- 节气基于太阳在回归黄道上的位置（每15°一个节气），不是恒星黄道

### 1.3 昼夜判定

- 计算出生地的日出日落时间
- 太阳在地平线以上 → 昼生
- 太阳在地平线以下 → 夜生
- 昼夜判定影响后续星曜旺衰判断（昼生人重日、木等阳星；夜生人重月、金等阴星）

### 1.4 月将确定

月将是七政四余安命宫的关键参数，由出生时刻所在的中气决定：

| 中气 | 月将 | 中气 | 月将 |
|---|---|---|---|
| 雨水后 | 亥 | 处暑后 | 巳 |
| 春分后 | 戌 | 秋分后 | 辰 |
| 谷雨后 | 酉 | 霜降后 | 卯 |
| 小满后 | 申 | 小雪后 | 寅 |
| 夏至后 | 未 | 冬至后 | 丑 |
| 大暑后 | 午 | 大寒后 | 子 |

月将本质上是太阳在黄道上的位置映射到地支系统——太阳在哪个中气区间，对应一个月将。

计算出生时刻（UT）十一个天体在恒星黄道上的经度位置：

**七政（七个实际天体）**：
| 天体 | 中文 | 性质 | 周期 |
|---|---|---|---|
| Sun | 日（太阳） | 阳星，主贵、主父、主君 | 1年 |
| Moon | 月（太阴） | 阴星，主母、主慈 | 27.3天（恒星月） |
| Jupiter | 木（木星） | 阳星，主仁、主生长 | 11.86年 |
| Mars | 火（火星） | 阳星，主礼、主躁烈 | 1.88年 |
| Saturn | 土（土星） | 阳星，主信、主厚重 | 29.46年 |
| Venus | 金（金星） | 阴星，主义、主刚锐 | 0.62年（会合周期584天） |
| Mercury | 水（水星） | 阴星，主智、主流动 | 0.24年 |

**四余（四个虚点）**：
| 虚点 | 中文 | 性质 | 定义 |
|---|---|---|---|
| Rahu | 罗睺 | 火之余，主燥、主横暴 | 月球升交点（北交点） |
| Ketu | 计都 | 土之余，主暗、主阻滞 | 月球降交点（南交点） |

注意：四余的定义在不同流派中有争议。罗睺计都有"新旧法"之分（升交点vs降交点的归属），紫炁有"自定义轨道vs平均远日点"之分。这些争议需要在实际分析中注意。

### 2.2 二十八宿宿度

将每个天体的黄经位置映射到二十八宿系统：

**东方青龙七宿**：角、亢、氐、房、心、尾、箕
**北方玄武七宿**：斗、牛、女、虚、危、室、壁
**西方白虎七宿**：奎、娄、胃、昴、毕、觜、参
**南方朱雀七宿**：井、鬼、柳、星、张、翼、轸

每宿有固定的黄道宿度（宽度不等），各宿有五行属性和禽名（如角木蛟、亢金龙等）。天体躔宿是格局判断的重要依据——"木躔角宿号天贵"就是躔度歌的典型格式。

### 2.3 逆顺迟疾

判断每个天体的运行状态：
- **顺**：正常运行方向（黄经增加）
- **逆**：逆行（黄经减少，外行星在特定时段逆行）
- **留**：顺逆转换时的停滞（速度接近零）
- **疾**：运行速度快
- **迟**：运行速度慢

逆顺迟疾影响星曜力量——顺行且疾则力强，逆行且迟则力弱。日月不计逆顺（太阳永远顺行，月亮逆顺周期短）。

### 2.4 升落时间

计算各天体的升落时间，用于判断星曜在地平线上下：
- 升起中的星曜力量更强
- 落入地平线下的星曜力量减弱

## 第三步：宫位系统

### 3.1 十二宫

七政四余使用十二宫制，每宫对应一个地支，按逆时针排列：

| 宫序 | 宫名 | 地支 | 主宰 |
|---|---|---|---|
| 1 | 命宫 | varies | 本人、性格、形体 |
| 2 | 财帛宫 | | 财富、收入 |
| 3 | 兄弟宫 | | 兄弟姐妹、邻里 |
| 4 | 田宅宫 | | 房产、家庭、父亲 |
| 5 | 男女宫 | | 子女、生育 |
| 6 | 奴仆宫 | | 下属、仆人、工作环境 |
| 7 | 妻妾宫 | | 婚姻、配偶、合作 |
| 8 | 疾厄宫 | | 疾病、灾厄 |
| 9 | 迁移宫 | | 出行、迁徙、旅行 |
| 10 | 官禄宫 | | 事业、官位、地位 |
| 11 | 福德宫 | | 福气、德行、精神 |
| 12 | 相貌宫 | | 相貌、隐秘、损失 |

十二宫从命宫起，按地支顺序逆时针排列。命宫所在的地支决定了整个宫位系统的起点。

### 3.2 宫位制

七政四余通常使用**整宫制**（Whole Sign Houses）：
- 每个地支对应一个完整的宫位
- 宫头就是该地支的起始度数
- 不像西方占星那样用不等的宫位划分

但也有使用**度数宫位制**的流派，以命度为起点划分12等分。

### 3.3 ASC和MC

- **ASC（上升点/命度）**：出生时刻东方地平线与黄道的交点
- **MC（中天/天顶）**：出生时刻子午线与黄道的交点（最高点）

命度（ASC的精确黄经度数）在七政四余中非常重要——它决定了"度主"（命度所在宿的五行主星）。

### 3.4 三方四正

- **三方**：地支三合关系
  - 申子辰（水局）
  - 寅午戌（火局）
  - 巳酉丑（金局）
  - 亥卯未（木局）
- **四正**：对宫关系（相隔180°）
  - 子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲

三方四正是判断星曜关系和宫位互动的基础——一颗星在三方四正位置上对命宫的影响，与直接在命宫中的影响不同但同样重要。

## 第四步：安命安身

安命安身是七政四余排盘的核心步骤，决定了整个星盘的框架。

### 4.1 安命宫

命宫是整个星盘的起点，决定了十二宫的排列。

**计算方法**：
1. 确定月将（由出生时刻所在的中气决定，见第一步）
2. 确定生时（出生时辰对应的地支）
3. 将月将放在生时位置上，顺数到卯位
4. 卯位上的地支即为命宫

**公式**：命宫 = (卯 + 月将 - 生时) mod 12

其中地支编号：子=0, 丑=1, 寅=2, 卯=3, ..., 亥=11

**示例**：
- 月将 = 亥（11），生时 = 子（0）
- 命宫 = (3 + 11 - 0) mod 12 = 14 mod 12 = 2 = 寅

**本质**：命宫的本质是出生时刻太阳所在的位置（由月将反映）与出生时辰的组合映射。月将代表太阳位置，生时代表地球自转位置，两者组合确定了命宫——这反映了"太阳-地球-出生时刻"的空间关系。

### 4.2 安身宫

身宫代表命主的身体、物质层面。

**计算方法**：
- 以月将加生时，逆数到酉（与命宫顺数到卯对称，但方向相反）
- 或者：身宫 = (酉 - 月将 + 生时) mod 12 = (9 - 月将 + 生时) mod 12

也有流派认为身宫直接由月亮所在的地支决定。

**命身关系**：
- 命宫主一生总体格局、性格、精神层面
- 身宫主身体、物质实现、行动层面
- 命身同宫：精神和物质一致，力量集中
- 命身对照（相隔6宫）：精神与物质张力大，需平衡

### 4.3 命主星与度主星

**命主星（宫主）**：命宫所在地的五行主星
| 地支 | 五行 | 命主星 |
|---|---|---|
| 寅、卯 | 木 | 木星 |
| 巳、午 | 火 | 火星 |
| 申、酉 | 金 | 金星 |
| 亥、子 | 水 | 水星 |
| 辰、戌、丑、未 | 土 | 土星 |

**度主星（度主）**：命度（ASC精确黄经）所在二十八宿的五行主星
| 宿 | 五行 | 度主星 |
|---|---|---|
| 角木蛟、斗木獬、奎木狼、井木犴 | 木 | 木星 |
| 亢金龙、牛金牛、娄金狗、鬼金羊 | 金 | 金星 |
| 氐土貉、女土蝠、胃土雉、柳土獐 | 土 | 土星 |
| 房日兔、虚日鼠、昴日鸡、星日马 | 日 | 太阳 |
| 心月狐、危月燕、毕月乌、张月鹿 | 月 | 太阴 |
| 尾火虎、室火猪、觜火猴、翼火蛇 | 火 | 火星 |
| 箕水豹、壁水㺄、参水猿、轸水蚓 | 水 | 水星 |

**身主星**：身宫所在地的五行主星（计算方法同命主星）

命主星和度主星是整个星盘的"两个主"——命主管宫位层面，度主管度数层面。两者的强弱、位置、关系是综合判读的核心。

## 第五步：四柱八字

七政四余虽然以星曜为主，但也结合八字系统作为辅助。

### 5.1 四柱起算

| 柱 | 起算方法 | 说明 |
|---|---|---|
| 年柱 | 以立春为年界，干支纪年 | 立春前出生用上一年干支 |
| 月柱 | 以节（非中气）为月界 | 立春→寅月，惊蛰→卯月，... |
| 日柱 | 当日干支，以子时为日界 | 23时后属次日子时（早子时） |
| 时柱 | 出生时辰对应干支 | 每2小时一个时辰 |

注意：七政四余中月柱的起算有两种传统：
- **节气分年月**（果老星宗/传统八字）：以节为月界
- **农历分年月**（琴堂派）：以农历月为月界

### 5.2 八字扩展数据

- **日主**：日柱天干，代表命主自身
- **十神**：以日主为基准，其他干支与日主的生克关系（比肩、劫财、食神、伤官、偏财、正财、七杀、正官、偏印、正印）
- **藏干**：地支中隐藏的天干
- **纳音**：60甲子纳音五行
- **长生十二运**：日主五行在各支的十二状态
- **季节旺衰**：日主在出生季节的旺衰

以年干为基准，推演出九个化曜星，分别落在不同地支位置：

| 化曜 | 含义 |
|---|---|
| 天禄 | 禄位，主食禄、俸禄 |
| 天暗 | 暗昧，主遮蔽、阻碍 |
| 天福 | 福德，主福气、顺遂 |
| 天寿 | 寿命，主长寿、健康 |
| 天贵 | 贵人，主贵气、地位 |
| 天刑 | 刑罚，主官非、刑伤 |
| 天印 | 印信，主权印、文书 |
| 天囚 | 囚禁，主困顿、束缚 |
| 天权 | 权力，主权威、掌控 |

每个天干对应一套化曜的地支分布，例如（以甲为例，其他天干有各自的对应表）：
- 甲：天禄在寅，天暗在卯，天福在辰，天寿在巳，天贵在午，天刑在未，天印在申，天囚在酉，天权在戌

### 6.2 天干星曜与地支神煞

- **地支神煞**：年支×地支 → 38神曜

这些将在第七步神煞中详述。

## 第七步：神煞

神煞是中国命理系统中特有的"虚拟星曜"系统，不是实际天体，而是由干支关系推演出的标记点。

### 7.1 神煞类别

**天干神煞**（以天干推算）：
- 天乙贵人、文昌、文曲、天厨等

**地支神煞**（以地支推算）：
- 驿马、桃花、华盖、劫煞、亡神、灾煞、天罗地网等

**年支神煞**（以年支为基准）：
- 太岁、岁破、大耗、小耗、官符、白虎、丧门、吊客等

### 7.2 重要神煞

| 神煞 | 含义 | 推算方法 |
|---|---|---|
| 天乙贵人 | 最大贵人星 | 以日干推算 |
| 文昌 | 学业、文才 | 以日干推算 |
| 驿马 | 出行、变动 | 以年支三合冲位推算 |
| 桃花 | 感情、人缘 | 以年支三合局推算（子午卯酉） |
| 华盖 | 孤高、宗教、艺术 | 以年支三合局末位推算 |
| 劫煞 | 劫财、意外 | 以年支三合局绝位推算 |
| 亡神 | 暗算、损失 | 以年支三合局寅位推算 |

### 7.3 神煞在星盘中的作用

- 吉煞入命宫或三方四正 → 增加命格吉利
- 凶煞入命宫或三方四正 → 减损命格
- 吉凶交见 → 辨主次，看力量对比
- 神煞与实际星曜叠加 → 效果叠加或抵消

神煞不是独立判断的，而是与星曜、宫位、格局综合考量。

## 第八步：状态判断

### 8.1 庙旺平陷

每个天体在每个地支位置有不同的力量状态，从强到弱：

| 状态 | 含义 | 力量 |
|---|---|---|
| 殿 | 星曜入本殿（最高尊严） | 最强 |
| 垣 | 星曜入本垣 | 极强 |
| 庙 | 星曜入庙 | 强 |
| 旺 | 星曜入旺 | 较强 |
| 乐 | 星曜乐居 | 中等偏上 |
| 喜 | 星曜喜居 | 中等 |
| 怒 | 星曜怒居（受克） | 弱 |

庙旺平陷表是七政四余的核心数据之一——11个天体×12地支 = 132个状态。星曜在庙旺则力量充分发挥，在平陷则力量受制。

### 8.2 长生十二运

以五行属性为基准，判断每个天体在各地支的"生命阶段"：

| 阶段 | 含义 |
|---|---|
| 长生 | 出生，力量初生 |
| 沐浴 | 沐浴，力量脆弱 |
| 冠带 | 成人，力量渐增 |
| 临官 | 入仕，力量强盛 |
| 帝旺 | 鼎盛，力量最强 |
| 衰 | 衰退，力量开始下降 |
| 病 | 病态，力量减弱 |
| 死 | 死亡，力量极弱 |
| 墓 | 入墓，力量封藏 |
| 绝 | 绝灭，力量消失 |
| 胎 | 受胎，力量孕育 |
| 养 | 养育，力量恢复 |

不同五行的长生起点不同：
- 木长生在亥，顺行
- 火长生在寅，顺行
- 金长生在巳，顺行
- 水长生在申，顺行
- 土长生在寅（与火同），顺行

### 8.3 纳音五行

60甲子纳音系统，每个干支组合对应一个纳音五行：
- 例如：甲子乙丑 → 海中金
- 纳音五行用于补充判断干支的五行属性
- 在七政四余中，纳音主要用于年柱和日柱的五行判断

### 8.4 五行生克与恩用仇难

以命主星的五行为基准，建立五行关系体系：

| 关系 | 定义 | 含义 |
|---|---|---|
| 恩 | 生我者 | 帮助、滋养 |
| 用 | 我生者 | 消耗、付出 |
| 仇 | 克我者 | 压制、阻碍 |
| 难 | 我克者 | 控制、获得 |

例如，命主为木：
- 恩 = 水（水生木）
- 用 = 火（木生火）
- 仇 = 金（金克木）
- 难 = 土（木克土）

恩星入命宫或三方四正 → 大吉；仇星入命 → 凶。这是判断星曜吉凶的基本框架——同一颗星对不同命主的意义不同，取决于它和命主的五行关系。

## 第九步：格局分析

格局是七政四余判断命格高低的核心。格局由星曜之间的特定组合关系构成。

### 9.1 格局的构成要素

**躔（Mansion Placement）**：星曜在二十八宿中的位置
- "木躔角宿号天贵"——木星在角宿构成"天贵"格局
- 28宿 × 11星 = 308种组合（躔度歌体系）

**照（Aspect to House）**：星曜对宫位的照射
- 一颗星从其所在位置照射对宫或三方宫位
- "照宫歌"体系：12宫 × 11星 = 132种组合中有96条有文本

**会（Conjunction）**：两颗星曜会合
- 两颗星在同一宫或同一宿
- "交会歌"体系：59条组合规则

**守（House Placement）**：星曜守在某个宫位
- 星曜直接落入某宫
- "守宫歌"体系：3条宫主入命规则

**冲（Opposition）**：星曜在对宫
- 两颗星相隔180°

**合（Trine）**：星曜在三方
- 两颗星相隔120°

**拱/夹/刑/穿/害**：其他位置关系
- 拱：特定角度关系
- 夹：两星夹住一宫或一星
- 刑：相刑关系
- 穿：穿宫关系
- 害：相害关系

### 9.2 吉格与忌格

**吉格（喜格）**：星曜组合带来吉利的格局
- 日月并明：日月同旺
- 木火通明：木火相生且旺
- 金白水清：金水相生且清
- 众星拱北：众星朝向北极（太阳）
- 五星环阳：五星环绕太阳
- 七政连环：七政顺行连珠

**忌格**：星曜组合带来凶险的格局
- 日月交蚀：日月被罗计遮挡
- 罗计犯阳：罗睺犯太阳
- 火土相克：火星土星相克
- 孛罗交战：月孛罗睺交战

### 9.3 格局判断原则

1. **格局完整度**：格局是否被破格星冲破
   - 吉格被凶星冲照 → 减分甚至破格
   - 忌格被吉星化解 → 减轻凶险

2. **格局优先级**：不同格局有不同权重
   - 涉及日月 > 涉及五星 > 涉及四余
   - 涉及命主/度主 > 涉及其他星

3. **格局叠加**：多个格局同时出现
   - 多个吉格叠加 → 加倍吉利
   - 吉格与忌格同时出现 → 辨主次，看力量对比

4. **互斥规则**：某些格局互斥，不能同时成立
   - 规则库中有 `exclude` 字段标记互斥关系

5. **星曜状态影响格局**：
   - 格局中的星曜庙旺 → 格局力量强
   - 格局中的星曜平陷 → 格局力量弱
   - 格局中的星曜逆行 → 格局不稳定

### 9.4 命格等级

综合所有格局，可以判断命格等级：
- **高命格**：多个吉格叠加，星曜庙旺，无破格
- **中命格**：有吉格但有瑕疵，或吉凶参半
- **低命格**：忌格多，星曜平陷，或吉格被破

## 第十步：限运系统

限运系统是七政四余推运的核心——它将人的一生划分为不同的运势阶段。

### 10.1 童限

童限是从出生到正式进入大限之间的过渡期。

**计算方法**：
- 基于命宫的度数位置和出生时间
- 本质：计算从出生时刻到命宫度数走完所需的时间
- 童限年数 = 命宫剩余度数 / 每年度数移动量

童限结束后，正式进入洞微大限。

### 10.2 洞微大限

洞微大限是七政四余最核心的推运系统，将人的一生划分为12个限，每限对应一个地支/宫位。

**基本结构**：
- 12限对应12地支
- 从命宫起，按地支顺序排列（逆时针，即按命宫→相貌→福德→官禄→...的顺序）
- 每限有一定的年数

**限年数**：
每限的年数由该限所在地的五行决定，基于河图成数：

| 五行 | 地支 | 限年数 | 河图成数 |
|---|---|---|---|
| 水 | 亥、子 | 6年 | 天一生水，地六成之 |
| 火 | 巳、午 | 7年 | 地二生火，天七成之 |
| 木 | 寅、卯 | 8年 | 天三生木，地八成之 |
| 金 | 申、酉 | 9年 | 地四生金，天九成之 |
| 土 | 辰、戌、丑、未 | 5年 | 天五生土，地十成之（用5） |

12限年数总和 = 6+6+7+7+8+8+9+9+5+5+5+5 = 80年（理论值，实际因命宫位置不同而排列不同）

**大限的运行方向**：
- 从命宫起，逆时针运行（与十二宫排列方向一致）
- 命宫 → 相貌宫 → 福德宫 → 官禄宫 → 迁移宫 → 疾厄宫 → 妻妾宫 → 奴仆宫 → 男女宫 → 田宅宫 → 兄弟宫 → 财帛宫

也有流派认为大限从命宫起顺时针运行，需注意流派差异。

### 10.3 小限

小限是年度级别的推运系统：
- 每年对应一个地支
- 从命宫起，按特定方向逐年推进
- 小限所在宫位的星曜配置影响该年运势

### 10.4 飞限

飞限是另一种推运系统，运行速度不同于大限：
- 可能是半年一切换或更快的周期
- 具体规则因流派而异

### 10.5 月限

月限是月度级别的推运：
- 每月对应一个地支
- 用于精细化的月度运势分析

## 第十一步：推限分析

推限分析是在限运系统的基础上，对每个限的吉凶进行系统化判断。

### 11.1 逐限分析

对12限中的每一限，分析以下要素：

**a. 限宫位**
- 该限落在哪个宫位？（限起始黄经 → 地支 → 十二宫）
- 宫位的含义决定该限的主题（如限入官禄宫→该限主题是事业）

**b. 限宫主**
- 该限宫位的宫主是谁？（按地支五行确定）
- 宫主在原盘中的位置：入命？入三方四正？落陷？
- 宫主的庙旺平陷状态
- 宫主与命主的关系（恩用仇难）

**c. 限内星曜**
- 原盘哪些星曜落入该限宫位？（行星黄经 vs 限黄经范围）
- 这些星曜的庙旺平陷
- 这些星曜与限宫主的关系

**d. 限内神煞**
- 该限宫位有哪些神煞？
- 吉煞多 → 该限顺遂
- 凶煞多 → 该限多阻碍

**e. 限内格局**
- 该限触发了哪些格局？（对限宫位重新求值规则）
- 限内星曜组合是否构成新的格局
- 原有格局在该限是否被激活或冲破

**f. 综合判断**
- 综合以上要素，判断该限总体吉凶
- 吉限：宫主旺、吉星入、吉煞多、格局成
- 凶限：宫主陷、凶星入、凶煞多、格局破

### 11.2 当前限深入分析

对命主当前所在的大限做更深入的分析：

**a. 当前限位置**
- 当前在12限中的第几限
- 限内年龄（已过几年/还剩几年）
- 限内度数（限黄经进度）

**b. 限内行运星**
- 当前有哪些行运星（transit）经过该限宫位
- 行运星与原盘星曜的交互

**c. 小限/飞限叠加**
- 当前年的小限在哪个宫
- 当前飞限在哪个宫
- 多重限运叠加的综合影响

### 11.3 限内逐年推演

对当前限内的每一年做逐年分析：
- 调用流年推演（见第十二步）
- 判断该年与当前限的叠加关系
- 识别限内的高峰年和低谷年

### 11.4 大限交接期分析

- 限与限交接的前后2-3年通常是运势转折点
- 交接期特征：
  - 前一限的余势渐弱
  - 后一限的新势渐起
  - 两个限的宫主和星曜交互
- 交接期往往是人生重大变化的时段

## 第十二步：流年推演

流年推演是对特定年份的运势做精细分析。

### 12.1 流年基础

**太岁**：流年的年支
- 太岁是流年的主宰
- 太岁与原盘命宫的关系决定该年基本格调

**流年四柱**：该年的干支组合
- 年柱、月柱、日柱、时柱
- 流年天干 → 化曜（天禄、天暗等）
- 流年地支 → 神煞

**流年神煞**：基于年支推算的神煞
- 太岁、岁破、大耗等年神煞
- 叠加到原盘神煞上

### 12.2 流年-原盘叠加分析

**a. 太岁与命宫关系**
| 关系 | 含义 |
|---|---|
| 合（太岁与命宫三合或六合） | 顺遂、和谐 |
| 冲（太岁与命宫相冲） | 动荡、冲突 |
| 刑（太岁与命宫相刑） | 是非、官非 |
| 破（太岁与命宫相破） | 破损、损失 |
| 害（太岁与命宫相害） | 暗害、阻碍 |
| 值（太岁与命宫同支） | 太岁当头，大变 |

**b. 流年神煞叠加**
- 流年凶煞激活原盘凶煞 → 凶力倍增
- 流年吉煞加强原盘吉煞 → 吉力倍增
- 流年吉煞化解原盘凶煞 → 减凶

**c. 流年化曜与原盘化曜**
- 流年天干产生新的化曜
- 与原盘化曜的关系：叠加、冲突、化解

### 12.3 流年-大限叠加分析

**a. 太岁与当前大限宫位**
- 太岁入大限宫 → 该限主题被激活
- 太岁冲大限宫 → 该限受冲击
- 太岁三合大限宫 → 该限得助

**b. 流年激活大限格局**
- 流年行运星经过大限宫位 → 激活该限的潜在格局
- 流年星与大限宫主的关系 → 影响该限走势

**c. 流年行运星**
- 当年各天体的实际位置
- 行运星经过原盘敏感点（命度、命宫、身宫）→ 触发事件
- 行运星与原盘星曜形成冲合关系 → 引发变化

### 12.4 流年综合判断

综合以上分析，判断该年：
- **吉年**：太岁合命、吉煞多、行运星吉、与大限叠加好
- **凶年**：太岁冲命、凶煞多、行运星凶、与大限叠加差
- **平年**：吉凶参半，需辨主次

## 第十三步：综合判读

综合判读是七政四余推命的最后一步，也是 AI 智能的核心战场——所有前面的步骤都是提供原料，综合判读是把这些原料整合为完整的命理判断。

### 13.1 判读原则清单

**a. 身命二主强弱**
- 命主星（宫主）的庙旺平陷
- 度主星的庙旺平陷
- 身主星的庙旺平陷
- 三者是否入命宫或三方四正
- 三者之间的五行生克关系
- 身命二主强 → 命格根基稳固；弱 → 根基不稳

**b. 四正宫吉凶**
- 命宫：本人总体
- 田宅宫（4宫）：家庭、房产
- 妻妾宫（7宫）：婚姻、配偶
- 官禄宫（10宫）：事业、地位
- 四正宫的星曜配置决定人生四大领域的基本格局
- 四正宫有吉星守照 → 该领域顺遂
- 四正宫有凶星冲破 → 该领域多阻碍

**c. 五行生克平衡**
- 恩用仇难四类星曜的力量对比
- 恩星多且旺 → 一生多得助力
- 仇星多且旺 → 一生多受压制
- 五行流通有情 → 命格通达
- 五行阻塞不通 → 命格郁滞

**d. 神煞叠加**
- 吉煞总数 vs 凶煞总数
- 吉煞入命宫/三方四正 → 加分
- 凶煞入命宫/三方四正 → 减分
- 吉凶交见 → 辨主次，看力量对比

**e. 格局成破**
- 匹配的吉格数量和质量
- 匹配的忌格数量和质量
- 吉格是否完整（有无破格因素）
- 忌格是否被化解
- 格局优先级（日月格 > 五星格 > 四余格）

**f. 大限吉凶**
- 当前限宫主强弱
- 限内星曜配置
- 限内格局触发
- 限运走势（从当前限到未来几限的吉凶趋势）

**g. 流年吉凶**
- 太岁与命宫关系
- 流年神煞叠加
- 流年与大限叠加
- 流年行运星触发

### 13.2 判读输出

综合以上七个维度，产出命理判断：

| 领域 | 判读内容 |
|---|---|
| 性格 | 命主性格特征、气质、倾向 |
| 六亲 | 父母、兄弟、配偶、子女的关系和状况 |
| 事业 | 适合的行业、事业发展轨迹、官禄 |
| 财运 | 财富格局、财运高峰、财源 |
| 健康 | 体质、疾厄、注意事项 |
| 婚姻 | 婚姻格局、配偶特征、婚姻走势 |
| 大运 | 一生12限的吉凶走势、转折点 |
| 流年 | 近年运势提示、关键年份 |

### 13.3 判读的注意事项

1. **不绝对化**：星象是条件不是宿命，"能量再大也怕结扎"——社会环境、个人选择都会改变兑现路径
2. **辨主次**：吉凶交见时，必须辨别哪个是主要矛盾，不能等量齐观
3. **看动态**：命盘是静态的，但限运和流年是动态的——同一命盘在不同限运阶段表现不同
4. **重原盘**：原盘是根基，限运和流年是枝叶——原盘格局决定上限，限运决定何时兑现
5. **结合时代**：同样的星盘配置在不同时代有不同的兑现方式（如"3子"在计划生育前后含义不同）
