## 13 · 综合判读

综合判读是七政四余推命的最后一步，也是 AI 智能的核心战场——所有前面的步骤都是提供原料，综合判读是把这些原料整合为完整的命理判断。

### 13.1 判读原则清单

**a. 身命二主强弱**
- 命主星（宫主）的庙旺平陷
- 度主星的庙旺平陷
- 身主星的庙旺平陷
- 三者是否入命宫或三方四正
- 三者之间的五行生克关系
- 身命二主强 → 命格根基稳固；弱 → 根基不稳

**b. 四正宫吉凶**
- 命宫：本人总体
- 田宅宫（4宫）：家庭、房产
- 妻妾宫（7宫）：婚姻、配偶
- 官禄宫（10宫）：事业、地位
- 四正宫的星曜配置决定人生四大领域的基本格局
- 四正宫有吉星守照 → 该领域顺遂
- 四正宫有凶星冲破 → 该领域多阻碍

**c. 五行生克平衡**
- 恩用仇难四类星曜的力量对比
- 恩星多且旺 → 一生多得助力
- 仇星多且旺 → 一生多受压制
- 五行流通有情 → 命格通达
- 五行阻塞不通 → 命格郁滞

**d. 神煞叠加**
- 吉煞总数 vs 凶煞总数
- 吉煞入命宫/三方四正 → 加分
- 凶煞入命宫/三方四正 → 减分
- 吉凶交见 → 辨主次，看力量对比

**e. 格局成破**
- 匹配的吉格数量和质量
- 匹配的忌格数量和质量
- 吉格是否完整（有无破格因素）
- 忌格是否被化解
- 格局优先级（日月格 > 五星格 > 四余格）

**f. 大限吉凶**
- 当前限宫主强弱
- 限内星曜配置
- 限内格局触发
- 限运走势（从当前限到未来几限的吉凶趋势）

**g. 流年吉凶**
- 太岁与命宫关系
- 流年神煞叠加
- 流年与大限叠加
- 流年行运星触发

### 13.2 判读输出

综合以上七个维度，产出命理判断：

| 领域 | 判读内容 |
|---|---|
| 性格 | 命主性格特征、气质、倾向 |
| 六亲 | 父母、兄弟、配偶、子女的关系和状况 |
| 事业 | 适合的行业、事业发展轨迹、官禄 |
| 财运 | 财富格局、财运高峰、财源 |
| 健康 | 体质、疾厄、注意事项 |
| 婚姻 | 婚姻格局、配偶特征、婚姻走势 |
| 大运 | 一生12限的吉凶走势、转折点 |
| 流年 | 近年运势提示、关键年份 |

### 13.3 判读的注意事项

1. **不绝对化**：星象是条件不是宿命，"能量再大也怕结扎"——社会环境、个人选择都会改变兑现路径
2. **辨主次**：吉凶交见时，必须辨别哪个是主要矛盾，不能等量齐观
3. **看动态**：命盘是静态的，但限运和流年是动态的——同一命盘在不同限运阶段表现不同
4. **重原盘**：原盘是根基，限运和流年是枝叶——原盘格局决定上限，限运决定何时兑现
5. **结合时代**：同样的星盘配置在不同时代有不同的兑现方式（如"3子"在计划生育前后含义不同）
