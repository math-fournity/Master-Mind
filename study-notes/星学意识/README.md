# 星学意识

## 什么是星学意识

星学意识是七政四余推命中**弥漫性的基础知识**——它们不是某个步骤的专属内容，而是贯穿整个推命过程的底层思维模式。

### 三个特征

1. **知识性的**：有明确的知识内容（五行生克关系、庙旺平陷表、恩用仇难定义等）
2. **意识性的**：是分析时要时刻装在头脑里的思维方式，不是查表就完事的
3. **弥漫性的**：贯穿多个甚至全部推命步骤，不是某个步骤的专属

### 与步骤文档的关系

- 步骤文档（`study-notes/01~13`）描述"怎么做"
- 星学意识描述"用什么思维做"
- 步骤文档中会引用星学意识，但不重复其内容

## 使用方式

1. **AI 推命时**：在按步骤文档执行的同时，随时参考星学意识文档，确保底层思维模式正确
2. **学习时**：先掌握星学意识，再学步骤文档
3. **判读时**：每个判断都要检查是否符合星学意识中的基本原则

## 如何识别意识性内容（吸收典籍时使用）

吸收《星平会海》《星学大成》等典籍时，遇到一段内容，用以下标准判断它是否属于星学意识：

### 三条判断标准

1. **知识性**：有明确的知识内容（不是纯方法论或纯步骤描述）
   - ✅ 是：五行生克关系表、恩用仇难定义、庙旺平陷判定标准
   - ❌ 否："先排盘再安命"（这是步骤，不是知识）

2. **意识性**：是分析时要时刻装在头脑里的思维方式（不是查一次表就完事的）
   - ✅ 是：五行生克——每次看星曜都要想它的五行和与命主的关系
   - ❌ 否：28宿度数表（查一次就够了，不需要"时刻装在头脑里"）

3. **弥漫性**：贯穿多个甚至全部推命步骤（不是某个步骤的专属）
   - ✅ 是：阴阳昼夜——排盘、庙旺、格局、限运、流年都要用
   - ❌ 否：安命安身的具体算法（只在排盘步骤用）

### 判断结果

- **三条都满足** → 放入 `study-notes/星学意识/`
- **只满足知识性+弥漫性，不满足意识性** → 可能是常量性内容，放入 `qizheng/constants.json`
- **只满足知识性+意识性，不满足弥漫性** → 可能是步骤性内容，放入对应步骤文档
- **三条都不满足** → 可能是纯步骤描述或原文，放入对应位置

### 吸收时的操作流程

1. 阅读典籍段落
2. 用三条标准判断内容性质
3. 如果是意识性内容：
   a. 检查 `study-notes/星学意识/` 中是否已有对应意识文档
   b. 如果有 → 补充到现有文档
   c. 如果没有 → 新建意识文档，更新本 README 的意识清单
4. 如果不是意识性内容 → 按其他分类原则处理
5. 在吸收 Check List 中记录去向

> **强制检查点**：每次吸收一批典籍内容后，必须问"本次吸收的内容中是否有意识性内容？如果有，是否已提取到 `study-notes/星学意识/`？"（见 AGENTS.md "典籍吸收分类原则"小节）
