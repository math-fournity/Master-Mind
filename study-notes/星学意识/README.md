# 星学意识

## 什么是星学意识

星学意识是七政四余推命中**弥漫性的基础知识**——它们不是某个步骤的专属内容，而是贯穿整个推命过程的底层思维模式。

### 三个特征

1. **知识性的**：有明确的知识内容（五行生克关系、庙旺平陷表、恩用仇难定义等）
2. **意识性的**：是分析时要时刻装在头脑里的思维方式，不是查表就完事的
3. **弥漫性的**：贯穿多个甚至全部推命步骤，不是某个步骤的专属

### 与步骤文档的关系

- 步骤文档（`study-notes/01~13`）描述"怎么做"
- 星学意识描述"用什么思维做"
- 步骤文档中会引用星学意识，但不重复其内容

## 使用方式

1. **AI 推命时**：在按步骤文档执行的同时，随时参考星学意识文档，确保底层思维模式正确
2. **学习时**：先掌握星学意识，再学步骤文档
3. **判读时**：每个判断都要检查是否符合星学意识中的基本原则
