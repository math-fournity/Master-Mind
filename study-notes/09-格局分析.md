## 09 · 格局分析

格局是七政四余判断命格高低的核心。格局由星曜之间的特定组合关系构成。[内知]

星平会海卷一以六篇歌诀构建了完整的格局体系，按"星曜位置关系"分为六类：[文献:星平会海/卷一]

| 格局类型 | 典籍篇目 | 关系定义 | 组合数量 |
|---|---|---|---|
| 躔度 | 星曜缠度歌 | 星曜在二十八宿中的位置 | 28宿×11星=308条 |
| 交会 | 星曜郊会歌 | 两颗星曜同宫会合 | 11星各自与其他星的交会 |
| 照宫 | 星曜照宫歌 | 星曜照射某个宫位 | 12宫×11星 |
| 守宫 | 主星守宫歌 | 宫主星入命宫 | 7组宫主入命规则 |
| 吊冲 | 吊冲秘诀 | 三方吊、对宫冲的飞星关系 | 12宫各宫规则 |
| 变局 | 五星变局 | 宫位五行因三合局而变 | 12宫各宫变局规则 |

### 9.1 躔度格局（星曜缠度歌）

> 出处：[文献:星平会海/卷一/星曜缠度歌]

**定义**：躔度格局是星曜在二十八宿中的位置组合。每宿有11星（日/月/木/火/土/金/水/气/孛/罗/计）各自的歌诀，描述该星在该宿时的命格含义。[文献:星平会海/卷一/星曜缠度歌]

**结构**：28宿 × 11星 = 308条组合。每宿先列11星歌诀，后附该宿的五行升殿注释。[文献:星平会海/卷一/星曜缠度歌/角度星曜]

| 星曜 | 格局名 | 歌诀要点 |
|---|---|---|
| 木躔角 | 天贵 | 诗礼传家居职位，艺术近公卿，财禄丰盈 |
| 火躔角 | 天娼 | 衣食随时不善良，害子克妻婚难合 |
| 土躔角 | 天寿 | 盖世文章冠魁首，经纶事业富胸襟 |
| 金躔角 | 天清 | 年少登科擅大名，为官清贵佐朝廷 |

| 月躔角 | 天贵 | 学问渊源须大智，夜里生人最为利 |
| 气躔角 | 天休 | 机智清闲艺术优，僧道逢人多吉庆 |

**宿度注释**：每宿歌诀后附五行升殿注释，说明该宿的五行属性、宿度宽度、升殿关系。如角宿注释："木缠角道主贵，角十至十二度。凶巳前不妨。有资培之功。木受金制。水能生之。先贫后贵。"[文献:星平会海/卷一/星曜缠度歌/角度星曜]

**升殿规则**：当星曜的五行与宿的五行一致时，称为"升殿"，力量最强。如"木星升殿"（木星在木宿：角/斗/奎/井）、"太阳升殿"（太阳在日宿：房/虚/昴/星）、"太阴升殿"（月亮在月宿：心/危/毕/张）等。[文献:星平会海/卷一/星曜缠度歌/各宿注释]

### 9.4 守宫格局（主星守宫歌）

> 出处：[文献:星平会海/卷一/主星守宫歌]

**定义**：守宫格局是宫主星入命宫时的组合关系。星平会海列出7组宫主入命规则。[文献:星平会海/卷一/主星守宫歌]

| 组别 | 规则 | 歌诀要点 |
|---|---|---|
| 身命二主 | 命主入身身入命 | "内外二苔君且听，命主入身身入命。纵教生煞会凶星，富贵荣华天赋定。" |
| 财田主 | 财帛主田宅主入命 | "财帛主，田宅主，身命二星喜相遇。若无暗曜与刑囚，可与石崇斗豪富。" |
| 兄弟主 | 闲极主入命 | "闲极主，入命宫，纵为吉曜总成空。白日只宜闲袖手，不知衣禄自何从。" |
| 官禄主 | 官禄主入命 | "官禄主，入命宫，纵为忌曜不成空。命主若还入官禄，互垣终是拜三公。" |
| 福德主 | 福德主入命 | "福德主，入命来，断主福寿永无灾。命主若还居福德，互垣终是拜上台。" |
| 相貌主 | 相貌主入命 | "相貌主，入命乡，命居相貌貌堂堂。若是煞尾来会此，破相多灾貌不扬。" |
| 元守主 | 元守星论 | "论五星宿无多诀，先后宫主分明说。世人只说元守星，此主元来不是活。" |

**核心原则**：[文献:星平会海/卷一/主星守宫歌/身命二主注释]

- "身命二主，星家之录要，如在强宫，主福无疑矣。"
- 官禄主与命主互垣（命主入官禄、官禄主入命）→ "互垣终是拜三公"，是大贵之格
- 福德主与命主互垣 → "互垣终是拜上台"，也是大贵之格
- 奴仆宫主入命 → "非贫则贱"，是凶格
- 疾厄宫主入命 → "非为恶弱命，主膺之，亦主显寄"，虽为弱宫但命主居之亦可显贵

**元守主注释**："元守者，元日所生之星，以安命之宫取之，为主曜。"[文献:星平会海/卷一/主星守宫歌/元守主注释]

### 9.6 变局格局（五星变局）

> 出处：[文献:星平会海/卷一/五星变局]

**定义**：变局格局是宫位五行因三合局而变化的关系。同一宫位可能因三合局的不同而有不同的五行归属。[文献:星平会海/卷一/五星变局]

- **岁君为决**：当三属冲突时，以岁君（年干纳音）为最终决定。"须看岁君并何神"[文献:星平会海/卷一/五星变局/辰宫释云]
- **生合到则依为真**：哪个五行有生合关系到达，就以哪个为真。[文献:星平会海/卷一/五星变局/辰宫释云]
- **亥宫无反变**：亥宫是唯一没有反变的宫位——"惟此数中无反覆，闲神限宿不须观"，因为木生在亥，亥与寅合，木临官在寅，二宫俱有木神。[文献:星平会海/卷一/五星变局/亥宫释云]

- **总结**："巳上起例，宫分星度诸歌诀，乃星家纲领，命学规模，习者果熟玩，详后看法，自得于心矣。"

### 9.8 格局判断原则

> 出处：[文献:星平会海/卷一/主星守宫歌] + [文献:星平会海/卷一/五星变局] + [内知]

**原则1：格局完整度**——格局是否被破格星冲破。[内知]
- 吉格被凶星冲照 → 减分甚至破格
- 忌格被吉星化解 → 减轻凶险

**原则2：格局优先级**——不同格局有不同权重。[内知]
- 涉及日月 > 涉及五星 > 涉及四余
- 涉及命主/度主 > 涉及其他星
- 互垣格（命主与官禄主/福德主互入）为最高等级——"互垣终是拜三公"、"互垣终是拜上台"[文献:星平会海/卷一/主星守宫歌/官禄主]

**原则3：格局叠加**——多个格局同时出现。[内知]
- 多个吉格叠加 → 加倍吉利
- 吉格与忌格同时出现 → 辨主次，看力量对比

**原则4：星曜状态影响格局**——[文献:星平会海/卷一/星曜缠度歌/各宿升殿注释]
- 格局中的星曜升殿（五行与宿五行一致）→ 格局力量最强
- 格局中的星曜庙旺 → 格局力量强
- 格局中的星曜平陷 → 格局力量弱
- 格局中的星曜逆行 → 格局不稳定

**原则5：宫位强弱影响格局**——[文献:星平会海/卷一/主星守宫歌/身命二主注释]
- "身命二主，星家之录要，如在强宫，主福无疑矣。"
- 格局中的星在强宫（命/官禄/田宅/妻妾/男女/福德/财帛）→ 格局力量强
- 格局中的星在弱宫（兄弟/奴仆/疾厄/相貌/迁移）→ 格局力量弱

**原则6：变局影响五行判断**——[文献:星平会海/卷一/五星变局]
- 宫位五行不是固定的，需考虑三合局变局
- 变局后五行关系改变，格局的吉凶可能反转
- "命宫为体限为用，命主论宫限论度"——命宫论宫位五行，限运论度数五行

**原则7：元守为主**——[文献:星平会海/卷一/五星变局/命宫]
- "命宫莫把他星取，但于安命求元守。"
- 元守星（出生时安命宫取的主曜）是格局判断的核心
- "世人只说元守星，此主元来不是活"——元守星不是固定不变的，需结合行限变通
