## 08 · 状态判断

### 8.1 庙旺平陷

每个天体在每个地支位置有不同的力量状态，从强到弱：

| 状态 | 含义 | 力量 |
|---|---|---|
| 殿 | 星曜入本殿（最高尊严） | 最强 |
| 垣 | 星曜入本垣 | 极强 |
| 庙 | 星曜入庙 | 强 |
| 旺 | 星曜入旺 | 较强 |
| 乐 | 星曜乐居 | 中等偏上 |
| 喜 | 星曜喜居 | 中等 |
| 怒 | 星曜怒居（受克） | 弱 |

庙旺平陷表是七政四余的核心数据之一——11个天体×12地支 = 132个状态。星曜在庙旺则力量充分发挥，在平陷则力量受制。

### 8.2 长生十二运

以五行属性为基准，判断每个天体在各地支的"生命阶段"：

| 阶段 | 含义 |
|---|---|
| 长生 | 出生，力量初生 |
| 沐浴 | 沐浴，力量脆弱 |
| 冠带 | 成人，力量渐增 |
| 临官 | 入仕，力量强盛 |
| 帝旺 | 鼎盛，力量最强 |
| 衰 | 衰退，力量开始下降 |
| 病 | 病态，力量减弱 |
| 死 | 死亡，力量极弱 |
| 墓 | 入墓，力量封藏 |
| 绝 | 绝灭，力量消失 |
| 胎 | 受胎，力量孕育 |
| 养 | 养育，力量恢复 |

不同五行的长生起点不同：
- 木长生在亥，顺行
- 火长生在寅，顺行
- 金长生在巳，顺行
- 水长生在申，顺行
- 土长生在寅（与火同），顺行

### 8.3 纳音五行

60甲子纳音系统，每个干支组合对应一个纳音五行：
- 例如：甲子乙丑 → 海中金
- 纳音五行用于补充判断干支的五行属性
- 在七政四余中，纳音主要用于年柱和日柱的五行判断

### 8.4 五行生克与恩用仇难

以命主星的五行为基准，建立五行关系体系：

| 关系 | 定义 | 含义 |
|---|---|---|
| 恩 | 生我者 | 帮助、滋养 |
| 用 | 我生者 | 消耗、付出 |
| 仇 | 克我者 | 压制、阻碍 |
| 难 | 我克者 | 控制、获得 |

例如，命主为木：
- 恩 = 水（水生木）
- 用 = 火（木生火）
- 仇 = 金（金克木）
- 难 = 土（木克土）

恩星入命宫或三方四正 → 大吉；仇星入命 → 凶。这是判断星曜吉凶的基本框架——同一颗星对不同命主的意义不同，取决于它和命主的五行关系。
