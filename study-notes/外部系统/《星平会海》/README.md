## Check List 标记规则

```markdown
- [x] `XPATH` → study-notes/NN-步骤名（吸收方式）
- [ ] `XPATH`
- [~] `XPATH` （部分吸收，注释说明）
```

**吸收方式分类**：
- `（全文吸收）`：整条内容被吸收
- `（要点吸收）`：只吸收了要点
- `（引用吸收）`：作为典籍依据引用
- `（归纳吸收）`：被归纳进某个总结表
