## 03 · 宫位系统

### 3.1 十二宫

> 出处：[文献:星平会海/卷一/星曜照宫歌] + [内知]

七政四余使用十二宫制，每宫对应一个地支，按逆时针排列。[内知]

| 宫序 | 宫名 | 地支 | 主宰 |
|---|---|---|---|
| 1 | 命宫 | varies | 本人、性格、形体 |
| 2 | 财帛宫 | | 财富、收入 |
| 3 | 兄弟宫 | | 兄弟姐妹、邻里 |
| 4 | 田宅宫 | | 房产、家庭、父亲 |
| 5 | 男女宫 | | 子女、生育 |
| 6 | 奴仆宫 | | 下属、仆人、工作环境 |
| 7 | 妻妾宫 | | 婚姻、配偶、合作 |
| 8 | 疾厄宫 | | 疾病、灾厄 |
| 9 | 迁移宫 | | 出行、迁徙、旅行 |
| 10 | 官禄宫 | | 事业、官位、地位 |
| 11 | 福德宫 | | 福气、德行、精神 |
| 12 | 相貌宫 | | 相貌、隐秘、损失 |

十二宫从命宫起，按地支顺序逆时针排列。命宫所在的地支决定了整个宫位系统的起点。[内知]

**典籍依据——照宫歌12宫**：[文献:星平会海/卷一/星曜照宫歌]
- 星平会海卷一星曜照宫歌按12宫各自列出11星照宫歌诀，12宫分别为：命宫/财帛（二宫）/兄弟（三宫）/田宅（四宫）/男女（五宫）/奴仆（六宫）/妻妾（七宫）/疾厄（八宫）/迁移（九宫）/官禄（十宫）/福德（十一宫）/相貌（十二宫）。

### 3.2 强宫与弱宫

> 出处：[文献:星平会海/卷二/入门四十四看法/五宫强]

**强宫**：命宫、官禄、田宅、妻妾、男女、福德、财帛。又云："财帛次弱，与其命宫相违故耳。"居强宫者旺。[文献:星平会海/卷二/入门四十四看法/五宫强]

**弱宫**：兄弟、奴仆、疾厄、相貌、迁移。又云："迁移近强，与其命宫相向故也。"临弱宫者衰。[文献:星平会海/卷二/入门四十四看法/五宫强]

### 3.3 宫位制

> 出处：[内知]

七政四余通常使用**整宫制**（Whole Sign Houses）。[内知]
- 每个地支对应一个完整的宫位 [内知]
- 宫头就是该地支的起始度数 [内知]
- 不像西方占星那样用不等的宫位划分 [内知]

但也有使用**度数宫位制**的流派，以命度为起点划分12等分。[内知]

### 3.4 ASC和MC

> 出处：[内知]

- **ASC（上升点/命度）**：出生时刻东方地平线与黄道的交点 [内知]
- **MC（中天/天顶）**：出生时刻子午线与黄道的交点（最高点）[内知]

命度（ASC的精确黄经度数）在七政四余中非常重要——它决定了"度主"（命度所在宿的五行主星）。[内知]

### 3.5 三方四正

> 出处：[文献:星平会海/卷二/入门四十四看法/十三宫对] + [文献:星平会海/卷二/入门四十四看法/十四合] + [内知]

- **三方**：地支三合关系 [内知]
  - 申子辰（水局）[内知]
  - 寅午戌（火局）[内知]
  - 巳酉丑（金局）[内知]
  - 亥卯未（木局）[内知]
- **四正**：对宫关系（相隔180°）[内知]
  - 子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲 [内知]

三方四正是判断星曜关系和宫位互动的基础——一颗星在三方四正位置上对命宫的影响，与直接在命宫中的影响不同但同样重要。[内知]

**典籍依据——对与合**：[文献:星平会海/卷二/入门四十四看法/十三宫对] + [文献:星平会海/卷二/入门四十四看法/十四合]
- **对**：对照也。如子午对照，丑未对照，寅申对照，卯酉对照，辰戌对照，巳亥对照。对照吉则吉，对照凶则凶。"此谓相冲之类。"
- **合**：合拱也。申子辰合拱，寅午戌合拱，巳酉丑合拱，亥卯未合拱。合拱吉则吉，合拱凶则凶。"此谓配合之类。"
