## 06 · 化曜

### 6.1 十干化曜

> 出处：[文献:星平会海/卷二/入门四十四看法/三宫星] + [内知]

以年干为基准，推演出九个化曜星，分别落在不同地支位置。[内知]

| 化曜 | 含义 |
|---|---|
| 天禄 | 禄位，主食禄、俸禄 |
| 天暗 | 暗昧，主遮蔽、阻碍 |
| 天福 | 福德，主福气、顺遂 |
| 天寿 | 寿命，主长寿、健康 |
| 天贵 | 贵人，主贵气、地位 |
| 天刑 | 刑罚，主官非、刑伤 |
| 天印 | 印信，主权印、文书 |
| 天囚 | 囚禁，主困顿、束缚 |
| 天权 | 权力，主权威、掌控 |

每个天干对应一套化曜的地支分布，例如（以甲为例，其他天干有各自的对应表）。[内知]
- 甲：天禄在寅，天暗在卯，天福在辰，天寿在巳，天贵在午，天刑在未，天印在申，天囚在酉，天权在戌 [内知]

化曜星落入命宫或三方四正，对命格有显著影响。[内知]

**典籍依据——宫星定义**：[文献:星平会海/卷二/入门四十四看法/三宫星]
- "宫星者，谓日月木火土金水气孛罗计，兼文魁名甲宫印，经纬羽马三元四元，催官禄神喜神爵星，十干化曜等星。此为宫分相合，以布七曜。"
- 十干化曜（天禄/天暗/天福/天寿/天贵/天刑/天印/天囚/天权）属于"宫星"范畴。
