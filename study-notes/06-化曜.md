## 06 · 化曜

### 6.1 十干化曜

以年干为基准，推演出九个化曜星，分别落在不同地支位置：

| 化曜 | 含义 |
|---|---|
| 天禄 | 禄位，主食禄、俸禄 |
| 天暗 | 暗昧，主遮蔽、阻碍 |
| 天福 | 福德，主福气、顺遂 |
| 天寿 | 寿命，主长寿、健康 |
| 天贵 | 贵人，主贵气、地位 |
| 天刑 | 刑罚，主官非、刑伤 |
| 天印 | 印信，主权印、文书 |
| 天囚 | 囚禁，主困顿、束缚 |
| 天权 | 权力，主权威、掌控 |

每个天干对应一套化曜的地支分布，例如（以甲为例，其他天干有各自的对应表）：
- 甲：天禄在寅，天暗在卯，天福在辰，天寿在巳，天贵在午，天刑在未，天印在申，天囚在酉，天权在戌

化曜星落入命宫或三方四正，对命格有显著影响。

### 6.2 天干星曜与地支神煞

除了九个化曜，还有基于天干和地支的其他星曜系统：
- **天干吉凶星曜**：天干×地支 → 禄勋、天贵、官贵等
- **地支神煞**：年支×地支 → 38神曜

这些将在第七步神煞中详述。
